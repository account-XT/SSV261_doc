write_pg_library


write_pg_library
[-help]
[-out_dir dir_name]
[-library_prefix prefix]
 

Generates the output for power-grid library generation.

Parameters


-help 


Outputs the command usage.
-library_prefix prefix

Specifies a prefix for the power-grid library. When this parameter is specified, the default PGV for each cell type is as follows:

  • techonly - prefix_techonly.cl (default: techonly.cl)
  • stdcells - prefix_stdcells.cl (default: stdcells.cl)
  • macros - prefix_cellname.cl (default: macros_cellname.cl)

You can generate macro PGVs without the "macro_" string in the name and without any prefix by specifying an empty string for -library_prefix, as shown below:
write_pg_library -out_dir output_folder -library_prefix ""

–out_dir dir_name


Specifies the name of the output directory in which power-grid libraries are created. The default is the current working directory.

Note: If you specify both -out_dir output_dir and -library_prefix prefix parameters, the command generates the PGV in the output_dir directory with PGV name prefix_<name>.cl.

Examples

  •  The following command generates a power-grid library in the temp folder:
    write_pg_library -out_dir temp/
  • The following command specifies to generate a technology library with the default PGV name techonly and prefix ab:
    set_pg_library_mode –celltype techonly ...
    write_pg_library –out_dir ./ -library_prefix ab
    The generated library name will be ab_techonly.cl
  • The following command specifies to generate a macro library with the default PGV name <cell_name> and prefix ab:
    set_pg_library_mode –celltype macros ...
    write_pg_library –out_dir ./ -library_prefix ab
    The generated library name will be ab_<cell_name>.cl
