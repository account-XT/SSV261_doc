get_flow_config

get_flow_config
[-help]
key ...
[-quiet]

Returns the feature configuration for a flow.

Parameters

-help

Outputs a brief description that includes type and default information for each get_flow_config parameter.

For a detailed description of the command and all of its parameters, use the man command:
man get_flow_config
key ...
 Specifies the key to get configuration value.
-quiet
 Suppresses errors in case the key does not exist.
