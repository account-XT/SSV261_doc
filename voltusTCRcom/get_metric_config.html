get_metric_config

get_metric_config
-help
-format {html excel text}

Gets the current metric configuration setting. 

Parameters

-help

Outputs a brief description that includes type and default information for each get_metric_config parameter.
For a detailed description of the command and all of its parameters, use the man command:

man get_metric_config
-format {html excel text} Specifies configuration for the specified report_metric format.
