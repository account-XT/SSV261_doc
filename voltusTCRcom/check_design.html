check_design

check_design
[-help]
[-out_file fileName]
[-type {{power_intent feedthru pin_assign budget place opt cts route signoff all} | -no_check ]

Checks that all prerequisites to run all or part of the hierarchical or block implementation flow are met.

Parameters 

-help

Prints a brief description that includes the type and default information for each check_design parameter.

For a detailed description of the command and all of its parameters, use the man command:
man check_design.
-type

Specifies the category of the flow to be checked:

  • assign_statements: Performs checks for the netlist for assign statements.
  • power_intent: Performs checks related to MSV setup including power domain/fence checks.
  • timing: Performs checks related to timing setup integrity.            
  • feedthru: Performs checks related to feedthru insertion for partitioning flows.
  • pin_assign: Performs checks related to pin assignment for partitioning flows.
  • budget: Performs checks related to time budgeting for partitioning flows.
  • place: Performs checks related to placement such as PG rail alignment and pin access issues.
  • opt: Performs checks related to optimization such as checks for available cells.
  • cts: Performs checks related to clock tree definition such as constraint targets and route types.
  • route: Performs checks related to routing such as congestion, placement, and pin access issues.
  • signoff: Checks related to the signoff activities including extraction and ECOs.
  • all: Runs all categories.
-no_check

Just echo out all the messages that would be checked, don't do any checks

Do not run the checks but echo the checks that would run per the categories provided by the user

-out_file fileName

Specifies the output report file. Contents dumped to this file in the Tcl format.
