compare_oa_cellview

compare_oa_cellview
[-help] 
[-ignore {pin_purpose}]
[-out_file report_file_name] 
{ {{-source {from_lib from_cell from_view} -compare {to_lib to_cell to_view}} | {-lib lib -cell cell -view {sourceView compareView}}} }

Compares specified cell views. Use this command to compare two OpenAccess databases. For instance, you can use this command to compare the lib/cell/view specified using -source to the lib/cell/view specified with -compare. In an abstract to layout comparison, boundary and terminals (name, direction, pin location and size) are compared.

Parameters

-help

Prints a brief description that includes type and default information for each compare_oa_cellview parameter.

For a detailed description of the command and all of its parameters, use the man command: man compare_oa_cellview.
-cell cell

Specifies the cell for comparing two views.

Data_type: string, optional
-compare {to_lib to_cell to_view}

Specifies the library/cell/view that is to be compared.

Data_type: string, optional
-ignore {pin_purpose}

Specifies the list of attributes to be excluded from the cell comparison. As of now, the only attribute that can be ignored is the purpose, which is specified using the value pin_purpose with -ignore.

Data_type: (enum)+, optional
-lib lib

Specifies the library for comparing two views.

Data_type: string, optional
-out_file report_file_name

Specifies the report file in which all the comparison detail is to be written.

Data_type: string, optional
-source {from_lib from_cell from_view}

Specifies the source library, cell, and view.

Data_type: string, optional
-view {sourceView compareView}

Specifies different views of the same library/cell.

Data_type: string, optional

Example

  • The following command compares two views of the same cell that are present in the same library myLib:
    compare_oa_cellview -source {myLib block1 layout} -compare {myLib block1 abstract}
