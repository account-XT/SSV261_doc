read_power_intent

read_power_intent
[-help]
power_intent_file
{-cpf | -1801 | -msv_db }

Reads IEEE1801  file for specifying power intent for the design for use in verification and implementation of the structure and behavior of the design in context of a given power management architecture. The method supports incremental refinement of power intent specifications required for IP-based design flows.

Parameters

-help

Prints a brief description that includes type and default information for each read_power_intent parameter.

For a detailed description of the command and all of its parameters, use the man command:

man read_power_intent

power_intent_file 

Specifies name of the IEEE1801 input file.

-cpf

Specifies name of the input file in CPF format.

-1801

Specifies the input file in IEEE1801 format.

-msv_db

Specifies the IEEE1801 data file (.cpfdb).

Note: -msv_db is for partition flow and must be read for power intent in partition implementation.
