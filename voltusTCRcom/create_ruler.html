create_ruler

create_ruler
[-help] {{-center {x y} -radius value} | -coords {x1 y1 x2 y2 ...}}

Adds a ruler. For an orthogonal ruler, use -coordinates to specify ruler segments. For a circular ruler, use -center and -radius.

Parameters

-help

Prints a brief description that includes type and default information for each create_ruler parameter.

For a detailed description of the command and all of its parameters, use the man command: 
man create_ruler
-center {x y}

Specifies the coordinates for the center of a circular ruler. 

Data_type: point, optional
-coords {x1 y1 x2 y2 ...}

Specifies the beginning and ending coordinates for the ruler line segments. The values are in microns.

Data_type: (point)+, optional
-radius value

Specifies the radius of a circular ruler.

Data_type: double, optional

Example

  • The following command creates a circular ruler of radius 500 with the center at {0 0}:
    create_ruler -center {0 0} -radius 500
