flowtool

flowtool
[-flow <>] [-from <> [-ref_run <>]] [-to <>]
[l][-files <>][/l]
[-overwrite]
[-display {all | trunk}]
[-dist <>]
[-dir <>] [-db <>]
[-enabled <>] [-inject_tcl <>]
[-isolate]
[-legacy_ui | -common_ui]
[-predict {script | summary | verbose | tcl}]
[-run_tag run_tag_value]
[-metrics_file]
[-status]
[-version]

flowtool provides a way to run flows from the command line. In addition to providing another interface to existing Flowkit functionality, it enables multi-session, multi-tool and branching flows.  

Note: TCL 8.5 or higher is required to run flowtool.

Parameters

-common_ui Runs the command in common user interface (default).
-display

Filters the output to various types of flows. Possible values are all and trunk.

-flow

Specifies that the flow has started running.
-from Specifies the step (inclusive) to start running the flow accepting a full dotted, comma-separated, and case-insensitive canonical path to a flow step object.
-ref_run If -from is specified, the -ref_run option points to a working directory/database of a previous run.
-to Specifies the step (inclusive) to stop running the flow accepting a full dotted, comma-separated, and case-insensitive canonical path to a flow step object.

-files

Specifies the tcl scripts describing the flow and flow steps

Default:  flow.scripts/run_flow.tcl
-overwrite Ignores any existing steps that have been run and runs those again.
-dist Specifies the distribution script and arguments to be prepended to the command line when executing tools.
-dir Changes to the named directory before doing anything else (including looking for starting scripts); analogous make’s –C argument.
-db Specifies the database to be used to start the run.
-isolate Runs each step in its own tool session.
-legacy_ui Runs the command in legacy user interface.
-predict Specifies the prediction of the flow that will run (before executing the flow). Possible values are script, summary, verbose, and tcl.
-run_tag run_tag_value

Sets the -dir option to the same as the run_tag_value, if the -dir option is not specified. Additionally, it updates the tool startup code to include:
set_db flow_run_tag <value>
-enabled Enables the specified features.
-inject_tcl Injects the specified TCL into every step.
-metrics_file Overrides the location of the flow.metrics file (unless the file is provided), and keeps any existing metrics.
-status Prints the execution status (completed steps) of a run.
-version Displays the version number and exits from the tool.
