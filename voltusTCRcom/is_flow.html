is_flow

is_flow
[-help]
[-after string]
[-before string]
[-hierarchical]
[-inside string]
[-quiet]

Allows you to query during the execution of a flow for further action.

Parameters

-help

Outputs a brief description that includes type and default information for each is_flow parameter.
-after string

Specifies the current execution after the flow or flow_step object.
-before string Specifies the current execution before the flow or flow_step object.
-hierarchical Displays all parent flows.
-inside string Specifies the current execution within the flow object.
-quiet Ensures that errors are not reported for missing flow or flow_step objects.
