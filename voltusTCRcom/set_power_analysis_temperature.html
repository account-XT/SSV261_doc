set_power_analysis_temperature

set_power_analysis_temperature
[-help]
temperature

Sets the temperature for static power calculation.

In the presence of a trilib set, the internal and leakage power will be interpolated as the per the given temperature specification.

Parameters


-help

Outputs a brief description that includes type and default information for each set_power_analysis_temperature parameter.

For a detailed description of the command and all of its parameters, use the man command:

man set_power_analysis_temperature

temperature

Specifies the temperature for static power calculation.

The static power calculation software gets the temperature value of each instance from the following sources (in order of precedence):

  • Instance temperature file
  • set_power_analysis_temperature command
  • The current operating condition temperature
