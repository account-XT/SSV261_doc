edit_flow

edit_flow
[-help]
[-after string]
[-append string]
[-before string]
[-enabled_feature string]
[-owner string]
[-prepend string]
[-reset]
[-unique]

Allows you to insert flow steps into an existing flow without redefining the flow itself. This command is very useful for flow customization.

Parameters

-help

Outputs a brief description that includes type and default information for each edit_flow parameter.
-after string

Adds the specified flow and/or flow_step objects after the flow supporting a full canonical path to a flow step object.
-append string

Appends the specified flow and/or flow_step objects before or after the flow.
-before string Adds the specified flow and/or flow_step objects before the flow supporting a full canonical path to a flow step object.
-enabled_feature string Executes the edit_flow command only if the specified user-defined features are enabled.
-owner string Specifies the owner of the flow being edited.
-prepend string Adds the specified flow and/or flow_step objects before or after the flow.
-reset Resets the customizations for the specified flow and/or flow_step objects before or after the flow.
-unique

Prevents the addition of the flow and/or flow_step objects, if those are already provided. This avoids duplication of the flow defined in the YAML file and the edit_flow statements scripted in the tech_flow_steps file.

Note: This parameter prevents the specified flow_step from getting added to the same flow twice, irrespective of the values provided to the -after or -before parameters. For example, if edit_flow -append bob -unique is called twice to insert different flow_steps in the floorplan flow, it will add bob only once.

See also:

Flowkit chapter of the Stylus Common UI Migration Guide document.

Examples

  • Following is an example of customizing the reference flow process using the flow_config.template file:

    create_flow_step -name write_sdf {

    write_sdf [get_db flow_report_directory]/[get_db local_flow].sdf

    }

    edit_flow -after flow_step:innovus_report_late_timing -append flow_step:write_sdf
  • Following is an example of inserting an additional step_2 step after the step_1 step:
    set file_dir [file dirname [ dict get [ info frame [ info frame ] ] file ] ]
    source ${file_dir}/scripts/run_flow.tcl
    create_flow_step -name step_2 {
    }
    edit_flow -append step_2 -after step_1 
  • Following is an example of adding flow customization to the flow_config.tcl file:
    create_flow_step -name output_files {
    set design_name [get_db current_design .name]
    write_netlist [get_db flow_report_directory]/${design_name}.v
    write_def [get_db flow_report_directory]/${design_name}.def
    }
    edit_flow -append flow_step:output_files -after flow_step:block_finish
