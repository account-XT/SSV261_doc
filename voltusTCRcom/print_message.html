print_message

print_message
-help 
formatString
[args]
[-error]
[-warning]

Generates a message that is included in the report_messages output if the message is designated as an error or a warning.

Parameters

args Specifies the format argument value to print. 
-error Specifies the message is an error. A prefix will be added.
formatString Specify the format specifier like sprintf or Tcl's format command.
-help

Prints a brief description that includes the type and default information for each print_message parameter.

For a detailed description of the command and all of its parameters, use the man command: 
man print_message.
-warning Specifies that the message is a warning. A prefix will be added.


Examples

The following commands generate an error and a message, which are included in the report_message output:

> print_message -error "A test %s." "from the user"
ERROR: (user): A test from the user.


> print_message -warning "A test %s." "from the user"
WARN: (user): A test from the user.


> print_message "A test %s." "from the user"
A test from the user.


> report_messages
*** Summary of all messages that are not suppressed in this session:
Severity      ID       Count         Summary 
ERROR       no_id       1            A test %s.
ERROR       user        1            A test %s.
WARN        user        1            A test %s.
*** Message Summary: 1 warning(s), 2 error(s)
