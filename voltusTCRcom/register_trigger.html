register_trigger

register_trigger
[-help]
[{-pre | -post}
command_name
proc_name]

Registers the -pre or -post callback procedures with the specified commands.

The procedure registered with -pre parameter runs before the command_name parameter is used while the procedure registered with -post parameter runs after the command_name parameter is used.

Note: The arguments passed to command_name are passed to proc_name. If the procedure registered with the -pre parameter returns a TCL_ERROR, then command_name is not run.

You can use the register_trigger command after starting the software.

Parameters

-help

Outputs a brief description that includes type and default information for each register_trigger parameter.

For a detailed description of the command and all of its parameters, use the man command: man register_trigger.

-pre

Specifies the procedure to be called before the command.

-post

Specifies the procedure to be called after the command.

command_name

Specifies the command name. The supported command names are read_db, write_db, read_oa, and write_oa.

proc_name

Specifies the procedure name that is to be registered as callback.
