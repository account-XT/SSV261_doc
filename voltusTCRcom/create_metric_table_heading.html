create_metric_table_heading

create_metric_table_heading
[-help]
[-format {html excel text}]
[-id heading_id]
-page page_name
-title heading_title
[-type {fixed collapse}] 

Create a new metric heading.

Parameters

-help

Prints out the command usage.

For a detailed description of the command, use the man command:
man create_metric_table_heading
-format {html excel text} Specifies configuration for the report_metric format.
-id heading_id Specifies the id for the new heading.
-page page_name Specifies the page name where the heading will be added.
-title heading_title Specifies the title of the heading.
-type {fixed collapse} Specifies the type of heading element, fixed or collapse.
