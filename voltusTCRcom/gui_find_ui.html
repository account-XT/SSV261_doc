gui_find_ui

gui_find_ui
[-help]
[name]
[-before name]
[-checked true | false]
[-command string]
[-disabled true | false]
[-enable_variable string]
[-foreground string]
[-icon filename]
[-in parent_name]
[-label string]
[-movable true | false]
[-newline true | false]
[-shortcut string]
[-tooltip string]
[-type {menu toolbar submenu command check radio separator toolbutton}]
[-underline index]
[-value string]
[-variable string]
[-visible_variable string]

Enables you to retrieve an element's name by specifying a property-value combination.

Parameters 

-help

Prints a brief description that includes type and default information for each gui_find_ui parameter.

For a detailed description of the command and all of its parameters, use the man command:

man gui_find_ui

name

Specifies the name of the parent element to define the search scope. If multiple elements are found with the same name, the first matched element is searched. If name is not specified, a global search is performed.

Data_type: string, optional

-before name

Returns the element that is positioned just before the element identified by name.

Data_type: string, optional

-checked {true | false}

Returns the names of check boxes and radio buttons with the specified checked state.

Data_type: bool, optional

-command string

Returns the name of the interface element that executes the specified command string.

Note: You can use the -command parameter only for elements of type command, check, radio or toolbutton.

Data_type: string, optional

-disabled {true | false}

Returns the name of the interface elements with the specified state.

Note: You can use the -disabled parameter only for elements of type menu, submenu, command, check, radio or toolbutton.

Data_type: bool, optional

-enable_variable string

Returns the name of the interface elements with the specified Enable status.

Data_type: string, optional

-foreground string

Returns the name of the tool button with the specified foreground color of the icon.

Note: You can use the -foreground parameter only for elements of type toolbutton.

Data_type: string, optional

-icon filename

Returns the name of the tool button with the specified image file in its icon. filename can be the full path of the icon file or an icon name supported by the tool.

The icon names used in the tool can be queried using the gui_get_ui command.

Note: The -icon parameter is applicable only for elements of type toolbutton.

Data_type: string, optional

-in parent_name

Returns the name of the interface elements with the specified parent name.

Data_type: string, optional

-label string

Returns the name of the interface element with the specified label.

Note: This parameter is NOT applicable for elements of type separator.

Data_type: string, optional
-movable true | false Returns whether the object is movable or not. This parameter is applicable only for elements of type toolbar.

Data_type: bool, optional

-newline {true | false}

Returns the name of the toolbars with the specified newline status.

Note: The -newline parameter is applicable only for elements of type toolbar.

Data_type: bool, optional

-shortcut string

Returns the name of the interface elements with the specified shortcut key.

Note: You can use the -shortcut parameter only for elements of type command, check, radio, or toolbutton.

Data_type: string, optional

-tooltip string

Returns the name of the toolbar or toolbutton with the specified tooltip text.

Note: The -tooltip parameter is applicable only for elements of type toolbar and toolbutton.

Data_type: string, optional

-type {menu | toolbar | submenu | command | check | radio | separator | toolbutton}


Returns the name of the interface elements of the specified type.

Data_type: enum, optional

-underline index

Returns the name of the interface elements that has character with the specified integer index underlined in the element label. The index begins with 0, so for example, to find elements that have the third character in their label underlined, specify an index value of 2.

Data_type: int, optional

-value stringValue

Returns the name of the radio button with the specified value.

Note: The -value parameter is applicable only for elements of type radio.

Data_type: string, optional

-variable string

Returns the name of the check boxes or radio buttons with the specified the Tcl global variable.

Data_type: string, optional

-visible_variable string

Returns the name of the interface elements with the specified Visible status.

Data_type: string, optional

Examples

  • The following command returns the names of all the menus in the main window:
    gui_find_ui main -type menu
  • The following command returns the name of the element before the Help menu in the main window:
    gui_find_ui -before help
