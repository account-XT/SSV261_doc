monitor_distributed_hosts

monitor_distributed_hosts
[-help]
[-kill_on_insufficient_resource]
[-log string]
[-min_required_tmp_space integer]
[-overwrite]
[-period integer]

Monitors hosts and periodically dumps memory or CPU usage information for each host to a file. If there are multiple hosts for a distributed flow (e.g., DMMMC in STA), then details of each host will be logged. This command automatically determines the hosts to be monitored. By default, after every 60 seconds hosts are monitored and the disk information is written to a log file.

The monitor_distributed_hosts command is also supported in DSTA mode. 

Parameters

-help

Prints out the command usage. For a detailed description of the command and all of its parameters, use the man command: man monitor_distributed_hosts.

-kill_on_insufficient_resource

Terminates the session if a host resource is below the specified threshold values.

-log string

Specifies the log file name.

Default: host-monitor.log

-min_required_tmp_space integer

Specifies the condition for insufficient resources.

This option should be used with the -kill_on_insufficient_resource parameter.

-overwrite

Overwrites the log file, if it already exists.

-period integer

Specifies the sampling period after which hosts will be monitored.

Default: 60
