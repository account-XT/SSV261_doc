Voltus Stylus Common UI Text Reference Manual
Product Version 26.10, May 2026

man

man
command_name | msg_id

Displays information for a command or variable from the Voltus Text Command Reference, or prints detailed information for a specified message ID. If no manual page is located, man prints an error message.

The man pages for Voltus commands and variables are located in the following directory:

<install_dir>/<platform>/share/fe/man

Parameter 

command_name

Indicates the name of the text command (or variable) for which the manual information is required.

msg_id

Specifies the unique message ID for which you want to display detailed information. The output is categorized in three sections:

  • NAME: Displays the message ID and its severity level.
  • SYNOPSIS: Displays the summary of the message text.
  • DESCRIPTION: Displays detailed information about the message. The detailed information can include the background of the message, likely causes, and alternative steps to troubleshoot the problem.

Example

  • The following command returns the manual description of the command report_power:
    man report_power
  • The following command returns the manual description of the SOCSYC-139 message ID:
    man SOCSYC-139
