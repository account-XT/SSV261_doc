create_port

create_port 
[-help] 
[-bus msb:lsb] 
-direction {in out inout} 
-name port_name

Create new ports for a design object and returns the newly created port object pointer.  It also implicitly creates hnet and net objects with the same name connected to the port.

Parameters

-bus msb:lsb

Specifies the bit range for bus ports.

Default is to create a scalar port.
-direction {in out inout}

Specifies the direction of the new port, in, out, inout.
-help

Outputs a brief description that includes the type and default information for each create_module parameter.

For a detailed description of the command and all of its parameters, use the man command: man create_module
-name module_name

Specifies the name of the new port. If the name has any illegal chars, it will be automatically escaped.  Therefore, -name "p1/2" will result in "p1\/2" for the .escaped_name, since it uses DEF escaping semantics. This is equivalent to checking if port_name is a legal Verilog identifier, and if not, prepend \ and add a trailing space to the internal Verilog name.

Example

  •  The following command creates a new input scalar port called P1:
    create_port -name P1 -direction in
  • The following command creates a new 8-bit output port called BP1
    create_port -name BP1 -bus 7:0
