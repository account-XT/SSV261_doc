report_area

report_area
[-help]
[-detail]
[-hierarchical_instance hinst_name]
[-include_physical]            
[-min_area area_per_module] 
[-min_count instance_count]
[-out_file filename]
[-show_leaf_cells]
[-show_msv_cells]
[-sort_by {name count area}]
[-table_style {horizontal vertical}]    
[-summary | -depth depth_of_hierarchy]                        

Reports the combined standard cell area in each of the hierarchy modules and the top-level design. Also reports the cell area based on different cell types if the -detail option is specified.

Note: The units used in the report depend on the units used in the library. The area for each module is calculated from all the standard cells within each module using the LEF information.

Parameters

-help

Prints a brief description that includes type and default information for each  report_area  parameter.

For a detailed description of the command and all of its parameters, use the man command:

man report_area 

-depth depth_of_hierarchy

 Specifies the depth of hierarchy, all levels if not specified; the top of the hierarchy (design) is 1.
-detail Report the area in different cell type (buffer, inverter, combinational, flop, latch, clock_gate, macro, physical).
-hierarchical_instance hinst_name Reports the area of the leaf instances in the specified hierarchical instance. You can use the -depth option to control the analysis depth of the specified hierarchical instance.
-include_physical Specifies to include physical cells in the area calculation and report. By default, it reports only logical cells.
-min_count instance_count                    

Specifies the min instance count per module. The generated output will report the area of hinsts with number of instances greater than the specified min_count value.

Default: 0
-min_area area_per_module                            

Specifies the min area per module.  The generated output will report the area of hinsts with area greater than the specified min_area lib_units.

Default: 0
-out_file filename
 Specifies the name of the output file.
-show_leaf_cells

Specifies to include the leaf cells at the design level and each hinst level. These are the instances whose parent is the hinst display.

Default: 0 (Shows the hinst children in the report)
-show_msv_cells

Includes multiple supply voltage cells in the report. This option works with "-table_style vertical"
-sort_by {name count area}

Specifies the order of hinst names.

Default: name
-summary Prints the area summary for the design. It is equivalent  "-depth 0".
-table_style {horizontal vertical}

Specifies whether the base report should be expanded in the vertical or horizontal direction.

Default: horizontal
