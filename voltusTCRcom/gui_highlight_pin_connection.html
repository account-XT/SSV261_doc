gui_highlight_pin_connection

gui_highlight_pin_connection
[-help]
-from_pin pin
[-mode {wire_segment | whole_net | flight_line}]
-to_pin pin
[-with_arrow | -select_only]
[-net_color_index index_value | -select_only]
[-inst_color_index index_value | -select_only]

Highlights the full timing path or its segment in the text format while generating the sign-off timing report. Use this command to quickly debug the timing path (timing point information) used in the tool.

Parameters

-help

Prints a brief description that includes the type and default information for each gui_highlight_pin_connection parameter.

For a detailed description of the command and all its parameters, use the man command:

man gui_highlight_pin_connection
-from_pin pin Specifies the name of the starting pin to be highlighted.
-inst_color_index index_value Specifies the instance color index value (an integer value from 1 to 64) for the specified timing path.
-mode {wire_segment | whole_net | flight_line} Specifies the draw mode between the starting and ending pins.
-net_color_index index_value Specifies the net color index value (an integer value from 1 to 64) for the specified timing path.
-select_only Selects only the specified path for highlighting.
-to_pin pin Specifies the name of the ending pin to be highlighted.
-with_arrow Specifies whether or not the connection is defined with an arrow.

Example

The following command highlights a line drawn from the specified input pin to output pin while generating the sign-off timing report:

gui_highlight_pin_connection -from_pin ffa/Q -U7/A -mode flight_line
