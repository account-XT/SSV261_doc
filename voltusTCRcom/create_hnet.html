create_hnet

create_hnet
[-help] 
[-bus <msb:lsb>]
{-name <hnet_name> }
[-parent <module|hinst|design>]

Creates a new hnet (and parent net) object and returns the newly created hnet object pointer.

Parameters

-bus msb:lsb

Specifies the bit range for bus nets.

By default, the tool creates a scalar hnet.
-ground Creates a ground net.
-help

Outputs a brief description that includes the type and default information for each create_hnet parameter.

For a detailed description of the command and all of its parameters, use the man command: man create_hnet
-name hnet_name

Specifies the name of the new hnet. If this is the full hierarchical path, then the parent will be derived from the name (i.e. the parent name is the string before the last "/".  In this case, the base_name of the new hnet (i.e. the string after the last "/" should not have any special characters that require escaping.

When the -parent option is used, the name is the base_name of the new hnet.  If the name has any illegal chars, it will be automatically escaped.  Therefore, -name "i1/n2" will result in "i1\/n2" for the .escaped_name, as it uses DEF escaping semantics.  This is equivalent to checking if hnet_name is a legal Verilog identifier, and if not, prepend \ and add a trailing space to the internal Verilog name.
-parent module|hinst|design 

Specifies the parent for the new hinst. It supports both the object or the name for the specified object types, module, hinst, design. 

Default is the current design.
-power Creates a power net.

Example

     CPU

      |

      +----------------+

      |                |

      H1 (alu)         H2 (fsm)

      |

      +----------------+

      |                |

     + H1 (add)        H2 (mult)


  • The following command creates a scalar top level net/hnet named N1 
    create_hnet -name N1 
  • The following command creates a 8-bit net/hnet named H1/H1/B1
    create_hnet -name B1 -bus 7:0 -parent module:add
  • The following command creates an 8-bit net/hnet named H1/H1/B1        
    create_hnet -name B1 -bus 7:0 -parent H1/H1
