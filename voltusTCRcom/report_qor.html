report_qor

report_qor
[-help]
[pattern]
-out_file fileName 
[-format {html json}]
[-id metricID]
[-names listOfNames]

Allows the user to generate reports in various file formats.  

Parameters

-help

Prints a brief description that includes the type and default information for each system root attribute.
pattern Specifies the pattern to be matched.
-out_file fileName Specifies the name of the target file. 
-format {html json} Specifies the output format.
-id metricID  Specifies the ID of metrics to report. 
-names listOfNames Specifies the list of names. You can use wildcards.
