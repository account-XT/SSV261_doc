report_rail


report_rail
[-help]
name
[-output_dir directory_name]
[-type {domain | net}]

Runs rail analysis on a net or domain. This command must be specified after defining the rail analysis mode properties using the set_rail_analysis_config command.

Parameters

-help

Outputs a brief description that includes type and default information for each report_rail parameter.

For a detailed description of the command and all of its parameters, use the man command:

man report_rail

name

Specifies the name of the domain or net that you want to analyze.

-output_dir directory_name


Specifies the name of the directory in which to store the output directories created during the analysis.

Default: Current working directory.

-type {domain | net}


Specifies whether to run rail analysis on a domain or a net. A domain is a list of power or ground nets to analyze together. See set_power_pads  for more details.

You can specify the variable "ALL" to analyze all domains. The domain name or the net name must be specified at the end of the command line, as shown below:

report_rail -type net -output_dir ./ vdd

Examples

  • The following command performs an analysis for the vdd net and places the results directories in the analysis_out directory:
    report_rail -type net -output_dir analysis_out vdd
  • The next command performs rail analysis on TDSP power domain and writes the results in current working directory.
    report_rail -type domain -output_dir ./ TDSP
  • The following command performs rail analysis on all power domains and writes the results in the current working directory:
    report_rail -type domain -output_dir ./ ALL
