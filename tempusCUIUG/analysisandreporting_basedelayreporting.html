Base Delay Reporting

The following commands can be used to generate reports on base delay:

  • report_timing
  • report_delay_calculation

Using the report_timing Command

You can use the report_timing command to report the base delays on a timing path. It is recommended to use the report_timing -split_delay parameter to produce a comprehensive report.

tempus > set_db timing_report_fields {hpin cell transition delay arrival}
