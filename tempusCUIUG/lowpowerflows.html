Low Power Overview

Along with capturing design and technology-related power constraints, the Common Power Format (CPF) defines timing analysis views based on combinations of operating corners, power modes, and timing library sets. CPF does not contain RC corner information. To update the RC corners for each timing view, you must use the Tempus command to define the RC corners.
