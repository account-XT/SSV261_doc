Types of Foundation Flows

In Tempus, you have three stand-alone foundation flows. These are:

  • MMMC Signoff flow
  • CPF-based MMMC Signoff flow
  • Single-view non MMMC flow

Each flow can either load an Innovus database or can source some other input files. For non-Innovus based flow, various input files such as design data, library information are sourced and the design is loaded. You can also load some other input files such as SDF, TWF, or IR drop files for all type of flows.

Each flow has its own setup file to configure the design. You can use one of the following pre-defined scripts to run these flows:

  • timing analysis: run_aae.tcl
  • tempus signoff optimization fixing: run_eco.tcl

For example, the Single view non MMMC flow has setup_default.tcl to configure its design, and run_aae.tcl to run the flow.
