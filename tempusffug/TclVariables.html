Tcl Variables

The Foundation Flow requires a configuration file (setup.tcl) that defines the necessary information to execute the flow including pointers to design data and command option information. Under the TEMPLATES directory, there are three sample setup files for different flows. You can copy these setup files to the running directory, rename these setup files to setup.tcl, and modify these as required.

  • setup_mmmc.tcl File Defines the variables to use in the MMMC analysis. This script is unique for each design and is the only script that you must edit. It is the source of all input flows, and is a superset of the configuration file that includes design data, library information, and flow control.
  • setup_cpf.tcl File This template is for the low power design specially, which uses the cpf file as the power domain definition file.
  • setup_default.tcl File This template is used for the single view non MMMC flow; if you have only one view to analyze and do not want to define view definition.
Two sample setup.tcl files have been provided that are able to run through. The setup.tcl files - one for single view non MMMC flow is located at EXAMPLES/TEMPUS/dtmf/WORK directory and the other for MMMC flow is available at EXAMPLES/TEMPUS/dtmf_mmmc/WORK directory. The required libraries, netlists, and SPEF data is also included in the EXAMPLES directory.
