Stylus Release Overview

The Certus Closure Solution software, also known as Certus, is a next generation design closure solution that enables engineers to perform distributed ECO on larger and complex designs. It provides enhanced performance and capacity by using the Paradime architecture that fully leverages multiple threads on distributed processes allowing maximum scalability. Certus provides a flexible computing environment, which ensures that a single user can perform subsystem/full-chip ECO timing/power closure, while reducing turnaround time from several days to hours. 

Another advantage of this solution is that Certus allows users to perform ECO routing and parasitic extraction in batch mode, in order to collect updated parasitic, and perform updated timing analysis with signoff accuracy post ECO within the same session.

Currently, users perform timing analysis runs and ECO closure runs in separate sessions if the design has a large number of MMMC views. After the ECO closure run, users need to implement ECOs, collect new Verilog and SPEF data, and then perform post ECO timing analysis. 

The Certus software addresses these usability concerns by automating all these steps through a single cockpit and a single session. 

Other advanced ECO solutions, such as High Capacity ECO (allows to reduce database size), and SmartMMMC (allows compact timing graph when large number of timing views are used), are complementary to Certus.

For more details, refer to the following Certus documents:

  • Certus Stylus Text Command Reference
  • Certus Stylus User Guide
