Read Design

Use the Restore Design form to read design data.

  • Choose File - Read Design.

The Restore Design form has two options:

  • Tempus Timing Solution
  • OA

These are explained below.

  • Restore Design - Tempus Timing Solution
  • Restore Design - OA

Restore Design - Tempus Timing Solution

Use the Restore Design form to load saved data from a previous design session.

Restore Design - Fields and Options

Restore Design File

Specifies the name of the design file to load.

With ERROR Line messages

Reads the file, including error messages.

With WARN Line messages

Reads the file, including warnings.

Read Physical Data

Reads physical data.

Related Text Commands

The following text command provides equivalent or additional functionality:

  • read_design

For more information, see the "Design Import Commands" in Tempus Text Command Reference.

Restore Design - OA

The OA option within the Restore Design form is used to restore all the design information from the previous design session, using the OpenAccess database format.

Restore Design - OA Fields and Options

Library

Specifies the location of the OpenAccess database to be restored. It contains the cell and the view to be restored.

The Setup tab contains the Verilog and OA radio buttons that changes the form from the current LEF based style (default) to the OpenAccess-based style.

Cell

Specifies the design cell from the library that is to be restored.

View

Specifies the view name of the cell that is to be restored.

Default: The layout view.

Library File Path

Specifies the full path to the library definitions file (cds.lib).

Read Physical Data

Reads physical data.

Browser button

Opens the Library Browser form, which enables you to browse available libraries, cells, or views.
