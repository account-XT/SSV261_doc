Power Analysis

The Power Analysis sub-menu contains the following items:

  • Set Power Analysis ModeOpens the Set Power Analysis Mode form
  • Run Power AnalysisOpens the Run Power Analysis form

Set Power Analysis Mode

The Set Power Analysis Mode form contains the following pages:

  • Set Power Analysis Mode - Basic
  • Set Power Analysis Mode - Advanced

Set Power Analysis Mode - Basic

Specifies whether static or dynamic power analysis should be run and some additional settings.

Fields and Options

Analysis Method

Specifies either static or dynamic power analysis

Dynamic Power Method

If dynamic power analysis is set this specifies if the method of analysis is vector less or vector-based.

Disable Static Analysis

When selected in the dynamic vector-based or dynamic vectorless flows, the command performs only dynamic analysis and turns-off static power calculation.

Default: Not selected for Static analysis method, selected for Dynamic analysis method.

Analysis View

Specifies the Analysis view.

Corner

Specifies the corner via a pull-down list. The choices are min, or max.

Default: max

Switch off Power Nets

Specifies if power nets should be switched off.

Create Power Binary Database

Specifies that a binary power database should be created. This can be used for viewing the power data graphically.

Write Current Files

Specifies to generate the current data files, one current data file per net.

Default: true

PowerGrid Libraries

Specifies the name of the Cadence power cell libraries (.cl).

Set Power Analysis Mode - Advanced

Fields and Options

Use Negative Internal Power in Timing Library

Specifies to keep negative internal energy numbers from the .lib internal power table. When not set, negative power is treated as 0.

Default: true

Ignore Control Signals

If set specifies that control signals will be ignored when propagating activity.

Default: true

X Transition Factor

When using VCD one can specify how transitions to and from X are counted. These transitions are defined as shown in Table. Transitions to and from the X state will be treated as full transitions multiplied by the specified factor.

Default: 0.5

Z Transition Factor

When using VCD one can specify how transitions to and from Z are counted. These transitions are defined as shown in Table. Transitions to and from the Z state will be treated as full transitions multiplied by the specified factor.

Default: 0.25

Transitions from/to X and Z Values

to/from X

[ 0 or 1 or Z] <-> X

0.5

to/from Z

Run Power Analysis

The Run Power Analysis form has five pages:

  • Run Power Analysis - Basic
  • Run Power Analysis - Activity
  • Run Power Analysis - Power
  • Run Power Analysis - Advanced

Run Power Analysis - Basic

Runs the power analysis with the provided parameters.

Fields and Options

Input Activity

Specifies the average number of times as a (Specified as a fraction) that a primary input switches in a clock cycle. It can be any number between 0 and 1.

Default: 0.2

Dominant Frequency

Specifies the dominant frequency of the design.

Flop Activity

Specifies the activity of outputs of sequential logic.

There is no default.

Clock Gate Activity

Specifies the average number of times that a clock-gating cell switches in a clock cycle at the output of the pin. Enter any positive number.

There is no default.

The value that you specify in GUI will overwrite the value in set_default_switching_activity -clock_gates_output parameter.

Activity File

 

If selected, activates the fields for entering VCD/FSDB information. A VCD/FSDB file must be specified.

Vector Profiler

When clicked, displays the Run Vector Profile window.

Scope

Specifies the scope of the VCD file.

Start

Specifies the start time in nanoseconds (ns) of the VCD file that will be used for power analysis.

Stop

Specifies the stop time in nanoseconds (ns) of the VCD file that will be used for power analysis.

Block

Specifies the block name.

Results Directory

Specifies the directory where the power analysis output will be placed.

Run Vector Profile

Use this form to create Vector profile report for the specified VCD file.

  • Choose Power & Rail - Run Power Analysis - Basic tab, and then click the Vector Profiler button.

Fields and Options

Activity

Enables activity profiling. Reports the number of toggles for every window.

Total Power

Enables total power profiling. Reports total power in milliWatts (mW).

Switching Power

Enables switching power profiling. Reports switching power in milliWatts (mW).

Internal Power

Enables internal power profiling. Reports internal power in milliWatts (mW).

Use Propagation

Enables propagation when partial VCD is provided.

Event Based Peak Power

Specifies to enable event-based vector profiling. This method computes power profile of every event on each net. The event-based peak power profiling enables you to accurately capture vectors that could produce peak power using very small resolution (1ps) and with better performance than average power profiling which uses larger resolution to compute average toggle density.

Output File

Writes out the Vector profiling report into the file that you specify.

By default, the report is written out into vcdprofile.report file.

Step Size (ns)

Specifies the step size, in nanoseconds (ns). Activity / Power profiling is carried out for every step size that you specify.

Number of windows with highest activity/power

Provides n top windows with maximum activity or power.

Default: 3

Instances

Enables profiling of the instances that you specify.

Instances File

Enables profiling of the instances from the instance file that you specify.

For example, instances in an instance file can be specified as follows:

-------------------
inst_1
inst_2
inst_3
.
.
.
inst_n
-------------------

Exclude Instances

Disables counting of toggles or calculating power for the specified instances while reporting activity or calculating power for the entire design.

Exclude Instances File

Disables counting of toggles or calculating power for the specified instances file while reporting activity or calculating power for the entire design.

Power Nets

Enables power profiling for the specified power net(s).

Align with Signal

Starts profiling at the first rise or fall of the signal.

Select rising to start profiling at the first rising edge.

Select falling to start profiling at the first falling edge.

Run Power Analysis - Activity

Fields and Options

Global Activity

Specifies the average number of times that all unset nodes switch in a clock cycle. If not specified the fastest domain frequency will be used unless one turns off clock domains.

There is no default.

Hierarchy(s)

A hierarchical name that the Global Activity is being assigned to. If not provided the whole design is assumed. Selecting the Add button adds hierarchical activity information to a list. The Remove button removes a selected item in the list. To highlight multiple items, click them while pressing either the Shift or Control key.

Activity Transition Density

Specifies whether Activity or Transition Density numbers will be used when supplying Net, Pin, or Port activities.

Net, Port, Pin

Specifies that the activity numbers are for a Net, Pin, or Port.

Name

Name of the Net, Pin, or Port.

Activity/Td

The Activity or Transition Density value based on which of these two was selected.

Duty Period

Duty cycle and Period for the named Net, Pin, or Port. Duty is the fraction of time that a net, pin, or port has a value of 1.0 A duty cycle of 0.25 has a value of one 25% of the time.

By selecting Add adds the supplied information to the list. Selecting Remove deletes selected items on the list. To highlight multiple items, click them while pressing either the Shift or Control key.

Period

Period for the named Net, Pin, or Port.

TCF

TCF file.

SAF

SAF file

SAF Scope

Scope of SAF file, if SAF is selected.

Run Power Analysis - Power

Fields and Options

Custom Power

When selected it activates the Power/PWL and PG Net fields for adding Cells.

Cell

Specifies that the Custom Power information is for a cell.

Instance

Specifies that the Custom Power information is for an Instance.

Name

The name of the cell or instance. Must be provided.

Sticky

Applies the simulation-based PWL waveform as is to the specified cell/instance.

Power/PWL

After selecting Custom Power, Cell or Instance, the Power/PWL and PG Net fields can be entered. By selecting the Add button this information is added to the list. The Remove button deletes any selected items that were previously added to the list. To highlight multiple items, click them while pressing either the Shift or Control key.

Scale Factor

Specifies to scale the power value by the specified scale factor. You can use this option to specify the scale factor for specific cells and instances.

PG Net

Specifies the name of the power rail.

Leakage

Specifies the target leakage power of the design, cell, or instance. To specify leakage power for cells and instances, you can use the Leakage option in conjunction with the Cell or Instance option.

Internal

Specifies the target internal power of the design, cell, or instance. To specify internal power for cells and instances, you can use the Internal option in conjunction with the Cell or Instance option.

Switching

Specifies the target switching power of the design, cell, or instance. To specify switching power for cells and instances, you can use the Switching option in conjunction with the Cell or Instance option.

Target Chip Power

Specifies the power for the entire design or rail, in milliwatts (mW).

Chip Scale Factor

Scales the power value by the specified scale factor.

Target Leakage

Sets the total target leakage power of the entire design in milliwatts (mW).

Run Power Analysis - Advanced

Fields and Options

Native Power Up

Specifies to enable the native power up flow.

Simulation Period

The simulation period that dynamic rail analysis will be performed.

Step Size

Specifies the transient time step size or resolution.

Include File

Adds the Power Analysis options that do not have an equivalent option in Tempus.

For more information, refer to "Power Analysis Options" in Voltus Text Command Reference.

Activity Mapping File

Specifies the rtl2gate mapping file which contains instance name mapping between RTL netlist and GATE level netlist. RTL level VCD or TCF are obtained from simulation on RTL Verilog netlist. Power analysis uses this instance name mapping to annotate the output nets of this instance from the pin based RTL, VCD, or TCF.

By default, this option is always selected when either VCD/TCF is specified.

Golden rtl gate

Specifies whether rtl or gate is Golden. The one not specified as golden will be considered as Revised. Currently the Conformal MatchPoint file does not specify this.

Default: rtl
