SI Window Components

Use the SI window components to display noise reports after crosstalk analysis.

  • Click on the SI tab.

The SI tab displays four sections: Histogram, Summary, Net list, and Aggressor Information.

The SI tab sections are described below:

Report File(s)

Specifies the name of the noise report file, which is generated after running crosstalk analysis.

Glitch Histogram

Displays the noise histogram according to the noise type (glitch or incr_delay). The histogram title is consistent with the noise type. By default, the Glitch Histogram is displayed.

Summary

Displays the summary of noise analysis (similar to the information displayed in the Tempus SI log in the SUMMARY section).

The information includes Total Net, Total Violation, Worst Glitch Voltage, Total Glitch Voltage, Worst Incr_delay Voltage, and Total Incr_delay Voltage according to the noise type.

Net List

Includes three tabs: Glitch, Incr Delay Max, and Incr Delay Min.

  • Glitch: Represents the glitch noise victims.
  • Incr Delay Max: Represents the push out incr delay used for late paths.
  • Incr Delay Min: Represents the push in incr delay used for early paths.

By default, the Glitch tab is selected if both the glitch and incr_delay reports are available. As a result, the netlist will be sorted by glitch voltage. If you click the Incr Delay Max or Incr Delay Min tab, the net list will be sorted by incremental delay.

Aggressor Information

Displays the aggressors information of a victim net. This information includes the victim name, slew, capacitance, peak, XCap, and net name.

For example, select a victim net in the Glitch tab to display the corresponding aggressor information.

SI Tab - Glitch

Use the Glitch Display tab to display the SI glitch distribution.

In the SI tab, click Glitch.

Fields and Options

The Glitch tab sections are described below:

H

Checkbox to select or deselect a victim net.

Net

Displays the Index.

Voltage

Displays the glitch peak voltage.

Level

Displays the Glitch Voltage Level.

PRP Voltage

Displays the propagated glitch noise voltage.

Receiver Instance

Displays the fanout instance connected to the victim net.

Victim Net

Displays the attacked victim net.

Report File(s)

Specifies the name of the glitch noise report file. By default, aae or aae_<viewname> will be generated in the reporting directory.

Glitch Histogram

Displays the glitch noise chart, which represents the glitch peak distribution.

Summary

Displays the summary of the glitch noise analysis. The information includes:

  • Total Net: Is the total number of victim nets.
  • Total Violation: Is the total number of victim nets with the glitch peak exceeds the threshold defined during file loading.
  • Worst Glitch Voltage: Is the highest glitch peak.
  • Total Glitch Voltage: Is the sum of the glitch peak.

Aggressor Information

Displays the slew, capacitance, and timing information for the victim and aggressor nets.

SI Tab - Incremental Delay

Use the Incr Delay Max or Incr Delay Min tab to display the SI delay distribution.

In the SI tab, click Incr Delay Max.

Fields and Options

The Incr Delay Max tab sections are described below:

H

Checkbox to select or deselect a victim net.

Net

Displays the Index.

Incr Delay

Displays the SI delay, shown in ps.

Receiver Instance

Displays the fanout instance connected to the victim net.

Victim Net

Displays the attacked victim net.

Edge

Displays the SI delay that happens at the rising or fall transition.

Report File(s)

Specifies the name of the incremental delay noise report file. By default, aae_<max/min>_incDelay or aae_<viewname>_<max/min>_incDelay will be generated in the reporting directory.

Incr Delay Max Histogram

Displays the incremental delay chart, which represents the SI delay distribution.

Summary

Displays the summary of the incr_delay max noise analysis. The information includes:

  • Total Net: Is the total number of victim nets.
  • Total Violation: Is the total number of victim nets with the SI delay that exceeds the threshold defined during file loading.
  • Worst Incr_delay: Is the largest SI delay.
  • Total Incr_delay: Is the sum of SI delay.

Aggressor Information

Displays the slew, capacitance, and timing information for the victim and aggressor nets.

Shortcut Menu for Net List Section

In the Net List section of the SI tab, right-click on any of the displayed victim net that displays the shortcut menu as shown below.

The following options are displayed:

  • Show Aggressor Information: Displays the detailed aggressor information of the selected victim net in the Aggressor Information section.
  • Highlight Only This Net: Highlights the net, which gets selected in the "H" column.
  • Highlight Net: Highlights a set of nets that gets selected in the "H" column.
  • Show Aggressor Information and Highlight Net: Highlights the victim net and displays the detailed aggressor information of the selected victim net in the Aggressor Information section.
