Context Menu of the Clock Path Analyzer

Right-click anywhere in the Clock Path Analyzer window to view the context menu. The following options are available in this menu:

  • Highlight
  • Collapse subtree
  • Abstract this node
  • Unabstract this node
  • Expand all subtrees
  • Select transitive sink fanout
  • Select subtree
  • Protect subtree
    Options Descriptions

    Highlight

    You can choose to highlight the Start Pin, End Pin, Full Path and Selected Pin in the color of your choice. Each of these items has a submenu containing a color picker, as in the Color By menu.

    The image below shows the Start Pin of the selected object highlighted in green.

    Collapse subtree

    Collapses the subtree.

    Abstract this node

    Abstracts the selected node.

    Unabstract this node

    Unabstracts the selected node.

    Expand all subtrees

    Expands all the collapsed subtrees.

    Select transitive sink fanout

    This option is available in the context menu when you right-click objects other than sinks. It selects the transitive sink fanouts for the selected object.

    Select subtree

    Selects everything under the selected node.

    Protect subtree

    Protects the subtree from collapsing.
