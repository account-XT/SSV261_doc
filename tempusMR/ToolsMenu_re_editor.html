Tempus Menu Reference
Product Version 26.10, May 2026

Editor

Use the Editor submenu to display and edit a text file.

Fields and Options

Pulldown Descriptions

File

Choose from one of the following options:

New

Opens a blank file for editing.

Open

Open an existing file for editing.

save

Saves a file.

Save As

Saves a file with a different file name.

Evaluate

Evaluates the commands in the file.

Close

Closes the file.

Exit

Exits the editor window.

Edit

Choose from one of the following options:

  

Undo

Reverses the last operation.

  

Cut

Cuts the selected text.

  

Copy

Copies the selected text so it can be pasted at another location.

  

Paste

Pastes the copied text.

  

Find

Opens window to find the specified string in the document.

  

Find Next

Finds the next instance of the specified string.

  

Find Prev

Finds the previous instance of the specified string.

  

Replace

Replaces the specified string with another specified value.

  

Goto Line

Go to the specified line number.

  

Grep

Searches for all files in the specified directory for the given string.

Preference

Choose form one of the following options:

  

Show Proc Window

  

Displays a right pane with procedure information.

Show Line Number

  

Shows the line numbers at the left of the screen

Word Wrap

To wrap words on a line to the next line if they do not fit in window.

Refresh Highlighting

Refreshes highlighting

Window

Provides the ability to switch between any documents that have been opened.
