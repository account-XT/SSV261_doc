Display/Generate Timing Report

Use the Display/Generate Timing Report form to specify the violation report to be read in for debugging timing results.

  • Choose Timing & SI - Debug Timing

Fields and Options

Timing Report File

Specify a filename, or click the file folder icon to choose a file.

Generate

Generates a violation report file in machine readable format.

Default: top.mtarpt

Check Type

Can be selected for the type of Check: Setup or Hold. Previously this was available only from the command line.

Retime

Specifies the advanced timing methods (aocv, ssta, path_slew_propagation, and waveform_propagation).

Append to Current Report

Appends the specified report to the report that you have already loaded in a timing debug session. This feature is useful to collate reports from several views into one timing debug session.

Path Category File

Specifies the path category file. The path category file contains category definitions that you saved in an earlier timing debug analysis.
