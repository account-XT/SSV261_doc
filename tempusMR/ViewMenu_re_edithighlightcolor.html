Edit Highlight Color

Use the Edit Highlight Color form to further customize the highlight color and pattern of selected object sets in the design display area.

  • Choose View - Edit Highlight Color.

Edit Highlight Color Fields and Options

Highlight Set

Lists the available highlight sets. To customize a highlight set:

  • Select the set.
  • Choose the appropriate highlight color and pattern from the Color and Stipple area, respectively.
  • Click Apply.

Color

Specifies the highlight color for the selected highlight set.

Stipple

Specifies the highlight pattern for the selected set.

Width of Highlight Boundary

Specifies the width of highlight boundary. You can set the number as 1, 2, 3, 4, or 5.

Default: 1

Save

Saves the highlight settings. The default filename is enc.hilite.tcl.

Load

Loads highlight settings previously saved in a file.

Default

Reverts to the default settings for all highlight sets.
