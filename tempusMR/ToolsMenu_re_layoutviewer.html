Layout Viewer

Use the Layout Viewer menu item to open the layout in a view-only window. You can launch multiple view-only windows in a single Tempus session. This is useful when debugging as it allows you to view and zoom into different portions of a design simultaneously.

The Layout Viewer window supports all viewing related features, such as Zoom and Pan. In addition, it supports functions and tools that do not modify the design, such as Attribute Editor and Design Browser.

  • Choose Tools - Layout Viewer.

Layout Viewer Tool Widgets

You can use the widgets in Layout Viewer to navigate through displays, open tools, and make selections.

Widget Description

Select - Selects an object in the design display area.

Create Ruler - Click this widget, then left-click in the design display area and drag the mouse to add a ruler (in micrometers), and left-click again to end the ruler. To move the ruler, click and drag it to a new location. Click the ruler again to keep it in the new location.

In by 2 - Click this widget to display a smaller area of the design in greater detail. Each click zooms in two levels.

Out by 2 - Click this widget to display a larger area of the design in less detail. Each click zooms out two levels.

Fit - Click this widget to display the entire placed design within the design display area.

Selected - Zooms in on a highlighted selection.

Previous - Click this widget to toggle the display between the previous location/zoom level and the current location/zoom level.

Redraw - Refreshes the Layout Viewer display.

Attribute Editor - Opens the Attribute Editor for the highlighted object.

Design Browser - Opens the Design Browser form.

Clear All Rulers - Clears all rulers from the display area.

To remove a single ruler, place the mouse cursor over the ruler and press Delete.

Floorplan View - Switches to the Floorplan view of the design.

Amoeba View - Switches to the Amoeba view of the design.

Physical View - Switches to the Physical view of the design.
