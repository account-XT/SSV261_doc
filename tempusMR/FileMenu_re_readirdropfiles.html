Read IR Drop Files

Use the Read IR Drop Files form to read an IR drop file.

  • Choose File - Read IR Drop.

Fields and Options

Operating Condition

Specify either Min or Max operating condition.

Derating

Applies the effects of IR-drop to the early path (data hold/clock setup) or late path (data setup/clock hold) in your design. Use the Early or Late parameter in conjunction with the Min or Max condition to account for the effects of early-max, early-min, late-max, or late-min IR-drop analysis.

Reset

Resets all IR-drop files, so a new one can be read.

Related Text Commands

The following text command provides equivalent or additional functionality:

  • read_instance_voltage

For more information, see the "Design Import Commands" in Tempus Text Command Reference.
