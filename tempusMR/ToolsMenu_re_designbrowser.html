Design Browser

Use the Design Browser to navigate through the chip's design hierarchy. You can use the Design Browser to view the design hierarchy tree at any time after the design is imported. You can use the widgets in the Design Browser to open forms to navigate through displays, and perform actions.

From the Design Browser, you can access the:

  • Connectivity Browser: To display the number of nets between instances.
  • Attribute Viewer: To display an object's type, name, and attributes.
  • Schematic Viewer: To display hierarchical and instance-based schematics.
  • Choose Tools - Design Browser.

Fields and Options

File

Provides the following options:

Load

Displays the Load Design Browser File form. Enter the filename and the format of the placement file.

Save As

Displays the Save Design Browser File form. Specify the filename. The recommended extension is .dbf.

Quit

Closes the Design Browser Window.

View

Provides the following options:

Refresh

Redraws the Design Browser display.

Sort By Size

Displays instances in the order of the number of cells in the instances. Deselect the View - Sort By Size option to display instances sorted alphabetically by name.

Accumulate Results

Traces the hierarchical path for the selected object in the design display area.

Edit

Provides the following options:

Delete Group/Group Member

Deletes an individual instance from a user-defined group, or to delete an entire user-defined group.

Tool

Provides the following options:

Get Selected

Displays a selected object in the Design Browser

Attribute Viewer

Opens the Attribute Viewer. For more information, see Attribute Viewer.

Connectivity Browser

Opens the Connectivity Browser. For more information, see Connectivity Browser.

Find

Enables you to search and display hierarchy information for a specific object. You can view information on the following object types:

Instance

Enables you to search for an instance and display its hierarchy in the Design Browser window. You can traverse to the next hierarchy by double-clicking on the instance name. Along with the instance name, the instance's cell type and number of cells are displayed.

Net

Enables you to search for a net and display its hierarchy in the Design Browser window. Double-clicking the net name displays the net connection.

Group

Enables you to search for an instance group and display its hierarchy in the Design Browser window.

Cell

Enables you to search for a cell and display its hierarchy in the Design Browser window.

Design Browser Tool Widgets

You can use the widgets in the Design Browser to navigate through displays, open tools, make selections, and perform actions.

Widget Description

Previous--Displays viewable data in a reverse direction.

Next--Displays viewable data in a forward direction.

Top Page--Returns to the top of the design.

Connectivity Browser--Opens the Connectivity Browser.

Select--Selects an object in the design display area.

Deselect--Deselects an object in the design display area.

Deselect All--Deselects all objects in the design display area.

Get Selected--Gets the selected object and displays it in the Design Browser.

Attribute Viewer--Opens the Attribute Viewer for the highlighted instances.

Delete Group/Group Member--Deletes selected floorplan object instance groups.

Refresh--Refreshes the Design Browser display.

Zoom Selected--Zooms in on a highlighted selection.

Highlight--Highlights an object in the design display area.

Dehighlight--Dehighlights an object in the design display area.

Dehighlight All--Dehighlights all objects in the design display area.

Show Instance Based Schematic--Opens the Schematic Viewer to display schematic in flattened mode for an instance, net, or a pin. For more information, seeSchematic Viewer.

Show Hierarchical Schematic--Opens the Schematic Viewer to display schematic in hierarchical mode for a module, instance, net, or a pin. For more information, see Schematic Viewer on page 391 .

Connectivity Browser

Use the Connectivity Browser to display connections from a source module to a destination module, including module guides, blocks, I/O blocks, and standard cells.

  • Choose Tools - Design Browser.

Highlight a module in the Design Browser and click the Connectivity Browser widget.

Fields and Options

Source Module Instance

Specify the name of the instance

Destination Module

Use this pull-down menu to select the destination module.

Check

Displays the connection information.

Attribute Viewer

Use the Attribute Viewer to display an object's type, name, and attributes. The contents of the Attribute Viewer form change depending on the object selected in the design.

To open the Attribute Viewer from the Layout window, do the following:

  • For a single object, double-left click on an object.

To open the Attribute Viewer from the Design Browser, do the following:

  • Choose Tools - Design Browser.

In the Design Browser, highlight or left click on an object or a set of objects.

  • Click the Attribute Viewer from the Design Browser tool widgets.
The Attribute Viewer displays different attributes, depending on the objects selected.

Fields and Options

Object Type

Displays the type of object currently selected.

Close

Closes the Attribute Viewer window.

Schematic Viewer

Use the Schematic Viewer with the Design Browser to explore the design connectivity, relationship between modules and instances, and design changes, such as CTS and ECO. You can cross-probe from the Schematic Viewer to the main display to get immediate feedback for debugging and diagnosing your design.

The Schematic Viewer has two main views:

  • Hierarchical view - To open the Schematic Viewer in Hierarchical view:

Select a module, instance, net, or pin in Design Browser and click the Show Hierarchical Schematic widget.

  • Flattened view - To open Schematic Viewer in Flattened view, select an instance, net, or pin in Design Browser and click the Show Instance Based Schematic widget.

Schematic Viewer Components

In both Flattened and Hierarchical views, the Schematic Viewer has the following components:

  • Menu Bar
  • Toolbar
  • Schematic Display Area
Except for the menu bar, the Schematic Viewer components are same as that of the Schematic tab in the main Tempus window. For more information on these components, see Schematic Tab Components in the Tab Options chapter.

Menu Bar

  • File Menu
  • View Menu
  • Preference Menu
  • Trace Menu
  • Window Menu

File Menu

The File menu enables you to print schematics and close the Schematic Viewer window.

Options Description

Print

Opens the Print Schematic form where you can choose printer options.

Quit

Closes the Schematic Viewer window.

View Menu

The View menu displays various options, which allow you to customize the display in the schematic display area. Many of the options in the View menu are also available on the View Option Pane to the right of the schematic display area.

Options Description

Port Name

Displays instance/block port names in the schematic display area. De-select this check box if you do not want to display port names.

Default: Selected

Pin Name

Displays I/O pin names in the schematic display area.

Default: Unchecked

Instance Name

Displays instance names in the schematic display area.

Default: Unchecked

Net Name

Displays net names in the schematic display area.

Default: Unchecked

Primitive Instance Type Name

Displays primitive instance type names.

Default: Selected

Highlight Cursor Object

Highlights objects as you move the cursor over them.

Default: Selected

Zoom In

Displays the schematic in greater detail. Each selection zooms in one level.

Zoom Out

Displays more contents of the schematic. Each selection zooms out one level.

Zoom to Full Window

Displays the entire schematic within the display area.

Pan

Pans the current schematic according to the option you select. You can choose to pan:

  • Left
  • Right
  • Up
  • Down
  • Horizontal Center
  • Vertical Center

Complete View

Returns to the original full schematic view.

Change Color

Opens the Timing Debug Preferences - Select Color form where you can change the color of the selected object.

Next Color

Changes the selected object's color to the next available color in the palette. You can do this repeatedly.

Display Information Box

Displays an information box that states the name of the object over which the cursor is currently placed and lists pertinent details about that object.

Default: Selected

Preference Menu

Use the Preference menu to customize the color and font settings of the schematic display.

Options Description

Color Settings

Opens the Color Settings form so you can change color and line settings for objects in the schematic display area.

Font Settings

Opens the Font Settings form so you can change the font size and style settings for the schematic display.

Mouse Properties

Opens the Mouse Properties form so you can change the font size and style settings for the schematic display.

Trace Menu

Use the Trace menu to trace drivers, loads, and connectivity for the selected object.

Options Description

Trace Driver

Traces all possible drivers of the selected object and highlights them in the schematic display area. The default highlight color for drivers is yellow.

Trace Load

Traces all possible loads of these object and highlights them in the schematic display area. The default highlight color for loads is red.

Trace Connectivity

Traces all possible drivers and loads of the selected object and highlights connectivity from the object's drivers to its loads. The default highlight colors for drivers and loads are yellow and red, respectively.

Window Menu

The Windows menu lists all of the active Schematic Viewer windows for your Tempus session. Click on a window name to bring it to the front of your screen.

  • Choose Cascade Window to refresh your desktop and display the main window on top with all other open windows in a cascading view to the left of the main window.

Schematic Viewer Context Menu

To access the context menu, right-click an object in the Schematic Viewer window. The options available in context menu varies depending on the current view of Schematic Viewer:

  • Flattened View Context Menu
  • Hierarchical View Context Menu

Flattened View Context Menu

The following table describes the options that are available from the Flattened view context menu of Schematic Viewer.

Options Description

Open Fan-in Cone

Opens the fan-in cone of the selected object. This option is available in the context menu of instances and block ports.

Close Fan-in Cone

Closes the fan-in cone of an object.

Open Fan-out Cone

Opens the fan-out cone of the selected object. This option is available in the context menu of instances and block ports.

Close Fan-out Cone

Closes the fan-out cone of an object.

Show Hierarchical Mode

Displays the object schematics in the Hierarchical View.

Highlight in Main Window

Highlights the object that you right-clicked in the schematic display in the main window. This option is useful for cross-probing.

Copy Object Name

Copies the object name.

Hierarchical View Context Menu

In Hierarchical view, the context menu of the Schematic Viewer is same as the context menu in the Schematic tab. For more information on the options in the Hierarchical view context menu, see Context Menu in the Tab Options chapter.
