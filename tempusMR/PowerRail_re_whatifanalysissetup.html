What-If Analysis Setup - Current

Use this form to scale current to do what-if analysis for a hierarchical partition and assess its effect on IR drop.

Fields and Options

Scale Hierarchy Currents

Specifies to scale hierarchical currents for all instances within the given hierarchy.

Scale Clock Network

Specifies to scale instances that belong to the clock network and scale currents for the rest of the instances within the given hierarchy to the specified value.

You cannot specify this option with -region x1 y1 x2 y2 or -global options.

Default: Not selected

Scale Global Current

Specifies current scaling to be applied to the entire design.

Scale Current Region

Specifies current scaling to be applied to the specified current region in the design.

Scale Hierarchy Current

Specifies current scaling to be applied to the specified hierarchical block.

Region

Specifies a region where current scaling is to be applied. The default unit of x and y coordinates is in microns (um).

Hierarchy Name

Specifies the name of the hierarchical block. For example, -hierarchy top/blockA. To specify global scaling for the design use "/". For example, -hierarchy /

This is a required option.

Scale

Specifies any value greater than 0. For example, a value of 0.5 will scale the resistance in half.

This is a required option.

Current (mA)

Specifies current value in milliAmperes. This is used as target peak current for the given hierarchy and is then scaled appropriately. You cannot specify this option with -region x1 y1 x2 y2 or -global options.

Related Topics

See command in chapter in the Text Command Reference.

What-If Analysis Setup - Capacitance

Use this form to scale the intrinsic cell capacitance value to determine how much additional capacitance can be added in a region to reduce dynamic IR drop.

Fields and Options

Scale Capacitance

Specifies to scale capacitance.

Intrinsic

Scales instance internal gate capacitance to the specified scale factor. The default scale value is 1.

Loading

Scales loading capacitance of the instance to the specified scale factor. The default scale value is 1.

Grid

Scales power-grid capacitance of the design to the specified scale factor. The default scale value is 1.

Global

Scales the specified capacitances for the entire design.

Region Draw

Scales the specified capacitances in the region. The default unit of x1 y1 x2 y2 is in database units.

Related Topics

See command in chapter in the Text Command Reference.

What-If Analysis Setup - Resistance

Use this form to scale resistance globally or in a region to determine how much resistance can be modified in a region to reduce the entire IR drop.

Fields and Options

Scale Resistance

Specifies to scale resistance.

Auto Scale Adjacent Via Layers

Specifies to use auto via scaling for what-if resistance analysis.

Scale

Specifies any value greater than 0. For example, a value of 0.5 will scale the resistance in half.

This is a required option.

Layer Name

Specifies the layer name (LEF layer or technology layer) on which the scaling is performed. Multiple commands can be issued to scale resistance on multiple layers.

This is a required option.

Net Name

Scales resistance of the specified net in the domain which is being analyzed.

This is a required option.

Global

Scales the resistance to the specified value for the entire design for a given layer.

Region

Draw

Scales the resistance in the specified region. The default unit of x1 y1 x2 y2 is in database units.

Related Topics

See command in chapter in the Text Command Reference.

What-If Analysis Setup - Virtual Shape

Use this form to add, select, deselect, delete, list, and display the what-if wires/vias to a design.

  • Choose Power & Rail > Run Rail Analysis > Advanced form, click on the What-If Analysis - Setup button > Virtual Shape tab.
     

Fields and Options

Create Virtual Shape

Creates virtual shapes (wires/vias) to a design.

Operation
 
  • Add - Specifies to add what-if wires/vias.
  • Delete - Specifies to delete all or selected what-if shapes by constraint Net/Layers/Type. You can use this field in conjunction with the Objects field.
  • Select - Specifies to select all what-if shapes by constraint Net/Layers/Type. Use this field in conjunction with Area to select what-if shapes overlapping with the specified area.
  • Deselect - Specifies to deselect all what-if shapes by constraint Net/Layers/Type. Use this parameter in conjunction with Area to deselect what-if shapes overlapping with the specified area.
  • Display - Invokes the GUI to show what-if shapes and zooms to the selected shapes.
  • List - Specifies to list all or selected what-if shapes by constraint Net/Layers/Type. You can use this field in conjunction with the Objects field.

Type

Specifies what kind of shape is to be created.

Net

Specifies the name of the net for which what-if wires/vias is to be created.

Layers

Specifies the LEF layer name for wires, or layer pair for via to be added.

Area

Specifies the rectangular region in which the what if wires/vias are to be generated.

Pitch Width

Specifies the width of what-if wires and the distance between the centre line of two adjacent what-if wires (pitch) to be drawn in the specified Area in the preferred direction of the specified layer. The direction of created wires can also be controlled using the Direction field.

If this field is not provided, a single rectangular shape of size {llx,lly,urx,ury} is created.

Direction

Controls the direction of the wires added with the Pitch Width field.

Method

Specifies the method used to add vias:

Auto: When area and layer pair are specified, the tool automatically adds vias on all intersecting points on the specified layer pairs in the given area.

Exact: When an area and layer pair are specified, the tool adds a via of exact size of the specified area between the specified layer pair.

Objects

Specify Objects in conjunction with the Delete or List fields to delete or list the selected what-if shapes.  You can also delete or list all what-if shapes. The default value is All.

Save Virtual Shape File

Specifies to save all the in-memory what-if wires/vias to the specified file.

Append to Existing File

Specifies to append all what-if wires/vias to the existing file specified with the Save Virtual Shape File field.

Load Virtual Shape Results

Loads the saved files of all vias/wires from the What-If Analysis Setup form and results are displayed in the design layout.

Related Topics

See create_what_if_shape command in the Rail Analysis Commands chapter in the Innovus Text Command Reference.

What-If Analysis Setup - Regions

Use this form to specify static or dynamic current regions on global power-grids over the placed macro to accurately capture high and low current consuming regions during rail analysis.

Fields and Options

Create Region

Creates current regions on global power-grids.

Static Current / Dynamic PWL

Static Current: Specifies a single current value in mAmp.

Dynamic PWL: Specifies a PWL current waveform in time (in ns) and current (in mA) format. For example, 0ns 0mA 0.5ns 1mA 1ns 2mA 3ns 1mA 4ns 0.

Layer

Specifies a layer name on which the scaling will be performed.

This is a required option.

Intrinsic Cap

Specifies the cell intrinsic capacitance in pico farads (pf). This is required option when set in the dynamic mode (set_rail_analysis_mode -method dynamic). This option is disabled in static mode.

Loading Cap

Specifies the cell loading capacitance in pico farads (pf). This is required option when set in the dynamic mode (set_rail_analysis_mode -method dynamic). This option is disabled in static mode.

Region

Draw

Specifies the region on the layer across which the specified current and capacitance (in dynamic mode) is distributed by the rail analysis engine.

This is a required option.

Related Topics

See command in chapter in the Text Command Reference. 

Run Resistance Analysis - Basic

Performs effective resistance calculation for all instances in a design. Effective resistance computes effective resistance between two nodes on the power-grid, or from a node to all the voltage sources in the design, or from an instance to all the voltage sources in the design.

Fields and Options

Analysis Method

Specifies the resistance analysis method as Effr.

Net Name

Specifies the net name that is to be analyzed.

Domain Name

Specifies the domain name that is to be analyzed.

Set PG Nets or Domain

Net Based - is equivalent to the set_pg_nets command.

Domain Based - is equivalent to the set_rail_analysis_domain command.

If you have used Tcl command in your scripts, you do not have to use these GUI fields to set PG nets or rail analysis power domain.

Power Net(s)

Specifies names of the power nets for which resistance analysis will be performed.

Voltage(s)

The voltage of the power net.

Threshold

The voltage threshold of the power net

Ground Net(s)

Specifies names of the ground nets for which resistance analysis will be performed.

Voltage(s)

The voltage of the ground net.

Threshold

The voltage threshold of the ground net

Power Pads
  • Def Pins - specifies that voltage sources will be determined by power pins.
  • Pad File - specifies that voltage sources will be determined by pad cells given in the file.
  • XY File - specifies that voltage sources will be specified by x y coordinates.
  • Boundary File - specifies that voltage source locations will be specified by information in the boundary file.

Default: Def Pins

File Name

The name of the power file containing the locations of the power rail voltage sources (VDD, VSS). You can automatically generate this file by clicking the Create button. The Edit Pad Location form appears.

Net Name

The name of the power net. The Add button adds the net to the list. The Remove button removes the net from the list.

Output Directory

Specifies the name of the directory in which the output report file is saved.

Output Report Name

Specifies the name of the output report file that contains the report header and the sorted list for resistance values. 

Effr To Power Pads

Specifies to check effective resistance of a node to the voltage sources or power pads. This option is enabled only when Power Pads is selected. When this option is selected, Node2 and Instance2 options are disabled.

Point-To-Point Effr

Specifies to check effective resistance between two nodes on the power-grid. When this option is selected, Node2 and Instance2 options are enabled.

Node1

Specifies the list of user-defined nodes for effective resistance calculation between the specified user-defined node and all voltage sources, or between two nodes on the power-grid. This option is enabled for both Effr To Power Pads and Point-To-Point Effr. You can add a list of nodes based on the region on a given layer.

  • x1 and y1 are the coordinates of the node.
  • Layer1 is the generic metal routing layer name on which the node is located.
  • Label is any name chosen by you to identify node entries in the list. This is optional but helps during debugging.
  • Get

Node2

Specifies the second node for effective resistance calculation between two nodes on the power-grid. This option is enabled only for Point-To-Point Effr.

  • x2 and y2 are the coordinates of the second node.
  • Layer2 is the generic metal routing layer name on which the second node is located.
  • Get

Region

Analyzes resistance in the specified region. You can draw a box on a specific layer, and specify the number of nodes to be selected (maximum limit of 100 nodes). This field allows you to compute effective resistance on a given layer across the chip and determine how the resistance is changing for the design from top to bottom layer. You can assign a name for the region.

  • x1,  y1, x2, and y2 are the coordinates of the box.
  • Nodes are the number of nodes to be selected.
  • Layer is the generic metal routing layer name on which the nodes are located.
  • Get Region 

Node File

Specifies the name of the node list file. This file contains the list of user-defined nodes in the same format as mentioned for the -node_list parameter of the analyze_resistance command. The file allows you to specify a large number of nodes.  

Node-Pair File

Specifies the name of the node pair list file. This file contains the node pair list in the same format as mentioned for the -node_pair_list parameter of the analyze_resistance command. The file allows you to specify a large number of node pairs.  

Instance1

Specifies the list of instances for which effective resistance is to be calculated. This option is enabled for both Effr To Power Pads and Point-To-Point Effr.

Pin1

Optionally, you can specify instance pin name. By default, the tool will use the instance pin associated with the net being analyzed. Pin name can be used in special cases when two different pins of an instance are connected to the same net.

Instance2

Specifies the second instance to enable effective resistance calculation between two instances in the design. This option is enabled only for Point-To-Point Effr.

Pin2

Specifies the pin name for the second instance.

Instance File

Specifies the name of the instance list file. This file contains the list of instances in the same format as mentioned for the -instance_list parameter of the analyze_resistance command. The file allows you to specify a large number of instances.

Instance-Pair File

Specifies the name of the instance pair list file. This file contains the instance pair list in the same format as mentioned for the -instance_pair_list parameter of the analyze_resistance command. The file allows you to specify a large number of instance pairs.

Effr Threshold (Ohms)

Specifies the minimum allowed effective resistance to display node/node-pair/instance/instance-pair that have a resistance value above this threshold value.

Force Re-extraction

Specifies to force a re-extract of resistances.

Append

When you select Append and click the Load button, the content of the effective resistance analysis result file is appended to the previous list in the node/instance list box. If Append is not selected, the previous list is cleared.

Add

Adds the specified node/node-pair/instance/instance-pair to the list box.

Remove

Removes the selected node/node-pair/instance/instance-pair to the list box.

Auto Zoom

Specifies to automatically zoom in to the selected node/instance in the list box.

AutoFilter

Specifies to show the nodes or instances with eight color filter. When you specify Effr Threshold (Ohms) and click AutoFilter, the layout displays the nodes or instances with eight color filter. When you change the threshold value, you will get different plots on the layout. 

Analyze ESD

Use the Analyze Electrostatic Discharge form to report an effective resistance from the power or ground bump to the nearest ESD cell.

Fields and Options

Output File

Specifies the name of the report file in which details of resistance between power/ground bumps to ESD is written.

 Bump File

Bump Cells: Specifies to account for the connected bump instances only of the specified cells. If this parameter is not specified, all connected bump instances will be taken into account.

Bump Instances: Specifies to account only for the listed connected bump instances. If this parameter is not specified, all connected bump instances will be taken into account. This parameter is mutually exclusive to the –bump_cell_list parameter.

ESD Cells

Specifies the ESD cell names.

Power Net

Specifies the power net for which ESD protection has to be checked.

Ground Net

Specifies the ground net for which ESD protection has to be checked.

Threshold

Specifies the minimum allowed effective resistance between a power or ground bump and an ESD device pair.

Loop Threshold

Specifies the minimum loop resistance that an ESD clamp cell would have between power and ground bump cells. This is the effective shunt resistance that current would pass through during an ESD event when the ESD device is on.

Method

Specifies the ESD calculation method.

When bump_to_esd_resistance is specified, the software checks effective resistance between the ESD clamp cell and the power or ground bump depending upon what nets are specified. In this case, you must specify either power or ground nets.

When bump_to_esd_loop_resistance is specified, the software calculates effective resistance between the power bump, ESD clamp cell and ground bump, and assumes that the specified threshold is for loop resistance. In this case, you must specify both power and ground nets.

Highlights power/ground bumps

Selecting this checkbox highlights the power or ground bump cells.

Optimize ESD

Use the Optimize Electrostatic Discharge form to perform ESD cell optimization that enables you to determine optimal number and location of ESD cells given a set of bump locations in the design.

Fields and Options

Output Directory

Specifies the output directory for ESD optimizer.

Power Grid Library

Specifies the cell library for ESD and bump cells.

Extraction File 

Specifies the extraction tech file name for power-grid view generation.

ESD Cell

Specifies the cell name that is to be placed.

Cell Orientation

Specifies the direction in which ESD cell is to be placed.

Pin Name

Specifies the name of the pin.

Number of CPUs

Specifies the number of CPUs on the local machine. This parameter is required for multi-threading.

Max Instances

Specifies the maximum number of locations to be tried for searching optimal ESD locations. If a blockage, macro, or placed instance is found, then that location is discarded. If you do not specify this parameter, the maximum number of locations are searched.

Net Name

Specifies the net that needs to be processed.

Effective resistance

Specifies the effective resistance from the power or ground bump to the nearest Electrostatic Discharge (ESD) cell.

Offset

Specifies the offset values in the X and Y directions.

Generate followpins

Specifies to generate followpins for routing.

Ignore placed macro

Specifies to ignore placed macros.

Ignore placed standard cell

Specifies to ignore placed standard cells.

Ignore placement blockage

Specifies to ignore placed placement blockages.

Cell Viewer

The Cell Viewer provides an artwork window for viewing the following objects:

  • any LEF library cell
  • any OpenAccess database cell view
  • abstract view of any partition in the design
  • power grid library cell

The Cell Viewer displays the content from the library database. It provides a convenient way to view the content of a cell, cell view or partition without having to zoom into the design. You can access this form without loading a design.

The Cell Viewer has the following tabs:

  • Cell Viewer - LEF
  • Cell Viewer - OA
  • Cell Viewer - Ptn
  • Cell Viewer - PGV

Cell Viewer - LEF

Use the LEF page to view the details of library cells using the information in the LEF file. You can navigate to a cell using the Library Browser, which is in the left side of the Cell Viewer. The details of the cell are displayed in the Display Area, which is in the right side of the Cell Viewer.

  • Choose Tools - Cell Viewer, and click on the LEF page if it is not already selected.

Cell Viewer - OA

Use the OA page to view the details of OpenAccess cells using the information in the OA library.

  • Choose Tools - Cell Viewer, and click on the OA page.

You can view an OA cell in two modes:

  • OA-Layout View
  • OA-Abstract View

OA-Layout View

  • In the Library Browser, select the OA cell, and then click Layout.

OA-Abstract View

  • In the Library Browser, select the OA cell, and then click Abstract.

Cell Viewer - Ptn

Use the Ptn page to display the abstract of any partition in the design. You can navigate to a partition through the Library Browser in the left side of the Cell Viewer.

  • Choose Tools - Cell Viewer, and click on the Ptn page.

Cell Viewer - PGV

Use the PGV page to view and debug power-grid libraries. To load multiple libraries, select Open Power Grid Library from the File menu.

You can navigate to a cell using the Library Browser, which is in the left side of the Cell Viewer. The details of the cell are displayed in the Display Area, which is in the right side of the Cell Viewer. You can expand a cell to view the default views corresponding to each PGV type (Tech, Early, EM, and IR).

  • Choose Tools - Cell Viewer, and click on the PGV page.

This form allows you to take a physical layout and overlay it with a power-grid resistor network extracted by Power-Grid Library Generator.

Fields and Options

File

The File menu provides the following options:

Open Power Grid Library

Opens multiple power grid libraries.

Free PGV Database

Specifies to free all the loaded power-grid libraries.

Quit

Closes the Cell Viewer window.

Options

 

Net Based View - Show Popup Automatically

If this menu item is selected, clicking on a view displays a dialog box automatically. This dialog box allows you to display the power-grid of a single net. By default, this menu item is not selected.

The dialog box displays the power, ground, and signal nets. You can select a net and click Plot to view a single net.

Alternatively, you can view this dialog box using the following method:

Right-click on a view to see the short-cut menu.

Click the view name option on the shortcut menu.

Clicking on the cell name returns to the whole view mode, and displays the selected views for the cell name.

PGV Cell Views

You can click the + button to expand a cell and view the default cell views. Each view has a check box for displaying the content specific to the selected view. You can view either one or multiple views overlapped over each other.

The default views for different power-grid view types are:

  • Tech Displays the basic port information of a cell. 
  • Early  Geometrical View - displays the LEF of a cell. The types of geometrical views are: PORT_GEOM, OBS_GEOM, PROMOTED_GEOM and OPTIMIZED_GEOM views. Port View - displays more accurate port and tap information of a cell when . This information is available in the PORT_POWER view of the library. Capacitance Views - displays the grid and device capacitance information of a cell. The types of capacitance views are: GRID_CAP and DEVICE_CAP views. These views are net specific.
  • EM Detailed View - displays the detailed power-grid information for all nets. This information is available in the DETAILED_POWER view of the library. Tap Current View - displays tap information of a cell. All the tap currents are shown in the viewer drawn in 8 colors for 8 linear filters according to the min max value. This information is available in the TAP_CURRENT view of the library. Dynamic Tap Current View - displays dynamic tap currents for each interval. The total current plot is net based, and supports multiple trigger view in a single PGV. This information is available in the DYN_TAP_CURRENT view of the library. Powergate View - displays the power switch information of a power-gate cell. This information is available in the POWERGATE view of the library.
  • IR Collapsed View - displays the collapsed current taps for the bit-cells inside the memory. This information is available in the TAPCOLLAPSE_POWER view of the library.

Cell Viewer Widgets

The Cell Viewer supports the following widgets: Zoom In, Zoom Out, Fit, View Last, Redraw, Clear All Rulers, Select and Ruler.

Auto Query

The Cell Viewer window includes an Auto Query (Q) button located at the bottom of the design display area that enables and disables the auto query. When you enable auto query, text information displays for any object that is under the cursor. You can use auto query for information on cell instances, instance pins, and resistors.
