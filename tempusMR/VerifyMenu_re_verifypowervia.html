Verify Power Via

Checks for metal geometry overlap on power-grid nets and for missing or open vias in the design.

To verify the design, the power-grid must be routed.

Choose Verify - Verify - Power Via.

Fields and Descriptions

Check Power Via

All Power Nets: Verifies power vias in all the power nets. This is the default option.

Nets: Verifies power vias in the specified net(s).

Report File

Specifies the name of the output file for the report.

Layer Range:

Top Layer

Bottom Layer

Optional. The layer range checks for missing stacked vias between only bottom and top layers. It also checks for missing vias between all intermediate layer intersections. You can specify standard metal layer names, such as M1, M2, and so on, or metal layer names as defined in the LEF file.

Default: All layers.

If Bottom Layer is specified but Top Layer is not , it assumes one layer up.

Area:

Draw x1 y1 x2 y2

When selected, enables you to draw a box in the display canvas to fill in x1 y1 x2 y2 values automatically. Optionally, you can also specify x1 y1 x2 y2 coordinates.

Include metal fill geometries

Specifies that metal fill should also be checked.

Default: Metal fill will be ignored.

Include non-orthogonal wires

Specifies that non-orthogonal crossing wires should also be checked.

Default: Non-orthogonal wires will be ignored.

Include wire-pin overlaps

Specifies that wire-pin overlaps should also be checked.

Default: Wire-pin overlaps will be ignored.

Check stacked via

Checks for missing vias between all non-adjacent as well as adjacent layers.

Default: Missing stacked vias will be ignored.

Check via utilization

Checks the via utilization.

Min via against overlapping metal area ratio

Specifies the minimum via area against overlapping metal geometry ratio.

The value must be between 0 and 1.

Keep Previous Setting

Specifies that all previous verifyPowerVia settings will be kept.

Default: Previous settings are not kept.
