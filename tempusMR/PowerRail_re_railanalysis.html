Rail Analysis

The Rail Analysis section has the following items:

  • Set Rail Analysis Mode form
  • Set Power Network Optimization Mode form
  • Run Rail Analysis form
  • Run Resistance Analysis form
  • Run ESD Analysis form
  • Run ESD Optimization form

Set Rail Analysis Mode

The Set Rail Analysis Mode form includes the following:

  • Set Rail Analysis Mode - Basic
  • Power Grid Library Directories
  • Set Rail Analysis Mode - Advanced
  • Create Current Region

Set Rail Analysis Mode - Basic

Sets whether static or dynamic rail analysis should be performed along with some related parameters.

Fields and Options

Analysis Stage

Specifies whether early rail analysis (Early) or signoff (Sign Off) rail analysis will be done. If you select Early, the XD mode is selected by default and HD mode is disabled.

Default: Sign Off

Analysis Method

Specifies whether static or dynamic analysis will be done.

Default: static

Accuracy

Specifies the accuracy mode of analysis.

  • XD (accelerated definition) – use for early implementation stage IR/EM analysis
  • HD (high definition) – use for final verification stage IR/EM analysis

Default: XD

PowerGrid Libraries

Specifies the name of the power-grid view library directories. If you select the folder icon, the Set Rail Analysis form appears, which will be used to select and add the appropriate files.

MMMC View

Specifies the Mult-Mode Multi-Corner (MMMC) view.

CPF mode

Specifies Common Power Format (CPF) mode.

Switched off Power Nets

Specifies a list of nets to exclude from analysis.

Powering up Nets

Specifies a list of powering up nets.

Block Power Up Net

Specifies a net for block power-up analysis.

Generate Power- Switched ECO

Specifies that a power switch ECO file should be created.

Default: false

Process EM Rule in Extraction Tech File

Processes the EM rules defined in the extraction technology file. When Process EM Rule in Extraction Tech File is specified with Extraction Tech File, the extraction technology file will be processed. If Process EM Rule in Extraction Tech File is specified without Extraction Tech File, the .cl model will be processed.

Enable Least Resistance Path Analysis

Enables least resistance path analysis for all the instances in the design.

EM Analysis Models

Specifies the name of a file that includes the electromigration (em) models.

ICT-EM Analysis Models

Specifies the ICT-EM file which only contains the EM rules and excludes the RC extraction data in ICT. The software will use the EM rules in the specified ICT-EM file to calculate EM limits for power net EM analysis even if there are embedded EM rules in the Quantus tech file.

Default Package

Specifies the default resistance, inductance and capacitance values of the package to be used for RLC model.

Source Search Distance

Specifies the search distance in microns(u) for adding voltage sources at power pin locations.

Default: 50um

Extraction Tech File

Specifies the extraction technology file to be used for top-level power-grid extraction. If you do not specify this field, the software will use the extraction technology file stored inside the power-grid view library.

Extraction Tech File is a mandatory input file for early rail analysis if  PGV is not specified.

Thermal Map

Specifies to process the thermal map file generated for Quantus to calculate resistance based on uniform temperature.

Default: Not selected

Generate Movies

Used to specify that dynamic movies will be created. For dynamic only.

Default: true

Save Voltage Waveforms Files

Saves voltage waveform files in the state directory of analyzed net(s) to feed to SPICE critical path analysis and Substrate Noise Analysis.

Default: Not selected

This option is disabled in the Static mode.

Decap Optimization Method

Specifies the decap optimization method to use. For dynamic only. Choices are Placement-Aware and Timing-Aware, Area-based, and Removal.

Default: Area-based

Decap Removal Method

Choices are Conservative and Aggressive. Used with Removal option of Decap Optimization Method.

Default: Aggressive

Maximum Leakage Current

Specifies the maximum leakage current in A, for placement-aware and timing-aware decap optimization methods.

Generate Decap ECO

Specifies that a decap eco file should be created.

Generate reduced die model:N-port

    

Creates n_port_freq_domain as well as n_port_time_domain die-models simultaneously.

Power Grid Library Directories

A form such as the one shown below appears when the folder icon is selected from a menu. Selecting the folder icon on this form will toggle the Selection part of the form. To add items, select a file, and then select the Add button. To add multiple items from the selection list, select the first item, then move the cursor to the last item and hold down the shift key while selecting the last item. The Delete button can be used for deleting items. Similarly the shift key can be used for deleting multiple items.

Set Rail Analysis Mode - Advanced

Fields and Options

Generate Block Boundary Voltage

Generated the voltages on the block pins. This data can be used for doing rail analysis at the next level up in hierarchy.

Instance Name(s)

The name of the instance that the block boundary voltages will be generated for.

Use Temp Directory

Specifies a directory to use for temporary files.

Report Via Current Direction

Determines that the current direction of vias will be reported.

Default: false

Save Current Files for Hierarchical View

Determines whether Voltus automatically saves current files.

Default: false

Temperature

Specifies the temperature in degree celcius during rail analysis.

The default temperature is 25 degree celsius.

Lifetime

Specifies the lifetime value in hours.

Default: 87,600 hours

GDS

Specifies that a GDS file will be used.

Flip-Chip GDS

Specifies that the gds data is for flipchip.

Full-Chip GDS

Specifies that the gds data is for full chip.

GDS File

Specifies the name of the gds file.

GDS Map

Specifies the name of the gds map file.

GDS Cell

Specifies the name of the gds top cell.

Don't Touch Decaps

Specifies the decaps that will not be removed.

For dynamic only and used if option: -decap_opt_method removal is set.

Decap Cells

Specifies the decap cells that will be used during decap optimization. This option is used when the decap cells are not tagged in the power-grid library.

For dynamic only.

Filler Cells

Specifies the filler cells that will be used during Placement- Aware or Timing-Aware decap optimization. This option is used when the filler cells are not tagged in the power-grid library.

For dynamic only.

Decap ECO

Specifies the name of the decap ECO file for domain based analysis that will be created after decap analysis is performed. This file is generated in decap_opt/addcap.cmd in the state directory.

For dynamic only.

Specify Current Region

Specifies a file that includes a list of regions and the amount of current to be distributed within them for the power-grid. This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

If you select this checkbox, the Create button is enabled that lets you create current regions for Static and Dynamic analysis. Click Create to view the Create Current Region form.

Default units in file are mA. You can also specify rectilinear current regions in the file.

Power Gate File

Specifies the name of the power gate (power switch) file that will be used to perform power gate steady-state analysis.

This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

Layer Mapping File

Specifies the layer map file to generate a port view. If a layer map file is not provided, it would be automatically inferred by the tool.

This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

Skip Layer (Pair)s for Virtual Via Insertion

Specifies to skip via insertion between stripes and non-stripes, on the specified LEF layer pairs.

This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

Skip Virtual Via Insertion for Shape Type

Specifies to skip a given via type. By default, ERA generates all virtual via layer types.

  • whatif - vias are virtual vias that have connectivity to user-defined what if shapes.
  • def - vias are virtual vias between two metal shapes defined in DEF.
  • all - will skip all virtual via generation.

Current Distribution Layer for Unplaced Instances

Specifies the layer name for distributing unplaced current in the early rail analysis mode.

This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

Enable Current Distribution for

Controls the behavior of era current distribution. set_power_data area based power, or current_region_file need to be specified for ERA current distribution to work. Placed instanced without uti or ascii based power can also be considered for era current distribution.

  • Unplaced: Enable current distribution only for unplaced instances. If set_power_data area based power is specified,  -era_current_distribution_layer will be required.
  • Placed: Enable current distribution for placed instances without any power specified.
  • All: Both unplaced and placed instances without power specified; will have ERA current.
  • None: Disable ERA current distribution.

This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

Virtual Followpin Insertion

Generates virtual followpins. The extended followpins will create followpins that extend from one stripe to another. The standard followpins may extend to previous stripe but does not reach the next stripe.

This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

Current Distribution Factor for Placed Macros

When you use Distribute Current for Placed Instance or Generate Current Region File for Unplaced Area, the ratio of power allocated to each macro/block is calculated based on its total area. This field controls the current distribution factors for the placed instances, hence power allocated for area-based power calculation. For example, if you specify 0.5, the software will assume all placed instances to be 50% of its actual size and distribute current accordingly.

This field will be enabled only if you select Early analysis stage in the Set Rail Analysis Mode - Basic tab.

Ignore Shorts

Specifies to perform sign-off mode extraction while ignoring shorts, extract each net per geometry defined in LEF/DEF and honor manufacturing effects. This option allows you to ignore shorts and continue sign-off mode extraction.

Enable Manufacturing Effects

Specifies to honor manufacturing effects during static or dynamic analysis.

Create Current Region

Fields and Options

Draw Current Region

Specifies the coordinates of the region, the layer, and the static current. The Add button can be selected to add the region to the Current Region List. The Delete button will delete a selected item on the list.

Label specifies a name for the region. If not specified, Innovus will provide a name (region1, region2...)

Net specifies the power/ground net name for domain-based analysis. This option allows you to specify current region values for a specific net.

x1, y1, x2, and y2 specifies a rectangular region that the current will be distributed within.

Rectilinear specifies the rectilinear current region that the current will be distributed within.

In the static mode, ERA splits the rectilinear region into several rectangular regions and distributes current to the rectangular regions based on the area. In the dynamic mode, you can specify rectilinear regions interactively in the layout canvas by selecting the Draw button. You can select a rectlinear region by clicking each vertex of the rectlinear in sequence (clockwise or counter-clockwise), and then pressing the ESC key on the keyboard. This will quit the point selection mode, and the selected points appear in the Rectlinear field.

Current in rectangular region = Area of the rectangle / Area of the rectilinear

Layer specifies the metal layer that the current sink will be placed on.

If you select Draw, then select a box in main window, the coordinate of this box will be automatically populated in the x1 y1 x2 y2.

If you select View after selecting an item in the list, the selected region will be displayed in the main window.

Dynamic PWL (0ns 0mA...)

Specifies the dynamic PWL for regions without any placed instance, in time (in ns) and current (in mA) format. For example, 0ns 0mA 0.5ns 1mA 1ns 2mA 3ns 1mA 4ns 0. This option is displayed only if you select the analysis method Dynamic.

Loading Cap (pf)

Specifies loading capacitance in pf (picoFarads) waveform for the current region(s). This option is displayed only if you select the analysis method Dynamic.

Estimate

Estimates Gate Capacitance (C1) and Loading Capacitance (C2) values for the specified current regions. These estimated values of C1 and C2 are used along with the PWL current waveform for the regions to perform dynamic rail analysis. This option is displayed only if you select the analysis method Dynamic.

Gate Cap (pf)

Specifies gate capacitance in pf (picoFarads) waveform for the current region(s). This option is displayed only if you select the analysis method Dynamic.

Current Region List

Displays the current region list. This is created by specifying the Draw Current Regions information and selecting Add. Selecting an item on the list and then Delete will delete the selected item.

Set Power Network Optimization Mode

  • Use the Set Power Network Optimization Mode form, which specifies how the power network optimization flow will be performed.

Fields and Options

ECO File

Specifies the ECO file for power networks. The ECO file contains the Innovus power-planning commands. If this parameter is not specified, the software creates the default ECO file name pno_eco.tcl.

Optimization region file

Specifies the region of IRdrop that should be optimized to fix IRdrop violations.

Net name

Specifies the net to be optimized in MSMV analysis.

Dont touch layer

Specifies the layers on which the wires are not be optimized.

Optimization Type

Specifies the optimization type of power-grids. This parameter works only when the wire_group resolution is selected.

The default value is upsize.

Dont touch wire type

Specifies the wire shapes that are not be optimized. The options are:

  • RING
  • BLOCKRING
  • STRIPE

Incremental

Specifies to generate only the power planning commands for analyzing the net.

Scale width of net under analysis only

Specifies to scale the width of only those nets that are under analysis, while keeping the width of the other nets as is.

Use all spacing

Specifies to use every possible spacing between nets.

Wire center on track

Specifies that the PG wire center should be on either full or half routing track.

Wire edge on grid

Specifies that the PG wire edge should be on the snap grid.

Run Rail Analysis

The Run Rail Analysis form has two pages:

  • Run Rail Analysis - Basic
  • Edit Pad Location
  • Run Rail Analysis - Advanced

Run Rail Analysis - Basic

Runs rail analysis using the provided parameters.

Fields and Options

Net Based

Set if net based analysis is being run.

Domain Based

Set if domain based analysis is being run.

Domain Name

Name of the power domain that rail analysis will be performed on. Only used for domain based analysis.

Power Net(s)

Name of the power nets that the rail analysis will be performed on.

Voltages

The voltage of the power net.

V Threshold

The voltage threshold of the power net

Ground Net(s)

Name of the ground nets that rail analysis will be performed on.

Voltage(s)

The voltage of the ground net.

V Threshold

The voltage threshold of the ground net.

Add

Click the Add button to add details of a specific net to the power/ground nets table for domain-based analysis.

Remove

Click the Remove button to remove details of a specific net from the power/ground nets table for domain-based analysis.

Power Data

The power data will be supplied by Current Files, an ASCII file or will be area based.

Scale

Specifies a scale factor to apply to the current data.

You can use this parameter to scale currents to a more optimistic or pessimistic power-consumption estimate.

This parameter is only for -format current and -format ascii.

Repeat

Repeats the dynamic current waveform for the specified time. You must ensure that the stop time for dynamic analysis is also specified and it matches the repeat duration. This option is only available for current format files during dynamic analysis. The repeat option can be used when multiple current files have different simulation periods or when IR drop analysis needs to be run for longer duration.

Default: ns

Total Power

Specifies the power per area in watts. Only required for option -format area.

Bias

The value of the bias voltage. This parameter is only for -format ascii and -format area.

Power File(s)

Specifies the name of the power data files. The file is optional if -format area is specified.

Power Pads

XYFile specifies that voltage sources will be specified by x y coordinates.

  • Def Pins specifies that voltage sources will be determined by power pins.
  • Pad File specifies that voltage sources will be determined by pad cells given in the file.
  • Boundary Files specifies that voltage source locations will be specified by information in the boundary file.

Default: Def Pins

File

The name of the power file.

Net Name

The name of the power net. The Add button adds the net to the list. The Remove button removes the net from the list. To highlight multiple items, click them while pressing either the Shift or Control key.

Package Model

Specifies a file containing a SPICE subcircuit describing the package model. This file is generated by Allegro Package SI (also known as APE3D from Cadence) or other package-modeling products.

Mapping File

Specifies the name of the package terminal mapping file, which contains the mapping of the terminals of the SPICE sub-circuit in the package model file (Specified by the Package Model field above) to the locations at the grid or top-level pins.

Offset X

Offset Y

Specifies the lower left and upper right points coordinate of the die.

Rotate

Specifies the rotation angle of the die. The possible values are: 0/45/90/135/180/225/270/315. Rotation is always in the counter clockwise direction from the original point.

Flip

Specifies to flip the die along the Y axis.

Results Directory

The directory where the rail analysis output will be saved.

Edit Pad Location

Use the Edit Pad Location form to create or edit power pad location files (one for each power net) to mark points on the power structures as voltage source reference points. Power pad location files identify the voltage source reference points, such as VCC, VDD, and VSS. You can use these files during all stages of power analysis.

Pad location displays are updated immediately after clicking Auto Fetch, Delete, or Add. The IR drops leading from the pad locations are displayed after running power analysis.
  • To open the Edit Pad Location form, click the Create button in the Run Rail Analysis form:

Fields and Options

Net

The power net or ground net name of the pad cells. This field is required only when the file format is VS.

You can only edit the pad location file for one net at a time.

Pad Location

The X and Y coordinates of a pad cell.

Layer

The layer that contains the pad cell.

Get coord

Populates the X and Y coordinates in the Pad Location field. Click this button, then click a location in the design display area.

Delete

Removes one or more pad location items from the Pad Location List. Highlight the item be removed, then click this button. To highlight multiple items, click them while pressing either the Shift or Control key.

Add

Adds the X and Y coordinates of a pad cell to the Pad Location List.

Region

x1, y1, x2, and y2 specifies a rectangular region that the current will be distributed within. A grid is created by using the xPitch and yPitch within the specified region. The current will be specified at each of the intersecting pitch lines. Layer specifies the metal layer that the current sink will be placed on.

If you select Get Region, then select a box in main window, the coordinate of this box will be automatically populated in the x1 y1 x2 y2.

Snap Constraint

Specifies whether to snap DC sources from I/O pad pins to some location on the power structure. If you select this option, the software performs auto fetch with snapping.

For I/O pad pins that are connected to core ring, the software selects the highest layer and center of the pin as the DC source location. When I/O pad pins are not connected to core ring, the software snaps the location of the I/O pad to somewhere on the core ring. The DC source location should be within the distance of snapping distance constraint from I/O pad pins, and the layer should not be lower than the lowest layer snap constraint.

Distance

Specifies the distance of snapping distance constraint from IO/pad pins. The default value is 50. You can edit this option only if Snap Constraint is selected.

Lowest Snap Layer

Specifies the lowest layer used to fetch a DC source. Use a value such as M1 or M2. The default value is M5. You can edit this option only if Snap Constraint is selected.

Honor Pin Wire Connection

Honors pin wire connection when fetching voltage source location from a power pad. When you select this option, only pins with wire connection are output as voltage sources.

Fetch All Layer Shapes

Specifies to fetch all layer shapes as voltage sources. When a PG pin has only one port with many shapes, this parameter specifies to fetch all shapes as voltage sources.

Specify

Specifies an instance/cell and their pins to auto fetch DC sources.

Instance Name

Specifies the instances from which voltage sources are determined.

Instance Name and Pin

Specifies the instances and their pins from which voltage sources are determined.

Cell Name

Specifies the cells from which voltage sources are determined.

Cell Name and Pin

Specifies the cells and their pins from which voltage sources are determined.

Auto Fetch

Automatically populates the Pad Location List with the pad locations based on properties defined in the LEF file.

There are two ways to get the dc source.

  • auto Fetch + net
  • auto Fetch + region

Source Name

Specifies the name of the voltage source that has to be updated.

Source Instance

Specifies the instance name of the voltage source that has to be updated.

R

Specifies the resistance value of the package resistance-inductance-capacitance (RLC) model in Ohm.

L

Specifies the inductance value of the package resistance-inductance-capacitance (RLC) model in Henry (H).

C

Specifies the capacitance value of the package resistance-inductance-capacitance (RLC) model in Farad (F).

Add

Adds the modified RLC values in Pad Location List.

Delete

Removes the modified RLC values from Pad Location List.

Pad Location List

The list of coordinates for pad cells. To populate this field manually, click the Add button. To populate this field automatically, click the Auto Fetch button.

Save File Format

The format of the saved Pad Location File. The choices are XY File (xy coordinates) and Pad File (VoltageStorm). You can create and save the voltage sources location file with a unique name for the voltage sources (both VDD and VSS).

Load

Opens the Load Pad Location File form. Select a file from this list, then click Open to display the pad locations in the Pad Location List.

Save

Opens the Save Pad Location File form. Specify a location for the pad location file, then click OK. This saves the pad location file, clears the Pad Location List, and closes the Save Pad Location form.

Clear

Clears the Pad Location List. Once the Pad Location List is cleared, you can begin creating a pad location file for a new net.

Cadence recommends that you use the Clear button after you save the pad location file before you use Auto Fetch again.

Run Rail Analysis - Advanced

Fields and Options

Group Name

Specifies the name for a group of power or ground nets.

Power Nets

Ground Nets

Replace power domain by group.

Start Time

Specifies the start time in nanoseconds (ns) for dynamic analysis.

Stop Time

Specifies the stop time in nanoseconds (ns) for dynamic analysis.

Resolution

Specifies the transient time step size or resolution in picoseconds (ps).

Voltus Include File Begin

This field provides the ability to provide a file that includes vstorm2 commands that will be run prior to the analyze command. This can be used for those VoltageStorm commands that do not have a Voltus GUI equivalent.

Voltus Include File End

This field provides the ability to provide a file that includes vstorm2 commands that will be run after the vstorm2 command. This can be used for those VoltageStorm commands that do not have a Voltus GUI equivalent.
