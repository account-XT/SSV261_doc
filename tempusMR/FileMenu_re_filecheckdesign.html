Tempus Menu Reference
Product Version 26.10, May 2026

Check Design

Use the Check Design form to check for missing or inconsistent library and design data at any stage of the design.

  • Choose File - Check - Check Design.

Fields and Options

IO

Checks I/O pads, generates warning messages, and reports the following information:

  • Floating pins that belong to I/O pads (warning)
  • I/O pins connected to non-I/O instances (directly connected to core cells)
  • Floating I/O pins

Netlist

Checks the netlist, generates error or warning messages, and reports the following information:

  • Output pins tied to power/ground nets (for example, BUFX1 U1 (.A(net1),.Y1(1'b0)))
  • Input pins floating (warning)
  • Multiple driver nets (warning)

Physical Library

Checks the physical libraries and reports whether all the cells have LEF views. Issues error messages for the following conditions:

  • Cells not defined in LEF
  • Cells with missing power ground pins
  • Cells with missing dimensions
  • Pins with missing direction
  • Cells and pins with missing geometry
  • Cell dimensions are not an integer multiple of the core site dimensions
  • Cells and power ground pins with missing geometry

Timing Library

Checks whether the cells used in the design have been defined in the timing library. This option does not check for the presence of timing arcs. All physical cells are excluded from this check.

SPEF Coverage

Reports the following SPEF information:

  • SPEF coverage
  • Number of nets in the design that are not in the SPEF
  • List of nets

Power Ground

Checks power and ground connections, generates warning messages, and reports the following information:

  • Power terminals connected to ground net
  • Ground terminals connected to power net
  • Floating power and ground terminals
  • Power and ground terminals connected to non-power and ground nets.

Tie High Low

Reports unconnected tie-high or tie-low terminals, and generates a warning message.

Floorplan

Checks the floorplan, generates error or warning messages, and reports the following information:

  • Off-grid horizontal and vertical tracks
  • Instances not snapped to row site
  • Unplaced I/O pins
  • Off Grid Power/Ground Pre-routes
  • Instances not on the manufacturing grid
  • Pre-routes not on the manufacturing grid (error)
  • Regular pre-routes not on tracks

Placement

Checks the floorplan, generates error or warning messages, and reports the following information:

  • Off-grid horizontal and vertical tracks
  • Instances not snapped to row site
  • Unplaced I/O pins
  • Off Grid Power/Ground Pre-routes
  • Instances not on the manufacturing grid
  • Pre-routes not on the manufacturing grid (error)
  • Regular pre-routes not on tracks

Text Only

Generates only a text version of the report.

Default: Generates both an HTML and a text version of the report.

File

Writes the report information to the specified file.

Default: checkDesign.rpt

HTML Only

Generates only an HTML version of the report.

Default: Generates both an HTML and a text version of the report.

HTML and Text

Generates both an HTML version and a text version of the report.

Output Directory

Saves both the HTML version and the text version of the report to the specified directory. If you select the HTML Only option, the software saves the HTML version of the report to the specified directory.

Default: checkDesign

Display HTML

Displays the HTML version of the report in the Report menu.

Related Text Commands

The following text command provides equivalent or additional functionality:

  • check_design

For more information, see the "Design Import Commands" in the Tempus Text Command Reference.

Report Timing Library

Use the Report Timing Library form to output the cell information to a report file after importing the design and loading the timing library. The report file is generated in ASCII format.

  • Choose File - Check - Timing Library

Fields and Options

All Cell(s)

Reports timing information for all the cells. This is the default option.

Cell Selection

Reports timing information on the cells specified in the text box.

Timing Library Report

Specifies a filename or you can click the file folder icon to choose a file. If you do not select this option, the report is displayed on the Tempus console. The default filename is TopCellName.talib.

Check Timing Library

Use the Check Timing Library form to check the contents of the timing library and reports any inconsistencies in a report file. Use this form after importing the design and timing library.

  • Choose File - Check - Library

Fields and Options

Report File

Specifies the name of the report file. The default filename is TopCellName.clrpt.

Related Text Commands

The following text command provides equivalent or additional functionality:

  • check_library

For more information, see "Timing Analysis Commands" in the Tempus Text Command Reference.
