Tempus Common Timing Engine Integration

Litmus is closely integrated with Tempus, Common timing Engine (CTE), Innovus, and other Signoff tools. The following figure demonstrates this integration with other tools:

The benefits of this integration include the ability to share scripts or setup, have identical interpretation and unrolling of constraints, and view accurate interdependencies between constraints and timing or crossings.

This is important for constraints in the following ways:

  • Common SDC parser.

  • Read the SDC the same way as a static timer (Tempus).

  • Stylus CUI enabled - shared setup with Genus/Innovus/Tempus.
