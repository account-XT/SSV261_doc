Set Case Analysis (set_case_analysis)

Signal value of the definition point should always be equal to the set value.

An example below: 

set_case_analysis 0 [get_pins select]

#

Condition

Pass / Fail

1.

signal at ‘select’ pin is fixed to 0

Pass

2.

signal at ‘select’ pin is fixed to 1

Fail

3.

signal at ‘select’ pin toggles from 0 to 1

Fail

4.

signal at ‘select’ pin toggles from 1 to 0

Fail

5.

signal at ‘select’ pin toggles from 0 to 1 to 0 outside of the verification period and remains fixed at 0 thereafter

Pass

Verilog testbench generation for set_case_analysis does not support the following options: rise, rising, fall, falling, non-switching
