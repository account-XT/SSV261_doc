Constraints Comparison Checks

Constraints Comparison validates consistency across the following constraint classes:

  • Clock Consistency
    • CONST_COMP_CLK* / CONST_COMP_UNC* / CONST_COMP_LAT* / CONST_COMP_CTR* / CONST_COMP_GRP* / CONST_COMP_CG* / CONST_COMP_PLS*
  • IO Consistency
    • CONST_COMP_IO*
  • Exception Consistency
    • CONST_COMP_EXC*
  • Case Analysis Consistency
    • CONST_COMP_SCA*
  • Others
    • CONST_COMP_SDT* / CONST_COMP_TIM* / CONST_COMP_DAT* / CONST_COMP_HFN*

These dimensions mirror hierarchical consistency checks, but are applied across SDC versions instead of hierarchy levels.
