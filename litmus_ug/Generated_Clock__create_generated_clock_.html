Generated Clock (create_generated_clock)

Generated (or derived) clock definitions in timing constraints are assumed behavior of the clock.

Logic that drives the generated clock definition object is assumed to create the frequency (clock edges) as defined by create_generate_clock.

The following command option is used to write assertions for generated clocks: generate_sva -cgc

CGC check is triggered only when generating clock toggles.

Assertions are composed of two parts

  • Constant check - Ensures that a gcl toggle is caused by mclk toggle
  • Waveform check - Checks the correlation between mclk and gclk

Examples

  • Constant Check
    // master clock: CLK0 at pin clk0
// generated clock: GCLK41 at pin mx1/Y
timeunit 1ns;
bit clk1ns;
initial forever #0.5 clk1ns=!clk1ns;

GCLK41___CGC_DIVIDED_BY_CONST_rise_fall: assert property( disable iff(`CFM_RESET)
@(clk1ns) ##2 $rose(`mx1/Y) && (`clk0) |-> $past (`clk0) == 1`b0);

GCLK41___CGC_DIVIDED_BY_CONST_rise_rise: assert property (disable iff(`CFM_RESET)
@(clk1ns) ##2 $rose(`mx1/Y) && (!`clk0) |-> $past (`clk0) == 1`b1);

GCLK41___CGC_DIVIDED_BY_CONST_fall_fall: assert property (disable iff(`CFM_RESET)
@(clk1ns) ##2 $fell(`mx1/Y) && (`clk0) |-> $past (`clk0) == 1`b0);

GCLK41___CGC_DIVIDED_BY_CONST_fall_rise: assert property (disable iff(`CFM_RESET)
@(clk1ns) ##2 $fell(`mx1/Y) && (!`clk0) |-> $past (`clk0) == 1`b1);

    At every clk1ns toggle, if a rise of mx1/Y is observed and clk0 is high, it implies that the previous clk0 should be low.
