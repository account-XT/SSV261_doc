Temporary File Locations

Each Litmus session creates its own temporary directory to store temporary files at the beginning of the run.

By default, the tmp_dir is created in the /tmp directory. If the Unix envar TMPDIR is set, then the tmp_dir is created inside $TMPDIR.

The name of the tmp_dir will appear as ssv_tmpdir_[pid]_xxxxxx

Where _xxxxxxx is a string that is added to make the directory unique. For example: ssv_tmpdir_10233_nfp9ez

The temporary directory is automatically removed on exit or if the run is terminated with a catchable signal (for example, SIGSEGV).
