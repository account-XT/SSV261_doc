Constraints - Design Initialization

This is supported for Multi-Mode Multi-Corner and uses this method of importing design data. Litmus supports only one active view for analysis in MMMC flow.

Design Setup with MMMC Flow

The following are the commands for design setup with MMMC initialization flow:

  • Use the read_mmmc command to load timing libraries and setup timing constraints.
  • Use the init_design command to load timing constraints.
