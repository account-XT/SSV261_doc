Introduction to Litmus

Litmus is the next generation of Cadence’s mature Conformal Constraints Designer (CCD). It provides the fastest path to full chip constraints signoff. The major benefit of Litmus is that it can run at both RTL and gate-level to support the full implementation and signoff of both blocks and full SoCs. 

Litmus has three main flows:

  • Constraints signoff
  • Hierarchical consistency checks
  • Clock/Reset domain crossing signoff

The following figure shows an overview of the Litmus flow:

It has the following improvements over the prior generation.

  • 100% Accuracy
    • Industry’s first static timer (Tempus Timing) integration for Constraints Signoff.
    • Accurately models the design and the constraints using the same interpretation as signoff timer.
    • Enables you to start verification early at RTL.

  • Industry-Leading Performance and Capacity

    • Built-in multi-CPU architecture.

    • The SoC-level capacity of more than 1 billion gates. 

    • Scalable to larger designs.

  • Smart Constraints Checking

    • Enables accurate, low-noise reporting.

    • Provides insights into the design and constraints intent.

    • Provides root cause analysis for rapid signoff.

    • Hierarchical consistency checking.

    • Constraints comparison.
