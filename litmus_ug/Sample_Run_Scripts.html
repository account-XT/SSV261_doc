Sample Run Scripts

This section provides reference script templates for running Constraint Promotion in both Netlist-based and RTL-based flows. These scripts reflect the recommended sequence of operations and illustrate how design setup, constraint registration, promotion analysis, and review align in a unified methodology.

  1. Netlist Flow Script: The Netlist flow is typically used when a synthesized or post‑layout gate-level is available.
    1. init_design ensures that all library, connectivity, and SDC contexts are resolved.
    2. Running report_sdc and report_rule_check before promotion eliminates structural or linting issues early.
    3. Promotion should start only after all block constraints are registered.
  2. RTL Flow Script: The RTL flow mirrors the Netlist flow but includes RTL elaboration and optional library loading. This flow is commonly used early in the project lifecycle when block SDCs and top-level constraints are still evolving.
    1. The input_libs step is optional and depends on the level of timing modeling required.
    2. All RTL must be elaborated before constraint lint checks are executed.
    3. The rest of the flow is consistent with the Netlist flow, ensuring uniformity across design representations.

To ensure stable and predictable promotion behavior:

  • Always validate SDC and lint issues before running promotion.
  • Use consistent MMMC environments across flows for alignment with Synthesis and Implementation tools.
  • Register block SDCs only after the top‑level SDC context is fully loaded.
  • Favor instance-based registration when blocks differ across instantiations.
  • Always write the final SDC using write_sdc to maintain a clean record of promoted constraints.
