Completeness

Completeness covers missing, redundant, and inefficient constraints. 

The following table lists all the signoff rules for completeness checks:

TypeRule Checks
Clock constraints CONST_CLK_DEF* / CONST_CLK_UNC* / CONST_CLK_LAT* / CONST_CLK_CTR* / CONST_CLK_GRP* / CONST_CG_CHK*
IO constraints CONST_IO_IDL* / CONST_IO_ODL* / CONST_IO_ITR* / CONST_IO_OLD*
Exceptions CONST_EXC_FLP* / CONST_EXC_MCP* / CONST_EXC_SMD* / CONST_EXC_OLP*
Case analysis constraints CONST_SCA_CHK*
Design rule constraints CONST_IO_DRC*
Others CONST_DGN_CMB* / CONST_DGN_TIM* / CONST_DAT_CHK* / CONST_HFN_CHK*

Consistency

Consistency covers conflicting constraints, inconsistent clock schemes, and inconsistent constraints.

The following table lists all the signoff rules for consistency checks:

TypeRule Checks
Clock constraints CONST_CLK_*
IO constraints CONST_IO_*
Exceptions CONST_EXC_OLP*
Case analysis constraints CONST_SCA_*
Others CONST_DGN_*
