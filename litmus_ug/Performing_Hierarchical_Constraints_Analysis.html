Performing Hierarchical Constraints Analysis

Constraints consistency analysis is run after analysis results configuration and report generation. It includes the following:

  1. Commands to verify hierarchical timing intent.
  2. Post-filters to configure analysis results.
  3. Generate reports for review.
  4. Constraints consistency failure modes.
