Using Litmus GUI

The Litmus Graphical User Interface (GUI) provides an interactive environment to inspect and analyze rule violations generated during Litmus runs. The GUI supports advanced debug workflows by enabling you to review violations, cross probe to design representations, access SDC constraints, and manage large result sets efficiently.

The following are the key capabilities of the Litmus GUI:

  • Violation visualization and analysis: Review rules across categories, their status, and details of the violated rules interactively in the GUI.
  • Violation-based schematic visualization: Navigate from a violation to the schematic view and inspect the highlighted objects with standard zoom controls.
  • Advanced debug via cross-probing: Navigate from violations to HDL/RTL using context-menu actions.
  • Direct interface to access SDC files: Navigate from violations to SDC representations. This opens the SDC viewer for the occurrence that contains the SDC file/line reference and jumps to the exact line.
  • Filtering for large datasets: Refine results using multiple filtering options, such as rule-level filtering (status/severity), name-based filtering, and occurrence-based filtering.
  • Scales for very large (1B+) designs: Supports interactive review for high-capacity designs and large violation sets.

For detailed information about GUI components and workflows, refer to Working with the GUI.

Launching the Litmus GUI

The Litmus GUI is launched from the Litmus command environment after the design has been initialized and analysis has been performed.

  • Before invoking the GUI, ensure that:
    • The design is initialized using the Litmus setup command: init_design
    • Rule checks are executed using the verify_timing_intent or the check_target_constraints command.
  • To invoke the GUI, type gui_show on the 'litmus>' command prompt. 

    This displays the Rules Summary workspace:


In typical workflows, the categories and violations shown depend on the analyses executed before launching the GUI. For example, violations may appear under categories such as constraint signoff and constraint lint after timing intent verification.

Exiting or Hiding the GUI

You can either exit the GUI (terminate the GUI application) or hide the GUI (remove it from view while keeping the Litmus tool in command mode available).

Exiting the GUI

You can exit the GUI by using any of the following methods:

  • From the Litmus command prompt, type quit or exit.
  • From the Menu Bar, select File → Exit, and click OK in the confirmation dialog to close the GUI.
  • Use the Close button at the top-right corner of the main GUI window.

Hiding the GUI

Hiding the GUI removes it from view but allows the Litmus session to continue running. The GUI process runs in the background.

  • From the Litmus command prompt, type gui_hide.
  • From the Menu Bar, select File → Hide GUI to hide the GUI.
  • Use the Hide GUI option (while using File → Exit or the Close button) to hide the GUI.
  • Use gui_show again to re-display the GUI window.
