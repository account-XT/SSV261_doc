SVA Generation for Functional Checks

Litmus generates System Verilog Assertions (SVA) corresponding to timing constraints. These SVAs help to ensure the constraint's functional correctness.

The following constraints are supported for generating SVAs:

  • Set False Path (set_false_path)
  • Set Multicycle Path (set_multicycle_path)
  • Generated Clock (create_generated_clock)
  • Set Case Analysis (set_case_analysis)
  • Set Disable Timing (set_disable_timing)
