Running Constraint Comparison

compare_constraints [-sdc_compare]
  • compare_constraints
    • Runs timing-aware + timing-unaware comparison

    • Timing-Aware Reports (Signoff Rules)

      • report_rule_check CONST_COMP* -verbose -attribute

      • Each reported violation includes:

        • Reference and target object mapping
        • Constraint attributes from both views
        • Root cause classification (missing, mismatched, inconsistent)
  • compare_constraints -sdc_compare
    • Runs timing-unaware only (2SDC comparison)

    • Timing-Unaware Reports

      • report_sdc [-sdc_compare] [-verbose]

      • Reports SDC statistics by default, with -sdc_compare, additionally reports:
        • Matched constraints
        • Mismatched constraints
        • Unique constraints
