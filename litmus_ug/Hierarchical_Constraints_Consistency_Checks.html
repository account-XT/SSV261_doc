Hierarchical Constraints Consistency Checks

The following are the signoff rules for hierarchical consistency checks:

  • Clock constraints

    • CONST_HIER_CLK* / CONST_HIER_UNC* / CONST_HIER_LAT* / CONST_HIER_CTR* / CONST_HIER_GRP* / CONST_HIER_CG* / CONST_HIER_PLS*

  • IO constraints
    • CONST_HIER_IO* / CONST_HIER_OLD*
  • Exceptions
    • CONST_HIER_EXC*
  • Case analysis constraints
    • CONST_HIER_SCA*
  • Others
    • CONST_HIER_SDT* / CONST_HIER_TIM* / CONST_HIER_DAT* / CONST_HIER_HFN*
