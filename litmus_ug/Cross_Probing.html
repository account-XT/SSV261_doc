Cross‑Probing

Cross‑probing enables you to navigate directly from a reported rule occurrence in the Occurrences Table to the corresponding design representation. This capability helps correlate rule violations with RTL, schematic, or constraint definitions and supports efficient root‑cause analysis.

Cross‑probing actions are available through the right‑click context menu on a selected rule occurrence row. Depending on the type of information associated with the selected occurrence, different cross‑probing options are presented.

  • Cross‑Probing to HDL / RTL
  • Cross‑Probing to Schematic
    • Open Schematic View (Cone)
    • Open Schematic View (Module)
  • Cross‑Probing to SDC

Cross‑Probing to HDL / RTL

For rule occurrences associated with RTL objects (for example, pins), you can cross‑probe to the HDL/RTL source code using the Open HDL Viewer option from the right‑click context menu.

When Open HDL Viewer is selected, the HDL viewer opens and navigates to the exact source‑code location corresponding to the selected object. The relevant object is highlighted in the HDL/RTL code, enabling you to quickly identify the implementation context related to the reported rule violation.

This form of cross‑probing allows direct correlation between a rule occurrence and the corresponding RTL construct without manual source navigation.

Note:

Cross‑probing to HDL/RTL is not supported for gate‑level netlists.

Cross‑Probing to Schematic

The Litmus GUI supports schematic cross‑probing through two distinct options available in the right‑click context menu of a rule occurrence:

  • Open Schematic View (Cone)
  • Open Schematic View (Module)

For both Cone and Module views, standard zoom and navigation controls can be used to inspect the schematic in detail.

Open Schematic View (Cone)

The Cone view focuses on the local logic cone around the selected object. Selecting Open Schematic View (Cone) opens a schematic that shows the immediate connectivity and surrounding logic relevant to the rule occurrence.

The Cone schematic view provides the following display options:

  • In Main – Opens the schematic view in the main GUI window
  • In New – Opens the schematic view in a new window
  • Append – Appends the schematic content to an already open schematic viewer

Open Schematic View (Module)

The Module view displays the complete module containing the selected object. Selecting Open Schematic View (Module) opens the full module‑level schematic, providing a broader structural context for the rule occurrence within the design hierarchy.

The Module schematic view provides the following display options:

  • In Main – Opens the module schematic in the main GUI window
  • In New – Opens the module schematic in a new window

Note:

An Append option is not provided for the Module view, as the entire module is already displayed as a single schematic entity.

Cross‑Probing to SDC

For rule occurrences that include SDC‑related information (for example, an SDC file and line reference), the Litmus GUI supports cross‑probing directly into the corresponding SDC constraint location. This capability helps to quickly inspect the constraint definition associated with a reported rule occurrence.

Cross‑probing to SDC is invoked from the right‑click context menu on a selected rule occurrence row in the Occurrences Table using the Open SDC Viewer option. In the context menu, the SDC entry is shown with the associated line number and SDC file name (for example, 105 : fifo_demo.sdc.AFIFO).

When Open SDC Viewer is selected, the SDC Viewer opens and loads the referenced SDC file. The viewer automatically navigates to the referenced line number and highlights the corresponding constraint line for easy identification. This allows you to validate the constraint content at the exact source location associated with the selected rule occurrence.
