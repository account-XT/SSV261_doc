Working with the GUI

This chapter provides detailed information about the components, layout, and workflows of the Litmus GUI. The Litmus GUI is launched using the gui_show command from the Litmus shell. Once launched, the GUI displays the Rules Summary, which serves as the primary workspace for reviewing and analyzing rule evaluation results. This chapter describes:

  • The structure of the Litmus GUI
  • The Menu Bar and Rules Summary components
  • Cross‑probing and filtering workflows

For information on launching the GUI and managing its lifecycle, refer to Launching the Litmus GUI.
