Set False Path (set_false_path)

This topic details the path-based sampling methods for set false path.

  • Level 1
  • Level 2
  • Level 3

Level 1

Constraint: set_false_path -to [get_clocks CLKA] -through [Ffto/D]]

Litmus commands used:

# This is default
set_db ltms_sva_path_based_sampling_opt_level 1

# Generate SVAs
generate_sva -sfp

Output SVA

sfp.sv
assert property (sfp_stable_cycle(`CLKA, `RESETA, $stable(Ffto.D) || $stable(AND2.Y)|| $stable(AND1.Y)|| $stable(FFfrom1.Q),2))
assert property (sfp_stable_cycle(`CLKA, `RESETA, $stable(Ffto.D) || $stable(AND2.Y)|| $stable(AND1.Y)|| $stable(FFfrom2.Q),2))
property sfp_stable_cycle(CLK, RESET, STABLE_PATH, CYCLES);
  @(posedge CLK) disable iff (RESET)
    ##1 !STABLE_PATH |=> STABLE_PATH[*CYCLES-1];
endproperty

Level 2

If there are transition points with the same value (one-to-one connection), Litmus merges them and retains output pins or pins specified in constraint.

Exception: set_false_path -from [get_clocks CLKA] -to [get_clocks CLKB] -through [FFto/D]]

Litmus commands used:

# Enable Mode 2 
set_db ltms_sva_path_based_sampling_opt_level 2

#Generate SVAs
generate_sva –sfp

Output SVA

sfp.sv
assert property (sfp_stable_cycle(`CLKB, `RESETA, $stable(FFto.D) || $stable(AND1.Y) || $stable(FFfrom1.Q),2))
assert property (sfp_stable_cycle(`CLKB, `RESETA, $stable(FFto.D) || $stable(AND1.Y) || $stable(FFfrom2.Q),2))
property sfp_stable_cycle(CLK, RESET, STABLE_PATH, CYCLES);
  @(posedge CLK) disable iff (RESET)
    ##1 !STABLE_PATH |=> STABLE_PATH[*CYCLES-1];
endproperty

Level 3

Litmus only samples the points specified in the SDC constraint command.

Exception: set_false_path -from [get_clocks CLKA] -through [FFto/D]]

Litmus commands used:

# Enable SDC Mode
set_db ltms_sva_path_based_sampling_opt_level 3

#Generate SVAs
generate_sva –sfp

Output SVA

sfp.sv
assert property (sfp_stable_cycle(`CLKA, `RESETA, $stable(FFto.D))
property sfp_stable_cycle(CLK, RESET, STABLE_PATH, CYCLES);
  @(posedge CLK) disable iff (RESET)
    ##1 !STABLE_PATH |=> STABLE_PATH[*CYCLES-1];
endproperty
