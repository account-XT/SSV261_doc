Using Litmus

Use the litmus command, to start a Litmus session. The command has the following options.

ParameterDescription
Controls
-abort_on_error

Exit if an error is detected at any point.
-batch

No interactive prompt occurs. Exit after -execute and -files options are processed.
-cds_lib_file in_file

Loads in_file rather than the default cds.lib file in the current directory to obtain the names and locations of OpenAccess libraries.
-cpus integer

Specify the number of CPUs to use for multi-threading on current host.
-disable_user_startup

Reads only the init file in the installation hierarchy. Does not read init files present in the home or current directory.
-execute tcl_command

Specify the TCL commands to be executed as a quoted string at startup.
-files file_list

Executes the script file at startup.

One or more TCL files to source at startup, after -execute.

Set the environment variable CDS_STYLUS_SOURCE_VERBOSE to 0 if you don't want the source command output to default to verbose in Stylus.
-log file

Setup the log file to save the transcript.
-no_logv file

Specify to avoid creating verbose logv file.
-no_cmd

Specify to avoid creating verbose command file.
-no_gui

Disable GUI and Tk support. GUI will not be available later in the session.
-overwrite

Specify to overwrite existing log files 
-version

Return program version information.

Use the exit command to exit a session.

Inside the Tool

Litmus supports command line tab completion. It also supports the following commands.

CommandsDescription
man <command>
man <rule>		 Shows the details of a command or a rule.
history Shows the list of previous commands. Alternatively, you can use the up or down arrow keys as well.

set_message -id <rule> -severity <warn | error | info | reset>
set_message -id <rule> -suppress | -unsuppress

Changes rule severity level or suppress/unsuppress a rule.

report_rule_check -severity <severity_name>
                  -category <category_name>
                  -status <name>

Reports the rule occurrences encountered when running the specified rule instances

set_rule_handling

Sets the severity level of rule instances or limits the number of occurrences that each rule instance can have.
