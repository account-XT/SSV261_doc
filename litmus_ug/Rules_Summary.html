Rules Summary

The Rules Summary is the primary workspace for reviewing rule evaluation results. It consolidates rule navigation, detailed violation data, and contextual rule information to support efficient analysis and debug. It displays information about rule check results in the design.

The Rules Summary is organized into the following sections:

  • Navigation Pane: Provides a hierarchical view of rule categories and individual rules.
  • Occurrences Table: Displays the attribute information of each occurrence of the rule selected in the navigation pane.
  • Description Tab: Displays contextual details for the rule selected in the navigation pane.
