Occurrences Table

The Occurrences Table displays occurrence‑level information for the rule selected in the Navigation Pane. Each row in the table represents a distinct occurrence of the selected rule. The set of columns displayed in the Occurrences Table is rule‑dependent. When a rule is selected, only the attributes relevant to that rule are shown as table columns. For example, a rule such as CONST_CLK_LAT4 may display columns as shown in the figure below. The Occurrences Table allows you to review, filter, and analyze multiple occurrences of the same rule independently.

Filtering in the Occurrences Table

There are filtering controls at the top of the Occurrences Table to help you refine the display, which is especially useful when a rule reports a large number of occurrences.

  • The Occurrence-based filters control how occurrences affected by rule filters are displayed. The following options are available: 
    • Show Filtered – Displays only occurrences that have been filtered using rule filters.
    • Show Unfiltered – Displays only occurrences that are not affected by rule filters.
    • Show All – Displays both filtered and unfiltered occurrences together.

Note:

The occurrence‑based filtering options reflect the filters defined using the Create Rule Filters feature.

  • The Name‑based filtering is enabled through the text input field next to the Filter icon. You can enter a search string in this field to dynamically filter the table rows based on matching attribute values. Only occurrences whose attribute values contain the specified search string are displayed.

These filtering mechanisms allow you to quickly narrow down the list of occurrences and focus on specific objects, attributes, or filtered results during analysis.
