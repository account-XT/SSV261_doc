Creating Rule Filters

When a rule reports a large number of occurrences, rule filters allow you to selectively filter specific occurrences without modifying the underlying rule results. Rule filters are created using the Create Rule Filter option available from the GUI context menu. It helps manage large violation sets by isolating occurrences of interest. From an analysis perspective, rule filters act as occurrence‑level waivers, temporarily suppressing selected occurrences from active consideration while preserving the original rule evaluation data.

Creating Rule Filters from the Navigation Pane

A rule filter can be created at the rule level by right‑clicking on a rule in the Navigation Pane and selecting Create Rule Filter.

Invoking the rule filter from the Navigation Pane opens the Add Rule Filter dialog for the selected rule. In this case, no specific occurrence is preselected by default, allowing you to define filter criteria from scratch. This is useful when you want to create a rule filter based on:

  • A specific Occurrence ID entered manually, or
  • A Custom range of occurrence IDs associated with the selected rule.

Creating Rule Filters from the Occurrences Table

Rule filters can also be created for a specific occurrence directly from the Occurrences Table. You can right‑click a row corresponding to a particular occurrence and select Create Rule Filter from the context menu.

When a rule filter is created from a specific occurrence:

  • The Occurrence ID corresponding to the selected row is preselected in the Add Rule Filter dialog.
  • The preselected Occurrence ID can be edited if required, allowing you to refine or expand the filtering scope with Custom range.

This is particularly useful when you identify a specific occurrence in the Occurrences Table that needs to be filtered.

Add Rule Filter Dialog

The Add Rule Filter dialog provides options to define the filter criteria and specify how the rule filter should be handled.

The dialog includes the following fields and options:

  • Filter Name – Displays the default filter name generated based on the selected rule and occurrence.

  • Criteria

    • Prefix (Optional) – Allows you to specify an optional prefix for the rule filter name.
    • Occurrence ID – Allows filtering of a specific occurrence by its ID. When the rule filter is created from the Occurrences Table, this field is auto‑populated with the selected occurrence ID.
    • Custom range – Allows you to specify a range of occurrence IDs (for example, 1,4,5‑12) to be filtered.
  • Write to File – Saves the generated rule filter expression to a file for reuse in future sessions.
  • Execute Rule Filter – Executes the rule filter immediately in the current GUI session.

    • When Execute Rule Filter is enabled and the dialog is applied, the rule filter is executed in the current session.

When the Apply action is performed, a confirmation message is displayed indicating that the rule filter has been applied. Once executed, the effect of the rule filter can be observed using the filtering controls available in the Occurrences Table, as described earlier in the section Filtering in the Occurrences Table.
