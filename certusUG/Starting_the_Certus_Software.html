Starting the Certus Software

You can start the Certus software using the executable: certus

Note that the binary pointed to by Certus is still the SSV binary structure. For example,

/install_dir/bin/certus

Using the above command, Certus will start Tempus clients using Tempus and Certus clients using Innovus.

Note: By default, Certus runs in ECO mode.
