Launching the Certus Console

When you start Certus in the non-GUI environment using the -no_gui parameter, the UNIX window (shell, xterm, and so on) where you start the Certus session is called the Certus console. This is where you enter all Certus text commands and where the software displays messages. When a session is active, this console displays the following prompt:

certus>

When you start Certus in the GUI environment, the Certus console is displayed within the main Certus window. If you use this console for other actions, for example, to use the vi editor, the session suspends until you finish the action.

If you suspend the session by typing Control-z, the certus> prompt is no longer displayed.

To return to the Certus session, type fg, which brings the session to the foreground.
