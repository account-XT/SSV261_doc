Certus Inputs Requirements

The input data for setting up the distributed ECO environment in Certus is as follows:

  • Tempus STA saved sessions:
    • These can be C-MMMC or SMSC - non-physical sessions.
    • Identify which view should be used for power reporting.
  • Innovus DB pointer for top-only and each partition:
    • Ensure that Innovus DBs are based on the same netlist as STA sessions.
    • You can use ILM inside Innovus DB, while the same modules are flattened inside STA sessions.
  • Resources:
    • 1 client manager machine (16 CPUs or more preferred).
    • 1 machine per STA sessions (16 CPUs or more preferred).
    • Extra machines - when the number of Innovus DBs is much higher than the number of STA sessions.
