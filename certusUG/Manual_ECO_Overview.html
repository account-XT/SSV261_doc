Manual ECO Overview

Manual ECO in Certus fixes timing, functional, or design rule violations in a design after signoff stages. This is especially useful in critical design phases, enabling precise fixes and reducing turnaround time before final signoff.

There are two modes supported in Manual ECO:

  • Non-Interactive mode
  • Interactive mode

Non-Interactive Mode

In this mode, the tool sources the specified Innovus-compliant ECO files. The command specified in these ECO files will first be executed on the respective Certus clients before being processed for execution on the manager. After this, the processed commands will be executed (block by block) on both the manager and the Tempus clients.

Note that if an error occurs at any stage during execution of the ECO files, processing will stop and control will be returned to the Certus manager.

To enable non-interactive mode, use the replay_distributed_eco - block_eco_file_list <file> setting, which specifies the list of Certus client block module names and the corresponding ECO files as input. You can also specify multiple ECO files for the same module.

Sample Template Script:

set_multi_cpu_usage -localCpu 12 -remoteHost 2 -cpuPerRemoteHost 8
## Settings for Certus start up
set_eco_opt_mode -distributed_opt_block_restore_file /icd/etsproject3/qor/RAK/LUI/blkRestore.txt
set_distribute_mmmc_mode -enable_high_capacity_eco
distribute_read_design -restore_design $dbnames -outdir paradime_Output
set_multi_cpu_usage -localCpu 12 -remoteHost 3 -cpuPerRemoteHost 8
start_distributed_eco_clients
#Setting to replay Certus Manual ECO
replay_distributed_eco -block_eco_file_list <path to block_eco_file> ./block_eco_file

Below is the template for block_eco_file_list:

dtmf_recvr_core ECO/drv_dtmf_recvr_core_eco_innovus.tcl
ptn_wrapper ECO/drv_ptn_wrapper_eco_innovus.tcl
tdsp_core ECO/drv_tdsp_core_eco_innovus.tcl
dtmf_recvr_core ECO/setup_dtmf_recvr_core_eco_innovus.tcl
ptn_wrapper ECO/setup_ptn_wrapper_eco_innovus.tcl
tdsp_core ECO/setup_tdsp_core_eco_innovus.tcl

Interactive Mode

In this mode, you need to provide the Tempus-compliant ECO commands on the Certus Client Manager (CCM), which then modifies them to obtain the relevant block-level ECOs (based on the instance on which ECO is performed). The processed ECO command is further sent to the Certus client through the TCL command interface.

The Certus client runs this ECO command and generates an enhanced ECO command for CCM (for example, by appending corner spec data), which CCM then processes. Further, CCM executes this ECO command on all the Tempus Clients first, followed by the Certus Client Manager.

Note:

  • The interactive manual ECO does not include support for eval.
  • You should not specify more than 1k ECOs to be sourced manually.

Sample Template Script:

set_distribute_mmmc_mode -eco true -merge_view_definitions
set_multi_cpu_usage -localCpu 12 -remoteHost 2 -cpuPerRemoteHost 8
## Settings for Certus start up
set_eco_opt_mode -distributed_opt_block_restore_file /icd/etsproject3/qor/RAK/LUI/blkRestore.txt
distribute_read_design -restore_design {save_db_dmmmc_setup_func
save_db_dmmmc_setup_test} -outdir paradime_Output
set_multi_cpu_usage -localCpu 12 -remoteHost 3 -cpuPerRemoteHost 8
start_distributed_eco_clients
##Tempus Compliant Manual ECO commands
change_cell -inst TEST_CONTROL_INST/g143 -cell NAND2X2
add_repeater -cell CLKBUFX2 -name FE_ESOC2_n_206 -term { CPF_ISO_HIER_INST_107/g471/A }
delete_repeater -inst PM_INST/FE_ESOC76_n_41

For details related to Manual ECO commands, refer to the Manual ECO Commands chapter of the Tempus Text Command Reference Manual.
