Template 1

The Certus flow performs hold timing closure on a Top+BM database based on timing violations from the Top+BM STA clients. You can decide to enable either GBA or PBA mode.

BM Generation Session

The BM session can be SMSC, MMMC, or D-MMMC.

set timing_full_context_flow 1
set timing_sum_cc_for_all_small_aggressors 1
set timing_write_aggressors_to_disk 1
set timing_enable_model_accurate_nef 1
set timing_enable_filter_fanin_cone 1
timing_enable_boundary_model_eco
…
create_boundary_model -overwrite -no_extended_fanin \
-latch_effort_low -skip_constants -exclude_no_delay_port \
-dir BM_${BlockName}_${view} -overwrite
The STA saved session can be SMSC or MMMC.

Top+BM STA Session

timing_enable_boundary_model_eco
<load_Top+BM_design>
save_design view1.enc

Certus Session

setDistributeHost -local -timeout 10000
set_multi_cpu_usage -localCpu 24 -remoteHost 4 -cpuPerRemoteHost 4 
set_distribute_mmmc_mode -enable_high_capacity_eco 
set eco_setup_view_list {setup_1v setup_2v setup_3v setup_4v}
set eco_hold_view_list {hold_1v hold_2v hold_3v hold_4v}
set eco_dynamic_view {setup_3v} ; set eco_leakage_view {setup_3v}
set_eco_opt_mode -distributed_opt_block_restore_file blocks.txt 
set_eco_opt_mode -optimize_replicated_modules true
distribute_read_design -restore_design all -restore_dir \     
STA_211/ -outdir reports_Paradime
set_distribute_host <your LSF args> -timeout 10000
start_distributed_eco_clients 
eco_opt_design -hold

Template 2

The Certus flow performs inter-partition Hold timing closure on a Top+BM database using a user-defined partition. The boundary model generation flow will remain the same as specified in Template 1.

The STA saved session can be SMSC or MMMC. The same template can be used to perform the inter-partition Power recovery.

Top+BM STA Session

timing_enable_boundary_model_eco
<load_Top+BM_design>
save_design view1.enc

Certus Session

setDistributeHost -local -timeout 10000
set_multi_cpu_usage -localCpu 24 -remoteHost 4 -cpuPerRemoteHost 4 
set_distribute_mmmc_mode -enable_high_capacity_eco 
set_eco_opt_mode -distributed_opt_block_restore_file blocks.txt 
set eco_setup_view_list {setup_1v setup_2v setup_3v setup_4v}
set eco_hold_view_list {hold_1v hold_2v hold_3v hold_4v}
set eco_dynamic_view {setup_3v} ; set eco_leakage_view {setup_3v}
set_eco_opt_mode -inter_partition {blockA blockB}
set_eco_opt_mode -intra_partition {}
set_eco_opt_mode -optimize_replicated_modules true
distribute_read_design -restore_design all -restore_dir \     
STA_211/ -outdir reports_Paradime
set_distribute_host <your LSF args> -timeout 10000
start_distributed_eco_clients 
eco_opt_design -hold

Template 3

The Certus flow performs DRV, Setup, and Hold timing closure on a Top+BM database using the user-defined Setup/Hold path_groups and a list of DRV pins. The boundary model generation flow will remain the same as specified in Template 1.

The STA saved session can be SMSC or MMMC.

Top+BM STA Session

timing_enable_boundary_model_eco
<load_Top+BM_design>
save_design view1.enc

Certus Session

setDistributeHost -local -timeout 10000 
set_multi_cpu_usage -localCpu 24 -remoteHost 4 -cpuPerRemoteHost 4 
set_distribute_mmmc_mode -enable_high_capacity_eco 
set_eco_opt_mode -distributed_opt_block_restore_file blocks.txt 
set_eco_opt_mode -path_group_file_name {TCL script which creates mySetupPG and myHoldPG path_groups} 
set_eco_opt_mode -include_setup_path_groups {mySetupPG} 
set_eco_opt_mode -include_hold_path_groups {myHoldPG} 
set_eco_opt_mode -select_drv_pin_file {myDRVPinList.txt} 
set eco_setup_view_list {setup_1v setup_2v setup_3v setup_4v} 
set eco_hold_view_list {hold_1v hold_2v hold_3v hold_4v} 
set eco_dynamic_view {setup_3v} ; set eco_leakage_view {setup_3v} 
set_eco_opt_mode -optimize_replicated_modules true 
distribute_read_design -restore_design all -restore_dir \     
STA_211/ -outdir reports_Paradime 
set_distribute_host <your LSF args> -timeout 10000 
start_distributed_eco_clients 
eco_opt_design –drv; eco_opt_design –setup; eco_opt_design -hold
