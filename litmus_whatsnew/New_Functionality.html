Litmus What's New
Product Version 26.10, May 2026

New Functionality

Release 26.10

Enhanced GUI

This release introduces a significantly enhanced high-capacity Graphical User Interface (GUI) that improves interactive analysis and debug of rule results through a more scalable and streamlined user experience. The updated GUI enables efficient browsing of rules, inspection of occurrence‑level details, and integrated cross‑probing and rule filtering workflows.

A key enhancement in this release is improved scalability, allowing the GUI to handle very large designs (1B+ instances). You can now interactively analyze rule violations and perform debug operations even for large, complex SoCs.

Additional enhancements include improved rule navigation, richer cross‑probing to HDL/RTL, schematic, and SDC views, and more flexible rule filtering, simplifying violation analysis across both block‑level and full‑chip use cases.

Constraint Promotion

This release introduces Constraint Promotion, a new capability that automates the migration of block‑level design constraints into the SoC‑level constraint environment. This feature enables systematic analysis, conflict detection, and controlled promotion of block constraints, ensuring consistent timing intent across hierarchical designs.

Constraint Promotion supports configurable promotion strategies and diagnostics, for both RTL and netlist flows, simplifying SoC integration and improving the reliability of hierarchical constraints signoff.

Constraints Comparison (1D2S)

This release introduces Constraints Comparison (1D2S – One Design, Two SDCs), which enables direct consistency checking between two SDC views of the same design. The feature supports reference‑versus‑target constraint validation, helping ensure that timing intent is preserved across design development, implementation, and constraint evolution workflows.

Constraints Comparison complements Hierarchical Constraints Signoff by extending consistency checks beyond block‑to‑top analysis to SDC‑to‑SDC comparison within the same design. It supports both timing‑aware comparison, reported through signoff rule checks, and fast timing‑unaware (2SDC) comparison, enabling early detection of missing, mismatched, or modified constraints.
