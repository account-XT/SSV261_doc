Litmus Attribute Reference
Product Version 26.10, May 2026

check_design

The root attributes in the check_design category are:

  • check_design_across_hierarchy
  • check_design_report_async_pins
  • check_design_report_scan_pins
  • check_design_threshold_fanout

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the read_physical category, use the following command:

get_db -category check_design

check_design_across_hierarchy

check_design_across_hierarchy {true | false}

Default: true

Data_type: boolean, read/write

Checks for undriven/multi-driven/unloaded/constant pins/ports by checking across hierarchical boundaries. By default checks are across hierarchy.

check_design_report_async_pins

check_design_report_async_pins {true | false}

Default: true

Data_type: boolean, read/write

Checks async pins in a netlist design. 

check_design_report_scan_pins

check_design_report_scan_pins {true | false}

Default: true

Data_type: boolean, read/write

Checks scan pins in a netlist design. 

check_design_threshold_fanout

check_design_threshold_fanout threshhold

Default: 10000

Data_type: int, read/write

Checks for upper threshold in a netlist design.
