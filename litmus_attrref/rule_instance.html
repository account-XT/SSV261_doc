rule_instance

The attributes in the rule_instance category are:

  • base_name
  • ltms_category
  • ltms_continue_on_error
  • ltms_desc
  • ltms_is_run
  • ltms_is_virtual
  • ltms_rule_filters
  • ltms_rule_occurrences
  • ltms_severity
  • ltms_status
  • ltms_table_header
  • name
  • obj_type

base_name

base_name string

Default: ""

Data_type: string, read/only

Name of the rule.

ltms_category

ltms_category string

Default: ""

Data_type: string, read/only

Category of the rule.

ltms_continue_on_error

ltms_continue_on_error {true|false}

Default: ""

Data_type: boolean, read/only

Check whether we should continue checking this rule in case of an error.

ltms_desc

ltms_desc string

Default: ""

Data_type: string, read/only

Description of the rule.

ltms_is_run

ltms_is_run {true|false}

Default: ""

Data_type: boolean, read/only

Check whether the rule_instance is run.

ltms_is_virtual

ltms_is_virtual {true|false}

Default: ""

Data_type: boolean, read/only

Check whether the rule instance is virtual.

ltms_rule_filters

ltms_rule_filters rule_filter

Default: ""

Data_type: object, read/only

List of filters of the rule instance.

ltms_rule_occurrences

ltms_rule_occurrences rule_occurrence

Default: ""

Data_type: object, read/only

List of occurrences of the rule instance.

ltms_severity

ltms_severity string

Default: ""

Data_type: string, read/only

Severity of the rule.

ltms_status

ltms_status string

Default: ""

Data_type: string, read/only

Status of the rule.

ltms_table_header

ltms_table_header string

Default: ""

Data_type: string, read/only

Table header of the rule.

name

name string

Default: ""

Data_type: string, read/only

Full name of the rule.
