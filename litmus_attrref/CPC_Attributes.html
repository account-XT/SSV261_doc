5

CPC Attributes

The attributes in the 'constraint promotion control' category are:

  • timing_disable_promotion_clock_prefix
  • timing_disable_promotion_clock_group_prefix
  • timing_enable_constant_promotion_to_top_driver
  • timing_promote_boundary_path_exceptions
  • timing_promote_cgc_enable_source_invert_and_multiply_by
  • timing_promote_cgc_source_pin_with_master
  • timing_promote_clock_to_top_port
  • timing_promote_derived_clocks_for_exceptions
  • timing_promote_global_block_constraints
  • timing_promote_in_out_delay_over_combinational_cone
  • timing_promote_inherit_clock_relationships
  • timing_promote_input_transition_as_annotated_transition
  • timing_promote_internal_set_input_delay
  • timing_promote_internal_set_output_delay
  • timing_promote_inverted_clock_pair_to_top
  • timing_promote_set_load_over_combinational_cone

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name


timing_disable_promotion_clock_prefix

timing_disable_promotion_clock_prefix {true | false}

Default: false

Data_type: Boolean

Removes instance name prefix from clock names if there is no collision.

timing_disable_promotion_clock_group_prefix

timing_disable_promotion_clock_group_prefix {true | false}

Default: false

Data_type: Boolean

Disables the automatic addition of instance name prefixes to clock group names after promotion.

timing_enable_constant_promotion_to_top_driver

timing_enable_constant_promotion_to_top_driver {true | false}

Default: true

Data_type: Boolean

Enables promotion of block constants to top driver for input type.

timing_promote_boundary_path_exceptions

timing_promote_boundary_path_exceptions {true | false}

Default: true

Data_type: Boolean

Enables promotion of block exceptions with block ports.

timing_promote_cgc_enable_source_invert_and_multiply_by

timing_promote_cgc_enable_source_invert_and_multiply_by  {true | false}

Default: true

Data_type: Boolean

Enables the -source_invert and -multiply_by options in promoted block clocks as cgc.

timing_promote_cgc_source_pin_with_master

timing_promote_cgc_source_pin_with_master {true | false}

Default: false

Data_type: Boolean

Replaces the CGC source of the promoted block clock with the promoted master root, when the value is set to 'true'.

timing_promote_clock_to_top_port

timing_promote_clock_to_top_port {true | false}

Default: false

Data_type: Boolean

Promotes unreachable block clocks to the top, otherwise the block clock is left at the same pin with reference to the top, when the value is set to 'true'.

timing_promote_derived_clocks_for_exceptions

timing_promote_derived_clocks_for_exceptions {true | false}

Default: true

Data_type: Boolean

Enables promotion derived clock for exceptions differences.

timing_promote_global_block_constraints

timing_promote_global_block_constraints {true | false}

Default: false

Data_type: Boolean

Promotes global block constraint to the top design, when the value is set to 'true'.

timing_promote_in_out_delay_over_combinational_cone

timing_promote_in_out_delay_over_combinational_cone {true | false}

Default: true

Data_type: Boolean

Enables promotion SIOD over combinational cone.

timing_promote_inherit_clock_relationships

timing_promote_inherit_clock_relationships {true | false}

Default: false

Data_type: Boolean

Enables promoted CGC to inherit the master clock relationship by using the set_clock_group commands.

timing_promote_input_transition_as_annotated_transition

timing_promote_input_transition_as_annotated_transition {true | false}

Default: false

Data_type: Boolean

Promotes the input transition applied on the block port as annotated transition on top pins if the block port is not directly connected to top port ( driver), when the value is set to 'true'.

timing_promote_internal_set_input_delay

timing_promote_internal_set_input_delay {true | false}

Default: false

Data_type: Boolean

Promotes set_input_delay inside the blocks, when the value is set to 'true'.

timing_promote_internal_set_output_delay

timing_promote_internal_set_output_delay {true | false}

Default: false

Data_type: Boolean

Promotes set_output_delay inside the blocks, when the value is set to 'true'.

timing_promote_inverted_clock_pair_to_top

timing_promote_inverted_clock_pair_to_top {true | false} 

Default: false

Data_type: Boolean

Promotes the clock if phase inversion is found in the path and clock is inverted, when the value is set to 'true'.

timing_promote_set_load_over_combinational_cone

timing_promote_set_load_over_combinational_cone {true | false} 

Default: false

Data_type: Boolean

Enables promotion of set load over combinational cone.
