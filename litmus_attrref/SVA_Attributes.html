To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the sva category, use the following command:

get_db -category sva

ltms_sva_assertion_in_module_limit

ltms_sva_assertion_in_module_limit int

Default: 1000

Data_type: Integer

Defines the maximum number of assertion generated per module.

ltms_sva_assertion_limit

ltms_sva_assertion_limit intltms_sva_sdt_tag

Default: 0 (no limit)

Data_type: Integer

Defines the maximum number of SVA assertions to generate.

ltms_sva_assertion_prefix

ltms_sva_assertion_prefix string

Default: " "

Data_type: String

Defines the prefix for false-path and multi-cycle-path assertions.

ltms_sva_assertion_suffix

ltms_sva_assertion_suffix string

Default: " "

Data_type: String

Defines the suffix for false-path and multi-cycle-path assertions.

ltms_sva_cgc_file_prefix

ltms_sva_cgc_file_prefix string

Default: " "

Data_type: String

Defines the prefix for create_generated_clock SVA file. If not defined, ltms_sva_file_prefix is used.

ltms_sva_cgc_file_suffix

ltms_sva_cgc_file_suffix string

Default: " "

Data_type: String

Defines the suffix for create_generated_clock SVA file. If not defined, ltms_sva_file_suffix is used.

ltms_sva_cgc_use_edge_sampling

ltms_sva_cgc_use_edge_sampling bool

Default: false

Data_type: Boolean

Setting this to 'true', enables the edge sampling mode of SVA generation for CGC (create_generated_clock) and disables the toggle based method (Default).

ltms_sva_clock_selection

ltms_sva_clock_selection string

Default: all_propagated

Data_type: String

Defines the clock(s) to be used for assertions: fast | fast_propagated | slow | slow_propagated | all | all_propagated | <clock_name>

ltms_sva_disable_sdc_comment_processing

ltms_sva_disable_sdc_comment_processing bool

Default: true

Data_type: Boolean

Setting this to 'true', disables the feature of filtering exceptions based on comments in SDC command. Attribute ltms_sva_generate_comment is not honored and exceptions category is not picked from SDC comment when -use_categry is specified with generate_sva.

ltms_sva_file_prefix

ltms_sva_file_prefix string

Default: " "

Data_type: String

Defines the prefix for false-path, multi-cycle-path and create_generated_clock SVA files.

ltms_sva_file_suffix

ltms_sva_file_suffix string

Default: " "

Data_type: String

Defines the suffix for false-path, multi-cycle-path and create_generated_clock SVA files.

ltms_sva_generate_comment

ltms_sva_generate_comment string

Default: " "

Data_type: String

Defines the comment to be added to generated assertions.

ltms_sva_include_per_property_comment

ltms_sva_include_per_property_comment bool

Default: false

Data_type: Boolean

When set to 'false', comments (// From|Through|To/Clock) for each SVA property are not written in output SVA file.

ltms_sva_inc_buf

ltms_sva_inc_buf bool

Data_type: Boolean

Include buffer in SFP/MCP path analysis.

ltms_sva_path_based_sampling_exhaustive

ltms_sva_path_based_sampling_exhaustive bool

Default: false

Data_type: Boolean

When set to 'true' tool exhaustively processes all paths corresponding to MCP/SFP exceptions, applies only to -sfp / -mcp options, causes higher runtime for SVA generation.

ltms_sva_path_based_sampling_opt_level

ltms_sva_path_based_sampling_opt_level enum

Default: 1

Data_type: Enum

Define level of optimization for Path Based SVA for MCP/FP: 1 | 2 | 3

  • 2 = Mode2
  • 3 = Basic Mode
