To set the value of any root attribute, use the set_db command:

get_db -category place

place_3d_use_existing_bump_tsv

place_3d_use_existing_bump_tsv {true|false}

Default: false

Data_type: string, read-only

Enables 3D placement to use preplaced but unassigned bump/TSV in the design for signal net assignment. The preplaced bump/TSV must be the specified cells for 3D concurrent bump/TSV insertion and legalization.

Note: When you set this option to true, you need to ensure that enough bump/TSV is preplaced and the corresponding bump grid is created in each die before invoking the 3D placement.

place_cell_edge_spacing

place_cell_edge_spacing {cell_edge_type1 cell_edge_type2 spacing}

Default: ""

Data_type: string

Specifies the list of cell edge-type spacing values from LEF CELLEDGESPACINGTABLE or OA techfile that affects the placer. It specifies the min-spacing between different edge-types of std-cells, in a list format: {cell_edge_type1 cell_edge_type2 spacing}. The edge-type names match the base_cell's right_edge_type and left_edge_type attribute values.

place_check_report_fixed_inst_on_blockage

place_check_report_fixed_inst_on_blockage {true | false}

Default: false

Data_type: bool, read/write

When true, check_place reports placement blockage violations for fixed instances under placement blockages.

place_design_enable_3d

place_design_enable_3d {true | false}

Default: false

Data_type: bool, read/write

Enables 3D placement in Integrity 3D-IC platform. You need to set this to true before invoking concurrent macro placement (place_design –concurrent_macros), standard cell placement (place_opt_design -place), and bump/TSV insertion (place_bump_tsv_detail) in a 3D design.

place_design_integrity_ir_fix_effort

place_design_integrity_ir_fix_effort {low|medium|high}

Default: medium 

Data_type: enum, read/write

Sets the power integrity placement IR fixing effort.

place_design_refine_macro

place_design_refine_macro  {true | false}

Default: false 

Data_type: bool, read/write

Specifies whether to run place_macro_detail after place_design -concurrent_macros. When place_design –concurrent_macros is run, it sets the value of place_opt_run_global_place attribute to seed.

place_detail_allow_border_pin_abut

place_detail_allow_border_pin_abut {true | false} 

Default: false

Data_type: bool

Some libraries have cells with pin geometry that is not set back by half-routing pitch from the normal PR-boundary of that cell. In cases where the pin geometries touch the cell PR_boundary, placement of an instance of this cell can cause a DRV violation with a normal pin geometry of the other cells. To avoid these DRVs, placer will add one Site padding to the cell-side during pre-processing, thus satisfying the min-spacing rules. The place_detail_allow_border_pin_abut attribute disables this pre-emptive DRV avoidance behavior, and no auto-padding is done when the option is set to true.

place_detail_allow_single_height_row_symmetry_x

place_detail_allow_single_height_row_symmetry_x siteName 

Default: ""

Data_type: bool, read/write

Specifies a single height row tech-site, which allows symmetry X during detail place.

place_detail_check_route

place_detail_check_route {true | false}

Default: false 

Data_type: bool

Considers pre-routed FIXED signal wires and avoids creating DRC violations between FIXED signal wires and instance pins. When this attribute is not specified, place_detail ignores FIXED signal wires.

Note: Using this attribute might result in longer run time.

If you specify place_detail -io_pin_blockage, you do not need to specify -check_route for signal pins because place_detail will treat the signal pins similar to supply pins for blockages. However, signal wires still need this attribute.

place_detail_color_aware_legal

place_detail_color_aware_legal {true | false}

Default: false

Data_type: bool

Enables placer to honor and fix double pattern constraints between adjacent cells.

Note: This attribute does not affect cell to pre-route color DRC checks.

place_detail_context_aware_legal

place_detail_context_aware_legal {none|all|optional|required|user|ignore_soft}

Default: all

Data_type: enum* {none all optional required user ignore_soft}

Instructs placer to support cell edge to cell edge spacing constraints as defined in the LEF files.

The optional, required, user argument values can be used separately or together, but they are exclusive to all and none. 

place_detail_honor_inst_pad

place_detail_honor_inst_pad {true | false}

Default: false 

Data_type: bool

Honors padding from set_inst_padding in detail placement.

place_detail_ir_aware_max_drive_strength

place_detail_ir_aware_max_drive_strength maxDriveStrength

Default: 0.0

Data_type: double, read/write

Specifies the current density value for the IR critical instances above which the instances gets padded during place_detail. This means that the IR critical instances with the current density value more than the specified value gets padded.

Note: There may be larger cell movement with this option, which can degrade the timing. So, it is preferred to be used at the pre-CTS stage in the flow. The current density values for the IR-critical instances are dumped in the Voltus Reports.

place_detail_pad_fixed_insts

place_detail_pad_fixed_insts {true | false}

Default: false

Data_type: bool

Specifies whether the place_detail command honors cell padding on FIXED instances.

place_detail_swap_eeq_cells

place_detail_swap_eeq_cells {true | false}

Default: false

Data_type: bool

Determines whether master cells can be replaced by EEQ cells during detailed placement to improve routability. After detailed placement, the software reports the number of replacements. EEQ cells are defined in the LEF file.

place_detail_m3_stripe_push_down

place_detail_m3_stripe_shrink site_units

Default: -1  

Data_type: int

Specifies the width threshold in site units for virtual push down of M3 stripe to M2 for M1 pin-access.

If the default value is set to -1, it indicates that no M3 stripe will be pushed down. If the default value is set to 0, it indicates that all M3 stripes will be pushed down. If the default value is larger than 0, then all M3 stripes having width greater than the specified value will be pushed down.

place_detail_m3_stripe_shrink

place_detail_m3_stripe_shrink site_units

Default: 0  

Data_type: int

Specifies the shrink effort of the virtual M2 stripe by given total site units. This global should work with place_detail_m3_stripe_push_down.

If the default value is set to 0, it indicates that the entire pushed down M3 stripe is used to evaluate M1 pin access. If the default value is set to more than 0, it indicates that M3 stripe will shrink by the specified value before it is pushed down to M2. The left side will shrink first. For example, if the specified value is set to 1, the M3 stripe will shrink by 1 site on left, and if the specified value is set to 2, 1 site on left will shrink, along with 1 site on right.

place_detail_use_diffusion_transition_fill

place_detail_use_diffusion_transition_fill {true | false}

Default: false

Data_type: bool

Specifies that the design has fillers with jogged diffusion obs. Use this attribute for designs where fillers with jogged diffusion obs are to be inserted between cells with varying diffusion widths.

place_detail_use_gate_array_filler_groups

place_detail_use_gate_array_filler_groups {true | false}

Default: false  

Data_type: bool

Specifies that the filler cell instances will only be replaced by logic instances that belong to same GA groups.

place_detail_pgftv_insertion_cell_list

place_detail_pgftv_insertion_cell_list listOfCells

Default: ""

Data_type: string, read/write

Specifies the list of cells as PG FTV cells. 

place_global_adaptive_subd1

place_global_adaptive_subd1 {true|false}

Default: false

Data_type: bool, read/write

When set to true, placement will call Opt API to get a list of cells not usable for subD1 and disable the usage of cells in the placement engine.

place_global_adaptive_subd1 can be used independently to get the list of subD1 cells.

place_global_ignore_low_effort_path_groups

place_global_ignore_low_effort_path_groups {true | false}

Default: false

Data_type: bool, read/write

When place_global_enable_distributed_place is set to true, for low effort path groups, the tool ignores it and does not work on the timing.
