set_db attribute_name value

get_db attribute_name

To get the current value of all attributes in the eco category, use the following command:

get_db -category eco 

eco_add_ports

eco_add_ports {true|false}

Default: true

Data_type: Boolean

Determines whether to add hierarchical module ports during buffering. 

Note: This attribute works only for the Manual ECO commands.

eco_batch_mode

eco_batch_mode {true|false}

Default: false

Data_type: Boolean

Speeds up the runtime in case the user performs lots of interactive ECO operations. When the user specifies eco_batch_mode true, various ECO operations are performed in a batch and initialization steps are not performed for every ECO call. In addition, updating timing is performed only once for all the ECO operations. Tool will only perform timing initialization at the first ECO command in the batch mode and timing update at the time of exiting the batchMode. User needs to specifybatchMode false to exit the batchMode.

The batch mode is activated by eco_batch_mode true and exited by eco_batch_mode false, and only eco_add_repeater, eco_delete_repeater and eco_update_cell could be given in between eco_batch_mode true and  eco_batch_mode false:

eco_batch_mode true
eco commands (eco_add_repeater, eco_delete_repeater, eco_update_cell)

eco_batch_mode false

If a user activates the batch mode, then the user needs to remember to exit it. If the user does not exit the batch mode, the user might see some unexpected results. For example, if the tool automatically added cell padding for blocks when place_detail is called by ECO commands for some reason, the cell padding will not be removed and the block size will change unless the user exits the batch mode.

All other settings should be made prior to activating the batch mode. If you would like to change settings, you need to exit the batch mode first.

Note: This option supports all commit ECO commands. Evaluation commands are not supported.

eco_check_logical_equivalence

eco_check_logical_equivalence {true|false}

Default: true

Data_type: Boolean

Enables functionality checking when swapping cells. The software can swap cells that are logically equivalent.

When -eco_check_logical_equivalence is true: 

  • eco_add_repeater adds inverter pair if the specified cell is inverter.
  • eco_delete_repeater deletes inverter pair if the specified instance is inverter.
  • eco_update_cell changes cell to another cell type with the same function as long as they have same number of pins.

When -eco_check_logical_equivalence is set to false:

  • eco_add_repeater can add only one single inverter if the specified cell is inverter.
  • eco_delete_repeater can delete only one single inverter if the specified instance is inverter.
  • eco_update_cell can perform nonequivalent cell change as long as they have same number of pins.

eco_honor_dont_touch

eco_honor_dont_touch cellName

Default: true

Data_type: Boolean

Checks for the don't touch attribute on nets and instances. If you specify a terminal list, this parameter checks each terminal for the don't touch attribute. The ecoAddRepeater command honors the don't touch nets. The eco_delete_repeater and eco_update_cell commands honor don't touch instances.

eco_honor_fixed_status

eco_honor_fixed_status {true|false}

Default: true

Data_type: Boolean

Checks for fixed net wires.

It restricts the addition or deletion on fixed net so that the fixed status of the wires is not altered.

eco_honor_fixed_wires

eco_honor_fixed_wires {true|false}

Default: true

Data_type: Boolean

Checks for fixed net wires.

It restricts the addition or deletion on fixed net so that the fixed status of the wires is not altered.

When -eco_honor_fixed_wires is set to false, eco_add_repeater can insert a cell on the wires with the FIXED/COVER status and change the status of these wires from FIXED/COVER to ROUTED. 

eco_honor_power_intent

eco_honor_power_intent {true|false}

Default: true

Data_type: Boolean

Performs Multi Supply Voltage Design (MSV) checks during ECO. 

When this parameter is set to true:

  • eco_update_cell does not allow:
    • Resizing a regular cell with an always-on cell (and vice-versa).
    • Resizing with cells belonging to different power domains.
  • eco_add_repeater does not allow:
    • Adding buffer to a power domain it doesn't belong to.
    • Buffering a cross power domain net if it can cause MSV violations.
    • Adding a regular buffer to a net that requires an always-on buffer.
    • Adding an always-on buffer to a net that does not require an always-on buffer.
  • eco_delete_repeater does not allow deletion of a buffer or an inverter-pair that will cause:
    •  A redundant isolation cell.
    •  A CPF-constrained net to be deleted.

eco_refine_place

eco_refine_place {true|false}

Default: true

Data_type: Boolean

Legalizes placement whenever eco_add_repeater or eco_update_cell are used. If false, you must run place_detail after ECO if you want to legalize placement.

Note: Specifying eco_refine_place true can affect performance when large numbers of cells are added or modified.

Note: This global variable is used only in the Paradime ECO flow.

eco_update_timing

eco_update_timing {true|false}

Default: true

Data_type: Boolean

Controls whether to eco* commands recompute timing. If true, the eco* commands recompute timing. If false, the commands do not recompute timing, and us can later use report_timing to recompute timing.
