add_tieoffs

The root attributes in the add_tieoffs  category are:

  • add_tieoffs_cells
  • add_tieoffs_create_hports
  • add_tieoffs_honor_dont_touch
  • add_tieoffs_honor_dont_use
  • add_tieoffs_max_distance
  • add_tieoffs_max_fanout
  • add_tieoffs_module_prevention
  • add_tieoffs_prefix
  • add_tieoffs_report_hports

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the add_tieoffs category, use the following command:

get_db -category add_tieoffs 

add_tieoffs_cells

add_tieoffs_cells {{tieHi1 tieLo1} {tieHi2 tieLo2} ...}

Default: ""

Data_type: string

Specifies the pairs of tie cells to be used by the add_tieoffs command. You can specify a maximum of two tie-cells in a cell list, where one cell must be a tie-high driver, and the other a tie-low driver.

A single cell with both tie connections, high and low, can be specified as below.
add_tieoffs_cells {{TieHiLo1} {TieHiLo2} {TieHiLo3} ….}

The software selects the nearest cell pair to make new tie connections during the post_mask flow.

This is a root attribute.

  • To set the value of any root attribute, use the set_db command:
    set_db attribute_name value
  • To get the current value of any root attribute, use the get_db command:
    get_db attribute_name

add_tieoffs_max_distance

add_tieoffs_max_distance distanceValue

Default: 0.0

Data_type: double, read/write

Specifies the maximum Manhattan distance, in microns, between the tie-cell driver and the tie-pins. A value of 0 implies no distance constraint.

This is a root attribute.

add_tieoffs_max_fanout

add_tieoffs_max_fanout fanOutValue

Default: 0

Data_type: int, read/write

Specifies the number of tie-pins a tie-net can drive. A value of 0 implies no fanout constraint.

Example

The following set of commands set TIEHI and TIELO cells a maximum distance of 20 microns between the tie-cell pin and the tie-off input pins and a tie-net can drive up to 10 tie-pins: 
set_db add_tieoffs_max_fanout 10
set_db add_tieoffs_max_distance 20
set_db add_tieoffs_cells "TIEHI TIELO"

This is a root attribute.

    set_db attribute_name value

add_tieoffs_module_prevention

add_tieoffs_module_prevention {true | false}

Default: false

Data_type: bool, read/write

When this attribute is set to true, the add_tie_offs command adds tie-cells for module instantiation port. Tie-cells may also be added inside the module to tie the output port of the module so that module function can be prevented.

This is a root attribute.
