add_reinforce_pg

The root attributes in the add_reinforce_pg category are:

  • add_reinforce_pg_critical_path_slack
  • add_reinforce_pg_irdrop_hierarchical_block
  • add_reinforce_pg_irdrop_hierarchical_top_rail_analysis_directory
  • add_reinforce_pg_respect_defined_nets
  • add_reinforce_pg_respect_routes
  • add_reinforce_pg_respect_stdcell_geometry

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the add_reinforce_pg category, use the following command:

get_db -category add_reinforce_pg

add_reinforce_pg_critical_path_slack

add_reinforce_pg_critical_path_slack slack

Default: 0.0

Data_type: double, read/write

Specifies a slack threshold value (in nanoseconds) for critical nets during timing-driven PG stripe reinforcement. It means that add_reinforce_pg honors all the violation paths with slack value lesser than the specified add_reinforce_pg_critical_path_slack value, since all such associated nets are considered critical.

This is a root attribute.

  • To set the value of any root attribute, use the set_db command:
    set_db attribute_name value
  • To get the current value of any root attribute, use the get_db command:
    get_db attribute_name

add_reinforce_pg_irdrop_hierarchical_block

add_reinforce_pg_irdrop_hierarchical_block block

Default: ""

Data_type: string, read/write

Reports the IR drop violations on the specified list of hierarchical block(s) to fix IR drop. The names of the specified hierarchical blocks should be instantiations of the same master block, which is the loaded block. If you specify the * value of this parameter, all the instantiations of the loaded block are considered.

This is a root attribute.

  • To set the value of any root attribute, use the set_db command:
    set_db attribute_name value
  • To get the current value of any root attribute, use the get_db command:
    get_db attribute_name

add_reinforce_pg_irdrop_hierarchical_top_rail_analysis_directory

add_reinforce_pg_irdrop_hierarchical_top_rail_analysis_directory {directory_name}

Default: ""

Data_type: string, read/write

Reads the rail analysis information of full chip available in the specified directory for the hierarchical flow blocks. It collects the IR drop information of the specified block and uses it to fix the IR drop.

This is a root attribute.

  • To set the value of any root attribute, use the set_db command:
    set_db attribute_name value
  • To get the current value of any root attribute, use the get_db command:
    get_db attribute_name

add_reinforce_pg_respect_defined_nets

add_reinforce_pg_respect_defined_nets {file_name}

Default:

Data_type: string, read/write

When this attribute is used, add_reinforce_pg respects the user-defined nets listed in the specified file, which are critical in stripe generation. This helps in reserving space around the specified nets, and the newly added PG wires are DRC clean with these nets. This attribute is independent of the add_reinforce_pg_respect_routes attribute. However, when it is used together with the add_reinforce_pg_respect_routes attribute, add_reinforce_pg respects all of them.

This is a root attribute.

  • To set the value of any root attribute, use the set_db command:
    set_db attribute_name value
  • To get the current value of any root attribute, use the get_db command:
    get_db attribute_name

add_reinforce_pg_respect_routes

add_reinforce_pg_respect_routes {none | fixed | fixed_and_clock | all}

Default: fixed_and_clock

Data_type: enum {none fixed fixed_and_clock all}, read/write

Specifies the route types to honor check of pre-existing routes during stripe generation. This attribute always honor all covers and PGs, but does not honor the trail routes, Following are the attribute values:

  • none: Specifies that no route types are respected.
  • fixed: Respects fixed regular wires.
  • fixed_and_clock: Respects fixed and routed clocks.
  • all: Respects fixed and routed clocks along with the routed signals.

add_reinforce_pg_respect_stdcell_geometry

add_reinforce_pg_respect_stdcell_geometry {none sequential all}

Default: all

Data_type: enum {none sequential all}, read/write

Specifies the cell pin types to be respected in via generation. This attribute ignores the standard cell pins to control DRC violation checking on standard cell pins in via generation.

This is a root attribute.
