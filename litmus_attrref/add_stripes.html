add_stripes_allow_jog

add_stripes_allow_jog {none|{[padcore_ring ][block_ring ]}}

Default: padcore_ring block_ring

Data_type: enum* {none padcore_ring block_ring}, read/write

Specifies the type that stripe can jog to connect.

  • If set to padcore_ring and/or block_ring, the stripes are allowed to be on the same/different metal layer to connect to padcore_ring/block_ring.
  • If set to none, the stripe is not allowed to jog on any layer. A straight/direct connection (no jog) with switch layer is allowed to make the connection.

This is a root attribute.

    set_db attribute_name value

    get_db attribute_name

Specifies the coordinates of the rectangular and/or rectilinear design area(s) in which the stripes must be created. It appends the specified area to previous ones.

set_db add_stripes_area "“

  • When this attribute is used with add_stripes_domain_offset_from_core true, the add_stripes -start_offset value for specified area is measured from core on using add_stripes_area.

add_stripes_break_at

add_stripes_break_at {none|{[block_ring] [selected_block] [unassigned_bump][overlap_ringpin] [outer_ring][outside_ringmacro]}}

Default: none

Data_type: enum* {none block_ring selected_block unassigned_bump overlap_ringpin outer_ring outside_ringmacro blocks_without_same_net}, read/write

Specifies the break point of stripes.

If any of the options block_ring, selected_block, unassigned_bump, overlap_ringpin, outer_ring or outside_ringmacro is specified, the stripe breaks when it encounters the specified structure that are not in the same wire group.

block_ring 
Stripes break and connect to the block rings and ring pins if they are encountered.

Note: This attribute applies only to block rings that surround a block, and does not apply to block rings that surround rows or standard cells. If the block 
is a ring macro, the stripe will break at the ring pin inside the block ring.

selected_block 
Stripes stop at the block boundary when the block does not contain a blockage.

Stripes stop at the block boundary when the block contains a blockage and spacing from the block boundary to the edge of the blockage is greater than the minimum spacing value of that layer.

Stripes stop at the minimum spacing away from the blockage when the spacing from the block boundary to the edge of the blockage is less than the minimum spacing of that layer.

Note: If the selected block has block ring, stripes break and connect to the block ring.

unassigned_bumps 
Stripes break at unassigned bumps. It prevents the unassigned bumps from being ignored and shorted with the power and ground nets by the stripes created in the same metal layer.

overlap_ringpin 
Prevents stripes from overlapping with same direction ring pins of a different net.

Note: This option is only valid if the ring pin is more than half the length of the macro in the direction of the ring pin.

outer_ring 
When a stripe encounters nested block rings or ring pins that are not in the same wire group, the stripe breaks at the outer ring. If not specified, the stripe breaks at the innermost ring.

Note: This attribute works only in conjunction with the following attribute values of add_stripes_break_at:

  • block_ring
  • selected_block

outside_ringmacro
Stripes break at a small distance outside the block if the selected block has ring pins.

Note: This attribute is available only if you also specify add_stripes_break_at selected_block

blocks_without_same_net
Breaks stripes at blocks, where no pin has same net as the nets specified in the add_stripes command.

Example

Block A has power supply VDD1 and VSS, Block B has power supply VDD and VSS, commands are as follows:
set_db add_stripes_break_at blocks_without_same_net
add_stripes -nets {VDD VSS}…
In the above commands, VDD breaks at Block A, VSS goes through Block A, VDD and VSS will go through Block B. Refer to the screen below:

add_stripes_in_cell_allow_shift

add_stripes_in_cell_allow_shift {true | false} 

Default: false

Data_type: bool, read/write

Allows to shift the newly created pillars when meeting DRC, if there is already an existing special_wire on the given track. This attribute works only when the add_stripes_in_cell_only attribute is set to true.

When the add_stripes_in_cell_allow_shift attribute is set to false, the pillar is removed when meeting violation. When set to true, the newly created pillar is shifted to right among the three tracks when meeting violation. The next pillar's position depends on the final position of the current pillar.

The distance between these pillars should satisfy the user specified spacing. The spacing between the two pillars should not be smaller than the user-specified spacing.

add_stripes_mask_color_balance

add_stripes_mask_color_balance  {same_color | alternate_color | none}

Default: none

Data_type: enum {same_color alternate_color none}, read/write

Specifies addition of VDD/VSS stripes with balanced color.

same_color 
Corresponds to interlace with groups.

alternate_color 
Corresponds to interlace within the group.

To achieve color balancing, the color of stripes occupying even number tracks is picked alternatively.

Note: The stripes location will always be either on full grid/track or half grid/track:

  • If the stripes occupy odd number of tracks, they must be on full grid.
  • If the stripes occupy even number of tracks, they must be on half grid.

To achieve color balance, the stripes color will be as mentioned below:

  • If the stripes occupy odd number of tracks, the color is opposite to the center track color.
  • If the stripes occupy even number of tracks, the color can be any of red or green and will keep alternating.

Only two nets are supported.

The attribute must be specified along with add_stripes_width_file.

This is a root attribute.

  • To set the value of any root attribute, use the set_db command:
    set_db attribute_name value
  • To get the current value of any root attribute, use the get_db command:

add_stripes_max_via_size

add_stripes_max_via_size {shape width% height% target_penetration%}

Default: ""

Data_type: string, read/write

The maximum size of a crossover via, specified as a percentage of a full-size via. You must specify three values for each shape that you specify.

The shape values are:

  • Pad 
    via size between stripe and pad pin/ring
  • Ring 
    via size between stripe and core ring
  • Stripe 
    via size between stripes
  • Blockring 
    via size between stripe and block ring
  • Blockpin 
    via size between stripe and block pin, including ring pin
  • Cover 
    via size between stripe and the macro which has CLASS COVER defined in LEF
  • Selected 
    via size between stripe and selected objects
  • No shape 
    via size between stripe and wires with shape None
  • Standardcell 
    via size between stripe and standarcell pin

The three values you must specify for each shape are:

  • The maximum width for the crossover via, as a percentage of a full-size via
  • The maximum height for the crossover via, as a percentage of a full-size via
  • The target penetration, which specifies a smaller size for vias connecting to targets of the specified shape

This is a root attribute.
