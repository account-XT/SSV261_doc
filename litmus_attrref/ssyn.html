ssyn

The root attribute in the ssyn category is:

  • pbs_db_directory
  • pbs_mim_flow

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the ssyn category, use the following command:

get_db -category ssyn

pbs_db_directory

pbs_db_directory string

Description

Default: .

Data_type: string, read/write

Specifies the directory where partition-based synthesis can write temporary files.

pbs_mim_flow

pbs_mim_flow {true | false}

Description

Default: false

Data_type: bool, read/write

Enables the Multiple instantiated Modules (MiM) flow inside Partition-Based Synthesis (PBS). Instead of creating a set of unique instances for each module at the start of the flow (by an internal call to the 'uniquify' command), the PBS steps inside the flow, optimizes a single instance for each module, and copies the result to all other instances. So for any module with N instances, the tool optimizes that logic just once instead of N times. This results in a faster runtime for generic and mapped optimization flow steps. There are however a few prerequisites that these MiM have to fulfill. The timing, activity and design constraints must be the same across all instances for a module. If the tool detects differences like unique timing exceptions or dont_touch/dont_scan attributes that do not match, then it uniquifies such instances.
