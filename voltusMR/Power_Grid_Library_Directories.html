Power Grid Library Directories

A form such as the one shown below appears when the folder icon is selected from a menu. Selecting the folder icon on this form will toggle the Selection part of the form. To add items, select a file, and then select the Add button. To add multiple items from the selection list, select the first item, then move the cursor to the last item and hold down the shift key while selecting the last item. The Delete button can be used for deleting items. Similarly the shift key can be used for deleting multiple items.

 Choose Power & Rail - Set Rail Analysis Mode - Basic tab, and then click the PowerGrid Libraries button.
