Power Report

Provides the ability to provide reports of power information in various ways.

 Choose Power Rail - Textual Reports - Power Analysis.

Report Power Generates a power report for the specified options.
Format Species the format for the power report.


Report Power

Fields and Options

Output File

Specifies the name of the report file in which power analysis output information is written. You can include the directory name.

Note: If you do not specify this parameter, the software directs the power report to the command line, as well as the log file, and no power report is written to a separate file.

Clock Network

Reports the power consumption of the clock network, including the power for generated clocks.

Specify a list to report the power consumed by specific clocks.

Specify all to report all clock networks.

Default: all

Count Sequential Elements in clock Network

If selected, report will include the leaf flip-flop power in the clock network power report.

Default: The leaf flip-flop power will not be included in the clock network power report.

Instances

Specifies a list of instances to include in the power report. The power report provides the amount of power consumed by a specified list of hierarchical or leaf-level instances. This field accepts wildcards (*) for leaf-level instances only.

Hierarchy Level

Specifies the hierarchy level that is included in the power report. You can specify the Hierarchy_level as a number that corresponds to a specific hierarchy level in the design. A Hierarchy_level of 0 specifies the top level.

Default: all

Cell

Specifies the cells to include in the power report. Accepts wildcards (*)

Cell Type

Specifies the cell type to included in the power report. The choices are all or any combination of macro, io, combinational, or sequential.

Default: all

Power Domain

Specifies all power domains or a list of power domains to be included in report.

PG Net

Specifies all power nets or those of a particular hierarchy level to be included in power report.

Net

Reports the net switching power, as well as the load capacitance, toggle rate, and switching values for each net in the design.

Number of Nets Consuming Highest Power

Reports the number of nets with the highest net switching power.

Note: You must use this parameter in conjunction with the Net parameter.

MMMC View

Specifies the view that was created using the multi-mode multi-corner (MMMC) create_analysis_view command. Power analysis is performed for the specified view.

Default: Uses current view in Voltus.
