Power Density Map


Allows to resize the tile power density plot (tpd power plot). This form allows you to resize the tpd plot without having to restore the power database (power.db) again.

 Choose Power Rail - Tile Power Density.

Fields and Options

Tile Count X

Specifies the number of tiles in the x direction.

Tile Count Y

Specifies the number of tiles in the y direction.

Tile Size X

Specifies the horizontal dimension of each tile polygon in µm.

Tile Size Y

Specifies the vertical dimension of each tile polygon in µm.

Tile Count/Tille Size

You can either specify the tiles by count or specify the tiles by size. If you select Tile Count, specify the number of tiles in the Tile Count X and Y fields. Alternatively, if you select Tile Size, specify the tile size in the Tile Size X and Y fields,

Related Text Commands

See set_power_rail_display command in the Voltus Text Command Reference.
