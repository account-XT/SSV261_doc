Voltus IC Power Integrity Solution Menu Reference
Product Version 26.10, May 2026

ESD Summary

Loads the ESD analysis results in the GUI. The ESD directory is generated using the analyze_esd_network command, and is located in the state directory.

 Choose Power Rail - ESD Results.

Fields and Options

ESD Database

Specifies the path to the ESD directory created using the analyze_esd_network command.

Load button

Loads the specified ESD directory.  It displays the list of rules that were analyzed, and the rule type and rule status for each rule. You can select a rule to open the Rule Detail form.
Pattern You can specify a pattern and click the Rule/Type/Status button to filter the rule records according to the specified pattern. For example, if you specify FAIL in the Pattern field, and click Status, all the rules with the FAILED status will be displayed.

Related Text Commands

See analyze_esd_network commands in the Voltus Text Command Reference.
