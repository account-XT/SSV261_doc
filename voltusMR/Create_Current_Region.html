Create Current Region


 Choose Power Rail - Set Rail Analysis Mode - Advanced tab, and then click the Create button.

Fields and Options

Draw Current Region

Specifies the coordinates of the region, the layer, and the static current. The Add button can be selected to add the region to the Current Region List. The Delete button will delete a selected item on the list.

Power Domain lets you specify a power domain based current region. You can use the Power Domain field to select a power domain name and click Get Coordinates to automatically get the coordinates of the power domain. When the power domain is selected, the label name of the current region will be the power domain name and the boundary box coordinates will be the power domain boundary, and you cannot modify these fields.

Label specifies a name for the region. If not specified, the tool will provide a name (region1, region2...)

Net specifies the power/ground net name for domain-based analysis. This option allows you to specify current region values for a specific net.

x1, y1, x2, and y2 specifies a rectangular region that the current will be distributed within.

Rectilinear specifies the rectilinear current region that the current will be distributed within.

Note: In the static mode, ERA splits the rectilinear region into several rectangular regions and distributes current to the rectangular regions based on the area. In the dynamic mode, you can specify rectilinear regions interactively in the layout canvas by selecting the Draw button. You can select a rectlinear region by clicking each vertex of the rectlinear in sequence (clockwise or counter-clockwise), and then pressing the ESC key on the keyboard. This will quit the point selection mode, and the selected points appear in the Rectlinear field.

Current in rectangular region = Area of the rectangle / Area of the rectilinear

Layer specifies the metal layer that the current sink will be placed on.

If you select Draw, then select a box in main window, the coordinate of this box will be automatically populated in the x1 y1 x2 y2.

If you select View after selecting an item in the list, the selected region will be displayed in the main window.
Static Current  Specifies the current to be attached in the window.

Dynamic PWL (0ns 0mA...)

Specifies the dynamic PWL for regions without any placed instance, in time (in ns) and current (in mA) format. For example, 0ns 0mA 0.5ns 1mA 1ns 2mA 3ns 1mA 4ns 0. This option is displayed only if you select the analysis method Dynamic.

Loading Cap (pf)

Specifies loading capacitance in pf (picoFarads) waveform for the current region(s). This option is displayed only if you select the analysis method Dynamic.

Estimate

Estimates Gate Capacitance (C1) and Loading Capacitance (C2) values for the specified current regions. These estimated values of C1 and C2 are used along with the PWL current waveform for the regions to perform dynamic rail analysis. This option is displayed only if you select the analysis method Dynamic.

Gate Cap (pf)

Specifies gate capacitance in pf (picoFarads) waveform for the current region(s). This option is displayed only if you select the analysis method Dynamic.

Current Region List

Displays the current region list. This is created by specifying the Draw Current Regions information and selecting Add. Selecting an item on the list and then Delete will delete the selected item.

Related Text Commands

See set_rail_analysis_mode command in the Voltus Text Command Reference.
