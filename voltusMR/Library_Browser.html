Voltus IC Power Integrity Solution Menu Reference
Product Version 26.10, May 2026

Library Browser

Use Library Browser to browse available library, cell, views, when restoring an OpenAccess design.

 Choose File - Read Design, and click the Browser button.

 Fields and Options

Library

Lists the available libraries.

Cell

Lists the available cells for the selected library.

View

Lists the available views for the selected cell.
