Voltus IC Power Integrity Solution Menu Reference
Product Version 26.10, May 2026

Run Resistance Analysis


Choose Power Rail - Run Resistance Analysis.

Basic Performs effective resistance calculation for all instances in a design. Effective resistance computes effective resistance between two nodes on the power-grid, or from a node to all the voltage sources in the design, or from an instance to all the voltage sources in the design.

Basic

Fields and Options

Analysis Method

Specifies the resistance analysis method as Effr.
Net Based Set if net-based analysis is being run. It is equivalent to the set_pg_nets command.
Domain Based Set if domain-based analysis is being run. It is equivalent to the set_rail_analysis_domain command.
Domain Name Specifies the domain name that is to be analyzed. Only used for domain based analysis.
Power Net(s) Specifies names of the power nets for which resistance analysis will be performed.
Voltage(s) The voltage of the power net.
Threshold The voltage threshold of the power net
Ground Net(s) Specifies names of the ground nets for which resistance analysis will be performed.
Voltage(s) The voltage of the ground net.
Threshold The voltage threshold of the ground net
Power Pads
  • Def Pins - specifies that voltage sources will be determined by power pins.
  • Pad File - specifies that voltage sources will be determined by pad cells given in the file.
  • XY File - specifies that voltage sources will be specified by x y coordinates.
  • Boundary File - specifies that voltage source locations will be specified by information in the boundary file.

Default: Def Pins
File Name The name of the power file containing the locations of the power rail voltage sources (VDD, VSS). You can automatically generate this file by clicking the Create button. The Edit Pad Location form appears.
Net Name The name of the power net. The Add button adds the net to the list. The Remove button removes the net from the list.
Output Directory Specifies the name of the directory in which the output report file is saved.
Output Report Name Specifies the name of the output report file that contains the report header and the sorted list for resistance values.
Effr To Power Pads

Specifies to check effective resistance of a node to the voltage sources or power pads. This option is enabled only when Power Pads is selected. When this option is selected, Node2 and Instance2 options are disabled.
Point-To-Point Effr Specifies to check effective resistance between two nodes on the power-grid. When this option is selected, Node2 and Instance2 options are enabled.
Node1

Specifies the list of user-defined nodes for effective resistance calculation between the specified user-defined node and all voltage sources, or between two nodes on the power-grid. This option is enabled for both Effr To Power Pads and Point-To-Point Effr. You can add a list of nodes based on the region on a given layer.

  • x1 and y1 are the coordinates of the node.
  • Layer1 is the generic metal routing layer name on which the node is located.
  • Label is any name chosen by you to identify node entries in the list. This is optional but helps during debugging.
  • Get
Node2

Specifies the second node for effective resistance calculation between two nodes on the power-grid. This option is enabled only for Point-To-Point Effr.

  • x2 and y2 are the coordinates of the second node.
  • Layer2 is the generic metal routing layer name on which the second node is located.
  • Get
Region

Analyzes resistance in the specified region. You can draw a box on a specific layer, and specify the number of nodes to be selected (maximum limit of 100 nodes). This field allows you to compute effective resistance on a given layer across the chip and determine how the resistance is changing for the design from top to bottom layer. You can assign a name for the region.

  • x1,  y1, x2, and y2 are the coordinates of the box.
  • Nodes are the number of nodes to be selected
  • Layer is the generic metal routing layer name on which the nodes are located.
  • Get Region 
Node File Specifies the name of the node list file. This file contains the list of user-defined nodes in the same format as mentioned for the -node_list parameter of the analyze_resistance command. The file allows you to specify a large number of nodes.  
Node-Pair File Specifies the name of the node pair list file. This file contains the node pair list in the same format as mentioned for the -node_pair_list parameter of the analyze_resistance command. The file allows you to specify a large number of node pairs.  
Instance1 Specifies the list of instances for which effective resistance is to be calculated. This option is enabled for both Effr To Power Pads and Point-To-Point Effr.
Pin1 Optionally, you can specify instance pin name. By default, the tool will use the instance pin associated with the net being analyzed. Pin name can be used in special cases when two different pins of an instance are connected to the same net.
Instance2

Specifies the second instance to enable effective resistance calculation between two instances in the design. This option is enabled only for Point-To-Point Effr.
Pin2 Specifies the pin name for the second instance.
Instance File Specifies the name of the instance list file. This file contains the list of instances in the same format as mentioned for the -instance_list parameter of the analyze_resistance command. The file allows you to specify a large number of instances.
Instance-Pair File Specifies the name of the instance pair list file. This file contains the instance pair list in the same format as mentioned for the -instance_pair_list parameter of the analyze_resistance command. The file allows you to specify a large number of instance pairs.
Effr Threshold (Ohms) Specifies the minimum allowed effective resistance to display node/node-pair/instance/instance-pair that have a resistance value above this threshold value.
Force Re-extraction Specifies to force a re-extract of resistances.
Append When you select Append and click the Load button, the content of the effective resistance analysis result file is appended to the previous list in the node/instance list box. If Append is not selected, the previous list is cleared.
Add Adds the specified node/node-pair/instance/instance-pair to the list box.
Remove Removes the selected node/node-pair/instance/instance-pair to the list box.
Auto Zoom Specifies to automatically zoom in to the selected node/instance in the list box.
AutoFilter Specifies to show the nodes or instances with eight color filter. When you specify Effr Threshold (Ohms) and click AutoFilter, the layout displays the nodes or instances with eight color filter. When you change the threshold value, you will get different plots on the layout.
