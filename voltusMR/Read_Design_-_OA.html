Read Design - OA

The OA page within the Restore Design form is used to restore all design information from the previous design session, using the OpenAccess database format.

 Choose File - Read Design. The OA page opens by default.


Fields and Options

Library

Specifies the location of the OpenAccess database to be restored. It contains the cell and the view to be restored. The OpenAccess library name should be specified in the cds.lib file.

The Setup tab contains the Verilog and OA radio buttons that changes the form from the current LEF based style (default) to the OpenAccess-based style.

Cell

Specifies the design cell from the library that is to be restored.

View

Specifies the view name of the cell that is to be restored.

Default: The layout view.
Library File Path Specifies the full path to the library definitions file (cds.lib).
Read Physical Data Reads physical data.
Browser button Opens the Library Browser form, which enables you to browse available libraries, cells, views.
