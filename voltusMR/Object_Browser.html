Object Browser

You can use the object browser (DB Browser) to retrieve the selected object's attributes. The DB Browser displays different attributes, depending on the objects selected in the main window.

 To launch the DB browser:

  1. Select one or more objects in the main window.
  2. Select Tools - DB Browser.

Fields and Options

Object Type

Specifies the type of object currently selected.

Click the Show next object in list button to display the attributes of the next object in the sequence. or Prev to view the previous object.

Note: This button is available only when multiple objects are selected in the main window.

Click the Show last object in list button to display the attributes of the previous object in the sequence.

Note: These buttons are available only when multiple objects are selected in the main window.

Click the Back to previous object button to return to the first object in the list. For example, if you select two instances i1 and i2. Use the Show next object in list button to move from i1 to i2 as the active instance, then descend to the i2's cell. Now if you select Back to previous object button, you return to i1.

Close

Closes the DB Browser.
