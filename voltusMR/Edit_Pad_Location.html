Voltus IC Power Integrity Solution Menu Reference
Product Version 26.10, May 2026

Edit Pad Location

Use the Edit Pad Location form to create or edit power pad location files (one for each power net) to mark points on the power structures as voltage source reference points. Power pad location files identify the voltage source reference points, such as VCC, VDD, and VSS. You can use these files during all stages of power analysis.

Note: Pad location displays are updated immediately after clicking Auto Fetch, Delete, or Add. The IR drops leading from the pad locations are displayed after running power analysis.
To open the Edit Pad Location form, click the Create button in the Run Rail Analysis form

Fields and Options

Net Name

The power net or ground net name of the pad cells. This field is required only when the file format is Padcell.

Note: You can only edit the pad location file for one net at a time.

Fetch Pad Location
Auto Fetch Specifies to fetch all voltage sources. If you select this option, you must specify the net name.
Snap Distance Specifies the distance of snapping distance constraint from IO/pad pins. The default value is 0. When selected , the software performs autofetch with snapping.
Lowest Snap Layer Specifies the lowest layer used to fetch a DC source. Use a value such as M1 or M2. The default value is M5. 
Region
   Specifies a rectangular region that the current will be distributed within. A grid is created by using the xPitch and yPitch within the specified region. The current will be specified at each of the intersecting pitch lines. Layerspecifies the metal layer that the current sink will be placed on.

If you click Draw, and then select a box in the main window, the coordinate of this box will be automatically populated in the x1 y1 x2 y2.

For region-based auto fetch, if the voltage source points that were fetched according to the start point and the specified region pitch (xPitch/yPitch) are not on the stripe, these points will be ignored during analysis. You can use the Snap Distance option to snap the voltage sources to a stripe within +/- snap distance/2. If no such stripe is found, this point will not be saved into the pad location file. As a result, the voltage sources are generated only on the stripes and these points will be saved to the pad location file.

Specify

Specifies an instance/cell and their pins to autofetch DC sources.

Instance Name

Specifies the instances from which voltage sources are determined.

Instance Name and Pin

Specifies the instances and their pins from which voltage sources are determined.

Cell Name

Specifies the cells from which voltage sources are determined.

Cell Name and Pin

Specifies the cells and their pins from which voltage sources are determined.
Honor Pin Wire Connection Honors pin wire connection when fetching voltage source location from a power pad. When you select this option, only pins with wire connection are output as voltage sources.

Fetch

Automatically populates the Pad Location List with the pad locations based on properties defined in the LEF file.

There are three ways to get the dc sources:

  • fetch all voltage sources - specifying Net Name and Auto Fetch
  • fetch the voltage sources within the specified region of the specified layer controlled by the specified xPitch/yPitch
  • fetch voltage source for the specified cell/cell pin/instance/instance pin

Note: You may need to reissue the globalNetConnect command for Auto Fetch to function properly if the power pads were not defined in the database at the time that the globalNetConnect command was first issued.

Pad Location List

The list of coordinates for pad cells. To populate this field manually, click the Add button. To populate this field automatically, click the Auto Fetch button.
Pad Location

The X and Y coordinates of a pad cell.
Layer The layer that contains the pad cell.
Get coord

Populates the X and Y coordinates in the Pad Location field. Click this button, then click a location in the design display area.
Delete Removes one or more pad location items from the Pad Location List. Highlight the item be removed, then click this button. To highlight multiple items, click them while pressing either the Shift or Control key.
Add Adds the X and Y coordinates of a pad cell to the Pad Location List.

Save File Format

The format of the saved Pad Location File. The choices are XY file (xy coordinates) , Padcell file (VoltageStorm), and TSV. You can create and save the voltage sources location file with a unique name for the voltage sources (both VDD and VSS).

Load

Opens the Load Pad Location File form. Select a file from this list, then click Open to display the pad locations in the Pad Location List.

Save

Opens the Save Pad Location File form. Specify a location for the pad location file, then click OK. This saves the pad location file, clears the Pad Location List, and closes the Save Pad Location form.

Clear

Clears the Pad Location List. Once the Pad Location List is cleared, you can begin creating a pad location file for a new net.

Note: Cadence recommends that you use the Clear button after you save the pad location file before you use Auto Fetch again.
