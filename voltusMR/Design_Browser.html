Design Browser

Use the Design Browser to navigate through the chip's design hierarchy. You can use the Design Browser to view the design hierarchy tree at any time after the design is imported. The Design Browser also makes it easier to highlight specific modules, instances, or nets in the design display area.

You can use the widgets in the Design Browser to open forms to navigate through displays, and perform actions. From the Design Browser, you can access the:

  • Connectivity Browser to display the number of nets between instances
  • Attribute Editor to display an object's type, name, and attributes
  • Schematic Viewer to display hierarchical and instance-based schematics



Choose Tools - Design Browser.

Note: If you select an object in the main window before opening Design Browser, the browser is automatically populated with the details of that object. If multiple objects are selected in the main window, Design Browser automatically displays details of all selected objects.


Design Browser Tool Widgets

You can use the widgets in the Design Browser to navigate through displays, open tools, make selections, and perform actions. The widgets are categorized into groups. You can right-click any empty space on the toolbars and choose which group of widgets to display.

File Widgets
Load - Displays the Load Design Browser File form, where you can enter the filename and the format of the placement file.
Save As - Displays the Save Design Browser File form, where you can specify the filename. The recommended extension is .dbf.
View Widgets

Previous Page - Displays viewable data in a reverse direction.

Next Page - Displays viewable data in a forward direction.

Top Page - Returns to the top of the design.

Refresh - Refreshes the Design Browser display.

Get Selected - Gets the selected object and displays it in the Design Browser.
Delete Group/Group Member - Deletes an individual instance from a user-defined group or an entire user-defined group.
Sort By Size - Displays instances in the order of the number of cells in the instances. This toggle button is selected by default. Deselect this button to display instances sorted alphabetically by name.
Accumulate Results - Traces the hierarchical path for the selected object in the design display area.
Select Widgets

Zoom Selected - Zooms in on the object (that you have selected in the Design Browser) in the design display area.

Select - Selects an object in the design display area.

Deselect - Deselects an object in the design display area.

Deselect All - Deselects all objects in the design display area.
Highlight Widgets
Edit Highlight Color - Allows you to select a highlight color from the available choices in the drop-down menu.

Highlight - Highlights an object in the design display area.

Dehighlight - Dehighlights an object in the design display area.
Dehighlight Selected - Dehighlights the selected object.

Dehighlight All - Dehighlights all objects in the design display area.
Tool Widgets

Connectivity Browser - Opens the Connectivity Browser. For more information, see Connectivity Browser.

Attribute Viewer - Opens the Attribute Viewer for the selected object. For more information, see Attribute Viewer.

Show Cone Schematic (New) - Opens the Schematic Viewer to display schematic in flattened mode.

Show Module Schematic (New) - Opens the Schematic Viewer to display schematic in hierarchical mode. For more information, see Schematic Viewer.
Find Bar

Enables you to search and display hierarchy information for the object you specify in the adjacent text input box. You can use wildcards to specify object names in the text input box. When you enter text in the text input box, the Clear button () is displayed next to the text input box. Use this button to clear any existing text in the input box.

You can view information on the following object types:

  • Instance: Enables you to search for an instance and display its hierarchy in the Design Browser window. You can traverse to the next hierarchy by double-clicking on the instance name. Along with the instance name, the instance's cell type and number of cells are displayed.
     
  • Net: Enables you to search for a net and display its hierarchy in the Design Browser window. Double-clicking the net name displays the net connection.
     
  • Group: Enables you to search for an existing instance group and display its hierarchy in the Design Browser window.
     
  • Cell: Enables you to search for a cell and display its hierarchy in the Design Browser window.
State Bar

Displays the name of selected object on the bar at the bottom of the browser.
