Save Design - OA

Use the OA page in the Save Design form to save all information from the current design session, using the OA database format.
Choose File - Save Design. The OA page opens by default.

Fields and Options

Library

Specifies the target OpenAccess library name.

Cell

Specifies the top cell that is to be saved.

Note: This field is read-only.

View

Specifies the view to save.
