Rule Detail

Displays a summary of the rule selected in the ESD Summary form.

 To open the Rule Detail Form, select a rule in the ESD Summary form.

This form has two parts:

  • The top section displays the rule details as specified in the ESD rule file.
  • The bottom section gives the rule status summary. It contains the rule details from the summary report.

For information on the ESD rule file and the summary report columns, refer to the "ESD Analysis" chapter in the Voltus User Guide.

See analyze_esd_network commands in the Voltus Text Command Reference.
