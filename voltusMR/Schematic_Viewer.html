Schematic Viewer

Use the Schematic Viewer with Design Browser to explore a design's connectivity, relationship between modules and instances, and design changes, such as CTS and ECO. You can cross-probe from the Schematic Viewer to the main display to get immediate feedback for debugging and diagnosing your design.

The Schematic Viewer has two main views:

  • Hierarchical view - To open Schematic Viewer in Hierarchical view:
    • Select a module, instance, net, or pin in Design Browser and click the Show Hierarchical Schematic widget.
    • Select an MSV violation in Violation Browser and click the Show MSV Violation Schematic widget.

  • Flattened view - To open Schematic Viewer in Flattened view, select an instance, net, or pin in Design Browser and click the Show Instance Based Schematic widget.

Toolbar

The Schematic Viewer toolbar provides a quick way to access the most commonly used commands. This section describes the toolbar items, which are available for flattened and module schematics, except where noted.

Description

Schematic Display Area

The schematic display area constitutes the major portion of the Schematic Viewer window. The schematics of the selected object is displayed here in flattened or hierarchical view. To change the default display properties for objects in the display area, use the Color tab on the Preferences form. 

World View Window

The world view window identifies the location of the current view in the schematic display area, relative to the entire area. The world view is identified by the pink crossbox. When you display an entire schematic in the area, the crossbox encompasses the world view window. When you zoom and pan through the schematic in the display area, the crossbox identifies where you are relative to the entire schematic.

  • To define a new world view, left-click and drag the mouse to create a new crossbox in the world view window.
  • To pan left, right, up, or down in the schematic display, right-click and drag the crossbox in the world view window.

Status Bar

The  Status Bar  is located at the bottom of the Schematic Viewer. When you select or hover over an object, this bar displays the object type, name, and ID number. 

Context Menu

To access the context menu, right-click an object in the Schematic Viewer window. The options available in context menu varies depending on the:

  • Current view of Schematic Viewer - Hierarchical or Flattened
  • Object you have selected in the schematic display area

Preferences

The Preferences form enables you to customize the display, colors, and fonts in the schematic display area. It has the following tabs:

  • Display
  • Color
  • Font


Display Tab

Use the Display tab to customize the display in the schematic display area.


Fields and Options

Port Name

Default: Selected

Pin Name

Displays I/O pin names in the schematic display area.

Default: Unchecked

Instance Name

Displays instance names in the schematic display area.

Default: Unchecked

Net Name

Displays net names in the schematic display area.

Default: Unchecked

Primitive Instance Type Name

Displays primitive instance type names.

Default: Selected
Module

Displays module names in the schematic display area.

Default : Selected
Net's Bit Index

Displays bit index for nets in the schematic display area.

Default : Unchecked

Highlight Cursor Object

Highlights objects as you move the cursor over them.

Default: Selected

Displays an information box that states the name of the object over which the cursor is currently placed and lists pertinent details about that object.

Color Tab

Use the Color tab to change color and line settings for objects in the schematic display area.


Fields and Options

Object Display Style

Specifies the object type for which you want to change color and line settings. Select any object type from this list and choose appropriate color and line settings, as required.

Line Width

Specifies the line width of the object type selected in Object Display Style list box.

Line Style

Specifies the line style of the object type selected in Object Display Style list box.

Color

Specifies the color of the object selected in Object Display Style list box. Click on the color box to open the Select Color form and choose a new color for the selected object type.

Default Style

Resets the selected object type to the default style.

Dark Background | Light Background | Dim Background


Specifies the background scheme for the Schematic Display Area. The default is Dark Background.
Set Default Sets the current selection as the default preference.

Font Tab

Use the Font tab to change the font size and style settings for the schematic display.

Fields and Options

Font

Specifies the font for the text displayed in the schematic display area.

Font Size

Specifies the size of the schematic display font.

Font Style

Specifies the style to be applied to the schematic display font.
Set Default Sets the current selection as the default preference.


Select Color

Use the Select Color form to change the color of an object in the schematic viewer. Select the required color from the color palette and click OK.

Note:  To apply the next available color on the palette, you do not have to re-select the object. Instead, choose  View  -  Next Color. You can do this repeatedly.

Print Schematic

Use the Print Schematic form to print the schematic in the display area.

  • Choose  File  -  Print.

Fields and Options

Design Name

Specifies the name of the design. This information appears in the bottom left corner of the printout.

Designer

Specifies the designer name. This information appears in the bottom left corner of the printout.

Description

Specifies a description. This information appears in the bottom left corner of the printout.

Orientation

Specifies the page orientation. Choose Portrait or Landscape.

Page Size

Specifies the page size. Choose a standard page size of 8.5X11 or use the pull-down menu to specify a custom size.

Job Size

Specifies the job size. Choose to print all the pages or only the current page.

Scaling

Specifies the scaling. Choose Full Page or Current View.

Print To

Specifies the print output destination. Choose one of the following:

  • Printer - If you choose this option, type the appropriate print command in the Print Command text box.
  • File - If you choose this option, the File text box at the bottom is enabled. Type a filename in the File text box or use the adjacent folder button to select the appropriate file.
  • GIF (Current View to File) - Choose this option to print the current view to the specified file.


Find Schematic Object

Use the Find Schematic Object form to find and highlight a specified object in the schematic display area.

  • Click the Find widget on the toolbar.

Fields and Options

Window

Identifies which schematic window was active when you selected this option.

Object Type

Specifies the object type you want to find.

Find

Specifies the object name or a portion of the name with wildcard characters. Type the object name in the adjacent text box and click Find. The search results are displayed in the list box below this field. Double-click a name to highlight the object in the schematic display area.

Case Sensitive

Allows you to make the search case sensitive.
