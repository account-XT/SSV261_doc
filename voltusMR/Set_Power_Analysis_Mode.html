Product Version 26.10, May 2026

Set Power Analysis Mode


Choose Power Rail - Set Power Analysis Mode.

Basic Specifies whether static or dynamic power analysis should be run and some additional settings.
Advanced Specifies the advanced power analysis setup options.


Basic

Fields and Options

Analysis Method

Specifies either static or dynamic power analysis

Dynamic Power Method

If dynamic power analysis is set this specifies if the method of analysis is vectorless or vector based.

Disable Static Analysis

When selected in the dynamic vector-based or dynamic vectorless flows, the command performs only dynamic analysis and turns-off static power calculation.

Default: Not selected for Static analysis method, selected for Dynamic analysis method

Analysis View

Specifies the Analysis view.

Corner

Specifies the corner via a pulldown list. The choices are min, or max.

Default: max

Switch off Power Nets

Specifies if power nets should be switched off

Create Power Binary Database

Specifies that a binary power database should be created. This can be used for viewing the power data graphically.

Write Current Files

Specifies that Voltus is to generate the current data files, one current data file per net.

Default: true.

PowerGrid Libraries

Specifies the name of the Cadence power cell libraries (.cl)


Advanced

Fields and Options

Use Negative Internal Power in Timing Library

Specifies that Voltus will keep negative internal energy numbers from the .lib internal power table. When not set, negative power is treated as 0.

Default: true

Ignore Control Signals

If set specifies that control signals will be ignored when propagating activity.

Default: true

X Transition Factor

When using VCD one can specify how transitions to and from X are counted. These transitions are defined as shown in the Transitions from/to X and Z Values table. Transitions to and from the X state will be treated as full transitions multiplied by the specified factor.

Default: 0.5

Z Transition Factor

When using VCD one can specify how transitions to and from Z are counted. These transitions are defined as shown in the Transitions from/to X and Z Values table. Transitions to and from the Z state will be treated as full transitions multiplied by the specified factor.

Default: 0.25
