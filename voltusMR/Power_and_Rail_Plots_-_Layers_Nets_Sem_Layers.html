Power and Rail Plots - Layers/Nets/Sem Layers


Choose Power Rail - Power Rail Plots, and then click the Layers/Nets button.

Layers Provides the ability to set the visibility of the layers and the opacity of the rail analysis or design database. This makes it easier to view when overlaying the rail analysis and the design database.
Nets Controls the visibility of power/ground nets.
Sem Layers Controls the visibility of the signal EM layers.
Esd EM Provides the ability to selectively load the required ESD EM result directories if there are multiple result directories under the ESD directory.

Layers

Fields and Options

Rail Analysis Opacity

Sets the opacity of the rail analysis output. These will be the resistor/node database load from rail analysis.

Design DB  Opacity

Sets the opacity of the design database. These will be the shapes coming from DEF (main control panel).
Via Size Specifies to modify the size of vias in the GUI. The default via size is 1. The possible via size values are 1, 2, 3, 4, 5, and 6.
Node Size Specifies to modify the node size in the GUI. The default node size is 1. The possible node size values are 1, 2, 3, 4, 5, and 6.
Vsrc Size Specifies to modify the size of voltage source (Vsrc) in the GUI. The default Vsrc size is 1. The possible Vsrc size values are 1, 2, 3, 4, 5, and 6.
Resistor Size Specifies to modify the size of resistors in the GUI. The default resistor size is 1. The possible resistor size values are 1, 2, 3, 4, 5, and 6. 
IV Window

Controls the window where effective instance voltage (EIV) is evaluated. EIV is obtained by processing the voltage waveforms and finding the worse-case effective voltage between the power and ground pins during a specific window.

There are two possible options to evaluate EIV:

  • timing/switching – both switching activity (current is non-leakage) and timing window
  • whole – entire rail simulation not filtered to a specific window
IV Method Type

Allows different methods of computing effective instance voltage during rail analysis. Using this option, you can write out the Best, Worst, or Average effective instance voltage between power and ground nets.

The WorstAvg method computes the average instance voltage during each evaluation window defined by the IV Window field, and reports the worst average instance voltage out of all the windows. If IV Method is WorstAvg and IV Window is whole, then this method will report average voltage across all time steps in simulation.

Default : Worst
Thermal Layers Displays the specified layer of the temperature map.
Enable Empty Layer Specifies to enable or disable the empty layers.
Layer Name
 You can enable or disable the reporting and visibility of the displayed layers.
Report Specifies to select the user-defined layers to be used for processing.
Visible Specifies which layers should be made visible when plotting.

Nets


Fields and Options
Filter Type a value in the Filter text field to locate a net in the list that matches the name you typed.  
Clear Click the Clear button to clear the filtered list.

Power Nets

Displays the list of power nets.

  • Click the Net Name column header to sort nets by names. You can switch between the ascending and descending order by clicking the column header. The directional arrow on the column points down to indicate that the net names are sorted in descending order, and points up to indicate that the net names are sorted in ascending order.
  • Select the visible checkbox next to the power nets to be viewed.

Ground Nets

Displays the list of ground nets.

  • Click the Net Name column header to sort nets by names. You can switch between the ascending and descending order by clicking the column header. The directional arrow on the column points down to indicate that the net names are sorted in descending order, and points up to indicate that the net names are sorted in ascending order.
  • Select the visible checkbox next to the ground nets to be viewed.

Sem Layers

Fields and Options

Layers

You can enable or disable the visibility of the displayed signal EM layers.
Visible

Specifies which layers should be made visible when plotting.

EsdEM 

Field and Options

Rule Name

Displays the list of EM rule name.
Domain Name Displays the list of domain name associated with the EM rule.
Net Name

Displays the list of nets associated with the EM rule.

Note: You cannot select the same net from different rule or domain.
Report

Specifies which ESD EM result directory should be loaded.

Related Text Commands
