Voltus IC Power Integrity Solution Menu Reference
Product Version 26.10, May 2026

Short

Loads the short violations report (voltus_short.report) in the GUI. This file is generated using the set_rail_analysis_mode -report_shorts true command parameter, and is located in the work directory.

 Choose Power Rail - Short.  

Fields and Options

Short File

Specifies the path to the short violations report.

Browse button

 Opens the Short File browser form, which enables you to browse to the short violations report.

Load button

Loads the report file and displays the list of short violations on the power/ground nets.

Layer Filter

Allows you to filter the records based on the selected layer.

Net Filter

Allows you to filter the records based on the selected net.
Filter button
 Displays the list of short violations based on the selected options from the Layer Filter and Net Filter drop-down lists.
Layer The layer on which the short is detected.
X

The x coordinate where the short is detected.
Y

The y coordinate where the short is detected.
Net The short violations report lists shorts between two geometries belonging to different nets. This field specifies the name of the first power or ground net.
Net The short violations report lists shorts between two geometries belonging to different nets. This field specifies the name of the second power or ground net.

Related Text Commands

See set_rail_analysis_mode and read_power_rail_results commands in the Voltus Text Command Reference.
