Setup Tab Components

Click the Setup tab.

Fields and Options

Display mandatory fields only

  

Displays mandatory fields in the form.

Display both mandatory and optional fields

  

Displays both mandatory and optional fields. The optional fields include Low Power, Physical, Multi-Mode Multi-Corner and Statistical Static Timing Analysis.

Read physical data

Reads physical information such as placement, floorplan and routing that you created using Innovus.

Design Setup Data

Loads a saved Innovus database. The database consists of configuration file, and all files listed in the configuration file such as verilog, libraries, SDC. The database also consists of the mode file.

Common Timing Libraries

  

Specifies the name of the libraries common to both the Best Timing Libraries and the Worst Timing Libraries, which are used in both setup and hold analysis.

Worst Timing Libraries

Specifies the name of the timing libraries containing worst-case conditions for setup-time analysis.

Best Timing Libraries

Specifies the name of the timing libraries containing best-case conditions for hold-time analysis.

Worst Noise Libraries

Specifies the noise library (cdB) files used in setup analysis mode. In setup analysis mode, the common cdB files and the max cdB files are used in SI analysis.

Best Noise Libraries

Specifies the noise library (cdB) files used in hold analysis mode. In hold analysis mode, the common cdB files and the min cdB files are used in SI analysis.

Common Noise Libraries

  

Specifies the name of the common noise library (cdB) files used in SI analysis.

Stamp Model Definitions

  

Specifies the Stamp model definition files.

Stamp model files contain timing information for a module, such as an instantiated module, block, or partitioned module. You do not need to translate these files before reading them into the software. However, currently you can only read in constant value models.

Stamp timing specifications supersede timing information read from the timing library.

Data Type - Verilog


Verilog Netlist Files

Specifies the gate-level Verilog netlist files to import.

If specifying multiple names in the text field, use spaces to separate the names. You can use wildcards (*.extension) or directory names to specify multiple files. You can specify compressed files (.gz extension).

Top Level Design Name

  

Specifies the top module name, and checks for consistency between verilog netlist and timing libraries. Voltus uses the top module for timing analysis.

Timing Constraint File

Specifies the Synopsys Design Constraint (SDC) constraint file to import. You can import one or more constraint files.

Data Type - OA


Library

Specifies the location of the Open Access database to import. It contains the cell and the view to be loaded.

Cell

Specifies the design cell from the library that is to be loaded.

View

Specifies the view name of the cell that is to be loaded.

SPEF Files

Specifies the name of the SPEF files.

SDF Delay

Specifies the name of the file containing the SDF delays you want to load.

SOCE MSMV File

Specifies the name of the MSMV file. This file uses a format that is similar to the IR-drop file and can be created in Innovus.

Power Net(s)

Specifies the names of the Power Nets. You can enter multiple names by separating the net names with a space, for example:

VDD VDD1

Ground Net(s)

Specifies the names of the Ground Nets. You can enter multiple names by separating the net names with a space, for example:

GND GND1

LEF Files

Specifies the LEF files to import. The LEF file provides the physical data information.

You must specify the technology LEF file first, then specify the standard cell LEF and block LEF in any order.

Floorplan File

Specifies the name of the floorplan file to load for the design session.

Placement File

Specifies the name of the placement file to load for the design session.

Routing File

Specifies the name of the routing file to load for the design session.

DEF Options

Choose from one of the following options:

Load All: Loads all DEF files.

Special Net & Components: Reads the SPECIALNETS and COMPONENTS section of the DEF file.

Specify Only: Loads only the specified files.

DEF Files

Specifies the name of a Design Exchange Format (DEF) file. You can supply hierarchical DEFs to generate a flattened physical database.

View Definition File

Specifies a Tcl command script that contains the analysis view configurations for multi-mode multi-corner timing analysis and optimization. The file contains a list of Tcl commands that create library sets, constraint modes, RC corners, delay corners, and analysis views.

Processing the file does not automatically place the software in multi-mode multi-corner analysis mode. If the file also contains a set_analysis_view command, then the software is placed in multi-mode multi-corner analysis mode after the file is processed.

MMMC Browser

Opens the Multi-Mode Multi-Corner Browser (MMMC Browser). The browser displays the multi-mode multi-corner configuration, and allows you to create and edit the various objects and analysis views necessary for multi-mode multi-corner analysis.

SPDF File

Specifies the name of a statistical parameter distribution format (SPDF) file. An SPDF file contains statistics of variation of process parameters and is used for statistical static timing analysis (SSTA). You can specify global, random and spatial variations in this file. You can create this file using the data provided by the foundry.

Statistical SPEF File

Specifies the name of the statistical SPEF (S-SPEF) file. The software requires an S-SPEF file to perform sensitivity-based extraction. Sensitivity-based extraction captures variations in interconnects. In sensitivity based extraction, in addition to nominal values of resistances and capacitances, the software also extracts the sensitivities of R and C to different interconnect process parameters. The S-SPEF file is used for statistical static timing analysis (SSTA).

Related Text Commands

The following text commands provide equivalent or additional functionality:

  • read_design
  • read_def
  • read_lib
  • read_power_domain
  • read_sdc
  • read_verilog
  • set_top_module

For more information, see the "Setup Commands" in Voltus Text Command Reference.
