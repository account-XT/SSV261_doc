Voltus IC Power Integrity Solution Menu Reference
Product Version 26.10, May 2026

Dynamic Results

 Choose Power Rail - Dynamic Results.

Movies Provides the ability to view dynamic movies..
Waveforms Provides the ability to display dynamic waveforms. This functionality requires a Simvision license. 

Movies

Fields and Options

Movie Directory

Specifies the directory that includes the movie files.

Analysis Type

Specifies the analysis type that will be viewed.

Movie

Specifies that a movie will be viewed.

Image

Specifies that an image or plot will be viewed.

Play

Plays the movie.

Pause

Pauses the movie.

Stop

Stops the movie.

Beginning

Goes to the beginning of the movie.

End

Goes to the end of the movie.

Cancel

Cancels the movie.

Waveforms

Fields and Options

Waveform Files

Specifies the waveforms that will be viewed.

To view multiple .ptiavg waveform files (current and voltage waveform) and .trn profiling databases, click Add to browse to the required directory and select the corresponding .ptiavg/.trn file.  These files can be loaded or removed using the Add and Remove buttons respectively.

Filter - Pattern

The list of nets/instances can be filtered basis the following:

  • Select Rail Current, Voltage, and/or Power Current to filter instances based on the waveform type.
  • Enter a value in the Pattern field and select either Net or Instance to filter instances based on the specified pattern.

Net

Specifies that the nets will be filtered by the text in the Pattern field.

Instances

Specifies that the instances will be filtered by the text in the Pattern field.

You can use multiple CPUs to enable the search of instances in parallel, and thereby improve the search time in large designs. Multi-threading is supported for instance search using both the Instances and Select From GUI buttons.

You must set up multi-CPU usage before accessing the View Waveforms form, as shown below:
set_multi_cpu_usage -localCpu number_of_cpus

Select From GUI

This button can be used to plot a waveform for an instance that is selected in the window.

Clear

The Pattern field can be emptied by selecting the Clear button.

Plot

To view a current or voltage waveform, select an item on the list, and select the Plot button. This will result in Simvision being run and a Simvision window appearing with the selected current waveform displayed.

Cancel

Closes the View Waveforms form.
