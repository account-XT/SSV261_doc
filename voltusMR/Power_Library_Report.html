Power Library Report


 Choose Power Rail - Textual Reports - PowerGrid Library.

Basic Reports contents of the already generated power library and physical view of the library power-grid network.


Basic

Fields and Options

Power Library

Specifies the power-grid library to generate the power library report.

View Power Library

Specifies the following options to view the power library:

  • All Cells
  • Cells

Overlay Stripes Database

Specifies the stripes database to be overlaid during the psviewer session.

Overlay Cell GDS

Specifies the cell gds design file to be overlaid, during the psviewer session.

Check Compatibility

Checks the compatibility between the specified cell libraries.

Related Text Commands

See check_pg_library command in the Voltus Text Command Reference.
