Voltus IC Power Integrity Solution Menu Reference
Product Version 26.10, May 2026

Go To

Use the Goto form to go to a specific point in the main window display. To open the Goto form:

 Select View - Go To.

 Fields and Options
Micron units Specifies the coordinates in micron or db units.
db units

Add

Adds the specified coordinates to the list box below.
Goto Zooms in to the selected location in the main window display and places a marker on the location. Click this button after selecting a coordinate from the list.
Remove Removes the selected coordinate from the list and the corresponding marker from the main window display.
Clear All Clears the list and removes all Goto markers from the main window display.
Load Loads the coordinates from a file.
Save Saves the coordinates in the list to a file.
Close Closes the Goto form.
