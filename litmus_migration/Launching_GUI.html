Launching GUI

Litmus GUI is built on Cadence Joules StudioTM platform. In the current release, the GUI needs to be launched through Joules Studio shell.

Steps to Launch GUI

  1. Ensure you have a Joules Studio installation
  2. Before invoking Litmus, do
  3. setenv JOULES_STUDIO <joules_installation_path> 

  4. In Litmus , after you have run verify_timing_intent / check_target_constraints, do the following:

       gui_show
  5. The Joules GUI should now show up in Litmus mode
  6. Please note that gui_show should be done only after init_design
  7. Rules check results should be visible in the "Litmus Rules Summary" tab.

     8. Right click on rule occurrence row for Cross probing options.

    1. Click on Open SDC viewer to Cross probe to SDC file.

    2. Click on Open Schematic viewer to get the design schematic view.

Note: For RTL designs, only the elaborated netlist would be loaded in GUI and hence crossprobing back to RTL will not be available
