CONST_CLK_GRP3

Rule Description : The harmonic cycle of a pair of connected and synchronous clocks exceeds the threshold

Reduced false violation in Litmus by skipping clock pairs which are synchronous but not connected, that is no path exists between the 2 clocks in the pair.

Example

litmus > get_clock_to_clock_association clkA clkB
synchronous

litmus > report_timing -from clkA -to clkB -unconstrained
##############################################################
#  Generated by:      Cadence Litmus 
#  OS:                Linux x86_64(Host ID xxxx)
#  Generated on:      xxx
#  Design:            test
#  Command:           report_timing -from clkA -to clkB -unconstrained
###############################################################
No unconstrained timing paths with given description found.
Paths may be constrained or  may not exist.

litmus > report_timing -from clkB -to clkA -unconstrained
##############################################################
#  Generated by:      Cadence Litmus 
#  OS:                Linux x86_64(Host ID xxxx)
#  Generated on:      xxx
#  Design:            test
#  Command:           report_timing -from clkB -to clkA -unconstrained
###############################################################
No unconstrained timing paths with given description found.
Paths may be constrained or may not exist.

Since no path exists for above clock pairs, no need to check for their harmonic threshold. No CONST_CLK_GRP3 violation is reported by Litmus
