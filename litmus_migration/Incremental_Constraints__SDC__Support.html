Incremental Constraints (SDC) Support

Litmus introduces support for providing incremental constraints and subsequently performing rule checking in the same session. This was not possible with Conformal Litmus. 

Example SDC

create_clock -name CLK1 -period 5.000 -waveform [list 0.000 2.500] [get_ports clk1]
create_clock -name CLK2 -period 15.000 -waveform [list 0.000 2.500] [get_ports clk2]
set_sense -stop_propagation buf4/X -clocks CLK1

set_input_delay -clock CLK1 1.0 [ get_ports data1]
set_input_delay -clock CLK2 1.0 [ get_ports data2]

Example Non-MMMC flow

Main Litmus Script
set libs [list lib1.lib lib2.lib]
read_lib $libs
read_netlist top.v
init_design
read_sdc top.sdc
verify_timing_intent
Output
@[DEV]litmus 12> report_rule_check CONST_CLK_LAT1 -verbose
CONST_CLK_LAT1: Undefined clock network latency for real and generated clocks
    Severity: Warning    Fail Occurrence: 2
    1: Fail: In line 1, file top.sdc (create_clock): Object: CLK1 
    2: Fail: In line 2, file top.sdc (create_clock): Object: CLK2
Incremental SDC constraint
@[DEV]litmus > set_clock_latency  0.3 [get_clocks CLK1]        
@[DEV]litmus > verify_timing_intent
...
@[DEV]litmus > report_rule_check CONST_CLK_LAT1 -verbose
CONST_CLK_LAT1: Undefined clock network latency for real and generated clocks
    Severity: Warning    Fail Occurrence: 1
    1: Fail: In line 2, file top.sdc (create_clock): Object: CLK2

Example MMMC flow

MMMC script (mmmc.tcl)
create_library_set -name max_libset -timing [list lib1.lib lib2.lib]
create_library_set -name min_libset -timing [list minlib1.lib minlib2.lib]

create_timing_condition -name default_mapping_tc_2 -library_sets [list max_libset]
create_timing_condition -name default_mapping_tc_1 -library_sets [list min_libset]

create_rc_corner -name rc_corner_worst\
   -pre_route_res 1\
   -post_route_res 1\
   -pre_route_cap 1\
   -post_route_cap 1\
   -post_route_cross_cap 1\
   -pre_route_clock_res 0\
   -pre_route_clock_cap 0\
   -temperature 0

create_rc_corner -name rc_corner_best\
   -pre_route_res 1\
   -post_route_res 1\
   -pre_route_cap 1\
   -post_route_cap 1\
   -post_route_cross_cap 1\
   -pre_route_clock_res 0\
   -pre_route_clock_cap 0\
   -temperature 25

create_delay_corner -name min_delay_corner -timing_condition {default_mapping_tc_1} -rc_corner rc_corner_worst

create_delay_corner -name ocv_delay_corner -early_timing_condition {default_mapping_tc_1} -late_timing_condition {default_mapping_tc_2} -rc_corner rc_corner_worst

create_delay_corner -name max_delay_corner -timing_condition {default_mapping_tc_2} -rc_corner rc_corner_best

create_constraint_mode -name CM1 -sdc_files[list ./top.sdc] 

create_analysis_view -name view1 -constraint_mode CM1 -delay_corner ocv_delay_corner

set_analysis_view -setup [list view1] -hold [list view1]
Main Litmus Script
read_mmmc mmmc.tcl

read_netlist ./top.v

init_design

verify_timing_intent
Output
