The following table explores the changes in various rule behavior from Conformal Litmus to Litmus.

RuleConformal LitmusLitmusAdditional Notes

CONST_CG_CHK3

 Additionally considers generated clock / master clock association.

Checking is based on Tempus check_timing.

It thus checks the endpoint in the fanout.
CONST_CLK_DEF1

Covers the following scenarios: MISSING_CLOCK, BLOCKED_CLOCK, MISSING_GENERATED_CLOCK

Covers the following scenarios: MISSING_CLOCK_NO_SHARED_DRIVER, MISSING_CLOCK, BLOCKED_CLOCK

A new rule is introduced, namely CONST_CLK_DEF4 which covers the following case: MISSING_GENERATED_CLOCK

Following behavior difference between Timing engines will cause difference in occurrence count:

Case when create_generated_clock -master_clock -> -source path is missing :
Conformal Litmus: Constraint object is not created for rule check.
Litmus: Clock object is created for rule check. The clock object is not included in clock propagation and stops others from being propagated over the reference.


Conformal Litmus: clock is not propagated at set_case_analysis transition point.
Litmus: clock is propagated at set_case_analysis transition point.
CONST_CLK_DEF2

Extra violations found

Fixed behavior


CONST_CLK_DEF40

Constraint object is not created for rule check.

Clock object is created for rule check.

The clock object is not included in clock propagation and stops others from being propagated over the reference.


CONST_CLK_GRP2

Rule check is performed on generated clocks in the transitive fanout.

Rule Check is performed on immediate generated clocks (directly inferred)


CONST_CLK_GRP4

Rule check is based on root clock source and clock group. Checked on synchronous clock group.

Rule check is based on root clock and clock relationship. Checked on synchronous but not physically exclusive clock group. 


CONST_CLK_UNC10

Check performed on clock pairs regardless of connection.

Check performed on “connected” clock pairs to see if they are asynchronous (w/o -allow_path) or exclusive.


CONST_IO_IDL1

Only input ports that are connected to some constrained path end point (a clocked register or a pin with set_output_delay) are considered for this rule.
However, a clock source will not be checked in this rule if it only drives clock pins of sequential elements.



CONST_IO_IDL13

This rule applies only to ports that are start points of a timing path that does not match any set_false_path. set_false_path should have both -setup and -hold specified, or neither. Otherwise, the port is still subject to this rule check.

This rule does not check inputs that are clock sources.



CONST_IO_ITR1


Litmus skips clock source, which is checked by CTR1/CTR6

Litmus drops set_dont_touch_network for this check
