SVA Generation

What is supported?

  1. set_multi_cycle_path
  2. set_false_path

What is not supported?

  1. create_generated_clock
  2. set_case_analysis
  3. set_disable_timing
  4. set_clock_sense


Command Line Changes 

  1. There is no change in options for command "generate_sva" in the current release
  2. In Nov 15 release , following options will be available for new SVA system:
    1. -use_category : Enables new SVA system. When enabled , tool uses the -category_file or SDC comment to write custom macro for SFP assertions
    2. -category_file : FIle containing categorization of SFP constraints

How to enable Mode1 & Mode2

  • This root attribute ltms_sva_path_based_sampling_opt_level  controls the modes
  • Only path based sampling is available in Litmus
  • In the Nov 3 release Mode1 is enabled by default, no need for any setting. Traditional mode is not available in Nov 3 release
  • For Mode2 do:
    • set_db set ltms_sva_path_based_sampling_opt_level 2
