CONST_DGN_CMB1 and CONST_EXC_SMD7

Litmus has split the existing rule CONST_DGN_CMB1 into two - CONST_DGN_CMB1 and CONST_EXC_SMD7

Rule Description of the new CONST_DGN_CMB1 now states the following: Unconstrained combinational path / Incomplete set_min/max_delay

If there is a combinational which cannot be constrained by use of one or more of the following constraints, CONST_DGN_CMB1 violation is not reported by Litmus:

  • set_input_delay
  • set_output_delay
  • set_max_delay
  • set_min_delay

Example

create_clock -name clk -period 10 i1
set_propagated_clock clk
set_clock_sense -stop_propagation -clock clk b1/x

In the above design and constraints, there is no way to constraint the combinational path from port i1 to o1. Hence, Litmus does not report a violation (Conformal Litmus does report violation). Other cases include the situation where the path is marked as false by set_false_path.  So even if the user would constraint the path with set_input_delay or set_max_delay , it would be overriden by set_false_path. Hence Litmus does not report a violation.
