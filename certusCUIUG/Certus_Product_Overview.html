Certus Product Overview

The Certus Closure Solution software, also known as Certus, is a next-generation design closure solution that enables engineers to perform distributed ECO on larger and complex designs. It provides enhanced performance and capacity by using the Distributed MMMC architecture, which fully leverages multiple threads across distributed processes, enabling maximum scalability. Certus provides a flexible computing environment that enables a single user to perform subsystem/full-chip ECO timing/power closure, reducing turnaround time from several days to hours.

Another advantage of this solution is that Certus allows the users to perform ECO routing and parasitic extraction in batch mode, to collect updated parasitic, and perform updated timing analysis with signoff accuracy post ECO within the same session.

Currently, users run timing analysis and ECO closure in separate sessions when the design has a large number of MMMC views. After the ECO closure run, users need to implement the ECOs, collect new Verilog and SPEF data, and then perform post-ECO timing analysis.

The Certus software addresses these usability concerns by automating all those steps through a single cockpit and a single session.

Other advanced ECO solutions, such as High Capacity ECO (which reduces the database size) and SmartMMMC (which compacts the timing graph when a large number of timing views are provided), are complementary to Certus.

Certus Solutions Architecture Overview

Certus includes the following key features:

  • Ensures that each partition and top level loads its own database.
  • Reduced memory peak as physical data is no longer assembled in the Tempus client manager session.
  • Reduced ECO cycle time, thus enabling improved productivity. This is due to the lighter design-loading phase and the embedded ECO implementation, which allows iteration within the same session.
  • Includes a simple use model where physical data are loaded directly from Innovus DB. There is no requirement to provide a full hierarchical UPF (power intent comes from STA clients and Innovus DBs).
  • Drives implementation directly from the Certus cockpit, where ECO implementation is done in batch mode on Certus clients. In addition, updated parasitic data is redirected to the Tempus STA session for final timing analysis post ECO implementation.
  • Provides support for multi-technology LEF design architecture.
  • Allows ECO optimization for inter-DIE paths concurrently, where each DIE is from different process nodes. This is specific to 3DIC designs.
  • Compatible with advanced existing features of Tempus, such as Distributed MMMC ECO, smartMMMC, and High Capacity ECO.
