Certus Licensing Requirements

The Certus software follows the sequence below for checking out licenses:

  1. To invoke Certus, the software checks out the client manager license - Certus Optimization Client Manager (CRTS200).
  2. To launch Tempus clients within Certus, the Tempus license per client is checked out.
  3. To launch Certus clients, the software checks out one (CRTS150) license per Certus client:
    1. For a 3nm technology node, each Certus client checks out a Certus 3nm license (CRTS230).
    2. For a 2nm technology node, each Certus client checks out a Certus 2nm license (CRTS232).
  4. To run ECO routing, the software checks out the Innovus Base (INVS) per Certus client and Innovus Technology (INVS_tech) licenses.
  5. To run signoff parasitic extraction, the software checks out the Quantus licenses.

You can iterate back to Step 1; however, all the licenses (except Quantus and Pegasus) will remain checked out until the Certus client manager exits.
