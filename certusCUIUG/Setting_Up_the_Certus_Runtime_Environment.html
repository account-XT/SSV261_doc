Setting Up the Certus Runtime Environment

If install_dir is the location of the Certus installation, then you should set up the runtime environment as follows:

  • Add the install_dir/bin directory to the path. The bin directory has links to all the public executable files in the install hierarchy.
  • If you want the Certus man pages to be available with the Unix man command, then you can add the install_dir/share/certus/man to the MANPATH envar.
  • If you want the Stylus Common UI Certus man pages to be available with the Unix man command, then you can add install_dir/share/certus/stylus to the MANPATH envar.
  • If you want the Tcl man pages to be available with the Unix man command, then you can add the install_dir/share/tcltools/man to the MANPATH envar.

For example, you can add the following to the startup shell script:

set install_dir = /tools/certus22.1/lnx86 set path = ($install_dir/bin $path)

setenv MANPATH $install_dir/share/certus/man:$install_dir/share/tcltools/ man:$MANPATH

Note:

When Certus launches, it automatically adds the legacy or Stylus CUI man pages (if the -stylus parameter is specified), and the Tcl man pages at the beginning of the current MANPATH inside Certus. Therefore, within Certus, the man command will show both the sets of man pages before any other man pages.

Temporary File Locations

Each Certus session creates a temporary directory to store temporary files at the beginning of the run.

By default, ssv_tmpdir is created in the /tmp directory. If the Unix envar TMPDIR is set, ssv_tmpdir is created inside $TMPDIR.

The name of the tmp_dir will appear as given below:

ssv_tmpdir_\[pid\]_xxxxxx

Where _xxxxxx is a string that is added to make the directory unique. For example:

ssv_tmpdir_10233_nfp9ez

The temporary directory is automatically removed on exit or if the run is terminated with a catchable signal (for example, SIGSEGV).
