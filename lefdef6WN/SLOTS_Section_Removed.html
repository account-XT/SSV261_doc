What's New in LEF/DEF 6.0
Product Version 6.0, May 2026

SLOTS Section Removed

Slots in metal were intended to reduce metal density. Although some older technologies still use slots, but DEF support was never used for them. Therefore, the SLOTS section syntax shown below is obsolete and has been removed:

[SLOTS numSlots ;
   [- LAYER layerName
      {RECT pt pt | POLYGON pt pt pt ... } ...
  ;] ...

END SLOTS]

Additionally, the SLOTS keyword (indicated with strikethrough below) in the BLOCKAGES section is now obsolete and has been removed:

[BLOCKAGES numBlockages ;

   [- LAYER layerName

      [ + COMPONENT compName | + SLOTS | + FILLS | + PUSHDOWN

         | + EXCEPTPGNET]

      ...
