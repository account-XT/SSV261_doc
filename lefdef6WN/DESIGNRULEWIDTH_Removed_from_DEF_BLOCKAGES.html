What's New in LEF/DEF 6.0
Product Version 6.0, May 2026

DESIGNRULEWIDTH Removed from DEF BLOCKAGES

The DESIGNRULEWIDTH attribute was intended to model abstract blockages using spacing rules for a given design rule width. However, it is not in use and has been removed from the BLOCKAGES syntax, as indicated with strikethrough below.

[BLOCKAGES numBlockages ;

   [- LAYER layerName

      [+ COMPONENT compName | + FILLS | + PUSHDOWN

         | + EXCEPTPGNET]

      [+ SPACING minSpacing | + DESIGNRULEWIDTH effectiveWidth]

         {RECT pt pt | POLYGON pt pt pt ...} ...

      ;] ...

LEF OBS DESIGNRULEWIDTH is still in use and has not been made obsolete.
