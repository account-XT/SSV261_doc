Tempus Stylus Known Problems and Solutions
Product Version 26.10, May 2026

6

Others

Identified in Previous Releases

The following features are not mapped from Tempus legacy to DSTA CUI:

  • The set_max_cap_per_freq_transition command is not supported.
  • The read_ilm command is supported in DSTA CUI. However, the command -help does not show up, the following error message is displayed:

**ERROR: (DSTA-1006): Command 'read_ilm' is not implemented.

The following features are not mapped from Tempus legacy to Tempus CUI:

  • The define_attribute -obj_type parameter does not support lib_pg_pin option.
  • The read_design and read_db command -help does not match.
  • The write_sdf command -help does not match for Tempus legacy and CUI.
  • The sizeof_collection command is not supported in get_db designs.
  • The read_lib -lef command parameter is not supported.
  • The get_common_ui_map command output for the following commands is not correct:
    • get_analysis_view
    • get_constraint_mode
    • get_delay_corner
    • get_library_set
    • get_op_cond

Solution

You can use eval_legacy to run a legacy command in the legacy Tcl interpreter.
