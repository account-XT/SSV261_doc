Signal Integrity

Identified in Previous Releases

The following update_glitch parameter is not mapped from Tempus legacy to DSTA CUI:

  • -effort

The following features are not mapped from Tempus legacy to Tempus CUI:

  • The following timing category attributes are not supported:
    • timing_disable_backward_compatible_timing_derate_mode
    • timing_enable_etm_latch_thru_mode
    • timing_extract_model_backward_compatible_report_mode
    • timing_extract_model_enable_waveform_propagation
    • timing_extract_model_improved_waveform_cache
    • timing_extract_model_write_asymmetric_lvf
    • timing_path_based_maximum_time_limit

Solution

You can use eval_legacy to run a legacy command in the legacy Tcl interpreter.
