Before You Begin the Installation


Before installing any Cadence products,

  1. Check the Cadence software emails and its contents.

The emails from edaontapsystem@cadence.com contains

  • An e-mail message of the Cadence License File

  • An e-mail message of the Cadence Control File

          These two emails are sent simultaneously as your order is fulfilled.

  1. Note:  Not all orders contain an Installation Control file. This is because Cadence has been using a new order entry/tracking system over the past few years which no longer generates an installation control file.   Control file is only intended for software built as InstallScape and InstallShield.


    The subject of the e-mail containing the Installation Control file has the following format:

     #INSTALLSCAPE PRODUCT "Product_ID" "Production Description"

          #INSTALLSCAPE SOURCE "sourceURL" "Description" "Version"


          For example, a partial entry of InstallScape control file for IC231 is shown below

   

     #INSTALLSCAPE PRODUCT "P95100" "P95100: Virtuoso(R) Schematic Editor L"

          #INSTALLSCAPE SOURCE "is/IC231/lnx86/Base" "Base IC231 LINUX RHEL 7.4;RHEL 7;RHEL 8;SLES 12;SLES 15 IC23.1.43 Release" "Version Base IC231 LINUX RHEL 7.4;RHEL 7;RHEL 8;SLES 12;SLES 15 IC23.1.43 Release"


        Note: By default the software installation will install all Products packaged from the Media/DVD. When you install the entire software, you will have the utilities/tools to run the purchased software aka product(s).


2. Determine the type of release received by looking on the DVD label below the words "electronic design software."

There are three different types of releases. Different product families have different release schedules, and your product may use a combination of these release types:

  • Base

    A complete software release.

  • Update

    A periodic update of a base software release.

  • Hotfix

    A collection of critical fixes, released intermittently between regularly scheduled releases. 

    Note: some hotfix may be built as a complete software release.


  1. Go to https://ask.cadence.com

    1. If you already have a Cadence Online Support account, enter your login name and password, and click Log In to log into your account.

      If you do not have a Cadence Online Support account, click Register Now, and follow the instructions to create a new account.

    2. Select Installation & Licensing

      The page that appears shows important information about configuration, system patches, and other requirements that relate to all Cadence products.

    3. Select Software - Computing Platforms, and perform the following steps:
      • Click Recommended platform patches for systems running Cadence products to view a list of recommended OS patches for running Cadence software.
      • Click Supported Platform Matrix for Cadence Applications to view the supported hardware and operating system matrix to Cadence applications.

        Check your system hardware and software configuration to make sure it is properly set up before you attempt to load the Cadence software onto your system. The Cadence family of products runs on a variety of UNIX/Linux-based and PC-based systems. You can use the CheckSysConf tool to verify that the machine on which you want to run Cadence tools have the required system configuration and OS patches. Note that this tool is only available for Solaris, HP-UX, AIX, and LINUX platforms. See Using CheckSysConf for more information.

        You can also contact the manufacturer of your platform or Cadence Customer Support at www.cadence.com/support.

    4. Select Resources - Product Manuals. The page that appears lists the most frequently used Cadence releases. Click a release to obtain the product manuals pertaining to that release.

      You can read the full documentation before installing the products to learn what is new in this release. This library also includes configuration manuals.

      If the release you are interested in is not listed, go Search Product Manuals, type "Release Documentation Index Page".

  2. Set the default compiler to the standard ANSI C compiler if you have other compilers on your system.

    Some Cadence products use the ANSI C compilers to link in customer C code or libraries.

    For information on the compilers required for your operating system, contact the manufacturer of your platforms or search in Cadence Online Support.

  3. Verify that your system has enough free disk space for the products you are installing.

    See your product documentation for more information about memory, disk, and swap requirements for design databases of various sizes.

  4. Determine the type of installation.

    • If your shipment contains only Baseline or both Baseline, Update, and Hotfix DVDs, follow the instructions in Chapter 4, "Installing Products into a New Hierarchy."

    • If you have previously installed products from this release and now want to install additional products from these DVDs, follow the instructions in Chapter 5, "Installing Additional Products into an Existing Hierarchy."

    • If you have previously installed products from this release and now want to update those products using Update and Hot Fix DVDs, follow the instructions in Chapter 6, "Updating an Existing Hierarchy."

    Note:  The type of DVD you mount first (Baseline, Update, and Hotfix DVD#1) determines the resulting installation type. That is, if you start with Baseline DVD#1, you will install the baseline version of the selected products. If you start with an Hotfiix DVD#1, you will install the Hotfix version of the products as they existed on the date that the Hotfix DVD set was created. To complete the installation, you may need to mount and install additional products from the Baseline version after installing from the Hotfix DVDs disk.
