Automating an InstallScape Installation


See the InstallScape BatchMode User Guide for details on how to automate product installation using InstallScape command line options.

Install from Cadence Server without Saving an Archive option, enter the following at the terminal prompt:

    • iscape.sh -batch majorAction=download minorAction=Install sourceLocation=https://sw.cadence.com/is/IC231/lnx86/Base installDirectory=/vols/Cadence/IC231

Enter your username and password as prompted to begin the installation.

Note the URL for sourceLocation is in the Control file email. Simple prepend https://sw.cadence.com/ to the SOURCE /is/IC231/lnx86/Base to form the complete software URL path. The installDirectory is your install directory path. The install directory must be empty and that you have permission to write into.

To get a complete InstallScape software sourceLocation, enter the following at the terminal prompt:

    • iscape.sh -batch majorAction=selectReleases minorAction=getSourceSites platforms=lnx86 releases=IC231

This command options return of the URLs of the IC231 release name.

Printing out list of available source sites:
              https://sw.cadence.com/is/IC231/lnx86/Base
              https://sw.cadence.com/is/IC231/lnx86/Hotfix_IC23.10.030

For more command line options go to https://downloads.cadence.com select DOWNLOAD ASSISTANTS ->InstallScape and open the Batch_Mode.pdf


Configure the software after installing, enter the following at the terminal prompt:

    • iscape.sh -batch majorAction=configure installDirectory=/vols/Cadence/IC231

If the software release has a configuration built in, the configuration script will be added and display on terminal to run. For example, the batch configure above added an entry below

            Initializing install directory to: /vols/Cadence/IC231
            Selected release is IC231_lnx86
            
            CREATING configuration script:
            /vols/Cadence/IC231/installData/IC231_lnx86/batch_configure.sh
            
            
            The following products will be added to the configuration script:
  
            Adding to configuration script: ncvhdl64b
            Adding to configuration script: ncvhdl
            Adding to configuration script: amsEnv64b
            Adding to configuration script: ihdl64b
            Adding to configuration script: oaRedist
            
            Done adding products to configuration script.
            
            IMPORTANT: To configure products run the script:
            /bin/sh /vols/Cadence/IC231/installData/IC231_lnx86/batch_configure.sh


For more command line options go to https://downloads.cadence.com select DOWNLOAD ASSISTANTS ->InstallScape and open the Batch_Mode.pdf


Get the latest License Manager, InstallScape, and CheckSysConf


Go to https://downloads.cadence.com, enter LCU in the Filter by Release and select Lic+Config_Utils (LCU) to download.   Unpack and install the release


Alternative if you have InstallScape run iscape.sh, click on "Search & Install Releases" to connect to Cadence server.   Under the Filter releases by release name scroll down to LCU43,

select it, choose the port, and select the latest Hotfix.  Click the checkbox the most current Release Date and click Continue and follow the wizard to install the release
