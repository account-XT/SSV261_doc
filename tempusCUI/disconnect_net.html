disconnect_net

disconnect_net
[-help]
-net <net_name>
{-pins <list_of_pins> | -all}

Disconnects a net and connects it to new pins or ports. The syntax is not order-dependent.

After any ECO command, the tool can performs either an incremental or full timing update when you run the next command that reports timing, for example, report_timing.

Note: The tool supports this command for flattened designs only.

Parameters

-all

Detaches all terminals connected to the net. You cannot specify a pin/port list if you specify this parameter.

-net

Specifies the net to connect.

-pins

Specifies the pins/ports from which the specified net is to be detached.

Examples

  • The following command detaches net26 from pins i1/A, i2/B, and i2/Z:
    tempus> disconnect_net -net net26 -pins "i1/A i2/B i3/Z"

  • The following command is equivalent of above example.
    tempus> disconnect_net -net [get_nets net26] -pins [get_cells "i1/A i2/B i3/Z"]
