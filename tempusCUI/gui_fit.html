gui_fit

gui_fit [-help]

Fits the entire design in the viewable window. You can use this command at any stage of the design flow to view the design in entirety.

Parameters

-help

Prints a brief description of the gui_fit command.

For a detailed description of the command, use the man command: man gui_fit.
