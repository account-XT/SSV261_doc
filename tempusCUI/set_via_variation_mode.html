set_via_variation_mode

set_via_variation_mode 
[-help]
[-reset]
[-corner_sigma_multiplier <std::string>]
[-correlation_type {corner}]
[-reset {true | false}]
[-separate_params_for_via {true | false}]

Allows you to scale via resistance from SPEF based on user-specified scaling factor. 

This command allows you to specify per via sigma multiplier and handles the advanced via variation scaling.

Parameters

-help Prints out the command usage
-corner_sigma_multiplier <std::string>

Provides the scaling multiplier for corner scaling.

Default: " "
-correlation_type {corner}  

Specifies inter-layer correlation values.

Default: corner
-reset Resets all or specified options to their default value.
-reset {true | false}

Resets via variation modes to their default value.

Default: false
-separate_params_for_via {true | false} 

Allows to create separate parameters for via variation.

Default: false

Examples

  • The following command uses correlation corner for scaling purpose:
    set_via_variation_mode –view view1 -correlation_type corner -corner_sigma_multiplier {{{param_V1 -3} {param_V2 -3}..}

    where V1, V2 are via name and “-3” is used as scaling factor. 
  • The following command will scale the via resistance as shown below:
    set_via_variation_mode –rc_variation false -corner_sigma_multiplier {{{param_V1  2} {param_V2   2}..}

    Via Calculation below:

    Via1_Rnew = Via1_Rspef *(1 + 0.021 + 2*0.110)
    Via2_Rnew = Via2_Rspef *(1 + 0.010 + 2*0.120)


                      Via1:
    table_meanshift: 0.021
    table_stdev :    0.110
                      Via2:
    table_meanshift: 0.010 
    table_stdev :    0.120
