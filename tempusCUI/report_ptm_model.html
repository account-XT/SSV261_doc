report_ptm_model

report_ptm_model 
[-path_types]
[-ports]
[-delay_param]
[-arcs]
[-arc_type] 

Generates a report on ports, arcs, and global delay parameter details for the current PTM model. This command must be used after the create_ptm_model command and before the save_ptm_model command.

Parameters 

-arcs

Displays the timing arc details for the current model, such as the input port, output port, and the delay value associated with the timing arc.

-arc_type

Reports the type of arc. When specified, the command output displays the Arc Type column.

-delay_param

Displays the global delay parameter details set using the set_ptm_global_parameter command.

-path_types

Reports only the path type details.

Default: Includes the details of path types created.

-ports

Displays the port details from the current PTM model that were set using PTM commands.

Example

  • The following command displays a report on the arcs of the model1 PTM model:

tempus> report_ptm_model -arcs
ModelName  : model1   
Arc                  From        To         Delay      PathType   PathFactor

     ---                  ----        --         -----      --------   ----------

     refclk_to_spi_fs     refclk      spi_fs     0.3        -          -        

     spi_fs_to_scan_se    spi_fs      scan_se    1.0        -          -        

  • The following command displays a report on the type of arc of the model1 PTM model.
    report_ptm_model -arc_type
    ModelName  : model1   

    DriveType    Cell     

     ---------    ----     

     stdDrive     pllclk   

     PathType     Cell       Arc Type 

     --------     ----       -------- 

          No path type defined.

  • The following command displays a report on the global delay parameters of the model1 PTM model: 

    report_ptm_model -delay_param 
    ModelName  : model1    

    DelayParameter       Delay               
    --------------       -----               
    setup                -                   
    hold                 -                   
    clk_to_output        -                 

  • The following command displays a report on the port details of the model1 PTM model: 

    report_ptm_model -ports     

    ModelName  : model1   

    DriveType    Cell     

    ---------    ----     

    stdDrive     pllclk   


    Port         Direction  BusRange   LoadValue  LoadType   DriveValue  DriveType

    ----         ---------  --------   ---------  --------   ----------  ---------

    refclk       clock      -          -          -          -           -        

    scan_se      out        -          -          -          -           -        

    spi_fs       in         -          -          -          -           -           

  • The following command displays a report on the global delay parameters of the dma PTM model: 
    tempus> report_ptm_model -delay_param 

    ModelName : dma  
    DelayParameter Delay 
    -------------- ----- 
    setup 1.2 
    hold 1.5 
    clk_to_output 1.6
  • The following command reports the path type details for the SETUP_TYPE1 path type. 
    tempus> create_ptm_model <name>
    :
    tempus> create_qtm_port -type clock CLOCK
    tempus> create_qtm_port -type input IN
    :
    tempus> create_ptm_path_type SETUP_TYPE1 -lib_cell typ_1.2/DFFX1 \
    -relative_pin CLK -target_pin D1
    tempus> create_ptm_path_type HOLD_TYPE1 -lib_cell typ_1.2/DFF2X1 \
    -relative_pin CLK -target_pin D2
    tempus> create_ptm_constraint_arc -from clock_gen_1 -to data_in -setup \
    -edge fall -path_type SETUP_TYPE1
