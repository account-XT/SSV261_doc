power_intent Category Attributes

The root attributes in the power_intent category are:

  • handle_old_lib_with_signal_level
  • power_intent_allow_back_to_back_isolation
  • power_intent_allow_nested_default_domain
  • power_intent_allow_power_domain_min_gap_zero
  • power_intent_allow_shifter_voltage_mismatch
  • power_intent_assume_iso_enable_pin_is_always_on
  • power_intent_check_all_nets_for_domain_crossing
  • power_intent_do_not_use_top_domain_for_port_voltage
  • power_intent_honor_power_domain_for_domain_crossing_route
  • power_intent_honor_power_domain_for_intra_domain_route
  • power_intent_include_dot_lib_related_pg_pin
  • power_intent_use_cpf_global_connect_for_always_on_buffer
  • power_intent_use_cpf_global_connect_for_shifter
  • power_intent_use_effective_domain_for_iso_shifter_insertion

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the power_intent category, use the following command:

get_db -category power_intent

handle_old_lib_with_signal_level

handle_old_lib_with_signal_level {true | false}

Default: false

Data_type: Boolean

Allows using the old-style .lib with signal_level and power_rail in the MSV cell identification and term voltage.

power_intent_allow_back_to_back_isolation

power_intent_allow_back_to_back_isolation {true | false}

Default: false

Data_type: Boolean

Supports back-to-back isolation insertion along one cross-domain net based on the CPF ISO rule. Set true to enable.

power_intent_allow_nested_default_domain

power_intent_allow_nested_default_domain {true | false}

Default: true

Data_type: Boolean

Allows a non-default power domain member to be logically nested in a default power domain. This default power domain member has fence constraint.

By default, due to grouping, the fence constraint is lost for the non-default power domain member. Set true to enable.

In the netlist: modules HInst11 and HInst12 are under HInst1; and HInst1 is under the top.

You have the following:

create_power_domain -instances HInst1

create_power_domain -default -instances {HInst11 HInst12}...

That means HInst11 and HInst12 are cut from HInst1 to default power domain. If there is a fence/region constraint for HInst11 and HInst12 in default power domain, then please turn this global on. Otherwise, the fence/region for HInst11 and HInst12 will be lost.

power_intent_allow_power_domain_min_gap_zero

power_intent_allow_power_domain_min_gap_zero {true | false}

Default: true

Data_type: Boolean

Allows users to set power domain zero minGap.

power_intent_allow_shifter_voltage_mismatch

power_intent_allow_shifter_voltage_mismatch {true | false}

Default: true

Data_type: Boolean

When set to false, it prevents insertion of level shifters by allowing voltage tolerance.

power_intent_assume_iso_enable_pin_is_always_on

power_intent_assume_iso_enable_pin_is_always_on {true | false}

Default: true

Data_type: Boolean

Insert ISO/LS for all the inter-domain nets using effective domain based on the CPF rules. Set true to enable.

power_intent_check_all_nets_for_domain_crossing

power_intent_check_all_nets_for_domain_crossing {true | false}

Default: true

Data_type: Boolean

Checks all the nets for domain crossings. Set true to enable.

power_intent_do_not_use_top_domain_for_port_voltage

power_intent_do_not_use_top_domain_for_port_voltage {true | false}

Default: false

Data_type: Boolean

Controls voltage using top fterm domain for IO pin voltage.

power_intent_honor_power_domain_for_domain_crossing_route

power_intent_honor_power_domain_for_domain_crossing_route {true | false}

Default: true

Data_type: Boolean

Routes nets belonging to more than one power domain so that the routing does not violate power domain boundaries, in addition to routing intra-power domain and global nets using the specifications of the power domains.

For example, when you specify power_intent_honor_power_domain_for_domain_crossing_route true, if a net belongs to power domains PD1 and PD3, but not PD2, Early Global Route routes the net without going over the PD2 power domain boundary.

power_intent_honor_power_domain_for_intra_domain_route

power_intent_honor_power_domain_for_intra_domain_route {true | false}

Default: true

Data_type: Boolean

Routes intra-power domain and global nets using the specifications of the power domains. If you specify power_intent_honor_power_domain_for_intra_domain_route true, Early Global Route routes intra-power domain nets only within their power domains. Global nets that do not connect with a power domain do not get routed through that power domain.

power_intent_include_dot_lib_related_pg_pin

power_intent_include_dot_lib_related_pg_pin {true | false}

Default: true

Data_type: Boolean

Honors library related PG pins. Set true to enable.

power_intent_use_cpf_global_connect_for_always_on_buffer

power_intent_use_cpf_global_connect_for_always_on_buffer {true | false}

Default: false

Data_type: Boolean

Honors connection pecs for AO buffer based on the CPF rules. Set true to enable.

power_intent_use_cpf_global_connect_for_shifter

power_intent_use_cpf_global_connect_for_shifter {true | false}

Default: false

Data_type: Boolean

Honors connection specs for shifters based on the CPF rules. Set true to enable.

power_intent_use_effective_domain_for_iso_shifter_insertion

power_intent_use_effective_domain_for_iso_shifter_insertion {true | false}

Default: true

Data_type: Boolean

Honors effective domains for ISO/LS insertions. Set true to enable.
