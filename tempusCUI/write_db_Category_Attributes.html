write_db Category Attributes

The root attributes in the write_db category are:

  • write_db_create_read_file
  • write_db_include_metal_fill_rules

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the write_db category, use the following command:

get_db -category write_db

write_db_create_read_file

write_db_create_read_file {true | false} 

Default: false

Data_type: bool

When set to true, 'write_db my_db' will also create a 'my_db.read' file with a 'read_db my_db' command inside it. This is a Tcl file that can be passed to the Linux executable to make it easy to load the DB at startup like this:

'tempus -files my_db.read'.

For OA usage, it would have the appropriate 'read_db -oa_lib_cell_view {<lib><cell> <view>}' command inside it.

write_db_include_metal_fill_rules

write_db_include_metal_fill_rules {0 | 1}  

Default: 0

Data_type: int

Specifies whether metal fill settings are to be saved in the .init file when saving the design. Metal fill settings include set_metal_fill, set_metal_fill_spacing_table, and set_via_fill settings. By default, these metal fill settings are lost when you exit Tempus. To enable Tempus to record metal fill settings in the .init file, you must set the write_db_include_metal_fill_rules to 1 before saving the design. You can easily reload your settings by restoring the saved design:

set write_db_include_metal_fill_rules 1

set_metal_fill -iterationName iter1 ...
