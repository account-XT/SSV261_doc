set_cell_edge_type

set_cell_edge_type
[-help]
-cell cellName 
{-left edgeType | -right edgeType | -bottom edgeType | -reset}
[{-left edgeType | -right edgeType} [-cell_row rowNumber]]
[{-left edgeType | -right edgeType} [-half {top | bottom}]]
[{-top edgeType | -bottom edgeType} [-range {x y}]] [{-cell cellName} [-reset ]]

Specifies edge type for cell edges as EDGETYPE in macro LEF. It allows to specify one edge at a time for a particular cell.

To ensure the correct edge type specification, edge types asserted by set_cell_edge_type command should be pre-defined by the set_cell_edge_spacing command. 

For example:

set_cell_edge_spacing grp1 grp2 0.18
set_cell_edge_type –cell BUF1X -left grp1

If the edge type is specified without corresponding spacing rule, tool gives a warning and ignores the edge type specification.

Note: This command is not supported for save and restore design.

Parameters 

-bottom edgeType Specifies an edge type on the bottom side. 
-cell cellName  Specifies cell to which to add edge constraint.
-cell_row rowNumber

Specifies the row number for horizontal edge type.

You can define different edge types for each row of multiple height cells using -cell_row.

For example, there is triple height cell CKBUF.

The following commands define different edge types for different rows of the CKBUF cell.

set_cell_edge_type –cell CKBUF -right grp1 –cell_row 1
set_cell_edge_type –cell CKBUF -right grp2 –cell_row 2

In the above example, grp1 is applied to the first row (bottom row) of the right edge, grp2 is applied to the second row of right edge, and no specific edge type is defined for the third row of right edge and is of DEFAULT type.

The legal value of -cell_row is from 1 to n, where n is the number of cell height of the cell.
-help

Outputs a brief description that includes type and default information for each set_cell_edge_type parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_cell_edge_type  
-half {top bottom} 

Defines the edge types corresponding to the top or bottom half of the cell. 

The following example associates the edge type 'grp1' with the bottom row, top half of the multi-height cell SDFF8:

set_cell_edge_type -cell SDFF8 -right grp1 -cell_row 1 -half top
-left edgeType Specifies an edge type on the left side. 
-range {x y} Specifies the range for the vertical edge type.
-reset Resets the specified cell constraint to lef status.
-right edgeType Specifies an edge type on the right side.
-top edgeType Specifies an edge type on the top side. 

Example

The following commands specify one edge at a time for the BUF1X cell

  • set_cell_edge_type –cell BUF1X -left grp1
  • set_cell_edge_type –cell BUF1X -right grp1 –cell_row 1
  • set_cell_edge_type –cell BUF1X -right grp1 –cell_row 2
