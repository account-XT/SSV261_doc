create_net

create_net 
[-help]
-module <string>  
-names <list_of_nets> 

Adds a net to the design.

After any ECO command, the tool performs either an incremental or full timing update when you run the next command that reports timing, for example, report_timing.

Note: The tool supports this command for flattened designs only.

Parameters

-help

Outputs a brief description that includes type and default information for each create_net parameter.

For a detailed description of the command and all of its parameters, use the man command: man create_net

-module <string>

Adds the new net to the specified verilog module.

If the module name contains special characters, you need to start the module name with a backlash '\' and end it with a space.

-names <list_of_nets>

Specifies the list of nets to be added.

If the net name contains special characters, you need to start the part of the net name, which contains special characters, with a backlash '\' and end it with a space.

Note: You must specify -names before you specify other parameters. The software issues an error message if you do not specify the -names first.

Examples

  • The following command adds nets n1, n2, and n3:
    tempus> create_net -names "n1 n2 n3"
  • The following command adds net with base name ant_net[1] to module H[1]:
    tempus> create_net -names {\ant_net[1] } -module {\H[1] }
