get_capacitance_unit

get_capacitance_unit

Returns the capacitance unit (in picofarads) for the current session, which may be derived from the library file or set with the set_library_unit -cap parameter. This unit will be used while generating reports and for constraint settings.

Parameters

-help Prints out the command usage.

Example

The following command returns the session capacitance unit:

get_capacitance_unit

1.000000pf
