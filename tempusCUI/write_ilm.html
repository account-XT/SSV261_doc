Product Version 26.10, May 2026

write_ilm

write_ilm
[-help]
-dir dirname
[-model_type {timing|si|all}]
[-no_core_sdc]
[-no_spef]
[-no_xtwf]
[-ignore_ports ListOfPorts]
[-include_objects ListOfInstancesorNets]
[-validation_dir]
[-write_sdf]

Creates the specified directory containing the Interface Logic Module (ILM) data for timing analysis and the Extended Interface Logic Module (XILM) data for SI analysis.

The information is saved in the following directories:

For Timing:

  • $dir/ilm_data
    • *.v
    • *.sdc
    • *.spef

For SI:

  • $dir/si_ilm_data
    • *.v
    • *.sdc
    • *.spef
    • *.xtwf

Note: The ILM is not supported for Signoff in Tempus.

Parameters 

-help Prints out the command usage.

-dir dirname

Specifies the location of the ILM and XILM files, which are generated in the ilm_data and the si_ilm_data subdirectories, respectively.

-include_objects ListOfInstancesorNets

Accepts a collection of instances and/or nets. All instances and nets specified are preserved in the generated ILM. When instances are preserved, their driving and load nets are also preserved. When nets are preserved, only the driving instances are preserved.

-ignore_ports ListOfPorts

The given ports and the associated interface path(s) which are starting or ending at these ports will not be included in the ILM model.

-model_type {timing|si|all}

Generates ILM and XILM models.

  • The -model_type timing parameter creates only ILM models.
  • The -model_type si parameter creates only XILM models.
  • The -model_type all parameter creates both the ILM and XILM models.

-no_core_sdc

Does not create the core SDC data for ILM/XILM models.

-no_spef

Does not generate the SPEF data for ILM and XILM models.

-no_xtwf

Does not create the xtwf data for ILM/XILM models.

Note: When the -no_core_sdc and -no_xtwf parameters are specified, write_ilm does not call any delay or timing calculation and skips creating both the SDC and XTWF files for ILM/XILM models.

-validation_dir

Creates a script and necessary data used to validate ILM/XILM.

-write_sdf

Creates an SDF file that is based only on the logic kept in the ILM model after netlist is trimmed. In the MMMC mode, one SDF file is written for one view.

Examples

  • The following command generates the ILM ignoring certain ports and including certain objects in the BlockB directory. It also writes out the ILM SDF file under the BlockB directory.
    ilmview > write_ilm -write_sdf -ignore_ports $ignorePorts include_objects $includeObjects -dir BlockB
  • In SMSC designs, the following command generates ILM files in the three subdirectories (ilm_setup, ilm_hold and si_ilm_setupHold) under directory BlockB:
    ilmview > write_ilm -dir BlockB
  • In MMMC designs, the following command generates ILM files in the one subdirectories (MMMC) under directory BlockB:
    ilmview > write_ilm -dir BlockB
