gui_report_ruler

gui_report_ruler -help

Reports the coordinates for all rulers in the main window.

To check the ID of a ruler, select the Create Ruler widget and hover the cursor over the ruler – the ruler ID is displayed on the status bar, as shown below. 

Parameters

-help

Prints a brief description of the gui_report_ruler command.

For a detailed description of the command, use the man command:
man gui_report_ruler

Example

  • The following command reports the coordinates of all rulers:
    > gui_report_ruler 
    The command returns the ruler coordinates, as shown below:   
    {Ruler-1 coords: {248.4450 146.9800} {247.4550 12.6400}} {Ruler-0 coords: {13.8450 226.4950} {87.9300 225.0150}}
