distribute_read_db

distribute_read_db  
[-help]
[-client_log_file string] 
-out_dir string
[-read_cellview {directory cell_name}] 
{-design_script string | [-read_db string [-read_dir string]]}

Opens up N number of Tempus clients (as set with set_multi_cpu_usage) for a distributed processing session, and loads the design script on Tempus clients.

The distribute_read_db command is used for distributed multi-mode multi-corner (DMMMC) timing analysis only.

Parameters 

-help Prints out the command usage.
-client_log_file logFilePathName

Redirects client logs to a new location. By default, Tempus client logs are created in the directory specified with the –out_dir option.

-design_script string

Specifies the design loading script. The script contains the common information that needs to be shared by all Tempus client runs. The script must include the design loading commands, as well as all MMMC configuration commands. The script must not include parasitic file loading commands (read_spef), analysis view setting commands (set_analysis_view) or the view specific settings like constraints through set_interactive_constraint_modes.

Timing derates settings (set_timing_derate) are corner specific and can be specified in this script.

-out_dir string

Specifies the directory where the run is to be executed. All data from the distributed analysis runs will be available in this directory. The software generates view-specific reports in directories with the corresponding view name within this directory.
-read_cellview {directory cell_name} Specifies the “directory” as a directory name having OpenAccess library name/OA cell and “cell_name” refers to the OA cell name.

-read_db string

Specifies the design views (previously saved using the distribute_views -write_design command) to be restored for both setup and hold analysis.

The number of sessions specified for restore can not be more than the machines specified with -remoteHost setting.

-read_dir string

Specifies the directory location which has the saved design views (that were previously saved using the distribute_views -write_design command) to be restored.

Examples

Here are some examples.

  • The following example command script lists the commands used to perform distributed multi-mode multi-corner timing analysis: 
    tempus > set_multi_cpu_usage -remoteHost 4 
    tempus > distribute_read_db \ 
    -design_script /stm1/timing/demo_dist_proc/preamble.tcl \ 
    -out_dir $output_directory 
    #preamble.tcl script includes design loading commands and MMMC configuration commands 

    set Views [list lmin-rmax lmax-rmin lmax-rmax] 
    tempus > distribute_views \ 
    -views $Views \ 
    -script /stm1/timing/demo_dist_proc/commands.tcl 
    #commands.tcl script contains read_spef and report commands 

    tempus > reset_servers
  • The following example command script lists the commands used to save a design in distributed multi-mode multi-corner mode: 
    tempus > set_distributed_hosts -local | -rsh ... 
    tempus > set_multicpu_usage -remoteHosts N 
    tempus > distribute_read_db -design_script dmmmc.tcl -out_dir output 
    set Views [list lmin-rmax lmax-rmin lmax-rmax] 
    tempus > distribute_views -views $Views -script dmmmc_report.tcl -write_design all
  • The following example command script lists the commands used to restore a saved session (with N views) in distributed multi-mode multi-corner mode: 
    tempus > set_distributed_hosts -local 
    tempus > set_multicpu_usage -remoteHosts N 
    set Views [list lmin-rmax lmax-rmin lmax-rmax] 

    tempus > distribute_read_db -read_db $Views -read_dir output -out_dir new_output 
    # output is the same directory used in above example where views were saved.

    tempus > distribute_command {source dmmmc_reports2.tcl} 
    # dmmmc_reports2.tcl can have analysis commands but do not need read_spef etc.
  • The following example restores the dtmf_chip OpenAccess design, which is saved at the path, /home/cdns/oa_dir:
    tempus > set outDir “/home/cdns/” distribute_read_db -read_db {view1 view2} -read_dir $outDir -read_cellview {oa_dir dtmf_chip} -out_dir output
