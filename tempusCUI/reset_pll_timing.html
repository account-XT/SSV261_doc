reset_pll_timing

reset_pll_timing 
[-help]
inst
-pll_output_clock clock name or ID
-pll_output_pin output pin name

Resets the phase locked loop (PLL) that is used to adjust the delay on the PLL output clock waveform.

Parameters

-help

Prints out the command usage.

inst

Specifies the instance on which we will search reference pin, feedback pin, or output pin.

-pll_output_clock clock name or ID

Specifies the PLL output clock.

-pll_output_pin output pin name

Specifies the PLL output pin.
