write_ml_library

write_ml_library
[-help] 
[-objects object_list]
-prefix string

Writes library-related data for JedAI to csv files with the specified prefix. It includes data that is library specific and relates to lib_cells, timing_tables, and power_tables.

Parameters

-help

Prints a brief description that includes the type and default information for each write_ml_library parameter.

For a detailed description of the command and all of its parameters, use the man command
man write_ml_library.

-objects object_list

Specifies the list of db object(s) to be dumped, which could include one or more of the following values:

lib_arc lib_cell lib_feature lib_pin library library_set power_table timing_table

Use curly braces to enclose multiple values.

Data_type: tcl_obj, optional

-prefix string

Specifies the prefix for the output files.

Data_type: string, required

Example

  • The following command writes library-related data for JedAI to csv files with the specified prefix:
    write_ml_library -prefix out/
