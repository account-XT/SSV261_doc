create_hport

create_hport
[-help] 
[-bus msb:lsb]
-direction {in out inout}
-name hport_name 
[-parent module|hinst|design]

Create new hports and corresponding hpins for the parent object.  It also implicitly creates hnet and net objects inside the parent object with the same name as the new hport. If the new hport is a bus, then the bus_bits objects are also created. The hnet object has no corresponding hnet or net object but is left dangling. It returns the newly created hport object pointer.

Parameters

-bus msb:lsb

Specifies the bit range for bus hports. You must separate the start and end IDs with a colon (:). If there is an existing bus (for example, 3:0) then additional bits can be added provided they are adjacent to the existing bits (7:4 for example).

By default, the tool creates a scalar hport.

Data_type: string, optional
-direction {in out inout}

Specifies the direction of the new port, in, out, inout.

Data_type: enum, required
-help

Outputs a brief description that includes the type and default information for each create_hport parameter.

For a detailed description of the command and all of its parameters, use the man command: man create_hport
-name hport_name

Specifies the name of the new hport. If this is the full hierarchical path, then the parent will be derived from the name (i.e. the parent name is the string before the last "/".  In this case, the base_name of the new hport (i.e. the string after the last "/") should not have any special characters that require escaping. When the -parent option is used, then the name is the base_name of the new hport.  If the name has any illegal chars, it will be automatically escaped.  Therefore, -name "hp1/2" will result in "hp1\/2" for the .escaped_name, since it uses DEF escaping semantics. This is equivalent to checking if hport_name is a legal Verilog identifier, and if not, prepend \ and add a trailing space to the internal Verilog name.

Data_type: string, required
-parent module|hinst|design 

Specifies the parent for the new hport.

Data_type: (hinst|design|module), optional

Example

     CPU

      |

      +----------------+

      |                |

      H1 (alu)         H2 (fsm)

      |

      +----------------+

      |                |

     + H1 (add)        H2 (mult)



  • The following command creates new scalar objects hpin:CPU/H1/H1/P1, hport:CPU/H1/H1/P1, and hnet/net H1/H1/P1.
    create_hport -name P1 -parent add -direction in
  • The following command creates a new 8-bit objects hpin:H1/H2/BP1, hport:H1/H2/BP1, and hnet/net H1/H2/BP1.
    create_hport -name BP1 -parent H1/H2 -bus 7:0
  • The following command creates new scalar objects hpin:CPU/H1/H2/P2, hport:CPU/H1/H2/P2, and hnet/net H1/H1/P2.
    create_hport -name H1/H2/P2 -direction out
  • The following commands add a single bit to an hport:
    get_db hports *data_in*
    {hport:cpu/H1/data_in[3]} {hport:cpu/H1/data_in[2]} {hport:cpu/H1/data_in[1]} {hport:cpu/H1/data_in[0]}
    create_hport -parent H1 -name data_in -bus 4:4 -direction in
