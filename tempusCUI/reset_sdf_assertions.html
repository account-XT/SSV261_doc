reset_sdf_assertions

reset_sdf_assertions

Resets the SDF delays to the values defined in the library. When you perform timing analysis, the software uses the SDF values defined with the read_sdf command.

You can use this command to discard the delay values specified with the SDF files, and use the delays defined in the library.

Note: You do not need to read in the SDF delays every time you perform delay calculations. The software uses the SDF files specified earlier in the flow.

Parameters

-help Prints out the command usage.

Related Commands

  • read_sdf
