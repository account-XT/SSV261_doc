report_socv_interconnect_variation

report_socv_interconnect_variation 
[-help]
[-delay_corner string]
[-power_domain string]

Reports the RC variation multiplier data provided in the SOCV files.

Parameters

-help Prints out the command usage.
-delay_corner string Specifies the name of the delay corner.
-power_domain string Specifies the name of the power domain.

Examples

  • The following command generates the below output for the specified delay corner:
    report_socv_interconnect_variation -delay_corner delay_corner_FUNC_PVT_ss_0p72_m40_rcmax

    Delay Corner: delay_corner_FUNC_PVT_ss_0p72_m40_rcmax

    ----------------------------------------------------------------------------------------------------------------------------------------------

    | Power Domain                                            | Voltage  | Data   | Data   | Data   | Data   | Clock  | Clock  | Clock  | Clock  |

    |                                                         | (in V)   | Rise   | Rise   | Fall   | Fall   | Rise   | Rise   | Fall   | Fall   |

    |                                                         |          | Early  | Late   | Early  | Late   | Early  | Late   | Early  | Late   |

    ----------------------------------------------------------------------------------------------------------------------------------------------

    | -                                                       | 0.72     | -      | -      | -      | -      | -      | -      | -      | -      |

    ----------------------------------------------------------------------------------------------------------------------------------------------

    | PD_WIFICORE                                             | 0.72     | -      | -      | -      | -      | -      | -      | -      | -      |

    ----------------------------------------------------------------------------------------------------------------------------------------------

    | PD_MXRAMWRAP_VCCD                                       | 0.72     | -      | -      | -      | -      | -      | -      | -      | -      |

    ----------------------------------------------------------------------------------------------------------------------------------------------

  • The following command generates the below output for the specified power domain:
    report_socv_interconnect_variation -power_domain _internal_VDD_0P9_BT2XTAL_GND_BT2XTAL_

    Delay Corner: delay_corner_FUNC_PVT_ss_0p72_m40_rcmax

    -----------------------------------------------------------------------------------------------------------------------------

    | Power Domain                           | Voltage  | Data   | Data   | Data   | Data   | Clock  | Clock  | Clock  | Clock  |

    |                                        | (in V)   | Rise   | Rise   | Fall   | Fall   | Rise   | Rise   | Fall   | Fall   |

    |                                        |          | Early  | Late   | Early  | Late   | Early  | Late   | Early  | Late   |

    -----------------------------------------------------------------------------------------------------------------------------

    | _internal_VDD_0P9_BT2XTAL_GND_BT2XTAL_ | 0.72     | -      | -      | -      | -      | -      | -      | -      | -      |

    -----------------------------------------------------------------------------------------------------------------------------
