distribute_launch_deferred_clients

distribute_launch_deferred_clients 
[-help]

Launches the clients and waits for them to become available.

When the distribute_start_clients -defer_launch parameter is specified, the clients are not launched until the launch command is run.

The distribute_launch_deferred_clients command can be run at any point after distribute_start_clients -defer_launch option is specified, but should be specified no later than immediately after the distribute_partition command. Most commands after this point will require clients to be running.

Parameters

-help

Prints out the command usage.
