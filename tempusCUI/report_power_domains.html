report_power_domains

report_power_domains
[-help]
[-bind_lib]
[-insts inst_name]
[-iso_inst]
[-modules {list_of_modules}
[-nets net_name]
[-out_file outFile]
[-pg_nets]
[-pins]
[-power_domain powerDomainName [-check_pg_scope]]
[-power_domain_boundary_port string]
[-power_domain_coverage pd1 pd2]
[-shifter]
[-supply_crossing supp1 supp2]
[-verbose]
[-voltage] 

Reports information about power domains. The report includes the following attributes:

  • Power domain name
  • Power domain bounding box
  • Timing library
  • Mingap
  • RS extension
  • Row type
  • Row spacing

The command also reports whether the power domain is always on.

Parameters

-help

Outputs a brief description that includes type and default information for each report_power_domains parameter.

For a detailed description of the command and all of its parameters, use the man command:
man report_power_domains.

-bind_lib

Reports the timing libraries available for instance binding including voltage scaling. However, the actual libraries that are used by the AAE delay calculation might be a subset of the timing libraries reported by this command. 
-check_pg_scope

Checks if there are any PG connections that cross UPF-defined scope. All PG connections for UPF scope should be at the boundary PG port. This parameter is used with the -power_domain parameter.

-insts inst_name

Reports the power domain-related information for the specified instance: the input, output, and power/ground connections.

-iso_inst

Reports all isolation cells in the power domain.

-modules {list of modules}

Checks whether the specified instances or hierarchical instances are in the power domain.

Default: The software does not perform this check.

-nets net_name

Reports power domain-related information for the specified net:

  • The driver instance of the net and its power domain.
  • The receiver instances of the net and their power domains.

-out_file outFile

Specifies the name of the output file.

Default: designName-powerdomain.rpt

-pg_nets

Reports all the power/ground nets in the power domain.
-pins pin1, pin2 ... Lists the pins and the option is of type string. This option is optional.

-power_domain powerDomainName

Specifies the power domain whose attributes you want to report.

Default: If you do not specify the power domain, this command report data about all power domains.
-power_domain_boundary_port string

Reports if the specified port name of the power domain boundary has an IEEE1801 constraint.
-power_domain_coverage pd1 pd2

Reports the coverage between two specified domains.

-shifter

Reports all shifters in the power domain.
-supply_crossing supp1 supp2

Reports if the two specified supplies have the on/off and low/high crossing.
-verbose Prints out the detail information and is optional.
-voltage Reports domain voltage.

Examples

  • The following command reports the power domain-related information for the specified instance:
    report_power_domains -insts i4 -verbose -bind_lib            

Analyzing i4 (Cell: BUFX1) power domain: AO

------- from side --------

  Pin A => Net n4

    sub_inst1/i4/Q in power domain AO

------- to side --------

  Pin Y => Net n5

    sub_inst2/LIN/a in power domain PD1 connected to domain AO

=============PG pins =================

VSS connected to Net: VSS

VDD12 connected to Net: rail1


VSS is connected to net:VSS by CPF GNC rule: -net VSS -pins  VSS -powerDomain AO

VDD12 is connected to net:rail1 by CPF GNC rule: -net rail1 -pins  VDD12 -powerDomain AO

  • The following command reports the attributes of the specified power domain in the out.lib file: 
    report_power_domains -power_domain pd_VDDalive -out_file out.lib

 =========================================

   Voltage = 0.0000

   Timing Lib:

   Setup View: Setup_SSG_m40C

   Hold View: Hold_SSG_m40C

   rsExts  = T:0.0000 B:0.0000 L:0.0000 R:0.0000

   core2Side = T:0.0000 B:0.0000 L:0.0000 R:0.0000

   rowSpaceType = 2

   rowSpacing = 0.0000

   rowFlip = noFlip

   AlwaysOn = 0

  • The following command reports the timing libraries available for instance binding for the specified power domain:
    report_power_domains -power_domain pd_VDDalive -bind_lib -out_file out.lib

report_power_domains -power_domain pd_VDDalive -iso_inst -out_file out.lib
