get_clock_to_clock_association

get_clock_to_clock_association
[-help]
clock_list
[-allow_paths]
[-group_name group_name]
[-type {logically_exclusive | physically_exclusive | asynchronous}]
[-view viewName]

Reports clock to clock associations.

Parameters

-help

Prints out the command usage.

clock_list

Specifies a list of clocks that must contain two entries.

-allow_paths

Checks whether the two specified clocks are asynchronous and timing analysis is allowed between these clocks.

-group_name group_name

Reports clock to clock association for the specified clocks along with the clock group name.

-type {logically_exclusive physically_exclusive asynchronous}

Checks clock to clock association for the specified type of clocks. You can use one of the following options:

  • logically_exclusive: Reports clock group with clocks that do not have any functional paths between them, but coexist in the design at the same time.
  • physically_exclusive: Reports clock group with clocks that cannot exist in the design at the same time.
  • asynchronous: Reports clock group with asynchronous clocks. Asynchronous clocks have no specified phase relationship.

-view viewName

Generates a report for the specified analysis view.
