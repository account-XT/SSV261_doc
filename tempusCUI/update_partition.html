update_partition

update_partition
[-pin_location]
[-post_eco_suffix postECOSuffix] 
{-flex_ilm_eco}
{-golden_block_dir directory}
-flex_ilm_dir directory
[-eco_dir directory]
[-full_netlist_with_eco_dir directory -flex_ilm_eco_dir directory]

Creates a new partitioned output that contains the optimised blocks and top. It also performs ECO on the original block. The ECO output is saved as new Tempus database in the partitioned block. The ECO would happen only on flexILM partitions and not the regular blocks.

Note: The ILM is not supported for Signoff in Tempus.

Parameters 

-eco_dir directory

Specifies the scratch directory for partitioning and running distributed ECO job after optimization.

-flex_ilm_dir directory

Specifies the new partitioned output directory containing optimized blocks/top and ECO results.

-flex_ilm_eco

Performs ECO on FlexILM modules.

Note: This is default.
-flex_ilm_eco_dir directory Specifies the directory to store the ECO job.
-full_netlist_with_eco_dir directory

Specifies the directory to store the ECO result of the full netllist.
-golden_block_dir directory Specifies the golden database directory for individual blocks.
-pin_location Updates new partition pin locations into the golden block DB. This option does not allow new added logic ports.
-post_eco_suffix postECOSuffix Specifies the suffix name that will be part of generated postECO DB name.
