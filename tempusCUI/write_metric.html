write_metric

write_metric
[pattern] 
{-out_file fileName}
[-format output_format] 
[-id metric_id] 
[-merge] 
[-names list_of_patterns] 

Writes the current set of metrics to a file or stdout.   

The write_metric command is used by write_db to write the metrics in the JSON format in the database directory. Super commands use write_metric to write metrics into the log file (stdout). This can also be used to write metrics in various formats by the user.

Parameters

-out_file fileName Specifies the name of the file in which metrics is written.
-format output_format

Specifies the output format, json, xml, csv, tcl.

Default: JSON
-help

Outputs a brief description that includes type and default information for each write_metric parameter.
For a detailed description of the command and all of its parameters, use the man command:

man write_metric
-id metric_id 

Specifies a list of labels from read_metrics. 

Default: Current metric
-merge Merges the results into an existing file.
-names  list_of_patterns Specifies the list of patterns to match snapshot names.
pattern List of regular expressions to chose metrics to write. Default is all metrics (*)

Example

The following code shows the usage of the write_metric command:

# --------------------------------------------------------------------

# Generate a XML file for all timing, power, and flow metrics from

# from prects to postcts for a previous run (id v101)

# --------------------------------------------------------------------

read_metric –id v101 run101/dbs/postcts.enc.dat/design.metrics

write_metric –id v101 –format xml
