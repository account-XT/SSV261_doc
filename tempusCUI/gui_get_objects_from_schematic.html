gui_get_objects_from_schematic

gui_get_objects_from_schematic
[-name string]
-type {all insts modules nets ports}

Gets all or the specified type of objects from the current (active) or specified schematic view. 

Parameters

-help

Prints a brief description of the gui_get_objects_from_schematic command.

For a detailed description of the command, use the man command: man gui_get_objects_from_schematic.
-name string

Specifies the name of the schematic view from which objects need to be returned. You can use the gui_get_schematic command to get the name of the schematic. If -name is not specified, returns objects from the current schematic view.

Data_type: string, optional
-type {all insts modules nets ports}

Specifies the type of the objects to be returned. If all is specified, returns the name of all objects from the current or specified schematic view.

Data_type: enum, required

Examples

  • The following command returns the instances from the current schematic:
    > gui_get_objects_from_schematic -type insts
    Sample output:
    ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/FE_OFC1329_q02_8_ ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/FE_OFC1326_q02_10_ ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/TESTACT_WSRAM/assignbuf_709853 ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U170 ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U182 ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U184 ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U187 ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U189 ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U202
  • The following command returns the nets from the schematic view named W0:
    > gui_get_objects_from_schematic -name W0 -type nets
    Sample output:
    ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/n7 ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/tpo_a_9_ VSS VDD
