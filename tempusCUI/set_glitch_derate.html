set_glitch_derate

set_glitch_derate  
[-help]
[-derate_height float]
[-derate_width float]
[-glitch_type string]
[-instance_pin string]
[-offset float]
[-pin string]
[-view string]

Sets the derating factors for glitch waveforms and determines the effect of on-chip variation on noise.

Parameters

-help

 Prints out the command usage.

-derate_height float

Specifies the derate height value.

This parameter scales all the glitch waveforms on the specified pins.

A value of 1.0 indicates that no glitch waveform derating will take place. A value greater than 1.0, such as 1.1, indicates a 10 percent increase in the magnitude of the complete glitch waveform, which results in an increase in propagated noise and noise failure. A value less than 1.0 reduces the magnitude of the complete glitch waveform.
-derate_width float Specifies the derate width value.

-glitch_type string

Specifies the glitch type - vl, vh, or all.
-instance_pin string Specifies the instance pin names on which derate is to be applied.
-offset float Specifies the derate offset value.

-pin string

Specifies the library pin names on which derate value is to be applied.

-view string

Specifies the name of the view.
