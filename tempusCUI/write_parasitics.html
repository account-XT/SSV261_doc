write_parasitics

write_parasitics 
[-help]
[-exclude_ilm]
[-no_resistances]
[-use_eeq_cell_with_liberty_info]
{{{-spef_file file_name} [-exclude_nets_file file_name | -include_nets_file file_name | -net_name list_of_nets]} } [-view view_name | -rc_corner rc_corner_name] [-cap_unit {pf | ff}]

Reads the parasitic database and outputs the parasitics in the Standard Parasitic Exchange Format (SPEF).

Parameters

-help Outputs a brief description that includes type and default information for each write_parasitics parameter. For a detailed description of the command and all of its parameters, use the man command: man write_parasitics.

-cap_unit {pf | ff}

Specifies the unit of capacitance as fF or pF in the output SPEF file.

Default: pf
-exclude_ilm

Writes out only the top-level SPEF while excluding the ILM parasitics. For example,

write_parasitics -exclude_ilm -spef abc.spef -rc_corner corner1

-exclude_nets_file file_name  

Specifies the name of the file that contains nets to be excluded from the output file.

-include_nets_file file_name

Specifies the name of the input file that contains the net names to be extracted.

Default: Extracts all net names
-net_name list_of_nets

Specifies the names of the nets to be written in the SPEF file.

Default: Writes all nets

-no_resistances

Generates a SPEF file without the resistance information. The SPEF file generated by this parameter can only be used to improve the performance of third-party simulator tools in early stages of the design.

Caution: Most tools expect the resistance information to be present in the SPEF file for performing extraction. Therefore, SPEF files with no resistance information should not be used with ostrich for RC correlation.
-rc_corner rc_corner_name Specifies the RC corner that is used to generate the parasitic output file in the multi-corner flow.
-spef_file file_name

Specifies the name of the SPEF output file.
-use_eeq_cell_with_liberty_info

Writes EEQ master cell in case the EEQ cells are present.

-view view_name

Specifies that the RC corner associated with the specified view is used to generate the output SPEF file in the multi-corner flow.

Examples

  • Reads the parasitic database created during RC extraction and writes the interconnect capacitance in the SPEF format to the file TOPCHIP_SP.spef for RC corner, corner1: 
    write_parasitics -rc_corner corner1 -spef_file TOPCHIP_SP.spef
  • Reads the parasitic database created during RC extraction for the view, view1:
    write_parasitics -view view1
