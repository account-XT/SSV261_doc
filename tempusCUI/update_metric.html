update_metric

update_metric
[-help]
[-format {html excel text}]
[-graph_type {treemap line none}]
[-group group_title]
[-header header_name]
[-link_file_metric metric_name]
[-link_table table]
[-metric metric_name]
[-no_shared_max]
[-renderer html_format]
[-show_graph]
-table table_id 
[-title html_table_title]

Updates a metric.

Parameters

-format {html excel text} Specifies configuration for the specified report_metric format.
-graph_type {treemap line none}

Specifies the type of graph to use in the table (treemap |line |none).

Default: line
-group group_title Specifies the group title to be used in the html table.
-header header_name Specifies the header name to be added.
-help

Prints out the command usage.
For a detailed description of the command, use the man command:
man update_metric
-metric metric_name Specifies the metric name to be added.
-no_shared_max When specified for a -renderer histogram metric, the Y axis of all the histograms in a single column stop sharing the same max Y value.
-link_file_metric metric_name Specifies the name of the metric containing filename to open when the metric value is clicked.
-link_table table Specifies the table to scroll to when the metric value is clicked.
-renderer html_format Forces a specific html format renderer for the histogram metric.
-show_graph Specifies whether to show this metric in a comparison graph.
-table table_id  Specifies the id of table to which the metric will be added.
-title html_table_title Specifies the title to be used in the html table.
