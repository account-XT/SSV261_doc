write_to_gif

write_to_gif
[-help]
out_file
[-honor_umask]

Saves a snapshot of the current screen to a GIF file with the specified name in the current directory. You can use this command at any stage of the design flow.

Parameters

-help

Prints a brief description that includes type and default information for each write_to_gif parameter.

For a detailed description of the command and all of its parameters, use the man command:
man write_to_gif.

out_file

Specifies the name of the output file as a string.
-honor_umask

Honors the umask settings while saving the GIF file. If you specify this option, the permission of the saved GIF file will be set by subtracting the umask value from the full permission value.

For example, if the full permission of file is 0666 and the umask setting is 0022, the tool saves the GIF file with the permission setting of 0666 - 0022, that is 0644.

Data_type: bool, optional

Example

The following example captures the current screen and saves it to test1.gif in the current directory.

write_to_gif test1.gif
