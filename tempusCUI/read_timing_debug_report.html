read_timing_debug_report

read_timing_debug_report
[-help]
[-name report_name]
[{-proto [-slack_margin number]  [-num_path number]}]
[-num_path] 
timing_report_filename 

Loads the violation report in Tempus for debugging timing results.

The violation report that you specify using the read_timing_debug_report command is in the output binary format, which you can generate through the binary value of the report_timing -output_format command parameter.

Note: The violation report that you specify in this command has a special machine readable format. Use the report_timing -output_format gtd command to generate the machine readable violation report.

Parameter 

-help

Outputs a brief description that includes type and default information for each read_timing_debug_report parameter.

For a detailed description of the command and all of its parameters, use the man command:
man read_timing_debug_report
timing_report_filename

Specifies the name of the timing debug timing_report_file.

-name

Specifies the report name to load the machine readable timing report timing_report_files incrementally.

-num_path

Specifies the number of paths to be reported in the detailed path violations.

{-proto [-slack_margin number]  [-num_path number]}

Creates flex model categories and displays the top path of the top 8 (by default) categories. This option can be used for design that has flexModels.

Use –additional_slack_past_wns to report all paths with slack worst than (WNS and additional specified slack value).

Use –num_path to control the number of violation paths.

Examples:

  • The following command loads the machine readable timing report top.btarpt:
    read_timing_debug_report top.btarpt
  • The following commands load two machine readable timing reports top1.btarpt and top2.btarpt together:
    read_timing_debug_report -name default_report top1.btarpt
    read_timing_debug_report -name default_report top2.btarpt
    GTD will first load the report top1.btarpt, then append top2.btarpt incrementally to the current report.
    Note: The name can be specified by user with any string, it is not the timing_report_file name.
