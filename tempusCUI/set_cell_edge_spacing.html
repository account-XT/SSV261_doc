set_cell_edge_spacing

set_cell_edge_spacing 
[-help] 
{<type1> <type2>
-spacing spacing
[-except_exact_spacing distance]
[-except_abutted | -forbidden_spacing ][-except_non_filler_in_between] } | [-reset]


Creates the cell edge spacing rule as in CELLEDGESPACINGTABLE in LEF.

The tool by default supports the latest Tcl settings. If a user tries to change the edge spacing, the tool will generate a warning message that resetting edge spacing would overwrite the old value.

Note: This command is not supported for save and restore design.

Parameters 

-except_abutted Specifies that two abutted macros of the given edge types are also allowed.
-except_non_filler_in_between

Specifies that the edge spacing is only for adjacent instances.

If two MACROs (cells) have a edge-spacing rule, say 0.8 micron, then normally the rule applies regardless of presence of another macro (cell) in the gap between. When the -except_non_filler_in_between option is used, the rule is exempted when a non-filler cell is present between the two constrained cell edges.
-except_exact_spacing distance

Specifies an exception distance to the minimum spacing.

Data_type: double, optional
<type1> Specifies edge type1 for edge spacing. 
<type2>

Specifies edge type2 for edge spacing.
-forbidden_spacing Forbids edgeType1 and edgeType2 without the space.
-help

Outputs a brief description that includes type and default information for each set_cell_edge_spacing parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_cell_edge_spacing  
-reset Resets the cell edge spacing to LEF. 
-spacing spacing

Specifies edge spacing between edgeType1 and edgeType2.

If there is no spacing defined between two edge types, it indicates that there is no spacing constraint (or 0.0 µm) between them.

Example

The following command creates 0.18 µm spacing between grp1 and grp2:

set_cell_edge_spacing grp1 grp2 0.18
