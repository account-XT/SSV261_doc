opt_signoff

opt_signoff
[-help]
[-area]
[-drv]
[-dynamic]
[-hold]
[-leakage]
[-power]
[-setup]
[-update_timing]

Triggers ECO. Depending on the opt_signoff category attributes settings, it will either auto generate the ECO Timing DB or load existing one, then proceed to the timing fixing phase and finally output an ECO file and detailed diagnostics in log file.

Note: This command requires a 64-bit executable.

Parameters 

-help

Outputs a brief description that includes type and default information for each opt_signoff parameter.

For a detailed description of the command and all of its parameters, use the man command: man opt_signoff.
-area Reclaims area on the netlist without causing any DRV/Setup/Hold degradation.

-drv

Optimizes DRV violations. DRV optimization fixes violations in the following order:

  1. glitch
  2. drv (max_transition/max_capacitance violations)
  3. xtalk delta delay

Note:

  • DRV optimization supports buffer addition and resizing.
  • CellEM violations are fixed only when set_db opt_signoff_fix_cell_em is set to true.
-dynamic

Prints initial and final power numbers. It optimizes the dynamic power to reduce the total power consumption.  
-hold Optimizes hold violations.

-leakage

Optimizes leakage power. Leakage optimization supports VT swapping.
-power Optimizes total power in the design. During total power optimization, the software performs swapping and sizing on both the combinational and sequential cells, and also do buffer removal when enabled. It reduces leakage, internal, and switching power in the design.

-setup

 Optimizes setup timing violations. Setup optimization supports buffer addition, VT swapping and resizing.
-update_timing

Generates the updated timing data to be used during optimization.

Note: This parameter is applicable only for the Tempus Paradime flow or Certus. It is only valid if opt_signoff_allow_multiple_incremental is true.

Examples

  • The following commands are used to annotate the parasitics of three active RC corners in the design using SPEF files before running timing analysis or opt_signoff:

    tempus> read_spef -rc_corner rc_max max.spef.gz
    tempus> read_spef -rc_corner rc_min1 min1.spef.gz
    tempus> read_spef -rc_corner rc_min2 min2.spef.gz

  • The following command performs hold fixing while not degrading setup timing:

    tempus> opt_signoff -hold

  • The following command recovers area by performing cell downsizing and buffer deletion while ensuring not to create any new Setup/Hold/DRV violations.

    tempus> opt_signoff –area  

  • The following command runs multiple types of optimization in incremental mode and generates new ECO DB (assuming opt_signoff_read_eco_opt_db is not used). It also generates the new timing data to be used during power and setup optimizations. 

    set_db opt_signoff_allow_multiple_incremental true
    opt_signoff -drv
    opt_signoff -setup
    opt_signoff -hold
    opt_signoff -power -update_timing
    opt_signoff -setup -update_timing
