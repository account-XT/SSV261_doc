write_eco

write_eco 
[-help]
-format {innovus tempus}
-hierarchical
out_file 
-prefix <prefix>
[-skip_non_eco_commands]

Logs ECO commands into an output file per file format. You can later load the files in the following ways:

  • Source the innovus format file in the Innovus tool
  • Source the tempus format file into the Tempus tool

The following commands can be appended to the report file:

  • create_net
  • delete_nets
  • create_inst
  • delete_inst
  • connect_net
  • disconnect_net
  • eco_update_cell
  • eco_add_repeater
  • eco_delete_repeater

Parameters 

-format {innovus tempus}

Generates an ECO file in the specified format.
-hierarchical Generate an ECO file for optimized partitions.

out_file

Specifies the name of the file generated using this command.
-prefix <prefix> Specifies the prefix to be used in naming the output ECO file.
-skip_non_eco_commands Removes all non-ECO commands, which are not specified by the user from the automatically generated ECO files.

Examples

  • The following command logs ECO commands into file Tempus.eco, in the tempus format: 
    write_eco -format tempus Tempus.eco
  • The following command logs ECO command into file innovus.eco, in the innovus format: 
    write_eco -format innovus innovus.eco
  • The following command removes all non-ECO commands from the automatically generated ECO file, opt_eco_tempus_cui.tcl:
    write_eco opt_eco_tempus_cui.tcl -format tempus -skip_non_eco_commands
