extract_parasitics

extract_parasitics
[-help]

Extracts resistance and capacitance for the interconnects and stores the results in an RC database. Optionally, an ASCII report file can be generated. Use this command after performing trial routing or final routing, and after setting the extract_rc Category Attributes.

Parameter

-help

Outputs a brief description of the extract_parasitics command. For a detailed description of the command, use the man command: man extract_parasitics.

Example

The following command extracts interconnect resistance and capacitance:

extract_parasitics

RC database is created.

The extract_parasitics command can be followed by the write_parasitics command to extract the parasitics from the RC database, and to generate an ASCII report containing the database information. You can find all the extraction reports in the extLogDir.
