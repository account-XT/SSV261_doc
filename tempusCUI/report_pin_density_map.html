report_pin_density_map

report_pin_density_map 
[-help] 
[-step step_value]
[-grid_unit micron] 
[-grid_length numberRow]
[-threshold density]

Generates a map that uses colors to represent pin density and generates a pin density report. Use this command any time after placement.

Parameters

-help

Outputs a brief description that includes type and default information for each report_pin_density_map parameter.

For a detailed description of the command and all of its parameters, use the man command: 

man report_pin_density_map

-step step_value

Specifies the range step for displaying the pin density map.

Default: 0.05

-grid_unit micron

Specifies the value of side of square grid for pin density calculations.

Default: 50
Minimum: 0.000000
Maximum: 1000.000000

-grid_length numberRow

Specifies the value (in row-height) of side of square grid for pin density calculations.

Default: 10
Minimum: 1
Maximum: 100

 -threshold density

Specifies a threshold density value over which the densities must be reported. Any grid under the threshold value is not reported. The value must be positive.

Default: 0.5
Minimum: 0.000000
Maximum: 2.000000

Examples

The following command reports the pin density map:

report_pin_density_map
*** Starting report pin density ***
default core: bins with pin density > 0.5 = 0 % (0 / 1)
bin size: 90 sites by 10 row(s). total 1 bins ( 1 by 1 )
pin density range   #bins     %
total                 0       0
