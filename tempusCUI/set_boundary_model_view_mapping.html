set_boundary_model_view_mapping

set_boundary_model_view_mapping 
[-help]
-block_view <string>
-top_view <string>

Provides the boundary model view mapping data.

Parameters

-help Prints out the command usage.
-block_view <string> Specifies the name of the block view.
-top_view <string>  Specifies the name of the top view.

Examples

  • The following command specifies the block view name as bview, and the corresponding view name at the top level is tview:
    set_boundary_model_view_mapping -block_view bview -top_view tview
