get_legacy

get_legacy
-help
common_ui_cmd_attr_name

Returns the legacy command, legacy Tcl global, or legacy setXXXMode -option that corresponds to the specified Stylus Common UI command or root attribute.

Parameters

-help

Outputs a brief description that includes type and default information for each get_legacy_command parameter.
For a detailed description of the command and all of its parameters, use the man command:

man get_legacy
common_ui_cmd_attr_name

Specifies the Stylus Common UI command name or attribute name.

Data_type: string, required

Examples

  • The following command returns the set_ilm_mode option that corresponds to the Stylus Common UI attribute ilm_keep_high_fanout_ports:

    @tempus 1> get_legacy ilm_keep_high_fanout_ports
    Mode option: set_ilm_mode -keepHighFanoutPorts


  • The following command returns the legacy Tcl global that corresponds to the Stylus Common UI attribute init_lef_files:
    @tempus 2> get_legacy init_lef_files 
    Tcl global: init_lef_file
