check_power_domains

check_power_domains
[-help]
[-all_inst_in_power_domain]
[-always_on_bias]
[-always_on_buffer_type]
[-antenna_diode {fileName ...}]
[-cell_bind {cell ...}]
[-drc_file string]
[-lib_binding_voltage]
[-lib_cell_binding]
[-global_connection [module_name_list]]
[-nets_missing_iso [fileName]
[-ignore_net_to_port_iso]
[-ignore_net_to_port_shifter]
[-place [-place_report report_name]]
[-power_switch]
[-power_within_min_gap]
[-retention {fileName ...}]
[-nets_missing_shifter [fileName] [-ignore_net_to_port_shifter]]

Verifies whether the power domains are set up correctly in terms of timing library binding and PG connection. This command also checks whether any power domains overlap. The check_power_domains command checks that libraries specified for each power domain of each dc_corner are complete for each power domain member list.

Parameters 

-help

Outputs a brief description that includes type and default information for each check_power_domains parameter.

For a detailed description of the command and all of its parameters, use the man command:
man check_power_domains.

-all_inst_in_power_domain

Verifies all instances are in the power domain.
-always_on_bias Checks the always_on_bias net connection.
-always_on_buffer_type

Checks if the AO buffer in each domain has correct type in terms of AO Nwell design and IEEE1801 Nwell specification.

Data_type: bool, optional
-antenna_diode {fileName ...}

Verifies antenna diode-related low power violations for the specified file.
-cell_bind {cell ...} Checks against all views and power domains if binding exists in the list of specified cells.
-drc_file fileName Creates the Design Rule Checking (DRC) violation markers and save those in the specified file.
-lib_binding_voltage

Checks voltage against the binding library.

-lib_cell_binding

Verifies that all cells are bound to correct timing library cells.
-global_connection module_name_list


Verifies that power and ground pins of instances within the power domain are connected to the power and ground nets of that power domain. In addition, this parameter verifies that the tie-high and tie-low connections of an instance are connected to the same power and ground nets of the power domain to which the cell belongs. If you do not specify a list of module names, all modules are verified.

-nets_missing_iso

Verifies if the nets are missing isolation instances according to the power intent file. It also checks if the isolation uses right type of cell specified in the IEEE1801 map_isolation_cell command (if any).

-ignore_net_to_port_iso

Ignores the nets connecting to I/O when verifying isolation using -nets_missing_iso.

-ignore_net_to_port_shifter

Ignores the nets connecting to I/O when verifying shifter using -nets_missing_shifter.

-place

Verifies if the instances are placed in the boundary of their power domain.
-place_report report_name


Specifies a name and location for the report generated when you use this command with the -place parameter.

-power_switch

Verifies whether each row in the power domains contain at least one power switch. The command issues a warning message detailing which rows do not contain at least one switch. It also checks if the power switch uses right type of cell specified in the IEEE1801 map_power_switch_cell command (if any).
-power_within_min_gap


Verifies that the power domain ring is within the distance specified by the update_power_domain -gap_sides command parameter.
-retention {fileName ...}

Specifies a name for storing the verify retention information. It checks if the retention uses the right type of cell specified in the IEEE1801 map_retention_cell command (if any).

-nets_missing_shifter

Verifies if the nets are missing level shifter according to the power intent file. It also checks if the level shifter uses right type of cell specified in the IEEE1801 map_level_shifter_cell command (if any).

Examples

The following command issues warning messages if instances that are not members of a power domain are placed within that power domain boundary, or if any power domains overlap:

check_power_domains -place
