create_boundary_model

create_boundary_model 
[-help]
-dir string
[-exclude_no_delay_ports]
[-include_full_parasitics]
[-include_userpins <string>]
[-latch_effort_low]
[-overwrite]
[-skip_constant_ports]
[-skip_constants]
[-skip_disabled]
[-skip_ports string]

Initiates the creation of a boundary model from a full design. 

Parameters

-help                      

Prints out the command usage.

-dir string              

Specifies the directory for boundary model files.

-exclude_constraints

Does not include constraints in the generated model.
-exclude_no_delay_ports

Skips tracing logic through unconstrained input ports in the boundary model.
-include_full_parasitics

Allows you to write out RCDB parasitics for all lower-level blocks as part of the current boundary model. 

When specified, the software writes out full parasitics by running the write_rcdb command under the hood.
-include_userpins string

Includes the specified pins in the boundary model. No fanin/fanout tracing is performed for the specified pins.
-latch_effort_low

Skips tracing of logic through latch aggressors that are not part of the interface logic. The aggressors in the fanout of latch aggressors will use an infinite timing window. By default, the entire fanin cone of latch aggressors is preserved to ensure accurate latency adjustment, which may increase the size of the boundary model.

-overwrite

Allows overwrite of the existing directory.
-skip_constant_ports

Skips tracing logic through constant ports in the boundary model.

-skip_constants

Skips tracing through constant logic in the boundary model.

-skip_disabled

Skips tracing of logic through disabled arcs (user or constant disabled) in the boundary model.

-skip_ports string

Skips tracing fanin/fanout logic through specified ports in the boundary model.

Examples

  • The following command creates a boundary model for the top cell being timed and writes the model files into the ./model_dir directory. Any existing directory contents are removed.
    create_boundary_model –dir ./model_dir –overwrite
