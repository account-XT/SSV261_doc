set_ilm

set_ilm
-cell cellName
-in_dir dirName

Specifies ILM data directory for the specified block. You can run set_ilm multiple times in the same session. Each time you specify set_ilm, the software overwrites the previous setting for the block. If master/clones exist in the design, the cell name will have the name of the master partition.

Note: The ILM is not supported for Signoff in Tempus.

Parameters 

-cell cellName

Specifies the block name.

-in_dir dirName

Specifies the directory for the files you want to read.

Example

  • The following commands specifies directory dir_dsp_core for block tdsp_core, and directory dir_onemore for block onemore:
    set_ilm -cell tdsp_core -in_dir dir_dsp_core
    set_ilm -cell onemore -in_dir dir_onemore
