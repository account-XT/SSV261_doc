update_inst

update_inst
[-help]
-base_cell base_cell 
[-dont_snap_to_placement_grid]
[-location {x y}] -name inst_name
[-orient {r0 r90 r180 r270 mx mx90 my my90}]
[-place_status {fixed soft_fixed placed unplaced cover}]

Updates the base cell of an existing instance object and returns the updated inst object pointer.  The new base cell and existing base cell must have the identical pins.

Parameters 

-help

Outputs a brief description that includes the type and default information for each update_inst parameter.

For a detailed description of the command and all of its parameters, use the  man  command:  
man update_inst

-base_cell base_cell

Specifies the base cell to use for the new instance.

Data_type: (base_cell), required)
-dont_snap_to_placement_grid

If -dont_snap_to_placement_grid is specified, the tool places the instance at the specified location even if the location is off the placement grid. This parameter is used with -location. 

Default: false

Data_type: bool, optional

-name instName

Specifies the name of the instance to update.

Data_type: (inst), required

-location {x y}

Specifies the location of the changed instance.

Default: Default is the same location.

Data_type: point, optional

-orient {r0 r90 r180 r270 mx mx90 my my90}

Specifies orientation of the changed instance.

Default: Default is the same orientation.

Data_type: enum, optional

-place_status {fixed soft_fixed placed unplaced cover}

Specifies the placement status of the changed instance.

Default: Default is the same place_status.

Data_type: enum, optional

Example

  • The following command updates the base_cell of inst i1/i2 from BUFX2 to BUFX4, and then marks it as fixed:
    update_inst -name i1/i2 -base_cell BUFX4 -place_status fixed
