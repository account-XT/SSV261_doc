report_timing_summary

report_timing_summary 
[-help]
[-checks {setup | hold | drv | clock}]
[-expand_clocks {launch_capture | capture_only}]
[-expand_views]
[-groups groupname_list]
[-sort_by {name | wns | tns | fep}]
[-views viewName]

Generates reports that provide details summarized by the violation type - setup, hold, or DRV. You can sort the rows by WNS, TNS, FEP, or by view name.  

Parameters

-help

Prints out the command usage.

-checks {setup | hold | drv | clock}

Generates a timing report for the specified check types.

The valid values are setup, hold, drv, and clock.

Default: setup hold drv clock

-expand_clocks {launch_capture | capture_only}

Includes per capture or launch/capture clock group details.

-expand_views

Includes per analysis view details.

-groups groupname_list

Generates a timing report for the specified path group(s). By default, all the path groups are analyzed.

-sort_by {name | wns | tns | fep}

Defines the order in which the report will be sorted - views, clocks, or path groups. The valid values are:

  • name: Places the items in alphabetical order.
  • wns: Sorts the output by WNS.
  • tns: Sorts the output by TNS.
  • fep: Sorts the output by FEP.

Default: name

-views viewName

Generates a timing report for the specified analysis views only. By default all the active views are analyzed.
