clear_all_rulers

clear_all_rulers -help

Removes all ruler lines from the main window. You can also clear the ruler lines with the Clear All Rulers icon on the toolbar in the main window.

Parameters

-help

Prints a brief description that includes type and default information for each clear_all_rulers parameter.

For a detailed description of the command and all of its parameters, use the man command: 
man clear_all_rulers
