report_noise_propagation

report_noise_propagation 
[-help]
[-level {vl | vh | worst | all}]
[-max_paths integer]
[-max_slack float]
[-nets string]
[-nworst integer]
[-pins string]
[-source_depth integer] 
[-style {default | extended}] 
[-views string]
[[ > | >> ]]

Generates text-based noise propagation reports. 

Note: You need to set si_glitch_enable_report attribute to true to enable glitch reporting.

Parameters

-help                   

Prints out the command usage. For a detailed description of the command and all of its parameters, use the man command: man report_noise_propagation

-level {vl | vh | worst | all}

Reports the paths for specified glitch level. The allowed values are: VL, VH, worst, or all.

-max_paths integer

Reports the specified number of paths.

-max_slack float    

Reports the paths with glitch slack equal to or lesser than the specified value.

-nets string   

Reports the paths with end point being all the input pins connected to the net.

-nworst integer

Specifies the maximum number of sources per end point for which paths need to be reported.

-pins string 

Reports the paths for the specified end point pins.
-source_depth integer

Specifies the maximum number of sources to be traced in any given branch in the fanin cone of violation.

-style {default | extended}

Provides an enhanced report format that shows fields - UDN and User annotated. You can specify the following options:

  • default: Prints the ROP column and VDD (in mV) in the output report.
  • extended:  Reports the drivers with annotated glitches as propagation sources.

-views string  

Reports the paths for the specified views.

> filename          

Redirects output to the specified file.

>> filename           

Appends output to the specified output file.
