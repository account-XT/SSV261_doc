delete_power_intent

delete_power_intent
[-help]
[-keep_fence]

The command deletes all the power intent data stored by the commit_power_intent command in current session and cleans up the design.

Parameters

-help

Prints a brief description that includes the type and default information for each delete_power_intent parameter. For a detailed description of the command and all its parameters, use the man command:

man delete_power_intent

-keep_fence

Retains domain groups and their fences at the time of removing the LP database for completing non-LP status of applications. After completing the non-LP status of the required applications, use read_power_intent and commit_power_intent -keep_rows to restore the retained domain groups and domain fences of the removed LP database.
