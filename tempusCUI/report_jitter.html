report_jitter

report_jitter 
[-help]
[-eiv_end_time float]
[-eiv_file string]
[-eiv_power_ground string]
[-eiv_start_time float]
[-from string]
[-from_fall string]
[-from_rise string]
[-mode {period | cycle_to_cycle | time_interval_error}]
[-out_dir string]
[-through <string>]
[-to string]
[ [ > | >> ] ]

Provides a native jitter interface to report jitter through the native Tempus engine.

The existing analyze_jitter command will continue to be used for Spice-based jitter analysis.

Parameters

-help

Prints out the command usage.

-eiv_end_time float

Specifies the end time in EIV.

-eiv_file string

Specifies the effective instance voltage files for accounting IR Drop in Jitter computation.

-eiv_power_ground string

Specifies the power and ground net name for each EIV file.

It is mandatory to provide power and ground net name for each eiv file provided using the -eiv_file parameter.  For example, "vdd1 vss1 vdd2 vss2", vdd1 and vss1 are for first and vdd2 and vss2 for second EIV file - specified using the -eiv_file parameter. 

-eiv_start_time float

Specifies the start time in EIV.

-from string

Creates the Spice deck with mesh net starting from pin.

-from_fall string

Creates the Spice deck with mesh net starting from falling transition of specified from pin.

-from_rise string

Creates the Spice deck with mesh net starting from rising transition of specified from pin.

-mode {period | cycle_to_cycle | time_interval_error}

Runs the analyze_jitter analysis natively - period is default jitter type.

-out_dir string

Specifies the output directory for the created Spice.
-through <string> Creates the Spice deck with mesh net going by through points.

-to string

Creates the Spice deck with mesh net ending at to pins.

> filename

Redirects the -run_path_simulation/-run_simulation output to a file.

>> filename

Appends the -run_path_simulation/-run_simulation output to a file.

Examples

  • The following command reports analysis jitter details (for period mode) in the specified output directory:
    report_jitter -eiv_file eiv_file1 -out_dir jitter_dir -mode period
  • The following command reports analysis jitter details (for cycle_to_cycle mode) in the specified output directory:
    report_jitter -eiv_file eiv_file1 -out_dir jitter_dir -mode cycle_to_cycle
