merge_model_timing

merge_model_timing
[-help]
-input_library_file string
[-keep_separate_arc]
[-merged_library_file string]
-mode_group string
-modes string
[-pin_cap_tolerance float]
[-tolerance float]

Merges extracted timing models (ETM) for various analysis views into a single output.

The merge_model_timing command should be the last command in the run script. Also, this command should be run separately in a Tempus session when a design is not loaded. 

When the DRV values are different in the libraries that are merged, then Tempus saves the worst value of the DRV with a warning message. 

If the DRV values are not equal, the greater value is stored for the following:

  • Minimum transition
  • Minimum capacitance
  • Minimum fanout

The smaller value is stored for the following, in case of unequal DRVs:

  • Maximum transition
  • Maximum capacitance
  • Maximum fanout
  • Fanout load

Parameters 

-keep_separate_arc

Enables creating separate timing arcs with respective modes.

-input_library_file string

Specifies input library files that are to be merged.

-modes string

Specifies the mode names required for merging the libraries. The number of mode names should be equal to the number of input libraries.

-mode_group string

Specifies the name of the mode group.

-merged_library_file string

Specifies the name of the merged library output file name. By default, the output file name is merge.lib.
-pin_cap_tolerance float Specifies the pin capacitance tolerance for making tolerance comparison for library merging.

-tolerance float

Specifies the tolerance value for making tolerance comparison for library merging.

Examples

  • The following command merges library files model1.view1.lib and model1.view1.lib.ref into a single output file:
    tempus >  merge_model_timing -input_library_file "model1.view1.lib model1.view1.lib.ref"
    -modes "v1 v2" -mode_group v1_v2
