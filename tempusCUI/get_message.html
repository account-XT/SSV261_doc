get_message

get_message
-help
-id msgID
[-severity | -limit | -suppress | -count | -short | -long | -on_error  | -stop_script_limit | -detail ] 

Returns the limit, severity, or suppression information about a message.

Parameters

-help

Outputs a brief description that includes type and default information for each get_message parameter.
For a detailed description of the command and all of its parameters, use the man command:

man get_message
-count

Returns the number of times this message has been issued this session.
-detail

Returns the message of specified id.
-id msgID

Specifies a single message ID, in the form "ENCFOO-123".
-limit

Returns the limit for the specified message as an integer. -1 is unlimited. 0 is suppressed.
-long 

Returns the long message description, as used for the Description section in "man msgID"
-on_error 

Returns the error action for the specified message.
-severity

Returns the severity, error, warn, info, or default, of the specified message as a string.
-short 

Returns the short message description. Equivalent to "help msgID" .
-stop_script_limit

Returns the message limit allowed for every public command. Message limit set as -1 means unlimited.
-suppress

Returns 1 if the message is suppressed, 0 if not suppressed.

Examples

The following commands return the suppression, severity, and limit levels for the message ID IMPDB-1241:

  • tempus> get_message -id IMPDB-1241 -suppress
    0
  • tempus> get_message -id IMPDB-1241 -severity
    default
  • tempus> get_message -id IMPDB-1241 -limit   
    20
