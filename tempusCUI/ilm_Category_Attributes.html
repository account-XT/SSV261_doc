ilm Category Attributes

The root attributes in the ilm category are:

  • ilm_auto_use_sdc_files
  • ilm_filter_internal_path
  • ilm_keep_async
  • ilm_keep_flatten
  • ilm_keep_high_fanout_ports
  • ilm_keep_inst_in_sdc
  • ilm_keep_loopback
  • ilm_max_num_insts
  • ilm_max_num_registers
  • ilm_slack_driven

To set the value of any root attribute, use the set_db command:

set_db attribute_name value

To get the current value of any root attribute, use the get_db command:

get_db attribute_name

To get the current value of all attributes in the ilm category, use the following command:

get_db -category ilm

ilm_auto_use_sdc_files

ilm_auto_use_sdc_files {true|false}

Default: false

Data_type: bool, read/write

Reloads the sdc_files of top-level design.

Related Command
  • write_ilm

ilm_filter_internal_path

 ilm_filter_internal_path {true|false}

Default: false

Data_type: bool

When set to true, group paths are created for internal paths with slack adjustment of 9999. Therefore, all internal paths are filtered out from the timing report.

Related Command
  • write_ilm

ilm_keep_async

ilm_keep_async {true|false}

Default: false

Data_type: bool

Keeps paths from asynchronous input ports. For example, paths from an input port to the reset pin of interface sequential instances, but not to the internal sequential instances.

ilm_keep_flatten

ilm_keep_flatten {true|false}

Default: true

Data_type: bool

Makes flow work under the flattenIlm mode.

ilm_keep_high_fanout_ports

ilm_keep_high_fanout_ports {true|false} 

Default: true

Data_type: bool

Keeps high-fanout input port paths.

ilm_keep_inst_in_sdc

ilm_keep_inst_in_sdc {true|false}

Default: false

Data_type: bool

Keeps instances which have constraints on it.

ilm_keep_loopback

ilm_keep_loopback {true|false}

Default: false

Data_type: bool
 

Keeps loop back paths.

When set to true, then any path touching a net used for the ILM model is also included. This is done for better model accuracy, so that the actual capacitance on an output port could affect the delay on a net which feeds an internal path that is normally not included in the ILM model. This also degrades the reduction ratio (#ILM_insts/#all_inst) for the block.

ilm_max_num_insts

ilm_max_num_insts maxInstances 

Default: 1000

Data_type: int, read/write

Specifies the maximum number of instances.

ilm_max_num_registers

ilm_max_num_registers maxRegisters

Default: 40

Data_type: int, read/write

Specifies the maximum number of registers.

ilm_slack_driven

ilm_slack_driven {true|false}

Default: false

Data_type: bool, read/write

Specifies slack driven ILM generation.
