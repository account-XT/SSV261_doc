eco_update_cell

eco_update_cell    
[-help]
[-pin_maps <string>]
{-cells <string> | -up_size  | -down_size  | -evaluate_all } [-evaluate_only  | -evaluate_all ] [-early  | -late ] [-location {x y} [-orient <string>]] [-sort_by {slack delay trans area} [-max_cells <integer>]] {-insts <string> | -from <string> | -from_rise <string> | -from_fall <string>} {-insts <string> | -to <string> | -to_rise <string> | -to_fall <string>} [{[-from <string>] [-from_rise <string>] [-from_fall <string>] [-to <string>] [-to_rise <string>] [-to_fall <string>]} [{[-timing_type {combinational combinational_fall combinational_rise falling_edge hold_falling hold_rising recovery_falling recovery_rising removal_falling removal_rising rising_edge setup_falling setup_rising}] [-view <string>] [-early ] [-late ] [-output_as_tcl ] [-sort_by {slack delay trans area}]}]] [{[-evaluate_all ] [-evaluate_only ]} [{[-from <string>] [-from_rise <string>] [-from_fall <string>] [-to <string>] [-to_rise <string>] [-to_fall <string>] [-timing_type {combinational combinational_fall combinational_rise falling_edge hold_falling hold_rising recovery_falling recovery_rising removal_falling removal_rising rising_edge setup_falling setup_rising}] [-view <string>] [-early ] [-late ] [-output_as_tcl ]} [-sort_by {slack delay trans area}]]]

Changes the cell of an instance. In multi-mode multi-corner (MMMC) mode, this command changes the cell and updates timing in all views. This command upsizes or downsizes the specified instance based on the available footprint. Cell mapping is also possible as long as the output pins are functionally equivalent. This command also checks for and observes power domains.

This command has the following features:

  • Changes the cell
  • Performs incremental timing updates of the paths passing through the cell
  • Supports spef, LEF, and DEF-based flows

Note: 

You do not need to provide physical information (LEF/DEF) in order to perform ECO with this command.

When resizing instances inside multiple-instantiated blocks, the resize would be applied to all instantiations of the block.

Parameters 

-help

Outputs a brief description that includes type and default information for each eco_update_cell parameter.

For a detailed description of the command and all of its parameters, use the man command:

man eco_update_cell

-cells string

Specifies name of the new cell of the given instance. The function of the original cell has to match the function of the new cell for all the outputs used by the old cell. The number of input pins have to be the same for both the original cell and the new cell.

-down_size

Downsizes the specified instance with the next available cell in the same footprint unless the specified cell is already of the lowest driving strength. Downsizing an instance on the noncritical path can reduce the loading of its driver on the critical path.
-early

Specifies that timing will be evaluated for early analysis. In such a case, only the active hold analysis views will be considered. If this parameter is not specified, timing will be evaluated for late analysis.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only.
-evaluate_all Allows to evaluate new timing(s) through the instance by using all functionally equivalent library cell(s) for the instance.
-evaluate_only Allows to evaluate new timing through the instance by using the specified library cell for the instance. 
-from string

Specifies the input pin for the instance to be evaluated for resize. Both the rise and fall transitions are considered in timing report.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only.
-from_fall string 

Specifies the input pin for the instance to be evaluated for resize. Only the fall transition is considered in timing report.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only.
-from_rise string

Specifies the input pin for the instance to be evaluated for resize. Only the rise transition is considered in timing report.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only.

-insts string

Specifies the name of the instance to be resized.
-late

Specifies that timing will be evaluated for late analysis. In such a case, only the active setup analysis views will be considered. If this parameter is not specified, timing will still be evaluated for late analysis.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only.
-location {x y} Specifies the legalized location where the instance will be placed.
-max_cells <integer>

Specifies the maximum number of improving and degrading cells (each) to be reported for evaluation.
-orient string

Specifies the legalized orientation for the instance.

You can specify this parameter with the -location parameter only.
-output_as_tcl

Returns the evaluation result as a Tcl list. By default, the command returns text-based format.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only.

-pin_maps string

Specifies the pin mapping for the new cell based on the old cell. This option is required if the new master cell has different pin names than the original cell. The net connected to oldpin1 of the original cell should be connected to newpin1 of the new cell, and so forth.

-sort_by {slack delay trans area}

 Specifies the sorting order for evaluation output.
-timing_type <timing_type>

Specifies the type of the timing arc to be used for timing evaluation between the specified -from/-from_rise/-from_fall and -to/-to_rise/_to_fall pins. The software will check for valid timing_types:

  • If only one arc is available, it will proceed.
  • If multiple arcs available, you need to specify which timing_type to be considered via this parameter.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only. For valid timing types, refer to section, List of Valid Timing-types.
-to string

Specify one of the following:

  • The output pin of the instance to be evaluated for resize, or
  • The input pin for the instance driven by the instance to be evaluated for resize.

Note: This parameter must be specified with -evaluate_only/-evaluate_all only.
-to_fall string Specifies name of the target pin of the cell to be resized, or the input pin of the next-stage cell. Only the fall transition is considered in the timing report.
-to_rise string

Specifies name of the target pin of the cell to be resized, or the input pin of the next-stage cell. Only the rise transition is considered in the timing report.

-up_size

Upsizes the specified instance with the next available cell in the same footprint unless the specified cell is already of the highest driving strength. Upsizing an instance that drives a large load can improve the driver delay and the transition time at the receivers.
-view string

Specifies the active analysis views for which timing must be evaluated. If this parameter is not specified, timing will be evaluated for all active analysis views and results reported for the worst view.

Note: This parameter must be specified with -evaluate_only or -evaluate_all only.

Examples

  • The following command substitutes the cell for instance DTMF_INST/ RESULTS_CONV_INST/FE_PHC268_r1477_1_ with cell DLY3X2. Pin A maps to pin I and pin Y maps to pin O of the new cell. 

    tempus> eco_update_cell -insts DTMF_INST/RESULTS_CONV_INST/FE_PHC268_r1477_1_ -cells DLY3X2 -pin_maps {A I Y O} 

  • The following command substitutes the cell for instance DTMF_INST/ RESULTS_CONV_INST/FE_PHC268_r1477_1_ with cell BUFX2.
    tempus> eco_update_cell -insts DTMF_INST/RESULTS_CONV_INST/FE_PHC268_r1477_1_ -cells BUFX2

  • The following command upsizes the cell for instance DTMF_INST/ RESULTS_CONV_INST/FE_PHC268_r1477_1_ and places the instance at the given location.
    tempus> eco_update_cell -insts DTMF_INST/RESULTS_CONV_INST/FE_PHC268_r1477_1_ -up_size -location {23.45 98.12}

  • The following command evaluates timing for instance, TDSP_CORE_INST/TDSP_CORE_GLUE_INST/lsh_120_47/FE_PSC502_n_661, using library cell BUF_X32 (prints delay for A to Y arc, slack at A pin, and slew at Y pin, corresponding to the worst timing path) :
