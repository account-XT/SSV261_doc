report_critical_pins

report_critical_pins     

[-help] 
-out_file fileName 

Performs slack analysis and writes the names of all critical terminals to the specified file. As a result, deterioration of setup slack can be avoided while the Innovus software repairs hold time violations.

Parameters

-help

Prints a brief description that includes type and default information for each report_critical_pins  parameter.

For a detailed description of the command and all of its parameters, use the man command:man report_critical_pins

-out_file fileName

Specifies the name of report file.

Command Order

Use this command after the timing graph is built by time_design/opt_design .

Examples

  • The following attribute and command write the setup critical terminals into a file called critTerm : 
    timing_analysis_check_type setup 
    report_critical_pins -out_file critTerm
