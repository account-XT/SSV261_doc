set_sense

set_sense 
[-help]
pin_or_port_list
[-clocks clock_list]
{[-positive | -negative | -stop_propagation | -clock_leaf] 
[-type type_list]}

Selects which phase of the clock to filter at the specified point.

This command accepts timing arcs collection as a valid argument.

Parameters 

-help Prints out the command usage.

-clocks clock_list

Specifies a list of clocks passing through a specified point to which the constraint applies.

When this parameter is not specified, the filtering of clock phase will be applicable to all the clocks passing through that specified point.

This parameter must be used with a specified pin name and one of the parameters : -positive, -negative, -stop_propagation, or -clock_leaf.

-clock_leaf

When specified, the software propagates clock phases to the specified pin.

-negative

Specifies that positive phase filtered clocks pass through pins in the pin_list.

Note: The -positive, -negative and -stop_propagation parameters are mutually exclusive.

pin_or_port_list

Specifies the list or collection of cell output pins. The unateness specified by the set_sense command is applied to clocks propagating through the specified point.

-positive

Specifies that negative phase filtered clocks pass through pins in the pin_list.

Note: The -positive, -negative and -stop_propagation parameters are mutually exclusive.

-stop_propagation

Stops the propagation of the specified clocks passing through the specified pins, or any phases that are specified by the -type parameter.

Note: The -positive, -negative and -stop_propagation parameters are mutually exclusive.
-type type_list

Applies clock sense to object types specified in the type_list. The type list options are - all, clock, data, and clock_source_data.

These are explained below:

  • all: Stops all phases from propagating. This is equivalent to specifying both the clock and data options.
  • clock: Stops clock phases launched by clock(s) specified in the clock_list from propagating.
  • data: Stops all data phases launched by clock(s) specified in clock_list, starting from the pins/ports specified in pin_or_port_list. The objects in the pin_or_port_list can be selected anywhere in the design - clock/data network.
  • clock_source_data: Stops only clock source data phases from propagating.

Notes:

  • The -type clock option should be used with the -stop_propagation parameter. When the -type parameter is not specified, then set_sense -stop_propagation will stop only the clock phases.
  • The -type data option should be used with the -stop_propagation and -clock parameters.
  • The -type data option is not supported with both -positive and -negative parameters.
  • The write_sdc command will automatically add -type clock when set_sense is specified with the -stop_propagation parameter (without -type).

Examples

  • The following command allows the positive phase clock CLK1 to pass through CLKBUF1/Z and filters out the negative phase clock CLK1:
    tempus > set_sense -positive -clocks CLK1 CLKBUF1/Z

  • The following command stops clock phases starting from pin1:
    tempus > set_sense pin1 –type {clock}

  • The following command stops data phases based only on CK1 and CK2 starting from pin1:
    tempus > set_sense pin1 –type {data} –clocks {CK1 CK2}

  • The following command stops only the clock source data phases starting from pin1:
    tempus > set_sense pin1 –type {clock_source_data}

  • The following command stops the clock and clock source data phases:
    tempus > set_sense pin1 –type {clock clock_source_data}
    or
    tempus > set_sense pin1 –stop_propagation
