init_ml

init_ml
[-help] 
[-comment string]
[-flow_phase string]
[-name string]
-prefix string
[-scenario string]

Initializes the environment to start writing data for JedAI. Run this command before using any of the following commands to ensure that content is properly labeled for big data ingestion and registration:

  • write_ml_design
  • write_ml_library
  • write_ml_timing_graph
  • write_ml_timing_path

Parameters

-help

Prints a brief description that includes the type and default information for each init_ml parameter.

For a detailed description of the command and all of its parameters, use the man command
man init_ml.

-comment string

Specifies a comment.

Data_type: string, optional

-flow_phase string

Specifies the flow phase.

Data_type: string, optional

-name string

Specifies the design name.

Data_type: string, optional

-prefix string

Specifies the prefix for the output files.

Data_type: string, required

-scenario string

Specifies the scenario.

Data_type: string, optional

Example

  • The following command initializes the environment to start writing data for JedAI for the cts flow phase with the default scenario for the dtmf design.
    init_ml -prefix out/ -name dtmf -flow_phase cts -scenario default -comment "This is a demo."
