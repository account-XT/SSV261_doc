write_ml_timing_path

write_ml_timing_path
[-help] 
[-anchor_file string]
[-begin_end_pair]
[-chain_levels int]
[-chain_path] 
[-each_endpoint]
[-from pin_list] 
[-gen_anchor]
[-hpin]
[-io_only]
[-max_paths int]
[-max_slack float]
[-nworst int]
[-partitions partition_list] 
[-path_group string]
[-per_partition]
-prefix string
[-retime {aocv ssta path_slew_propagation aocv_path_slew_propagation}]
[-retime_mode {path exhaustive}]
[-start_pathid int]
[-to pin_list]
[-verbose]
[-views view_list]

Writes timing-related data for JedAI to csv files. It includes data for individual timing paths. Timing path data can be computed in either graph-based analysis (GBA) or path-based analysis (PBA) fashion using the -retime option.

Parameters

-help

Prints a brief description that includes the type and default information for each write_ml_timing_path parameter.

For a detailed description of the command and all of its parameters, use the man command
man write_ml_timing_path.

-anchor_file string

Specifies the name of the anchor file to be used as input.

Data_type: string, optional

-begin_end_pair

Reports all violations between unique source and target register pairs.

Data_type: bool, optional

-chain_levels int

Specifies the chain level if -chain_path is enabled.

Data_type: int, optional

-chain_path

Gets chained paths.

Data_type: bool, optional

-each_endpoint

Specifies whether to dump at least one path for each end point.

Data_type: bool, optional

-from pin_list

Dumps data from the specified pin(s).

Data_type: tcl_obj, optional

-gen_anchor

Generates the anchor file.

Data_type: bool, optional

-hpin

Dumps hpin in timing points.

Data_type: bool, optional

-io_only

Specifies that only the io path should be dumped.

Data_type: bool, optional

-max_paths int

Specifies the max_paths for report_timing.

Data_type: int, optional

-max_slack float

Specifies the max_slack for report_timing.

Data_type: float, optional

-nworst int

Specifies the nworst for report_timing.

Default: 100

Data_type: int, optional

-partitions partition_list


Specifies a partition list if -per_partition is set.

Data_type: tcl_obj, optional

-path_group string

Specifies the path_group for report_timing.

Data_type: string, optional

-per_partition

Specifies that only paths through top level partitions should be dumped.

Data_type: bool, optional

-prefix string

Specifies the prefix for the output files.

Data_type: string, required

-retime {aocv ssta path_slew_propagation aocv_path_slew_propagation}

Specifies the method to be used for reanalysis of specified set of paths with report_timing.

Data_type: enum, optional

-retime_mode {path exhaustive}


Passes the specified retime mode to report_timing. To understand the difference between the two retime modes, path and exhaustive, see report_timing.

Data_type: enum, optional

-start_pathid int

Specifies the starting path id.

Default: 1

Data_type: int, optional

-to pin_list

Dumps data to the specified pin(s).

Data_type: tcl_obj, optional

-verbose

Displays a more detailed message.

Data_type: bool, optional

-views view_list

Dumps the timing path for the specified analysis view(s).

Data_type: tcl_obj, optional

Example

  • The following command writes out the attributes of timing paths to csv files with the specified prefix:
    write_ml_timing_path -prefix out/ -max_paths 10000 -nworst 1
