gui_open_schematic

gui_open_schematic
[-help]
[-name string]
[-type {module cone}]
[-objs <inst | net | pin | port | hinst>+ | -selected]

Opens the Schematic Viewer.

Parameters

-help

Prints out the command usage. For a detailed description of the command, use the man command:

man gui_open_schematic
-name string

Specifies the unique window name for the schematic view to be opened.
-objs <inst | net | pin | port | hinst>+

Specifies the object(s) to be added in the schematic view.

If multiple objects are specified, the Schematic Viewer can be opened only in the flattened mode (-type cone). As the default schematic mode is hierarchical, this means you must always specify -type cone when specifying multiple objects.

Note: This option cannot be used with -type module. 

Data_type: (inst|net|pin|port|hinst)+, optional
-selected

Specifies that the selected object(s) are to be added in the schematic view. 

If multiple objects are selected, the Schematic Viewer can be opened only in the flattened mode (-type cone). As the default schematic mode is hierarchical, this means you must always specify -type cone when selecting multiple objects.

Note: This option cannot be used with -objs or -type module. 

Data_type: bool, optional
-type {module cone}

Specifies the type of schematic to be opened. If you specify cone, the tool opens the Schematic Viewer to display schematic in the flattened mode. If you specify module, the tool opens the Schematic Viewer to display schematic in the hierarchical mode.

Default: module

Data_type: enum, optional

Examples

  • The following command opens the schematic for the specified instance in the hierarchical mode:
    gui_open_schematic -obj DTMF_INST/PLLCLK_INST
  • The following command opens the schematic for the specified instance in the flattened mode:
    gui_open_schematic -obj DTMF_INST/PLLCLK_INST -type cone
  • The following opens the schematic for the selected object in the flattened mode:
    gui_open_schematic -selected -type cone
  • The following command opens the schematic for multiple selected objects in the flattened mode:
    gui_open_schematic -selected -type cone
