create_ilm_from_files

create_ilm_from_files
[-help]
[-cell block_name]
[-incremental]
-model_type {timing | cts | si}
[-overwrite]
[-si_timing_window_file xtwf_file.spef] 
{-out_dir directory_name | -oa_cellview lib cell view} 
[-verilog_file cell_name.v [-cell_prefix cell_prefix -uniquify_netlist]]
[-sdc_file file_name -timing_view view_name]
[-spef_file spef_file.spef -rc_corner RC_corner_name]
[-opt_stage stage] 

Creates an ILM directory from existing data. It can only create non-merged models. This command is useful in situations where an ILM is to be created through external inputs or using data from third party models into a format that could be recognized by Tempus. 

If the data files already exist in the specified directory, the tool stops and generates an error message. You can overwrite existing files by specifying -overwrite. You can add files to the directory by specifying -incremental.

The command also creates a tcl script (cell_name_ILM.tcl) that you can source in your command file. The script contains the following command:

read_ilm -cell cell_name -out_dir dir_name 

Note: The ILM is not supported for Signoff in Tempus.

Parameters

-cell block_name

Specifies the name of the block.

-cell_prefix cell_prefix

Specifies the cell prefix.
-oa_cellview lib cell view Specifies the library name, cell name, and view name in the OpenAccess database format.
-opt_stage stage Specifies the optimization stage, preCTS or postCTS.

-out_dir dir_name

Stores the ILM data in the specified directory: the absolute directory path or the path relative to the current directory.
-incremental Lets you add files in addition to the existing files to the directory.
-model_type {timing | cts | si} Specifies the type of ILM model, i.e timing, cts or si,.

-help

Outputs a brief description that includes the type and default information for each create_ilm_from_files parameter.

For a detailed description of the command and all of its parameters, use the man command:
man create_ilm_from_files.

-overwrite

Overwrites existing files in the directory.

-rc_corner RC_corner_name

Specifies the RC corner name for MMMC analysis. It identifies the specified corner to be used with -spef_file.
-sdc_file file_name Specifies an existing .sdc file that you want to include in the directory. It identifies the sdc file to be used with the specified view.

-spef_file spef_name.spef

Specifies an existing .spef file that you want to include in the directory. It identifies the spef file to be used with the specified corner.
-timing_view view_name Specifies the view name for the ILM module. It identifies the specified view to be used with –sdc.

-uniquify_netlist

Uniquifies the input Verilog netlist. This ensures that there are no errors when ILMs are being loaded.

Using this parameter, each sub-module for an ILM has a unique name, which is composed of the time stamp and its original name.

For example, in top_sm WedJun31138212009$data_path, top_sm specifies the top-level design, WedJun31138212009 specifies the time stamp, and $data_path specifies the original module name.

Default: Off

-verilog_file netlist_name.v

Specifies the verilog file you want to include in the ILM data directory.

-si_timing_window_file xtwf_file.spef

Specifies the .xtwf file that you want to include in the directory.

Examples

  • The following commands create two module directories:

    create_ilm_from_files -cell blk1 -out_dir A -model_type timing -verilog_file V1.v -spef_file 1.spef -rc_corner corner1 -sdc_file sdcfile1 -timing_view view1 


    create_ilm_from_files -cell blk2 -out_dir A -model_type si -verilog_file V2.v -spef_file 2.spef -rc_corner corner2 -sdc_file sdcfile2 -timing_view view2

  • The command creates two tcl files in the current directory. The blk1_ILM.tcl file contains the following command:

    read_ilm -out_dir A -cell blk1

    The blk2_ILM.tcl file contains the following command:

    read_ilm -out_dir A -cell blk2
