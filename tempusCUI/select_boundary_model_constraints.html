select_boundary_model_constraints

select_boundary_model_constraints 
[-help] 
[-block string]
[-define_bundled_bus string]
[-instance string]
[-set_instance_library <string>]
[-set_quiet_attacker string]

Applies boundary model constraints to specific blocks/instances.

Parameters


-help

Prints out the command usage.

-block string

Specifies the block for which the constraints will be applied.

-define_bundled_bus string

Applies the define_bundled_bus constraints.

-instance string

Specifies the instance for which the constraints will be applied.
-set_instance_library <string> Applies the instance library constraints defined with the set_instance_library command.

-set_quiet_attacker string

Applies the set_quiet_attacker constraints.
