create_flow

create_flow
[-help]
[steps]
-name name
[-owner string]
[-skip_metric]
[-tool tool]
[-tool_options options]

Creates a new, named flow object. run_flow then allows the execution of a named flow (in addition to its existing functionality).

Parameters

-help

Outputs a brief description that includes type and default information for each create_flow parameter.

For a detailed description of the command and all of its parameters, use the man command:
man create_flow.
[steps]

Specifies a list of flow step names in the order they must be executed.

Note: This is an optional parameter. You can either provide [steps] or use the -tool parameter.
-name name

The name of the flow object to create.
-owner string Specifies the owner of the flow.
-skip_metric Restricts the tool from capturing the flow's metric snapshot.
-tool tool

Specifies the name of the tool with which to run this flow.
This option allows you to create flows for other tools than the one currently running. If not specified, default is the current tool.
-tool_options options

Specifies options for use when launching this flow.
