report_voltage

report_voltage
[-help]
[-early]
[-inst string]
[-late]
[-net string]
[-pin string]
[-quiet]
[-view string]

This command reports the voltage for the net/pin (term)/inst in the specific view under a specific corner.

Parameters 

-help

Outputs a brief description that includes the type and default information for each report_voltage parameter. For a detailed description of the command and all of its parameters, use the man command:

man report_voltage

-early

Specifies that the voltage is reported in the early mode.
-inst string Specifies the instance power domain voltage (PVT).
-late Specifies that the voltage is reported in the late mode.
-net string Specifies the net voltage (driver's pin voltage).
-pin string Specifies the term voltage.
-quiet

Displays only the pin voltage-related information without other additional unnecessary information to avoid huge log size.
-view string Specifies the analysis view.

Examples

  • The following command specifies to display the derived voltage for the net, n1:

    tempus> report_voltage -net n1

    -> driving term: i1/Y, mode: late
    =======================
    derived voltage = 0.9
    0.9
  • The following command specifies to display the net (driver's pin) voltage and its related information:
    tempus> report_voltage -net n1 -quiet

    0.9
  • The following command specifies to display the term voltage reported in the late mode:
    tempus> report_voltage -pin sub_inst2/in -late

    -> hterm: sub_inst2/in, connected to net n5
    -> net: n5, volt 0.9
    =======================
    derived voltage = 0.9
    0.9
  • The following command specifies to display the term voltage reported in the early mode:
    tempus> report_voltage -pin sub_inst2/in -early

    -> hterm: sub_inst2/in, connected to net n5
    -> net: n5, volt 1.1
    =======================
    derived voltage = 1.1
    1.1
