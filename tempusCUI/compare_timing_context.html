compare_timing_context

compare_timing_context
[-help]
[-abs_thresh float]
[-instances string]
[-module string]
-out_file string
[-pct_thresh float]
-reference string
[-sort_by {abs | pct}]
-target string
[-type {clocks |  latency | arrival | required | slew | load | constant | glitch}]
[-verbose]
[-view string]

Compares two timing contexts generated by Tempus.

The contents of context like clocks, clock latency, arrival time, required, slew, load, constant, and glitch are compared. To perform context comparison, it is required to generate context using the -include_text_format parameter of the write_timing_context command.

Parameters

-help

Prints out the command usage.

-abs_thresh float

Specifies the threshold value to compare the context data.

The absolute threshold value is specified in pico seconds (ps).

Default: 0

-instances string

Specifies the list of instances for which context comparison will be done.

-module string

Specifies the list of modules for which context comparison will be done.

-out_file string

Specifies the output file that will show the differences between reference and target context data.

-pct_thresh float

Specifies the percentage threshold in percent (%).

If the difference is greater than both the specified -abs_thresh and -pct_thresh thresholds, the software considers the comparison as “Fail”.

Default: 0

-reference string

Specifies the reference path of the context directory.

-sort_by {abs | pct

Sorts the report based on the absolute tolerance or percent tolerance.

By default, the report is sorted based on the percentage difference.

-target string

Specifies the name of target context directory used for comparison.

Note: The missing entries in target or reference will be represented by “-”.

-type {clocks |  latency | arrival
| required | slew | load | constant | glitch}

Specifies the type of text data to be compared.

The latency option includes comparison of the latency, uncertainty, or incremental delay values.

By default, all the text data values are compared. 

-verbose

Reports the failed as well as passed comparison data.

-view string

Specifies the MMMC analysis view for which context comparison needs to be done.
