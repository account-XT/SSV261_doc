write_lef_library

write_lef_library
[-help]
[lef_file]
[-lef_layer_order]
[-all_auto_generated_via | -macro_only]
[-macro_only [-no_property]]
[-tech_only | -macro_only]
[-tech_only | -macro_list string]
[-use_spacing_table_default]

Writes the LEF library data (composed of technology data and macros) that is present in the tool's database.

The write_lef_library command facilitates comparisons between LEF-based input and OpenAccess-based input. LEF allows cases where VIARULE GENERATE has WIDTH specified for either the top or bottom layer. However, such cases are not supported by the OpenAccess tech. To make the comparison between LEF-based and OpenAccess-based input easier, write_lef_library dumps "WIDTH 0 TO 1000 ;" for any VIARULE GENERATE that does not have WIDTH specified in the original LEF.

Parameters 

-help

Outputs a brief description that includes type and default information for each write_lef_library parameter.

For a detailed description of the command and all of its parameters, use the man command: man write_lef_library.

lef_file

Specifies the output LEF file name.

Data_type: string, optional
-all_auto_generated_via

Includes all auto-generated vias.

Data_type: bool, optional
-lef_layer_order

Writes out only the layers specified in the lefLayerOrder constraint.

Data_type: bool, optional
-macro_list string

Writes the macros specified in the macro list.

Data_type: string, optional

-macro_only

Writes only the macro data to the LEF file.

Data_type: bool, optional
-no_property

Writes data in the LEF file without any properties. This option can be used only with the -macro_only option.

Data_type: bool, optional

-tech_only

Writes only the technology data to the LEF file.

Data_type: bool, optional

-use_spacing_table_default


Replaces any spacing value that matches the default spacing value with the "-" character in the LEF file.

When reading spacing tables from a LEF file, lef2oa replaces any "-" table entry with the default spacing value. The spacing table in the OpenAccess version therefore contains the default values for all such entries. By default, write_lef_library writes out the actual values in the spacing table in the LEF file. When -use_spacing_table_default is specified, write_lef_library replaces any spacing value that matches the default value with the "-" character in the LEF file. This makes it easier for you to compare the LEF file generated by write_lef_library with the original LEF file.

Data_type: bool, optional

Example

  • The following command writes the technology data into the tech.lef file:
    write_lef_library tech.lef -tech_only

    You can set the LEF version to 5.7 or 5.8 using write_def_lef_out_version:
    set_db write_def_lef_out_version 5.8
