create_hnet

create_hnet
[-help]
[-bus <msb:lsb>] { -name <hnet_name> } [ -parent <module|hinst|design> ] [ -power | -ground ]

Creates a new hnet (and parent net) object and returns the newly created hnet object pointer.

Parameters 

-help

Outputs a brief description that includes the type and default information for each create_hnet parameter.

For a detailed description of the command and all of its parameters, use the man command: man create_hnet
-bus <msb:lsb>

Specifies the bit range for bus nets.

By default, the software creates a scalar hnet.
-name <hnet_name>

Specifies the name of the new instance. If this is the full hierarchical path, then the parent will be derived from the name (that is the parent name is the string before the last "/".  In this case, the base_name of the new instance (that is the string after the last "/" should not have any special characters that require escaping.

When the -parent parameter is used, then the name is the base_name of the new instance. If the name has any unknown characters, it will be automatically escaped. Thus -name "i1/i2" will result in "i1\/i2" for the .escaped_name, since it uses DEF escaping semantics. This is equivalent to checking if <inst_name> is a legal Verilog identifier, and if not, prepend \ and add a trailing space to the internal Verilog name.

-ground

 Creates a ground net.
-parent <module|hinst|design>

Specifies the parent for the new hinst. It supports both the object or the name for the specified object types.

Default is the current design.
-power Creates a power net.

Examples

     CPU

      |

      +----------------+

      |                |

      H1 (alu)         H2 (fsm)

      |

      +----------------+

      |                |

     + H1 (add)        H2 (mult)

  • The following command creates a scalar top level net/hnet named N1  
    create_hnet -name N1 
  • The following command creates a 8-bit net/hnet named H1/H1/B1
    create_hnet -name B1 -bus 7:0 -parent module:add
  • The following command creates an 8-bit net/hnet named H1/H1/B1        
    create_hnet -name B1 -bus 7:0 -parent H1/H1
