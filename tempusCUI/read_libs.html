read_libs

read_libs
[-help]
[<in_file <file1[file2] ...>>]
[-aocv_libs <string>]
[-lef_files <string>]
[-library_side_file <string>]
[-aocv_libs aocvLibs]
[-max_aocv <string>]
[-max_libs maxLibs]
[-max_noise_libs maxNoiseLibs]
[-min_aocv <string>]
[-min_libs minLibs]
[-min_noise_libs minNoiseLibs]
[-noise_libs noiseLibs]
[-oa_ref_libs oaLibs]
[-power_ground_files powerGridLibFiles]
[-socv_libs soceLibs]

Schedules reading of one or more technology library files. These files either contain timing-related or noise-related information for the primitive cells used in the design. 

Timing libraries can be in text format or Cadence binary library format (LDB). The LDB (library database) files generated from other tools, like Innovus, Voltus, or Genus are read in to Tempus with an error message (TECHLIB-1249). The LDB files are not forward compatible, that is, a LDB generated from 15.2 version cannot be used with 15.1 or prior versions of the software.

Note: The read_libs command determines the priority of ECSM vs CCS data (if both are present). The software first checks for ECSM construct, if it is missing then CCS construct is loaded.

Note: You can use wildcards with the read_libs command as follows:
read_libs [glob *.lib]

Parameters

-help Prints a brief description that includes the type and default information for each read_libs parameter.
<in_file <file1[file2] ...> Specifies to read the library files.

-aocv_libs aocvLibs

 Specifies to read the default AOCV libraries.
-lef_files <string> Specifies the name of the LEF files to be loaded.
-library_side_file <string> Specifies to read the default incremental files.
-max_aocv string Specifies to read the max AOCV libraries.
-max_libs maxLibs Specifies to read the max libraries.
-max_noise_libs maxNoiseLibs Specifies to read the CDBs for max noise analysis.
-min_aocv string  Specifies to read the minimum AOCV libraries.
-min_libs minLibs Specifies to read the min LIBs.
-min_noise_libs minNoiseLibs Specifies to read the CDBs for min noise analysis.
-noise_libs noiseLibs Specifies to read the default CDB files for noise analysis.
-oa_ref_libs oaLibs Specifies to read the OA reference library.
-power_ground_files powerGridLibFiles Specifies to read the power grid library files.
-socv_libs soceLibs Specifies to read the default SOCV libraries.
