init_hier_cell

init_hier_cell
[-help]
cell_names
[-dual_view]

Initializes one or more hierarchical cells based on the applicable order.

Parameters

-help

Prints a brief description that includes the type and default information for each init_hier_cell parameter.

For a detailed description of the command and all its parameters, use the man command:

man init_hier_cell
cell_names

Specifies the names of the hierarchical cells to be initialized.
-dual_view

Binds the top and global views, and initializes the hierarchical cells inside ILMs.
