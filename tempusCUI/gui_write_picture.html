gui_write_picture

gui_write_picture
[-help]
filename
[-format {bmp gif jpg jpeg png pbm pgm ppm xbm xpm}]
[-honor_umask]
[-width integer_value -height integer_value]
[-window string]

Saves a snapshot of the layout or specified window with the specified name in the current directory. You can specify the size as well as the format in which you want to save the snapshot. The command also prints out overlay maps with legends.

You can use this command at any stage of the design flow. 

Parameters

-help

Prints a brief description that includes type and default information for each gui_write_picture parameter.

For a detailed description of the command and all of its parameters, use the man command:

man gui_write_picture

filename

Specifies the name of the picture file as a string. You can specify the file extension as well.

Note: The file extension you specify does not control the format of the picture. The picture file is dumped in the PNG format by default or the format you explicitly specify with -format. For example, the following command saves the testShot picture file in the PNG format:
> gui_write_picture testShot.gif

current_directory@file testShot.gif
testShot.gif: PNG image data, 540 x 688, 8-bit/color RGB, non-interlaced

Data_type: string, required
-format {bmp gif jpg jpeg png pbm pgm ppm xbm xpm}

Specifies the format of the picture file.

Default: png

Data_type: enum, optional
-height integer_value

Specifies the height of the picture as an integral value.

Note: The -width parameter is required when -height is specified.

Min: 100

Max: 20000

Data_type: int, optional
-honor_umask

Honors the umask settings while saving the picture. If you specify this option, the permission of the saved picture file will be set by subtracting the umask value from the full permission value.

For example, if the full permission setting of a file is 0666 and the umask setting is 0022, the tool saves the picture file with the permission setting of 0666 - 0022, that is 0644.

Data_type: bool, optional
-width integer_value

Specifies the width of the picture as an integral value.

Note: The -height parameter is required when -width is specified.

Min: 100

Max: 20000

Data_type: int, optional
-window string

Specifies the ID of the window that you want to dump. You can use the following IDs:

  • For Layout Viewer: designview.win
  • For Cell Viewer: .uiCellView.win

If -window is not specified, the main layout window is dumped out by default.

Data_type: string, optional

Examples

  • The following command captures the layout window and saves it in the default PNG format with the name test2 and the dimensions 1000 x 1000 in the current directory:
    gui_write_picture test2 -width 1000 height 1000
  • The following command captures the layout window and saves it in the GIF format with the name test1.gif in the current directory:
    gui_write_picture -format gif test1.gif
  • The following command captures the layout viewer window and saves it in PNG format with the name testShot.png in the current directory:
    gui_write_picture testShot.png -window designview.win
    Note: You must have the layout viewer open.
  • The following command captures the view in the cell viewer window and saves it in PNG format with the name testCell.png in the current directory:
    gui_write_picture testCell.png -window .uiCellView.win
