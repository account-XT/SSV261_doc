gui_schematic_add_selected

gui_schematic_add_selected
[-help]
[-name window_name]

Adds the selected object to the current or specified schematic view.

Parameters

-help

Prints a brief description of the gui_schematic_add_selected command.

For a detailed description of the command, use the man command: man gui_schematic_add_selected.
-name window_name

Specifies the unique window name for an open schematic view to which the selected object needs to be added.

Data_type: string, optional
