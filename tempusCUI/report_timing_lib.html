report_timing_lib

report_timing_lib
[-help]
[-out_file <string>]
[[[-all | -pin | -threshold | -sibling]
[cell_name]
[-by_lib ]] | -library <string>]

Reports the contents of the timing library.

Parameters


-help Prints out the command usage.
-all Reports all the pin properties, siblings of a cell, the libraries where they are defined, and the voltage.

-by_lib

Organizes the generated report by libraries.

If you do not specify this parameter, the report_timing_lib command prints out cells with the same name together. Use this parameter to support multi-supply multi-voltage feature of the software, where you can define same cell names in more than one library with different voltage values and timing data.
cell_name

Specifies the individual cell name to be reported.
-library string

Reports a specified library.

If you do not specify this parameter, all the library names are reported.
-pin Reports the pin properties, such as the pin name, direction, capacitance, max load, max fanout, and fanout load.
-threshold Reports the input, output, and slew thresholds of a cell.

-sibling

Reports sibling cells, the libraries where they are defined, and the voltage.

-out_file string

Specifies the name of the file to which the results are written.

Command Order

Use this command after importing the design when the timing library is also loaded.

Examples

  • The following command organizes the generated report by libraries and displays all the cell information:
    tempus > report_timing_lib  -by_lib  -all

    InThR=50          InThF=50          OutThR=50       OutThF=50
    SlewLowThR=10     SlewLowThF=10     SlewUpThR=90     SlewUpThF=90
    SlewMLowThR=10    SlewMLowThF=10    SlewMUpThR=90    SlewMUpThF=90

    Pin      Dir   Pin Cap   Rise Cap   Fall Cap   Max Load   Max Tran   FO Load  Max FO  
    D        In    0.001178   0.001180   0.001177      -       5.000000      -        -     
    G        In    0.000734   0.000739   0.000730      -       5.000000      -        -     
    Q        Out   0.000000   0.000000   0.000000   0.008000   5.000000      -        -     

    Sibling cell                       Library                            Voltage  
    DLH_X1                             FrP45_lib_v1.0(libset_slow)    0.80000
    DLH_X1                             FrP45_lib_v1.0(libset_fast)    0.80000

  • The following command reports the input, output, and slew thresholds of the given cell:
    tempus > report_timing_lib -by_lib -threshold
    Cell AND3_X1
    InThR=50          InThF=50          OutThR=50       OutThF=50
    SlewLowThR=10     SlewLowThF=10     SlewUpThR=90     SlewUpThF=90
    SlewMLowThR=10    SlewMLowThF=10    SlewMUpThR=90    SlewMUpThF=90
  • The following command organizes the generated report by libraries and reports the pin properties:
    tempus > report_timing_lib -by_lib -pin
    Cell AND3_X4
    Pin     Dir   Pin Cap   Rise Cap   Fall Cap   Max Load   Max Tran   FO Load  Max  FO  
    A1      In    0.000390   0.000394   0.000385      -       5.000000     -        -     
    A2      In    0.000524   0.000532   0.000517      -       5.000000     -        -     
    A3      In    0.000355   0.000362   0.000347      -       5.000000     -        -     
    ZN      Out   0.000000   0.000000   0.000000   0.032000   5.000000     -        -     
  • The following command reports the cell information in the timing library, and writes the results to the file yz.dmp.lib:
    report_timing_lib -out_file yz.dmp.lib
