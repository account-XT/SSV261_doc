distribute_print_partition_stats

distribute_print_partition_stats  
[-help]
[-all]
[-counts]
[-resources]
[-tcl_list]

Provides an estimate of the client memory requirements after partitioning, based on the instance count for each partition.

This command prints the partition statistics and estimated resource requirements after partitioning.

Parameters

-help      

Prints out the command usage.

-all       

Prints out instance and net counts by partition, overlap statistics, and resource requirements.

-counts    

Prints out the instance and net counts by partition and overlap statistics.

-resources 

Prints out the estimated memory and temp file size requirement by partition. This is the default behavior.
-tcl_list

Returns the requested statistics in a TCL list form.

This parameter is supported with -resources.

Examples

  • The following command shows the client resources:
    distribute_print_partition_stats -resources

    Active analysis views: 1
    Partition 0 Estimated Memory: 50 GB. Estimated /tmp space: 60 GB.

    Partition 2 Estimated Memory: 50 GB. Estimated /tmp space: 60 GB.
    Partition 3 Estimated Memory: 40 GB. Estimated /tmp space: 48 GB.
