create_hinst

create_hinst
[-help]
[-parent <module|hinst|design>] { -name <hinst_name> } { -module <module|design> }

Creates a new hinst object and returns the newly created object pointer.

Parameters 

-help

Outputs a brief description that includes the type and default information for each create_hinst parameter.

For a detailed description of the command and all of its parameters, use the man command: man create_hinst
-module <module>

Specifies the module to be used for the new hinst. The new hinst will have hports/hpins created based on the module ports as well as hnets of the same name.  
-name <hinst_name> Specifies the name of the module instance to add.

-parent <hinst|module|design>

Specifies the parent for the new hinst. It supports both the object or the name for the specified object types.

Default is the current design.

Examples

  • The following command adds a hierarchical instance A/B/spare of module type spareModule to the design, here A/B should be an existing hierarchical instance in the design:
    create_hinst -cell spareModule -hinst A/B/spare
  • The following commands create a new module modA with the instance inst_modA and its clone inst_modA_clone:
    create_hinst -cell modA -hinst inst_modA
    create_hinst -cell modA -hinst inst_modA_clone

    The resulting Verilog netlist would have:
    module modA();
    endmodule
    modA inst_modA();
    modA inst_modA_clone();
