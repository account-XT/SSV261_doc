create_gui_shape

create_gui_shape
[-help]
[-layer layerName]
[-name guiShapeName]
[-width width] 
{-rect {x1 y1 x2 y2} | -line {x1 y1 x2 y2 ...} | -polygon {x1 y1 x2 y2 ...}} 
[ -line {x1 y1 x2 y2 ...} [-arrow ] ]

Adds a shape to the specified custom layer. You can use the create_gui_shape command at any point in the design flow. The shapes added by the command annotate comment shapes and do not show up in a DEF output.

Parameters

-help

Prints a brief description that includes type and default information for each create_gui_shape parameter.

For a detailed description of the command and all of its parameters, use the man command:

man create_gui_shape
-arrow

Draws an arrow in the middle of the line segment to indicate the start to end direction. This parameter can only be used with -line.

Data_type: bool, required

-layer layerName

Specifies the GUI layer name to use or create for the shape. If the specified layer does not exist, it is created automatically. If a layer is not specified, the tool automatically creates a layer with the name defaultLayer and adds the shape to it.

Data_type: string, optional

-line {x1 y1 x2 y2 ...}

Creates a line, with x1 y1 x2 y2 ... specifying the coordinates for the line segments. The values are specified in microns.

Data_type: (point)+, optional
-name guiShapeName

Specifies the name of the GUI shape.

Data_type: string, optional
-polygon {x1 y1 x2 y2 ...}

Creates a polygon shape, with x1 y1 x2 y2 ... specifying the coordinates for the polygon segments. The values are specified in microns.

Data_type: (point)+, optional

-rect {x1 y1 x2 y2}

Specifies the coordinates of the lower-left and upper-right points of the rectangle. The values are specified in microns.

Data_type: rect, optional
-width width

Specifies the width of the shape border in pixels. The minimum (default) value is 1 and the maximum is 7.

Data_type: int, optional

Examples

  • The following command adds a triangular shape in layer 1:
    create_gui_shape -layer 1 -polygon {95.841 -645 96.592 -644.147 96.926 -644.777}

  • The following command adds a line shape with two segments:
    create_gui_shape -layer 1 -line {95.841 -645 96.592 -644.147 96.926 -644.777}

  • The following command adds a line shape with two segments and direction arrows:
    create_gui_shape -layer 1 -line {95.841 -645 96.592 -644.147 96.926 -644.777} -arrow

  • The following command adds a line shape of 3-pixel width:
    create_gui_shape -layer 1 -line {95.841 -645 96.592 -644.147 96.926 -644.777} -width 3
