report_metric

report_metric
[-help]
pattern 
-out_file fileName 
-format {html json}
[-id metricID]
[-names listOfNames]

Allows the user to generate reports in various file formats.  

Parameters

-out_file fileName 

Specifies the name of the target file.
-format {html json} Specifies the output type.
-help

Outputs a brief description that includes type and default information for each report_metric parameter.

For a detailed description of the command and all of its parameters, use the man command: man report_metric
-id metricID Specifies the ID of metrics to report.
-names listOfNames

Specifies the list of names.

Note: Wildcards are supported.
pattern Specifies the pattern to match.
