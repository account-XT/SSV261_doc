connect_hpin

connect_hpin
[-help] 
-hinst moduleName 
-net netName 
[-no_new_hpins] 
-pin_name hpinName

Attaches an hpin in the specified hinst (or top level design) to a net.

Parameters 

-help

Outputs a brief description that includes the type and default information for each connect_hpin parameter.

For a detailed description of the command and all of its parameters, use the man command: man connect_hpin

-hinst hinstName

Specifies the hinst to that has the hpin. To specify the top design, enter `-'.
-net netName  Specifies the name of the net.
-no_new_hpins

Prevents the creation of new hpins. If the hpin cannot connect to the net in a different hierarchy through existing hpins, the software displays an error message and the command stops running.

Default: If you do not specify this parameter, the software creates new hpins as required to reach the net.

-pin_name pinName

Specifies the base_name of the hpin on the hinst.

Examples

  • The connect_hpin command connects the hpin with base_name p1 on hinst  named h1/h2 to the net h1/h2/net3:
    connect_hpin -hinst h1/h2 -pin_name p1 -net h1/h2/net3
