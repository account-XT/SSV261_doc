report_messages

report_messages
[-help]
[[{-errors | -warnings | -all } [-count ]] | -suppressed] [[-prefix <string> [-detail] [-summary ]]]
[-detail | -count | -suppressed ] [-summary | -count | -suppressed]

Reports the messages that have been issued since the software was launched.

When you run the report_messages command without any parameters, it prints a summary table and does not return any Tcl value. However, when you specify a parameter(s), it returns a list a of message IDs.

Parameters

-help

Prints a brief description that includes type and default information for each  report_messages  parameter.

For a detailed description of the command and all of its parameters, use the man command:

man report_messages 

-all

Returns a list of all issued message IDs as a Tcl result. The result does not include suppressed message IDs.
-count Returns a count of every message when the -errors, -warnings, or -all parameter is specified.
-detail Returns a list of detailed message of the specified prefix.
-errors

Returns a list of issued error message IDs as a Tcl result.
-prefix Returns a list of issued error message IDs matched with the specified prefix as a Tcl result.
-summary Returns a message summary of the specified prefixes.
-suppressed

Returns a list of suppressed message IDs as a Tcl result.
-warnings

Returns a list of issued warning message IDs as a Tcl result.

Examples

  • The following command reports the count of all issued message IDs:
    report_messages -all -count

{IMPMSMV-1810 855} {IMPEXT-3570 6} {IMPESI-3140 1} {IMPMF-5054 1} {CHKTIM-4 16} {IMPTCM-6 1} {IMPTCM-46 2} {IMPTCM-48 1} {SPEF-1152 4} {TCLCMD-981 2} {TCLCMD-1110 1} {TCLCMD-1247 1} {TCLCMD-1470 1}

  • The following command reports the count of all issued warning message IDs:
    report_messages -count -warnings  

{IMPMSMV-1810 858} {IMPEXT-3570 6} {IMPESI-3140 1} {IMPMF-5054 1} {CHKTIM-4 16} {SPEF-1152 4}

  • The following command reports a list of suppressed message IDs:
    report_messages -suppressed

IMPESI-3086 IMPESI-3188 IMPESI-3194 IMPESI-3199 IMPESI-3198 IMPESI-3197 IMPESI-3196
