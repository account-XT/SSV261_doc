create_ipd_configuration

create_ipd_configuration 
[-help]
[-no_commit  | -load_constraints ]
[-no_commit  | -load_derates ]
[-setup  | -hold ]
[-setup  | -bounded_corners ]
[-hold  | -bounded_corners ]
[-min_bounded_corner  | -setup  | -bounded_corners  | -max_bounded_corner ]
[-max_bounded_corner  | -hold  | -bounded_corners  | -min_bounded_corner ]
[-min_bounded_corner  | -pd_list <string>]
[-max_bounded_corner  | -pd_list <string>]
[-hold  | -pd_list <string>]
[-setup  | -pd_list <string>]
[-bounded_corners  | -pd_list <string>]

Creates IPD combinations or the analysis views in both the bounded scope generation and the scope analysis session.

This command automatically generates the views based on the set_ipd_rail_voltage settings and loads the view definition for IPD analysis.

Parameters


-help

Prints out the command usage.

-bounded_corners

Creates the minimum/maximum bounding voltage combinations to be used for analysis.

This parameter is used only in scope creation run.

-load_constraints

Loads the constraints stored in IPD scope during scope analysis run. (Applicable only in IPD scope analysis.)

-load_derates

Loads the derates stored in the IPD scope during scope analysis run. (Applicable in only IPD scope analysis.)

-no_commit

Creates the IPD view definition file named, ipdViewDefinition.tcl - but does not load it. By default,  the IPD view definition is read in automatically.

This parameter is mutually exclusive to the -load_derates and -load_constraints parameters.

Examples

  • The following example shows usage of create_ipd_configuration command in scope analysis run.
    create_ipd_configuration -load_derates -load_constraints

    The -load_constraints and -load_derates parameters are optionally used in the scope analysis session to load the constraints and derates stored in the IPD scope. This IPD rail voltage specification, creates 16 (2^4) views corresponding to 4 PG nets.
  • The following command creates bounding IPD views:
    tempus > set_ipd_rail_voltage –sweep { PGN1 {0.7 0.8} PGN2 {0.9 1.0} PGN3 {1.1 1.2} PGN4 {0.6 0.7} }
    create_ipd_configuration –bounded_corners

    This will create bounding IPD views with the following voltage combinations:
    • minimum bounding view: PD1=0.8v PD2=1.0v PD3=1.2v PD4=0.7v
    • maximum bounding view: PD1=0.7v PD2=0.9v PD3=1.1v PD4=0.6v
