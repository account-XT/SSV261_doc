report_critical_nets

report_critical_nets   
[-help] 
[-max_slack double]
[-number integer] 
[-view viewName] 
-out_file fileName 

Generates a file containing a list of nets which have critical slack for the currently specified (setup or hold) timing analysis mode.

Parameters

-help

Prints a brief description that includes type and default information for each  report_critical_nets  parameter.

For a detailed description of the command and all of its parameters, use the man command: man report_critical_nets
-max_slack double

Reports nets with slack less than the specified slack value.

-number integer

Restricts the number of critical nets to be reported to the first integer - most critical nets.

-out_file fileName

Specifies the name of report file.

-view viewName

Generates the report based on the specified analysis view only. You can specify this parameter only when the software is in multi-mode multi-corner timing analysis mode.

Command Order

Use this command after the timing graph is built.

Examples

  • The following command reports nets with slack less than the specified slack value:
    tempus > report_critical_nets -max_slack -1           
    Marking critical nets with target slack = -0.1ps.
    Critical nets number = 7144.
  • The following command generates a maximum slack report for the specified number of critical nets:
    tempus > report_critical_nets -max_slack -1 -number 5
    Marking critical nets with target slack = -0.1ps.
    Critical nets number = 5.
  • The following command generates a report named critnet that lists critical nets:
    report_critical_nets -out_file critnet
