set_aocv_interface_path_offset

set_aocv_interface_path_offset
[-help]
derate_offset_value
[lib_cell_list]
[-view view_name]
[-delay_corner dc_corner_name]
[-cell]
[-net]
-power_domain power_domain_name_list

You can perform path-based inter power domain (IPD) timing analysis by specifying derate offset value for an entire power domain(s) and specific library cell(s) on paths crossing multiple power domains. This feature is supported for path-based analysis (PBA) mode only.

The set_aocv_interface_path_offset command allows you to specify the derate offset value for path segments crossing multiple power domains. The software adds the derate offset value to the AOCV derate value if the combined (AOCV + IPD offset) derate number causes pessimistic PBA timing slack value.

Parameters


-help

Prints out the command usage.

-cell

It is a boolean option. When the -cell option is specified, intent is to apply “derate offset” only for that cell objects.

In absence of these options, derate offset value will be applied to both cell and net type of objects

-delay_corner dc_corner_name

Specifies a list of delay corners.

derate_offset_value

Specifies value of derate offset.

lib_cell_list

Specifies a list of library cells for a specific interface.
-net It is a boolean option. When the -net option is specified, intent is to apply “derate offset” only for that net objects.

In absence of these options, derate offset value will be applied to both cell and net type of objects

-power_domain power_domain_name_list

Specifies a list of power domains.

-view view_name

Specifies a list of views.

Examples

  • The following example specifies the offset derate value of -0.6 for the power domain {PD3 PD4}:
    set_aocv_interface_path_offset -0.6 -power_domain {PD3 PD4} -delay_corner V1_PM1_dc
