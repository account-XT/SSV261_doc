get_clock_network_objects

get_clock_network_objects 
[-help]
[-clocks clock_list]
[-type {cell | pin}]

Returns the cells or pins that exist in a clock network of the specified clocks.

Parameters

-help  Prints out the command usage.
-clocks clock_list Returns the cells or pins present in a clock network of the specified clock(s).
-type {cell | pin}

Returns the specified cells or pins in the clock network.


Examples

  • The following command returns the pins present in the clock network of all the clocks:
    tempus > get_clock_network_objects
  • The following command returns the pins that exist in the clock network of CLK and CLK2 clocks:
    tempus > get_clock_network_objects -clocks {CLK CLK2}
  • The following command returns the cells that exist in the clock network of CLK clock.
    tempus > get_clock_network_objects -clocks {CLK} -type cell
