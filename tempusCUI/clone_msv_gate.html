clone_msv_gate

clone_msv_gate
[-iso]
[-shifter]
[-instances inst1 inst2 .... ]
[-max_fanout integer]
[-max_transition num]
[-max_cap num]
[-honor_pre_placed]
[-honor_dont_touch]

Ensures that the cloned isolation or level shifter can drive a group of the receivers and be placed close to this group of receivers. By doing this, the timing QoR can be improved.

Note: The command will not automatically update your CPF file to match the new netlist. It is advised that you run Conformal Low Power to check for any issues. When the enable signal for isolation cells is cloned (creating new ports on the boundary of the power domain) the users may need to update the create_isolation_rule in CPF by defining the isolation control differently.

Parameters 

-honor_dont_touch

Does not clone don't touch instances or cells.

The default is to clone don't touch instances.

-honor_pre_placed

Does not clone pre-placed (fixed) instances.

The default is to clone fixed instances

-instances inst1 inst2 ...

Clones specified instances.
-max_fanout integer Specifies the maximum fanout count.

-iso

Clones isolation cells.

-max_cap num

An optional check to clone instances with maximum capacitance violation.

The default is not to use -max_cap violation.

-max_transition num

Cloning will be only on instances with maximum transition

time violation.

The default is 2ns.

-shifter

Clones level shifters.
