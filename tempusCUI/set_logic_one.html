set_logic_one

set_logic_one
-help
pin_or_port_list

Sets ports or pins to logic 1 in the design.

Parameters


-help

Outputs a brief description that includes type and default information for each set_logic_one parameter. For a detailed description of the command and all of its parameters, use the man command: man set_logic_one.

pin_or_port_list

Specifies the list of the ports or pins that are to be set to logic 1.

Examples

  • The following command sets the specified port to logic 1:
    tempus > set_logic_one [get_ports {din[1]}]
