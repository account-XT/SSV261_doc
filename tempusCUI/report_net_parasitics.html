report_net_parasitics

report_net_parasitics 
[-help]
net_name
-rc_corner rc_corner_name
[-out_file output_file_name] 

Reports the RC parasitics of the specified net.

The report_net_parasitics command reports a list of attackers in the order of worst coupling capacitance by default. The software determines and reports the probable top N worst attackers for a victim. The command output will show worst coupling capacitance, in addition to RC parasitics.


Parameters

-help Outputs a brief description that includes type and default information for each report_net_parasitics parameter. For a detailed description of the command and all of its parameters, use the man command: man report_net_parasitics.

-out_file output_file_name

Specifies the name of the output file.

-rc_corner rc_corner_name

Specifies the RC corner name for which the RC parasitics are to be reported.

net_name

Specifies the name of the net for which the RC parasitics are to be reported.

Example

  • The following command reports the RC parasitics for net, NET1 for RC corner, rc_best: 
    report_net_parasitics -rc_corner rc_best NET1

    Net: NET1
    RC Corner: rc_best
    Total Cap = 0.473082 ff
    Total Res = 2.104041 ohms
    Total XCap = 0.334035 ff
    Cap Distribution:

    Total Ground Cap = 0.139046 ff
    XCap With Nets:

    NET3 = 0.059964 ff
    NET4 = 0.040277 ff
    NET5 = 0.233794 ff
  • The following command reports the RC parasitics for the specified RC corner and net named E_CN541_ds_dtin_10:
    report_net_parasitics  -rc_corner  corner_worst_RCMAX  E_CN541_ds_dtin_10
    Net: E_CN541_ds_dtin_10
    RC Corner: corner_worst_RCMAX
    Total Cap  = 10.881560 ff
    Total Res  = 294.239014 ohms
    Total XCap = 4.972800 ff
    Cap Distribution:
      Total Ground Cap = 5.908761 ff
      XCap With Nets:
        DATA_SAMPLE_MUX_INST/E_N27_n_39 = 2.341080 ff
        scan_in2 = 2.208500 ff
        E_IG_N67E_N231_digit_5_ = 0.423220 ff
