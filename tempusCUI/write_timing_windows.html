write_timing_windows

write_timing_windows
[-help]
out_file
[-pin]
[-power_compatible]
[-ssta_sigma_multiplier value]
[-view viewName]
[-voltage_threshold {lower_threshold upper_threshold}]

Generates a Timing Window File (TWF). The TWF file primarily contains the earliest and latest possible arrival times for a signal on a net or a pin.

The format of a timing window file consists of eight pairs of data as given below:

(NET <netname>

minRTW:maxRTW minRt:maxRt minRDr:maxRDr minRSlk:maxRSlk minFTW:maxFTW minFt:maxFt minFDr:maxFDr minFSlk:maxFSlk)

Where:

  • minRTW: Minimum rise arrival time
  • maxRTW: Maximum rise arrival time
  • minRt: Minimum rise transition time
  • maxRt: Maximum rise transition time
  • minRDr: Minimum rise source resistance
  • maxRDr: Maximum rise source resistance
  • minRSlk: Minimum rise slack time
  • maxRSlk: Maximum rise slack time
  • minFTW: Minimum fall timing window
  • maxFTW: Maximum fall timing window
  • minFt: Minimum fall transition time
  • maxFt: Maximum fall transition time
  • minFDr: Minimum fall source resistance
  • maxFDr: Maximum fall source resistance
  • minFSlk: Minimum fall slack time
  • maxFSlk: Maximum fall slack time

Parameters

-help Prints out the command usage.

out_file

Writes the TWF file to the specified file name.

The filename parameter must be the last argument in the list.

Note: To write a compressed file, add the .gz extension to the file name.

-pin

Generates a TWF for each pin instead of each net.

Default: Generates a TWF for the crosstalk analysis tool, which contains timing windows on each net.
-power_compatible 

Generates a timing windows file that is suitable for power analysis.

-ssta_sigma_multiplier value

Specifies a sigma multiplier between 0 and 3. The value that you specify increases the arrival window by that amount and worst slack value is generated. The transition and impedance values are not impacted.

-view viewName

Generates a TWF for the specified multi-mode multi-corner view only. You must be multi-mode multi-corner analysis mode to use this parameter.

If the -view parameter is not specified, then by default the first active view will be used to generate timing windows.

-voltage_threshold {lower_thresholdupper_threshold}

Specifies voltage threshold values for generating a Timing Window File (TWF). All the slews in the TWF file will be scaled with these values. The lower threshold value must be less than the higher threshold value.

Value range: 0 to 100

Examples

  • The write_timing_windows -voltage_threshold {20 80} command outputs the following in the TWF file:
    (VOLTAGE_THRESHOLD 20 80)

(WAVEFORM "Iclk1" 10000.000000 (POSEDGE 0.000000) (NEGEDGE 5000.000000))
