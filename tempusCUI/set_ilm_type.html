set_ilm_type

 set_ilm_type
[-help]
[-model {timing | si}]

Controls the behavior of commands in the presence of ILMs.

ILM models can be an SI model or a non-SI model. In the flow, sometimes an explicit flatten_ilm needs to be performed to perform the underlying operation. Based on the nature of operation, an appropriate model could be invoked/switched with the above command.

Use the get_ilm_type command to display the current settings for the set_ilm_type command.

Note: The ILM is not supported for Signoff in Tempus.

Parameters 

-help

Outputs a brief description that includes type and default information for each set_ilm_type parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_ilm_type.

-model {timing | si}

Specifies the ILM model that is to be used by the flatten_ilm command. All the timing-related commands require data to be in the flattened state (physical command require unflattened state).

Design commands such as optDesign, clockDesign, timeDesign, and so on automatically set this parameter before flattening ILMs. However, the CTE commands and some clock commands, which can be run in the flattened mode require manual settings.

  • Use the si model for flattening the SI ILM model.
  • Use the timing model for flattening the non-SI related timing commands.

Note: In case of non-merged models, use the cts model before running flatten_ilm followed by the command which directly deals with the clocks.

Default: timing

Examples

  • The following command can be used to get timing reports containing the SI push-out delays on nets using the -set_ilm_type -model command:
    set_ilm_type -model si

    # Flattens to SI model

    flatten_ilm

    # Turns on SI aware delay calculation

    set_db delaycal_enable_si true

    # Adds incremental delay column (for SI push-out delays)
    #  in timing output:

    set_global_report_timing_format {instance arc cell fanout load slew delay incr_delay arrival}

    # Minimizes the width of the report such that it easily
    # fits into the screen without wrapping

    set_table_style -name report_timing -no_frame -indent 0

    report_timing

Note: You can also invoke the Global Timing Debugger (Timing - Debug Timing - Generate)
