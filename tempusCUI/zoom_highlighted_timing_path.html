zoom_highlighted_timing_path

zoom_highlighted_timing_path
[-help]
[-previous | -next]

Enables zooming into highlighted timing paths within the Timing Debug form in the Layout view, and supports sequential traversal when multiple paths are highlighted. This command reduces the number of steps required to view and navigate timing paths in the Layout view. The command is very useful for zooming into highlighted timing paths in large designs.

Parameters

-help

Outputs a brief description that includes the type and default information for each zoom_highlighted_timing_path parameter.

For a detailed description of the command and all its parameters, use the man command: 
man zoom_highlighted_timing_path

-next

Enables zooming into the next highlighted timing path.
-previous

Enables zooming into the previous highlighted timing path.
