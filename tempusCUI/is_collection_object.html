is_collection_object

is_collection_object 
[-help]
collection

Returns a value of true if the specified object is a collection, otherwise false is returned.

Parameters

-help Prints out the command usage.
collection     Specifies the collection to be checked.

Examples

  • The following example shows how the is_collection_object command can be used to check for collection objects:
    set cells [get_cells]
    set pins [get_pins]
    set nets [get_nets]
    set paths [report_timing -max_paths 5 -coll]
    set heterogenColl ""
    append_to_collection heterogenColl $cells
    append_to_collection heterogenColl $pins
    append_to_collection heterogenColl $nets
    append_to_collection heterogenColl $paths
    set name "123"

    '1' is returned for all of the following 'is_collection_object' commands
      is_collection_object $cells
      is_collection_object $pins
      is_collection_object $nets
      is_collection_object $paths
      is_collection_object $heterogenColl

    '0' is returned for these 'all is_collection_object' commands
      is_collection_object $name
      is_collection_object [get_cells xyz* -quiet]
