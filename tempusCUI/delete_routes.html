delete_routes

delete_routes
[-help]
-net net*

Deletes physical wires, any vias connected to the wires, and violation markers associated with the wires.

Note: The delete_routes command deletes only those vias that are connected to wires. 

Parameters

-help

Prints a brief description that includes type and default information for each delete_routes parameter.

For a detailed description of the command and all of its parameters, use the man command:

man delete_routes

-net net*

Specifies the net or list of nets from which to delete wires. You can use wildcard values in this field. For example, if you specify V*, deletes wires from nets VDD and VSS.

Note: The wires and vias that are shielding the nets specified with delete_routes -net are not deleted.

Data_type: (net)*, mandatory

Examples

  • The following command deletes the wires and vias belonging to the net carry4:
    delete_routes -net carry4
