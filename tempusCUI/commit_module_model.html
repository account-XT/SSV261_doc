commit_module_model

commit_module_model
[-help]
[-copy_mmmc_latencies]
[-merged_mmmc_map_file mapFiles]
[-merged_mmmc_sdc_files mergedSdcFiles]
[-mmmc_file fullChipSdc]
[-mmmc_module_model_tag modelTag]
[-propagate_clocks]
[-cpf_file filename | -1801 filename]Specifies and commits flexILM. 

Commits module models.

Note: The ILM is not supported for Signoff in Tempus.

Parameters

-1801 filename Specifies IEEE 1801 file.
-copy_mmmc_latencies

Copies clock latencies of all the analysis views at the top-level design and applies them after assembling the design:

When this option is specified, the command will do following after assembling the design:

update_analysis_view -name $view -latency_file $latency_map($view)

Where latency_map has clock latency files for all the views.
-cpf_file filename 

Specifies the name of the full chip CPF file to be used.
-help

Outputs a brief description that includes the type and default information for each commit_module_model parameter.
For a detailed description of the command and all of its parameters, use the man command:
man commit_module_model
-merged_mmmc_map_file mapFiles

Specifies merge hierarchical mmmc map files.
-merged_mmmc_sdc_files mergedSdcFiles Specifies SDC files for different dies.
-mmmc_file fullChipSdc  Specifies the name of the full chip MMMC view file.
-mmmc_module_model_tag modelTag

Specifies MMMC module model tag.
-propagate_clocks

Changes clock ideal to propagated clock. When this option is specified, you can run the following commands:

 set_interactive_constraint_modes [all_constraint_modes -active]

 set_propagated_clock [all_clocks]
