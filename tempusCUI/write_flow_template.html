write_flow_template

write_flow_template
[-help]
[-describe string]
[-directory string]
[-enable_feature string]
[-ip_steps string]
[-list]
[-optional_feature string]
[-tech_steps string]
[-template_file string]
[-tools]
[-type string]
[-user_steps string]
[-version string]

Creates a set of template TCL files to be used as the basis for a flow. This command is used at the beginning after which, you can manage the generated and modified files. When invoking the command, you will select the type of flow required (implying a subset of template scripts to include) and the arrangement of sections across generated files.

On completion, a message is given to indicate creation of the flow template in the specified directory.

Parameters

-help

Outputs a brief description that includes type and default information for each write_flow_template parameter.

For a detailed description of the command and all of its parameters, use the man command:
man write_flow_template.
-describe string

Specifies detailed description of the available flow features. If it matches multiple features, then these features are listed along with a short description for each.
If it matches exactly one feature, a full description of this feature is printed. Matching no features results in an error.
-directory string

Specifies the name of the directory for saving the generated files. If no directory is specified, the command uses the name flow.
If required, the tool appends “_” and an integer to the directory name to avoid overwriting an existing directory. For example, flow_1, flow_2 and so on). 
-enable_feature string Specifies a list of flow features that are unconditionally incorporated into the generated scripts.
-ip_steps string Overlays the contents of the generated flow.yaml file and inserts the specified scripts under the ip_flow_steps flow.
-list

Lists the available flow templates.
-optional_feature string Specifies a list of flow features that are conditionally incorporated into the generated scripts.
Both the enabled and disabled code are included, with conditionals based on a new user attribute.
-tech_steps string

Overlays the contents of the file(s) generated by running the write_flow_template command. The file(s) provided with this parameter are copied into the scripts directory inside a tech sub-folder and appear in tech_flow_steps for the stylus flows.
-template_file string Specifies the flow template file.
-tools Returns the list of tools whose scripts should be included in the flow.
-type string Specifies the type of flow to be used.
-user_steps string

Overlays the contents of the generated flow.yaml file and inserts the specified scripts under the user_flow_steps flow.
-version string Specifies the version of the flow to be used.
