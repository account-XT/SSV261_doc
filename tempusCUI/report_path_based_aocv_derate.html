report_path_based_aocv_derate

report_path_based_aocv_derate
  [-help]
  [-aocv_derate_only]
  [-delay_corner delayCornerName]
  [-derate_mode {worst_slack | worst_derate}]
  [-early]
  [-include_clock_derate]
  [-late]
  [-max_slack val]
  [-max_paths integer | -max_points integer]
  [-nworst worst_entries]
  [-retime {aocv | aocv_path_slew_propagation}]
  [-retime_mode {path | exhaustive}]
  [> filename[.gz]]
  [>> filename[.gz]]

Parameters

-help Prints out the command usage.
-aocv_derate_only Allows AOCV reporting only.
-delay_corner delayCornerName Specifies name of the delay corner.
-derate_mode {worst_slack | worst_derate}

Specifies the derating mode.

Default: worst_derate
-early Specifies derates for early paths.
-include_clock_derate Includes the clock derate values.
-late Specifies derates for late paths.
-max_paths integer Reports derates based on the specified number of paths.
-max_points integer Reports derates based on the specified number of endpoints.
-max_slack val Reports the upper bound value of the reported slack.
-nworst worst_entries Reports the derates based on the specified number of worst paths per end point.
-retime {aocv | aocv_path_slew_propagation}

Reanalyzes the specified set of paths using the specified method.

Default: aocv
-retime_mode {path | exhaustive} Defines the retime mode as path or exhaustive.
> filename[.gz] Redirects output to the specified file.
>> filename[.gz] Redirects output to the specified file.

Examples

  • The following command reports derates based on the given number of paths for the specified delay corner:
    tempus > report_path_based_aocv_derate -delay_corner DC_wc -max_paths 1 

    INFO: Path Based Analysis (PBA) performed on total '1' paths
    set_timing_derate -late -delay_corner DC_wc -data -rise 1.600 [get_cells { i0 }]
    set_timing_derate -late -delay_corner DC_wc -data -rise 1.000 [get_cells { i1 }]
    set_timing_derate -late -delay_corner DC_wc -data -rise 1.000 [get_cells { sub_inst1/i1 }]
  • The following command reports clock derates for the specified delay corner:
    tempus 8> report_path_based_aocv_derate -delay_corner DC_wc -include_clock_derate             

    INFO: Path Based Analysis (PBA) performed on total '4' paths
    set_timing_derate -late -delay_corner DC_wc -data -rise 1.600 [get_cells { i0 }]
    set_timing_derate -late -delay_corner DC_wc -data -rise 1.000 [get_cells { i1 }]
    set_timing_derate -late -delay_corner DC_wc -data -fall 1.014 [get_cells { i2 }]
    set_timing_derate -early -delay_corner DC_wc -clock -rise 0.820 [get_cells { i3 }]
