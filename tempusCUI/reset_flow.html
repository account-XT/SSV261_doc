reset_flow

reset_flow
[-help]
[-all]
[-edits]
[-features]
[-flows]
[-history]
[-steps]

Resets the content for the current flow in the software by clearing any existing flows, steps, or features. The functionality of the -history parameter of this command is equivalent to run_flow -reset.

Parameters

-help

Outputs a brief description that includes the type and default information for each reset_flow parameter.

For a detailed description of the command and all its parameters, use the man command:
man reset_flow
-all

Resets all the flows, steps, features, edits, and history set in the software.

Data_type: bool, optional
-edits

Resets all the flow edits appended through the edit_flow command.

Data_type: bool, optional
-features

Resets all the flow features and associated values.

Data_type: bool, optional
-flows

Resets all the flow objects.

Data_type: bool, optional
-history

Resets flow history and state of all the attributes (such as flow_step_canonical_current, flow_history, and flow_top).

Data_type: bool, optional
-steps

Resets all the flow_step objects.

Data_type: bool, optional
