set_quiet_aggressor

set_quiet_aggressor 
[-help]
[-analysis_type {early | late}]
[-aggressor string] 
[-transition {rise | fall}]
[-victim string]
[-view string]

Specifies one or more coupled nets as non-attackers (silent) for the delay and glitch analysis of a given victim net.

You can run the update_glitch or update_timing command and view the results in the report_noise or report_timing command output.

Parameters

-help Prints out the command usage.
-analysis_type {early | late} Specifies the analysis type for which the attackers will be assumed quiet. If no value is specified, attackers are skipped for both early/late analysis. 
-aggressor string

Specifies the attackers which should be made quiet for given victim net(s). If no attacker is specified, all the aggressors of given victim(s) will be ignored.

Note: If no victim is specified, the specified attackers are made quiet for all victim nets in the design. 
-transition {rise | fall} Specifies the victim transition for which attackers will be assumed quiet. If no value is specified, attackers are skipped for both rise and fall transitions of the victim net. 

-victim string

Specifies a list of victim nets for which attackers should be made quiet. Specific attackers can be skipped using the -aggressor option of this command. If the -aggressor option is not specified, all the attackers of the given nets are made silent and SI analysis will not be performed on these nets.

Note: If this option is not specified, the attackers specified in the -aggressor option are made quiet for all the nets in the design.  
-view string

Specifies the view for which attackers should be made quiet. If no view is specified, attackers are assumed quiet in all views

Examples

Consider a design having an attacker agg to victim nets vic1 and vic2. The following command sets the attacker agg as quiet for both the victim nets vic1 and vic2.
tempus > set_quiet_aggressor –aggressor {agg}

  • The following command sets the attackers A1 and A2 as quiet when V1 is rising during late analysis. 
    tempus > set_quiet_aggressor –victim V1 –aggressor A1 A2 –transition rise –analysis_type late
  • The following command sets the attacker A1 quiet for victim V1 in the analysis view VIEW1. In this case, A1 may be a valid attacker during SI analysis for victim V1 in views other than VIEW1. 
    tempus > set_quiet_aggressor –victim V1 –aggressor A1 –view {VIEW1}

Consider a design having victim vic with attackers agg1 and agg2:

  • The following command sets both the attackers agg1 and agg2 as quiet for the victim net vic.
    tempus > set_quiet_aggressor –victim {vic}
  • The following command sets the attacker agg1 as quiet for the given victim net vic
    tempus > set_quiet_aggressor –aggressor {agg1} –victim {vic}
