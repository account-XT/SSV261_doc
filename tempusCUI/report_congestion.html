report_congestion

report_congestion
[-help]
[-3d]
[-hotspot]
[-include_blockage]
[-num_hotspot number]
[-overflow]

Reports the early global route congestion and the local hotspot score.

Route needs be called before using this command.

Parameters 

-help

Outputs a brief description that includes type and default information for each report_congestion parameter.

For a detailed description of the command and all of its parameters, use the man command: man report_congestion.
-3d Honors 3d congestion map. When specified, it enables the layer-based congestion reporting.
-hotspot Reports the local hotspot score.
-include_blockage Includes blockage area in hotspot.
-num_hotspot number Specifies the number of hotspots to be reported.
-overflow Reports horizontal and vertical overflow. 

  • The following command reports the local hotspot score:

    report_congestion -hotspot

    Output:  

    Local HotSpot Analysis: normalized max congestion hotspot area = 0.00, normalized total congestion hotspot area = 0.00 (area is in unit of 4 std-cell row bins)
