write_exclude_nets

write_exclude_nets 
[-help]
out_file

Writes out the excluded nets to an output file. Nets that exceed the default value of 1,000 pins are excluded from delay calculation, and default delay values are used. . 

You can use delaycal_excluded_net_file attribute to use the file containing nets to be excluded during delay calculation. The list of excluded nets can be redirected to an output file.

Parameters

-help Prints out the command usage
out_file Specifies the name of the excluded net file.
