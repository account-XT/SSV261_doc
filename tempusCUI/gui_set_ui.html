gui_set_ui

gui_set_ui
[-help]
name
[-before name]
[-checked {true | false}]
[-command string]
[-disabled {true | false}]
[-enable_variable string]
[-foreground string]
[-geometry string | -full_screen {true | false}]
[-icon filename]
[-in name]
[-label string]
[-message string]
[-movable {true | false}]
[-menu_separate {true | false}]
[-newline {true | false}]
[-shortcut string]
[-statusbar string] 
[-title string]
[-titlebar_color string]
[-tooltip string]
[-underline integer]
[-value string ]
[-variable string]
[-visible {true | false}]
[-visible_variable string]

Sets the specified property of an element. Use this command to customize the tool's graphical interface by configuring various interface elements, such as submenus and commands. The properties that can be set for a specific element depends on the type of that element. To see the list of properties that can be set for each type, see the "Accepted Properties for Each Type" section below.

For elements of type menu, submenu, command, check, radio, separator, toolbar, and toolbutton, the gui_set_ui command works like the tk command widgetconfigure. For the main window (main), it works like the tk command wm.

Parameters 

-help

Prints a brief description that includes type and default information for each gui_set_ui parameter.

For a detailed description of the command and all of its parameters, use the man command:

man gui_set_ui

name

Specifies the name of the element whose property is to be set. An error is returned if specified name does not exist.

Data_type: string, required

-before name

Sets the specified element before the element identified by name.

Data_type: string, optional

-checked {true | false}

Checks or unchecks the specified element.

Note: You can use the -checked parameter only for elements of type check or radio.

Data_type: bool, optional

-command string

Specifies the Tcl command to be executed when the specified element is invoked.

Note: You can use the -command parameter only if you are adding elements of type command, check, radio or toolbutton.

Data_type: string, optional

-disabled {true | false}

Disables or enables the specified interface element.

Note: You can use the -disabled parameter only for elements of type menu, submenu, command, check, radio or toolbutton. The parameter is NOT applicable for elements of type toolbar and separator.

Data_type: bool, optional

-enable_variable string

Sets the Tcl global variable for Enable status.

Data_type: string, optional

-foreground string

Specifies the foreground color of the icon of the specified interface element.

Note: You can use the -foreground parameter only if you are adding an element of type toolbutton.

Data_type: string, optional
-full_screen {true | false}

Maximizes the main window. This property can be set only for the element main.

Note: This option cannot be used with -geometry.

Data_type: bool, optional
-geometry string

Modifies the geometry of the specified window element.

Data_type: string, optional

-icon filename

Specifies the file name of the toolbutton icon. filename can be the full path of the icon file or an icon name supported by the tool.

The icon names used in the tool can be queried using the gui_get_ui command.

For list of supported image formats for the icon file, see the "Supported Image Formats" section of the Customizing the User Interface chapter in the User Guide.

Note: The -icon parameter is applicable only for elements of type toolbutton.

Data_type: string, optional

-in name

Specifies the name of the parent element.

Data_type: string, optional

-label string

Specifies the label to be displayed on the element being modified.

Note: This parameter is NOT applicable for elements of type separator.

Data_type: string, optional
-message string

Specifies the message to be displayed on the element being modified.

Note: This parameter is applicable for elements of type statusbar.

Data_type: string, optional
-menu_separate {true | false}

Specifies whether or not a menu or submenu can be torn off or detached.

  • When set to true (default), a dashed line appears at the top of the menu or submenu to indicate that it can be detached. 
  • When set to false, the dashed line no longer appears at the top of the menu or submenu and it cannot be detached. 

Note: This parameter is applicable for elements of type menu and submenu.

Data_type: bool, optional
-movable {true | false}

Specifies whether or not the element being modified should be movable.

Note: The -movable parameter is applicable only for elements of type toolbar.

Data_type: bool, optional

-newline {true | false}

Specifies whether or not the element being modified should be on a new row.

Note: The -newline parameter is applicable only for elements of type toolbar.

Data_type: bool, optional

-shortcut string

Specifies the shortcut key for a command, check box, radio button, or toolbutton.

Note: You can use the -shortcut parameter only if you are modifying elements of type command, check, radio, or toolbutton.

Data_type: string, optional
-statusbar string

Sets the statusbar of the specified window element.

Data_type: string, optional
-title string

Specifies the window title.

Data_type: string, optional

-titlebar_color string

Sets the color of the title bar of the window.

Note: This parameter is applicable only for the main window (main).

Data_type: string, optional

-tooltip string

Specifies the tooltip text for the toolbar or toolbutton you are adding.

Note: The -tooltip parameter is applicable only for elements of type toolbar and toolbutton.

Data_type: string, optional

-underline integer

Specifies the integer index of the character to be underlined in the element label. The index begins with 0 and should have a value less than or equal to the length of the element label. For instance, if you want the second letter of the element label to appear underlined, specify integer as 1.

Note: The -underline parameter is NOT applicable for elements of type toolbar, separator, and toolbutton.

Data_type: int, optional

-value stringValue

Specifies the value to be stored in the associated variable when the specified radio button is selected.

Note: The -value parameter is applicable only for elements of type radio.

Data_type: string, optional

-variable string

When modifying a check box or radio button, specifies the Tcl global variable for the item.

Data_type: string, optional
-visible {true | false}

Specifies the visibility status of the element being modified.

Data_type: bool, optional

-visible_variable string

Sets the Tcl global variable for Visible status.

Data_type: string, optional

Accepted Properties for Each Type

The accepted properties for each type are listed below.

  • For the main window (main), the following properties can be set:
    -geometry {widthxheight | widthxheight+x+y}
     -title title
     -close_command string
     -visible true | false
  • For a status bar (statusbar), the following property can be set:
    -enable_variable string
     -in parentname
     -message msg
     -visible true | false
     -visible_variable string
  • For elements of type menu or submenu, the following properties can be set:
    -enable_variable string
     -before nextSiblingName]
     -disabled true | false
     -in parentName
     -label label
    -menu_separate true | false
     -underline index
     -visible true | false
     -visible_variable string
  • For elements of type command, radio, and check, the following properties can be set:
    -disabled true | false
     -label label
     -underline index
     -command commandName
     -in parentName
     -before nextSiblingName
     -enable_variable string
     -visible true | false
     -visible_variable string
     -shortcut string
     
    For radio and check, the -checked and -variable properties can also be set.
  • For elements of type toolbutton, the following properties can be set:
    -state normal | disabled
     -label label
     -tooltip toolTipText
     -underline index
     -foreground colorName
     -icon iconName
     -command commandName
     -in parentName
     -before nextSiblingName
     -enable_variable string
     -visible true | false
     -visible_variable string
     -shortcut string

Examples

  • The following command makes the View menu in the main window non-detachable:
    gui_set_ui view -menu_separate false
  • The following command sets the color of the main window's title bar to blue:
    gui_set_ui main -titlebar_color blue
