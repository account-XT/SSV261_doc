delete_nets

delete_nets
[-help]
[-all <string>]
-module <string>
net

Logically deletes nets from a design. If a net is routed, wire segments associated with the net are also deleted.

You can use wildcards (*?) to specify the nets you want Tempus to delete.

Parameters

-all <string> Deletes all nets from a design.

-module <string>

 Deletes the net from the specified verilog module.

net

 Specifies the list of nets to be deleted.

Example

  • The following command deletes net1: 
    tempus> delete_nets net1
  • The following command deletes all nets whose name begin with net1: 
    tempus> delete_nets net1*
  • The following command deletes all nets from the design:
    tempus> delete_nets -all
  • The following command deletes the net with base name ant_net[1] from module H[1]:
    tempus> delete_nets {\ant_net[1] } -module {\H[1] }
