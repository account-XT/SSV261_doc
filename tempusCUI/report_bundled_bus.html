report_bundled_bus

report_bundled_bus 
[-help] 
[-name string]
[-nets string]
[-type {user_defined | tool_inferred}]
[[ > | >> ]]

Generates a report for bundled buses.

Parameters

-help                                                                  

Prints out the command usage.

-name string                                                

Specifies the name of the user-defined bus group(s) to be reported.

-nets string                                                 

Specifies the name of the net(s) to be reported.

-type {user_defined | tool_inferred}          

Reports the type of bundled bus(es) - user-defined or tool-inferred - to include in the report.

By default, the report_bundled_bus command generates reports for both user-defined and software-inferred type of buses.

> filename                                       

Redirects the output to the specified file.

>> filename                                       

Appends to the specified output file.

Examples

  • The following command reports details of user-defined bus group bus1:
    tempus > report_bundled_bus -name bus1

    Summary:
    Total number of user defined bus groups reported  = 1
    Total number of tool inferred bus groups reported = 0

    ------------------------------------------------------  

    Group Name (user_defined) : bus1

    Constituents:
    - FE_OF_13

  • The following command reports details of user-defined bus group bus2 for the specified nets:
    tempus > report_bundled_bus -nets FE_OF_2
    Summary:
    Total number of user defined bus groups reported  = 1
    Total number of tool inferred bus groups reported = 0

    ------------------------------------------------------ 

    Group Name (user_defined) : bus2

    Constituents:
    - FE_OF_2

  • The following command reports the user_defined bundled buses:
    tempus > report_bundled_bus -type user_defined

    Summary:
    Total number of user defined bus groups reported  = 2
    Total number of tool inferred bus groups reported = 0

    -------------------------------------------------------

    Group Name (user_defined) : bus1

    Constituents:
    - FE_OF_13
    -------------------------------------------------------

    Group Name (user_defined) : bus2

    Constituents:
    - FE_OF_2
    - FE_OF3_data_out_1
    ------------------------------------------------------
