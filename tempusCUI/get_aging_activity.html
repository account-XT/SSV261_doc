get_aging_activity

get_aging_activity 
[-help]
-net <string>
[-views <string>]

Returns the current settings of the set_aging_activity command.

Parameters

-help Prints out the command usage.
-net <string> Returns the net names.
-views <string> Returns a list of the specified views.
