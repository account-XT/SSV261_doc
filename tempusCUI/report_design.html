report_design

report_design
[-help]
[-view viewName]
[{> | >>} filename | -tcl_list]
[-early | -late]

Reports the minimum and/or maximum operating conditions and active design rules for the current design.

Both minimum and maximum operating conditions are available for on-chip variation analysis mode.

When simultaneous setup hold analysis mode is set to on, the minimum or maximum conditions can be reported using the -early/-late parameters.

Parameters


-help Prints out the command usage.

{> | >>} filename

When specified with >, writes the report to the specified file name. If the file already exists, the software overwrites it.

When specified with >>, writes the report to the specified file name. If the file already exists, the software concatenates the report to the end of the file.

The filename parameter must be the last argument in the list. The filename and -tcl_list parameters are mutually exclusive; you cannot specify them together.

Note: To write a compressed report, add the .gz extension to the file name.

Default: Report is displayed on standard output without being saved.

-early | -late

The -early parameter reports minimum operating condition in best_case_worst_case or ocv analysis mode (timing_analysis_type attribute).

The -late parameter reports maximum operating condition.

The -late and -early parameters are mutually exclusive.

-tcl_list

Produces the report in Tcl list format instead of a tabular format. This is useful for integrating timing with custom Tcl functions, and also for customizing report generation.

Note: The -tcl_list and filename parameters are mutually exclusive; you cannot specify these parameters together.

-view viewName

Reports view specific operating conditions.

Examples

  • The following command reports the operating conditions related to the view, scan_slow_RCMAX, along with the design rules:
    report_design -view scan_slow_RCMAX
