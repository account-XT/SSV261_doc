check_timing_model

check_timing_model
 [-absolute_cap_tolerance float]
[-absolute_tolerance float]
[-absolute_tolerance_optimistic float]
[-absolute_tolerance_pessimistic float]
[-absolute_transition_tolerance float]
-compare_file string
[-ignore_view]
-out_file string
[-percentage_cap_tolerance float]
[-percentage_tolerance float]
[-percentage_tolerance_optimistic float]
[-percentage_tolerance_pessimistic float]
[-percentage_transition_tolerance float]
-reference_file string

Compares two reports that contain interface timing characteristics generated by the report_timing_model command.

This command compares the interface timing report generated by using the report_timing_model command on the original netlist with the interface timing report generated by using the report_timing_model command on the model extracted for the same design.

Parameters 

-help

Outputs a brief description that includes type and default information for each check_timing_model parameter. For a detailed description of the command and all of its parameters, use the man command: man check_timing_model.

-absolute_cap_tolerance float

Specifies the tolerance value for capacitance (as an absolute value) while comparing two report files. This parameter specifies the permissible difference, as an absolute value, between the capacitance values of two report files. If the difference in the value of capacitance exceeds the absolute tolerance value specified, the comparison status is set to FAIL.

Note: When this parameter is not specified, the software uses the absolute value specified with the -absolute_tolerance parameter. If the -absolute_tolerance parameter is not specified, the value defaults to 0.


When the -percentage_cap_tolerance and -absolute_cap_tolerance parameters are used together, the comparison status is set to FAIL only when the difference in the value of capacitance exceeds the specified absolute as well as percentage tolerance values.

-absolute_tolerance float

Specifies the absolute tolerance value. The tolerance value is used when there is a difference between the timing characteristics of the reference file (-reference_file) and the file that is being compared (-compare_file) to determine the PASS or FAIL status of the comparison. If the difference in the value of a timing characteristic exceeds the absolute tolerance value, the comparison status is set to FAIL.

Note: When used with the -percentage_tolerance option, the difference in the value of a timing characteristic should exceed both absolute and percentage tolerance values for the comparison result status of an arc to be FAIL.

Default: 0

-absolute_tolerance_optimistic float

Specifies the absolute tolerance limit for flagging an optimistic failure. An optimistic path violating absolute as well as percentage tolerance limit will be flagged as FAIL in the report output.

Default: 15ps

-absolute_tolerance_pessimistic float

Specifies the absolute tolerance limit for flagging a pessimistic failure. A pessimistic path violating absolute as well as percentage tolerance limit will be flagged as FAIL in report output.

Default: 15ps

-absolute_transition_tolerance float

Specifies the tolerance value for transition time at ports (as an absolute value) while comparing two report files. This parameter specifies the permissible difference, as an absolute value, between the transition time at ports of two report files. If the difference in the transition time exceeds the absolute tolerance value specified, the comparison status is set to FAIL.

Note: When this parameter is not specified, the software uses the absolute value specified with the -absolute_tolerance parameter. If the -absolute_tolerance parameter is not specified, the value defaults to 0.


When the -percentage_transition_tolerance and -absolute_transition_tolerance parameters are used together, the comparison status is set to FAIL only when the difference in the value of transition exceeds the specified absolute as well as percentage tolerance values.

-compare_file string

Specifies the name of the report file that contains the interface timing characteristics extracted from the model created using the write_timing_model command. The timing characteristics of this file are compared with the timing characteristics of the reference file that you specify with the -reference_file option.

-ignore_view

Compares non-MMMC design report_timing_model output report with the MMMC design output report (of report_timing_model command).

When you specify this parameter, the software ignores the view information while comparing the reports. So you do not require to create dummy views for timing model validation flow.

-out_file string

Specifies the name of the output file in which the comparison results will be generated. This file contains the PASS or FAIL status for the timing data comparison.

-percentage_cap_tolerance value

Specifies the tolerance value for capacitance (as a percentage) while comparing two report files. This parameter specifies the permissible difference, in percentage, between the capacitance values of two report files. If the percentage difference in the value of capacitance exceeds the percentage tolerance value specified, the comparison status is set to FAIL.

Note: When this parameter is not specified, the software uses the percentage value specified with the -percentage_tolerance parameter. If the -percentage_tolerance parameter is not specified, the value defaults to 0.


When the -percentage_cap_tolerance and
-absolute_cap_tolerance parameters are used together, the comparison status is set to FAIL only when the difference in the value of capacitance exceeds the specified absolute as well as percentage tolerance values.

-percentage_tolerance float

Specifies the percentage tolerance value for comparing the timing data of two report files. The percentage tolerance value is used when there is a difference between the timing characteristics of the reference file (-reference_file) and the file that is being compared (-compare_file) to determine the PASS or FAIL status of the comparison. If the percentage difference in the value of a timing characteristic exceeds the percentage tolerance value, the comparison status is set to FAIL.

Note: When used with the -absolute_tolerance option, the difference in the value of a timing characteristic should exceed both percentage and absolute tolerance values for the comparison result status of an arc to be FAIL.

Default: 0

-percentage_tolerance_optimistic float

Specifies the percentage tolerance limit for flagging an optimistic failure. An optimistic path violating percentage as well as absolute tolerance limit will be flagged as FAIL in the report output.

Default: 3%

-percentage_tolerance_pessimistic float

Specifies the percentage tolerance limit for flagging a pessimistic failure. A pessimistic path violating percentage as well as absolute tolerance limit will be flagged as FAIL in the report output. 

Default: 3%

-percentage_transition_tolerance float

Specifies the tolerance value for transition time at ports (as a percentage) while comparing two report files.This parameter specifies the permissible difference, in percentage, between the transition time at ports of two report files. If the percentage difference in the transition time exceeds the percentage tolerance value specified, the comparison status is set to FAIL.

Note: When this parameter is not specified, the software uses the percentage value specified with the -percentage_tolerance parameter. If the -percentage_tolerance parameter is not specified, the value defaults to 0.


When the -percentage_transition_tolerance and
-absolute_transition_tolerance parameters are used together, the comparison status is set to FAIL only when the difference in the value of transition exceeds the specified absolute as well as percentage tolerance values.

-reference_file string

Specifies the name of the reference file that is used for comparison. This is the report file that was generated by using the write_timing_model command on the original design.

The file specified with the -compare_file option is compared with this file.
