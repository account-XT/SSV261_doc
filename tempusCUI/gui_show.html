gui_show

gui_show 
[-help] 
[on | off]

Opens the Tempus main window. This is usually done after executing the command Tempus -init tclCommandFile.

If you run the gui_show command when the Tempus main window is already displayed, the form is refreshed and the display is fitted to the design area.

Note: If you started the Tempus software with the tempus -gui_show off command, you cannot then use the gui_show command to display the Tempus main window.

Parameters

-help Prints a brief description that includes type and default information for each win parameter. For a detailed description of the command and all of its parameters, use the man command: man gui_show
on | off Specifies to on or off the window.
