report_socv_library

report_socv_library  
[-help]
[-categories string]
[-coverage_verbose]
[-list_not_annotated]
[-library_set string | { -delay_corner string [ -power_domain string] }| { -view string [-power_domain string]}]
[-libraries string | -lib_cells string]
{-coverage}

Reports the coverage of SOCV library(s) loaded in the design.

Parameters

-help                     

Prints out the command usage.

-categories string

Allows you to control what types of table data to check delay arcs, transition arcs, and check arcs. 

Default: all

-coverage                 

Controls for reporting coverage library data.

-coverage_verbose         

Generates a detailed report table per cell.

-delay_corner string   

Checks all the libraries defined in the specified delay corner.

-lib_cells string      

Specifies the library cells.

The allowed format is \u201clibrary/cell\u201d name or pattern or collection. This will typically be done to drill-down debugging of problems.

-libraries string         

Allows you to select the library. 

If -library_set, -delay_corner, or \u2013view is not specified then all libraries matching the library name across the MMMC configuration will get checked.

-library_set string        

Checks all the libraries defined in the specified library set.

-list_not_annotated       

Allows you to control the types of table data to check delay arcs, transition arcs, and check arcs. 

Default: all

-power_domain string  

Checks the specified power domain.

-view string        

Checks all the delay corners associated with the specified view.
