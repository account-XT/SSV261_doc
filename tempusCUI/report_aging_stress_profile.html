report_aging_stress_profile

report_aging_stress_profile 
[-help]
[-early]
[-late]
[-views <string>]

Reports the stress profiles for aging-aware STA defined using the create_aging_stress_profile command. The report contains stress duration, stress temperature, and stress voltage per power rail.

Parameters

-help

Prints out the command usage.

-early

Reports the stress profile associated with early paths.

-late

Reports the stress profile associated with late paths.

-views <string>

Specifies a list of view names associated with the aging stress profile.
