set_preference

set_preference 
[-help] 
preference_name 
value 

Defines preferences, such as, commands issued during a session can be logged to a log or the screen. 

Parameters

-help

Outputs a brief description that includes type and default information for each set_preference parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_preference.

preference_name

Specifies the name of the preference variables that you want to set.

To view preferences in the Tempus GUI, select View - Set Preferences from the main menu.

For more details, refer to the "Set Preferences" section of the Tempus Menu Reference guide.

value

The value for the preference. For example, the CmdLogMode preference has the following values.

0--write to command only

1--write to command and log (default)

2--write to command, log, and screen

When writing to a log and screen, the commands are preceded by <CMD>.

Preference Variables

For a complete list of preference variables that you can set using the  set_preference command and their GUI equivalent in the Preferences form.

Examples

The following command writes log to command, log, and screen:

tempus > set_preference CmdLogMode 2

Related Topics

For more information on setting preferences from the GUI, see:

  • The Preferences form in the "Tools Menu" chapter in the Tempus Menu Reference.
