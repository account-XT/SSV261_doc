get_cpf_user_attributes

get_cpf_user_attributes
[-help]
-domain domainName | -net netName

Reports the user_attributes of the power domain or net specified in the CPF file. If the domain or net has no user_attributes in the CPF file, then this command reports an empty string.

Parameters 

-help

Outputs a brief description that includes type and default information for each get_cpf_user_attributes parameter.

For a detailed description of the command and all of its parameters, use the man command:
man get_cpf_user_attributes

-domain

Specifies the name of the power domain containing the user_attributes.

-net

Specifies the name of the net having the user_attributes.
