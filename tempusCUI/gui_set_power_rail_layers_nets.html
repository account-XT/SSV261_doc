gui_set_power_rail_layers_nets


set_power_rail_layers_nets
[-help]
[-design_opacity value]
[-rail_analysis_opacity value]
[-nets {{all_power 0/1}{all_ground 0/1}} |
 -enable_nets {names} |
 -disable_nets {names} ]
[-enable_switch_nets {all|net_names} |
 -disable_switch_nets {all|net_names} ]
[-enable_report_layers {all|layer_names} |
 -disable_report_layers {all|layer_names} |
 -layers {{name report0/1 visible0/1}{...}} ]
[-enable_visible_layers {all|layer_names} |
 -disable_visible_layers {all|layer_names} |
 -layers {{name report0/1 visible0/1}{...}} ]
[-enable_visible_signal_em_layers {all|layer_names} |
 -disable_visible_signal_em_layers {all|layer_names} ]
[-show_layer_net_setting_list {true | false}]
[-via_size {1 | 2 | 3 | 4 | 5 | 6}]

Controls the visibility of the layers, the opacity of the rail analysis or design database, and the visibility of power/ground nets.


Parameters


-help

Outputs a brief description that includes type and default information for each gui_set_power_rail_layers_nets parameter.

For a detailed description of the command and all of its parameters, use the man command: man gui_set_power_rail_layers_nets.
-design_opacity value

Specifies the design opacity value for the design database.

The opacity range is from 0-100%, the default value is 60.
-disable_nets {names}

Hides the specified nets. This parameter is mutually exclusive to the -enable_nets and -nets parameters.
-disable_report_layers {all|layer_names}

Hides the report (user-defined layers to be used for processing) layers. You can use all to hide all layers, or list the specific layers that are not to be displayed.

This parameter is mutually exclusive to the -enable_report_layers and -layers parameters.
-disable_switch_nets {all|net_names}

Hides the specified switch nets. You can use all to hide all the switch nets, or list the specific switch nets that are not to be displayed. This parameter is mutually exclusive to the -enable_switch_nets parameter.
-disable_visible_layers {all|layer_names}

Specifies which layers should not be made visible when plotting. You can use all to hide all layers, or list the specific layers that are not to be displayed.

This parameter is mutually exclusive to the -enable_visible_layers and -layers parameters.
-disable_visible_signal_em_layers {all|layer_names}

Specifies which signal EM layers should not be made visible when plotting. You can use all to hide all layers, or list the specific layers that are not to be displayed.

This parameter is mutually exclusive to the -enable_visible_signal_em_layers parameter.

-enable_nets {names}


Displays only the specified nets. This parameter is mutually exclusive to the -disable_nets and -nets parameters.
-enable_report_layers {all|layer_names}

Specifies to select the user-defined layers to be used for processing. You can use all to select all layers, or list the specific layers that are to be selected.

This parameter is mutually exclusive to the -disable_report_layers and -layers parameters.
-enable_switch_nets {all|net_names}

Displays the specified switch nets. You can use all to display all the switch nets, or list the specific switch nets that are to be displayed. This parameter is mutually exclusive to the -disable_switch_nets  parameter.
-enable_visible_layers {all|layer_names}

Specifies which layers should be made visible when plotting. You can use all to display all layers, or list the specific layers that are to be made visible.

This parameter is mutually exclusive to the -disable_visible_layers and -layers parameters.
-enable_visible_signal_em_layers {all|layer_names}

Specifies which signal EM layers should be made visible when plotting. You can use all to select all layers, or list the specific layers that are to be selected.

This parameter is mutually exclusive to the -disable_visible_sem_layers parameter.
-instance_voltage_method {Worst | Best | Avg | WorstAvg}

Allows different methods of computing effective instance voltage during rail analysis. Using this option, you can write out the Best, Worst, or Average effective instance voltage between power and ground nets.

The WorstAvg method computes the average instance voltage during each evaluation window defined by the IV Window field, and reports the worst average instance voltage out of all the windows. If IV Method is WorstAvg and IV Window is whole, then this method will report average voltage across all time steps in simulation.

Default : Worst
-instance_voltage_window {timing/switching | whole}

Controls the window where effective instance voltage (EIV) is evaluated. EIV is obtained by processing the voltage waveforms and finding the worse-case effective voltage between the power and ground pins during a specific window.

There are two possible options to evaluate EIV:

  • timing/switching – both switching activity (current is non-leakage) and timing window
  • whole – entire rail simulation not filtered to a specific window
-layers {{name report0/1 visible0/1}{...}}

Controls the visibility of layers. You can enable or disable the reporting and visibility of specific layer. For example, -layer {{M1 1 1} {M2 0 0} means enable reporting and visibility of layer M1, and disable reporting and visibility of layer M2


This parameter is mutually exclusive to the -disable_report_layers, -disable_visible_layers, -enable_visible_layers, and -enable_report_layers parameters.
-nets {{all_power 0/1}{all_ground 0/1}}

Controls the display of all the power and ground nets. 

When all_power is set to 0, hides all power nets, and when set to 1, displays all power nets. When all_ground is set to 0, hides all ground nets, and when set to 1, displays all ground nets.

This parameter is mutually exclusive to the -enable_nets and -disable_nets parameters.
-rail_analysis_opacity value

Specifies the opacity value for the rail analysis output.

The opacity range is from 0-100%, the default value is 100.
-show_layer_net_setting_list {true | false}

Displays the current status (OFF/ON) of all layers and nets in the console. The following is an example of the output:

#-------------------------------#
# Layers   Report    Visible #
# RD        ON         ON #
# M0        ON         ON #
.....
#-------------------------------#

# PowerNets  Status #
# VDD          ON #
# VDDm         ON #
#-------------------------------#
# GroundNets Status #
# VSS         ON #
#-------------------------------#
-via_size {1 | 2 | 3 | 4 | 5 | 6}

Specifies to modify and control the size of vias in the GUI. The default via size is 1. The possible via size values are 1, 2, 3, 4, 5, and 6.


Examples

  • The following command specifies the layers that will be visible:
    gui_set_power_rail_layers_nets \
      -enable_visible_layers{RD M1 V12 M2 V23 M3 V34 M4 V45 M5 V56 M6} \
     -enable_nets {vdd vdd_1}

  • The following commands describe the use model for enabling and disabling switch nets. Here, consider a net VDD with three switch nets VDD_sw0, VDD_sw1, and VDD_sw2:

    • The following command hides the switch net VDD_sw0:
      set_power_rail_layers_net -disable_switch_nets {VDD {VDD_sw0}}
      Displays VDD_sw1 and VDD_sw2.
    • The following command hides all the switch nets:
      set_power_rail_layers_net -disable_switch_nets {VDD {all}}
    • The following command displays the switch net VDD_sw0:
      set_power_rail_layers_net -enable_switch_nets {VDD {VDD_sw0}}
    • The following command displays all the switch nets:
      set_power_rail_layers_net -enable_switch_nets {VDD {all}}
