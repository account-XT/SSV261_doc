monitor_distributed_hosts

monitor_distributed_hosts
[-help]
[-log string]
[-overwrite]
[-period integer]

Monitors hosts and periodically dumps memory or CPU usage information for each host to a file. This command automatically determines the hosts to be monitored. By default, after every 60 seconds hosts are monitored and the disk information is written to a log file. This command is not required for DMMMC because it also performs client monitoring.

Parameters

-help

Prints out the command usage. For a detailed description of the command and all of its parameters, use the man command: man monitor_distributed_hosts.

-log string

Specifies the log file name.

Default: host-monitor.log

-overwrite

Overwrites the log file, if it already exists.

-period integer

Specifies the sampling period after which hosts will be monitored.

Default: 60
