report_ilm_status

report_ilm_status
[-help]

Reports ILM status information including ILM block names, ILM data locations, and if the design is in the flattened or unflattened state.

You can use this command at any time in the flow, but it only reports ILM information if you have already specified ILMs in the design.

Note: The ILM is not supported for Signoff in Tempus.

Parameters 

-help

Outputs a brief description of the report_ilm_status command. For a detailed description of the command, use the man command:

man report_ilm_status

Examples

The following command generates the ILM status report for dtmf_chip:

report_ilm_status

*** ILM status report ***

Current design: dtmf_chip

The following blocks are specified as an ILM block:

  Hierarchical instance(HInst) DTMF_INST/RAM_128x16_TEST_INST (cell: ram_128x16_test)

  Hierarchical instance(HInst) DTMF_INST/RAM_256x16_TEST_INST (cell: ram_256x16_test)

  Hierarchical instance(HInst) DTMF_INST/TDSP_CORE_INST (cell: tdsp_core)

  Hierarchical instance(HInst) DTMF_INST/RESULTS_CONV_INST (cell: results_conv)

Current view is ILM (after flattenIlm)

Current ILM data is for cts-mode.

ILM blocks data location:

ram_128x16_test  :  ../../PTN/ram_128x16_test/ilm

ram_256x16_test  :  ../../PTN/ram_256x16_test/ilm

tdsp_core  :  ../../PTN/tdsp_core/ilm

results_conv  :  ../../PTN/results_conv/ilm

*** end of ILM status report ***
