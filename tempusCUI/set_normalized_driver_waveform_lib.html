set_normalized_driver_waveform_lib

set_normalized_driver_waveform_lib
[-help]
[-fall_waveform string]
[-rise_waveform string]
-ref_lib string
-libs string

Specifies normalized driver waveform for a library. The normalized driver waveform given in the reference library is applied to all the specified libraries.

Note: This command must be specified after the design is loaded. For this command to take effect, you should set the timing_generate_normalized_driver_waveform attribute to false before loading libraries.

Parameters


-help Prints out the command usage.
-fall_waveform string

Specifies the name of the fall normalized driver waveform.
-libs string Specifies a list of space separated libraries to which normalized driver waveform is to be applied.
-ref_lib string Specifies the reference library from which normalized driver waveform is to be selected.
-rise_waveform string

Specifies the name of the rise normalized driver waveform.

Examples

  • The following example shows that normalized driver waveform given in $libDir/libs/ref.lib will be applied to all the cells in $libDir/1.lib $testDir/2.lib $libDir/libs/3.lib: 
    tempus > set_normalized_driver_waveform_lib -libs "$libDir/1.lib $testDir/2.lib $libDir/libs/3.lib" -ref_lib $libDir/libs/ref.lib
