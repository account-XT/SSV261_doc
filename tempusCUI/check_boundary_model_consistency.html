check_boundary_model_consistency

check_boundary_model_consistency 
[-help]

Performs several checks on loaded models.

When this command is run, the software performs the following checks:

  • Global variables and modes set during the boundary model (BM) generation have the same settings in the loading run.
  • If a boundary model sub-module is also instantiated outside of the BM, and the BM definition is used for the module.
  • The view definition used to generate the BM is consistent with the loading run’s view definition. (BM generation views can be a superset.)
  • The loading run’s active views are all active during the BM generation.
  • Constant logic in the BM generation run has the same constants in the loading run.
  • Power nets/voltages are consistent between BM generation and BM loading.
  • Chip size is consistent between BM generation and BM loading.

A report file is written for each loaded boundary model. The default name of the report is ${auto_file_prefix}<cell_name>_bmodel_check.txt, written in to the $auto_file_dir. You can specify the name of the report file using the read_boundary_model -report_file command parameter.

Parameters


-help Prints out the command usage.

Related Commands
