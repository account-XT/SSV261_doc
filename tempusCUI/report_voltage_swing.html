report_voltage_swing

report_voltage_swing
[-help]
-high_threshold float
-low_threshold float
[-out_file string]
[-required_width {all | clock}]
[-view string]

Reports the voltage swings that are shorter than the user-specified thresholds for both clock and data signals.

Parameters

-help Outputs a brief description of the report_voltage_swing command. For a detailed description of the command, use the man command: man report_voltage_swing

-high_threshold float

Specifies the high threshold percentage of the pin supply voltage.

-low_threshold float

 Specifies the low threshold percentage of the pin supply voltage.
-out_file string Specifies the name of the output file.
-required_width {all | clock}

Reports the required high and low pulse widths corresponding to the user-specified high and low thresholds. You can specify one of the following options:

  • clock: Reports the required widths for all clock pins in the design.
  • all: Reports the required pulse widths for all input pins in the design.

Default: all
-view string

Specifies the name of the view being defined.

Note: If this option is not specified, it will dump report for all views.

Examples

  • The following command shows the total number of voltage swing violations at the specified high and low thresholds:
    report_voltage_swing -high_threshold 0.6 -low_threshold 0.1

    Total number of voltage swing (Rail to Rail) violations : 505
    Total number of voltage swing (Rail to Rail) violations : 453
    Total number of voltage swing (Rail to Rail) violations : 142
    Total number of voltage swing (Rail to Rail) violations : 142

  • The following command shows the total number of voltage swing violations for the view, func_slow_RCMAX, at the specified high and low thresholds:
    report_voltage_swing -high_threshold 0.6 -low_threshold 0.1 -view func_slow_RCMAX          

    Total number of voltage swing (Rail to Rail) violations : 505

  • The following command reports the required pulse widths for all input pins in the design corresponding to the specified high and low thresholds in the rep output file:
    report_voltage_swing -high_threshold  1 -low_threshold 0.9 -required_width all -out_file rep
