report_density_map

report_density_map
[-help]
[-grid_length rowHeight]
[-grid_unit microns]
[-ignore_block {true|false}]
[-ignore_filler {true|false}]
[-threshold density]

Generates a map that uses colors to represent placement density and generates a placement density report. If you run this command without parameters, it generates a map with a threshold of 0.75 and measures the grid in row height.

Use this command any time after placement.

Use the Display Density Map form to select colors and step-size for the density levels in the map.

Parameters 

-grid_unit microns

Specifies the value (in micron) of side of square grid for density calculations.
-grid_length rowHeight

Specifies the value (in row-height) of side of square grid for pin density calculations.
-help

Outputs a brief description that includes type and default information for each report_density_map parameter.

For a detailed description of the command and all of its parameters, use the man command: man report_density_map.
-ignore_block {true|false}

Skips block cells instances from both supply and demand calculation.
-ignore_filler { true | false}

Ignores the density of fillers in the post-filler density heat map to show density of standard cells.

Default: false
-threshold density

Specifies a threshold density value for the grid. Any grid under the threshold value is not reported. The value must be positive.

Example

The following are output from command report_density_map. It generates a map with default threshold of 0.75 and measured in row height:

powerDomain TOP: bins with density > 0.75 = 0.519 % ( 6 / 1156 )

bin size: 59 sites by 10 row(s). total 1156 bins ( 34 by 34 )

density range #bins %

0.75 - 0.8 5 0.4325

0.8 - 0.85 1 0.08651

total 6 0.519
