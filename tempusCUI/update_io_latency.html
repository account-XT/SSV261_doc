update_io_latency

update_io_latency
[-help]
[-adjust_source_latency]
-verbose

Provides an automated means of balancing IO and Core clock latencies after the clock network has been added to the design so that pre and post clock tree skew between the clocks is maintained as closely as possible. This results in minimum change of inbound and outbound IO slacks.

This command performs the following actions:

  • Measures and calculates ideal average latency for each Core clock.
  • Calculates preCTS skew between IO and Core clocks.
  • Asserts set_propagated_clock on all clock root pins or ports to put clock trees in propagated mode.
  • Measures and calculates propagated mode average latency for each Core clock.
  • Adjusts set_clock_latency on IO clocks network latency to minimize pre to post CTS IO-to-Core clock skew.

In case a single IO clock interacts with multiple Core clocks, the IO clock will be adjusted by the overall average latency of all the related Core clocks combined.

To be effective, this command should only be used after clock trees have been implemented and before the set_propagated_clock command is issued. This allows the command to see both the ideal and propagated state of the clock trees.

Parameters


-help Prints out the command usage.
-adjust_source_latency

Adjusts the source latency of core clock.

-verbose

Provides additional information to the console as adjustments are made to each IO clock.
