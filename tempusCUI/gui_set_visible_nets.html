gui_set_visible_nets

gui_set_visible_nets
[-help]
{nets | -all}

Displays only the specified nets and hides all other nets. To display all nets, specify the -all parameter.

Parameters

-help

Prints a brief description that includes type and default information for each gui_set_visible_nets parameter.

For a detailed description of the command and all of its parameters, use the man command:
man gui_set_visible_nets
-all Displays all nets.

nets

Displays only the specified nets and hides all other nets. You can specify multiple net names.

Examples

  • The following command hides all nets except the specified net:
    gui_set_visible_nets ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/tpo_a_9_
