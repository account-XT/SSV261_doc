gui_set_visible_bumps

gui_set_visible_bumps
[-help]
{-bump_cells bump_cell_name | -exclude_bump_cells string | -all}

Displays only the bumps with the specified bump cell names and hides all other bumps. Alternatively, you can use the command to display all bumps except the ones specified with -exclude_bump_cells.

To redisplay all bumps, specify the -all parameter.

Parameters

-help

Prints a brief description that includes type and default information for each gui_set_visible_bumps parameter.

For a detailed description of the command and all of its parameters, use the man command:
man gui_set_visible_bumps
-all

Displays all bumps.

By default, all bumps are displayed. When you specify gui_set_visible_bumps bump_cell_name, the tool displays only the bumps with the specified bump cell names and hides all other bumps. You can then use gui_set_visible_bumps -all to redisplay all bumps.

-bump_cells names

Displays only the bumps with the specified bump cell names and hides all other bumps. You can specify multiple bump cell names.

-exclude_bump_cells string

Displays all bumps except the ones specified with -exclude_bump_cells. The specified bumps are hidden.

Data_type: string, optional

Examples

  • The following command displays only the bumps with bump cell as BUMPCELL:
    gui_set_visible_bumps -bump_cells BUMPCELL
  • The following command hides the bumps with bump cell as BUMPCELL but displays all other bumps:
    gui_set_visible_bumps -exclude_bump_cells BUMPCELL
  • The following command redisplays all bumps:
    gui_set_visible_bumps -all
