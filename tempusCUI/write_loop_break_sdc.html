write_loop_break_sdc

write_loop_break_sdc
[-help]
out_file
-in_file string

Generates SDC file containing constraints for combinational loop breaking. The command selects the disable arc (s) with flag set to 1 from the third-party report file, and generates the equivalent SDC commands in an output file.

You can load the output SDC file at any time during an Tempus session. To load the file, use the read_sdc command.

Parameters 

-help

Prints out the command usage.

out_file

Specifies the name of the output SDC file.

-in_file string

Specifies the disabled time arcs report that you generate using third-party tool.

Command Order

Use this command after generating the disable arcs report.

Examples

The following command generates an etsCombLoopBreak.sdc file when the input is a disable_arcs.rpt file:
tempus > write_loop_break_sdc -in_file disable_arcs.rpt -out_file etsCombLoopBreak.sdc
