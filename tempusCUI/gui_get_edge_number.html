gui_get_edge_number

gui_get_edge_number
[-help]
[-coordinate]
[-edge index_num]
-objects name|inst_ptr hinst_ptr

Returns the total number of edges and/or edge coordinates for the specified block.

You can use the related gui_show_edge_number command to display edge numbers on the sides of the selected or specified objects in the GUI. 

Parameters

-help

Prints a brief description of the gui_get_edge_number command.

For a detailed description of the command, use the man command: man gui_get_edge_number.

-coordinate

Returns the coordinates of all the edges.

Data_type: bool, optional

-edge index_num

Returns the coordinates of the specified edge for the specified object. The index_num value should be greater than or equal to 0.

Data_type: int, optional

-objects name|inst_ptr hinst_ptr


Specifies the object(s) for which edge numbers and/or coordinates are to be returned. You can specify the object(s) either by name or as inst/hinst pointers.

Data_type: (inst|hinst)+, required

Examples

  • The following command returns the total number of edges of the specified instance:
    gui_get_edge_number -objects ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U202
    Returns:
    4
  • The following command returns the coordinates of all the edges of the specified instance:
    gui_get_edge_number -objects ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U202 -coordinate
    Returns:
    {edge0:{ 97.152000 -645.084000 97.152000 -643.896000 } edge1:{ 97.152000 -643.896000 98.736000 -643.896000 } edge2:{ 98.736000 -643.896000 98.736000 -645.084000 } edge3:{ 98.736000 -645.084000 97.152000 -645.084000 } }
  • The following command returns the coordinates of edge with index number 0 for the specified instance:
    gui_get_edge_number -objects ram1/subram02_lower/TESTACT_INST_PERIWDSRAM001PAA512W27C3/U202 -edge 0
    Returns:
    {97.152000 -645.084000 97.152000 -643.896000}
