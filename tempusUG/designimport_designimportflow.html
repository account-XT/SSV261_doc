Design Import Flow

The design import flow involves the following steps:

  • Loading the design
  • Saving the design
  • Restoring the design

The design import flow in MMMC mode is summarized below:

Table -1 MMMC Design Import Flow

Load Design

Logical Data

read_view_definition <>
read_verilog <>
set_top_module <>

Physical Data

read_lib –lef <>
read_view_definition <>
read_verilog <>
set_top_module <>
read_def

OA Physical Data

read_lib -oaRef <>
read_view_definition <>
read_verilog <>
set_top_module <>

Save Design

Logical Data

save_design <session>

Physical Data

save_design <session>

OA Physical Data

save_design -cellview <>

Restore Design

Logical Data

read_design <session> topcell

Physical Data

read_design session topcell -physical_data

OA Physical Data

read_design -physical_data -cellview

To load a design in DMMMC mode, refer to the “Distributed Multi-Mode Multi-Corner Timing Analysis” chapter of the Tempus User Guide.

The following is an example script to import non-MMMC data:

read_lib –lef <> 
read_lib <>
read_verilog <>
set_top_module <>
read_sdc <>
read_spef <> 
read_def <>

When the data is imported using non-MMMC commands, Tempus internally stores it in the MMMC configuration as the following MMMC objects:

default_emulate_view
default_emulate_delay_corner
default_emulate_rc_corner
default_emulate_libset_max
default_emulate_libset_min
default_emulate_constraint_mode
