Voltus IC Power Integrity Solution Text Command Reference
Product Version 26.10, May 2026

set_rail_analysis_domain


set_rail_analysis_domain
-help
-gndnets ground nets
-name domain_name
-pwrnets power_net_list
-signets signal_nets
[-threshold value]

Specifies a rail analysis power domain.

Note: For a power-gated domain, you should only specify the "always on" net. The switched net should not be specified as part of power domain definition, because it is traced by the program automatically.

Parameters


-help

Prints out the command usage.

-gndnets ground_net_list


Specifies a list of ground nets that are in the domain.
-name domain_name

 

Specifies the name of the power domain.

-pwrnets power_net_list


Specifies a list of power nets that are in the domain.

-signets signal_nets


Specifies a list of signal nets.
-threshold value

 

Specifies the minimum allowed voltage on the power net or the maximum rise on the ground net, depending on the setting of the -voltage parameter. The -threshold parameter is used to verify that the power grid passes the limit check and to set the filters for an IR plot.

Note: This parameter does not support domains with MSMV power nets.

If you have specified both net (set_pg_nets -threshold) and domain-based (set_rail_analysis_domain -threshold) thresholds, the net-based threshold will be honored.

The valid value for threshold is between 0 and 0.5 (50%). For example, set_rail_analysis_domain -threshold 0.1 indicates that 0.1 is 10% IRdrop. If a power net in the domain has nominal voltage of 1v, 10% of threshold will translate to 100mV of maximum effective IRdrop between the power and ground net.

Examples

  • The following command sets the power domain TDSP to include VDD_TDSPCore_R and VSS nets:
    set_rail_analysis_domain -name TDSP -pwrnets VDD_TDSPCore_R -gndnets VSS
  • The following command sets the power domain TDSP to include the nets mentioned in the specified files, power_file and ground_file:
    set_rail_analysis_domain -name TDSP -pwrnets_list_file power_file -gndnets_list_file ground_file
