verify_power_via

verify_power_via
[-help ]
[-append]
[-area {x1 y1 x2 y2}]
[-check_wire_pin_overlap]
[-edge_to_edge]
[-error integer]
[-exclude_region_file check_file]
[-fill]
[-ignore_objects {drc_fill | io_wire}]
[-layer_range {bottom_layer top_layer}]
[-net {net_names}]
[-non_orthogonal_check [-distance {x y}]]
[-report file]
[-shielding]
[-stacked_via]
[-via_util value]
[-what_if_report filename]
[-width_range string]

This command has a variety of power-rail overlap checks to look for missing power-grid vias. By default, it checks that orthogonal power-routes on adjacent routing layers have a via between them at every intersection. For example, there should be a via at the point where a metal3 power stripe overlaps a metal2 power stripe. By default, horizontal routes get checked only for overlaps with vertical routes. If the power shapes are polygon, the polygon is split into rectangles and the rectangles are used to decide the direction. Support for checking stacked vias between non-adjacent routing layers is optional. Violations are highlighted in the layout window, and a text report is generated with the location of the missing vias.

Parameters

-help

Outputs a brief description that includes type and default information for each verify_power_via parameter.

For a detailed description of the command and all of its parameters, use the man command: man verify_power_via.

-append

Specifies that all previous verify_power_via settings will be kept.

-area x1 y1 x2 y2

Specifies the coordinates of the area to be checked.

-check_wire_pin_overlap

Specifies that wire overlaps of pin shapes should also be checked. By default, only wire overlaps with wires are checked.
-distance {x y}

Specifies distances for finding missing via within a specified window for a non-orthogonal check, with x and y representing the distance in the horizontal and vertical directions, respectively.

When the x or y distance is provided, verify_power_via checks if the wire is parallel with another wire. If yes, it checks:

  • The via center to via center spacing between parallel wires against the value x (y) 
  • The via center to wire end distance against the value x/2 (y/2)

If the actual distance is greater than the required distance in either case, it marks a violation.

When the x or y distance is not provided or set to 0, the via to via distances are not checked.

Note: This parameter can only be specified with the -non_orthogonal_check parameter.
-edge_to_edge Checks the non-orthogonal distance from edge to edge within a layer.
-error integer Specifies the maximum number of errors to report.
-exclude_region_file check_file

Ignores missing VIA checks within the specified check_file regions for a cell extension area. The check_file format can be a set of the following values:

  • cell: Specifies the cell type.
  • ext_layer_bottom: Specifies the extension area bottom layer.
  • ext_layer_top: Specifies the extension area top layer.
  • ext_x: Specifies the extension length in the X direction.
  • ext_y: Specifies the extension length in the X direction.
  • exc_x: Specifies the exception length in the X direction.
  • exc_y: Specifies the exception length in the Y direction.

The following set of check_file formats ignores missing VIA check within the yellow rectangle (in the output), but checks missing VIA within the blue rectangle:

FTV_CELL, B_M0, B_M1, X, Y, X’, Y’
INV_D2, M0, M1, X2, Y2, X2’, Y2’

-fill

Specifies that tied-off metal fill should also be checked. Floating fill is still ignored.

Default: Metal fill will be ignored.
-ignore_objects {drc_fill | io_wire}

Skips checking the power vias of the specified wire type.

-layer_range {bottom_layer top_layer}


Checks for missing stacked vias between the bottom and top layers. It also checks for missing vias between all adjacent intermediate layers, but does not check for stacked vias between the intermediate layers.  You can specify full layer names like METAL1, or abbreviations like M1 or 1. For example, verify_power_via -layer_range {M2 M5} checks for missing stacked vias between overlapping M2 and M5, and also missing vias for overlapping M2/M3, M3/M4, M4/M5.

It checks the missing vias between all adjacent layer intersections but does not check for missing stacked vias between bottom and top layers. If bottomLayer is specified but topLayer is not, it assumes topLayer is one layer up.

-net {net_names}


Specifies the names of the power nets that will be checked. A single net or a list of nets enclosed in curly braces({}) or quotes (" ") can be specified. Wildcards (* and ?) are supported. For example, when you specify verify_power_via -net {v*}, all PG net names having initial letter as v are checked.

Note: Currently, wildcards are supported for checking PG nets only.

Default: All power grid nets.

-non_orthogonal_check

Checks the overlap area for non-orthogonal crossing wires (e.g. wires that are both in the same direction) in adjacent as well as non-adjacent layers. Checks for missing vias between two or more parallel wires. The via center-to-center distance between parallel wires should be less than or equal to the specified spacing

If this parameter is not specified, horizontal wires get checked only against vertical wires.

Note: You can use -distance {x y} parameter with -non_orthogonal_check to find missing vias within a specified window. When the x or y distance is provided, verify_power_via checks if the wire is parallel with another wire. If yes, it checks the via center-center spacing and via center-wire end distance between parallel wires. If the actual distance is greater than the required distance, it marks a violation.

-report file

Specifies the name of the output file for the report.

-shielding

Specifies that shielding wires should also be checked. By default, shielding wires are not checked.

-stacked_via

Checks for missing vias between all non-adjacent as well as adjacent layers.
-via_util value

Checks if the cut area in the metal intersection area is sufficient.

viaUtil = Total cut area / Metal intersect area

If the actual ratio is less than specified ratio, verify_power_via marks it as violation.

Note: When -via_util is specified, the verify_power_via command will not check for missing vias.
-what_if_report filename Writes out verify_power_via violations data into a ECO file that can be used directly as input for whatIf rail analysis. When you specify this parameter, the missing via information generated can be used as input for what-if virtual wires.
-width_range string

Specifies the metal width to be considered. verify_power_via uses the specified width range to filter wires. Only the bottom and top wires that fall in the range are checked.

The string value takes the following format:

-width_range {min_width max_width [layer_name …] [min_width max_width [layer_name …]] … }

  • If min_width is 0, all wires with width less than specified max_width will be checked. 
  • If max_width is 0, all wires with width greater than specified min_width will be checked.
  • If layer_name is specified in the string, width_range is enabled only for the specified layer.
  • If no layer_name is specified in the string, width_range is enabled for all non-specified layers. 

Note: Use braces or quotation marks to enclose the string value for width_range.

Examples

  • Specifies that all vias for all powergrid nets will be checked, except for metal fill and reports it to a file called power_via.report:
    verify_power_via -report power_via.report
  • The following command checks for missing stacked vias between METAL5 and METAL8 layer intersections on VSS net. In addition, it checks for missing vias between METAL5-METAL6, METAL6-METAL7 and METAL7-METAL8 layer intersections. The violations will be reported in powerVia.rpt file and highlighted in GUI.
    verify_power_via -layer_range {METAL5 METAL8} -net VSS -report powerVia.rpt

  • The following command checks that the overlapping power routes on adjacent layers have vias that cover at least 70% of the overlap area.
    verify_power_via -via_util 0.7
  • The following command checks that the overlapping power routes have vias that cover at least 70% of the overlap area for layers between METAL3 and METAL4.
    verify_power_via -via_util 0.7 -layer_range {METAL1 METAL4}
  • The following command checks for wire overlaps for all pin shapes included, enclosed, or touched by the specified area:
    verify_power_via -area {100 100 1000 1000} -check_wire_pin_overlap
