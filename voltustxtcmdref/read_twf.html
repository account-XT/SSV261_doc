read_twf


read_twf
[-help]
[filenames]
[-cell master_cell_name]
[-prefix string]
[-quiet]
[-reset]
[-scope string]
[-skipconst]
[-skiptw]
[-strip_prefix string]
[-verbose]
[-view]

Reads the external Timing Window File (TWF) for noise and power calculation in CPE and Tempus SI.

Parameters


filenames

Specifies the names of the timing window files.
-cell  master_cell_name

Specifies the master cell name for the timing window file. This parameter allows you to support master cell based TWF annotation. That is, you need to specify only the master cell name for the timing window file, instead of specifying all the instances that were instantiated from a master cell.

Example

Let us consider a design that has a cell named "cpu_core" with two instances "cpu_core_0" and "cpu_core_1":

Use Model for Instance-based TWF annotation

read_twf -scope cpu_core_0 cpu_core.twf.gz
read_twf -scope cpu_core_1 cpu_core.twf.gz

Use Model for Master Cell based TWF annotation

read_twf -cell cpu_core cpu_core.twf.gz

-prefix string

Adds a prefix to the net or pin name.
-quiet Skips information and warning messages.

-reset

Clears the previously read TWF files.

-scope string

Specifies the scope for the given hierarchical timing window file.

-skipconst

Skips constant processing.

-skiptw

Skips timing windows processing.

-strip_prefix

Removes hierarchical path name.
-verbose Prints the command progress details.

-view

Specifies the view for the timing window file.
