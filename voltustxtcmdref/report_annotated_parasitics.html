report_annotated_parasitics

report_annotated_parasitics   
[-help]
[{[-list_annotated] 
[-list_broken_net] 
[-list_extra_pin_net] 
[-list_float_net]
[-list_nodriver_net]
[-list_noload_net ] 
[-list_not_annotated ] 
[-list_real_net ] 
[-list_supply_net ] 
[-list_zero_cap_net]
[-max_missing {max_missing_int}]}]
[-net_file string] 
[-nets string] 
[-view {viewName}]
[> {write_fileName}]
[>> {append_fileName}]

Reports the back-annotated parasitics of the design. By default only summary report is generated. The software groups all the nets by net-types and annotation-status (annotated or not-annotated).

Parameters

-help

Outputs a brief description that includes type and default information for thereport_annotated_parasitics parameters.

For a detailed description of the command and all of its parameters, use the man command: manreport_annotated_parasitics.

>> {append_fileName}

Appends the report to the specified file name.

-list_annotated

Generates a list of annotated nets.
-list_broken_net Reports broken nets in the design.
-list_extra_pin_net Generates a list of nets that have extra pins in the SPEF but not in the Verilog.

-list_float_net

Generates a list of floating nets.

-list_nodriver_net

Lists one terminal nets that have no driver.

-list_noload_net

Lists one terminal nets that have no load.

-list_not_annotated

Generates a list of not annotated nets.

-list_real_net

Lists all real nets.

-list_supply_net

Lists all supply nets.
-list_zero_cap_net Generates a list of zero capacitance nets.

-max_missing {max_missing_int}

Limits the number of missing annotations to the specified number of annotations.

Default: 1000
-nets string

Specifies the list of net names for which annotation summary is required.
-net_file filename Accepts a file name, which contains a list of net names, as input. When this parameter is specified, the parasitic annotation summary is provided only for the listed nets. The net names in the file can be specified as one net per line.

-view viewname

Reports the back-annotated parasitics for the specified analysis view. You can specify this parameter only when the software is in multi-mode multi-corner timing analysis mode.

Default: Reports against the default analysis view
> {write_fileName}

Writes the report to the specified file name.
