create_power_pads_regions


create_power_pads_regions 
[-help]
-design_stack_config filename
-pad_config {{ pad_cfg_file1 die_inst1} { pad_cfg_file2 die_inst2} { pad_cfg_file3 die_inst3}…}
-power_net_config filename
-tsv_subckt_config {{file1 top_layer bottom_layer die1} {file2 top_layer bottom_layer die2}+}
-voltage_source_layers {{metal_layer die1}+}
[-work_directory directory]

Generates virtual power pads and pseudo TSVs for multi-die ERA.


Parameters


-design_stack_config filename


Specifies the name of the XML file containing the design stack information. This file is from the Integrity™ 3D-IC product.
-help

Outputs a brief description that includes the type and default information for each create_power_pads_regions parameter. For a detailed description of the command and all of its parameters, use the man command:

man create_power_pads_regions
-pad_config {{ pad_cfg_file1 die_inst1} { pad_cfg_file2 die_inst2} { pad_cfg_file3 die_inst3}…}

Specifies the mapping of the bump region configuration file and die instances. The format of the bump region configuration file is:

#Net, Region, metal layer, number

One net can have multiple P/G pad regions, but pad regions should not overlap. The pad regions of a net should be inside the net region.

Format Example:
VDD, {0 0 380 0 380 180 340 310 200 310 200 380 70 150 0 150 0 0}, AP, 250
VDD, {0 150 70 150 70 380 0 380 0 150}, AP, 200
VSS, {0 0 380 0 380 180 340 310 200 310 200 380 70 150 0 150 0 0}, AP, 280
VSS, {0 150 70 150 70 380 0 380 0 150}, AP, 300
-power_net_config filename.pwrcfg

Specifies the name of a file containing power net inter-die mapping configuration. This file is from the Integrity™ 3D-IC product.
-tsv_subckt_config {{file1 top_layer bottom_layer die1} {file2 top_layer bottom_layer die2}+}

Specifies the TSV subcircuit configuration. For each die instance, you need to specify the TSV subcircuit file, TSV top layer, and the TSV bottom layer.
-voltage_source_layers {{metal_layer die1}+}


Specifies the voltage source layer for each die instance.
-work_directory directory


Specifies the location of the run directory.

Examples

  • The following command specifies static current region:
    create_power_pads_regions -design_stack_config ./data/Integrity3DIC/top_2Die.xml \
         -power_net_config ./data/Integrity3DIC/FCCC_top_2Die.pwrcfg \
         -pad_config { {./data/bump_cfg/U1_bump_region.cfg U1} {./data/bump_cfg/U2_bump_region.cfg U2} } \
         -tsv_subckt_config { {./data/tsv_model/tsv_rc.subckt M13 BPMS U1} } \
         -vsrc_layers { {AP U1} }\
         -work_directory ./RUN_era/work_bump/
