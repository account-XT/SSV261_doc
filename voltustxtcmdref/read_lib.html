read_lib


read_lib
-help
 [-aocv aocv files]
[-cdb cdb_list]
[-lef file_names]
[-library_side_file <<side files>>]
[-max_aocv max_aocv files]
[-max_cdb max_cdb_list]
[-max max_lib_list]
[-min_aocv min_aocv files]
[-min_cdb min_cdb_list]
[-min min_lib_list]
[-oaRef OA_reference_libs]
[-pgv power_grid_list]
[-socv socv files]

Schedules reading of one or more technology library files. These files either contain timing-related or noise-related information for the primitive cells used in the design. When you use the read_lib command, the library information is scheduled for reading but is actually read in after you use the set_top_module command.

Timing libraries can be in the text format or Cadence binary library format (LDB). The LDB files generated from Innovus and Genus are read in Voltus with an error message (TECHLIB-1249). The Tempus generated LDB files can be used in Tempus, Innovus, Voltus, Genus, and Conformal software tools. The LDB files are not forward compatible, that is, an LDB generated from the 15.2 version cannot be used with the 15.1 or prior versions of the software.

Note: You can use wildcards with the read_lib command as follows:
read_lib [glob *.lib]

Parameters


-help

Prints out the command usage.

-aocv aocv_file_list


Reads the AOCV libraries with timing libraries. In this case, as compared to worst OCV, the tool annotates less pessimistic derate factors from the given AOCV library on to design elements (cells/nets) resulting in less pessimistic timing results.

To enable the AOCV flow, you also need to set the following while reading the AOCV libraries:

set_analysis_mode -aocv true
-cdb cdb_list

 

Specifies the name of the noise library file(s).
-lef file_names

 

Specifies the name of the LEF files to be loaded. dotlib_file and -lef file_names are mutually exclusive.
-library_side_file <<side files>>

Specifies the name of the incremental side libraries.
-max max_lib_list

 

Specifies the libraries to be used for maximum timing analysis.
-max_aocv max_aocv files

Reads the maximum AOCV libraries.

-max_cdb max_cdb_list


Reads the maximum noise libraries.
-min min_lib_list

 

Specifies the libraries to be used for minimum timing analysis.
-min_aocv min_aocv files

Reads the minimum AOCV libraries.

-min_cdb min_cdb_list


Reads the minimum noise libraries.

-oaRef OA_Reference_libs


Loads OpenAccess reference libraries in the physical flow.

-pgv power_grid_list


Reads the power-grid library files.

This parameter is required when you run Voltus.
-socv socv files

Reads the SOCV libraries with the timing libraries. To enable the SOCV flow, you also need to set the following while reading the SOCV libraries:

set_analysis_mode -socv true

Examples

  • The below command reads the LEF files. Note that the first file is a technology LEF.
    read_lib -lef tech.lef allcells.lef
  • The next command reads the minimum libraries.
    read_lib -min stdcells_min.lib memories_min.lib
  • The next command reads the maximum libraries.
    read_lib -max stdcells_min.lib memories_min.lib
  • The following command reads a list of timing libraries to be used for minimum and maximum analysis.
    read_lib -min { fast.lib mem1_min.lib macro2_min.lib } -max { slow.lib mem1_max.lib macro2_max.lib }
  • The following command reads a User Defined Noise model (UDN) and the noise library (cdB):
    read_lib -cdb {std_cells.cdB cells.udn}
