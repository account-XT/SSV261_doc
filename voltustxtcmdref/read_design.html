read_design


read_design
[-help]
[dir dir topcell]
[-black_box_modules <blackBoxModules>]
[-cellview {lib cell view}]
[-common]
[-dynamic_view userDynamicView]
[-exclude_path_collection]
[-hold_views userHoldViews]
[-leakage_view userLeakageView]
[-mmmcFile userMmmcFile]
[-lef_files lefFiles]
[-module_dirs moduleDirs]
[-no_timing_graph]
[-oaRef oaRefLib]
[-physical_data]
[-setup_views userSetupViews]

Loads a saved design database. You can also read the physical data such as floorplan, placement and routing using the -physical_data parameter.

Note: You can also use the read_def command to read the DEF file for physical information.

Parameters

-help Prints out the command usage.
-black_box_modules blackBoxModules Specifies modules for which black box models should be loaded.

-cellview {lib | cell | view}

Restores an OpenAccess design. It specifies the name of the library, top cell, and cell view for the OA design. This parameter works both for the physical and non-physical flow.
-common Specifies to read the common-db design directory.
dir dir topcell  Specifies the design data directory name and topcell.
-dynamic_view userDynamicView Specifies the analysis view for the dynamic power analysis.
-exclude_path_collection

Restores design data without archived path collection.
-hold_views userHoldViews Specifies the hold views for loading, rather than the hold views active during save_design.
-leakage_view userLeakageView Specifies the analysis view for leakage power analysis.

-lef_files lefFiles

Specifies the LEF files for loading. You can use this parameter, if you need to override the existing LEF files in the design being restored and load different LEF files.

  • This option is intended to allow upgrading to new versions of LEF files that are compatible with the old versions. The list of all LEF files used by this design must be given.
  • If any pin locations or cell boundaries or OBS shapes are changed for used cells, new DRC violations may occur.
  • If pins are added or removed from used cells, or used cells are removed, fatal errors may occur when loading the netlist.
  • If the removed pins and cells are unused in the design, warnings or errors may still occur if any library-specific data was stored for those cells or pins during the design flow (for example, dont_touch data)
-mmmcFile userMmmcFile Specifies the name of the path to a viewDefinition.tcl (MMMC) file.
-module_dirs moduleDirs Specifies module-level sessions that should override the corresponding modules in the top-level hierarchical session.
-no_timing_graph

Restores the design data without a timing graph.
-oaRef oaRefLib  Reads the OA reference library.

-physical_data

Reads the physical data such as floorplan, placement, and routing that you generate.
-setup_views userSetupViews Specifies the setup views for loading.


Examples

  • The following command loads the saved database dtmf_chip:
    read_design dtmf_chip.dat dtmf_chip
  • The following command reads a design called dtmf_chip with physical data.
    read_design –physical_data dtmf_chip.dat dtmf_chip
  • The following command loads the ‘layout’ view of the 'design1’ cell from the ‘designLib’ libraries of an OA database.
    read_design -cellview {designLib design1 layout}
  • The following command loads the ‘layout’ view of the ‘dtmf_chip’ design from the ‘designLib’ libraries of an OA database in physical mode.
    read_design -cellview "designLib dtmf_chip layout" -physical_data
