analyze_rail


analyze_rail
-help
[-type {domain | net}]
[-output directory_name]
name

Runs rail analysis on a net or domain. This command must be specified after defining the rail analysis mode properties using the set_rail_analysis_mode command.

Parameters


help

Prints out the command usage

name

Specifies the name of the domain or net that you want to analyze.

-output directory_name


Specifies the name of the directory in which to store the output directories created during the analysis.

Default: Current working directory.

-type {domain | net}


Specifies whether to run rail analysis on a domain or a net. A domain is a list of power or ground nets to analyze together. See set_power_pads for more details.

You can specify the variable "ALL" to analyze all domains.

Examples

  • The following command performs an analysis for the vdd net and places the results directories in the analysis_out directory:
    analyze_rail -type net -output analysis_out vdd
  • The next command performs rail analysis on TDSP power domain and writes the results in current working directory.
    analyze_rail -type domain -output ./ TDSP
  • The following command performs rail analysis on all power domains and writes the results in the current working directory:
    analyze_rail -type domain ALL -output ./
