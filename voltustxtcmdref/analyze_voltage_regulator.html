analyze_voltage_regulator


analyze_voltage_regulator
name
[-results_directory directory_name]
-type {domain | net}

Runs low dropout (LDO) analysis on a net or domain. This command must be specified after defining the rail analysis mode properties using the set_rail_analysis_mode command.

Parameters


name

Specifies the name of the domain or net that you want to analyze.

-results_directory directory_name


Specifies the name of the directory in which to store the output directories created during the analysis.

Default: Current working directory.

-type {domain | net}


Specifies whether to run LDO analysis on a domain or a net. A domain is a list of power or ground nets to analyze together. 

You can specify the variable "ALL" to analyze all domains.

Examples

  • The following command performs an analysis for the vdd net and places the results directories in the analysis_out directory:
    analyze_voltage_regulator -type net -results_directory analysis_out vdd
  • The next command performs rail analysis on TDSP power domain and writes the results in current working directory.
    analyze_voltage_regulator -type domain -results_directory  ./ TDSP
