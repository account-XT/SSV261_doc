Voltus IC Power Integrity Solution Text Command Reference
Product Version 26.10, May 2026

debug_irdrop


debug_irdrop
[-help]
[-eco_report]
[-enable_xp {true | false}]
[-net netname | -domain domainname]
[-net_threshold value | -domain_threshold value]
[-non_violating_instslimit value]
[-nworst_instances value]
[-output_directory dir]
-state_directory dir
[-summary_only]
[-region {x1 y1 x2 y2 }| -nregion value]
[-tile_row_col {X Y}]
[-tile_size {X Y}]

Specifies to automatically identify the region with worst IRdrops and EM violations, and provide necessary information to determine and fix the root cause.  The reports are consolidated for each region to find root-cause. Root cause analysis is done by identifying top 10 instances in each hotspot and report the following:

  • Hotspot Region Coordinate
  • Timing Library Analysis
  • Power-Grid View Analysis
  • Power-Grid Integrity Analysis
  • IR-Drop Composition
  • Root Cause Analysis

You must specify this command after running the analyze_rail command.

The debug_irdrop command requires a VTS-XL license.


Parameters


-help

Outputs a brief description that includes the type and default information for each debug_irdrop parameter.

For a detailed description of the command and all of its parameters, use the man command man debug_irdrop.
-domain domainname

Specifies the name of the power domain.
-domain_threshold value

Specifies the minimum allowed voltage for the domain being analyzed. The value will be in percentage. This parameter behavior is same as the set_rail_analysis_domain -threshold parameter.
-eco_report

Specifies to generate a file with IR drop information that can be used by Tempus ECO to fix IR voltage drop for all instances in a design. The report (eco.ird) is generated in the specified output directory (debug_irdrop -output_directory).
-enable_xp {true | false}

Specifies to identify the worst IR drop and EM violations regions in the Extensively Parallel (XP) mode wherein processing is distributed over a large number of machines.

Default : false
-net netname

Specifies the name of the power or ground net that you want to analyze.
-net_threshold value

Specifies the minimum allowed voltage for the power net being analyzed. The value must be an absolute number. This parameter behavior is same as the set_pg_nets -threshold parameter.
-non_violating_instslimit value

Reports non-violating instances within hotspots (violating tiles) that are close to the threshold value. This parameter allows you to define a limit (sub-threshold) that can be used to report the non-violating instances that are close to the threshold.

For example, if the -net_threshold or -domain_threshold is 60mV, and -non_violating_instslimit is 3mV close to the threshold, the debug_irdrop command will report all the violating instances above the domain/net threshold and also the non-violating instances which are in the range of 60mV-57mV. This information about the non-violating instances can be used for IR improvement in the Timing-aware IR Drop Fixing flow.
-nregion value

Specifies the number of regions to be analyzed. The default value is 3.
-nworst_instances value

Specifies the number of worst instances to be reported. The default value is 5.

 -output_directory dir


Specifies the output directory in which the Irdrop and EM violation results will be saved in.

 -region {x1 y1 x2 y2 }


Specifies the region containing the worst instances. The default unit of x1 y1 x2 y2 is in database units.

-state_directory dir


Specifies the top-level state directory that is generated by the dynamic IR drop analysis. This state directory contains analysis of all nets associated with the power domain. This is the output directory in which the results of the analyze_rail command is stored (for example, core_25C_dynamic_1).
-summary_only

Specifies to generate a violation summary report that displays a summary of the IR drop violation distribution for all the cells. In addition, the report also displays the summary of the IR drop violation distribution for the standards cells. If this parameter is specified, the detailed IR report is not generated.
-tile_row_col {X Y}

Specify the number of tiles in the x and y direction. The -tile_row_col and -tile_size parameters enable tile-based analysis of the hotspot regions. Tile-based analysis divides the design into user-defined tile size, and reports IR drop violations on each tile.  

The default value is 100um^2 (10x10 tiles).
-tile_size {X Y}

Specify the size of tiles in the x and y direction. The -tile_row_col and -tile_size parameters enable tile-based analysis of the hotspot regions. Tile-based analysis divides the design into user-defined tile size, and reports IR drop violations on each tile. 

Examples

  • The following command generates IR debug report for the VSS net in the specified output directory:
    debug_irdrop -state_directory dynamic_rail/core_25C_dynamic_1/VSS -net VSS -output_directory IR_DEBUG_VSS -nworst_instances 10
  • The following command generates a violation summary report that displays a summary of the IR drop violation distribution:
    debug_irdrop -summary_only
