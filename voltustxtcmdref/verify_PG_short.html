verify_PG_short


verify_PG_short
[-help]
[-area {x1 y1 x2 y2}]
[-net net_name]
[-no_cell_blkg]
[-no_routing_blkg]
[-report filename]

Checks for power and ground shorts between two geometries belonging to different nets. The command performs power and ground short check between the following:

  • PG and PG nets
  • PG and signal nets
  • PG and other special net

This command enables you to check for power and ground shorts in the design before performing any kind of power-grid analysis. You can use this command after restoring the physical design (read_design -physical_data *.enc or read_def filename).

Parameters


-area {x1 y1 x2 y2}


Specifies the coordinates of the area to verify. For example, verify_PG_short -area {0 0 100 100}. The unit of coordinates is micron.

-help

Outputs a brief description that includes type and default information for each verify_PG_short parameter.

For a detailed description of the command and all of its parameters, use the man command: man verify_PG_short.

-net net_name

Specifies the name of the power or ground net to be verified.

-no_cell_blkg

Specifies to ignore cell blockages during during power and ground short checking.

-no_routing_blkg

Specifies to ignore routing blockages during during power and ground short checking.

-report filename

Specifies the name of the report file that contains the violation information.

Example

  • The following command checks for power and ground shorts in the area specified and generates a detailed report named shorts.rpt.
    verify_PG_short -area {0 0 1600 1600} -report shorts.rpt
