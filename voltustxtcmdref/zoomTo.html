zoomTo

zoomTo
[-help]
x y 
[-radius value]

Zooms in the viewable window to the point defined by the coordinates.

Parameters

-help

Prints a brief description that includes type and default information for each zoomTo parameter.

For a detailed description of the command and all of its parameters, use the man command: man zoomTo.
-radius value

Specifies the radius of the zoom area in microns, with center at the point specified by x and y. value is of type float.

Default: 100 microns

x y

Specifies x and y coordinates of the zoom point.

Example

  • When the following command is run, the display zooms in to point with x=100 and y=200. The display area is centered at this point and has the default radius of 100 microns:
    zoomTo 100 200

  • When the following command is run, the display zooms in to point with x=100 and y=200. The display area is centered at this point and has a radius of 50 microns:
    zoomTo 100 200 -radius 50
