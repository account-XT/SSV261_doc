Voltus IC Power Integrity Solution Text Command Reference
Product Version 26.10, May 2026

set_license_check


set_license_check
[-help]
[-checkout license]
[-default]
[-existOnServer]
[-optionList {license1 license2 …}]
[-status]
[-wait time_in_minutes]

Manages licenses for product options. Specifies licenses to check out, license wait time, and the status of all product option licenses.

Parameters


-checkout license

Checks out the licenses for the specified product options when this command runs.

-default

Restores the default. values for this command.

-existOnServer

Outputs a table that provides the following information for each of the licenses that exist on the license server.

  • License name
  • Product number
  • Product name
  • License string
  • Version

-help

Outputs a brief description that includes type and default information for each set_license_check parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_license_check.

-optionList {license1 license2 …}


Specifies licenses to check out dynamically. Dynamic licenses are not checked out until they are needed. If you specify a license that is not allowed with your base license, or a license that is not available, the software does not check out that license and instead issues a warning message.

If you specify more than one license, begin and end the option list with double quotation marks or braces.

-status

Outputs the following information:

  • The name of the base license that is checked out
  • The current wait time
  • A list of the allowed license options
  • A list of the available license options
  • A list of the currently checked-out license options.

-wait time_in_minutes


Specifies the amount of time the system waits for a license to become available. If the license is available in less than the specified wait time, the system checks out the next needed license without waiting.
Default: 0 (no wait time)
Value range: 0 to 10,000

Examples

  • The following command outputs a table that provides information about the licenses that exist on the license server:
    set_license_check -existOnServer

    The system outputs the following information:

    Name       Prod #    Product Name                        License string            Version

    vtsaa      VTS201    Voltus Advanced Analysis GXL Option Voltus_Power_Integrity_AA 15.1

    vtsng      VTSENG100 Voltus Next Generation Product 100  VTS_NG100                 1.0000

    tpsxl      TPS200    Tempus Timing Signoff Solution XL   Tempus_Timing_Signoff_XL  15.1

    tpsl       TPS100    Tempus Timing Signoff Solution L    Tempus_Timing_Signoff_L   15.1

    invs_ms    INVS30    Innovus Mixed Signal Option         Innovus_MS_Opt            15.1


  • The following command specifies that licenses for Tempus Timing Signoff Solution-L and Tempus Timing Signoff Solution-XL may be checked out. Tempus Timing Signoff Solution-L licenses are checked out before Tempus Timing Signoff Solution-XL licenses.
    set_license_check -optionList {tpsl tpsxl}
  • The following command outputs license status and wait time and lists the optional licenses that can be checked out and the licenses that are checked out:
    set_license_check -status

    The system outputs the following information:

    Current checked out base license : vtsxl (Voltus_Power_Integrity_XL 13.2).

    When checking-out an optional license, wait for up to : 0 minutes.

    The base license allows the following optional licenses available now on the server(s) : vtsaa vtsng tpsxl tpsl encsd

    The automatic optional license check-out is limited by -optionList to : vtsaa vtsng tpsxl tpsl encsd

    Current checked out optional licenses : tpsxl

    Summary of all checked out licenses:

    Voltus_Power_Integrity_XL:Tempus_Timing_Signoff_XL

  • The following command sets the wait time to 5 minutes:
    set_license_check -wait 5
