createMarker

createMarker
[-help]
[-bbox { x1 y1 x2 y2 } | -poly { x1 y1 x2 y2 ...}]
[-desc description]
[-layer layerName]
[-rulemap]
[-subtype subtypeName] 
[-tool toolName]
[-type typeName]  

Creates markers for violations in the database and imports DRC markers generated by other software applications. Use this command if you want to import only a specific marker or check a specific marker that has been created by a third party tool.

Parameters 

-help

Outputs a brief description that includes type and default information for each createMarker parameter.

For a detailed description of the command and all of its parameters, use the man command:

man createMarker

-bbox { x1 y1 x2 y2 }

Specifies the area of the bounding box of the marker. For example, createMarker -bbox 100 100 100.5 100.5.
Type: Real

-desc description

Describes the marker. For example, createMarker -desc "the user mark is non default rule spacing check".
Default: ""
Type: String

-layer layerName

Specifies the layer. For example, createMarker -layer METAL2.
Type: String
-poly { x1 y1 x2 y2 ...}
 		 Specifies the area of the bounding polygon of the marker.
-rulemap Specifies whether the marker needs to be created through ruleMap.

-subtype subtypeName

Specifies the marker subtype. For example, createMarker -subtype user_spacing.
Default: Other
Type: String

-tool toolName

Specifies the source software application. For example, createMarker -tool Calibre.
Default: Other
Type: String

-type typeName

Specifies the marker type. For example, createMarker -type user_verify.
Default: Other
Type: String

Example

  • The following command generates markers for tool named Calibre with type METAL1 and subtype S.1:
    createMarker -bbox { 1 2 1 2 } -tool Calibre -type METAL1 -subtype S.1

    The violation browser displays the marker in the above example as follows:

    + Calibre
        + METAL1
            + S.1
                ...
  • Suppose the cadence LPA tool has created the following marker on layer METAL3:
    CDNLitho;SPACING; Severity: 3; MARKER_INFO: "CD = 45.39"

    bbox = (468.248, 63.511) (468.310, 63.599)

    The following command creates a corresponding marker in the design:

    createMarker -bbox {468.248 63.511 468.310 63.599} -layer M3 /
                 -type CDNLitho -subtype Spacing
