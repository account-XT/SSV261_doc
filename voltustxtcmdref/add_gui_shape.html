add_gui_shape

add_gui_shape
[-help]
-arrow
-layer layerName 
[-line {x1 y1 x2 y2 ...} [-arrow ] ]
-name guiShapeName
-polygon {x1 y1 x2 y2 ...}
[-width width]
{-rect {x1 y1 x2 y2} | -line {x1 y1 x2 y2 ...} | -polygon {x1 y1 x2 y2 ...}}

The command add_gui_shape adds a shape to the specified custom layer. You can use the command at any point in the design flow. The shapes added by the command are to annotate shapes and do not show up in a DEF output.

 Parameters

-help

Prints a brief description that includes type and default information for each add_gui_shape parameter.

For a detailed description of the command and all of its parameters, use the man command:

man add_gui_shape
-arrow Draws an arrow in the middle of the line segment to indicate the start to end direction. This parameter can only be used with -line.

-layer layerName

Specifies the GUI layer name to use or create for the rectangle/line. If the specified layer does not exist, it will be created automatically.

-line {x1 y1 x2 y2 ...}

Creates a line, with x1 y1 x2 y2 ... specifying the coordinates for the line segments. The values are specified in microns.
-name guiShapename The name of the GUI shape.
-polygon {x1 y1 x2 y2 ...} Creates a polygon shape, with x1 y1 x2 y2 ... specifying the coordinates for the polygon segments. The values are specified in microns.

-rect {x1 y1 x2 y2}

Coordinates of the lower-left and upper-right points of the rectangle. The values are specified in microns.
-width width Specifies the width of the shape border in pixels. The minimum (default) value is 1 and the maximum is 7.

Examples

  • The following command adds a triangular shape in layer 1:
    add_gui_shape -layer 1 -polygon {95.841 -645 96.592 -644.147 96.926 -644.777}

  • The following command adds a line shape with two segments:
    add_gui_shape -layer 1 -line {95.841 -645 96.592 -644.147 96.926 -644.777} 

  • The following command adds a line shape with two segments and direction arrows:
    add_gui_shape -layer 1 -line {95.841 -645 96.592 -644.147 96.926 -644.777} -arrow 

  • The following command adds a line shape of 3-pixel width:
    add_gui_shape -layer 1 -line {95.841 -645 96.592 -644.147 96.926 -644.777} -width 3
