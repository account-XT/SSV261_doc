NAME

IMPSYC-6127

SUMMARY

Command will become obsolete in the next major release as the software moves to using the Multi-Mode/Multi-Corner (MMMC) architecture for design import. The functionality provided by this command is not required in the MMMC environment. You should use separate MMMC delay corners to model best-case vs. worst case corner library variation. You may also specify early and late library variation within a single delay corner - refer to the create_delay_corner command for detailed information. For more information on creating MMMC configurations, and for a full list of design import related commands to be made obsolete, see the Whats New document for this release.
