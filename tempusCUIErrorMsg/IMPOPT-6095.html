IMPOPT-6095

NAME

IMPOPT-6095

SUMMARY

Cannot delete instance as cell is neither a buffer nor an inverter. Only buffers & inverters can be deleted with this command.

DESCRIPTION

This error comes when tool does not find the specified instance as a buffer/inverter.

In order to get rid of this error: -

1. Check the name of buffer/inverter instance specified.

2. Dump out the footprint of the cell using report_footprints command. If the cell is not interpreted as a buffer/inverter, check library for buffer/inverter footprint and function.
