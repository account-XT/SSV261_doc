distribute_certus_command

distribute_certus_command
[-help]
<command> [-designs <string>]

Queries the physical attributes or properties from Certus clients or verifies the placement status of a few instances in the design. The distribute_certus_command command can be run at any point after start_distributed_eco_clients is specified. The tool waits for the design to be loaded on the Certus clients before running the commands that are passed through distribute_certus_command.

Note: 

The commands passed to distribute_certus_command should not impact routing, change the don't_touch/don't_use attribute, or trigger a new parasitic extraction. In addition, the tool should not reset any parasitics or generate any timing reports. These are not included because they may desynchronize the Certus client manager from the Certus clients.

Parameters 

-help

Outputs a brief description that includes type and default information for each distribute_certus_command parameter.

For a detailed description of the command and all its parameters, use the man command: man distribute_certus_command.

<command>

Specifies the command for which you want to query the physical attributes/properties from Certus clients.

-designs <string>     

Specifies the list of partitions for which distribute_certus_command is executed.

Examples

  • The following command queries report_annotated_parasitics from each partition and sends the output to the Certus clients. The output shows a summary report, which is a list of annotated and unannotated nets:
