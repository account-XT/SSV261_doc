start_gui

start_gui
[-help]
[-designs <string>]

Displays the Certus Manager GUI.

The start_gui -designs command launches the GUI of the Certus Clients. 

Parameters 

-help

Outputs a brief description that includes type and default information for each start_gui parameter.

For a detailed description of the command and all its parameters, use the man command: man start_gui.
-designs <string>

Specifies the list of partitions for which start_gui is executed.

Note:

The start_gui -designs command can be run at any point after start_distributed_eco_clients is specified. The tool waits for the design to be loaded on the Certus Client(s) before launching the GUI. The Certus Manager shell remains inaccessible until all Certus Clients GUIs are closed. This GUI should be used solely as a viewer to display physical constraints, such as placement blockage, routing blockage, routing congestion, local density, and the availability of legal locations.

The following warning is displayed when you run start_gui -designs after start_distributed_eco_clients:

Operations done through the Certus Clients GUI should not impact routing, should not change dont_touch/dont_use attribute, should not trigger a new Parasitic extraction or a reset of parasitic, should not perform any timing report or timing query. 
Purpose of this GUI is to view the layout, query any physical attribute/property from the Certus Clients or change some instances placement status, and anything else is prohibited as it can desynchronize the Certus client manager from the Certus clients.

Examples

  • The following command launches the GUI for the Certus clients for the specified partitions, ptn_wrapper and tdsp_core:
    certus> start_gui -designs {ptn_wrapper tdsp_core}
  • The following command launches the GUI for all the partitions loaded as Certus clients:
    certus> start_gui -designs all
