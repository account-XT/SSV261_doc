IMPEXT-6159

NAME

IMPEXT-6159

SUMMARY

The annotated parasitics can not be reported because the command report_annotated_parasitics is issued before the design is loaded. Load the design before issuing report_annotated_parasitics.

DESCRIPTION

Load the design with either restoreDesign (or read_design in Tempus) or init_design and the parasitic data with one of the following: extractRC (or extract_rc in tempus), spefIn (or read_spef in Tempus), and read_parasitics, before issuing report_annotated_parasitics.

The following example loads a design from the test.imp.dat directory and reads the parasitic data into the Innovus session:

restoreDesign test.imp.dat TOP

read_parasitics -rc_corner C1 TOP_C1ef.gz -rc_corner C2 TOP_C2ef

report_annotated_parasitics -list_annotated -list_not_annotated -list_real_net -list_float_net -list_nodriver_net -list_noload_net -max_missing 3
