DSTACL-2232

NAME

DSTACL-2232

SUMMARY

A clock map file for the boundary modeled cell was not provided. All clock mappings will be automatically deduced. If some clock mappings cannot be determined, a clock map file should be provided to give those mappings.

DESCRIPTION

Clock mappings are required for applying timing windows stored in the boundary model from the block run, in order to convert the windows from block-level clocks to top-level clocks. If a clock mapping cannot be determined, an infinite timing window will be applied, which may give pessimistic results for the analysis. In such cases, the user is expected to supply a file which provides the correct mapping between the block and top clock so that the stored timing window can be converted and used in the analysis. Unmapped clocks will be written by the tool into the file <auto_dir>/<cell_name>_unmapped_clocks.txt. See the read_boundary_model command documentation for the format of the user clock mapping file. If the analysis is setup to use infinite timing windows, then there is no need for the clock mappings.
