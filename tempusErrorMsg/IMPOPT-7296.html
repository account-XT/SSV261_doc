IMPOPT-7296

NAME

IMPOPT-7296

SUMMARY

The stack via rule <> doesnt have any via available for z= This error is encountered because of a design setup issue. One reason could be that there are no vias available for the stack via rule because these have not been added. Another reason could be that vias for all stack rules are not generated because of some user-defined settings. To resolve the error, check the settings using the getGenerateViaMode command to ensure that all necessary vias for all stack via rules are defined.

DESCRIPTION

Please run the command generateVias -advanced_rule in order to generate all necessary vias for all stack via rules defined.
