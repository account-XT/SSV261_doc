init_design

init_design [-help]

Initializes the database and ensures that the tool is ready for full execution.

During init_design, the tool steps through the defined MMMC objects, the design object, and the power requirements and builds up the full representation of the design. After initialization is complete, the design is in a consistent state and is ready for manipulation (floorplanning, synthesis, and so on) or timing.

The init_design command corresponds to the Init step in the Initialization flow. In this step, the full database is prepared for execution. The constraints are loaded into the correct mode, the power data is loaded and applied to the appropriate instances, and the operating conditions are applied to the power domains. Extensive error checking is performed, including checking of objects, and checking for completeness of data. After the Init step is complete, the database is completely consistent and ready for execution.

The init_design command can be broken into the following sub-steps, which are executed by the tool without requiring any user intervention:

1. Power Domain Creation

First, the power domains are populated by the design data. The design instances associated with a particular domain are defined in the Common Power Format (CPF) or UPF file. This instance data is used to populate the power domain attributes. At the end of this sub-step, the different power domains are resolved, and every instance in the system is associated with its power domain.

2. Power Domain Binding to Domain Corners

After the power domains are fully resolved, they can be bound to the library sets in the various create_domain_corner commands. In this sub-step, the active domain corners are processed with each instance getting assigned to the appropriate library set.

3. Power Domain Object Processing

After the power domains are associated with library sets, the power domain objects (state retention, iso cells, and level shifters) can be processed. The power object rules are processed against the defined library sets for each domain to identify the power cells to be used.

4. Constraint Loading

During constraint loading, the SDC files required by the active view are loaded and error checking is done. In addition, the RC corner defined by the required domain_corner is processed and loaded.  In both cases, syntax and error checking is performed.

5. Active View Setting

The final step is to set the active view based on the set_active_view command, and to perform final checks to ensure the view is fully and completely defined. At the conclusion of this command, the system is ready for timing.

After a design has been initialized with init_design, the design is ready for execution. Execution can include incremental updates to timing. 

Timing Incremental Updates

After init_design, you can enter MMMC commands at the command line. These commands populate the mmmc database objects, and perform error checking to report missing objects. For example, if you create a timing condition involving libsets that do not exist, an error will be issued. No data load takes place during command entry. Instead, the loading of new libraries, constraints, and so on, is deferred until an additional init_design is entered.

After you have completed entering the MMMC commands, issue the init_design command to load the new timing intent. After init_design is complete, the database is ready for timing again.

The exception to requiring init_design is set_analysis_view. When this command is issued and datasets are not present in memory, the tool will effectively issue an init_design to load in the required data. If the data is already in memory, the view information is changed without any additional load.

Note: Design data (netlist) and physical data (LEF/OA) incremental update is not allowed. After the first init_design is completed, these steps are effectively disabled. If you issue a read_netlist or read_physical command after the first init_design, the tool returns an error.

Parameters

-help

Prints out the command usage.

For a detailed description of the command, use the man command:

man init_design
