reset_disable_timing

reset_disable_timing 
[-help]
[-from pin_name -to pin_name] 
obj_list 

Restores timing arcs that were disabled using the set_disable_timing command.

Parameters

-help Prints out the command usage.

-from pin_name -to pin_name

Specifies the arc(s) that are to be restored. Specify the -from and -to options together.

You can specify the -from and -to parameters when the obj_list contains instance or library cell objects. Do not specify the -from and -to parameters when the obj_list includes instance pin or library cell pin objects.

The -from and -to options are optional. If not specified, all cell arcs found in the instance or library cell objects are restored.

obj_list

Specifies the instance, instance pin, library arc, library cell, or library cell pin objects.

If the obj_list includes instance pin or library cell pin objects, all cell arcs attached to the specified pin objects are restored.

If the obj_list contains instance or library cell objects, and the -from and -to parameters are not specified, all arcs found in the specified instance or library cell objects are restored.

Examples

  • The following commands sets and resets the timing arcs and displays the resulting reports:

    % set_disable_timing -from A -to Y [get_cells b1] 
% report_inactive_arcs
