report_case_analysis

report_case_analysis
[-help]
[pins_and_ports_list]
[-all]
[-dir]
[-include_ref_name]
[-nosplit]
[-tcl_list]
[-verbose]
[-view view_name]
[> <filename[.gz]>]
[>> <filename[.gz]>]
[-propagated [-include_function]]

Generates a User Case Analysis table, which reports ports and pin that have a set_case_analysis constraint. These ports and pins are constant only for timing analysis. You can optionally generate a Logic Constant Value table, which reports ports and pins whose constant status is part of the design. Information from this table includes ports or pins with set_logic constraints (set_logic_zero and set_logic_one), netlist explicit constants, and output pins with constant output functions.

Parameters

-help Prints out the command usage.

{> | >>} filename

When specified with >, writes the report to the specified file name. If the file already exists, the software overwrites it.

When specified with >>, writes the report to the specified file name. If the file already exists, the software concatenates the report to the end of the file.

The filename parameter must be the last argument in the list. The filename and -tcl_list parameters are mutually exclusive; you cannot specify them together.

Note: To write a compressed report, add the .gz extension to the file name.

Default: Report is displayed on standard output without being saved.

-all

Specifies that the Logic Constant Value table report pins or ports with set_logic constants, constants in the netlist, and output pins with a constant function. These output pins are from library cells or netlist modules.

-include_function

Displays the pin function of a pin.

This must be specified with the -propagated parameter.

-include_ref_name

Displays the reference name of an instance in the report.

-no_split

Specifies that reports with long names will not be split into multiple lines.

Note: The -no_split parameter works if set_table_style -no_frame_fix_width command is specified.

-dir

Specifies that the report include the direction of the pin or port, which is reported as input, output, or inout (internal pins may not have constant constraints).

pins_and_ports_list

Generates a report only for the pins and ports in the specified list.

Default: Generates a report for all pins and ports in the design.

-propagated

Generates a report that includes all the constant pins, including pins with propagated constants. When specified, the report column header shows the constant values - the column header for constant values is User case analysis value.

Default: Report shows pins specified with the set_case_analysis command. 

-tcl_list

Produces the report in Tcl list format instead of a tabular format. This is useful for integrating timing with custom Tcl functions, and also for customizing report generation.

The -tcl_list and filename parameters are mutually exclusive; you cannot specify them together.

-verbose

Generates a report in which each pin is listed on a separate line with a cause. If the pin is a propagated constant, a table is included that reports a chain of constants from an original cause to the reported pin.

Default: All pins are reported in a table.

-view view_name

Generates a User Case Analysis table for the specified analysis view only. To specify this parameter, the software must be in multi-mode multi-corner (MMMC) analysis mode.

Default: When in MMMC analysis mode, generates a table for all active analysis views

Examples

  • The following command reports user case analysis values for all the analysis views:

    litmus > report_case_analysis                       
    Pin name      User       View Name         
                  case                         
                  analysis                     
    -----------------------------------------
    tst_mode      0          scan_fast_RCMIN
    tst_mode      0          scan_slow_RCMIN
    tst_mode      0          func_slow_RCMAX
    scan_en       0          scan_fast_RCMIN
    scan_en       0          scan_slow_RCMIN

  • The following command reports all the constant pins, including pins with propagated constants - and long names are not split into multiple lines:
    litmus > report_case_analysis -propagated -no_split
    ------------------------------------------------
    Pin name          Constant   View Name
                      value
    -----------------------------------------------
    AB_IS/se_0/D       0         func_slow_RCMAX
    AB_IS/se_0/RN      1         func_slow_RCMAX
    AB_IS/se_0/SE      0         func_slow_RCMAX
    AB_IS/se_0/SI      0         func_slow_RCMAX
    AB_IS/se_0/SN      1         func_slow_RCMAX
    AB_IS/se_1/D       0         func_slow_RCMAX
    AB_IS/se_1/RN      1         func_slow_RCMAX
    AB_IS/se_1/SE      0         func_slow_RCMAX

  • The following command reports the Logic Constant Value table report pins or ports with set_logic constants, constants in the netlist, and output pins with a constant function. These output pins are from library cells or netlist modules.
    litmus > report_case_analysis -all -no_split
    ----------------------------------
    Pin name                 Logic
                             constant
                             value
    ----------------------------------
    AB_IS/t0/Z               0
    AB_IS/t1/Z               1
    AB_IS/dma_reg/SE         0
    AB_IS/pre_reg[1]/SE      0
    AB_IS/ECO1reg[2]/SE      0
    ----------------------------------

  • The following command reports the Logic Constant Value table of pins:
    litmus > report_case_analysis -all -no_split -verbose
    --------------------------------
    Pin name               Logic
                           constant
                           value
    -------------------------------
    AB_IS/t0/Z             0
    AB_IS/t1/Z             1
    AB_IS/dma_reg/SE       0

    Pin tst_mode 0 view scan_fast_RCMIN is caused by set_case_analysis 0 on pin tst_mode


    Pin tst_mode 0 view scan_slow_RCMIN is caused by set_case_analysis 0 on pin tst_mode


    Pin tst_mode 0 view scan_fast_RCMAX is caused by set_case_analysis 0 on pin tst_mode

  • The following command reports user case analysis values for the specified view:
    litmus > report_case_analysis -view scan_fast_RCMIN
    --------------------------------------------
    Pin name       User        View Name
                   case
                   analysis
                   value
    --------------------------------------------
    tst_mode        0          scan_fast_RCMIN
    scan_en         0          scan_fast_RCMIN
    --------------------------------------------
  • The following command reports pins that include the direction of the pin - as input: 
    litmus> report_case_analysis -dir

    ------------------------------------------ 
    Pin name          Dir      User case 
                               Analysis value 
    ------------------------------------------ 
    gscanmode        input     0 
    gscanenable      input     0 
    ------------------------------------------

  • The following command reports all the constant pins, including pins with propagated constants: 
    litmus> report_case_analysis -propagated     

    ----------------------------------------

                                   value

    clockandlatch_dup1/U8/TE       1 
    clockandlatch_dup2/U8/TE       1 
    clockandlatch_dup3/U8/TE       0 
    ----------------------------------------

  • The following command reports details of each pin separately. The pin crclocklatch/U8/TE is reported because of a set_case_analysis 0 assertion on pin gscan:
    litmus> report_case_analysis -propagated -verbose crclocklatch/U8/TE
