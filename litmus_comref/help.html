help

help
[<command_name> | <message_name> | -message]
[-verbose]

Note: Although the help command is still available, it is recommended that you use the man command.

Displays all the Litmus commands and their command syntax. To display a group set of commands, use a keyword such as add, delete, report, or set. To display the usage for all commands, use help -help .

While in the Tcl mode, the help command displays a list of all available Tcl mode commands.

Parameters

<command_name>

 Displays the command syntax for a given command name. If you do not specify a command name, the Litmus displays all the commands.

<message_name>

Displays help for the corresponding rule check message.

-message

Displays all rule check messages.

-verbose

Expands information about the command, including examples and related commands.

Examples

% help
% help read_hdl
% help read_hdl -verbose
% help -help
% help -message
