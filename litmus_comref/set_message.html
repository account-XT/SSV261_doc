set_message

set_message
-help
-id list_of_msgIDs
[-reset_count  | -severity {warn error info} | -limit number | -no_limit | -suppress | -unsuppress | -on_error {msg_only exit stop_script}| -stop_script_limit limitNumber]


Specifies to change the message severity levels, INFO, WARNING or ERROR, at the beginning of the message. This command allows you to control the messages that are displayed for a particular design. For example, if there are some warnings that are critical for the design, you can change the message severity to ERROR. Similarly, if there are messages that you want to ignore, you can change the message severity to INFO.

Parameters

-help

Outputs a brief description that includes type and default information for each set_message parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_message.
-id list_of_msgIDs Specifies the list of message IDs that require a change in the message severity level. If you do not specify a message ID, the change in severity level is applied to all message IDs.
-limit number

Sets the message limit to number per every public command. The default limit is 20, so any specific message will be written out 20 times for one command and then further output of that message will be disabled (along with an additional message saying the message limit has been exceeded). If the number is set to 0, the message will be completely suppressed for the next public command that triggers the message. You can unsuppress the message by setting the number greater than 0.
-no_limit

Removes any existing limit on the selected messages. Suppressed messages are not unsuppressed.
-on_error {msg_only | exit | stop_script}

Specifies an extra action for error messages (not for warn or info messages). If no message is specified, the action applies to all error messages.

  • msg_only: Prints error message only, and the command proceeds as it normally would. This is the default.
  • exit: Exits immediately and returns to Linux.
  • stop_script: Waits for the current Tcl command to finish, then stops executing any Tcl script, and returns to the interactive Tcl prompt.

If the message severity is changed from error to warn or info, the software will no longer trigger extra action.
-reset_count

Resets the count of the specified message. You can use this option when you want to clear previously generated warnings or errors before beginning the next major step in the design flow.
-severity {warn | error | info | reset} Specifies the new severity level for the message ID being modified. The reset argument sets the message severity back to its original state.
 -stop_script_limit limitNumber Sets the message limit for a public command. If you set -stop_script_limit for a command as 10 and message for the command is triggered for the 10th time, the tool will wait for the current Tcl command to finish, then stop executing any Tcl script, and return to the interactive Tcl prompt. The default value of -stop_script_limit is -1, which is unlimited.
-suppress Suppresses the message. 
-unsuppress Unsuppresses the message. 

Examples

  • The following command changes the message IMPLF-81 from ERROR to WARN:
    set_message -id IMPLF-81 -severity warn
  • The following command returns all messages to their original severity:
    set_message -severity reset
  • The following command resets the specified message to its original severity:
    set_message -id ENCLF-18  -severity reset
