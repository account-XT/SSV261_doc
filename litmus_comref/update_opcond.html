update_opcond

update_opcond 
[-help]
-name opcondName
[-process processValue]
[-temperature temperatureValue] 
[-voltage voltageValue]

Updates a set of virtual operating conditions in the specified library that were created using the create_opcond command.

Parameters

-help Prints out the command usage.

-name opcondName

Specifies the name of the operating condition to be updated.

-process processValue

Specifies the process value for the operating condition.

-temperature temperatureValue

Specifies the temperature value for the operating condition.

-voltage voltageValue

Specifies the voltage value for the operating condition.

Related Commands

  • set_opcond
  • create_opcond
