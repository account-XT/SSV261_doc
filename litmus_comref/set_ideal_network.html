set_ideal_network

set_ideal_network 
[-help]
obj_list 
[-no_propagate] 

Identifies driver pins or ports as sources of an ideal network. By default, all pins and nets in the transitive fanout of the specified port or driver pin are marked as ideal. Ideal network marking normally propagates through combinational cells and stops at sequential cells.

This command is not view/mode-based - it applies to all the active views.

The set_ideal_network command sets 0 slew for bi-directional pins. This ensures that unnecessary DRV violations do not occur.

Parameters

-help Prints out the command usage.

-no_propagate

Prevents propagation through transitive fanout.

obj_list

Specifies a list of objects - instance pins, ports, or nets.

Examples

The following command marks the fanout of the input port scan_se as an ideal network:

% set_ideal_network scan_se

This can be observed in the output of below mentioned report_timing command where the whole fanout of 'scan_se' is considered as ideal:
