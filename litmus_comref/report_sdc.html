report_sdc

report_sdc 
[-help]
[-view <string>]
[-scope <string>]
[-verbose  [-status <string>]]
[-sdc_compare]

Reports SDC parsing results and constraint lint rule results for the specified SDC commands. By default all the SDC commands are reported, and reporting consists of two sections : SDC parsing status and constraint lint rule violations.

Parameters 

-help Prints out the command usage.

-view string

Specifies the name of view.
-status string

Specifies rule status as pass or fail.
-scope string Specifies the SDC commands that are associated with the scope to report.
-verbose Provides additional information.
-sdc_compare Provides SDC Compare results (bool, optional)

Command Order

Use this command after design initialization (init_design).

Examples

  • The following command generates SDC command report for create_clock and create_generated_clock commands.

    % report_sdc create*clock

  • The following command generates SDC command report for the SDC commands that failed SDC parsing.

    % report_sdc -status fail
