report_black_box

report_black_box
[-class <full | user | system | undefined | unsupported | empty | notranslate>]
[-detail]
[-module | -instance]
[-timing_arcs_missing]

Displays blackboxes from the design. The blackboxes might already exist in the design or might have been added previously with the add_black_box command.

Parameters

-class

Displays one of the following classes of blackboxes, where:

  • full: Blackboxes from both the user and system classes. This is the default.
  • user: Blackboxes added previously with the add_black_box command.
  • system: Blackboxes that are contained in the original design.
  • undefined: Blackboxes for undefined modules.
  • unsupported: Blackboxes for unsupported modules.
  • empty: Blackboxes for empty modules.
  • notranslate: Blackboxes for notranslate modules.

-detail

Displays details about blackboxes, where:

  • user: Indicates that the blackbox was added by the add_black_box command.
  • system(empty): Indicates that the module contains no logic.
  • system(graybox): Indicates that a Liberty cell has an incomplete functional definition. The cell has undriven outputs and a tied ouput, but no well-functioning output pin.
  • system(lef): Indicates that the macro is defined in the LEF file, but not defined in library/design modules.
  • system(notranslate): Indicates that the blackbox was added by the add_notranslate_modules command.
  • system(undefined): Indicates that the blackbox was added by the set_undefined_cell_blackbox command.
  • system(unsupported): Indicates that the module contains unsupported statements.

-module

Reports only the blackbox modules. This is the default.

-instance

Reports the blackbox instances.

-timing_arcs_missing

 Specifies that only blackboxed Liberty cells that have no timing arcs should be reported.
