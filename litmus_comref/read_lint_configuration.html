read_lint_configuration

read_lint_configuration
< <filename> | -default >
[-version <version>]
[-summary | -verbose]

Reads a configuration file for SDC lint checks. Only the configure_lint_check command should be used in this file.

To specify for which SDC version should the linting be configured, use the "-version" option of this command. The Tcl variable ::sdc::sdc_version_list contains all the SDC version numbers supported by the tool. To apply the same configuration change file updated_config.txt to all supported versions, write:

tclmode
foreach v $::sdc::sdc_version_list {
  read_lint_configuration updated_config.txt -version $v
}

Parameters

<filename>

Specifies the name of the configuration file to read.

-default

Specifies that tool's default configuration will be loaded.

-version <version>

Specifies the SDC version to which the configuration will be applied. If this is not specified, the configuration will be applied for version 2.0.

-summary

Reports only a summary of the configuration changes. This is the default.

-verbose

Reports details of all changes made by the specified configuration.

Examples

  • The following command reads the lint configuration from file config.txt and applies it to version 2.0:

    % read_lint_configuration config.txt

  • The following command reads the lint configuration from file config.txt, applies it to version 1.6, and reports any changes:

    % read_lint_configuration config.txt -version 1.6 -verbose
