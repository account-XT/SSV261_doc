set_path_adjust_group

set_path_adjust_group 
[-help]
[-fall]
[-fall_through through_list]
-name path_adjust_group_name
[-rise]
[-rise_through through_list]
[-through through_list]
[-from from_list | -rise_from from_list | -fall_from from_list]
[-to to_list | -rise_to to_list | -fall_to to_list]

Allows you to specify the path that is used by the set_path_adjust command for setting path slack adjustment values.

The set_path_adjust_group command is not allowed to be used inside the SDC constraints file. It is only allowed in the tool run script.

If path group definitions are matching/overlapping (when the -from/-through/-to parameters are used), then path group resetting is applied. The path group overwriting and prioritization rules are similar to path exceptions.

For more details, refer to group_path.

Parameters

-help

Prints out the command usage.

-fall                          

Applies set_path_adjust_group at the falling edge of the signal on the path endpoints.

-fall_from from_list

Applies set_path_adjust_group at the falling edge of the signal on the from pins.

-fall_through through_list

Applies set_path_adjust_group at the falling edge of the signal on the through pins.

-fall_to to_list]

Applies set_path_adjust_group at the falling edge of the signal on the to pins.

-from from_list  

Specifies the list of pins, instances, or clocks that are the start of the paths.

-name path_adjust_group_name

Specifies the name of the path adjust group.

-rise    

Applies set_path_adjust_group at the rising edge of the signal on the path endpoints.

-rise_from from_list

Applies set_path_adjust_group at the rising edge of the signal on the from pins.

-rise_through through_list

Applies set_path_adjust_group at the rising edge of the signal on the through pins.

-rise_to to_list

Applies set_path_adjust_group at the rising edge of the signal on the to pins.

-through through_list

Specifies the list of pins or instances where the paths go through.

-to to_list

Specifies the list of pins, instances, or clocks where the path ends.

Examples

The following commands specify the adjusted path groups:

  • set_path_adjust_group -name AG1 -from in1 -through buf1/A –to out1
  • set_path_adjust_group -name AG2 -from [get_clocks CK1] -through buf1/A -to [get_clocks CK2]
  • set_path_adjust_group -name AG3 -from [get_clocks {CK1 CK2}] -to [get_clocks {CK1 CK2}]
