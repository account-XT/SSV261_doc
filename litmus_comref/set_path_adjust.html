set_path_adjust

set_path_adjust
[-help]
adjust_value
-path_adjust_group path_adjust_group_name
-view string
[-setup | -hold]

Defines the slack adjustment value for timing paths. The defined adjustment value is added to the slack of a path specified by the path adjust group, referred to by the –path_adjust_group parameter. You can specify a path adjust group by using the set_path_adjust_group command.

If multiple path adjustment values are applicable on the same pin, which is on the path specified by multiple set_path_adjust_group constraints, then the smallest adjustment value will be applied.

Note: The set_path_adjust command is not allowed to be used inside the SDC constraints file. It is only allowed in the software run script.

Parameters

-help

Prints out the command usage.

adjust_value

Specifies the value of slack adjustment.

-hold 

Specifies to apply the adjust value to early paths.

-path_adjust_group path_adjust_group_name

Specifies the name of path adjust group that defines the path for which the adjustment will be applied.

-setup

Specifies to apply the adjust value to late paths.

Note: If you do not specify -setup or -hold parameter, the software sets the adjust value to both setup and hold analysis.

-view string 

Specifies a list of analysis views for which adjustment will be applied.

This parameter accepts multiple views as argument.


Examples

  • The following commands define the slack adjustment values for the specified views:
    litmus> set_path_adjust 0.44 -path_adjust_group AG1 -view view1 -hold
    litmus> set_path_adjust 0.44 -path_adjust_group AG2 -view view2 –setup
    litmus> set_path_adjust 0.44 -path_adjust_group AG3 -view view3
