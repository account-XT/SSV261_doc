add_rule_filter

add_rule_filter
[-help]
filter_name
[-description string]
[-filter string [-regexp]]
[-object_filter object_names]
[-rule string]
[-replace]

Adds a new rule filter that can be applied to any number of rule objects. Rule filters are used to select which occurrences should be ignored by commands such as report_rule_check.

Parameters

-help Prints out the command usage.

filter_name

 Specify the name of the rule filter to add or apply.

-description string

Specify the description for the added rule filter.

-filter filter_expression

The rule filter will apply to the rule occurrences for which the specified filter_expression evaluates to true.

The syntax of the filter_expression must follow the format "<attribute_name> <operator> <value>". 

The operator can be ==, !=, >=, >, <=, <, =~, and !~.

Multiple conditions can be combined with the logical operators !, &&, ||, and parentheses ().

-regexp

 Specifies that the pattern matching operators used inside filter_expression (such as =~) should use regular expressions as patterns, rather than glob-style patterns.
-object_filter object_names

Specifies the objects which will be filtered out from the rule occurrences.

Supported rules: CONST_CLK_DEF1, CONST_CLK_DEF6.

-rule string

Specify the description for the added rule filter.

-replace

Deletes and creates a new file if the specified file already exists.

Examples

  • This command adds the rule filter occurrence_filter_1 that filters out a rule occurrence if its witness contains my_reg. The rule filter is applied to CONST_CLK_DEF1 rule.

    % add_rule_filter occurrence_filter_1 -filter "witness =~ *my_reg*" -rule CONST_CLK_DEF1

  • This command adds the rule filter object_filter_1 that filters out my_reg from a rule occurrence. Then the rule filter is applied to CONST_CLK_DEF1 and CONST_CLK_DEF6 rules.

    % add_rule_filter object_filter_1 -object_filter my_reg
% add_rule_filter object_filter_1 -rule CONST_CLK_DEF1
% add_rule_filter object_filter_1 -rule CONST_CLK_DEF6
