update_timing_condition

update_timing_condition 
[-help]
[-library_sets string]
-name timingConditionName
[-opcond string]
[-opcond_library string]

Updates the virtual operating conditions (set using create_timing_condition command) with the new settings.

Parameters

-help                          

Prints out the command usage

-library_sets string        

Specifies list of library sets to associate with the specified timing condition.

-name timingConditionName   

Specifies a unique name for the timing condition. This name must exist or an error is issued.

-opcond string           

Specifies a single name of an operating condition to associate with the timing condition.

-opcond_library string      

Specifies a name of the library to search for the defined operating condition.

Examples

  • The following example shows the update_timing_condition command performs an update on the specified timing condition:
    create_timing_condition –name TC1 –library_sets {ls1 ls2} -opcond oc1
    update_timing_condition –name TC1 –library_sets {ls3}; # TC1 now only has libset ls3
  • The following commands result in identical results. However, the first command creates the bin TC2 and the second command updates both the options:
    create_timing_condition –name TC2 –library_sets {ls1 ls2} -opcond oc1
    update_timing_condition –name TC2 –library_sets {ls1 ls2} -opcond oc1
