report_rule_instance

report_rule_instance
[<full_name* ...>]
[-summary | -verbose]

Reports one or more rule instances in the current session. This command applies to rules that are not related to SDC integration.

Parameters

<full_name* ...>

Specifies the fully qualified name(s) of the rule instance(s) to report. By default, the command reports all rule instances. This accepts wildcards.

-summary

Reports the name, description, and severity level of the specified rule instances.
-verbose Reports extended information for the specified rule instances.
