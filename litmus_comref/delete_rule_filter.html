delete_rule_filter

delete_rule_filter
<filter_name* ...>
[-rule <rule_name*>] ...

Deletes rule filters from the current session or stops applying rule filters to certain rule objects (rule sets, rule groups, or rule instances).

Parameters

<filter_name* ...>

Specifies the name(s) of the rule filter(s) to delete.
If the -rule option is not specified, the specified rule filters will be deleted and removed from all rule objects to which they are applied.

-rule <rule_name*>

Removes only the selected rule filters from the specified rule objects. At least one filter name is required when using this option.

Examples

  • The following command deletes filterf1and all references to it:

    delete rule filter f1

  • The following command removes filter f1 from the list of filters that are applied to rule set s1:

    delete rule filter f1 -rule s1
