pushdown_hierarchical_constraints

pushdown_hierarchical_constraints
[-help]
-dir <string>
[-types <string>]
[-instances <string> | -blocks <string>]

Pushes down timing constraints from a higher design level down to selected blocks or instances, with optional filtering by constraint type.

Parameters 

-help Prints out the command usage
-dir <string> Specifies directory name where output to be redirected (string, required)
-blocks <string> Pushdowns constraints for specific module(s).
-instances <string> Pushdowns constraints only for listed instances.
-types <string> Pushdowns only selected constraint classes.

Related Commands
