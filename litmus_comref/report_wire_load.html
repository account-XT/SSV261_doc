report_wire_load

report_wire_load
[-help]
[-instances name_or_collection_of_hierarchical_instances]
[-ports name_or_collection_of_ports]
[-late | -early]
[> | >> filename]

Reports the wireload name, library, wire load mode and selection type for all hierarchical instances in the design.

Note: To use the wireload model functionality, you must enable the enable_wire_load_model_support attribute using the following command:

set_var enable_wire_load_model_support 1

Parameters


-help Prints out the command usage.

>|>> filename

When specified with >, writes the report to the specified file name. If the file already exists, the software overwrites it.

When specified with >>, writes the report to the specified file name. If the file already exists, the software concatenates the report to the end of the file.

The filename parameter must be the last argument in the list.

Note: To write a compressed report, add the .gz extension to the file name.

Default: Report is displayed on standard output without being saved.

-early

Reports wireload model information for the best case condition.

-instances name_or_collection_of_hierarchical_instances

Specifies the name of an instance or collection for which the report_wire_load command reports the wireload name, library, wire load mode, and selection type. The report_wire_load command also supports wildcard names such as U*.

-late

Reports wireload model information in worst-case condition.

Data_type: bool, optional

-ports name_or_collection_of_ports

Reports the wireload details for the specified ports.

Examples

  • The following command reports the wireload details for the specified ports.
    report_wire_load -ports clk1 -early
