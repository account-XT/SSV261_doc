create_flow_step

create_flow_step
[-help]
body
[-categories string]
[-check checkTcl]
[-description string]
[-exclude_time_metric]
-name name
[-owner string]
[-write_db] 
[-skip_metric]

Creates a single flow_step object and fills-in the required, and some optional attributes. Further modifications of the step can be performed using the set_db command. If you try to define a step with the same name as an existing step, it results in error. To redefine a flow step, you must use the set_db command to modify the attributes, or delete and recreate it.

Note: Unlike Tcl procedures, flow steps do not take arguments and refer to attributes instead. The use of attributes requires that the data on which a step relies, is stored in the database and may be examined later.

Parameters

-help

Outputs a brief description that includes type and default information for each create_flow_step parameter.

For a detailed description of the command and all of its parameters, use the man command:
man create_flow_step.
body

Specifies a block of Tcl that is run as the main action of the step.
-categories string Defines the metric categories to calculate the flow step.
-check checkTcl

Specifies a block of Tcl to run step-specific static checks.
-description string

Describes the purpose for the current flow step.
-exclude_time_metric Ensures that the CPU and wall time of the corresponding step is not included in any parent steps.
-name name

Specifies the name of the Tcl of the step. This can consist of alphanumeric characters and underscore only, and may not start with a digit.

The following names have special meanings and may not be used for steps:

  • next
  • end
-owner string Specifies the owner of the flow.
-write_db

Automatically saves a database when the flow step is complete.
-skip_metric

Skips generating metrics when the step is complete.  By default, every step saves the design and runs metrics when completed.
