generate_sva

generate_sva
[-category_comment_keyword string]
[-category_file string]
[-cgc]
[-mcp] 
[-output_path output_path]
[-replace]
[-sca]
[-sdt]
[-sfp]
[-use_category]
[-include_clock_to_clock]
[-help]

Generates sfp.sv, mcp.sv, cgc.sv, macro_lib.sv, "top_degisn_name"_defines.h, and a "top_design_name".summary log file.

Parameters

-category_comment_keyword

Specify the keywrod to identify category tag in SDC comment.

For example, If SDC has set_false_path -comment {foo**SVA FP_01 **SVA bar}, keyword is **SVA (string, optional)
-category_file

Specify the file containing categorization of SFPs.

-cgc

 Write verilog testbench to verify create_generated_clock
-mcp

Writes verilog testbench to verify set_mutlicycle_path.

-output_path output_path

Specify the output path.
-replace Replaces the original SVA (.sv) files if they exist
-sca Writes verilog testbench to verify set_case_analysis.
-sdt Writes verilog testbench to verify set_disable_timing.

-sfp

Writes verilog testbench to verify set_false_path.

-use_category

 Generates custom assertions based on category of SFP define in file specified by -category_file or -comment in SDC.

-include_clock_to_clock

 Include MCPs & FPs defined with -from clock -to clock (bool, optional)
-help Prints out the command usage.
