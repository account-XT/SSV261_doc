reset_max_fanout

reset_max_fanout
[-help]
obj_list

Resets maximum fanout limit specified (using the set_max_fanout command) on the objects in the object list. The valid objects in the object list are input and bidirectional ports and current design.

Parameters


-help Prints out the command usage.

obj_list

Specifies the list of ports or modules for which assertions are reset.
