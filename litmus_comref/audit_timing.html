audit_timing

audit_timing

Performs a focused set of timing constraint coverage and sanity checks. It is a Litmus pre-STA audit command, that helps identify unconstrained paths, missing clock definitions, and common timing modeling issues before final STA signoff. Following checks are performed by this command: 

Constraint Coverage Checks: These checks identify timing checks (report_analysis_coverage - RAC) that were not exercised due to missing, blocked, or incomplete constraints.

RuleDescription
CONST_COV_SHSetup and/or hold checks not performed on pins
CONST_COV_RRRecovery and/or removal checks not performed on pins
CONST_COV_CGClock-gating setup/hold/pulse-width checks not performed
CONST_COV_DATAData setup and/or hold checks not performed
CONST_COV_CPClock period checks not performed
CONST_COV_CSClock separation checks not performed
CONST_COV_SKEWSkew checks not performed
CONST_COV_PWPulse-width checks not performed

Clock Gating and Clock Quality Checks:

RuleDescription
CONST_CG_CHK5Clock-gating enable pin not reached by any constrained data (check_timing: clock_gating_no_data)
CONST_CG_CHK6Clock clipping due to incorrect gate type or trigger (check_timing: clock_clipping_gate)
CONST_CG_CHK7Clock clipping due to incompatible clock and data frequencies (check_timing: clock_clipping_freq)

Data Path and Structural Timing Checks:

RuleDescription
CONST_DAT_CHK5Internal endpoints unconstrained by clocks but affected by max-delay exceptions (check_timing: max_delay_constrained_internal_endpoint)
CONST_DGN_TIM2Latch and its fanout operating on the same clock (check_timing: latch_fanout_clock_connectivity)

Clock Interaction and Exception Checks:

RuleDescription
CONST_EXC_CLK2Interactions between multiple clock domains, including true, false, or partial crossings (check_timing: clock_crossing)

Missing Generated Clock Checks:

RuleDescription
CONST_CLK_DEF1Detects missing generated clocks on clock generator circuits (flop/ICG driving another clock pin through logic without a generated clock)
CONST_CLK_DEF46Detects missing create_generated_clock definitions
  • To enable check_timing checks, add following to your Litmus runscript:
    • set_rule_handling -category constraint_enhanced_signoff -severity warning
  • To enable report_analysis_coverage checks, add following to your Litmus runscript:
    • set_rule_handling -category constraint_coverage_signoff -severity warning

audit_timing provides a compact, signoff-oriented audit to ensure that:

  • All critical timing checks are exercised
  • Clock gating and generated clocks are correctly modeled
  • Cross-clock interactions and structural issues are visible early.

Parameters

None

Related Commands

  • check_timing
  • report_analysis_coverage
