input_design

input_design 
[-help]
[-hdl_script_1 <string> | [-netlist_1 <string> -top_1 <string>]]
[-hdl_script_2 <string> | [-netlist_2 <string> -top_2 <string>]]

Loads a design using either an HDL script or a netlist with a specified top module to establish the design context.

Parameters 

-help Prints out the command usage.

-hdl_script_1 <string>

Specifies Design1's HDL Script (string, required)
-hdl_script_2 <string> Specifies Design2's HDL Script (string, required)
-netlist_1 <string> Specifies Design1's Netlist (string, required)
-netlist_2 <string> Specifies Design2's Netlist (string, required)
-top_1 <string> Specifies Design1's top module (to be used when -netlist_1 is specified) (string, required)
-top_2 <string> Specifies Design2's top module (to be used when -netlist_2 is specified) (string, required)
