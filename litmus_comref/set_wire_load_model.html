set_wire_load_model

set_wire_load_model  
[-help]
[obj_list]
[-library library_name]
[-max]
[-min]
-name wireload_model

Specifies the wire load model to be used from the technology library, and sets the wire load model on the design or on a hierarchical object (instance). If the list of instances is not specified, the wire load model is set on the current instance. Otherwise, the wire load model is set on all the specified instances or ports.

Use wire load models for estimating delays before the actual wire loads are back annotated. A technology library contains different wire load models, previously computed based on the analysis of several designs differing in area.

Parameters 

-help Prints out the command usage.

-library library_name

Specifies the technology library to use when searching for the name of the wire load model. You can specify a library name, or a collection of libraries.

Default: All technology libraries are searched.

obj_list

Specifies the list of objects - designs, ports, or hierarchical instances.

-max

Sets the wire load model only for the maximum PVT (process, voltage, temperature) corner.

Default: The specified wire load model applies to all three PVT corners if neither the -min nor the -max parameter is specified.

-min

Sets the wire load model only for the minimum PVT (process, voltage, temperature) corner.

Default: The specified wire load model applies to all three PVT corners if neither the -min nor the -max parameter is specified.

-name wireload_model

Specifies the name of the wire load model in the library.

Examples

  • The following command sets the COM3_LV_WLM_0.0 wire load model from the COM3_LV_WIRE library on the current module for all PVT corners:
    litmus>  set_wire_load_model -library COM3_LV_WIRE -name COM3_LV_WLM_0.0
  • The following command sets the B1X1 wire load from the lca500kv library on the clk1 port for the minimum PVT corner: 
    litmus>  set_wire_load_model -library lca500kv -min -name B1X1 clk1
  • The following command sets the 3M_TO_4500Kwire load from the c13tsmc_slow2s108v125c library on the current module for the minimum PVT corner: 
    litmus>  set_wire_load_model -library c13tsmc_slow2s108v125c -min -name 3M_TO_4500K
