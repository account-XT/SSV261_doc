report_clock_mapping

report_clock_mapping
[-help]
[-block_clock <string>]
[-top_clock <string>]
[-unmapped_clocks]
[-scope <string>]
[-clock_path ]
[-data_path ]

Reports clock mapping information with optional scoping and clock‑based path selection.

Parameters 

-help Prints out the command usage
-block_clock <string>

Specifies the block clock name (string, optional)
-clock_path

Includes clock path information in the clock mapping report (bool, optional)
-data_path

Includes data path information in the clock mapping report (bool, optional)
-scope <string>

Specifies the name of hierarchical instance (string, optional)
-top_clock <string>

Specifies the top clock name (string, optional)
-unmapped_clocks

Includes unmapped clocks in the clock mapping report (bool, optional)
