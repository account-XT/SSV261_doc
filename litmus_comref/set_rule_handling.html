set_rule_handling

set_rule_handling
full_name
[-limit num]
[-severity name]
[-suppress | -unsuppress]

Sets the severity level of rule instances or limits the number of occurrences that each rule instance can have.

Options and Arguments

full_name

Specifies the name(s) of the rule instance(s) to configure.

This accepts wildcards.
[-limit]

Sets the maximum number of occurrences that a rule instance can have.

Zero (0) means no limit, which is the default if not specified.
[-severity]

Sets severity level of the rule instance(s).

The specified severity can be Error, Warning, Note, Ignore.

If this option is not used, Warning is the default severity level.
[-suppress|-unsuppress] Suppresses or unsuppresses the rule instance(s).
