time_info

time_info
[-help]
[stage_name]
[-current]
[-report]
[-stamp]
[-table metric_table_id]
 

Reports and tracks runtime and memory performance.

When the time_info command is used without any name, an entry for the stage is created in the table named as "undefined". When the command is used multiple times without any stage name, the stage name is incremented, for example undefined1, undefined2, undefined3. This will ensure that each stage name in the table is unique.

Parameters

-help

Outputs a brief description that includes type and default information for each time_info parameter.

For a detailed description of the command and all of its parameters, use the man command: man time_info.
stage_name Specifies the name of the stage.
-current Reports the current stage.
-report Reports all stages up to this point
-stamp Creates a time stamp.
-table metric_table_id

Specifies metrics table ID to support multiple tables.

Default: 'default'

Examples

  • The following command shows the usage of the -current parameter:
    litmus > time_info -current
    =======================================================
    CPU Runtime: 0:00:52.5
    Wall Runtime: 0:03:41
    Memory Usage: 1387.4 MBytes
    Peak Memory Usage: 1505.3 MBytes
    Current Time: 12:17:13 (Jul07)
    =======================================================
  • The following command shows the suage of -report:

    litmus > time_info -report

    Total Wall | Stage Wall | Wall % | Date - Time     | Memory   | Stage
    ----------------+----------------+------------+-------------------+------------+----------------------
    0:00:00    | 0:00:00    | 0.0%   | 8:27:08 (Jul07) | 824.3 MB | init
    ----------------+----------------+------------+-------------------+------------+----------------------
    Number of threads: 1 * 1 (id: default)
