get_time_unit

 get_time_unit
[-help]

Returns the current time unit (in nanoseconds) for the session derived from the library file or set with the set_library_unit -time parameter. This unit will be used during report generation and constraint settings.

Parameters

-help Prints out the command usage.

Examples

  • The following command returns the time unit for the session:
    get_time_unit

    1.000000ns
