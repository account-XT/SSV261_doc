delete_hierarchical_clock_mapping

delete_hierarchical_clock_mapping
[-help]

[-top_clock]

[-block_clock]

[-instance]

[-reset]

Deletes clock mapping for the top clocks and the block clocks in the hierarchical signoff flow.

Parameters 

-help Prints the command usage.
-top_clock Specifies the name of top-level clock.
-block_clock Specifies the name of block-level clock.
-reset Resets the clock mapping.
-instance

Specifies the hierarchical instance name.

Command Order

Use this command after design initialization (init_design).

Examples

The following command deletes the clock mapping for all the top clocks and block clocks: 

% delete_hierarchical_clock_mapping
