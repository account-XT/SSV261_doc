report_lint_configuration

report_lint_configuration
[<command_name*>] ...
[-all | changed | -unchanged]
[-default]
[-lint_rules]
[-version <version>]

Reports the current lint configuration used by Litmus to perform SDC lint checks. This command can also be used to report all SDC lint checks that will be performed based on the current settings if an SDC file is read.

Parameters

<command_name*>

 Reports only on the configuration of these selected SDC commands. This accepts wildcards.

-all

Report all attributes. This is the default.

-changed

Reports only attributes that have been changed.

-unchanged

Reports only attributes that have not been changed.

-default

Reports tool's default configuration for the specified version.

-lint_rules

Reports all SDC lint checks performed based on the selected configuration.

version <version>

Specifies the SDC version the lint configuration to be reported. If this is not specified, the configuration for version 2.0 is reported.

Examples

  • The following command reports the default lint configuration for the create_clock SDC command in version 1.6:

    % report_lint_configuration -default -version 1.6 create_clock

  • The following command reports all lint rules checked based on the lint configuration for the create_clock SDC command in version 2.0:

    % report_lint_configuration create_clock -lint_rules
