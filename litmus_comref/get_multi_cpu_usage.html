get_multi_cpu_usage

get_multi_cpu_usage
[-help]
[-auto_page_fault_monitor]
[-cpu_per_remote_host]
[-keep_license]
[-local_cpu]
[-remote_host]
[-thread_info]
[-verbose] 

Displays the requested number of threads or hosts.

To request threads or hosts, use set_multi_cpu_usage.

Parameters

-help Prints out the command usage.

-auto_page_fault_monitor

Displays the warning rank set for performance issues caused by major page faults

-cpu_per_remote_host

Displays the number of CPUs available on every remote host for Superthreading.

-help

Outputs the command usage and a brief description about the command parameters.

-keep_license

Displays the current setting for the set_multi_cpu_usage -keep_license parameter.

-local_cpu

Displays the number of available local CPUs for multi-threading.

-remote_host

Displays the number of available remote hosts for distributed processing or Superthreading.

-thread_info

Displays the level of informational messages for each thread.

-verbose

Displays a message with the current multiple-CPU setting.

Examples

  • The following command displays the requested number of threads for multi-threading:
    get_multi_cpu_usage -local_cpu
  • The following command displays the requested number of remote hosts for Superthreading or distributed processing:
    get_multi_cpu_usage -remote_host
  • The following command displays the requested number of CPUs per remote hosts for Superthreading:
    get_multi_cpu_usage -cpu_per_remote_host
