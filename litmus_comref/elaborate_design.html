elaborate_design

elaborate_design
[-help]
-script hdl_script

Converts RTL to a generic netlist based on the specified script, which should contain commands for reading HDL files into memory and creating a design hierarchy consisting of a top-level design and its referenced sub-designs from Verilog or SystemVerilog modules or VHDL entity/architectures. The command transforms each module/architecture to be represented as a design in the form of a structural netlist. It also performs semantic checking, sequential register (flops/latches) inferencing, and high-level HDL optimizations. Instances of undefined modules or entities are marked as unresolved and the corresponding modules/entities reported as blackboxes.

A sample script that can be passed to elaborate_design is shown below:

Sample hdl_script.tcl

read_hdl -language sv "cpu_if.sv cpu_alu.sv cpu_rf.sv"

read_hdl -language v2001 "cpu_top.v"

elaborate cpu_top

 Note that the commands specified above are only valid within the script being passed to elaborate_design. You cannot use them directly at the Innovus prompt.

Parameters 

-help

Outputs a brief description that includes type and default information for each elaborate_design parameter.

For a detailed description of the command and all of its parameters, use the man command:
man elaborate_design.

-script hdl_script

Specifies the script for HDL manipulation within the Synthesis engine. The software looks for the specified script file in each search path directory set using the script_search_path attribute. Alternatively, you can specify the complete path to the script.  

Data_type: string, required

Examples

  • The following command elaborates the top-level design and all of its references based on the specified script:
    elaborate_design -script Xm_hifi3_ss_spfpu_7Xtmem.hdl.tcl
