verify_timing_intent

verify_timing_intent
[-help]
[-force]

Performs timing constraint signoff analysis, which checks the rules in the category of CONSTRAINT_SIGNOFF.

Parameters 

-help Prints out the command usage.

-force

Forces timing constraint signoff analysis to perform.

Command Order

Use this command after design initialization (init_design).

Examples

  • The following command performs timing constraint signoff analysis:

    % read_libs cell.lib
% read_netlist -top top top.v
% read_sdc top.sdc
% init_design
% verify_timing_intent
% report_rule_check -category CONSTRAINT_SIGNOFF
