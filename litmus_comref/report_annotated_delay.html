report_annotated_delay

report_annotated_delay
[-help]
[-ignore_tied_net_arcs] 
[-list_annotated]
[-list_non_annotated]
[-view viewName]
[-max_line number]
[{> | >>} filename[.gz] | -tcl_list]
[pin_port_list]

Reports coverage of annotations on a design. These annotations include SDF delay arc annotations. Besides SDF annotations, the command also reports annotations that are set using the set_annotated_delay command.

Parameters


-help Outputs a brief description that includes type and default information for each report_annotated_delay parameter. For a detailed description of the command and all of its parameters, use the man command: man report_annotated_delay.

> | >> filename

When specified with >, writes the report to the specified file name. If the file already exists, the software overwrites it.

When specified with >>, writes the report to the specified file name. If the file already exists, the software concatenates the report to the end of the file.

The filename parameter must be the last argument in the list. The filename and -tcl_list parameters are mutually exclusive; you cannot specify them together.

Note: To write a compressed report, add the .gz extension to the file name.

Default: Report is displayed on standard output without being saved.

-ignore_tied_net_arcs

Ignores timing arcs of power and ground nets.

-list_annotated

Lists detailed annotation information for the following annotated arcs:

  • annotated internal net arcs
  • annotated input port arcs
  • annotated output port arcs
  • annotated cell arcs

-list_non_annotated

Lists the arc information for the non-annotated arcs corresponding to the following types of arcs:

  • non-annotated internal net arcs
  • non-annotated input port arcs
  • non-annotated output port arcs
  • non-annotated cell arcs

-max_line number

Controls the number of output lines reported by -list_annotated or -list_non_annotated parameter.

pin_port_list

Specifies the pin/port list for which annotated delay is to be reported.

-tcl_list

Produces the report in Tcl list format instead of a tabular format. This is useful for integrating timing with custom Tcl functions, and also for customizing report generation.

The -tcl_list and filename parameters are mutually exclusive; you cannot specify them together.

-view viewName

Generates the report for the specified analysis view only. You can specify this parameter only when the software is in multi-mode multi-corner timing analysis mode.

Examples

  • The following command reports the status of annotation for cell arcs, internal net arcs, net arcs from primary inputs, and net arcs to primary outputs, and all the timing arcs separately. 
    litmus > report_annotated_delay  -view scan_slow_RCMIN  -list_annotated  -ignore_tied_net_arcs
