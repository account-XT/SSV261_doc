add_group


add_group
[-help] 
-group {pg_pin operating_conditions}
-group_name <string> 
-parent_group {cell library}

Adds liberty groups to the ETM/ PTM library.

Parameters

-help

Prints out the command usage.

-group {pg_pin operating_conditions}

Specifies the group that needs to be added.

-group_name <string>

Specifies the name of the group for which attribute needs to be added.

-parent_group {cell library}

Specifies the parent group for which the group needs to be added.

Examples

  • The following command is used to add group named pin_group_1 specified with group pg_pin:
    add_group -group pg_pin -parent_group cell -group_name pin_group_1

add_mode_definition


add_mode_definition

-mode_value <string>

Parameters

-help

Prints out the command usage.

-mode_value <string>

Specifies the names of the mode values.

-name <string>

Specifies the name of the group for which mode values are to be set.
