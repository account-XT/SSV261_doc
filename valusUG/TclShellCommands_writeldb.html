write_ldb


write_ldb
[-help]
-library string
[-opt_level integer]
-outfile string

Converts a text library to the Cadence binary format library called the library database (LDB).

Parameters

-help

Prints out the command usage.

-library string

Specifies the library to be converted to the LDB format.

-opt_level integer

Specifies the optimization level for the library database size. You can set this parameter to 0 or 1.

When set to 0, the library database is not optimized.

When set to 1, the software reduces the size of the LDB files by excluding the dotlib content, but limits their usage across other tools, such as Conformal.

Default: 0

-outfile string

Specifies the output LDB file.

Examples

  • The following command will convert the specified library to LDB format:
    valus> write_ldb -library A.lib -outfile A.ldb
