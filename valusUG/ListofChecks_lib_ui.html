LIB_UI

The LIB_UI checks are performed during the validation of various parameters of a library.

LIB_UI
Message Prefix ID Message Severity Description

VALUS

1042

Invalid message ID '%s'. Specify only one message ID at a time. For example, '%s VALUS-1005

Error

This message is issued when incorrect or more than one message id is specified in detail help.

VALUS

1043

write_lib will not write out '%s' library as there are no modifications done.

Error

This message is issued when the library is not modified and user is trying to write library using command write_lib.

VALUS

1044

The input library '%s' is not in the correct format to modify. The LDB or encrypted libraries are not supported.

Error

This message is issued when the library cannot be modified due to its format. The LDB or encrypted libraries are not supported. To fix the issue, specify the library in correct format.

VALUS

1045

The input library '%s' is not an ETM/PTM library. The library other than ETM/PTM are not allowed to modify.

Error

This message is issued when the library cannot be modified as it is not an ETM/PTM library. The library other than ETM/PTM are not allowed to modify. To fix the issue, specify the correct library.

VALUS

1047

Invalid name '%s' specified with '%s' option.

Error

This message is issued when the name of library/cell/pin/timing_arc/pg_pin specified is invalid. For example, the library name specified may not match the name of the library being updated. To fix the issue, specify the correct name. This message is also issued when pin name specified in format fromPin_toPinwhen group_name is timing_arc, does not exists in library or when the pin/pg_pin name specified is not present in the library.

VALUS

1048

Attribute will be %s in all occurrence of group '%s' specified with option '-group' with command '%s'. Specify name of pin in option '-name' to add the group for specific pin.

Warning

The attribute specified in command 'add_attribute/delete_attribute' will be added to or deleted from all occurrence of group defined with option '-group'. Specify the name of pin in option '-name' to add/delete the group for specific pin.

VALUS

1049

Invalid value '%s' for '-value' option.

Error

The message is issue when the value specified for '-value' option of 'add_attribute' or 'add_power_info' command

VALUS

1050

The ETM library '%s' consists more than one cell. Rerun the command with correct ETM library.

Error

This message is issued when the ETM library cannot be modified as it is having more than one cell. ETM library can have only one cell. To fix the issue, specify the correct library.

VALUS

1051

The %s '%s' specified for option '%s' with command '%s' does not exist in library and is not valid.

Error

This message is issued when incorrect pin name or pin name with improper format is passed to '-to' or '-from' or '-ref' option of 'add_timing_info' or 'add_power_info' or 'add_noise_info' or 'add_attribute' or 'copy_attribute' command

VALUS

1052

Command '%s' cannot be executed as no library is read in the session.

Error

This message is issued when no library is read in the current session. To fix the issue, read the library which needs to be modified using command 'read_libs'.

VALUS

1053

Command 'update_library' is mandatory in case multiple libraries are read in the session to specify which library needs to be modified.

Error

This message is issued when multiple libraries are read in the current session and update_library command is not specified. To fix the issue, run update_libary command and specify the library name which needs to be modified.

VALUS

1054

Options '%s' and '%s' are mutually exclusive for command '%s

'Error

This message is issued to notify that options '-rise_transition -fall_transition -cell_rise -cell_fall' and '-rise_constraint -fall_constraint' are mutually exclusive for command 'add_timing_info'. The options '-ref' and '-from' are mutually exclusive for command 'add_noise_info'. The options '-ref' and '-propagated_noise_*' are mutually exclusive for command 'add_noise_info'.

VALUS

1055

The attribute '%s' defined on pin '%s' which is %s pin. The attribute '%s' cannot be added on this pin.

Error

This message is issued when the attribute is specified on incorrect pin. The correct pin type for the attributes are: max_transition can be defined on input or output pin but not on an internal pin, min_pulse_width_low/min_pulse_width_high can be defined on input/internal pin, min_period can be defined on clock pin, max_capacitance can be defined on output or inout pin but not on an internal pin and capacitance can be defined on input, output, inout, or internal pin. To fix the issue, specify the attribute correctly.

VALUS

1056

The '%s' is already present for '%s' and would be over-written.

Warning

This message is issued when attribute to be added/copied with command add_attribute/copy_attribute is already present and would be over-written.

VALUS

1058

'%s' pin specified for option '%s' is invalid for '%s' arc. The correct pin type for option '%s' is '%s'.

Error

The correct pin type for combinational/trigger arcs is output/bidi pin and for constraint arcs is input pin or inout pin.

VALUS

1059

None of the valid attributes i.e. '%s', have been specified with timing type '%s'.

Error

This message is issued when the none of the valid attributes are not given with the specified timing_type.

VALUS

1060

Mode definition specified with command option '%s -mode' does not exist in the library. Specify valid mode condition.

Error

This message is issued when mode definition specified with command 'add_timing_info/add_power_info -mode' is not present in the library. Mode definition already deinfed in library can be specified with this option.

VALUS

1062

The '%s' is specified for incorrect group '%s' with command add_attribute.

Error

This message is issued when the attribute is specified for incorrect group with command add_attribute. The valid attributes for group 'pin' are minimum_pulse_width_low, minimum_pulse_width_high, min_period, max_transition, max_capacitance and capacitance and for groups 'cell' is 'cell_leakage_power'. To fix the issue, specify the correct group name.

VALUS

1064

The attribute '%s' is already present on '%s' and would be over-written.

Warning

This message is issued when attribute to be added/copied with command add_attribute/copy_attribute is already present and would be over-written.

VALUS

1065

The group '%s' cannot be specified with command '%s'.

Error

This message is issued when incorrect group is specified for the given command. Valid groups for command 'add_attribute/delete_attribute': library, cell, pin and timing_arc, for command 'copy_attribute' : pin and timing_arc.

VALUS

1066

The attribute '%s' with '%s' group has not been specified using the 'define_attribute' command and thus, cannot be copied/added/deleted.

Error

This message is issued when an attribute is not defined by the user, is attempted to be copied/added/deleted, using the copy_attribute/add_attribute/delete_attribute command. To fix this issue, attribute should be predefined before adding/copying.

VALUS

1067

The '%s' attribute with '%s' group is already defined using 'define_attribute' command.

Error

This message is issued when the attribute with same group_name is already defined using define_attribute command. For example, attribute is defined as 'define_attribute -name abc -group pin -type int' thus cannot be reefined as 'define_attribute -name abc -group pin -type float'.

VALUS

1068

The attribute '%s' specified with command 'delete_attributue' to delete is not present in the library.

Error

This message is issued when the attributes defined with command 'delete_attributue' to delete is not present in the library.

VALUS

1069

'%s' is the valid and mandatory attribute for power_arcs, to be specified on '%s' pin.

Error

This message is issued when a power arc is being added on an output/inout pin without a related pin.

VALUS

1070

The option '-name' is mandatory in case of adding/deleting attributes on %s group.

Error

This message is issued when an attribute is added/deleted using add_attribute/delete_attribute command on timings arcs/operating_conditions/generated_clock/pg_pin groups without specifying the corresponding pin/group using -name option.

VALUS

1071

The pin names specified with '-to' and '-from' option differ, in the command '%s'. These must be the same for arc with timing_type '%s'.

Error

This message is issued, when different pin names are specified with '-to' and '-from' option with command add_timing_info. These must be the same for arcs with timing_type 'minimum_period' and 'min_pulse_width'.

VALUS

1072

The attribute name '%s' specified to be copied using 'copy_attribute' command, does not exist on the reference pin '%s' specified with the option '-reference'.

Error

This message is issued, when the attribute to be copied is not present on the reference pin specified with the option '-reference' while using 'copy_attribute' command.

VALUS

1073

The attribute '%s' cannot be %s, as no timing arc exists from pin '%s' to pin '%s'.

Error

This message is issued, when the attribute cannot be added/deleted as the timing arc between the from and to pins specified, does not exist.

VALUS

1074

The attribute '%s' is not supported with '%s' power arcs.

Error

This message is issued, when the attribute cannot be added with the power arc type specified with the command 'add_power_info'.

VALUS

1075

The '%s' power arc can not be added at the '%s' level.

Error

This message is issued, when a power group is added at an incorrect level. 'internal_power' can only be added at pin level and 'leakage_power' can only be added at cell level.

VALUS

1076

The option '%s' is mandatory while adding an internal power arc.

Error

This message is issued, when an internal power group is added without specifying the to pin through '-to' option, using command 'add_power_info'.

VALUS

1077

The attribute '%s' is specified with negative value with command option 'add_attribute -value'.

Error

This message is issued when the value specified for attribute with command option add_attribute -value option is negative. Attributes area, default_max_transition, default_max_capacitance and fanout_load cannot have negative value.

VALUS

1078

The value '%s' provided with '%s' option of command '%s' is invalid.

Error

This message is issued when the value specified with '-name' option of command add_attribute/delete_attribute is invalid. The value to be provided with this option should be in the syntax 'toPin_fromPin'.

VALUS

1079

The voltage_map for voltage_name '%s' does not exist in the library '%s', thus cannot be added.

Error

This message is issued when the voltage_name specified with '-value' option of command add_attribute is invalid. The voltage_name provided should have a corresponding voltage_map in the library.

VALUS

1080

The attribute '%s' is not valid attribute for internal power on '%s' pin. Remove the option and rerun the 'add_power_info' command.

Error

This message is issued when the option 'related_pin' is specified while adding an internal power arc on an 'input' pin, which is not valid. This option should be removed and command can be rerun.

VALUS

1081

Can not add 'default_operating_condition' attribute to library as the operating condition '%s' does not exist in library '%s'.

Error

This message is issued when the undefined operating_condition is specified with '-value' option of command add_attribute is invalid. The operating condition should exist in the library for it to make default_operating_condition.

VALUS

1082

Arguments given to 'voltage_map' in 'add_attribute' command must be exactly two, having string name and its float value, thus '%s' given with '-value' option is invalid and cannot be added.

Error

This message is issued when the voltage_map specified with '-value' option of command add_attribute is invalid. The voltage_map must have exactly two arguments.

VALUS

1083

The '%s' group is specified for incorrect parent group '%s' with command add_group.

Error

This message is issued when group is specified for incorrect parent group with command add_group. The valid groups for parent group 'cell' are 'pg_pin' and 'generated_clock' and for parent group 'library' is 'operating_conditions'. To fix the issue, specify the correct parent group name.

VALUS

1084

The '%s' name specified with group '%s' already exists and cannot be added.

Error

This message is issued when the name specified for group already exists in the library. The group name specified should be unique.

VALUS

1085

Command option '%s' is specified but its corresponding option '%s' is missing. Height and width tables for a particular region (low, high, below_low, above_high) must be specified in pairs.

Error

This message is issued if propagated_noise_width_low/high is defined but its corresponding propagated_noise_height_low/high command option is missing.

VALUS

1086

The library '%s' specified for option '%s' with command '%s' does not exist.

Error

This message is issued if the library specified by user does not exist.

VALUS

1087

The library specified for option '%s' with command '%s' does not have CCSN data to be copied.

Error

This message is issued if the library specified by user does not have CCSN data to be copied. This can be triggered under any of two scenarios. (1) While copying default CCSN data from pin/arc level and CCSN data is not available on ref_pin. (2) While copying CCSN data from pin/arc level with when_condition specified with the command and CCSN data is not available for that specified when_condition.

VALUS

1088

Pin '%s' specified with command option '%s' is invalid. The valid pin type is '%s'.

Error

This message is issued when 'ref_pin/to_pin' is not 'input/inout' pin while adding ccsn_first_stage data or 'to_pin/from_pin' is not 'output/inout' while adding noise attributes at arc level.

VALUS

1089

Mode definition name '%s' specified with command option 'add_mode_definition' already exists. Only unique mode_definition can be added.

Error

This message is issued when the 'mode_definition' name specified by the user with command 'add_mode_definition', already exists on the ETM/PTM cell. Only unique mde_definition can be added.

VALUS

1090

Table '%s' defined with command option 'add_power_info' but table(s) '%s' are not defined. Arc cannot be added. Both tables 'rise_power' and 'fall_power' are mandatory if any one is specified.

Error

This message is issued when all the required tables are not defined while adding the arc using command 'add_power_info'. For example if rise_power is specified, then fall_power must also be specified, and if fall_power is specified, then rise_power must also be specified.

VALUS

1091

The option '%s' cannot be used with command 'add_timing_info' for type '%s'.

Error

This message is issued, when min_delay_arc value is set with command 'add_timing_info' on arcs other than combinational and rising edge/falling edge. This option can be used with combinational delay arcs and rising edge/falling edge only.

VALUS

1092

Either the option 'power' or both 'rise_power' and 'fall_power' must be specified while using the command 'add_power_info'.

Error

This message is issued, when none of power, rise_power or fall_power value is specified with command 'add_power_info'. Either the option 'power' or both 'rise_power' and 'fall_power' must be specified while using the command 'add_power_info'.

VALUS

1093

The ccsn_first_stage group with the specified when_condition could not be found, while using command 'add_noise_info'.

Error

This message is issued, when the ccsn_first_stage to be copied from a reference library, cannot be found with the specified when_condition, while using command 'add_noise_info'. To avoid this issue, the correct when condition needs to be specified.

VALUS

1094

The options 'to_pin' and 'from_pin' are mandatory while adding propagated noise data to a pin. The options 'to_pin' and 'ref_pin' are mandatory when copying ccsn_first_stage group to a pin from a reference library pin and the option 'to_ref_pin' is also mandatory when copying ccsn_first_stage group to a pin from a reference library arc, while using command 'add_noise_info'.

Error

This message is issued, when an incorrect combination of options is specified while using command 'add_noise_info'. The options 'to_pin' and 'from_pin' are mandatory while adding propagated noise data to a pin The options 'to_pin' and 'ref_pin' are mandatory when copying ccsn_first_stage group to a pin from a reference library pin and the option 'to_ref_pin' is also mandatory when copying ccsn_first_stage group to a pin from a reference library arc.

VALUS

1095

The option 'input_ccb' is only valid with options '-ref_pin' and '-to_pin'.

Error

This message is issued, when an incorrect combination of options is specified while using command 'add_noise_info'. The options 'to_pin' and 'ref_pin' are mandatory and valid while copying input_ccb group to a pin from a reference library pin.
