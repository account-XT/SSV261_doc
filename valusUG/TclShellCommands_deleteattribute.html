delete_attribute


delete_attribute
[-help] 
-attribute_name <string>
-group {timing_arc pin cell library pg_pin}
[-name <string>]

Deletes an existing user-defined attribute from the ETM/ PTM library.

Parameters

-help

Prints out the command usage.

-attribute_name <string>

Specifies the attribute name needs to be deleted.

-group {timing_arc pin cell library pg_pin}

Specifies the group name for which attribute needs to be deleted.

-name <string>

Specifies the name of library pin name for which attribute needs to be deleted.

Examples

  • The following command deletes the max_transition attribute from pin b to pin a
    delete_attribute -attribute_name max_transition -group pin -name b
