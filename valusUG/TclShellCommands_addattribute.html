add_attribute


add_attribute
[-help] 
-attribute_name <string>
-group_name {timing_arc pin cell library pg_pin operating_conditions generated_clock}
[-name <string>] 
-value <string>

Adds the liberty attribute to the ETM/ PTM library.

The supported attributes are:

  • Library level:
    • default_max_fanout
    • default_max_transition
    • voltage_map
    • operating_conditions
    • default_operating_conditions
  • Cell level:
    • duty_cycle
    • area
    • pad_cell
    • pg_pin attributes
    • pg_pin group
  • Pin level:
    • related_power_pin
    • fanout_load
    • related_ground_pin
    • prefer_tied
    • power_down_function
    • is_analog
    • minimum_pulse_width_low
    • minimum_pulse_width_high
    • min_period
    • max_transition
    • max_capacitance
    • capacitance
  • Operating condition group attributes:
    • process
    • temperature
    • voltage
    • tree_type

Parameters

-help

Prints out the command usage.

-attribute_name <string>

Specifies the attribute name that needs to be added.

-group_name {timing_arc pin cell library pg_pin operating_conditions generated_clock}

Specifies the group name for which attribute needs to be added.

-name <string>

Specifies the name of library, cell or pin for which attribute needs to be added. In case of timing arc, the convention to be followed is toPin_fromPin.

-value <string>

Specifies the attribute value to be added.

Examples

  • The following command adds attribute "cell_leakage_power" on cell level with the value 2.2:
    add_attribute -attribute_name cell_leakage_power -value 2.2 -group_name cell
