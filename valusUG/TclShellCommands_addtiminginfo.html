add_timing_info 


add_timing_info
[-help] 
[-cell_fall <float>] 
[-cell_rise <float>]
[-fall_constraint <float>] 
[-fall_transition <float>]
-from <string> 
[-label <string>] 
[-min_delay_arc]
[-mode <string>] 
[-rise_constraint <float>]
[-rise_transition <float>] 
[-sdf_cond <string>]
[-sdf_edge {noedge start_edge end_edge both_edges}]
[-timing_sense {positive_unate negative_unate non_unate}]
-timing_type {{<Timing type of Arc >}
-to <string> 
[-when <string>]

Adds timing data in ETM/ PTM library.

Parameters

-help

Prints out the command usage.

-cell_fall <float>

Specifies the delay value for fall.

-cell_rise <float>

Specifies the delay value for rise.

-fall_constraint <float>

Specifies fall_constraint value for constraint arcs.

-fall_transition <float>

Specifies the transition value for fall.

-from <string>

Specifies the 'from' pin name for which timing arc needs to be added.

-label <string>

Specifies the name of the timing group to identify the timing arc.

-min_delay_arc

Specifies the min_delay_arc value for the combinational/ rising_edge/ falling_edge arc.

-mode <string>

Specifies the name of mode for which timing arc needs to be added.

-rise_constraint <float>

Specifies rise_constraint value for constraint arcs.

-rise_transition <float>

Specifies the transition value for rise.

-sdf_cond <string>

Specifies sdf condition for the corresponding timing arc.

-sdf_edge {noedge start_edge end_edge both_edges}

Specifies the edge-specific information for both the start pins and the end pins.

Default: noedge

-timing_sense {positive_unate negative_unate non_unate}

Specifies the unateness of the pin.

-timing_type <string>

Specifies the type of timing arc.

Default: combinational

-to <string>

Specifies the 'to' pin name for which timing arc needs to be added.

-when <string>

Specifies the condition to enable the corresponding timing arc.

The following attributes are supported by the -timing_type parameter:

{combinational combinational_rise combinational_fall three_state_disable three_state_disable_rise three_state_disable_fall three_state_enable three_state_enable_rise three_state_enable_fall rising_edge falling_edge preset clear hold_rising hold_falling setup_rising setup_falling recovery_rising recovery_falling skew_rising skew_falling removal_rising removal_falling min_pulse_width minimum_period non_seq_setup_rising non_seq_setup_falling non_seq_hold_rising non_seq_hold_falling nochange_high_high nochange_high_low nochange_low_high nochange_low_low}

Examples

  • The following command can be used to add timing information on w pin having related_pin y with specified delay/transition values:
    add_timing_info -from y -to w -cell_rise 4.4 -cell_fall 2.2 -rise_transition 1.6 -fall_transition 7 -timing_sense positive_unate -timing_type combinational
