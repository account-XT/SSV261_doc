report_summary


report_summary
[-help] 
[-cumulative]
[-file <string>] 
[-severity <string>]
[-sort {CATEGORY | SEVERITY | COUNT}]]

Generates a summary report of all the messages displayed during a session for the specified library.

Parameters

-help

Prints out the command usage.

-cumulative

Generates a cumulative message summary.

-file string

Specifies a timing library file name for which the message summary is to be generated.

-severity string

Specifies the severity list for which a message summary is to be generated.

-sort [CATEGORY | SEVERITY | COUNT]

Sorts the report summary on the basis of the specified option. You can specify one of the following options:

  • CATEGORY: The messages are categorized on the basis of groups, such as, LIB_TIMING, LIB_NOISE, LIB_POWER, etc, that are defined in the liberty.
  • SEVERITY: The messages are sorted on the basis of the severity level - Error, Warning, or Information.
  • COUNT: Shows the number of occurrences of a message. The message count is displayed in ascending order.

Examples

  • The following command generates a cumulative report summary:
    valus> report_summary -cumulative
    -----------------------------------------------------------
    *** Message summary for timing library test.lib :-
    -----------------------------------------------------------
    Severity ID Count Category Summary
    ERROR TECHLIB-1213 1 LIB_TIMING For '%s' timing group de ...
    ERROR TECHLIB-1223 2 LIB_SEMANTIC The attribute '%s' on li ...
    WARNING TECHLIB-9161 1 LIB_SEMANTIC Empty Group encountered; ...
  • The following command generates a report summary of the specified file.
    valus> report_summary -file test.lib
    -----------------------------------------------------------
    *** Message summary for timing library test.lib :-
    -----------------------------------------------------------
    Severity ID Count Category Summary
    ERROR TECHLIB-1213 1 LIB_TIMING For '%s' timing group de ...
    ERROR TECHLIB-1223 2 LIB_SEMANTIC The attribute '%s' on li ...
    WARNING TECHLIB-9161 1 LIB_SEMANTIC Empty Group encountered..
  • The following command generates a report summary according to the severity level, that is, error.
    valus> report_summary -severity error
    -----------------------------------------------------------
    *** Message summary for timing library test.lib :-
    -----------------------------------------------------------
    Severity ID Count Category Summary
    ERROR TECHLIB-1213 1 LIB_TIMING For '%s' timing group de ...
    ERROR TECHLIB-1223 2 LIB_SEMANTIC The attribute '%s' on li ...
  • The following command generates a sorted report summary based on the message count.
    valus> report_summary -sort count
    -----------------------------------------------------------
    *** Message summary for timing library test.lib :-
    -----------------------------------------------------------
    Severity ID Count Category Summary
    WARNING TECHLIB-9161 1 LIB_SEMANTIC Empty Group encountered;
    ERROR TECHLIB-1213 1 LIB_TIMING For '%s' timing group de ...
    ERROR TECHLIB-1223 2 LIB_SEMANTIC The attribute '%s' on li ...
