update_library


update_library 
[-help] 
<lib_name>

Specifies the ETM/PTM library to be modified when 2 or more libraries are read in a single session.

Parameters

-help

Prints out the command usage

<libName>

Specifies the name of the library to be updated.

Examples

The following command specifies that library the "test2.lib" needs to modified, when 3 libraries are read. 

read_libs test1.lib test2.lib test3.lib > read
update_library test2.lib
This command is mandatory when multiple libraries are read.
