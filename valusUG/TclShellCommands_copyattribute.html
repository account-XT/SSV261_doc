copy_attribute


copy_attribute
[-help] 
-attribute_name <string>
-group {pin}
-reference <string>
-target <string>

Copies the value from one attribute to another in an ETM/ PTM library. This command works for the user-defined attributes only.

Parameters

-help

Prints out the command usage

-attribute_name <string>

Specifies the attribute name needs to be added.  

-group {pin}

Specifies the group name for which attribute needs to be added.     Note: the -group argument accepts pin only.    

-reference <string>

Specifies where should the attribute be copied from  

-target <string>

Specifies where should the attribute be copied to.  

Examples

  • The following command copies the max_transition attribute from pin a to pin b
    copy_attribute -attribute_name max_transition -group pin -reference a -target b
