define_attribute


define_attribute
[-help] 
-group {library cell pin timing_arc}
-name <string> 
-type {string integer float boolean}

Adds user-defined attribute to the ETM/ PTM library. You can use the add_attribute command after defining attributes using this command.

Parameters

-help

Prints out the command usage.

-group {library cell pin timing_arc}

Specifies the group where attribute should be defined.

-name <string>

Specifies the name for the attribute.

-type {string integer float boolean}

Specifies the type of attribute should be defined.

Examples

  • The following commands are used to first define an attribute with name "sampleAttribute" on cell level and then adding it by using add_attribute under the same group_name.
    define_attribute -name sampleAttribute -group cell -type string 
    add_attribute -attribute_name sampleAttribute -value true -group_name cell
