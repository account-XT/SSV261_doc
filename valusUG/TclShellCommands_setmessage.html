set_message


set_message
[-help]
[-id list_of_msgIDs] 
[-severity {warn | error | info} | -limit number | -no_limit | -suppress | -unsuppress]

Controls the type of messages to be displayed. You can specify message severity levels as - information, warning, or error.

Parameters

-help

Prints out the command usage.

-id list_of_msgIDs

Specifies the list of msg IDs to be processed.

-limit number

Sets the message limit for the selected messages. The limit must be greater than zero.

-no_limit

Removes any existing limit on the selected messages.

The suppressed messages will not be un-suppressed.

-severity {warn | error | info}

Specifies the new severity level for the message ID being modified.

-suppress

Suppresses the message.

-unsuppress

Unsuppresses the message.

Examples

  • The following command sets the limit of TECHLIB-436 to 1:
    valus> set_message -id TECHLIB-436 -limit 1
  • The following command removes any existing limit set for the message TECHLIB-436:
    valus> set_message -id TECHLIB-436 -no_limit
  • The following command changes the severity of TECHLIB-436 to error:
    valus> set_message -id TECHLIB-436 -severity error
  • The following command suppresses the TECHLIB-436:
    valus> set_message -id TECHLIB-436 –suppress
  • The following command unsuppresses the TECHLIB-436:
    valus> set_message -id TECHLIB-436 –unsuppress
