add_power_info


add_power_info 
[-help] 
[-fall_power <string>] 
-group_name {cell pin}
[-mode <string>] 
[-power <string>]
-power_type {internal leakage} 
[-related_pg_pin <string>]
[-related_pin <string>] 
[-rise_power <string>]
[-to <string>] 
[-when <string>]

Adds the power data in ETM/ PTM library.

The supported power types are:

  • Internal power
  • Leakage_power

Parameters

-help

Prints out the command usage.

-fall_power <string>

Specifies the value of fall_power.

-group_name {cell pin}

Specifies the level where the power arc is to be added  

-mode <string>

Specifies the name of mode for which the leakage power arc needs to be added.

-power <string>

Specifies the attribute value.

-power_type {internal leakage}

Specifies the internal_power or leakage_power to be added.

-related_pg_pin <string>

Specifies the 'related_pg_pin' name for the internal/leakage power arc.

-related_pin <string>

Specifies the 'related_pin' name for the internal power arc.

-rise_power <string>

Specifies the value of rise_power.

-to <string>

Specifies the 'to' pin name for which internal power arc needs to be added.

-when <string>

Specifies the 'when' condition for the leakage power arc.

Examples

  • The following command adds internal power with value 2.4 to pin x:
    add_power_info -power_type internal -power 2.4 -group_name pin -to x
  • The following command adds leakage power with value 1.2 with a specified when condition at cell level:
    add_power_info -power_type leakage -value 1.2 -related_pg_pin VDD -group_name cell -when !IN1
