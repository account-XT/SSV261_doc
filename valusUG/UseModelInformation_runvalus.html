Valus User Guide
Product Version 26.10, May 2026

How to Run Valus

To open the Valus console window, type valus in the UNIX window (shell tool, xterm). When a session is active, the Valus console displays the following prompt:

valus>

To read the timing libraries (.lib), the following command is used:

valus> read_libs lib

Examples

  • The following example shows a script to import a single .lib file:
     ############# Script 1 : "read_lib.tcl" #########################
     set $rootDir <path of root directory>
     read_libs $rootDir/test.lib
     report_summary
     #################################################################
  • The following example shows a script to import multiple .lib file:
     ############# Script 2 : "read_libs.tcl" #########################
     set $rootDir <path of root directory> 
     read_libs {$rootDir/test.lib $rootDir/test1.lib $rootDir/test2.lib}
     report_summary
     #################################################################

Handling TCL Files

The following command executes the tcl file during startup:

valus -file read_lib.tcl

Valus validates the .lib file(s) listed in the read_lib.tcl script (see Examples) and displays the checks that are performed during library validation.

If you exit the session by typing exit, the valus> prompt is no longer displayed and the prompt returns to the Unix shell.

Tab Auto-Completion of Commands

You can use the Tab key at the prompt to complete command names.

After typing the first few letters of a command name, press the Tab key. The software displays the complete command name (if the string is unique to one text command), or shows all the commands that match the text that you typed.
