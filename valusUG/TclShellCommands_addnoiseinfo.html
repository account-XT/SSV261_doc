add_noise_info


add_noise_info 
[-help] 
[-from_pin <string>] 
[-input_ccb <string>]
[-propagated_noise_height_above_high <float>]
[-propagated_noise_height_below_low <float>]
[-propagated_noise_height_high <float>]
[-propagated_noise_height_low <float>]
[-propagated_noise_width_above_high <float>]
[-propagated_noise_width_below_low <float>]
[-propagated_noise_width_high <float>]
[-propagated_noise_width_low <float>] 
[-ref_pin <string>]
[-timing_sense <string>] 
[-timing_type <string>]
-to_pin <string> 
[-to_ref_pin <string>]
[-when_condition <string>]

Adds the noise data in ETM/PTM library.

It is recommended to use the below command for disabling clipping of noise data while using the add_noise_info command:
set_valus_mode -ccs_noise_data_disable_clip

This command supports the following CCSN-first_stage attributes/groups:

  • ccsn_first_stage
  • is_inverting
  • is_needed
  • miller_cap_fall
  • miller_cap_rise
  • stage_type
  • dc_current
  • output_voltage_fall
  • output_voltage_rise
  • propagated_noise_low
  • propagated_noise_high
  • related_ccb_node

The template corresponding to each sub group will also be copied.

Parameters

-help

Prints out the command usage.

-from_pin <string>

Specifies the from pin.

-input_ccb <string>

Specifies if input_ccb is to be added.

This parameter cannot be used without the -ref_pin and -to_pin parameters.

-propagated_noise_height_above_high <float>

-propagated_noise_height_below_low <float>

-propagated_noise_height_high <float>

-propagated_noise_height_low <float>

-propagated_noise_width_above_high <float>

-propagated_noise_width_below_low <float>

-propagated_noise_width_high <float>

-propagated_noise_width_low <float>

-ref_pin <string>

Specifies the from pin.

-timing_sense <string>

Specifies the timing sense of the reference arc.

-timing_type <string>

Specifies the timing type of the reference arc.

-to_pin <string>

Specifies the to pin

-to_ref_pin <string>

Specifies the sink pin specified in the reference arc (mandatory for arc-based data).

-when_condition <string>

Specifies the when condition of the reference arc

Examples

  • The following commands add noise information to the ETM library in accordance with the specified reference CCS library and write it to a new library:
    set_valus_mode -ccs_noise_data_disable_clip
    read_lib abc.lib xyz.lib #abc.lib is ETM lib and xyz is CCS ref lib
    update_library abc.lib #specify the ETM library where noise data needs to be added
    add_noise_info -from_pin A -to_pin Y -propagated_noise_width_high 1 -propagated_noise_width_low 1
    write_lib -lib_name new.lib
  • The following commands add input_ccb group from reference CCS library xyz cell BUFX2 pin A to pin A of ETM library:
    add_noise_info -ref_pin xyz/BUFX2/A -to_pin A -input_ccb CCB_D1
    write_lib -lib_name new.lib

Here, CCB_D1 indicates that the CCB group belongs to pin D and 1 indicates that this is the first input_ccb group of pin D. The pin D can be input/inout pin only.

Important Points

  • If propagated_noise_width_low/high is defined, then its corresponding propagated_noise_height_low/high will be mandatory and vice-versa.
  • The CCSN data (input_ccb and CCSN first stage) can be defined on input/inout pin only.
  • The propagated noise data can be defined on output/ inout pin only.
