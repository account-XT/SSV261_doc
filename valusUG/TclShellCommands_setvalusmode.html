set_valus_mode


set_valus_mode
[-help]
[-capacitance_index_max float]
[-capacitance_index_min float]
[-capacitance_value_tolerance float] 
[-ccs_current_peak_tolerance float] 
[-ccs_noise_data_disable_clip] 
[-ecsm_power_peak_current float] 
[-ecsm_power_time float] 
[-merge_library_checks]
[-setup_hold_checks] 
[-slew_index_max float] 
[-slew_index_min float] 
[-slew_threshold_tolerance float]
[-slew_value_tolerance float]
[-timing_value_threshold float]
[-voltage_waveform_tolerance float

Sets parameters for running Valus.

Parameters

-help

Prints out the command usage.

-capacitance_index_max float

Specifies the upper limit of the capacitance range.

-capacitance_index_min float

Specifies the lower limit of the capacitance range.

-capacitance_value_tolerance float

Specifies the tolerances in which the capacitances values can vary from that of the pins capacitance values.

Default: 0.1

-ccs_current_peak_tolerance float

Specifies the percentage tolerance for allowing multiple peaks in the output current waveform.

Default: 0.95

-ccs_noise_data_disable_clip

Specifies whether the dc_current data clipping needs to be disabled.

-ecsm_power_peak_current float

Specifies the peak current value against which the ECSM power group current values need to be checked.

-ecsm_power_time float

Specifies the time value against which the ECSM power group time values need to be checked.

-merge_library_checks

Allows the software to performs the merge library check.

-setup_hold_checks

Enables the setup/hold checks.

-slew_index_max float

Specifies the upper limit of the slew range.

-slew_index_min float

Specifies the lower limit of the slew range.

-slew_threshold_tolerance float

Specifies the tolerances in which the sample points can vary near the slew threshold.

Default: 0.1

-slew_value_tolerance float

Specifies the tolerances in which the slew value can vary from that of the NLDM slew values.

Default: 0.1

-timing_value_threshold float

Specifies the threshold value for ignoring large timing values

Default: 100s (seconds)

-voltage_waveform_tolerance float

Specifies the tolerances for voltage waveform to start/end at 0 or 1.

Default: 0.1

Examples

  • The following command sets the minimum value to 0 and the maximum value to 10 of the capacitance index.
    valus> set_valus_mode -capacitance_index_min 0 
-capacitance_index_max 10
  • The following command sets the value of the -slew_threshold_tolerance parameter to 0.9.
    valus> set_valus_mode -slew_threshold_tolerance 0.9
