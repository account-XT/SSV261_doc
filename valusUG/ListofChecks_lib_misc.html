LIB_MISC

The LIB_MISC checks are performed during the validation of various parameters of a library. This category includes checks related to file read/write permission, incorrect command line options, invalid library format, and so on.

LIB_MISC
Message Prefix ID Message Severity Description

VALUS

40

No write permission in the directory. Check the write permission and run the tool.

Error

This message is issued when the software cannot open a file for writing. It could be the unix write permission issue.

VALUS

1032

The set_message -id string '%s' is incorrectly specified. Check the tool help for usage of command.

Error

This message is issued when command set_message is incorrectly specified. The example format is 'set_message -id TECHLIB-436 -limit 10'.

TECHLIB

246

Error encountered while reading cell '%s' in library '%s

Error

This message is issued when the error is already issued while reading a cell in library. Refer the log file for the failure reason.

TECHLIB

281

Attempt to read .lib library '%s' failed

Error

This message is issued when the error is already issued while reading a library. Refer the log file for the failure reason.

TECHLIB

622

Could not read %s. Check the file path and read permissions.

Error

This message is issued when software cannot open a file to read. It could be the Unix read permission issue.

TECHLIB

1141

Cell '%s' redefined in library. The first cell definition will be retained, rest will be ignored.

Error

Cell re-definitions in a library is not allowed. In case of multiple definitions for the same cell name, only the first definition is retained and rest are ignored. In order to retain all cell definitions, the cell names must be unique. Modify the cell definition in library by changing name of cells such that all the cells are distinct

TECHLIB

1145

Message with id '%d' not found.

Error

This message is issued when valid message id is not specified.

TECHLIB

1230

Failed to parse '%s' expression for %s group on line number %d. %s

Error

This message is issued when software encounters an error in parsing the boolean expressions like next_state/function/when/when_start/when_end/sdf_cond etc.. To rectify the issue, fix the error issued by correcting the Boolean expression definition.

TECHLIB

1242

The library format in the file '%s' is not supported by software. Check the format.

Error

The software is not able to recognize the library format of file. Liberty timing libraries or side-file files must be in either text-readable format or Cadence compiled .ldb format.

TECHLIB

1276

Cannot find timing library file '%s' specified with '%s'. Check unix permissions.

Error

This message is issued when the specified library is not found

TECHLIB

1370

Identified inconsistency between function and timing sense for timing arc on pin '%s' of cell '%s

'Error

This message is issued when the timing sense defined for timing arc is not consistent with the function of pin. For example, in case of inverter, which has function '!A' then arc should have a negative_unate timing sense. To fix the issue, re-characterize the library with appropriate settings, such that the timing_sense and function are consistent.

TECHLIB

1419

The expression '%s' specified for attribute %s for %s is invalid. %s. The attribute will be ignored.

Error

This message is issued when software encounters an error in parsing the boolean expressions like power_down_function etc.. To rectify the issue, fix the error issued by correcting the Boolean expression definition.

TECHLIB

1472

The library attribute '%s' preexists in library '%s', with a value of '%f'. Preexisting library attributes cannot be overwritten by user-level annotations. The attribute value has not been changed.

Error

This message is issued when the sigma constraint folding factor being annotated to the specified library using command 'set_socv_constraint_config', preexists in the specified library. The preexisting sigma constraint folding factors cannot be redefined, thus, attribute value will not be changed.

TECHLIB

9164

The group name is larger than %d characters. Such large names would cause problems in downstream tools. Rename the group to remove this error.

Error

The group name cannot be larger than the limit specified. The downstream tools might not be able to handle such large names. Rename the group to meet the size limit.

TECHLIB

1297

LDB generation could not complete. Refer to previously issued error messages in the session.

Warning

This message is issued when library has some serious errors which prevent LDB file generation. To fix the issue, re-characterize the library to fix the error messages issued in the session.

TECHLIB

1420

The receiver capacitance group specified for '%s' input transition is invalid for '%s' timing arc defined for %s in cell '%s'.

Warning

This message is issued when a timing arc had receiver capacitance group specified which is not invalid. The validity check is done on the basis of valid input pin transitions for the given timing group.

TECHLIB

927

Message <%s> has exceeded the message display limit of '%d'. Use 'set_message -no_limit -id list_of_msgIDs' to reset the message limit.

Info

This message is issued when the message has exceeded the message display limit which defaults to 20 and can be changed with the help of command 'set_message -no_limit -id list_of_msgIDs'. For example: set_message -id TECHLIB-436 -limit 5.
