How do I load the ESD results directory?

  1. Select ESD Results from the Power Rail menu.
  2. Click the ESD database browse button to access the ESD directory under the state directory.
  3. Click Load.

Tcl Command:

read_power_rail_results -esd_directory directory

Example:

read_power_rail_results -esd_directory ESD_domain/PD_25C_esd_1/ESD
