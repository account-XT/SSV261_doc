ESD Analysis Quick Help
Product Version 23.10, November 2023

How can I perform bump-to-bump ESD analysis using IV curve PGV models?

The current parameter must be added to the rule file when the IV curve PGV models are used to perform non-linear bump-to-bump ESD analysis. This parameter specifies the zap current value.

To perform electromigration analysis using the specified current value and report its results, you can include the em_results true parameter in the rule file.

Rule for computing bump-to-bump resistance check for IV curve PGV models

Rule b2b_rule_non_linear_all_net
type bump2bump  
nets -from all -to all -reporting both -report_threshold 0.8
setup -ahdl_include /DATA/models.va
current 1.5
em_results true
end rule
