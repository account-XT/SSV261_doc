Product Version 23.10, November 2023

Can I selectively load the Current Density (rj) result directory for ESD EM analysis?

You can use the -esd_rj (legacy)/-esd_em (Stylus) parameter of the read_power_rail_results command to load and view the current density/electromigration results generated by the ESD analysis flow. This parameter allows you to selectively load the required EM result directory if there are multiple ESD EM result directories under the ESD directory.

The following is the command syntax for the -esd_rj parameter:
read_power_rail_results -esd_rj  ESD_rj_directory_name

You must either load the rail directory before running this command, or specify the rail directory with the -esd_rj parameter.

The following is an example of specifying the rail directory and the ESD EM result directory in the Stylus mode:
read_power_rail_results -rail_directory dynamic_rail/core_25C_dynamic_1 -esd_em em_rule_all_nets_VDD_VDDvsrc1_VSS_VSSvsrc1
