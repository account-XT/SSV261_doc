ESD Analysis Quick Help
Product Version 23.10, November 2023

Which are the various design rule checks supported by the ESD analysis command?

Voltus ESD analysis supports the following rule checks:

  • bump to clamp effective resistance check - Effective resistance is computed between each bump to all ESD devices in the design, or from each ESD device to all bumps in the design (if the report method is reverse). It also supports ESD analysis from shorted bumps to each clamp.
  • bump to bump effective resistance check - Effective resistance is computed for all paths - from a power bump to an ESD device to a ground bump.  It also supports bump to bump ESD checks over a user-specified radius.
  • clamp to clamp effective resistance check - Effective resistance is computed between all clamps for each net.
  • bump to instance effective resistance check - Effective resistance is computed between every bump to instance, and will check if the resistance value is less than that of the same bump to clamp cell.
  • clamp to instance effective resistance check - Effective resistance is computed between every instance to nearest clamp. This report is important to perform CDM check.
  • isolated bump/clamp check - Checks if there are any bumps that are not protected by an ESD cell, or checks if there are any clamps that are not connected to any bumps.
  • current density/EM analysis - Checks whether current densities are not exceeding limits that cause metal melting or fusion.
