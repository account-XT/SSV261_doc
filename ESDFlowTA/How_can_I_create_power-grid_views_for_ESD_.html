How can I create power-grid views for ESD?

The PGVs are preprocessed cell library databases that contain cell geometries and parasitics required for ESD analysis. It is essential to tag the ESD cells in the PGVs because they contain cell pin information and ESD device electrical characteristics like RON/ROFF or IV curves required to perform non-linear ESD analysis.

To create PGVs for ESD cells, the following parameters of the set_advanced_pg_library_mode command are specified:

Parameter NameDescription
-esd_cells {cell_list}
-esd_cells_list_file {esd_cell_list.txt}

Specifies the list of ESD cells used in the design. 

File Format:
clamp_cell_name clamp_type #clamp type can be used to group clamps

Example of -esd_cells_list_file file:
esd_decap_vdd CLAMPIO
esd_decap_core CLAMPCORE
-esd_pin_list {pin1 pin2 ....pinN}

Specifies the list of ESD pins in the ESD cell.
-esd_parameters_file filename

Specifies the electrical characteristics of the ESD cells.

File Format:
Cell cell_name  Ron Roff power_pin ground_pin voltage
Type esd_cell_type Ron Roff power_pin ground_pin voltage

Example of -esd_parameters_file file:
Cell esd_decap_vdd 0.9 10000 vdd_esd vss_esd 0.4

Examples:

  • set_advanced_pg_library_mode -esd_cells {IOESD} -esd_pin_list {VDD TVDD}
  • set_advanced_pg_library_mode -esd_cells_list_file {esd_cell_list} -esd_parameters_file param_file.txt -esd_pin_list {VDD VSS VDDESD VSSESD}
