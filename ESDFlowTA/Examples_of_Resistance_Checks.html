Examples of Resistance Checks

Rule for computing clamp-to-clamp resistance

Rule c2c_rule1
type clamp2clamp
power -nets VDD
ground -nets VSS
clamp_types -from "CLAMPTYPE1" -to "CLAMPTYPE2“    
reff_threshold 3
end rule

Rule for computing bump-to-clamp resistance (shorted clamps)

Rule b2c_rule
type bump2clamp
clamp_cells "ESDCLAMP"
ground -nets NET1 -short_bumps false
reporting both
reff_threshold 3.5
pass_criteria all
effective_calculation true
parallel_clamp_threshold 2
end rule

Rule for computing bump-to-bump resistance (shorted bumps)

Rule rule_shorted_bump_device
type bump2bump
power -nets all -short_bumps true
ground -nets all -short_bumps true
lerp_threshold 10
skip_domains VSS0:VDD
esd_device_check true
end rule

Rule for reporting isolated bump/clamps

Rule connectivity
type connectivity
clamp_cells CLAMP_A CLAMP_B
power -nets all
ground -nets all
check_isolated_bumps true
check_isolated_clamps true
end rule
