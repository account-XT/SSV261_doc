ESD Analysis Quick Help
Product Version 23.10, November 2023

Can I run ESD analysis in the early design phase?

You can check ESD protection in the early design phase when the grid is not ESD connected. Voltus can make virtual ESD connections to the clamps.

Early Mode ESD Analysis

##Define the ERA method to be used for ESD analysis:
set_rail_analysis_config -method era_static -accuracy xd -extraction_tech_file tech.tch
##ESD command to start ESD analysis:
report_esd_network PD -config_file rule1.txt -output_dir early_ESD_analysis -type domain -use_power_pad true

Sign-off Mode ESD Analysis

##Define the rail analysis method and power-grid library to be used for ESD analysis:
set_rail_analysis_config -method static -accuracy xd -extraction_tech_file tech.tch -power_grid_libraries {techonly.cl esd_macro.cl}
##ESD command to start ESD analysis:
report_esd_network PD -config_file rule1.txt -output_dir early_ESD_analysis -type domain -use_power_pad true

For the sign-off mode ESD analysis, all ESD and BUMP cells must be tagged in the input PGV (esd_macro.cl). In the early mode ESD analysis flow, PGVs are generated internally and are not user-specified. However, if you explicitly specify a PGV for the early mode, all ESD and BUMP cells must be tagged in the PGV.
