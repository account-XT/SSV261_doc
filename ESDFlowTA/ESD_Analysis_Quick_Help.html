ESD Analysis Quick Help

The Electrostatic Discharge (ESD) analysis flow is run on IC designs to check whether every power and ground pin or bump has an ESD device, and the device is placed in such a way that it does not violate the effective resistance or current density limit. 

You can perform the following tasks to run the ESD analysis flow:

Perform ESD Analysis using the analyze_esd_network Command

The analyze_esd_network (legacy)/report_esd_network (Stylus) command performs different types of effective resistance checks and current density analysis during an ESD zap event.

Work with ESD Analysis Results using the ESD Summary Form

The ESD Summary form allows you to load and display the ESD resistance check and EM results.
