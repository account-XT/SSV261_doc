ESD Analysis Quick Help
Product Version 23.10, November 2023

What are the prerequisites for running ESD analysis in Voltus?

The following table lists the required inputs for performing ESD analysis in Voltus:

InputDescription
ESD cell PGVs

Contains cell pin information and ESD device electrical characteristics. ESD cells are tagged using the -esd_cells or -esd_cells_list_file parameter of the set_advanced_pg_library_mode command, and ESD cell pins are tagged using the -esd_pin_list parameter of the set_advanced_pg_library_mode command.
ESD Rule File

Specifies a set of rules that define all the ESD checks to be performed.
ESD EM Technology File Contains the current density check limits for each metal layer.
Technology PGV Contains the extraction technology file, area capacitance specification, decap/filler/powergate cells, and tech view for all the cells.
Design DEF Contains information about cell placement, power/ground grid, and signal routing.
Design LEF Contains the LEF technology information for a design, such as placement and routing design rules.
