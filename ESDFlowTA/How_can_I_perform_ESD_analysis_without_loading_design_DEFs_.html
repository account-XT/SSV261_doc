Product Version 23.10, November 2023

How can I perform ESD analysis without loading design DEFs?

The ESD analysis flow allows you to specify DEF files for internal processing without loading their physical data in memory. Therefore, the design DEFs are not loaded at the outset which leads to performance gain.

Legacy: Following is an example command list illustrating how to run analyze_esd_network with specify_def, including the PGV generation step:

read_lib -lef data/file.lef
set_advanced_pg_library_mode -common_supply_pins IO -esd_cells { ESD1 ESD2 } -esd_pin_list {VDD VSS VDDESD VSSESD}
set_pg_library_mode -celltype techonly  -extraction_tech_file data/qrcTechFile
generate_pg_library -output ./PGV
specify_def ./data/design.def
set_rail_analysis_mode -method static -accuracy hd \
  -power_grid_library { \./PGV/techonly.cl \}
analyze_esd_network -config_file ./esd_new_rule.txt -type domain -output ESD_analysis

Stylus: Following is an example command list illustrating how to run report_esd_network with set_power_def_files, including the PGV generation step:

read_physical -lefs data/file.lef
set_advanced_pg_library_mode -common_supply_pins IO -esd_cells { ESD1 ESD2 } -esd_pin_list {VDD VSS VDDESD VSSESD}
set_pg_library_mode -cell_type techonly -extraction_tech_file data/qrcTechFile
write_pg_library -out_dir ./PGV
set_power_def_files ./data/design.def
set_rail_analysis_config -method static -accuracy hd \
  -power_grid_libraries { \./PGV/techonly.cl \}
report_esd_network -config_file ./esd_new_rule.txt -type domain -output_dir ESD_analysis
