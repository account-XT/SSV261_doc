Release 26.10 Enhancements

The following enhancements have been made.

Added New Report Attributes

The following report attributes have been added:

  • timing_report_skip_icg_from_all_fanin_fanout_collection: When set to true, the software skips ICG clock pins from the all_fanin (or all_fanout) command collection when queried with startpoints/endpoints. By default, this global variable is set to false.
  • timing_report_enable_qpin_as_start_for_begin_end_pair: Enables reporting of multiple paths with different q-pins having the same clock pin. By default, this global variable is set to false.
  • timing_report_enable_write_twf_third_party_for_input_pins: When set to true, the software writes timing information for input pins in third-party TWF file. By default, this global variable is set to false.
  • timing_report_limit_max_path_count: Sets the maximum number of violations (of data/clock checks) to be reported.  By default, this global variable is set to 2000000 (integer).

For more details, refer to the timing Category Attributes.

report_constraint Command Enhancements 

The following report_constraint command enhancements have been made:

  • Added new parameters:
    • -drv_abs_margin: Specifies the absolute DRV margin value applied to obtain the threshold transition. 
    • -drv_ratio_margin: Specifies the ratio DRV margin value applied to obtain the threshold transition.
  • Added new -drv_fields option:

hnet: Reports hierarchical nets. When the timing_enable_hierarchical_get_nets_support attribute is set to true, the software enables support for displaying hierarchical net names. For more details, refer to the timing Category Attributes.

report_timing Collection Report Output Enhancements

The timing report Retime Analysis header has been enhanced for collection reports. When the report_timing -path_type exhaustive -collection command is used, the following tags will be printed in the report output:

  • PBA COLL: Shows a collection of paths for which retime analysis is performed while creating the collection.
  • GBA COLL:  Shows a collection of paths for which retime analysis is not performed.

When the report_timing -collection parameter is specified, the GBA and PBA slack values are not shown separately by default. 

Added New report_case_analysis Parameters

The following report_case_analysis parameters have been added:

  • -include_function: Displays the pin function of a pin. This must be specified with the -propagated parameter.
  • -include_ref_name: Displays the reference name of an instance in the report.
