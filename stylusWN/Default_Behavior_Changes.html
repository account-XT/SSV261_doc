Release 26.10 Enhancements

Timing Analysis

Timing Report Format Default Change in PBA Mode

Previous Behavior

New Behavior

Earlier, by default timing reports (report_timing command) did not display PBA column headers.

In this release, by default, the timing reports will display PBA column headers for nsigma, mean, sigma, and standard deviation details.

Impact: This default change might impact parsing of reports in some cases.
