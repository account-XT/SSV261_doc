Release 26.10 Enhancements

The following enhancements have been made.

Support for Derate-Based Advanced Multi-Input Switching (AMIS-Derate) Analysis

A simulation-based advanced multiple-input switching (AMIS-Simulation) analysis can model MIS effects on both delay and slew. As a result of modeling MIS effects on slew, enabling AMIS-simulation can be very pessimistic. Due to the detailed simulation performed for each instance, the runtime overhead can be high.

To mitigate these shortcomings, the AMIS-derate feature has been introduced. AMIS-derate pre-characterizes MIS impact on multi-input cells as delay derates for different slew/load combinations and uses these derates in timing analysis. AMIS-derate applies MIS impact only to the base delay component. AMIS-derate maintains accuracy similar to AMIS-simulation and provides better runtime, debuggability, and reporting capabilities.

  • To enable derate-based MIS, you can use the following setting:
    • set_analysis_mode -multi_input_switching_mode 3

When MIS-derate is enabled, Tempus will automatically disable AMIS-simulation.

  • To generate MIS-derate reports (in PBA mode only), the report_timing -format parameter supports the retime_mis_derate option. 

  • The get_property (and report_property) command supports the following new properties:

    For more information on AMIS-Derate, refer to "Derate-Based Advanced Multi-Input Switching (AMIS-Derate) Analysis" section in the Tempus User Guide.

Ability to Set Advanced Variation Settings

The Tempus software allows you to set up advanced variation settings. The following new command has been added:

  • set_advanced_variation_mode: Sets the advanced variation scope to configure generic effect specific settings.

Ability to Scale Via Resistance using Scaling Factor

The Tempus software allows you to scale via resistance from SPEF, which is based on the user-specified scaling factor. The following new commands have been added:

  • set_via_variation_mode
  • get_via_variation_mode

The set_via_variation_mode command allows you to specify per via sigma multiplier and handles the advanced via variation scaling.

Added New set_wire_variation_mode Command Parameters

The following set_wire_variation_mode command parameters have been added:

  • -wire_cell_variation_correlation {true | false}: Controls whether to RSS or add the random cell variation and wire variation for arrivals and slack. Default: false
  • -use_nsigma_coupling_capacitance {true | false}: Allows to use the mean+nSigma coupling capacitance. Default: false
