Release 26.10 Enhancements

The following enhancements have been made.

Added merge_noise_reports Command

The Tempus software allows you to generate merged noise reports for the specified views. The following new command has been added:

  • merge_noise_reports

Added New Command Parameters

The following new parameters have been added:

  • report_noise_propagation -style {default | extended}: Provides an enhanced report format that shows new fields - UDN and User annotated. You can specify the following options:
    • default: Prints the ROP column and VDD (in mV) in the output report.
    • extended:  Reports the drivers with annotated glitches as propagation sources.
  • set_si_mode -virtual_inter_die_attacker_slew <value>: Specifies the virtual inter-die attacker slew value. Default: 2.5e-11
  • set_si_mode -enable_advanced_flow {true | false}: Enables advanced SI analysis. Default: false
  • report_noise -merge: Generates a merged report that shows only the worst glitch slack for each pin level combination across views.
  • create_spice_deck -scale_mode string: Allows you to specify the UMC_URI scale mode option. Default: effective
