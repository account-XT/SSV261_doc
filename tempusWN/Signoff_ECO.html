Release 26.10 Enhancements

The following enhancements have been made:

set_eco_opt_mode Command Enhancements

The following new set_eco_opt_mode parameters have been added:

  • -smart_mmmc_force_keep_hold_view_list <string>: List of hold views, which have to be retained after SmartMMMC view compaction. These views represent the minimum hold views retained by the system, on top of which additional views can be retained.
  • -smart_mmmc_force_keep_setup_view_list <string>: List of setup views, which have to be retained after SmartMMMC view compaction. These views represent the minimum setup views retained by the system, on top of which additional views can be retained.
  • -high_effort_cell_list <list of cells>: Enables the controlled utilization of high-leakage or high-power cells during signoff optimization. These cells are typically classified as dont_use or dont_touch due to their power characteristics; however, they may be beneficial in specific scenarios. When this parameter is specified, ensure that the don’t_use constraint is set to false for cells included in -high_effort_cell_list. 
    • In setup timing optimization, the cells are considered only if they are essential to meet timing requirements without causing a significant increase in power consumption. 
    • In power optimization, the cells may be inserted if their usage leads to an overall decrease in power usage, such as enhancements in fanin/fanout cone.

This parameter allows treating the specified cells as high-effort resources, using them only when necessary to improve timing or power efficiency, while maintaining the broader design objective of reducing power impact.
