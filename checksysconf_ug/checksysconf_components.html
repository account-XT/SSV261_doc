CheckSysConf Components

CheckSysConf is a tool that verifies whether the machine on which you want to run the Cadence tools has the required system configuration and OS patches. This tool is available for Solaris (sun4v and sol86), HP-UX, AIX, and LINUX (32-bit and 64-bit) platforms.




CheckSysConf Components

This tool consists of three parts:

  • A script

    checkSysConf is a script that performs the checks.

  • Data files

    A group of data files that define all the parameters and patches required for a particular release of operating system. The script uses these datafiles to determine whether the machine has the required system configuration and system patches.

  • Documentation

    The documentation set consists of the user guide, a README file, and the man pages. The README file and man pages are located in your_inst_dir/doc/check_conf.




CheckSysConf Installation Hierarchy

CheckSysConf is installed in the following directory structure:
