Doc Assistant - Offline Mode

You can use Doc Assistant even when you are working in a restricted environment where you have limited or no internet connectivity. In this case, Doc Assistant is launched in Offline mode. 

In Offline mode, you can search content from documents of products that are installed on your system.

In this mode, Doc Assistant collects anonymous usage data, which helps our development team to improve the tool functionality and optimize your reading experience. This data provides insights on understanding user interaction patterns while maintaining strict privacy boundaries—excluding any personal or sensitive information from being collected. The data collection system operates under a consent-based model, where your can maintain control over your participation through privacy settings. All data collected is handled while adhering to the established organizational privacy and security guidelines and ensuring compliance with institutional policies.

When you first launch Doc Assistant in Offline mode, you will be prompted to allow anonymous tracking of your browsing data. You can modify this setting at any time through your privacy preferences.


To make Offline Documentation the default mode when Doc Assistant is launched:

  • Set the CDA_OFFLINE environment variable to true.
  • Specify the CDA_OFFLINE variable in the help.ini file on a new line.

If Doc Assistant is in Online mode, you can switch to Offline mode and set it as the default mode by switching off the View Documentation Online option from the hamburger menu.
