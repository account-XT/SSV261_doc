Sharing Content

You can share interesting and important information with other Doc Assistant users. The recipient can view the content only if they have access to the same set of product documents for the same release as you.

Offline Mode

To share content in Offline mode:

  1. Open the topic you want to share.
  2. Right-click anywhere in the topic viewer.


  3. Choose Copy link address from the shortcut menu.
  4. Send this link through any communication channel such as email or messenger.  

To access the content, the recipient must copy the link and paste it in the search box of the Doc Assistant and press Enter. 

Online Mode

To share content in Online mode, you must be logged on to the Doc Assistant. The Share button in the topic viewer page allows you to easily share the content of the current page with your contacts through email. The recipient receives a notification and can open the topic only in Doc Assistant. 

To share a topic through email:

  1. Open the topic in Doc Assistant.
  2. Click the Share button to open the Share this page form.
  3. Type the email address of the recipient. 
  4. Type a personalized message in the corresponding box.
  5. Click Share.

An email, with a link to access the topic in Doc Assistant, is sent to the specified email ID. To access the content, the recipient must copy the link and paste it in the search box of the Doc Assistant and press Enter. The recipient does not need to log on to the Doc Assistant to access the content using this method. 

When logged on the Doc Assistant, the recipient receives a notification in the Doc Assistant window.

Click the link in the message to view the shared information.

Topics for the current release are displayed in a new tab in the same Doc Assistant window. Topics from other releases are displayed in a new Doc Assistant window.
