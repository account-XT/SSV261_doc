Browse Modes in Doc Assistant

Doc Assistant provides various Browse modes to explore documentation when you prefer structured navigation instead of keyword search. These modes are useful when you want to discover content, learn a product area, or access manuals systematically.

The Doc Assistant home page includes a Browse menu on the top navigation bar that provides the following browsing modes: 

Browse All Manuals

In Browse All Manuals mode, the complete set of user guides (manuals) available for the current release is listed alphabetically. 
Use this mode when you know the name of the user manual but do not want to search for it.

There are additional doc filter options available under the following tabs:

  • By DocType: Filter by product, feature, and sub-feature
  • By Group: Filter by product, documentation group, and user manual

These filter categories can be sorted alphabetically using the A-Z button.

Browse by Product

In Browse by Products mode, all Cadence products that are available for the current release, for example, Virtuoso Layout Suite, Spectre RF, Xcelium, and AMS Designer, are listed as product tiles. 

You can select a product tile to view a list of related user manuals. The topic viewer panel displays the TOC of the first user manual. Clicking any link in the topic viewer opens the documentation on a new tab.

Use the Edit button to add more products to the Product Documentation list.

Use this mode when you are working with a specific Cadence product and need all product-focused documentation for the product in one place.

Browse by Technology

(Online mode only) Browse by Technology mode groups documentation by technical domains and workflows, for example, Analog Mixed-Signal, Digital Design Circuit Modeling, Verification, and SKILL Infrastructure. These technologies are listed as tiles, and you can click a tile to view a list of Core Concepts related to the technology. Documentation for the first core concept is displayed in the topic viewer panel.

 

Clicking any link in the topic viewer panel opens the topic on a new tab.

Use this mode to learn concepts, flows, and best practices related to a specific technology.
