Doc Assistant - Online Mode

If you are connected to the Internet and have a valid license, Doc Assistant launches in Online mode. In this mode, search results are displayed from documents that are available on the Doc Assistant cloud-based server, where the latest production documents are uploaded, and from the Cadence Application Support & Knowledge (ASK) portal.

In addition to user documentation, in Online mode, you can access several other types of documents available in the ASK portal, such as App Notes, RAKs, videos, and troubleshooting information.

If Doc Assistant is in Offline mode, you can switch to Online mode by selecting the View Documentation Online option from the hamburger menu.
