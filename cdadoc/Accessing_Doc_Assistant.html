Accessing Doc Assistant

Doc Assistant can be launched through multiple methods depending on your operating system and preferences. Choose the method that best suits your workflow - from within the Cadence tool that you are working on or from the command-line as a stand-alone interface.

Depending on your operating system, use one of the following methods to launch Doc Assistant.

  • Windows systems: 
    - Select Doc Assistant from the Start menu.
    - Use the Help menu within a product.
    - Click Help buttons on product forms.

    Doc Assistant on Windows Machines - Launching from a Network Drive

    On Windows systems, due to security reasons, Doc Assistant does not launch using network drives. To override this restriction, set the environment variable QTWEBENGINE_DISABLE_SANDBOX to 1.

  • Linux systems:
    - Type cda in the terminal and press Enter. See Launching Doc Assistant from Command Line.

When you launch Doc Assistant, a message box is displayed that lists all the products for which documents are installed on your system.
To customize this list, see My Products.


To turn off the notification, clear the Show on Startup check box in the above message box before you click OK. Alternatively, you can clear the Show Product Selection Information on Startup check box in the Doc Assistant Settings page. 

Doc Assistant launches in Online mode by default when you are connected to the internet. In this mode, all online documents related to the products installed on your system are displayed. You can switch to Offline mode using the toggle button in the hamburger menu. Offline mode displays all product documentation available in your installation hierarchy.

When you have no internet connectivity, Doc Assistant launches in Offline mode.

To make Doc Assistant the default documentation viewer for all Cadence products, set the value of the CDA_ENABLE environment variable to true. When both Cadence Help and Doc Assistant are installed, setting the environment variable to true sets Doc Assistant as the default documentation viewer. 

Use the CDA_WINDOW_SIZE environment variable to resize the Doc Assistant window. Ensure that the specified width and height values are lower than the maximum display area and higher than the Doc Assistant minimum height and width values.

Syntax: setenv CDA_WINDOW_SIZE widthxheight 

Example: setenv CDA_WINDOW_SIZE 800x1200
