How to use CSF search mechanism

Doc Assistant uses the CSF search mechanism to open documentation from custom or user-created help forms. You need to define their tag files and directory in which these files exist in the way as explained below:

  1. Create the custom help documentation html/s.
  2. Create a <My_Helpdoc>.tgf file, which contains entries for custom help documentation html/s mentioned in point 1, according to the format specified in Working with a Tag File.
  3. Ensure that the help documentation html/s and the related <My_Helpdoc>.tgf file is placed in the <My_Helpdoc> directory.
  4. Ensure that the <My_Helpdoc> directory is placed inside the doc directory, so that the directory structure looks like <ANY_PATH>/doc/<My_Helpdoc>/...
  5. You can have multiple <My_Helpdoc> like directories in the doc folder corresponding to different help forms.
  6. Create a csfLookupConfig named ASCII file that contain entries of all <MY_Helpdoc>.tgf files as shown below:
    INCLUDE <MY_Helpdoc1>.tgf
    INCLUDE <MY_Helpdoc2>.tgf
    ..
    ..
    ..
  7. In the setup.loc file located in <INST_DIR>/share/cdssetup/setup.loc, add the path where the csfLookupConfig file (created in the above point) is located. Also add the path to all the <My_Helpdoc> directories in the setup.loc file as:
    <ANY_PATH>/doc/<My_Helpdoc1>
    <ANY_PATH>/doc/<My_Helpdoc2>
    ..
    ..
  8. When you call a non-Cadence supplied <tool>:<tag> from custom help form, it should now use the CSF mechanism to find the <tool>.tgf file and then open the corresponding html entry against that <tag> entry in the <tool>.tgf file.

Alternatively, you can place such created <MY_Helpdoc> directories under the following locations for custom/user-created documentation if you do not want to use the CSF mechanism:

  • <doc_assistant_install_directory>/local/doc directory.

  • $HOME/doc directory OR %userprofile%\doc directory for Windows.
