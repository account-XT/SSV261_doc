Filtering Search Results

Use the FILTERS options on the Doc Assistant search results page to quickly narrow down and find exactly what you need. These powerful filtering tools are available on both the Product Manuals and Reference Guide tabs.

In Online mode, filters are updated dynamically based on the currently selected filter. For example, when you select any filter—such as Content Type—all other filter options, Product, Product Feature, and Document Types, automatically update to show only relevant choices. This ensures you always see the most accurate filtering options.

The selected filters are displayed at the top of the search results with a cross icon for quick removal. The number in brackets next to each filter option shows how many search results will be available if the filter is applied. You can clear any filter to return to your full search results.

Refine your search using the following content filters:

  • Content Type
  • Examples and Code
  • Product
  • Product Feature
  • Document Types
  • Category

Content Type

You can filter search results based on the content type:

  • Concept: Features, benefits, product flows, and prerequisites
  • Task: Step-by-step how-to guides and procedures
  • Reference: API documentation, environment variables, and interface descriptions (forms, dialogs, menus, toolbars)

Click Clear All to remove all the selected filters at once.

Examples and Code

Toggle this filter to show or hide documents containing code snippets and examples. The search counts may reflect multiple instances from the same document.

Product

Use this filter to narrow results to specific products, for example, Virtuoso Schematic Editor and Virtuoso Layout Suite.

Product Feature

Filters search results according to product features. For example, select Power Manager to view only Power Manager-related topics.

Document Types

Filters search results according to the type of document—User Guides, SKILL Reference, and Release Notes.

Category

This filter is available only on the Learning & Support Resources tab. You can filter content according to the content categories, such as Troubleshooting, Videos, and What's New.
