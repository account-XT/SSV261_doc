Document Releases

Doc Assistant automatically displays documentation for your current active release. When you are running a tool, Doc Assistant shows the documentation that matches your tool version by default.

To access documentation from a different release:

  1. Click the hamburger menu.
  2. Select Releases.
  3. Choose the required release version.

The Releases interface for the Online and Offline modes is displayed above. The GUI includes a table that lists the releases for which documentation is available. The table includes the following columns:

  • Release provides a list of releases. Hover over the release names to view the Copy button, which lets you copy the release location.
  • Selected Release lets you switch between releases. Current Release is the release for which documents are currently displayed in the Doc Assistant. To change the release, click Make Current for the required release. If the index of the selected release is not available, a relevant message is displayed, and indexing is triggered for that release before loading the documents.
  • Create Index is available only in Offline mode. This option lets you create a search index for the offline documents that are available in your installation directory.
  • Remove lets you delete release lists.

You can add or remove documentation releases from this list.
