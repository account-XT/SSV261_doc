Debugging Proxy Settings and Firewall Issues in Doc Assistant

When Doc Assistant fails to connect to the network, try the following procedure to troubleshoot:

  • Check your computer's network connection. 
  • If it is protected by a proxy or firewall, ensure that you are able to access the Internet. Additionally, check if the proxy settings have been correctly specified in the Proxy Server section of the Settings page.
  • If your network does not use a proxy, clear all the fields in the Proxy Server section of the Settings page
  • If you are still not able to access Doc Assistant, it could be possible that Cadence servers are not running. Try accessing after some time.
  • It could be due to the firewall settings in your environment. Contact your IT team for assistance.
