Doc Assistant Themes

The Doc Assistant supports the following themes:

  • Light: In this theme, the background is light and text appears in a darker color. This is the default theme and provides a traditional reading experience with high contrast for clear text visibility.
  • Dark: In this theme, the background is dark and text appears in a contrasting lighter color. This is an alternative theme that reduces eye strain during extended use and can help decrease power consumption on certain devices.

Use the Theme option in the Hamburger menu to toggle between the Dark and Light themes.
