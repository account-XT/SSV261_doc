Introduction to Doc Assistant

Doc Assistant is a next-generation documentation viewing tool that lets you access the latest documents available for all the Cadence products installed on your system. Doc Assistant has a web application interface through which you can search and view locally installed and online documentation.

Doc Assistant provides multiple ways to access information. Using the Search option, you can type the keywords, phrases, or natural language questions to search for relevant documentation. The Browse option allows you to explore documentation in an organized structure. The What’s New section, available in Online mode, highlights newly added and updated documentation for the current release. 

Doc Assistant Features

  • Dual access modes: Online mode provides 24x7 access to the latest documentation updates and releases, while Offline mode lets you access locally installed content even when not connected to the internet.
  • Intelligent search capabilities: Provides smart search results through semantic AI and NLP-based search capabilities that understand context and intent.
  • Smart content recommendations: Suggests related documentation, topics, and resources based on what you are currently viewing, helping you discover relevant information and explore connected concepts.
  • Flexible content views: Offers multiple viewing options and customizable display settings to match your workflow preferences and reading habits.
