Using Chatbot in Doc Assistant

Doc Assistant integrates a chatbot assistant that helps you quickly find the relevant information, clarify concepts, and get contextual answers from Cadence documentation. Instead of searching manually or navigating multiple topics, you can type your questions in natural language. The chatbot locates and summarizes the most relevant content from the documentation.

The chatbot operates exclusively in Doc Assistant Offline mode, ensuring full functionality without internet connectivity by accessing documents directly from your local installation directory.

Prerequisites

Ensure that the Cadence Joint Enterprise Data and AI (JedAI) server is running with the required embeddings at your premises. 

Accessing the Chatbot

  1. Open Doc Assistant.
  2. Click the chatbot icon  at the bottom-right corner of the window.
  3. The chatbot opens in a separate window, ready to assist you.
  4. Log in with your corporate ID and password.


  5. Specify the JedAI server URL in the format: http://localHost:portNumber/, for example, http://ind-myHost1:1234/.
  6. Select a Login provider. The default is LDAP.
  7. The chatbot opens in a new window while keeping Doc Assistant open in the original window. This allows you to generate content using the chatbot and simultaneously search and browse documentation in Doc Assistant.
  8. Select the scope from the drop-down list to set the context for your queries. The default scope matches your current installation. Available scopes correspond to specific Cadence releases (and release versions) with the embeddings stored on the JedAI server. For example, cdn_Innovus_25.10 provides access to the Cadence Innovus product documentation for release 25.1. The chatbot references documentation from both the ASK portal and user guides available on the JedAI server.
  9. Type your question in the input field and press Enter.

This tool searches the server for the relevant information and generates contextual responses to your queries, displaying them directly in the chatbot window.

Citation links used to form each response are listed below, with user guide links opening in the main Doc Assistant window and articles opening in your default browser.

What You Can Ask

Here are some sample questions you can ask the chatbot – whether it is about a concept, a procedure, reference, troubleshooting, or navigation:

  • “What is a constraint group?”
  • “How do I set up a simulation run?”
  • "List arguments for the lxChain SKILL function."
  • “How can I fix the DRC mismatch error?”
  • “Show me documentation on layout editing.”

You can type questions in natural language or use keywords.

Tips for Better Results

  • Be specific about your content request. For example, instead of "I have a question about Modgens", type "How do I create a Modgen?"
  • Ask one question at a time for clearer guidance.
  • Instead of short forms, use complete words in search prompts.
  • Ensure that the scope is correctly set.
