Displaying Search Results from Multiple Releases

In Online mode, the search results page in Doc Assistant includes a Search Multiple Releases check box that controls the scope of your search.

  • Unselected (default): Search runs only within the currently active release.
  • Checked: Search runs across all releases selected in the Releases interface.

Search results are displayed only for the products you have selected in the My Products page. You can customize this product list individually for each release.

When searching multiple releases, results are organized by release, with the current release shown first. Select a different release to display search results from that release.

Select a search result to view the topic. Topics for the current release open in a new tab within the same Doc Assistant window. Topics from other releases open in separate Doc Assistant windows. This behavior helps you easily distinguish between content from different releases while maintaining your workflow.

When you select a release, the system automatically fetches and caches data locally for faster performance. Subsequent searches for the same term will load instantly from your saved session data.
