Adding Custom Content to Doc Assistant

This topic describes how to add your custom documentation to Doc Assistant so that users can browse and search through your custom content.

Before you begin, ensure that:

  • Doc Assistant is installed on your system
  • You have the HTML documentation files ready
  • You have access to the Doc Assistant installation directory

To make your content available in Doc Assistant, you need to first organize your documents in a standard hierarchy, and then add the documentation path to Doc Assistant.

Organizing Documents in a Standard Hierarchy

To organize your documents in a standard hierarchy:

  1. Create the main document directory named doc that will serve as the root for your documentation.
  2. Under the doc directory, create separate subdirectories for different document sets. Each subdirectory must include the related HTML files.
    Example structure:
    doc/
├── manualA/
│   ├── chapter1.html
│   ├── chapter2.html
│   └── manualATOC.html
├── manualB/
│   ├── overview.html
│   ├── procedures.html
│   └── manualBTOC.html
└── doc.cfg
  3. For each subdirectory under doc:
    1. Create a TOC file.
    2. Rename the TOC file to match your directory name, for example, manualATOC.html for the manualA directory. 
    3. Add entries for all HTML files in that directory to the TOC file in the following format: 

  4. Create a configuration file named doc.cfg in the main doc directory and add the following line:
    Release=Custom Document
  5. To generate the configuration files, open a command terminal and navigate to the Doc Assistant tools directory:

    cd <install_directory>/tools

  6. Run the topic generation command: 
    cda/bin/topicgen -docset <path_to_custom_docset>/doc

Adding the Custom Document Set to Doc Assistant

After creating the standard documentation hierarchy, to add the document path to Doc Assistant:

  1. Launch Doc Assistant.
  2. Select Release—Add Release from the hamburger menu.
  3. Select your custom document set to add it to Doc Assistant.

Your custom content is now be available for browsing and searching within Doc Assistant.

  • You can create as many subdirectories under the doc directory as needed.
  • Ensure all HTML files are properly formatted and contain valid content.
  • The TOC files are essential for proper navigation within Doc Assistant.
