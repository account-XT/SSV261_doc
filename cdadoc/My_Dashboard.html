My Dashboard

The dashboard provides tools to manage the Doc Assistant settings. You can access the dashboard by selecting any option from the the hamburger icon on the menu bar.

Use the dashboard to:

  • View and manage your activity:
    • History
    • Bookmarks
    • Managing Bookmarks
  • View your user analytics
    • Focus Area
    • Content Type
  • Set doc preferences
    • Document Releases
    • My Products
    • Doc Assistant Settings
    • My Downloads
