Doc Assistant User Interface

Doc Assistant is an intelligent documentation viewer that helps you quickly find, explore, and stay updated with product documentation from a single interface. The Doc Assistant window combines search-based discovery, structured browsing, and release-specific updates.


Field/IconDescription

Home Page Icon

 Brings you back to the home page.

Search

 Lets you search for documentation in both Online and Offline modes.

Browse

 Allows you to explore documentation by categories:
- Browse All Manuals: Displays an alphabetical list of all product manuals available for the current release.
- Browse by Product: Displays a list of products available in the current release. Select a product to open a list of related documentation.
- Browse by Tech: (Online mode only) Displays a list of key technologies in the current release. Select a technology to display a list of related documentation.

What’s New

 (Online mode only) Lists the technologies or product areas that have new or enhanced features for the current release. Click a link to display the What's New document.

My Products List

Displays a list of products installed on your system. Documentation of only the selected products is displayed when you browse or search for information in Doc Assistant.

Notifications (Bell icon)

Displays alerts and updates, including errors, warnings, information, and success messages.

Network Mode /

Indicates whether Doc Assistant is in Online or Offline mode.

Hamburger Menu

Provides additional navigation and settings options to personalize Doc Assistant and perform tasks such as switching between modes and themes, viewing history and user analytics, changing settings, and closing all tabs.

Hamburger Menu Options

The hamburger menu includes the following options:

    • View Documentation Online/Offline: Switches between network modes
    • Theme: Switches between light and dark themes
    • Zoom: Controls zoom settings
    • History: Displays your browsing history
    • My Analytics: Depicts your user analytics in the form of a pie chart
    • My Downloads: Lets you manage documentation downloads
    • Releases: Lets you switch between releases
    • Settings: Lets you modify Doc Assistant settings
    • Close All Tabs: Closes all open tabs
    • Application Feedback: Lets you share your feedback about Doc Assistant
    • About Doc Assistant: Displays information about the current Doc Assistant version and release
    • Help: Opens Doc Assistant help documentation
    • FAQ: Opens the FAQ document
    • Exit: Closes Doc Assistant

Search Box

Lets you search for documentation. 

Sidebar / Shortcut Pane

Provides quick access to the bookmark and change releases options.

Submit Feedback Button

Lets you submit both positive and negative feedback about the documentation, product, or help application.

Recent Searches

Displays the last five search keywords from the current session.
