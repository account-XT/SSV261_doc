AI Search

In addition to the traditional keyword-based search, your installation can support semantic search in offline mode and Natural Language Processing (NLP)-based search in Online mode.

Semantic Search in Offline Mode

Semantic AI Search is an intelligent, query intent-based hybrid search, which includes both keyword-based and semantic-based results depending on your search query.

Use the AI Search button to toggle between the two modes.

  • Deselect AI Search to run keyword-based search (default).
  • Select AI Search to run hybrid search. In this mode, use the buttons to share your feedback about AI Search.

NLP Search in Online Mode

AI Search is an intelligent, query-intent, Natural Language Processing (NLP)-based search that provides NLP-based results depending on your search query. NLP-based search uses Generative AI to understand natural language questions and display direct, contextual answers from the documentation. Instead of keyword matching, it interprets user intent and provides summarized responses along with links to related topics.

Running NLP-based search in Online mode provides:

  • A generated answer
  • Suggested follow-up questions and supporting explanations
  • Relevant documentation links from both the current release and the ASK portal

In this mode, use the button to share your feedback about AI Search.

Use the AI Search button to toggle between the keyword-based and NLP-based search modes.
