Product Version 25.13, February 2026

Bookmarks

Doc Assistant lets you bookmark topics and save them for quick access later.

To bookmark a topic:

  1. Click the Bookmark icon on the top of the Topic Viewer. Alternatively, right-click anywhere in the topic viewer and choose Add to Bookmarks from the shortcut menu.
    The Add Bookmark dialog box is displayed. 

  2. The Title and Manual Name fields are auto-populated with the current topic information.
  3. Select a folder from the Folder drop-down list in which you want to store the bookmark.
  4. Click Save to confirm.
    The bookmark is saved.


Viewing All Bookmarks

Click Bookmarks in the dashboard to display complete bookmark collection across all releases.

When you bookmark a page, the Bookmark icon on the page automatically changes to colored, indicating that the page is already bookmarked. You cannot bookmark this page again unless you delete the bookmark.

To import Cadence Help bookmarks into Doc Assistant, refer to Importing Cadence Help History and Bookmarks.
