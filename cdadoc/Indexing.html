Indexing

Doc Assistant searches for content by matching the specified keywords against the index files that contain all searchable content from the documentation.

Doc Assistant automatically builds a search index when needed. If the index is missing or corrupted in the <installation_dir>/doc directory, Doc Assistant recreates it and sends a notification through the Notifications panel.

Platform-Specific Index Location

  • Linux Systems: If you do not have write permissions to the Doc Assistant installation directory, set the CDA_HOME_AUTOINDEX environment variable to true to create the search index in your home directory instead.
  • Windows Systems: By default, Doc Assistant creates the search index in your home directory. To force index creation in the installation directory, set the CDA_DISABLE_HOME_AUTOINDEX environment variable to true.
