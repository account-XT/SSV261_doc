View Contents of a Topic

Use the search page in Doc Assistant to search for the required product documentation. Click a search result to open the required topic.

The topic opens in a new tab that displays the following elements:

FieldDescription
Breadcrumbs 

Allow you to navigate to the lower nodes of the document. If the user guide belongs to a group (for example, SKILL LANGUAGE), the group name is also listed in the breadcrumbs. 
Switch Topic Version

Lets you select a different release and view the version of the current topic published for that release. The topic opens in a new tab.
Filter by Title

Lets you specify a keyword to filter content in the current user manual.
Table of Contents (TOC)

Provides navigation through the document structure. 
View PDF

Opens the topic contents in PDF format. The PDF opens in a new tab.
Download PDF

Lets you download a PDF of the topic contents.
Show or Hide Header

Lets you control the display of the header. Hiding the header improves the readability of content in the topic viewer.
View Content Summary

Displays a concise summary of the topic contents. Use the feedback buttons on the summary page to share your feedback on the generated content.
Recommended Content

Displays a list of topics related to the current topic.
Share

Lets you share the current topic with others.
Topic Content

Displayed on the right side of the interface.

To close a tab in the topic viewer, use the Ctrl + W bindkey. This bindkey does not work as required when there is only one tab open in the topic viewer.

Alternatively, click the Close button for the tab, or right-click anywhere in the topic viewer and choose Close Tab from the shortcut menu.

If only one tab is open, this command opens the Doc Assistant home page.
