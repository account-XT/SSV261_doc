Doc Assistant FAQs

This document contains answers to common questions you might have related to Doc Assistant. For further assistance, write to docassistant.support@cadence.com.


#

Question or Problem Statement

Solution / Workaround
1 How to launch Doc Assistant?

You can launch Doc Assistant in one of the following ways:

  • Windows systems: Run cda.exe from: 

C:\Program Files (x86)\Cadence\Doc Assistant\tools\bin\cda.exe

  • Linux systems: Type the cda command in the terminal or from <INSTALL>/bin/cda
  • Both Windows and Linux systems, after launching the Cadence tool: Product Help menu, Product Help buttons.

2

What to do when:

  • Doc Assistant is not launching
  • Doc Assistant freezes after launching

Doc Assistant might not launch in one of the following situations:

  • The firewall settings of your system might need an update to enable socket communication.
  • The communication port that is required to launch Doc Assistant is turned off. To enable it:

    1. Work with your IT team to enable a specific range of ports. For more information, see The Ephemeral Port Range.

    2. Use the CDA_WEBSERVER_PORT environment variable to define the port range to be used by Doc Assistant. For example, if your IT team has enabled port range 1024 through 65535 in your system for running Doc Assistant, use the CDA_WEBSERVER_PORT environment variable to define the port range by specifying the maximum and minimum values:
      setenv CDA_WEBSERVER_PORT <PORT_NUMBER_MIN>-<PORT_NUMBER_MAX>
      Alternatively, define a webserver port in the help.ini file:
      CDA_WEBSERVER_PORT= <PORT_NUMBER_MIN>-<PORT_NUMBER_MAX>

      In the above example, PORT_NUMBER_MIN must be higher than or equal to 1024 and       PORT_NUMBER_MAX must be less than or equal to 65535.

      Doc Assistant runs in the specified port range.
  • Check and end any help process running in the background. Relaunch Doc Assistant.

3

Doc Assistant opens in standalone mode with its default view displayed, but it does not open from the tool help. How can I fix this?

To fix the problem:

  1. Check the process table associated with your system and end any running Doc Assistant process.

  2. Launch Doc Assistant in standalone mode before launching the Cadence product you want to launch. 

  3. Check if Doc Assistant works with the tool Help options.

If the problem persists, contact your IT team to check if the communication ports are blocked on the system from which you are accessing Doc Assistant. Try launching Doc Assistant after the ports are enabled.
4 When Doc Assistant is accessed from certain Cadence tools, the tool temporarily stops responding. How can I fix this?

This might be due to access restrictions to the user temp directory. To fix this issue:

  1. Create a user directory at your home location, where you have write access, for example, /home/<USER_NAME>/CdaTempfiles in Linux and C:\Users\<USER_NAME>\CdaTempfiles in Windows.
  2. Set the PAR_GLOBAL_TEMP system environment variable to the location of the new user directory, for example, PAR_GLOBAL_TEMP /home/<USER_NAME>/CdaTempfiles.
  3. Launch Doc Assistant.
5 What to do when context-specific help topic is not displayed?

  1. Ensure you have read access to the documentation directory (INST_DIR/doc) and all the subdirectories. After getting the required permissions, launch Doc Assistant from the dialog box or tool interface from where you saw the error.

  2. If the problem persists, create a debug file that replicates the issue and send it to Cadence Customer support.

For more information, see How to debug Doc Assistant?
6 What to do when Doc Assistant license check fails?

Set the following environment variable to specify a valid licensing server:

setenv CDS_LIC_FILE serverName
7 Doc Assistant does not fetch results for an online search. How can I fix this?
  1. Check your internet connection. It should be running uninterrupted.
  2. Debug the Doc Assistant proxy and firewall settings. For more information, see How to debug proxy settings in Doc Assistant?
  3. Check the firewall settings. Your IT team should add Doc Assistant to the firewall exception list.
  4. As a temporary workaround, switch to Offline mode and search only in the local doc hierarchy. 

Also see How to debug Doc Assistant?

8

How to debug Doc Assistant?

To debug Doc Assistant, set the CDA_API_DEBUG and CDA_DEBUG environment variables.

  1. Set the value of the CDA_API_DEBUG environment variable to debug to log the Doc Assistant API debug information to the CDA_API_log.txt file in the $HOME/.config/cadence directory. In Windows systems, the file is located at: C:\Users\<username>\.config\cadence
  2. Set the value of the CDA_DEBUG environment variable to debug to log the Doc Assistant debug information to the cdaLogger.txt file in the $HOME/.config/cadence directory. In Windows systems, the file is located at: C:\Users\<username>\.config\cadence

9

How to debug proxy settings in Doc Assistant?

If Doc Assistant does not respond, debugging proxy settings could help. To do this:

  1. Check if your system is connected to the network. 
  2. If your system is protected by a proxy or a firewall, ensure that you can access the Internet. Additionally, check if the proxy settings have been correctly specified in the Proxy Server section of the Settings page.
  3. If your network does not use a proxy, clear all the fields in the Proxy Server section of the Settings page.
  4. If you are still unable to access Doc Assistant, Cadence servers may be down. Try accessing Doc Assistant after some time.
  5. After trying again, if Doc Assistant still does not respond, the firewall settings in your environment may be blocking your access. Contact your IT team for assistance.
10 Search results in Doc Assistant do not display relevant content even when the related documents exist in the documentation hierarchy. How can I fix this?

The Doc Assistant index might be outdated. Doc Assistant automatically updates the search index and displays a notification in the Notifications list.

In Offline mode, use the Create Index option in the Releases section to create a search index for the offline documents that are available in your installation directory. 
11 How to increase the font size in Doc Assistant?
  1. Click the hamburger icon on the menu bar.
  2. Choose Settings.
  3. In the Content Display Settings section, select a font style from the Font Style drop-down list.
  4. Select a size from the Font Size drop-down list. A preview is displayed in the Preview section.
  5. (Optional) Unselect Preserve Spaces and Line Break to reduce line spaces and line breaks in content pages. This provides a compact view of the content in the topic viewer.
  6. Click Save.
12 When I close the parent application, Doc Assistant also closes. Is there any setting to keep the Doc Assistant open?
  1. Click the hamburger icon on the menu bar.
  2. Choose Settings.
  3. Unselect Allow APIs to Close the Application in the Shutdown/Startup Behavior section.
13 How to view documents from another release?

Doc Assistant, by default, displays documents for the currently active release in your system. To access documents from another release:

  1. Click the hamburger icon on the menu bar.
  2. Choose Releases. 
  3. Click Make Current for the release for which you want to view documentation.

If your release is not listed, you can add the required release to the list of Releases.

To add a release:

  1. Click Add Release on the Releases page.
  2. Browse and select a document directory.
  3. Click Choose.
    The selected document directory is added to the Releases list.
14 What to do when My Downloads does not show any options?

Ensure that:

  • You are connected to the Internet and Online mode is enabled.
  • You are signed in to Doc Assistant.
  • You have write permissions to the default document directory located at: <installation_dir>/doc.
  • The current online and default offline releases are the same. To synchronize the releases, open the Releases page and locate the Default Doc release. Click Make Current to set it as the current release.
15 Videos play in Doc Assistant, but there is no audio. How can I fix this? Check if the system has a sound card.
16 What to do when search results are not displayed for the specified keywords?

Check if you have an outdated version of Doc Assistant running on your system. Upgrade to the latest version and rerun the search command.
17 Cross-functional documentation (hyperlinks) is inaccessible from Doc Assistant. How can I fix this?

Check if you have an outdated version of Doc Assistant running on your system. Upgrade to the latest version.
18 The PDF Not Found error is displayed when I try to access PDFs in Offline mode. How can I access PDFs?

The PDFs might be unavailable in the installation directory. Switch to Online mode and access the PDFs. You can download the required release documentation when in Online mode.

Alternatively, access the PDF on the Cadence Application Support & Knowledge (ASK) portal.
19 Hyperlinks do not open in a separate web browser, outside of the Doc Assistant window. Can I configure Doc Assistant to open HTTP links in an external web browser?

You can configure Doc Assistant to open HTTP links in an external web browser. To do this:

  1. Click the hamburger icon on the menu bar.
  2. Choose Settings.
  3. Select the Open Web Links in Browsers check box. This option is available only in Online mode.

In Offline mode, all HTTP links automatically open in an external browser.
