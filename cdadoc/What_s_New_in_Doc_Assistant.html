What's New in Doc Assistant

This topic highlights the key enhancements and new features introduced in Doc Assistant.


25.1 ISR3

TitleTypeDescription
Redesigned Home Page: Streamlined Interface  Major

The Doc Assistant home page has been redesigned for enhanced user experience. The streamlined interface now offers two intuitive ways to find content:

  • Search (default mode) – Quickly locate information using keyword or semantic-based searches
  • Browse – Navigate systematically through organized product and technology categories

By focusing on the key features, the new home page delivers a cleaner, more efficient interface that lets you access the information you need faster.
NLP Search Results Includes an AI-Generated Response and Follow-Up Questions  Major

Performing an NLP-based search in Online mode now uses Generative AI to understand user intent and provides direct, contextual answers from the documentation. This intelligent search feature generates summarized responses, suggests follow-up questions, and provides relevant documentation links from both the current release and the ASK portal.

25.1 ISR2

TitleTypeDescription
Using Chatbot in Doc Assistant Major

The chatbot in Doc Assistant helps you quickly find information, clarify concepts, and get contextual answers from Cadence documentation. Instead of searching manually through multiple topics, type your questions in natural language. The chatbot locates and summarizes the most relevant content from the documentation.

25.1 ISR1

TitleTypeDescription
Support for Semantic Search in Offline Mode Major

Semantic search is an intelligent, intent-driven hybrid search capability that provides both keyword-based and semantic-based results depending on your search query.
Enhanced Feedback Submission Mechanism Major The built-in feedback submission feature has been redesigned for greater clarity, improved usability, and more intuitive user experience. 
Capturing User Activity in Offline Mode Major With user consent, Doc Assistant now captures usage activity in Offline mode. The data helps improve the performance and user experience by providing insights based on real usage patterns.
