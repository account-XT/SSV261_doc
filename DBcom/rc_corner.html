rc_corner

Parent Objects

delay_corner, root

Definition

The rc_corner object represents a specific interconnect parasitic corner. It contains configuration information for controlling the extraction of the parasitics and possible scaling. Parasitic files are annotated or exported with respect to an rc_corner object name. The rc_corner object is typically referenced from one or many higher-level delay_corner objects. Use the create_rc_corner command to define new rc_corners and the update_rc_corner command to update the attributes of existing rc_corners.
