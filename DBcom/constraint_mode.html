constraint_mode

Parent Objects

analysis_view, design, root

Definition

Associates a list of SDC constraint files with a specified constraint mode name, for multi-mode multi-corner analysis. This constraint mode name can be referred to later when creating analysis views. Use the create_constraint_mode and update_constraint_mode commands to create and modify constraint_modes.
