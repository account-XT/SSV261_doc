delay_corner

Parent Objects

analysis_view, design, root

Definition

The delay_corner object provides references to rc_corner objects which define the interconnect corner and timing_condition-to-domain bindings which define device operating corners - providing the majority of the configuration information needed to drive delay calculation. An analysis_view object will reference the delay_corner and combine it with a constraint_mode to complete the configuration. Use the create_delay_corner and update_delay_corner commands to create and modify delay_corner objects.
