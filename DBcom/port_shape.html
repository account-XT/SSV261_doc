port_shape

Parent Objects

design, net, root

Definition

This corresponds to one of a port's .physical_pins.layer_shapes.shapes, but is directly accessible from the design and root objects. It carries a link to the port object, that a layer_shape object does not have. This allows GUI operations that need both the layer_shape and the port object together as one object like delete_obj or wire-editing commands.
