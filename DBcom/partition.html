read_only

This attributes is set by set_module_view to identify if a partition is read only or not. It means the partition cannot be optimized, and cells inside will not be moved. Setting this attribute will set the dont_touch_effective attribute on all insts and hinsts within the partition unless overridden at a lower level partition. It cannot be overridden by other hinst or inst values.
 Supported values:
  false:  This partition is allowed to be optimized, even if a partition or design above has read_only = true.
  true:  The partition is read_only.
  none:  No constraint. This partition inherits any read_only from a partition or design above.
Type:  enum
Enum Values:  none false true
Default:  none
Edit:  No
