cts_pin_insertion_delay_sources

The amount of insertion delay under this pin, broken down by the source
  of the pin insertion delay (PID).
  The value of this attribute is a Tcl dictionary of PID values,
  keyed on the source of that PID. This provides an 'exploded' view into the
  total pin insertion delay that is present, categorizing the various
  contributions by their origin.
  Valid Tcl dict keys:
  user Asserted by user Tcl scripting or restored from an older DB.
  sdc Extracted from SDC set_clock_latency by spec creation.
  sink_type Asserted to reflect the impact of the cts_sink_type attribute.
  ilm Records the mean clock latency of the ILM clock network that is rooted at this pin.
  useful_skew A useful skew generated by pre-CTS optimization.
  incremental An incremental offset, used to specify useful skews to incremental CTS.
  total The formal sum of the above contributions. This value is the 'overall'
  pin insertion delay accessible via the cts_pin_insertion_delay attribute.
  Valid Tcl dict values: double | ignore | min | auto
  Reading the attribute returns a dict value that exposes the
  current state of the PID, recording all the PID sources and the associated PID
  value of each one. Sources whose value are auto are omitted. If there are no
  non-auto sources, the returned dict is empty. For convenience, the total is
  always included in the dict if it is non-auto.
  Writing a dict value to the attribute will update each of the
  specified sources with the specified PID value. The total PID value will then
  be updated. Sources in the dict that are assigned a value of 'auto' will be
  reset. Sources omitted from the dict are left unchanged from their current value:
  assigning an empty dict is a no-op.
  Resetting the attribute will clear all the sources and the total
  back, resetting them to the default value of 'auto', thereby completely removing
  the PID from the pin.
  Valid values: A Tcl dictionary of PID values, keyed on PID source.
Type:  string
Allowed -index values:  delay_corner
Default:  ""
Edit:  Yes

This value serves as a pin-specific override to use this stack_via_rule when connecting to this pin.   stack_via_rule == {} && stack_via_rule_required == false: stack_via_rule does not affect the choice.
