Specifies the preferred lowest routing layer. This attribute is a soft limit; that is, the router might use a layer below the specified layer if necessary to complete routing. You can set route_preferred_layer_effort to determine how strict the router needs to honor this limit. If the top routing layer is equal to or greater the 4th routing layer (layer with .route_index = 4), and no bottom preferred routing layer is specified for clock nets, the router automatically sets the route_bottom_preferred_layer for clock nets to the 3rd routing layer (layer with .route_index = 3), to prevent the clock nets from blocking other nets.

route_coaxial_shield_interval

Specifies the interval of crossties for the shield wires by routing track. A single value applies to all layers, or you can use a list of <layer> <value> pairs for individual layer controls. The default of 0 means there are no gaps between cross-ties. For example, '2' means 2 empty tracks between cross-ties on all layers, while 'metal2 2 metal3 4' means metal2 has 2 empty track and, metal3 have 4 empty tracks, and the default of 0 for all the other layers. The <layer> args can be input as a DPO name 'layer:metal3' or a layer name 'metal3', or as a layer index '3'. The output is always in a DPO name format like {layer:metal2 2 layer:metal3 4}.
Type:  string
