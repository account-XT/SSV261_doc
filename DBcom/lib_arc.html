Parent Objects

Definition

cte library timing arc

Attribute Description
aocv_weight
  Returns the AOCV stage weight for this library arc. By default, all library cells and library arcs have default stage weight of 1.0. The aocv_weight property is specified as a user-defined library attribute in the Liberty timing library explicitly - or, by asserting it via command. You can use -index to return a value for a specific view.
Type:  double
Allowed -index values:  analysis_view
Default:  ""
Edit:  No
