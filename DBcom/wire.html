Stylus Common UI Database Object Information

wire

Parent Objects

net

Definition

A 2-point wire segment intended for symbolic routing where the end-points normally align with other wire or via end-points, or end on a pin shape or special_wire. The wire, via, and patch_wire objects correspond to the DEF NETS symbolic routing data.
