exclusive_group_gap

This is the gap should be maintained between exclusive_groups (per safety island groups). The value is measured in microns. It can be set by command create_exclusive_groups -gap. It is only valid when the group's constraint_type is region or fence.
Type:  coord
Default:  5
Edit:  No
exclusive_group_type

This attribute specifies the logical type of this group. It describes the logical relationship of the group relative to other groups which can be used to implement safety islands in automotive application designs.

Enum Values:  none master checker mutually_exclusive
Default:  none

This attribute specifies a list of groups that are exclusive of this group. It can be used to implement safety islands in automotive application designs.
Type:  string
Default:  ""
Edit:  No
is_floating

Only affects groups with .constraint_type = fence or region. If true, the global placer can move the fence or region. The .rects value must also be set, and is currently restricted to a single rect. The global placer will not change the size of the rect, but may move it.
Type:  bool
