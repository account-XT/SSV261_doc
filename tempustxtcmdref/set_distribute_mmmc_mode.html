set_distribute_mmmc_mode

set_distribute_mmmc_mode
[-help]
[-client_init_execute_script filename]
[-eco {true | false}]
[-enable_high_capacity_eco]
[-enable_smart_mmmc] 
[-lic_startup_extra {list_of_options}]
[-load_def_only]
[-merge_view_definitions]
[-min_host_needed integer]
[-set_filler_mode {list_of_options}]
[-use_one_host_per_batch_job {true | false}]
[-interactive {true | false} [-views {list_of_views | all}]]

Controls distributed MMMC analysis settings.

Parameters

-help Prints out the command usage.
-client_init_execute_script filename

Specifies a file containing the TCL code that will be executed on a Tempus client(s) immediately after it is invoked. This allows you to load settings on a client prior to loading a database or design initialization.
-eco {true | false}

Enables/disables the timing signoff flow integrated with distributed MMMC.
-enable_high_capacity_eco

Enables database size reduction in the Tempus Paradime flow or Certus for high capacity ECO timing/power closure based on timing violations, list of partition names, or user-defined path group.

Note: It is mandatory to apply set_distribute_mmmc_mode -eco true command before set_distribute_mmmc_mode -enable_high_capacity_eco in Tempus Paradime flow. In case of Certus, it should be set before distribute_read_design.
-enable_smart_mmmc

Enables reduced memory or runtime solution when many timing views are enabled in Tempus Paradime flow or Certus.

Note: It is mandatory to apply set_distribute_mmmc_mode -eco true command before set_distribute_mmmc_mode -enable_smart_mmmc in Tempus Paradime flow. In case of Certus, it should be set before distribute_read_design.
-lic_startup_extra {list_of_options}

Specifies a list of licenses to be checked out by Tempus clients.

When specified, the software shows the extra Innovus startup licenses that are checked out by Tempus clients.
-load_def_only Specifies if a client database being restored in a flow contains LEF information and needs to load DEF (specified using the eco_def_file_list variable), to make it a fully physical flow.

-interactive {true | false}

Enables or disables the interactive mode.
-merge_view_definitions

Creates ECO analysis view(s) from view definition files in restore sessions.

The -merge_view_definitions parameter must be used only after set_distribute_mmmc_mode -eco true command is set.
-min_host_needed integer

Specifies minimum number of machines required to start a session in case all the machines cannot be acquired after time out.
-set_filler_mode {list_of_options}

Specifies a list of set_filler_mode command options.

This parameter allows to pass a list of options that the set_filler_mode command applies during physical data loading in Tempus Paradime.
-use_one_host_per_batch_job {true | false}

Enables/disables one batch mode job per host.

A new client is started for each view or each combined view job. This is used when running flows, such as manual ECO flows, where netlist updates during analysis makes scheduling of subsequent views difficult.  

-views {list_of_views | all}

Specifies a list of views for interactive mode. The all option selects all the view.

Examples

  • The following commands enable the distributed MMMC analysis in interactive mode for views view1 and view2:
    tempus > set viewnames {view1 view2}
    tempus > set_distribute_mmmc_mode -views $viewnames -interactive true
  • The following command disables the interactive mode once all the reporting/ECO on interactive views is done:
    tempus > set_distribute_mmmc_mode -interactive false

  • The following command lists all the filler cell names to be applied on set_filler_mode command:
    set_distribute_mmmc_mode -set_filler_mode {-core ”FILLX1 FILLX2 FILLX4”}

  • The following commands enable design loading in Paradime with the minimized set of data to reduce the memory or runtime during ECO fixing stage when many timing views are enabled, and performs Setup timing closure.

    tempus > set_multi_cpu_usage -localCpu 16 -remoteHost 4 -cpuPerRemoteHost 4
    tempus > set_distribute_mmmc_mode -eco true
    tempus > set_distribute_mmmc_mode -enable_smart_mmmc
    tempus > set_eco_opt_mode -retime path_slew_propagation
    tempus > set_distribute_mmmc_mode -merge_view_definitions
    tempus > set eco_setup_view_list “<list_of_Setup active_views>”
    tempus > set eco_hold_view_list “<list_of_Hold active_views>”
    tempus > set eco_lef_file_list “<list_of_LEF_files>”
    tempus > set eco_def_file_list “<list_of_DEF_files>”
    tempus > distribute_read_design -restore_design all -restore_dir PARADIME_SESSIONS/ -outdir reports_Paradime
    tempus > eco_opt_design -setup
