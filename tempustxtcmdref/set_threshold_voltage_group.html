set_threshold_voltage_group

set_threshold_voltage_group
[-help]
[-hinst <string>]
-name <group_name>
[-override]
{-libraries <library list> | -lib_cells <lib cell list>}

Groups timing libraries into different voltage threshold (Vth) classes (e.g., HVT, LVT, ULVT). 

This command can be used to define (or redefine) the threshold voltage groups associated with the specified timing library cells. You can group entire libraries into a single group, or group by per library cell specification.

Parameters

-help                        

Prints out the command usage.

-hinst <string>              

Specifies the hierarchical instances.

-lib_cells <lib cell list>    

Specifies a list of library cells to be defined in the VT group.

-libraries <library list>    

Specifies a list of libraries to be defined in the VT group.

-name <group_name>            

Specifies the name of the threshold voltage group being defined.

-override                    

Allows you to override Liberty-defined VT groups.

If the Liberty timing library already has native threshold_voltage_group attributes at the library or library cell level, you can use the -override parameter to customize it with the specified threshold voltage group.

Examples

  • The following commands define library threshold voltage groups if they do not preexist in the .lib:
    set_threshold_voltage_group -name SVT  -libraries stdcell_vt_1p62V_cworst
    set_threshold_voltage_group -name LVT  -libraries stdcell_2vt_1p62V_cworst
    set_threshold_voltage_group -name ULVT -libraries stdcell_vlvt_1p62V_cworst
    set_threshold_voltage_group -name ELVT -libraries stdcell_flvt_1p62V_cworst
