load_eco

load_eco <fileName>
-help
fileName

Loads a file that was generated in db format using the write_eco –format db command.

Parameters 

fileName

Specifies the name of the file generated by write_eco to load.

Examples

The following example reads myfile generated by the write_eco command.

tempus> load_eco myfile
