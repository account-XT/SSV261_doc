update_glitch

update_glitch
[-help]
[-effort {medium | high}]

Allows you to run glitch analysis without running SI delay analysis. This command provides the ability to run glitch analysis on all the nets in a design or on a subset of nets.

Using the update_glitch command without report_timing or update_timing will only run glitch analysis.

Note: It is not recommended to run the update_glitch command after the report_timing or update_timing command. 

Parameters

-help Outputs a brief description that includes type and default information for each update_glitch parameter. For a detailed description of the command and all of its parameters, use the man command: man update_glitch.
-effort {medium | high}

Specifies the effort level for the update glitch.

When set to high, glitch analysis uses more accurate modeling of the glitch for small attackers, thereby reducing pessimism.

Note: The run time in high mode may be slightly higher and is largely dependent on the distribution of coupling.

Default: medium

Examples

  • The following command will run glitch analysis without SI delay:
    tempus> update_glitch
