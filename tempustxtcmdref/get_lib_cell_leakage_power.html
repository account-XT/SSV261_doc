get_lib_cell_leakage_power

get_lib_cell_leakage_power
[-help]
-cell string
[-file string]
[-stateleakagegrp]
[ {-view string | -delay_corner string}
[-power_domain string]]
[ -early  | -late  ]

Returns the default leakage power of a cell.

Parameters

-help

Prints out the command usage

-cell string

Specifies the cell name for which the leakage power needs to be fetched (string, required)

-delay_corner string

Selects a cell from the specified delay corner

-early 

Selects a cell from the early library of the specified delay corner. If this option is not specified, late will be used by default. (bool, optional)

-file string

Specifies a.Name of the output file. (string, optional)

-late

Selects a cell from the late library of the specified delay corner. If this option is not specified, late will be used by default. (bool, optional)

-power_domain string

Selects a cell from the library of the specified power domain (string, optional)

-stateleakagegrp

Reports state dependent leakage power information.

-view string

Selects the cell from the specified view.

Examples

  • The following example reports state-independent cell leakage power along with the return value:
    tempus> get_lib_cell_leakage_power -cell xyz
  • The following command shows state-dependent groups:
    tempus> get_lib_cell_leakage_power -cell xyz -stateleakagegrp
