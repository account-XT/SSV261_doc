reset_clock

reset_clock
[-help] 
{-all | clock_list} 

Removes previously created clock assertions.

Parameters 

-help Prints out the command usage.

-all

Removes all clocks in the design.

clock_list

Specifies the list of clocks for which the clock assertion is removed.

Examples

  • The following commands reset a list of clocks and all clocks, and display the results using the report_clocks command:
    tempus > report_clocks

    # Generates the following report:

    GCLK4   u8/Q        CLK4        CLK_W_4      n      1/2        -           -       -
