define_parameter

define_parameter
[-help]
[<setup/hold>]
[-correlation <string>]
[-distribution <string>]
[-moments <string>]
[-name <string>]
[-range <string>]
[-related <string>]
-scope <string>
[-view <string>]

Provides variation information to Tempus. You can directly specify the range information, and Tempus will internally calculate moments and use them for wire variation calculation.

Parameters

-help                      

Prints out the command usage.

<setup/hold>              

Defines a parameter that is valid for setup or hold.

-correlation <string>      

Specifies the correlation between different parameters within the same scope; parameters must be predefined.

-distribution <string>    

Specifies the parameter distribution. You can also use user-defined distribution.

-moments <string>          

Specifies the parameter moments - mean or std-dev.

-name <string>            

Specifies the name of the parameter.

-range <string>            

Specifies the parameter minimum or maximum range - min or max.

-related <string>          

Specifies the related information on the sub-scope of the parameter within the specified -scope.

For back-end-of-line (BEOL), the allowed arguments are:

  • <layer  name>: capacitance
  • <layer name>: resistance

-scope <string>            

Specifies the parameter scope - vtskew, wire_variation, or via_variation.

-view <string>            

Specifies the view name.

Examples

  • The following command defines R/C range for normal distribution for M1 layer for setup for view view1:
    define_parameter setup –view view1 -name param_M1_R -scope wire_variation -distribution gaussian -range {1 1.15}    
    define_parameter setup –view view1 -name –param_M1_C -scope wire_variation -distribution gaussian -range {0.95 1}
  • The following command defines R/C moments for normal distribution for M1 layer for setup for all views:
    define_parameter setup -name param_M1_R -scope wire_variation -distribution gaussian –moments {0.2 0.01}   
    define_parameter setup -name param_M1_C -scope wire_variation -distribution gaussian -moments {0.95 1}
  • The following command defines correlation between metal layers - if M1, M2, and M3 are fully correlated:
    define_parameter -scope wire_variation  -correlation {{param_M1_C param_M2_C param_M3_C} {1.0}}
