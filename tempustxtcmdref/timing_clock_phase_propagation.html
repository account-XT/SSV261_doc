timing_clock_phase_propagation

timing_clock_phase_propagation
{positive | negative | both}

Default: both

Data_type: Enum

Allows you to the select appropriate clock phases at register clock pins, when both the positive and negative phases of the same clock signal are seen in the clock network. For example, a register whose clock pin is fed by a two-input XOR gate where one input is a clock port and the other input is a data port. When the value of the data signal of the XOR gate is unknown, the XOR gate can see both positive and negative phases of the clock signal.


both

Selects both positive and negative clock phases at the register clock pins.

positive

Selects positive clock phases.

negative

Selects negative clock phases.

To set this global variable, use the set_global command.
