sizeof_collection

sizeof_collection
[-help]
collection

Returns the total number of objects contained in the specified collection. If the collection contains objects of different types, sizeof_collection returns the sum of all the objects of different types in the collection.

Parameters 

-help Prints out the command usage.

collection

Specifies the collection.
