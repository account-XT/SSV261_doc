set_noise_lib_pin

set_noise_lib_pin
[-help]
-from string 
-to string

Allows you to map the noise properties of an instance pin to those of a different library cell pin.

Parameters

-help

Prints out the command usage.
-from string
Specifies the library pin name whose definition will be mapped from the given pin name.
-to string

Specifies the library pin name whose definition will be mapped to the given pin name.

When multiple set_noise_lib_pin commands are run on the same -to pin, the software will honor the first command only.

Note: The -from and -to parameters also accept library cell pin names (that can be retrieved using the get_lib_pins command). These parameters do not honor collections or instance pin names.

Examples

  • The input pin A of the macro_cell cell inherits the noise characteristics of the input pin I of the library cell, ccs_noise_lib/inv. This information is used to calculate the pin's noise immunity, library1/macro_cell/A.
    tempus> set_noise_lib_pin –to library1/macro_cell/A –from ccs_noise_lib/inv/I
  • The following syntax specifies the library pin name whose definition will be mapped from the given pin name to the given pin name: 
    tempus> set_noise_lib_pin –from [from_lib/from_cell/from_pin] –to [to_lib/to_cell/to_pin]
  • The following syntax specifies that a bidi pin is mapped to two pins; that is, –1 input pin and 1 output pin.
    tempus> set_noise_lib_pin –to library1/macro_cell/PAD –from “ccs_noise_lib/inv/I ccs_noise_lib/inv/Z”
