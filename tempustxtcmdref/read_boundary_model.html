Tempus Text Command Reference
Product Version 26.10, May 2026

read_boundary_model

read_boundary_model 
[-help]
[-check_contents]
[-clock_mapping_file string]
[-instances string]
[-report_file string]
[-skip_version_check]
[-unconstrained_net_use_inf_tw]
[-view_mapping_file string]
{-dir string}

Saves the directory information.

This command can be used for each cell boundary model generated by the block-level runs.

Parameters

-help Prints out the command usage.
-check_contents Checks for required files in the boundary model directory.
-clock_mapping_file string

Uses the mapping file created by the set_boundary_model_clock_mapping command.

The basic syntax of -clock_map_file is:

Block_clock_name(view_name) Top_clock_name(view_name) instance_name

However, both view_name and instance_name are optional. If you want to have the same mapping for all instances and views, then it is specified as follows:

Block_clock_name Top_clock_name

  • If it is instance-specific but not view-specific, then it is specified as follows:
    Block_clock_name Top_clock_name instance_name
  • If it is view-specific but not instance-specific then it is specified as follows:
    Block_clock_name(view_name) Top_clock_name(view_name)

Note that no spaces are currently allowed between the clock name and the view name.
-dir string Specifies the directory for the boundary model.
-instances string Specifies the instances for which the boundary model must be read.
-report_file string

Specifies the name of the boundary model check report file. After the boundary model is checked and the results are logged into this file.

If this parameter is not specified, the report is written to the <cell_name>_bmodel_check.txt file by default.
-skip_version_check Does not check for Tempus version consistency.
 -unconstrained_net_use_inf_tw Forces unconstrained nets to infinite timing windows.
-view_mapping_file string Uses the mapping file created by the set_boundary_model_view_mapping command.

Examples

  • The following command loads the boundary model files from the ./model_dir directory:
    read_boundary_model –dir ./model_dir
  • The following command loads the boundary model files from the ./model_dir directory:
    read_boundary_model –dir ./model_dir –clock_mapping_file clock.data 

    The clock.data file will be read for user-defined updates for clock mappings from the boundary model clock names to the clocks defined in the constraints for the current session.
