set_socv_rc_variation_factor

set_socv_rc_variation_factor 
[-help]
variation_factor
[-early]
[-late]
[-view list_of_views]

Defines the value of the interconnect delay variation factor.

This command applies a global variation as a percentage of the nominal delay. 

To enable this feature, you can set the timing_socv_rc_variation_mode global variable to true.

Parameters

-help

Prints out the command usage

variation_factor

Specifies the value of the interconnect delay variation factor to be used.

-early

Specifies the variation factor for early interconnect delays.

-late

Specifies the variation factor for late interconnect delays.

-view list_of_views

Apply the SOCV interconnect variation factor to the specified list of analysis views.
