set_timing_context_view_mapping

set_timing_context_view_mapping 
[-help]
[-block_clock_suffix block_clock_suffix]
-block_view block_view_name
-top_view top_view_name

Provides mapping between the top and block STA views. This command can be used only if the top and block STA view names differ.

A text file containing a set of set_timing_context_view_mapping commands can be provided to the read_timing_context -view_map_file parameter.

Parameters

-help

Prints out the command usage.

-block_clock_suffix block_clock_suffix

Specifies the suffix for block clock names. The block clocks with the specified suffix in the block_view name will only be mapped to the top clocks from the top_view.

-block_view block_view_name

Specifies the name of the view in the block-level analysis. The software maps the specified view with the -top_view view.

-top_view top_view_name

Specifies the name of the view in the top-level analysis. The software maps the specified view with the -block_view view.

Examples

  • The following example shows how a view mapping file can be set up:
    set_timing_context_view_mapping -top_view T1_view -block_view B1_view
    set_timing_context_view_mapping -top_view T2_view -block_view B2_view
