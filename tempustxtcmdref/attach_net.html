attach_net

attach_net
-help
net_name
list_of_pins

Attaches nets to pins. The syntax is order-dependent.

After this command, the software will perform a full timing update when you run the next command that reports timing, for example, report_timing.

Note: The tool supports this command for flattened designs only.

Parameters 

-help

Outputs a brief description that includes type and default information for each attach_net parameter.

For a detailed description of the command and all of its parameters, use the man command:
man attach_net

list_of_pins

Specifies a list of pins/ports to attach to the specified net or nets.

net_name

Specifies the net to attach to the pins.

Examples

The following example attaches net26 to pins i1/A, i2/B, and i3/Z:

tempus> attach_net net26 "i1/A i2/B i3/Z"

The following command is equivalent to the above example

tempus> attach_net [get_nets net26] [get_cells "i1/A i2/B i3/Z"]
