check_ipd_logic

check_ipd_logic
[-help]
[-outfile <filename>]
{ [-multi_pd_type <enum> [-verbose ]]}

Performs IPD logic checks and reports power-domain crossing information based on data and clock path checks.

Parameters

-help

Prints out the command usage.

-multi_pd_type <enum>

Specifies the type of IPD logic check that needs to be performed. You can specify the following options:

  • clock_divergence: Enables similar crossings on the divergent clock check.
  • clock_crossing: Enables multiple power domain crossings on clock path checks.
  • data_crossing: Enables multiple power domain crossings on data path checks.
  • cppr_aware: Enables checks for multiple power domains post the common point.
  • all: Enables all the crossing checks, except cppr_aware.

-outfile <filename>

Specifies the name of the output report file (suffix .rpt) to be generated.

-verbose

Allows the report_timing command to generate a detailed output for checks with .tcl suffix.

Examples

  • The following command reports all the IPD logic checks in the design:
    tempus> check_ipd_logic -multi_pd_type all -outfile ipd_logic_check_report -verbose

    The output of ipd_logic_check_report.rpt is as shown below:

    # Multiple Power Domain Crossings On Data Paths  #

    Endpoint: ff2/Q (clk1)
    PD1->PD2 lvl_cell1/Y
    PD2->PD3 lvl_cell2/Y
    2.
    Beginpoint: ff3/D (clk1)
    Endpoint: ff4/Q (clk2)
    PD1->PD2 lvl_cell3/Y
    PD2->PD3 lvl_cell2/Y

    ##########################
    # Clock Divergence Data  #
    ##########################
    1.
    Beginpoint: ff4/D (clk2)
    Endpoint: ff5/Q (clk2)
    PD1->PD2 lvl_cell5/Y (L) level_cell6/Y (C)

    ##########################################
    # Multiple Clock Power Domain Crossings  #
    ##########################################

    #######################################
    #Early Check Path Count Summary Output#
    #######################################

    Multiple IPD Data Crossing : 2
    ------------------------------------
    Count           Power Domain 
    ------------------------------------
    2             PD1->PD2->PD3

    IPD Clock Divergence : 1
    ------------------------------------
    Count          Power Domain 
    ------------------------------------
    1              PD1->PD2

    Multiple IPD Clock Crossing : 0
    ------------------------------------
    Count          Power Domain 
    ------------------------------------

    • The output of ipd_logic_check.tcl is as shown below: 

    ##################################################
    # Multiple Power Domain Crossings On Data Paths  #
    ##################################################
    report_timing -through lvl_cell1/Y -through lvl_cell2/Y
    report_timing -through lvl_cell3/Y -through lvl_cell2/Y

    ##########################
    # Clock Divergence Data  #
    ##########################
    report_timing -from ff4/D -clock_from clk1 -to ff5/Q -clock_to clk2

    ##########################################
    # Multiple Clock Power Domain Crossings  #
    ##########################################

  • The following command generates a report showing cppr_aware checks:
    tempus> check_ipd_logic -multi_pd_type cppr_aware -outfile cppr_aware_report

    cppr_aware_report.rpt

    # Multiple Power Domain Crossings Paths  #

    Beginpoint : inst11/Q(clk21)
    Endpoint : inst12/D(clk12)
    PD1 -> PD2 cinst13/Y (L)
    PD2 -> PD3 cinst123/Y (L)
    PD3 -> PD4 inst314/Y (D)
    PD4 -> PD5 inst414/Y (D)
    PD5 -> PD3 inst42/Y (D)
    PD1 -> PD2 cins246/Y (C)
    PD2 -> PD3 cins26/Y (C)

    #Early Check Path Count Summary Output#

The types of crossing in the path is indicated by the following abbreviations:

  • C : Capture Path
  • L : Launch Path
  • D: Data Path
