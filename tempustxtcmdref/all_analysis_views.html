all_analysis_views

 all_analysis_views
[-help]
[-type string]

Returns a TCL list of all the defined analysis views in a design.

You can use this command after creating multiple analysis views (using the create_analysis_view command).

Parameters

-help Prints out the command usage.
-type string

Specifies the type of analysis views. The following options are available:

  • setup: Active setup views in the design.
  • hold: Active hold views in the design.
  • active: Active setup and hold views in the design.
  • dynamic: Dynamic analysis views in the design.
  • leakage: Leakage analysis views.
  • em: Electromigration (EM) analysis views.
  • inactive: Setup/hold views that are not in use.
  • all: All defined views in the design, including those that are currently inactive.

Examples

  • The following commands create analysis views missionSlow and missionFast: 
    tempus > create_analysis_view -name missionSlow -constraint_mode missionSetup -delay_corner dcWCCOM
    tempus > create_analysis_view -name missionFast -constraint_mode missionHold -delay_corner dcBCCOM

    The following command returns a list of the defined analysis views in the design: 
    tempus > all_analysis_views

    The software returns the following results:
    {missionSlow missionFast}
