init_enable_drc_region_layer

init_enable_drc_region_layer {list_of_drc_region_layer}

Default: ""

Data_type: String

Specifies a list of drc_region_layer to restore the active DRC region layer. The init_enable_drc_region_layer global is saved through saveDesign in the *.global file.

init_enable_drc_region_layer {M1_FB1, M2_FB1}

LAYER M1_FB1

TYPE ROUTING ;

PROPERTY LEF58_REGION "REGION FB1 BASEDLAYER Metal1 ;" ;

WIDTH 0.460 ;

MINWIDTH 0.230 ;

MAXWIDTH 0.60 ;

SPACING 0.230 ;

SPACING 0.6 RANGE 10.0 100000.0 ;

PITCH 0.560 ;

DIRECTION HORIZONTAL ;

END M1_FB1

Tool loads only the DRC region layer which is defined in init_enable_drc_region_layer.

If the base layer (Metal3) only has one DRC region layer(M3_FB1) and is not defined in init_enable_drc_region_layer, the tool loads the DRC region layer without showing any message. However, if the base layer(Metal3) has multiple DRC region layers(M3_FB1, M3_FB6) and are not defined in init_enable_drc_region_layer, the tool will give a warning message and load the first DRC region layer.
