add_inst

add_inst
-help
<list_of_instances>
<lib_cell_name>

Adds an instance and places it in the design. The syntax is order-dependent.

After this command, the software will perform a full timing update when you run the next command that reports timing, for example, report_timing.

Note: The software supports this command for flattened designs only.

Parameters 

-help

Outputs a brief description that includes type and default information for each add_inst parameter.

For a detailed description of the command and all of its parameters, use the man command: man add_inst

lib_cell_name

Specifies the name of a cell or the names of a collection of cells used as a reference for the new instances added. You will need to specify the library when you specify the cell.

list_of_instances

Specifies a list of instances to create.

Examples

The following example creates two instances, inst1 and inst2, of library cell LIB/BUFX2:
tempus> add_inst "inst1 inst2" [get_lib_cells LIB/BUFX2]
