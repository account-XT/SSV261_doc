analyze_paths_by_hierarchy

analyze_paths_by_hierarchy 
[-help]
[-master string]
{-fp_file string [-include_macros ]} | {-use_current_floorplan [-all ] [-types string] [-port2port ] [-port2macro ] [-port2bbox ] [-port2hinst ] [-port2stdcell ] [-port2instgrp ] [-macro2port ] [-macro2macro ] [-macro2bbox ] [-macro2hinst ] [-macro2stdcell ] [-macro2instgrp ] [-bbox2port ] [-bbox2macro ] [-bbox2bbox ] [-bbox2hinst ] [-bbox2stdcell ] [-bbox2instgrp ] [-hinst2port ] [-hinst2macro ] [-hinst2bbox ] [-hinst2hinst ] [-hinst2stdcell ] [-hinst2instgrp ] [-stdcell2port ] [-stdcell2macro ] [-stdcell2bbox ] [-stdcell2hinst ] [-stdcell2stdcell ] [-stdcell2instgrp ] [-instgrp2port ] [-instgrp2macro ] [-instgrp2bbox ] [-instgrp2hinst ] [-instgrp2stdcell ] [-instgrp2instgrp ]} | {-partitions string | -macros string} 

Creates categories according to the hierarchical characteristics of the paths. User can use either a user specified floorplan file or current floorplan file of the design in memory and can create categories according to the hierarchy of the design. This way, the paths can be narrowed down to small group.

Parameters 

-help

Outputs a brief description that includes type and default information for each analyze_paths_by_hierarchy parameter.

For a detailed description of the command and all of its parameters, use the man command:
man analyze_paths_by_hierarchy

-fp_file floorplan_file

Specifies the name of the floorplan file.

Default: Uses the current floorplan file.

-include_macros

Includes macros in addition to guides and fences for creating categories.

Default: Macros are not considered.

-macros macro_list

Specifies the names of the macros to be used. Use this parameter with the -partitions parameter.

-master master_category_name

Specifies that the timing paths should be categorized only for the specified master category.

-partitions partition_list

Specifies the names of the partitions to consider for extracting hierarchical information.

-use_current_floorplan

Uses the current floorplan.

-all

Creates categories of paths within all types

Default: All types are categorized.

-types type_list

Creates categories of paths within the type_list.

Valid types are: port, macro, bbox, hinst, stdcell

-port2port

Creates categories of paths from port to port.

-port2macro

Creates categories of paths from port to macro.

-port2bbox

Creates categories of paths from port to black box.

-port2hinst

Creates categories of paths from port to hierarchical instance.

-port2stdcell

Creates categories of paths from port to std cell.

-macro2port

Creates categories of paths from macro to port.

-macro2macro

Creates categories of paths from macro to macro.

-macro2bbox

Creates categories of paths from macro to black box.

-macro2hinst

Creates categories of paths from macro to hierarchical instance.

-macro2stdcell

Creates categories of paths from macro to standard cell.

-bbox2port

Creates categories of paths from black box to port.

-bbox2macro

Creates categories of paths from black box to macro.

-bbox2bbox

Creates categories of paths from black box to black box.

-bbox2hinst

Creates categories of paths from black box to hierarchical instance.

-bbox2stdcell

Creates categories of paths from black box to standard cell.

-hinst2port

Creates categories of paths from hierarchical instance to port.

-hinst2macro

Creates categories of paths from hierarchical instance to macro.

-hinst2bbox

Creates categories of paths from hierarchical instance to black box.

-hinst2hinst

Creates categories of paths from hierarchical instance to hierarchical.

-hinst2stdcell

Creates categories of paths from hierarchical instance to standard cell.

-stdcell2port

Creates categories of paths from standard cell to port.

-stdcell2macro

Creates categories of paths from standard cell to macro.

-stdcell2bbox

Creates categories of paths from standard cell to black box.

-stdcell2hinst

Creates categories of paths from standard cell to hierarchical instance.

-stdcell2stdcell

Creates categories of paths from standard cell to standard cell.
-bbox2instgrp Creates categories of paths from black box to instance group.
-hinst2instgrp Creates categories of paths from hierarchical instance to instance group.
-instgrp2bbox Creates categories of paths from instance group to black box.
-instgrp2hinst Creates categories of paths from instance group to hierarchical instance.
-instgrp2instgrp Creates categories of paths from instance group to instance group.
-instgrp2macro Creates categories of paths from instance group to macro.
-instgrp2port Creates categories of paths from instance group to port.
-instgrp2stdcell Creates categories of paths from instance group to standard cell.
-macro2instgrp Creates categories of paths from macro to instance group.
-port2instgrp Creates categories of paths  from port to instance group.
-stdcell2instgrp Creates categories of paths from standard cell to instance group.

Examples:

  • By default, it categorizes all paths inter/intra the 5 hierarchical entities by following command :
    tempus> analyze_paths_by_hierarchy -use_current_floorplan -all
  • The following command categorizes all paths from "port" or to "port":
    tempus> analyze_paths_by_hierarchy -use_current_floorplan -type port
