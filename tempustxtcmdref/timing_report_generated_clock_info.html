timing_report_generated_clock_info

timing_report_generated_clock_info {true | false}

Default: true

Data_type: Boolean

Generated clock information is automatically added to the report, if generated clocks are encountered in either the launching or capturing clock paths.

The generated clock information column is displayed if the `Delay' field exists. If the `Delay' field does not exist, then the generated clock adjustment column is added to the report only when explicitly specified using the report_timing -format command or by setting the report_timing_format global variable.

To set this global variable, use the set_global command.
