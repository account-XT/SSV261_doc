write_noise_eco

 write_noise_eco 
[-help]
[-filename string] 
[-problem_nets string]

Tempus performs ECO analysis for noise failures. The default ECO file is named glitch. 

Note: The write_noise_eco command should always be called after glitch analysis has been performed.

Parameter

-help Prints out the command usage.
-filename string

Specifies the name for the ECO file.

If this parameter is not specified, the report is written to standard output (screen).
-problem_nets string

Reports the specified list of net names. The software provides the capability to generate ECO for the user-specified set of nets.

Examples

The following command generates an ECO file for all the glitch failures. 
tempus> write_noise_eco -filename glitch_eco.txt
