dump_histogram_view

dump_histogram_view 
[-help]
-name string
[-type string]

Saves (dumps) the image of the histogram shown in Global Timing Debug automatically during the process. 

Parameters


-help

Outputs a brief description that includes type and default information for each dump_histogram_view parameter.

For a detailed description of the command and all of its parameters, use the man command: 
man dump_histogram_view.

-name string

Specifies the name of the image file to save the histogram.
-type string

Specifies the type of file (image format) to be saved. Options are bmp/jpg/gif/tif/csv.

Default: bmp

Examples

The following commands automatically generates the gtd2.bmp image file of the histogram:

tempus 1> start_gui
