distributed_child_license_checkout_list

distributed_child_license_checkout_list {tpsl tpsxl vdst} 

Controls license that is being checked out by the Distributed MMMC client. This enables Distributed MMMC design analysis to utilize advanced features.

To set this variable, use the set_var command.

Default: tpsl tpsxl vdst

Data_type: String
