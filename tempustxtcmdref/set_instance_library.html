set_instance_library

set_instance_library 
[-help]
-library string
-instance string
[-early | -late]

Binds a cell library to an instance. When specified, the software overrides the default binding mechanism for a cell from the library set.

Note: The set_instance_library command cannot be used at the command prompt - this command can be specified in the ViewDefinition file. For more details, refer to the Tempus User Guide.

Parameters

-help    

Prints out the command usage.

-early

Uses the library binding for early timing analysis.

-instance <string>

Specifies the instance for which the library binding needs to be done.

-late

Uses the library binding for late timing analysis.

-library <string>

Specifies the library file path.

Examples

The following commands specify the instance for which the library binding will be done:

  • set_instance_library -library newcell.lib -instance {i1}
  • set_instance_library -library mysil.lib -instance {i1 i2}
  • set_instance_library -library {new.lib mysil.lib} -instance {i1} -early
  • set_instance_library -library {mynew.lib mysil.lib} -instance {i1 i2} -late
