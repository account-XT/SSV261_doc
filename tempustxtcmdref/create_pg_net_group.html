create_pg_net_group

create_pg_net_group 
[-help]
-name <name>
-pg_nets <net>

Allows you to group a set of PG nets. This helps simplify the overall UI of the IPD flow by specifying sweeps for a PG net group rather than a PG net. Also, the IPD crossings between the PG nets within a PG net group are automatically ignored.

Parameters

-help        

Prints out the command usage.

-name <name>    

Specifies the PG net group name.

-pg_nets <net> 

Specifies a list of power nets.

Examples

  • In the following example, the PG nets pgn1, pgn2, and pgn3 are a part of the PG net group PG1. 
    create_pg_net_group -name PG1 -pg_nets {pgn1 pgn2 pgn3}
    set_ipd_rail_voltage -sweep { PG1 {0.7 0.8} }

    The voltage values specified for PG1 apply to the PG nets within the PG net group. The crossings between pgn1 and pgn2, pgn2 and pgn3, and pgn1 and pgn3 will be ignored automatically.
  • In the following example, the PG nets pgn1, pgn2, and pgn3 are part of PG net group PG1: 
    tempus > create_pg_net_group -name PG1 -pg_nets {pgn1 pgn2 pgn3}
    tempus > create_delay_corners -name dc1 -library_set libset1 -rc_corner rc1 -pg_net_voltages {PG1@0.7}

    The voltage values specified for PG1 are applicable for the PG nets that are part of this PG net group (defined using create_delay_corner -pg_net_voltages).
