report_message

report_message
[-help]
[[{-errors | -warnings | -all } [-count ]] | -suppressed ]
[[-prefix <string> [-detail ] [-summary ]] ]
[-detail | -count | -suppressed ]
[-summary | -count | -suppressed]

Reports the messages that have been issued since the software was launched.

When you run the report_message command without any parameters, it prints a summary table and does not return any Tcl value. However, when you specify a parameter(s), it returns a list a of message IDs.

Parameters

-help

Prints a brief description that includes type and default information for each report_message parameter.

For a detailed description of the command and all of its parameters, use the man command:
man report_message

-all

Returns a list of all issued message IDs as a Tcl result. The result does not include suppressed message IDs.
-count

Returns count of every message when the -errors, -warnings, or -all parameters are specified.
-detail   Returns a list of detailed messages of the specified prefix.
-errors

Returns a list of issued error message IDs as a Tcl result.
-prefix <string>  Returns a list of issued error message IDs that match with the specified prefix.
-summary      Returns the message summary for the specified prefix.
-suppressed

Returns a list of suppressed message IDs as a Tcl result.
-warnings

Returns a list of issued warning message IDs as a Tcl result.
