change_inst_name

change_inst_name
-help
-inst inst_name 
-newBaseName base_name

Changes the base name of the specified instance to the given base name.

Note:  The change_inst_name command does not change the path of hierarchy.

Parameters

-help

Outputs a brief description that includes type and default information for each change_inst_name parameter.

For a detailed description of the command and all of its parameters, use the man command:
man change_inst_name
-inst inst_name Specifies the name of the instance that needs to be changed.
-newBaseName base_name Specifies the new base name for the specified instance.

Example

The following example changes the instance name from h3/inv3 to h3/h2/inv1:

tempus> change_inst_name -inst h3/inv3 -newBaseName h2/inv1
