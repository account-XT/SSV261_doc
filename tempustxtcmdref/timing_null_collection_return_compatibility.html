timing_null_collection_return_compatibility

timing_null_collection_return_compatibility
{true | false}

Default: false

Data_type: Boolean

Allows you to migrate previous release scripts to the new use model.

When the global is set to true, the software returns "NA" values that are consistent with the previous release. The nil return values are returned as an empty collection. This allows the return value to be used directly by collection iterators, such as foreach_in_collection.

The default value is false, which is consistent with the current release.

Note: This compatibility option may be removed from future releases. You should update your scripts to the new use model to avoid future problems.

To set this global variable, use the set_global command.
