set_message

set_message
[-help]
[-id list_of_msgIDs]
[-severity {warn | error | info | reset} | -limit number | -no_limit | -suppress | -unsuppress | -on_error {msg_only | exit | stop_script | -stop_script_limit <number>}]

Control messages that are displayed for a particular design. The command specifies the message severity levels - INFO, WARNING, or ERROR - at the beginning of the message. For example, if there are some warnings that are critical for the design, you can change the message severity to ERROR. Similarly, if there are messages that you want to ignore, you can change the message severity level to INFO.

Parameters

-help

Outputs a brief description that includes type and default information for each set_message parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_message.
-id list_of_msgIDs

Specifies the list of message IDs that require a change in the message severity level. If you do not specify a message ID, the change in severity level is applied to all message IDs.
-severity {warn | error | info | reset}

Specifies the new severity level for the message ID being modified.
-limit number Sets the message limit for the selected messages. The limit must be greater than zero. 
-no_limit Removes any existing limit on the selected messages. The suppressed messages are not unsuppressed.
-on_error {msg_only | exit | stop_script}

Takes extra action for error messages specified using the -id list_of_msgIDs parameter. Without the -id parameter, the extra action applies to all the error messages. You can specify any one of the following options:

  • exit: Exits immediately.
  • stop_script: Waits for a command to finish and return to the Tcl prompt;
  • msg_only: Prints an error message.

If the message severity is changed from error to warn or info, the software will no longer trigger extra action.
-stop_script_limit <number>

Sets the message limit for every public command.

If you set the -stop_script_limit parameter to 10, then at the 10th time the message will be triggered for one command. The software will wait for the current Tcl command to finish, the Tcl script will stop executing - and return to the interactive Tcl prompt.

Default: -1  (unlimited)
-suppress Suppresses the message. 
-unsuppress Unsuppresses the message. 

Examples

  • The following command changes the message IMPLF-81 from ERROR to WARN:
    tempus > set_message -id IMPLF-81 -severity warn
