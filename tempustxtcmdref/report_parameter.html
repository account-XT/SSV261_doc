report_parameter

report_parameter
[-help]
[-correlation]
[-name <string>]

Generates a report showing the settings for the define_parameter command.

Parameters

-help              

Prints out the command usage.

-correlation      

Reports the parameter correlation.

-name <string>    

Reports the parameter name.

-scope {vtskew | wire_variation
| beol | lle layout_effect}

Reports the parameter scope. Allowed options are:

  • vtskew
  • wire_variation
  • beol
  • lle layout_effect

-view <string>    

Shows the name of the specified view name.

Examples

  • The following command reports the moments information of the M2 layer resistance:
    tempus > define_parameter -name param_M2_R -scope wire_variation -distribution gaussian -range {1, 1.15}
    tempus > report_parameter -scope wire_variation -view func_spg_m4c_cmax                       
    -----------------------------------------------------------------------
                        PARAMETERS ( SCOPE: wire_variation )                          
    -----------------------------------------------------------------------
    Name         Mean-shift    Std-dev     Distribution     Analysis Type
    -----------------------------------------------------------------------
    param_M2_R   0.075         0.025       Normal           Setup
    param_M2_R   0.075         0.025       Normal           Hold
    -----------------------------------------------------------------------
