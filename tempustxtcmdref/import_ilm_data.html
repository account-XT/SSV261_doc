import_ilm_data

import_ilm_data
[-help]
-cell string
[-incr]
-model_type {timing | cts | si}
[-overwrite] 
[-xtwf string]
{-dir string | -cell_view string}
[-verilog string [-cell_prefix string -uniquify_netlist]]
[-sdc string -timing_view string] 
[-spef string -rc_corner string]
[-optStage string]

Creates an ILM directory from existing data. It can only create non-merged models. This command is useful in situations where an ILM is to be created through external inputs or using data from third party models into a format that could be recognized by Tempus. 

If the data files already exist in the specified directory, the tool stops and generates an error message. You can overwrite existing files by specifying the -overwrite option. You can add files to the directory by specifying -incr.

The command also creates a TCL script (cell_name_ILM.tcl) that you can source in your command file. The script contains the following command:

specify_ilm -cell cell_name -dir dir_name 

Note: The ILM is not supported for Signoff in Tempus.

Parameters

-help

Outputs a brief description that includes the type and default information for each import_ilm_data parameter.

For a detailed description of the command and all of its parameters, use the man command:
man import_ilm_data.
-cell string
 Specifies the name of the block.

-cell_prefix string

Specifies the cell prefix.
-cell_view string Specifies the library name, cell name, and view name in the OpenAccess database format.

-dir string

Stores the ILM data in the specified directory: the absolute directory path or the path relative to the current directory.
-model_type {timing | cts | si} Specifies the type of ILM model, i.e., timing, cts, or si.
-incr Let's you add files in addition to the existing files to the directory.
-optStage string Specifies the optimization stage, preCTS or postCTS.

-overwrite

Overwrites existing files in the directory.

-rc_corner string

Specifies the RC corner name for MMMC analysis. It identifies the specified corner to be used with -spef.
-sdc string Specifies an existing .sdc file that you want to include in the directory. It identifies the SDC file to be used with the specified view.

-spef string

Specifies an existing .spef file that you want to include in the directory. It identifies the SPEF file to be used with the specified corner.
-timing_view string Specifies the view name for the ILM module. It identifies the specified view to be used with –sdc.

-uniquify_netlist

Uniquifies the input Verilog netlist. This ensures that there are no errors when ILMs are being loaded.

Using this parameter, each sub-module for an ILM has a unique name, which is composed of the time stamp and its original name.

For example, in top_sm WedJun31138212009$data_path, top_sm specifies the top-level design, WedJun31138212009 specifies the time stamp, and $data_path specifies the original module name.

Default: Off

-verilog string

Specifies the Verilog file you want to include in the ILM data directory.

-xtwf string

Specifies the .xtwf file to include in the directory.

Examples

  • The following commands create two module directories:

    import_ilm_data -cell blk1 -dir A -model_type timing -verilog V1.v -spef 1.spef -rc_corner corner1 -sdc sdcfile1 -timing_view view1 

    import_ilm_data -cell blk2 -dir A -model_type si -verilog V2.v -spef 2.spef -rc_corner corner2 -sdc sdcfile2 -timing_view view2

  • The command creates two TCL files in the current directory. The blk1_ILM.tcl file contains the following command:

    specify_ilm -dir A -cell blk1

    The blk2_ILM.tcl file contains the following command:

    specify_ilm -dir A -cell blk2
