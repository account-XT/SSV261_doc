report_jitter

report_jitter 
[-help]
[-eiv_end_time float]
[-eiv_file string]
[-eiv_vdd_vss string]
[-eiv_start_time float]
[-from string]
[-from_fall string]
[-from_rise string]
[-mode {period | cycle_to_cycle | time_interval_error}]
[-outdir string]
[-through <string>]
[-to string]
[ [ > | >> ] ]

Provides a native jitter interface to report jitter through the native Tempus engine.

The existing analyze_jitter command will continue to be used for Spice-based jitter analysis.

Parameters

-help

Prints out the command usage.

-eiv_end_time float

Specifies the end time in EIV.

-eiv_file string

Specifies the effective instance voltage files for accounting for IR Drop in Jitter computation.

-eiv_vdd_vss string

Specifies the power and ground net name for each EIV file.

It is mandatory to provide the power and ground net name for each eiv file provided using the -eiv_file parameter.  For example, "vdd1 vss1 vdd2 vss2", vdd1 and vss1 are for the first, and vdd2 and vss2 for the second EIV file - specified using the -eiv_file parameter. 

-eiv_start_time float

Specifies the start time in EIV.

-from string

Creates the Spice deck with a mesh net starting from the pin.

-from_fall string

Creates the Spice deck with a mesh net starting from the falling transition of the specified from pin.

-from_rise string

Creates the Spice deck with a mesh net starting from the rising transition of the specified from pin.

-mode {period | cycle_to_cycle | time_interval_error}

Specifies the mode used by the analyze_jitter command. 

Default: period

-outdir string

Specifies the output directory for the created Spice.
-through <string> Creates the Spice deck with a mesh net going through the -through points.

-to string

Creates the Spice deck with a mesh net ending at two pins.

> filename

Redirects the -run_path_simulation/-run_simulation output to a file.

>> filename

Appends the -run_path_simulation/-run_simulation output to a file.

Examples

  • The following command reports analysis jitter details (for period mode) in the specified output directory:
    report_jitter -eiv_file eiv_file1 -outdir jitter_dir -mode period
  • The following command reports analysis jitter details (for cycle_to_cycle mode) in the specified output directory:
    report_jitter -eiv_file eiv_file1 -outdir jitter_dir -mode cycle_to_cycle
