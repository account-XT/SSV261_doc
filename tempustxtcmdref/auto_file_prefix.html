auto_file_prefix

auto_file_prefix string  

Default: ""

Data_type: String

Represents the prefix to be applied to all files/sub-directories that are auto-generated in a session by the software. 

When specified, the software adds a prefix to the files. For example, a default name like "CTE_loops.rpt" will change to "<prefix>CTE_loops.rpt". These files are created by Tempus automatically and are retained after the run completes. This includes report files or other output files with default names that are auto-generated in the current run directory.

To set this global variable, use the set command.
