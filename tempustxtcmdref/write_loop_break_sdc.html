write_loop_break_sdc

write_loop_break_sdc
[-help]
-input_file fileName
-outfile fileName

Generates an SDC file containing constraints for combinational loop breaking. The command selects the disable arc(s) with flag set to 1 from the third-party report file, and generates the equivalent SDC commands in an output file.

You can load the output SDC file at any time during a Tempus session. To load the file, use the read_sdc command.

Parameters 

-help Prints out the command usage.

-input_file fileName

Specifies the disabled time arcs report that you generate using a third-party software. To generate the report, use the following command:

report_disable_timing -nosplit > disable_arcs.rpt

-outfile fileName

Specifies the name of the output SDC file.

Command Order

Use this command after generating the disable arcs report.

Examples

The following command generates an etsCombLoopBreak.sdc file when the input is a disable_arcs.rpt file:
tempus> write_loop_break_sdc -input_file disable_arcs.rpt -outfile etsCombLoopBreak.sdc
