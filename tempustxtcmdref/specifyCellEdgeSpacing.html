specifyCellEdgeSpacing

specifyCellEdgeSpacing 
[-help] 
{<type1> <type2> <spacing>
[-exceptExactSpacing distance][-exceptAbutted | -forbiddenSpacing][-exceptNonFillerInBetween]} | [-reset]

Creates the cell edge spacing rule as in CELLEDGESPACINGTABLE in LEF.


The tool, by default, supports the latest TCL settings. If a user tries to change the edge spacing, the tool will display a warning message that resetting edge spacing would overwrite the old value.


Parameters 

-help

Outputs a brief description that includes type and default information for each specifyCellEdgeSpacing parameter.

For a detailed description of the command and all of its parameters, use the man command:
man specifyCellEdgeSpacing
-exceptAbutted Specifies that two abutted macros of the given edge types are also allowed.
-exceptExactSpacing distance

Specifies an exception distance to the minimum spacing.
-exceptNonFillerInBetween

Specifies that the edge spacing is only for adjacent instances.

If two MACROs (cells) have an edge-spacing rule (for example, 0.8 microns), the rule normally applies regardless of the presence of another macro (cell) in the gap between. When the -exceptNonFillerInBetween option is used, the rule is exempted when a non-filler cell is present between the two constrained cell edges.
<type1> Specifies edge edgeType1 for edge spacing. 
<type2>

Specifies edge edgeType2 for edge spacing.
-forbiddenSpacing Forbids edgeType1 and edgeType2 with the space.
-help

Outputs a brief description that includes type and default information for each specifyCellEdgeSpacing parameter.

For a detailed description of the command and all of its parameters, use the man command: man specifyCellEdgeSpacing  
-reset Resets the cell edge spacing to LEF.
spacing

Specifies edge spacing between edgeType1 and edgeType2.

If there is no spacing defined between two edge types, it indicates that there is no spacing constraint (or 0.0 µm) between them.

Example

The following command creates a 0.18 µm spacing between grp1 and grp2:

specifyCellEdgeSpacing grp1 grp2 0.18
