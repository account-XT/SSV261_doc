define_proc_arguments

define_proc_arguments
[-help]
proc_name
[-info info_text]
[-define_args arg_defs]
[-hide]

Defines the arguments and attributes of a Tcl procedure. The arguments and attributes are displayed when you view the help associated with the procedure.

The define_proc_arguments command, when used with the parse_proc_arguments command, enables you to validate command usage. For invalid commands, appropriate error messages are displayed.

Parameters 

-help Prints out the command usage.

proc_name

Specifies the name of an existing Tcl procedure.

-info info_text

Provides help information for the procedure.

-define_args arg_defs

Defines all possible arguments of the Tcl procedure. It can also be used to define the help text and constraints for individual arguments of the procedure and generate the help for command options.

The variable arg_defs is a list of lists, where each list element defines one argument. Each element in the list has the following format:

"arg_name" "option_help" "value_help" "data_type" "attributes"


arg_name: Specifies the name of the argument.


option_help: Provides a short description of the argument.


value_help: Specifies the help information for the associated option values.


data_type: (Optional) Used for validation of options.

Supported data types are string, list, boolean, int, integer, float, or one_of_string.

Default: string


attributes:

(Optional) Used for validation of options.

The attributes can be:

  • required: This argument must be specified. This is mutually exclusive with optional and internal.
  • optional: Specifying this argument is optional. This is mutually exclusive with required.
  • internal: Disables the display of help information for the option in the procedure help. This argument is mutually exclusive with required.
  • value_help: Indicates that the valid values for one_of_string argument should be listed whenever argument help is shown.
  • values {allowable_values}: This argument must be used with the one_of_string data type.
  • merge_duplicates : Ensures that when the option appears more than once in a command, its values are concatenated into a list of values. The default behavior is to use the rightmost value specified for the option.
  • bind_option other_arg_name: Binds the current option with the option specified as the other_arg_name variable.
  • mutual_exclusive_group group_name: Defines a group name and includes the current option in the group_name group. All options within a group are mutually exclusive.
  • Default: optional

-hide

Hides the procedure and its body.

Examples

The following Tcl procedure uses the define_proc_arguments command to define arguments and attributes, and to validate the command usage.

proc cmdProc {args} {
parse_proc_arguments -args $args results
foreach argname [array names results] {
puts "$argname = $results($argname)"
}
}
define_proc_arguments cmdProc -info "Command Description" \
-define_args \
{{-string "String help" "string_val" string optional}
{-integer "Int help" "int_value" int optional}
{-list "List help" "list_value" list {optional bind_option -Bool}}
{-boolean_a "BoolA help" "" boolean {optional mutual_exclusive_group
g0}}
{-boolean_b "BoolB help" "" boolean {optional mutual_exclusive_group
g0}}
{-float_num "Float help" "float_value" float}
{-oosa "One of StringA help" "one_of_str_value" one_of_string
{optional value_help {values {v1 v2}}}}
{-oosb "One of StringB help" "one_of_str_value" one_of_string
{optional {values {v4 v5}}}}
}

Now, if the cmdProc procedure is invoked with the -help option at the command prompt, the following help information is displayed.

tempus> cmdProc -help
Usage: cmdProc # Command Description
[-string string_val] (String help)
[-integer int_value] (Int help)
[-list list_value] (List help, Bind_Option=-Bool)
[-boolean_a ] (BoolA help, Mutual_Exclusive_Group=g0)
[-boolean_b ] (BoolB help, Mutual_Exclusive_Group=g0)
[-float_num float_value] (Float help)
[-oosa one_of_str_value] (One of StringA help, Values={v1 v2 })
[-oosb one_of_str_value] (One of StringB help)
