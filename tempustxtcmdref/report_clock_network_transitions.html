report_clock_network_transitions

report_clock_network_transitions 
[-help]
[-all]
[-clock string]
[-exclude_pins string]
[-threshold float] 
[-verbose]
[-view string]

Reports all the clock tree pins that have valid rise/fall maximum transition values.

This command generates reports on a per clock basis. For virtual clocks, no pins will be reported.

Parameters

-help

Prints out the command usage.

-all

Reports all the pins having a valid transition value.

-clock string

Specifies a list of clocks. 

-exclude_pins string

Does not report the specified pins.

-threshold float

Does not report pins that have at least one of the transition values (rise or fall) greater than the specified threshold value.

-verbose

Specifies to include the library cell information.

-view string

Specifies the name of the view.

Examples

  • The following command reports all the pins along with the rise/fall transition values for the specified clock:
    report_clock_network_transitions -all -clock clk_48
