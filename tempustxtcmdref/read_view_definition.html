read_view_definition

read_view_definition
-help
-cpf
<viewDefinitionFile>

Specifies a view definition file for loading an MMMC design.

When using the MMMC flow, it is recommended to use the following flow whereby the view definition file is read before the set_top_module command:

read_view_definition viewDefinitionFile
read_verilog
set_top_module
report_timing

The recommended flow for a design where MMMC configuration is specified in CPF file is as follows:

read_view_definition -cpf <cpf_file>
read_verilog
set_top_module
read_power_domain -cpf <cpf_file>

Parameters

-help

Outputs a brief description of the read_view_definition command. For a detailed description of the command, use the man command: man read_view_definition.
-cpf Specifies CPF file with MMMC configuration.

viewDefinitionFile

Specifies MMMC view definition file.
