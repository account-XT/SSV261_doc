delete_inst

delete_inst 
[-help]
<list_of_instances>
[-module_based <string>]

Deletes specified instances. The tool checks whether the instance is physical or logical, and deletes the instance accordingly.

After this command, the software will perform a full timing update when you run the next command that reports timing, for example, report_timing.

Note: The tool supports this command for flattened designs only.

Parameters 

-help

Outputs a brief description that includes type and default information for each delete_inst parameter.

For a detailed description of the command and all of its parameters, use the man command:

man delete_inst

list_of_instances

Specifies the instances to be removed.

-module_based string

Specifies the name of the block in which you want to delete the instances.

Examples

  • The following command deletes instance i1/i2:
    tempus> delete_inst i1/i2
  • The following command deletes all instances whose names begin with i:
    tempus> delete_inst [get_cells i*]
