report_ipd_crossings

report_ipd_crossings 
[-help]
[-all]
[-cppr_aware]
[-from <pin_list>]
[-from_power_domain <string>]
[-out_file <file_name>]
[-to <pin_list>]
[-to_power_domain <string>]

Reports the IPD crossing information summary on the design. This command also provides details on the pins and instances that are part of these crossings.

Parameters

-help                

Prints out the command usage.

-all                           

Reports detailed crossing information.

-cppr_aware

Reports all the IPD crossings with CPPR awareness.  

-from <pin_list>               

Specifies the source pin for which crossing is to be reported.

-from_power_domain <string>    

Specifies the source power domain for which crossing is to be reported.

-out_file <file_name>          

Specifies the output file name - in case the output is to be redirected to a file.

-to <pin_list>                  

Specifies the sink pin for which crossing is to be reported.

-to_power_domain <string>      

Specifies the sink power domain for which crossing is to be reported.

  • The following output is generated by the report_ipd_crossings command:
