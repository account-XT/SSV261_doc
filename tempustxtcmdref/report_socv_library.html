report_socv_library

report_socv_library 
[-help] 
[-categories string]
[-coverage_verbose]
[-list_not_annotated]
[ -libset string | { -delay_corner string [ -power_domain string] }| { -view string [-power_domain string]}] [ -libs string | -lib_cellsstring]
[-coverage]

Reports the coverage of the SOCV library(s) loaded in the design.

Parameters

-help                     

Prints out the command usage.

-categories string    

Allows you to control the types of table data to be used to check delay arcs, transition arcs, and check arcs.

Default: all

-coverage                 

Reports coverage library data.

-coverage_verbose         

Generates a detailed report table for each cell.

-delay_corner string    

Checks all the libraries defined in the specified delay corner.

-lib_cells string      

Specifies library cells.

The allowed format is \u201clibrary/cell\u201d name or pattern or collection. This is typically used for debugging purposes.

-libs string          

Specifies the name of the library.

If the -library_set or -delay_corner parameter is not specified, then all libraries matching the library name across the MMMC configuration will get checked.

-libset string        

Checks all the libraries defined in the specified library set.

-list_not_annotated       

Control the types of table data to be used to check delay arcs, transition arcs, and check arcs.

Default: all

-power_domain string   

Checks and reports the specified power domain.

-view string           

Checks all the delay corners associated with a view.
