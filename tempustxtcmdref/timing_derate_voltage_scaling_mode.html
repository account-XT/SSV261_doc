timing_derate_voltage_scaling_mode

timing_derate_voltage_scaling_mode {first_library | snap_to_nearest | interpolate}

Default: first_library

Data_type: Enum

Controls how the timing derates are computed when analysis voltage is not at the characterization voltage of any of the currently loaded timing libraries. When timing analysis environment is configured for interpolation, the MMMC library set will contain a list of timing libraries at different voltage characterizations points.

You can specify the following options:

first_library Derates associated with the first library in the timing library list will be used. 
snap_to_nearest Allows the software to choose one set of derates from the library closest to the required analysis voltage. 
interpolate Allows the timer to perform interpolation of the derates associated with the two bounding reference libraries. 

Consider the following example:

create_library_set -name ls_interp_1.50V_1.80V
-timing [list stdcell_1.50V.lib stdcell_1.75V.lib stdcell_1.80V.lib]

In this example, by default (first_library) the derates associated with the library stdcell_1.50V.lib will be used.

When set to snap_to_nearest, if the analysis voltage is 1.70V, the derates from the library stdcell_1p75V.lib will be used.

When set to interpolate, if the analysis voltage is 1.60V, then interpolation of derates from the libraries stdcell_1.50V.lib and stdcell_1.75V.lib will be used.

If interpolation mode is selected and the analysis voltage is beyond either the smallest or largest voltage, then the library derates will not be interpolated. The derates associated with the nearest bounding library will be used. If the analysis voltage is 1.90V, then only the derates from stdcell_1.80V.lib will be used.

If interpolation mode is enabled, but not all the bounding libraries have derate values, a default derate value of 1.0 will be assumed for the missing derates and used for interpolation. A TA-960 warning message will also be issued.

To set this global variable, use the set command.
