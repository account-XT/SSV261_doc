set_pulse_clock_max_width

set_pulse_clock_max_width
[-help]
pulse_width
object_list
[-transitive_fanout]

Sets the maximum pulse clock width constraint on the specified pulse generator cells, pulse generator library cells, clocks, and/or current design.

To report the maximum pulse clock width constraint, you can use the report_constraint -check_type pulse_clock_max_width command. 

Parameters


-help Prints out the command usage.

object_list

Specifies a list of objects - pulse generator cells, pulse generator library cells, clocks, or current design.

pulse_width

Specifies the pulse width value.

-transitive_fanout

Specifies the pulse width value for transitive fanout.

Examples

The following example sets the maximum pulse clock width constraint of 1ns on the pulse generator instance 'pg_inst':
tempus > set_pulse_clock_max_width 1 pg_inst

This constraint can be observed using the following command:

tempus > report_constraint pg_inst/Y -check_type pulse_clock_max_width

Fragmented output:

--------------------------------------------
Pin Required Actual Pulse Slack Clock Type
Pulse Width Width
--------------------------------------------
pg_inst/Y (high) 1.000 0.366 0.634 PG
--------------------------------------------
