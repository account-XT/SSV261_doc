restore_db_file_check

restore_db_file_check {true | false}

Default: true

Data_type: Boolean

By default, read_design will check all the files inside the saved DB directory. If any file is edited, renamed, or deleted, the tool will give an error. However, read_design will not perform this check if restore_db_file_check is set to false.
