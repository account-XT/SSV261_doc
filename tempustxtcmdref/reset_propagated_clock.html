reset_propagated_clock

reset_propagated_clock 
[-help]
pin_clock_list

Removes the propagated clock assertion for the specified clock waveforms or pins. 

The ideal or propagated status of clock endpoints in the fanout of the specified pin/clock list is determined by the remaining clock latency propagated clock assertions in the clock network. 

When new analysis views are used, the new corners do not have the source latency updated as per the clock propagation (update_io_latency) settings, so a reset and re-calculation is required.

Note: You must specify set_interactive_constraint_modes constraint prior to running the reset_propagated_clock command.

Parameters 

-help Prints out the command usage.

pin_clock_list

Specifies a list of pins or clocks for which you want to reset the clock propagation mode to ideal mode.

The pin_clock_list parameter can be a collection, however, no hierarchical pins are allowed in the list.

Examples

  • The following command sets the CLK1 clock waveform to propagated mode:
    tempus > set_propagated_clock CLK1
  • The following command resets the CLK1 clock waveform back to ideal mode:
    tempus > reset_propagated_clock CLK1

  • The following commands set the CLK1 clock to propagated mode and then reports them:
    tempus > set_propagated_clock [get_clocks CLK1]
    tempus > report_clocks
