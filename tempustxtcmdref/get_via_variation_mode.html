get_via_variation_mode

get_via_variation_mode
[-help]
[-corner_sigma_multiplier]
[-correlation_type]
[-reset]
[-separate_params_for_via]
[-quiet]
[-nonDefault]

Displays the following information about the specified set_via_variation_mode command parameters in the Tempus log file and the Tempus console:

  • Parameter name
  • Current value
  • Type (Boolean, string, and so on)
  • Whether the user sets the current value

If you do not specify any parameters, the software displays information for all of the parameters.

Parameters

-help Prints out the command usage.

parameter_names

Displays information for the specified parameters. You can specify one or more parameters.

See set_via_variation_mode for descriptions of the parameters you can specify.
