set_timing_context_clock_mapping

set_timing_context_clock_mapping 
 [-help]
[-add]
-block_clock block_clock_name
[-instance <string>]
-top_clock top_clock_name
[-top_view view_name]
[-view view_name]

Specifies user-defined clock mapping in context analysis. The auto-inferred clock mappings will be overridden by user-specified mappings. This command should not be specified directly in the Tempus shell.

Note: To ensure correct behavior, this command must be specified in the clock mapping file and subsequently loaded into the Tempus environment using the following command: 
read_timing_context -clock_mapping_file clock_mapping_file

This command should not be run as a standalone command; it must be enclosed in the mapping file.

Parameters

-help

Prints out the command usage.

-add

Specifies the multiple top clocks to a single block clock mapping. When -add is not specified, the last specified top to block clock mapping will override the previously specified mapping for that block clock.

-block_clock block_clock_name

Specifies the name of the clock from the block-level analysis. The software maps the specified clock with the clock specified using the -top_clock parameter.

-instance string

Specifies the list of block instances for which the clock mapping is to be applied.

When this parameter is not specified, the clock mapping will be applied to all the instances for which context analysis is to be performed. 

-top_clock top_clock_name

Specifies the name of the clock from top-level analysis. The software maps the specified clock with the clock specified using the -block_clock parameter.

-top_view view_name

Specifies the top analysis view for top or block level clock matching.

-view view_name

Specifies the MMMC analysis view for which the top-block clock mapping is to be applied.

 Examples

  • In the following example, the block clock BCLK is mapped to the top clock TCLK in block view B_view:
    set_timing_context_clock_mapping -top_clock TCLK -block_clock BCLK -view B_view
  • In the following example, the block clock BCLK is mapped to both top clocks TCLK1 and TCLK2 in block view B_view:
    set_timing_context_clock_mapping -block_clock BCLK -top_clock TCLK1 –view B_view
    set_timing_context_clock_mapping -block_clock BCLK -top_clock TCLK2 –view B_view –add
  •  In the following example, the block clock BCLK is mapped only to TCLK2 in block view B_view since -add is not specified:
    set_timing_context_clock_mapping -block_clock BCLK -top_clock TCLK1 –view B_view
    set_timing_context_clock_mapping -block_clock BCLK -top_clock TCLK2 –view B_view
