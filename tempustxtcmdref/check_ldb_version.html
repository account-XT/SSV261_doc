check_ldb_version

check_ldb_version
[-help]
-ldb string

Reports the LDB version, size, and the source of the software that is used to generate the library database (LDB) file. The LDB is the Cadence binary library format.

Parameters

-help

Prints out the command usage.

-ldb string

Specifies the LDB (library database) file whose version is to be printed.

Examples

  • The following example displays the missing features/recommendations for the library database cell_w.db:
    tempus > check_ldb_version -ldb cell_w.ldb

    The output is as shown below:
    LDB file compiled with tool version: v15.20 ((64bit) mm/dd/yyyy 08:40 (Linux 2.6.18-371.el5))
    File Size is xxxxx
    Source Tool: Innovus
