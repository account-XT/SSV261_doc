read_partition

read_partition
[-help]
-verilog fileName
-def fileName

The read_partition command allows you to load the Verilog/DEF files for a module that is currently treated as a black box (represented by LEF/LIB). This command is needed for hierarchical designs to assemble the top-level database with all the block-level databases. The tool will automatically create a fence for every partition loaded.

Note: It is mandatory to provide LEF files for every partition when loading the top-level database.

Parameters

-help

Outputs a brief description that includes type and default information for each read_partition parameter.

For a detailed description of the command and all of its parameters, use the man command:
man read_partition

-verilog fileName

 Specifies the Verilog file name.

-def fileName

 Specifies the DEF file name.

Examples

  • The following command assembles the ptn1 block-level database to the top level database already present in the memory.
    tempus> read_partition –verilog ptn1.v –def ptn1.def
