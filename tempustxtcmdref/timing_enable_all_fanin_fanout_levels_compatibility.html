timing_enable_all_fanin_fanout_levels_compatibility

timing_enable_all_fanin_fanout_levels_compatibility
{true | false}

Default: true

Data_type: Boolean

Enables computation of gate level count (for all_fanout/all_fanin commands) when an input pin is specified using the all_fanout -from parameter and output pin is specified using the all_fanin -to parameter. When the initial gate is traversed, the count is computed as 1.

When set to false, the global computes the gate level count as 0.

To set this global variable, use the set_global command.
