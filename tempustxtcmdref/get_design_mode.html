get_design_mode

get_design_mode
[-help]
[-backsideBottomRoutingLayer layer]
[-backsideTopRoutingLayer layer]
[-bottomRoutingLayer]
[-compressedPGDB]
[-congEffort {low|medium|high|auto}]
[-earlyClockFlow]
[-idealHoldFixing {true|false}]
[-merge_trim_shapes {{layers layer_name_list gap gap_value max_merge_num number_of_max_merge masks {mask_num ...}} ...}]
[-node]
[-optimizationDensityScreenMargin margin]
[-quiet]
[-nonDefault]
[-topRoutingLayer]
[-trim_grid_group]

Displays the following information in the log file and at the console:

  • Parameter name
  • Current value
  • Type (Boolean, string, and so on)
  • Whether the current value was set by user

If you do not specify a parameter, the software displays information for all the parameters.

Parameters

-help

Outputs a brief description that includes type and default information for each get_design_mode parameter.

For a detailed description of the command and all of its parameters, use the man command:

man get_design_mode.
-backsidebottomroutinglayer

Returns the highest backside LEF layer name for global and detail routing.

Default: ""
-backsideTopRoutingLayer

Returns the lowest backside LEF layer name for global and detail routing.

Default: ""
-bottomRoutingLayer

Returns the lowest lef layer name for global and detail routing.

Default: ""
-compressedPGDB Returns whether the compressed PG feature is enabled. When it's true, read_design will automatically compress the PG data when load a design.
-congEffort {low|medium|high|auto} Returns the congestion effort level.
-earlyClockFlow

Returns the setting for early clock flow.

Default: false
-idealHoldFixing

Returns the value ideal hold fixing flow.

Default: false
-merge_trim_shapes Returns the setting for trim shapes merge. 
-node

Returns the design technology node.
-optimizationDensityScreenMargin  Returns the margin on the top of original density screen for optimization.

-quiet

Returns the current settings for the specified parameter in Tcl list format only.

If you specify -quiet without a parameter, the software displays the current settings of all set_design_mode parameters in Tcl list format.
-nonDefault Displays the current settings which are not default settings.
-topRoutingLayer layer_name

Returns the highest lef layer name for global and detail routing.

Default: ""
-trim_grid_group group_name

Returns the GROUP name of the set from which the trim metal grid will be used for placement and routing.

Default: ""

If the specified group name does not exist in LEF, the tool will return an ERROR.

Examples

  • The following command displays the current setting of the -process parameter:
    tempus > get_design_mode -process

    The software displays the following information:
    -process 65 # int, default=65, min=10, max=250
  • The following command displays the current setting for the -process parameter in Tcl list format only:
    tempus > get_design_mode -process -quiet

    The software displays the following information:
    65
