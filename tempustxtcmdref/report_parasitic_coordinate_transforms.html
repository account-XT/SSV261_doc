report_parasitic_coordinate_transforms

report_parasitic_coordinate_transforms
[-help]
[-user]

Reports the transformations applied to the hierarchical SPEF instances to translate the hierarchical locations given in the SPEF files to the flat locations for the design.

Parameters

-help

Prints a brief description that includes type and default information for each report_parasitic_coordinate_transforms parameter.

For a detailed description of the command and all of its parameters, use the man command: man report_parasitic_coordinate_transforms.

-user

Reports user-specified transforms.
