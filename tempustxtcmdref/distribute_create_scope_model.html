Tempus Text Command Reference
Product Version 26.10, May 2026

distribute_create_scope_model

distribute_create_scope_model 
[-help] 
[-cell string]
[-cell_nohier string]
-dir <string>
[-exclude_cell string]
[-exclude_cell_contents]
[-exclude_instance string]
[-ignore_scope_fanouts]
[-instance string]
[-instance_nohier string]
[-nosettings]
[-overwrite]

Creates the scope from a full-chip run in DSTA mode.

Parameters

-help                        

Prints out the command usage.

-cell string           

Creates block-scope models for all instances of the specified cell
-cell_nohier string Creates top scope models for all instances of a cell.

-dir string             

Specifies the name of the directory for the writing scope.
-exclude_cell string

Excludes instances of the specified cells in the created scope.
-exclude_cell_contents Does not include the scope cell SPEF and Verilog in the generated scope.
-exclude_instance string Excludes the specified instances in the created scope.

-ignore_scope_fanouts        

Ignores fanouts of the scope.

-instance string           

Creates block scope models for the specified instances.
-instance_nohier string Creates top scope models for the instances.

-overwrite                   

Allows overwrite of the existing directory.

Examples 

  • The following command creates a scope model for all instances of cell hcell1 and writes the model files into the ./scope_dir directory:
    distribute_create_scope_model –dir ./scope_dir –overwrite –cell hcell1 

    Any existing directory contents are removed. If there are multiple instances of hcell1, a representative instance will be chosen for timing internal register-to-register paths. 
  • The following command creates a scope model for the single instance hcell1_inst1 and writes the model files into the ./scope_dir directory: 
    distribute_create_scope_model –dir ./scope_dir –instance hcell1_inst1 

    If the directory already exists, then an error is issued, and no scope model is created. 

  • The following command creates a scope model that includes the instances and nets in the top cell, along with the boundary paths of the hierarchical children:
    distribute_create_scope_model -dir ./scope_dir -overwrite -cell_nohier top_cell

  • The following command creates a scope model for top_cell, except that only the boundary paths are included for any child instances of the cell hcell1:
    distribute_create_scope_model -dir ./scope_dir -overwrite -cell top_cell -exclude_cell hcell1
