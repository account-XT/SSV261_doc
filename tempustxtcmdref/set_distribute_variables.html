set_distribute_variables

set_distribute_variables 
[-help]
list_of_variables
[value]

Allows you to set variables on the Tempus master and clients.

The variables can be set after issuing the distribute_read_design command on the master.

Parameters

-help Prints out the command usage.
list_of_variables Specifies a list of variables to be set on master and client(s).
value Specifies the value which should be set on the master and client.

Examples

  • The following command sets a variable var having value 1 on the master and client(s):
    tempus > set_distribute_variables var 1
  • The following command sets multiple variables with value 1 on master and client(s):
    tempus > set_distribute_variables "var1 var2 var3" 1
  • The following command sets multiple variables each with different values on master and client(s):
    tempus > set var1 1
    1
    tempus > set var2 2
    2
    tempus > set var3 3
    3
    tempus > set_distribute_variables "var1 var2 var3"
