rc_out

rc_out
[-help]
[-excludeIlm]
[-noRes]
{{{-spef file_name } [-excNetFile file_name | -net file_name | -netName list_of_nets]}}
[-useEEQCellWithLibertyInfo]
[-view view_name | -rc_corner rc_corner_name]
[-cUnit {pF | fF}]

Reads the parasitic database and outputs the parasitics in the Standard Parasitic Exchange Format (SPEF).

Parameters

-help Outputs a brief description that includes type and default information for each rc_out parameter. For a detailed description of the command and all of its parameters, use the man command: man rc_out.

-cUnit unit

Specifies the unit of capacitance as fF or pF in the output SPEF file.

Default: pF
-excludeIlm

Writes out only the top-level SPEF while excluding the ILM parasitics. For example,

rc_out -excludeIlm -spef abc.spef -rc_corner corner1

-excNetFile file_name 

Specifies the name of the file that contains nets to be excluded from the output file.

-net file_name

Specifies the name of the input file that contains the net names to be extracted.

Default: Extracts all net names
-netName list_of_nets

Specifies the names of the nets to be written in the SPEF file.

Default: Writes all nets
-noRes

Generates a SPEF/SPF file without the resistance information. The SPEF/SPF file generated by this parameter can only be used to improve the performance of third-party simulator tools in early stages of the design.

Caution: Most tools expect the resistance information to be present in the SPEF/SPF file for performing extraction. Therefore, SPEF/SPF files with no resistance information should not be used with ostrich for RC correlation.

-rc_corner rc_corner_name

Specifies the RC corner that is used to generate the parasitic output file in the multi-corner flow.

-spef file_name

Specifies the name of the SPEF output file.
-useEEQCellWithLibertyInfo Writes EEQ master cell in case the EEQ cells are present.

-view view_name

Specifies that the RC corner associated with the specified view is used to generate the output SPEF file in the multi-corner flow.

Example

  • Reads the parasitic database created during RC extraction and writes the interconnect capacitance in the SPEF format :
    tempus> rc_out -spef design.spef
