write_eco

write_eco
-help
-format {innovus tempus}
-hierarchical
-output <string> 
-prefix <string>
[-skip_non_eco_commands]

Logs ECO commands into an output file per file format. You can later load the files in the following ways:

  • Source the innovus format file in the Innovus tool
  • Source the tempus format file into the Tempus tool

The following commands can be appended to the report file:

  • add_net
  • delete_net
  • add_inst
  • delete_inst
  • attach_net
  • detach_net
  • attach_term
  • detach_term
  • change_cell
  • add_repeater
  • delete_repeater

Parameters 

-help

Outputs a brief description that includes type and default information for each write_eco parameter.

For a detailed description of the command and all of its parameters, use the man command:
man write_eco

-format {innovus tempus}

Generates an ECO file in the specified format.
-hierarchical Generate an ECO file for optimized partitions.

-output <string>

Specifies the name of the ECO file generated using this command.
-prefix <string> Specifies the prefix to be used in naming the output ECO file.
-skip_non_eco_commands Removes all non-ECO commands, which are not specified by the user, from the automatically generated ECO files.

Examples

  • The following command logs ECO commands into file Tempus.eco, in the tempus format:
    tempus> write_eco -format tempus -output Tempus.eco
  • The following command logs the ECO command into the file innovus.eco, in the innovus format:
    tempus> write_eco -format innovus -output innovus.eco
  • The following command removes all non-ECO commands from the automatically generated ECO file, opt_eco_tempus.tcl:
    write_eco -format tempus -output opt_eco_tempus.tcl -skip_non_eco_commands
