restore_db_keep_updated_macro_lefs

restore_db_keep_updated_macro_lefs {true | false}

Type: Boolean

Default: false

If set to true, the lef files of the updated macros that have been saved in DB would be honored, even if the new lef files are specified in read_design -lef_files {xxx} for these macros. If set to false, the lef files of updated macros in db would be ignored. Only the lef files that are specified in read_design -lef_files {xxx} would be updated.
