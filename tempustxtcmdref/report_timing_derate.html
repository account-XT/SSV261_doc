report_timing_derate

report_timing_derate
[-help]
[-delay_corner delayCornerName ]
[-include_inherited]
[ object_list ]
[{> | >>} filename [.gz]]

Reports delay scaling or derating factors for early and late clock and data paths in the current design.

By default, the report_timing_derate output shows pulse_width_check and clock_period_check details for instance objects (see set_timing_derate).

If you specify this command without any parameters, reports are generated for global derating factors for each instance, net, or cell for which derating is asserted.

The following reports are also generated:

  • In the best case, worst case, maximum, and minimum corner
  • Early values from the minimum corner and late values from the maximum corner in on-chip variation mode
  • In MMMC mode, specified corners, or for all corners when a corner is not specified
  • Power domains (if present in the design)

  • Derates for pulse width and clock period checks. Also, the report will show mean/sigma values when the set_timing_derate -mean/-sigma parameters are specified.

Parameters 

-help Prints out the command usage.

> | >> filename

When specified with >, writes the report to the specified file name. If the file already exists, the software overwrites it.

When specified with >>, writes the report to the specified file name. If the file already exists, the software concatenates the report to the end of the file.

Note: To write a compressed report, add the .gz extension to the file name.

-delay_corner delayCornerName

Reports the derating factors for the specified delay calculation corner only.

Default: Reports derating factors for all delay calculation corners.

-include_inherited

Reports the object names from which the derating factor values are inherited.

When specified, the report displays the name of the cell for each instance from which derate values are inherited.

object_list

Specifies the list of cells, nets, or library cells.

Examples

Here are some examples.

  • The following commands display global derating factors:
    tempus > set_timing_derate 1.2
    tempus > set_timing_derate -clock -early 1.1
    tempus > set_timing_derate -data -late 1.2
    tempus > report_timing_derate
