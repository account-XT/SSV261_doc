report_glitch_thresholds

report_glitch_thresholds
[-help]
[-failure_point {input | output}]
[-glitch_type <string>]
[-instance_pins <string>]
[-library_pins <string>]
[-list_unannotated_instance_pins]
[-list_unannotated_library_pins]
[-view <string>]

Reports user-defined glitch thresholds applied to library or instance pins. 

Parameters

-help                              

Prints out the command usage.

-failure_point {input | output}     

Specifies if the threshold failure point is input or output.

Default: input 

-glitch_type <string>        

You can specify one or more glitch types (space-separated) for reporting. The valid options are: vl,  vh, vlu, vho, and all.

When the -glitch_type parameter is specified, only the user-specified glitch types will be checked.  

Default: all

-instance_pins <string>      

Specifies a list of instance pin names.

-library_pins <string>   

Specifies a list of library pin names to be reported.

-list_unannotated_instance_pins

Reports list unannotated instance pins.

Reports all the instance input pins that do not have a glitch threshold applied.

-list_unannotated_library_pins

Shows a list of all the library input pins that are not covered by the library pin-based/corresponding library cell-based glitch threshold.

-view <string>            

Specifies the view name.
