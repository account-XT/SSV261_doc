set_filler_mode

set_filler_mode
[-help]
[-check_trim_rule {true|false}]
[-double_height_filler_insertion {true|false}]
[-enable_restore_filler_flow {true|false}]
[-reset]
[-core {{list-of-cells1} {list-of-cells2} ...}]
[-corePrefix prefix]
[-vt_swap_out_dir {vtSwapReportFileDirectory}]
[-vt_swap_out_file {file name}]
[-vt_swap_to_fix_filler_violations {true|false}]

Controls how the software deletes filler cells during eco_opt_design. The mode setting is persistent and saved along with the database when the save_design command is run. It is important to ensure that fillers can be removed by eco_opt_design; otherwise, there would be no legal location to insert buffers or resize instances.

Parameters

-help

Outputs a brief description that includes type and default information for each set_filler_mode parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_filler_mode.
-check_trim_rule {true|false}

Controls trim rule checking during the filler insertion. When set to true, the trim rule is checked, and the runtime increases.

Default: false
-double_height_filler_insertion {true|false}

Enables double-height filler during filler insertion. 
-enable_restore_filler_flow {true|false}

When this option is set to false,  fillers are not saved in the memory (which is the default, i.e, the save and restore filler insertion flow is default ON).

Default: true
-reset

Resets all or specified options to their default value.

-core {{list-of-cells1} {list-of-cells2} ...} 

Specifies the filler cells. Enclose the filler cell names in quotation marks (") or curly braces ({ }). You can specify multiple cell lists at one time, using curly braces ({ }) to separate each one.

Default: "" (empty string)

-corePrefix prefix

Specifies the prefix for the filler cells.

Default: "" (empty string)
-vt_swap_out_dir vtSwapReportFileDirectory

Specifies the directory of the vt swap report file,

Default: Current directroy ./
-vt_swap_out_file fileName

Specifies the file name of the vt swap report.

Default: ""
-vt_swap_to_fix_filler_violations {true|false}

Changes the VT of the functional cell to fix filler gaps.

Default: false

Examples

  • The following command specifies that filler instances of cells FILL64 and FILL8 have a prefix of ABC in the design.
    tempus> set_filler_mode -corePrefix ABC -core "FILL64 FILL8"

  • The following command lets eco_opt_design delete all filler cells that have a prefix FILL in their instance name.

    tempus> set_filler_mode -corePreFix FILL -core <List of Filler cells>
    tempus> eco_opt_design -setup
