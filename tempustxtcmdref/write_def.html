write_def

write_def 
[-help]
def_file
[-all_layers]
[-bump_as_pin]
[-output_mask_layers string] 
[-routing]
[-scan_chain]
[-unit integer]
[-wrong_way_routing_to_specialnet | -no_special_net]

Writes the specified information to a DEF file. By default, the write_def command writes floorplan, and all placed and unplaced standard cell information to the DEF file.

The write_def command does not support multiple groups per region. If you run Trial Route before you run the write_def command, the software does not write information about FIXED status wires to the DEF file. The write_def command supports rectilinear die area.

You can use the write_def command after importing a design.

Note: The write_def command cannot be used unless you include the Innovus license at startup. You can add one of the possible Innovus licenses by using the tempus -lic_startup_extra option when Tempus is started. 

Parameters

-help

Prints a brief description that includes the type and default information for each write_def parameter.

For a detailed description of the command and all of its parameters, use the man command:
man write_def.
-all_layers

Writes out wires, vias, and shapes on non-routing layers to the SPECIALNETS section. This includes the LEF MASTERSLICE layers, IMPLANT layers, and ROUTING or CUT layers with sub-types MIMCAP or PASSIVATION.

-bump_as_pin

Writes bump cells as top-level pins in the PINS section. If a PORT in a block has a PASSIVATION layer, the tool treats it as an embedded bump.

The -bump_as_pin parameter outputs all the layer information for embedded bumps in the PIN section as for normal bumps. 

def_file

Specifies the DEF output file.
-no_special_net

Excludes special net information from the DEF file.
-output_mask_layers string

Specifies the output MASK data on the specified layers only.

The valid values for this option are "metal", "cut", or a list of layers separated by a space character in a form of either a single layer or a range of layers. For example, -output_mask_layers {Metal1:Metal3 Via23} 

-routing

Writes the routing information to the NETS section of the DEF file. If the -routing option is not specified, both power and signal vias are not written to the DEF file.

-scan_chain

Writes scan chain information to the DEF file.

-unit integer

Defines the units for the DEF file.
-wrongway_routing_as_specialroute

Writes wrong-way routing in the SPECIALNETS section. 

This option duplicates any wrong-way routing segments that require extra-width into the SPECIALNETS routing section as a RECT with +SHAPE DRCFILL.

Examples

  • The following command writes bump cells as top-level pins in the PINS section of the test.def file:
    write_def -bump_as_pin test.def

    The PINS section in the test.def file is as follows:

    ++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
    PINS 102 ;

    - iot_schm_2m16m_3v + NET iot_schm_2m16m_3v + DIRECTION OUTPUT + USE SIGNAL

    + SPECIAL + POLYGON ap ( 93300 65970 ) ( 65970 65970 )

    ( 65970 93300 ) ( 27330 93300 ) ( 27330 65970 ) ( 0 65970 )

    ( 0 27330 ) ( 27330 27330 ) ( 27330 0 ) ( 65970 0 )

    ( 65970 27330 ) ( 93300 27330 ) + FIXED ( 386690 2658905 ) N ;

    - tck + NET tck + DIRECTION INPUT + USE SIGNAL

    + SPECIAL + POLYGON ap ( 93300 65970 ) ( 65970 65970 )

    ( 65970 93300 ) ( 27330 93300 ) ( 27330 65970 ) ( 0 65970 )

    ( 0 27330 ) ( 27330 27330 ) ( 27330 0 ) ( 65970 0 )

    ( 65970 27330 ) ( 93300 27330 ) + FIXED ( 53350 2658905 ) N ;

    +++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
