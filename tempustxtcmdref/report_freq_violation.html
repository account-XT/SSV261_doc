report_freq_violation

report_freq_violation
[-help]
[-detailed]
[-em_type {avg | peak | rms | all}]
[-excInstFile string]
[-outfile string]
[-reportFormat integer]
[-selInstFile string]
[-slew {min | max}]
[-sort {name | freq | minDiff | maxDiff | minFreq | maxFreq}]
[-tableScale float]
[-view string]

Runs electromigration (EM) analysis based on the frequency table defined in the Liberty library and generates a frequency violation report.

You must run the following commands prior to setting the report_freq_violation command:

  • write_tcf activityFile
  • read_activity_file -format TCF activityFile
  • propagate_activity
  • read_activity_file -set_net_freq true -format TCF activityFile
  • set_analysis_view -setup default_view_setup -hold default_view_hold
  • set_analysis_mode -checkType hold

Note: If activity files are not defined, the frequency can also be calculated on a pin by the clock period. There will also be a default frequency of 500M (toggle count 1e+9) if there is no clock phase on this pin.

Parameters

-help

 Prints a brief description that includes type and default information for each report_freq_violation parameter.

For a detailed description of the command and all of its parameters, use the man command:
man report_freq_violation.

-detailed

Generates a detailed report containing information about instances with frequency violations. The report includes per-instance details rather than just the summary statistics. It is particularly useful for debugging and root cause analysis as it provides instance-level information, expanded metrics, and sorting and filtering compatibility. The report generated by this parameter includes the following frequency violation values:

  • [V]: Represents the operating voltage applied to the instance during EM analysis.

  • [F]: Indicates the switching frequency or activity rate of the instance.

  • [P]: Represents the power consumption for the instance derived from the dynamic and leakage components.
-em_type {avg | peak | rms | all}

Specifies the electromigration analysis type to apply when reporting a frequency violation. This parameter determines the current stress model used for evaluating EM reliability. Use one of the following values with this parameter:

  • avg: Uses the average current over time to estimate the EM stress. Use this value for the nets with relatively stable current flow.
  • peak: Uses the maximum instantaneous current observed while reporting a frequency violation. This is the most appropriate value to be used for worst case analysis.
  • rms: Uses the root mean square (RMS) current, which accounts for variations and switching activity.
  • all: Reports results for all the above three values (avg, peak, and rms) in the same run for comprehensive analysis.

Default: avg

-excInstFile excInstFileName

 Specifies an instance file that lists the names of instances to be excluded from the frequency violation report.

Note: The instance file is a text file that contains a list of instances. Each instance name appears on a single line in the file. The comments begin with "#". Leading or ending spaces in instance names are ignored.

-outfile fileName

 Specifies the report file for the violation data.

-reportFormat integer

 Specifies a format for the violation report. The report details vary according to the selected report format. You can specify report formats 0, 1, or 2. For more information on the report formats, see the Report Format section below.

Default: 0

-selInstFile selInstFileName

 Specifies a file that lists the names of instances to be included in the frequency violation report.

Note: The instance file is a text file that contains a list of instances. Each instance name appears on a single line in the file. The comments begin with "#". Leading or ending spaces in instance names are ignored.

-slew {min | max}

 Specifies the minimum or maximum slew value.

Default: min

-sort {name | freq | minDiff | maxDiff | minFreq | maxFreq}

Sorts the instance-based frequency data by name, freq, minDiff, maxDiff, minFreq, and maxFreq. By default, the violation report is not sorted. You can use one of the following options:

    • name: Name of a pin or arc.
    • freq: Frequency value of a pin or arc.
    • minDiff: Difference between freq and minFreq of a pin or arc.
    • maxDiff: Difference between freq and maxFreq of a pin or arc.
    • minFreq: Minimum frequency value of a pin or arc as defined in the frequency table.
    • maxFreq: Maximum frequency value of a pin or arc as defined in the frequency table.
-tableScale float

Specifies the scale factor for the EM table value.

Default: 1.0

-view viewName

 Specifies the view for which to generate the frequency violation report. Use this parameter when working with multi-mode multi-corner (MMMC) designs.

Example

  • The following command reports instances that violate frequency constraints and lists them in the freqViol.rpt report file: 
    report_freq_violation -outfile freqViol.rpt

Report Format

The report formats are described below.

  • Format 0 
    The following command generates a report providing details of minFreq, Freq, Tran, Cap, Remark, and Arc/Pin and directs the output to the report file summaryViol.rpt:
    report_freq_violation -outfile summaryViol.rpt -reportFormat 0

    For example:
    minFreq    Freq    Tran     Cap        Remark    Arc/Pin
    5.985      1.009   0.0356   0.003103             tt0/data/r3/add_27/U1_1_6/Y
  • Format 1 
    When report_freq_violation -reportFormat is set to 1, the report provides details as shown in the following example:
    Status   Remark   freq   minFreq   maxFreq   Arc/Pin
    [P]      *        1.009  5.985     5.995     tt0/data/r3/add_27/U1_1_6/Y

  • Format 2
    A detailed report is generated when report_freq_violation-reportFormat is set to 2, as shown in the following example:
    Status  Remark  freq   minFreq  maxFreq    minTran    maxTran    minCap         maxCap     Arc/Pin
    [P]     *       1.009  5.985    5.995      3.560e-02  3.790e-02  3.103e-03      3.103e-03  tt0/data/r3/add_27/U1_1_6/Y

    Where:

    Status

    Arc or pin status - F (fail), V (violation), P (pass), or ? (unknown)

    Remark

    Indicates whether the pin is a clock

    freq

    Working frequency of the arc or pin

    minFreq

    Minimum frequency value taken from the frequency table

    maxFreq

    Maximum frequency value taken from the frequency table

    minTran

    Minimum slew value

    maxTran

    Maximum slew value

    minCap

    Minimum capacitance load

    maxCap

    Maximum capacitance load
    Arc/Pin Name of the arc or pin
