timing_enable_sdc_compatible_data_check_mcp

timing_enable_sdc_compatible_data_check_mcp
{true | false}

Default: false

Data_type: Boolean

Enables checking for SDC compatible data checks when set_multicycle_path -start parameter is specified.

When set to true, the -start parameter shifts (or reverses) the reference clock back by one clock cycle.

When set to false, the set_multicycle_path -start and -end parameters use the same number of cycles, even though the actual adjustment is computed using the signal clock for -start and reference clock for -end parameters. Additionally, the software computes adjustments for set_data_check -hold checks between multiple frequency clocks with the set_multicycle_path -start -setup setting.

To set this global variable, use the set_global command.
