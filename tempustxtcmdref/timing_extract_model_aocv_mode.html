timing_extract_model_aocv_mode

timing_extract_model_aocv_mode {graph_based | path_based | none}

Default: none

Data_type: Enum

Range: {none graph_based path_based}

Allows you to set the AOCV derating mode.

The valid values are described below:

    • graph_based: Specifies that the delays in the timing model are derated using the graph-based stage counts.
    • path_based: Specifies that the delays in the timing model are derated using the total path stage count of worst path between those pin pairs.
    • none: Specifies that the delays in the timing model are non-AOCV derated base delays.
       

Note: Before setting this global to graph_based or path_based mode, it is mandatory that the AOCV libraries are read in and AOCV analysis is enabled (by setting set_analysis_mode -aocv true).

To set this global variable, use the set command.
