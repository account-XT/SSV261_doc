reset_clock_transition

reset_clock_transition 
[-help]
clock_list

Removes the clock transition assertions you had set on the specified list of clock waveforms.

Parameters 

-help Prints out the command usage.

clock_list

Specifies a list of clock waveforms for which the clock transition assertions are removed. The clock_list variable can be a Tcl list or collection of clock waveforms.
