report_bundled_bus

report_bundled_bus
[-help]
[-name string]
[-nets string]
[-type {user_defined | tool_inferred}]
[[ > | >> ]]

Generates a report for bundled buses.

Parameters

-help                                                                  

Prints out the command usage.

-name string                                                

Specifies the name of the user-defined bus group(s) to be reported.

-nets string                                                 

Specifies the name of the net(s) to be reported.

-type {user_defined | tool_inferred}          

Reports the type of bundled bus(es) - user-defined or tool-inferred - to include in the report.

By default, the report_bundled_bus command generates reports for both user-defined and software-inferred types of buses.

> filename                                       

Redirects the output to the specified file.

>> filename                                       

Appends to the specified output file.

Examples

  • The following command shows the user-defined bus groups:
