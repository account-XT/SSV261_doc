get_delay_cal_mode

get_delay_cal_mode
[-help]
[accuracy_level]
[-advanced_pincap_mode]
[-accurate_receiver_out_load]
[-combine_mmmc]
[-disable_randomcell_in_socv]
[-early_irdrop_data_type]
[-enable_accurate_lle_analysis]
[-enable_corner_based_beol]
[-enable_high_fanout]
[-enable_input_slew_sensitivity_on_constraint]
[-enable_quiet_receivers_for_hold]
[-equivalent_waveform_model] 
[-equivalent_waveform_model_for_timing_check]
[-honorSlewPropConstraint]
[-library_interpolation_mode]
[-nonDefault]
[-reportOutBound] 
[-SIAware]
[-skip_slew_merge_from_disabled_path]
[-slewOutBoundLimitHigh]
[-slewOutBoundLimitLow] 
[-socv_lvf_mode]
[-socv_use_lvf_tables]
[-quiet]

Returns the current settings of the set_delay_cal_mode command. The following information is displayed: 

  • Parameter name
  • Current value of the parameter
  • Type (Boolean, string, and so on)
  • Information on whether the parameter value is user-defined or default.

If you do not specify any parameter, the software displays the current settings of all the set_delay_cal_mode command parameters.

Parameters 

-help

Outputs a brief description that includes type and default information for each set_delay_cal_mode parameter. For a detailed description of the command and all of its parameters, use the man command: man get_delay_cal_mode.

parameter_names

Displays information for the specified parameters.

See the set_delay_cal_mode command for descriptions of the parameters that you can specify.

-quiet

Displays the current settings of the specified parameters in Tcl list format.

If you specify -quiet without any other parameters, the software displays the current settings of all the set_delay_cal_mode parameters in Tcl list format.

Examples

  • The following command displays the current settings of the set_delay_cal_mode -combine_mmmc parameter: 
    tempus> get_delay_cal_mode -combine_mmmc

    The following information is displayed:
    -combine_mmmc early_late # enums={none early_late}, default=early_late
    early_late
  • The following command displays the current settings of all the set_delay_cal_mode parameters:
    tempus> get_delay_cal_mode -quiet
