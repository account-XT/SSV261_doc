timing_report_analysis_summary_csv_extended_new_format

timing_report_analysis_summary_csv_extended_new_format
{true | false}

Default: false

Data_type: Boolean

Keeps the analysis summary CSV extended report in sync with the summary timing report. These reports are available when the respective report_timing parameters are specified:

  • -analysis_summary_csv_extended_file
  • -analysis_summary_file

When set to true (and when the report_timing -analysis_summary_csv_extended_file parameter is specified), the column name sequence will be from fromClk to toClk, that is, fromClk will be printed first, and then toClk. Also, the timing report will show "-", if toClk or fromClk is not present (and when report_analysis_summary -expanded_summary_clocks is set to false).

When set to false, the missing toClk or fromClk column will be represented as “*”.

To set this global variable, use the set command.
