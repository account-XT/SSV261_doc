highlight_timing_report

highlight_timing_report
[-help]
[-append]
[-color_index integer]
[-file filename ] 
[-noarrow]
[-path path_number | -all]

Highlight the selected paths in the user interface.

For more information on timing debug categories,  see the 'Appendix - Timing Debug GUI' chapter in the Tempus User Guide.

Parameters

-help

Outputs a brief description that includes type and default information for each highlight_timing_report parameter.

For a detailed description of the command and all of its parameters, use the man command:
man highlight_timing_report
-all Highlights all the path in the Global Timing Debug through the user interface.
-append Appends a path to the current highlight.
-color_index integer Specifies the path's color index on a scale of 1 to 8.

-file filename

Name of the file. The option is of type string and optional.

-noarrow

Removes the highlighted arrow. The option is of type boolean and optional.

-path path_number

Specify the number of the path. The option is of type string and required.

Examples

The following commands generate the worst 1000 paths to a machine readable report, and then highlight the top five paths in Global Timing Debug:

report_timing -machine_readable -max_points 1000 > foo.mtarpt 
load_timing_debug_report foo.mtarpt 
highlight_timing_report -file foo.mtarpt -path "1 2 3 4 5" -noarrow
