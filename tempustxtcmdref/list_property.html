list_property

list_property
[-help]
[-type {cell clock design lib lib_cell lib_pin lib_timing_arc net path_group pin port timing_arc timing_path timing_point pg_net pg_pin lib_pg_pin si_victim si_attacker}]

Lists all of the properties associated with the specified object type.

If you do not specify any object type, this command lists all the supported object types and all the properties associated with those object types.

Parameters

-help Prints out the command usage.

-type object_type

Lists the properties associated with the specified object type. The following object types are supported:

cell, clock, design, lib, lib_cell, lib_pin, lib_timing_arc, net, path_group, pin, port, timing_arc, timing_path, timing_point, pg_net, pg_pin, lib_pg_pin, si_victim, si_attacker

Additional SI properties can be included with the timing_point object. To enable SI properties, you can set the timing_report_enable_si_debug global variable to true.
