read_def

read_def 
[-help]
[<defFile>]
[-force_create_phy_inst]
[-keepPinGeometry]
[-preserve_shape]
[-rdl_def <string>]
[-rdl_orientation <orientation>] 
[-rdl_placement <(x y)>]
[-read_flat_data <dir>]
[-skip_pg]
[-skip_signal]
[-top]
[-top_scope]
[-topcell_orientation <orientation>]
[-topcell_placement <(x y)>]
[-write_flat_data <dir>]

Reads a single DEF file. This command can be used to supply single DEF to generate a physical database.

The read_def command cannot read multiple or hierarchical DEF files. To read multiple or hierarchical DEF files and create a flattened database, use the merge_hierarchical_def command.

The read_lib -lef command is required in order to load DEFs. This command should never include LEF definition of the block level partitions. It should only include LEF definition for primitive cells like standard cells, IOs and memories.

Note: All hierarchical DEFs are passed to power and rail analysis without flattening and processed by Power Analysis and Rail Analysis engines separately. The flattened DEF is only used for display of layout in the GUI. The flattened DEF should not be used for analysis.

Parameters

-help                                 

Prints out the command usage

<defFile>                         

Specifies the def file to be read.

-force_create_phy_inst                

Specifies to force create physical cell instances

-keepPinGeometry                      

Keeps pins shapes equivalent to the block pin shapes, in the form of special route
-preserve_shape Preserves the shape of pins.

-rdl_def <string>                     

Specifies RDL def file.

-rdl_placement (x y)               

Specifies offset of RDL def.
-rdl_orientation <orientation> Specifies orientation for RDL def.

-read_flat_data <dir>                 

Reads flat data from the specified directory.
-skip_pg Skips merging routing on pg nets.

-skip_signal                          

Skips reading signal nets.

-top                                  

Reads DEF files with the same top cell name.
-top_scope Merges routing on top scope nets only.

-topcell_orientation <orientation>    

Specifies orientation for topcell.

-topcell_placement (x y)            

Specifies placement for topcell.

-write_flat_data <dir>                

Writes flat data to the specified directory.

Examples

  • The following command reads the compressed DEF file dma_mac_filled.def.gz:
    tempus > read_def dma_mac_filled.def.gz
