get_metric

get_metric 
-help
<pattern>
[-branch list_of_patterns]
[-exclude_inherited]
[-id id_name] 
[-names label_name] 
[-pending] 
[-pending_top]
[-raw]

Gets the current state of metric(s). 

You can use this command to query the current state of any metric or metrics from the current specified list of metrics as well as a previous state. 

Parameters

-help

Outputs a brief description that includes type and default information for each get_metric parameter.
For a detailed description of the command and all of its parameters, use the man command:

man get_metric
-branch list_of_patterns

Specifies list of patterns to match snapshot branches.

This will limit all output to metrics stored in snapshots whose branch matches the specified branch. This requires any inheritance to be re-run to exclude inherited values from non-matching snapshots.
-exclude_inherited Specifies not to return any inherited value.
-id id_name Specifies the database ID to output. Default is current database.
-names label_name

List of patterns to match snapshot names

Name of label to get metrics from (wildcards supported); no label reports current metrics
<pattern>

Specifies the list of patterns to match metrics.

Supports wildcard *. Use of * gets all metrics
-pending Returns metrics from the pending (not yet created) snapshot.
-pending_top Returns metrics from the entire pending (not yet created) snapshot stack.
-raw Returns metrics as raw value (without normalization to defined units).
