report_mutex_condition

report_mutex_condition
[-help]
[-filename <string>]
[-net <string>]

Reports mutex nets of a victim net.

When this command is used, all coupled nets participating in the mutex for a victim are reported. The coupled nets will be reported as a group of mutex nets (user-defined). By default, all the mutex conditions are reported.

Parameters 

-help Prints out the command usage.
-filename <string>  

Specifies the name of the file that saves the command output results.
-net <string> 

Reports the coupled nets mutex to the specified net name.

You can specify multiple net names with multiple report_mutex_condition commands.

Examples

  • The following example shows the mutex nets of a victim net. This report does not indicate the attackers not listed due to the mutex command:

    Vic: Net1
    Attackers: Att1, Att2, Att3
    set_mutex_condition {Att1, Att2 }
    set_mutex_condition {Att2, Att3 }
    set_mutex_condition {Att1, Att3 }

    report_mutex_condition -net Net1 will report:

    - Victim Net: Net1
    Mutex groups:
    {Att1, Att2 },
    {Att2, Att3 },
    {Att1, Att3 }

  • The following example shows that if a coupled net has an LC chain, then the entire chain will be reported along with other mutex group nets:

    Vic: Net1
    Attackers: Att1, Att2, Att3
    Att1 chain: Agg1 Agg11 Agg111
    Att2 chain: Agg2 Agg22 Agg222
    Att3 chain: Agg3 Agg33 Agg333
    set_mutex_condition {Att1, Att2 }
    set_mutex_condition {Att2, Att3 }
    set_mutex_condition {Att1, Att3 }

    report_mutex_condition -net Net1 will report:

    - Victim Net: Net1

    Mutex groups:
    {{ Agg1 Agg11 Agg111 }, { Agg2 Agg22 Agg222}}
    {{ Agg2 Agg22 Agg222}, { Agg3 Agg33 Agg333}}
    {{ Agg1 Agg11 Agg111 }, { Agg3 Agg33 Agg333}}
