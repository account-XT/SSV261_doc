set_multi_input_switching_mode

set_multi_input_switching_mode
[-help]
[-disable_lib_cells <string>]
[-mis_alignment_mode {0 | 1}]
[-switching_alignment_factor <float>]
[-view <string>]

Configures multi-input switching (MIS) mode settings.

You can enable the MIS feature using the set_analysis_mode -multi_input_switching_mode command parameter.

For reporting advanced MIS in delay calculation and delta delay in timing reports, you can use the following options:

    • report_delay_calculation -mis
    • report_timing -format retime_mis_delta
    • report_timing_format {retime_mis_delta}

Parameters

-help

Prints out the command usage.
-disable_lib_cells <string>

Enables or disables the multi-input switching (MIS) mode support for the specified library cells.

Default: " "
-mis_alignment_mode {0 | 1}  

Controls the MIS alignment mode. 

Default: 0
-switching_alignment_factor <float>

Allows to configure the relative alignment of side inputs switching with respect to the primary inputs. The switching alignment factor is applied for all the instances for which MIS analysis is to be performed.

This parameter accepts values between -1 and 1. These are described below:

  • 1: Side inputs switch at the earliest arrival.
  • 0: Side inputs switch at the same time as the actual input.
  • -1: All the side inputs switch at the same time and align at the completion of the output pin transition.

Default: 0

Note: Setting the -switching_alignment_factor to 1 can be pessimistic if a side input switches much earlier than the main input. You can use the -mis_alignment_mode parameter to reduce pessimism in this mode.
-view <string>

Specifies the name of the view.

Examples

  • The following commands disable MIS support for the specified library cells: 
    set_multi_input_switching_mode -disable_lib_cells [get_libs_cell aoi*]
    set_multi_input_switching_mode -disable_lib_cells [get_libs_cell lib_0.510v/aoi*]
