Tempus Text Command Reference
Product Version 26.10, May 2026

set_limited_access_feature


set_limited_access_feature
[-help]
featureName
{1 | 0}

Enables or disables a limited-access feature.

The Tempus software provides certain limited-access features that showcase advanced technology integrated into the software. These features have been internally qualified at Cadence but have had only limited customer testing. 

Note: Limited-access features are enabled by a variable specified through the set_limited_access_feature command. To use the limited-access features, you can contact your Cadence representative to qualify your usage and ensure your requirements are met before deploying them widely.

Parameters

-help

Prints a brief description that includes type and default information for each set_limited_access_feature parameter.

For a detailed description of the command and all of its parameters, use the man command:
man set_limited_access_feature

featureName

Specifies the name of the variable that enables the limited access feature.
{1 | 0}

Enables/disables a feature - 1 enables a feature, 0 disables a feature.
