set_aging_analysis_mode

set_aging_analysis_mode 
[-help]
[-activity_propagation_mode {probabilistic | worst_case}]
[-constraints {true | false}]
[-disable_aging]
[-max_duty_cycle <value>]
[-max_toggle_rate <value>]
[-max_toggle_rate_limit <value>]
[-min_duty_cycle <value>]
[-min_toggle_rate <value>]
[-param_priority_sets <string>]
[-recovery {true | false}]
[-sequential_activity_propagation {true | false}]
[-sequential_max_duty_cycle <value>]
[-sequential_max_toggle_rate <value>]
[-sequential_min_duty_cycle <value>]
[-sequential_min_toggle_rate <value>]
[-type {bti | hci | all}]
[-use_fixed_duty_cycle {true | false}]
[-views <string>]

Sets the aging analysis-related global variable settings and defaults.

By default, all signals in STA are assumed to have a 50% duty cycle at primary pins. The duty cycle for clock waveforms can be specified in the SDC. The same duty cycle is assumed at every clock pin associated with that waveform. You can override the duty cycle defaults for primary ports and force duty cycles on specific nets in the design.

Starting from the initial default values (and user overrides), Tempus propagates the duty cycle throughout the logic. 

Parameters

-help                                 

Prints out the command usage.

-activity_propagation_mode
{probabilistic | worst_case}

Specifies the activity (duty cycle and toggle rate) propagation mode - probabilistic or worst_case.

Default: probabilistic

-constraints {true | false}             

Enables the aging constraints.

Default: false

-disable_aging

Disables aging analysis.

-max_duty_cycle <value>               

Specifies the default maximum duty cycle.

Default: 1

Min: 0, Max: 1

-max_toggle_rate <value>              

Specifies the default maximum toggle rate (number of transitions per second).

Default: 100000000

Min=0, Max=3.40282346638529e+38
-max_toggle_rate_limit <value>

Specifies the maximum toggle rate limit.

Default:=3.40282346638529e+38

Min=0, Max=3.402

-min_duty_cycle <value>               

Specifies the default minimum duty cycle.

Default: 0

Min: 0, Max: 1)

-min_toggle_rate <value>              

Specifies the default minimum toggle rate (number of transitions per second).

Default: 0

Min: 0, Max: 3.40282346638529e+38)

-param_priority_sets <string>

Specifies an ordered list of lists of additional aging parameters to be used across all views, e.g., { {p1 p2 p3} {q1 q2} }; parameters from the aging library will always have the highest priority.

-recovery {true | false}                

Enables the aging recovery analysis.

Default:  true

-sequential_activity_propagation {true | false}

Enables the activity propagation through sequentials.

Default: false

-sequential_max_duty_cycle <value>

Specifies the default sequential maximum duty cycle.

Default: 1

Min: 0, Max: 1

-sequential_max_toggle_rate <value>   

Specifies the default sequential maximum toggle rate (number of transitions per second).

Default=100000000

Min: 0, Max: 3.40282346638529e+38

-sequential_min_duty_cycle <value>    

Specifies the default sequential minimum duty cycle.

Default: 0

Min: 0, Max: 1

-sequential_min_toggle_rate <value>   

Specifies the default sequential minimum toggle rate (number of transitions per second).

Default: 0

Min: 0, Max=3.40282346638529e+38)

-type {bti | hci | all}                   

Specifies the type of aging analysis - bti, hci, or all.

Default: all

-use_fixed_duty_cycle {true | false}    

Enables the fixed duty cycle instead of the propagated duty cycle for aging

Default: false

-views <string>

Specifies a list of view names for the defined settings.

Examples

  • The following command sets the minimum and maximum toggle rate on ports and special nets. This should be specified when HCI analysis is enabled in the flow:
    tempus > set_aging_analysis_mode -min_toggle_rate 1e+09 -max_toggle_rate 1e+09
  • The following command sets the toggle rate on sequential cells' output pins. This should be specified when HCI analysis is enabled in the flow:
    tempus > set_aging_analysis_mode -sequential_min_toggle_rate 1e+09 -sequential_max_toggle_rate 1e+09
  • The following command models recovery for OMI and URI Spice models that are recovery-aware:
    tempus > set_aging_analysis_mode -recovery true
  • The following command specifies the minimum and maximum toggle rate and duty cycle for probabilistic propagation mode:
    tempus > set_aging_analysis_mode -activity_propagation_mode probabilistic \
    -min_toggle_rate 1e9 -max_toggle_rate 1e9 -min_duty_cycle 0 -max_duty_cycle 0.2
