set_ptm_port_drive

set_ptm_port_drive
-type drive_type
[-input_slew_rise rise_slew_value]
[-input_slew_fall fall_slew_value]
port_list

Sets the drive for the output and bidirectional ports. The drive_type specifies the type of cell within the model as drivers on the interface nets. You cannot specify two different drivers for two timing arcs ending at the same output port.

Parameters 

port_list

Specifies the name of the output or bidirectional port.

Note: This parameter allows you to specify a list of patterns for port names using wildcard characters.

-input_slew_fall fall_slew_value

Overrides the fall transition value specified with the
-input_slew_fall option of the create_ptm_drive_type command.

-input_slew_rise rise_slew_value

Overrides the rise transition value specified with the
-input_slew_rise option of the create_ptm_drive_type command.

-type drive_type

Specifies the drive type to use for the timing model.

Examples

  • The following command sets the stdDrive drive to be used on the output data port data_out:
    tempus> set_ptm_port_drive -type stdDrive data_out
