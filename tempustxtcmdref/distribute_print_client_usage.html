distribute_print_client_usage

distribute_print_client_usage
[-help]

Reports CPU time, real time, current memory, and peak memory for all the clients. This command must be used instead of report_resource, which cannot run in DSTA mode.

Parameters

-help

Outputs a brief description that includes type and default information for each distribute_print_client_usage parameter.

For a detailed description of the command and all of its parameters, use the man command: man distribute_print_client_usage.
