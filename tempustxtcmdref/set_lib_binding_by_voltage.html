set_lib_binding_by_voltage

set_lib_binding_by_voltage
[-help]
[-default_power_net string]
[-early_dynamic_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...}]
[-late_dynamic_power_net_voltages string]
[-process float]
[-temperature float] -power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} | {-early_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} -late_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...}} | {-data_early_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} -data_late_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} -clock_early_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} -clock_late_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...}}

Initiates auto-inferencing of power intent, library binding, and view definition. It also provides voltages for each power net in the design. Use this command to assert voltages for power rails. This command creates the view definition file for single corner analysis and assigns the operating voltage for each power domain accordingly. It also creates library sets for each power domain based on the assigned PVT and associates the corresponding library set for the power domains.

Parameters

-help

Outputs a brief description that includes type and default information for each set_lib_binding_by_voltage parameter. For a detailed description of the command and all of its parameters, use the man command: 

man set_lib_binding_by_voltage
-clock_early_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} Assigns power net voltage for early corner of the clock path.
-clock_late_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} Assigns power net voltage for late corner of the clock path.
-data_early_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} Assigns power net voltage for early corner of the data.
-data_late_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} Assigns power net voltage for late corner of the data.
-default_power_net string Specifies the default power net.
-early_dynamic_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...}

Specifies whether the software uses power‑net voltage values during early-stage dynamic power analysis. When this parameter is specified, the software considers power‑net voltages while estimating dynamic power in early stages of the flow.

This parameter is intended for early power analysis scenarios where approximate power‑net voltage information is available.
-early_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} Assigns power net voltage for early corner.
-late_dynamic_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...}

Specifies whether the software uses power‑net voltage values during late-stage dynamic power analysis. When this parameter is specified, the software considers power‑net voltages while estimating dynamic power in later stages of the flow.

This parameter is intended for late power analysis scenarios where approximate power‑net voltage information is available.
-late_power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} Assigns power net voltage for late corner.
-power_net_voltages {pwr_net1@volt1 pwr_net2@volt2 ...} Assigns power net voltage.
-process float Defines filtering condition for the timing library characterized process.
-temperature float Defines filtering condition for timing library characterized temperature.
