set_ipd_rail_voltage

set_ipd_rail_voltage 
[-help]
[-exclude_voltage_signatures <List of combinations to be excluded>]
[-add  | -sweep <List of power rails and corresponding voltage sweep list>]

Specifies the PG net voltage and excludes those voltage combinations that do not require analysis. When power intent is specified through CPF/IEEE-1801, the set_ipd_rail_voltage specification refers to the primary power net of the power domain.

Parameters

-help   

Prints out the command usage.

-add    

Specifies with the -exclude_voltage_signatures parameter to exclude voltage combinations incrementally.

-exclude_voltage_signatures <List of combinations to be excluded>

Specifies the list of voltage combinations to be excluded from all the possible combinations of voltage.

-sweep <List of power rails and corresponding voltage sweep list>

Specifies the list of power rails and their corresponding voltage values.

Examples

  • The following command is used to specify the PG nets in the design and the corresponding voltages (in volts):
    tempus > set_ipd_rail_voltage -sweep { PGN1 {0.7 0.8} PGN2 {0.9 1.0} PGN3 {1.1 1.2} PGN4 {0.6 0.7} }
  • The following command removes a particular combination from the analysis:
    tempus > set_ipd_rail_voltage -exclude_voltage_signatures { {PGN1 0.7 PGN2 0.9 PGN3 1.2 PGN4 0.6} }
  • The following command excludes more combinations:
    tempus > set_ipd_rail_voltage -exclude_voltage_signatures { {PGN1 0.7 PGN2 0.9 PGN3 1.2 PGN4 0.7} } -add
