report_instance_cdb

report_instance_cdb 
[-help]
[-analysis_type {early | late}]
[{instance_list or collection}]
[-output_file filename]
[-quiet]
[-view viewname]

Allows you to report the cdB for all instances or a subset of instances in a design.

Note: This command must be issued after report_timing, update_timing, or update_glitch commands.

Parameters

-help Outputs a brief description that includes type and default information for each report_instance_cdb parameter. For a detailed description of the command and all of its parameters, use the man command: man report_insance_cdb
-analysis_type {early | late} Specify the analysis type for the query.
Default: late
instance_list or collection Specify the instance for which the cdB association is desired. By default, the cdB association for all the instances is reported.
-output_file filename  Specify the output filename for the instance report. By default, the report output is displayed on the screen.
-quiet Suppresses warning messages for cells missing in CDB files.
-view {viewnames}

Specifies the view names. By default, all views are reported.

Examples

  • The following command reports the cdB instance connection for all the instances in the design and writes it to the inst_cdb.rpt file:
    tempus > report_instance_cdb –output_file inst_cdb.rpt
  • The following command reports the cdB instance connection for the u5 instance to the screen:
    tempus > report_instance_cdb u5

    VIEW: default_emulate_view -- ANALYSIS TYPE: late
    u5 : inv_t1 : test1.cdb.txt
  • The following command reports the cdB instance connection for the early analysis type for the u5 and u6 instances
    tempus > report_instance_cdb –analysis_type early {u5 u6}

    VIEW: default_emulate_view -- ANALYSIS TYPE: early
    u5 : inv_t1 : test1.cdb.txt
    u6 : inv_t2 : test2.cdb.txt
