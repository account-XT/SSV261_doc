write_ipd_scope

write_ipd_scope 
[-help]
[-context_only]
[-exclude <string>]
[-include <string>]
[-scope_data <string>]
[[[-bounded_corners ] [-include_derates ] [-include_constraints] [-overwrite ] [<dir_name>]] | [[-early_structural_checks <string>] [-out_file_prefix <string>] [-power_domain_count_threshold <integer>]] | [-write_all_paths <string>]]

Writes out the IPD scope in the scope creation run. The scope is generated in the directory location specified as the command argument. 

This command is used to write out the IPD Scope in the scope creation run. The scope is generated in the directory location specified as a command argument, which provides options to control whether constraints and derates are to be written out in the scope or not.

Parameters

-help                          

Prints out the command usage.

-context_only

Re-generates constants that will be a part of context data.

-early_structural_checks <string>

Specifies the early check types to be performed.

The valid values are:

  • clock_divergence
  • multiple_pd_data_paths
  • multiple_pd_clock_paths
  • multiple_pd_paths

-exclude <string>

Specifies the netlist exclusions. The supported options are clock, port, async, scanchain, and <$list_of_PD_combinations>.

-include <string>

Specifies the netlist filter inclusions - the supported options are:

  • equivalent_power_domains
  • internal_power_domains
  • timing_disabled_network
  • equivalent_supply_voltage

-include_constraints

Allows the IPD scope to be written with victim constraints.

-include_derates 

Allows the IPD scope to be written with timing derates.

<dir_name>                  

Specifies the output directory containing partial Verilog and partial SPEF, or marking data, and context data.

-bounded_corners        

Generates a bounded corner scope based on the minimum/maximum voltage combination analyzed in the scope creation run.

By default, the software writes out the maximum voltage combination details in the scope if this parameter is not specified in the bounded corner run.

-scope_data <string>

Specifies the scope data to be written from the minimum or maximum voltage combination.

-out_file_prefix <string>

Specifies the outfile for structural checks.

-overwrite

Overwrites the already present directory's content with the new content.

-power_domain_count_threshold <integer>

Specifies the threshold for the power domain count reported using the multiple_pd_paths option.

-write_all_paths <string>

Writes all the IPD paths and uses the name of the path descriptions' file.

Examples

  • The following command generates a bounded corner scope based on the minimum/maximum voltage combination analyzed in the scope creation run:
    tempus > write_ipd_scope -bounded_corner -overwrite bounded_corner_scope

    This command writes out the derates and constraints in the IPD scope, and overwrites an existing scope generated with the same directory name argument.
