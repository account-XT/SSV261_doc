Tempus Text Command Reference
Product Version 26.10, May 2026

write_sdc

write_sdc
[-help]
[-clocks <string>]
[-commands <string>]
filename
[-exclude_annotated <string>]
[-path_adjust_only]
[-path_group_only]
[-pins <string>]
[-sdc]
[-view <string>]
[-vt_skew_derate_only]

Generates the timing constraints file in a third-party compiler format.

Parameters 

-help Prints out the command usage.
-clocks <string>

Specifies the name of the clocks to be included in the SDC file.
-commands <string> Specifies the name of the commands to be included in the SDC file.

-exclude_annotated string

Disables listing of annotated constraints. You can specify one of the following options:

  • delays: Suppresses dumping of set_annotated_delay constraints.
  • checks: Suppresses dumping of set_annotated_check constraints.
  • transitions: Suppresses dumping of set_annotated_transition constraints.

filename

Specifies the name of the constraints file. By default, the constraint file is generated in the current directory. To save to a different directory, you need to specify the complete path.
-path_adjust_only

Exports set_path_adjust_group and set_path_adjust constraints.
-path_group_only Exports group_path constraints.
-pins <string> Specifies the name of the pins to be included in the SDC file.

-sdc

Produces an SDC file in which functions for manipulating collections are expanded. For example, the remove_from_collection all_inputs, all_outputs, all_clocks, and filter commands are replaced by the resulting list of objects.

Note: When you specify the -sdc parameter, a warning is issued stating that using the parameter produces a constraint file containing SDC standard constraints only. This may cause some design constraints to be dropped.

-view string

Specifies a view name to obtain the desired SDC.

-vt_skew_derate_only

When specified, the software will check the voltage threshold (VT) skew configuration and report the VT skew derate details as per the voltage groups defined.

Command Order

Use this command after reading in a timing constraints file.

Examples

  • The following command generates a constraints file, newc, and saves the generated file in the directory new:
    tempus> write_sdc new/newc
  • Specifying the following constraints will have new entries in the output constraints file:
    tempus> set_annotated_delay -from u1/A -to u1/Y -cell 2
    tempus> set_annotated_check 2 -setup -from f0/CK -to f0/D

    The write_sdc output will be as follows:

    set_annotated_delay -cell 2 -from [get_pins {u1/A}] -to [get_pins {u1/Y}]
    set_annotated_check -setup -from [get_pins {f0/CK}] -to [get_pins {f0/D}] 2
  • For the following constraints in the design :
    tempus> set_annotated_delay -from u1/A -to u1/Y -cell 2
    tempus> set_annotated_transition 2 u1/A
    tempus> set_annotated_check 2 -setup -from f0/CK -to f0/D

    The write_sdc -exclude_annotated delays output will be as follows:

    set_annotated_transition 2 [get_pins {u1/A}]
    set_annotated_check -setup -from [get_pins {f0/CK}] -to [get_pins {f0/D}] 2
    The write_sdc -exclude_annotated {delays transitions} command outputs the following:
    set_annotated_check -setup -from [get_pins {f0/CK}] to [get_pins {f0/D}] 2
