set_dont_touch

set_dont_touch 
[-help]
object_list 
[{true | false}]

Prevents the specified object from being modified during optimization.

When the set_dont_touch command is set to true, the specified nets cannot be buffered or become part of the logic cone restructuring. However, you can resize the instances connected to this net because the set_dont_touch attribute does not affect the connected instances.

Parameters 

-help Prints out the command usage.

{true | false}

Sets or removes the set_dont_touch attribute for the specified list of objects.

Default: true

object_list

Specifies the collection or list of instances, library cells, nets, or sub-modules.

Examples

  • The following command prevents the specified instance from being modified:
    tempus > set_dont_touch [get_cells {TWA/FF1}]

  • The following commands prevent the specified net from being modified and check the setting with get_property:
    tempus > set_dont_touch clk1_net
    tempus > get_property [get_nets clk1_net] dont_touch true

  • The following commands can be used to prevent any ECO inside RESULTS_CONV_INST hierarchical instance: 
    set_dont_touch [get_cells RESULTS_CONV_INST/*] true
    set_dont_touch [get_nets RESULTS_CONV_INST/*] true

    The set_dont_touch RESULTS_CONV_INST/* true command will return [get_cells RESULTS_CONV_INST/*] only. This is because the software looks into the first match (type of object). If a match is not found, then the successive objects are searched.
