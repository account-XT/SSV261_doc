create_aging_stress_profile

create_aging_stress_profile 
[-help]
[-views {views}]
[-early]
[-late] 
[-bti_pmos_scale <scale_val>] 
[-bti_nmos_scale <scale_val>] 
[-hci_pmos_scale <scale_val>] 
[-hci_pmos_scale <scale_val>] 
{segment1 segment2 …}

Defines the stress profile for aging-aware STA. The profile contains stress duration, stress temperature, and stress voltage per power rail.

You can apply different stress profiles to different views and to early/late timing. 

Parameters

-help

Prints out the command usage.

-early

Specifies the early timing path.

-late

Specifies the late timing path.

-bti_pmos_scale <scale_val>

Specifies the BTI PMOS scale value.

-bti_nmos_scale <scale_val>

Specifies the BTI NMOS scale value.

-hci_pmos_scale <scale_val>

Specifies the HCI PMOS scale value.

-hci_nmos_scale <scale_val> 

Specifies the BTI NMOS scale value.

{segment1 segment2 …}

Specifies the stress duration, voltages, and temperature information.

Here, the segment1, segment2 … specifies the stress duration, voltage, and temperature information, for example,
{{duration <float>}[{voltage {<pg_net1> <float> <pg_net2> <float> …}}] [ {temperature <float>}] }
-views {views} Specifies the views for which the stress profile is to be created.

Examples

  • The following command specifies a multi-segment stress profile consisting of stress duration, stress temperature, and stress voltage for view “view1”. 
    tempus > create_aging_stress_profile -view view1 \
    {{{ duration 3} {voltage {VDD 0.8 VSS 0.0}}{temperature 125}} \
    {{duration 7} {voltage {VDD 0.45 VSS 0.0}}{temperature 25}}}
    You can specify the initial 3 years of aging with one stress condition and the rest of the 7 years with different stress conditions - for a total of 10 years of aging:
  • The following command specifies the stress profile along with BTI and HCI scales for PMOS and NMOS. 
    tempus > create_aging_stress_profile { { { duration 10 } {voltage {VDD 1.05 VPW 0.0 VNW \
    1.05 VSS 0.0 }} {temperature 125 } } } -bti_pmos_scale 0.5 -bti_nmos_scale 0.5 \
    -hci_pmos_scale 1 -hci_nmos_scale 1
