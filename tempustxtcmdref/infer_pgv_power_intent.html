infer_pgv_power_intent

infer_pgv_power_intent
[-help]
[-default_net string]

Initiates power intent inferencing after loading the design with the template view definition file. This command creates an individual power domain for each power net, similar to the SMSC PGV flow. It also updates the view definition file and delay_corners with the power domain information. This command creates library sets for each power domain based on PVT. Power domain PVT is inferred based on the voltage from the associated power net of the domain, and the process and temperature of design-level PVT for the corner.

Parameters

-help

Outputs a brief description that includes type and default information for each infer_pgv_power_intent parameter. For a detailed description of the command and all of its parameters, use the man command: 

man infer_pgv_power_intent
-default_net string Specifies the default power net.
