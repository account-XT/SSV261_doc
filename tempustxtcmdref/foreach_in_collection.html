foreach_in_collection

foreach_in_collection 
[-help]
var_name
 collection
 body

Iterates through all objects in the specified collection and executes the commands in the specified script body.

Parameters 

-help Prints out the command usage.

body

Specifies the script body of commands to start during each iteration.

collection

Specifies the collection of objects to iterate over.

var_name

Specifies the iterator variable. During each iteration, var_name is set to a collection of exactly one object. Any command that accepts collections can accept var_name as a value.

Examples

  • The following command prints out the hierarchical names of all the cells in a design:
    foreach_in_collection iCell [get_cells *] {
    puts "Cell = [get_property $iCell hierarchical_name]"

         }
         Cell = ck_0
         Cell = ck_1
         Cell = ck_2
         Cell = ck_4

  • The following example shows a more complex use of the foreach_in_collection command:

    set cellCollection [get_cells temp1_reg]
    set libCellCollection [get_lib_cells -of_objects $cellCollection]
    set libArc [get_lib_arcs -of_objects $libCellCollection]

    foreach_in_collection arc $libArc {
    set fpin [get_property $arc from_lib_pin]

    set tpin [get_property $arc to_lib_pin]
    set sense [get_property $arc timing_type]

    set from_pin_name [get_property $fpin name]
    set to_pin_name [get_property $tpin name]

    puts [format "%25s -> %25s %-20s" $from_pin_name $to_pin_name $sense]

}
