timing_spatial_derate_chip_size

timing_spatial_derate_chip_size value_in_microns 

Default: 1e+30

Data_type: Double

Allows you to define the chip size.

The chip size is the diagonal length of a rectangle that is formed by the chip's length and width. You can obtain the diagonal distance by calculating the square-root of the Length2 + Width2. The diagonal distance should always be specified in units of microns.

The chip size can be picked in the following ways (in order of highest to lowest precedence):

  • When set to a value other than 1e+30, the specified value will have the highest precedence.
  • If the physical floorplan information is available, the chip size will be derived automatically from the floorplan.
  • If the SPEF parasitic files containing the coordinate information are loaded, then the chip size will be automatically derived.

To set this global variable, use the set command.
