Tempus Text Command Reference
Product Version 26.10, May 2026

update_rc_corner

update_rc_corner
[-help]
[-T float]
-name string
[-postroute_cap string]
[-postroute_res string]
[-postroute_xcap string]
[-qx_tech_file string] 
[-via_variation_file string]

Adds or changes attribute values for the specified existing RC corner object.

Note: You can edit an RC corner object before the multi-mode multi-corner definition file is loaded into the design or after. However, after the software processes the file, any change to an existing object when the software is in multi-mode multi-corner mode results in the timing, delay calculation, and RC data being reset.

Note: If the read_spef command is specified without the -rc_scale parameter, for example, "read_spef -rc_corner early_spef_${rc_corner}", then the software does not apply the capacitance scale factor specified in -postroute_cap and -postroute_xcap parameters. If the read_spef command is specified with the -rc_scale parameter, for example, "read_spef -rc_corner early_spef_${rc_corner} -rc_scale ", then the software applies the capacitance scale factor. Here, no factor is specified in the -rc_scale option.

Parameters

-help Prints out the command usage.

-name string

Specifies the name for the RC corner object being created. You can choose any name for an RC corner object, but it is recommended that you use a name that can be easily recognized as referring to a specific RC corner (for example, rc-min, rc-max, c-min, c-max, and so on).
-postroute_cap string

Specifies the capacitance scale factor for RC extraction in post-route mode.
-postroute_res string Specifies the resistance scale factor for RC extraction in post-route mode.
-postroute_xcap string Specifies the coupling capacitance scale factor for RC extraction in post-route mode.

-qx_tech_file string

Specifies the name of a Quantus QRC technology (.tch) file used by Quantus QRC sign-off RC extraction.

The technology file is generated by TechGen, a built-in functionality of Quantus QRC. For most technologies, you can obtain this file from the technology vendor. For technologies not available from the technology vendors, you can enter fabrication process information into an ASCII-format interconnect technology (ICT) input file. The ICT file is then used as input to IceCaps, which in turn generates the technology file.

-T float

Specifies the temperature, in units of Celsius, to use for derating resistance values.

Use this parameter to override the default temperature specified in the Quantus QRC technology file.

Note: The software does not require that the temperature specified for the PVT operating condition at the delay calculation corner level match the RC nominal or user-specified temperature value.
-via_variation_file string

Specifies a file for modeling via variation. The VIA variation file lists all VIA layer names and their corresponding multipliers. Each RC corner can have its own VIA variation file.

For example:

update_rc_corner

-name rcCornerName1 \

-via_variation_file viaVariationFileName1

update_rc_corner

-name rcCornerName2 \

-via_variation_file viaVariationFileName2

Examples

  • The following command creates an RC corner called rc-cbest that uses the capacitance table myTech_bc.CapTbl, and derates the resistance values based on the temperature of 50 Celsius:
    create_rc_corner -name rc-cbest -cap_table myTech.4_bc.CapTbl -temperature 50
  • The following command changes the capacitance table used by RC corner rc-cbest to myCap.2_bc.capTbl, and the temperature by which resistance values are derated to 25 Celsius:
    update_rc_corner -name rc-cbest -cap_table myCap.2_bc.capTbl -temperature 25
