distribute_partition

distribute_partition 
[-help]
[-block_list string]
[-cell string]
[-cell_nohier string]
[-exclude_block_list string]
[-instance string]
[-instance_nohier string]

Controls the method by which design partitioning is performed, and determines the scope of DSTA. This command tells the master process to start using the clients for partitioning. It is recommended that you run the command after the parasitics are read in, so it can provide constraints, timing updates, and reports to be shared among all clients.

Parameters

-help

Outputs a brief description that includes type and default information for each distribute_partition parameter.

For a detailed description of the command and all of its parameters, use the man command: man distribute_partition.

-block_list string

Specifies the list of blocks to be partitioned. It lists the blocks that are to be analyzed in the incremental flow. This enables block-scope analysis in DSTA; therefore, only the specified blocks are analyzed in the run, and all the other blocks are ignored.
-cell string  Specifies a list of cell instances for partitioning.
-cell_nohier string  Specifies a list of cell instances for partitioning, excluding hierarchical children.
-exclude_block_list block_names

Specifies the list of blocks to exclude from the DSTA analysis in the incremental flow. This enables top-scope analysis in DSTA. All blocks not on this list are analyzed, along with the top-level of the design.
-instance string  Specifies a list of instances for partitioning.
-instance_nohier string  Specifies a list of instances for partitioning, excluding hierarchical children.

Examples

The following command specifies to perform a full-flat (non-incremental) flow:

dsta> distribute_partition
