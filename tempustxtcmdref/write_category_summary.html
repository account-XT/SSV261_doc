write_category_summary

write_category_summary [-help] -report <string> [[-ascend  | -descend ] [-byTNS  | -byWNS ]] [-csv  | {-no_frame_fix_width  [-no_split ]}]
-csv

Writes a text file containing the following information:

  • Category name
  • Total number of paths
  • Number of passing paths
  • Number of failing paths
  • Worst negative slack
  • Total negative slack

Parameters 

-help

Outputs a brief description that includes type and default information for each write_category_summary parameter.

For a detailed description of the command and all of its parameters, use the man command:
man write_category_summary
-ascend

Specifies that the report in ascending order, should specify option -byTNS or -byWNS.
-byTNS

Specifies that the TNS value specified as the sorting key, should specify option -ascend or -descend.
-byWNS

Specifies that the WNS value specified as the sorting key, should specify option -ascend or -descend.
-csv Reports entries in csv format.
-descend

Specifies that the report in descending order should specify option -byTNS or -byWNS.

-no_frame_fix_width

Specifies that the table columns have a fixed minimum width, but no maximum width (the data does not wrap). Column data that fits within the column's minimum width will left-justify and pad its location to fill the specified column space.

Column data that is longer than the column's minimum width will take as much space in the table as needed. If a column is overwritten by the data from the preceding column, its data will begin on a new line at the correct column location.

-no_split

Specifies that each column follows the preceding column without splitting to a new line, if the data in one column overruns the next column. The wrapping behavior for data is controlled by the size of the display window.

This format is useful for machine parsing the report.

Note: You must specify -no_frame_fix_width in order to use this parameter.

-report fileName

Specifies the name of the category report file.

Default: category.rpt

Examples

The following command writes a category summary file category.rpt:

tempus> write_category_summary -report category.rpt
