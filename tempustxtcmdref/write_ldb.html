Tempus Text Command Reference
Product Version 26.10, May 2026

write_ldb

write_ldb
[-help]
-library string 
-outfile string 

Converts the text library to a Cadence binary format library called LDB.

You can use LDB to run Tempus analysis. The ECSM and CCS libraries can be very large, and loading them may take significant time. You can convert the ASCII NLDM (Liberty .lib), ECSM, and CCS libraries to LDB by using the write_ldb command.

When loading the design, the timing libraries will be read faster because the software reads the binary versions.

Instead of the original ASCII libraries, you can specify LDB in the read_lib command or the create_library_set command in the MMMC configuration file.

Notes:

  • Tempus-generated LDB files can be used in Tempus, Innovus, Voltus, Genus, and Conformal software.
  • The LDB files are not forward compatible; that is, the LDB generated in one version cannot be used with the prior versions of the software.
  • The software does not support concatenated Liberty library (multiple libraries in the same dotlib file) files during LDB conversion. To use these files, you are required to separate individual libraries before converting to individual LDB files.

Parameters

-help Prints out the command usage.

-library string 

Specifies the name of the input library file.

-outfile string

Specifies the name of the generated LDB file.

Examples

  • The following example illustrates the conversion of libraries to LDB:
    write_ldb -library A.lib -outfile A.ldb
