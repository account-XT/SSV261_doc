set_place_mode


set_place_mode
[-help]
[-reset]
[-place_check_report_fixed_inst_on_blockage {true|false}]
[-place_3d_use_existing_bump_tsv {true|false}]
[-place_design_enable_3d {true|false}]
[-place_design_integrity_ir_fix_effort {low|medium|high}]
[-place_design_refine_macro {true|false}]
[-place_detail_allow_border_pin_abut {true|false}]
[-place_detail_allow_single_height_row_symmetry_x siteName]
[-place_detail_check_route {true|false}]
[-place_detail_color_aware_legal {true|false}]
[-place_detail_context_aware_legal {none|all|optional|required|user}]
[-place_detail_honor_inst_pad {true|false}] 
[-place_detail_pad_fixed_insts {true|false}]
[-place_detail_PGFTV_insertion_cell_list listOfCells] 
[-place_detail_swap_eeq_cells {true|false}]
[-place_detail_use_diffusion_transition_fill {true|false}]
[-place_global_adaptive_subd1 {true|false}]

Controls certain aspects of how the software places cells. This command is enabled only in physical mode and primarily used to control placement settings during the eco_opt_design command.

Parameters 

-help

Outputs a brief description that includes type and default information for each set_place_mode parameter.

For a detailed description of the command and all of its parameters, use the man command:

man set_place_mode.
-reset

Resets all specified options back to default values.
-place_check_report_fixed_inst_on_blockage {true|false}

When true, checkPlace reports placement blockage violations for fixed instances under placement blockages.

Default: false
-place_3d_use_existing_bump_tsv {true|false}

Enables 3D placement to use preplaced but unassigned bump/TSV in the design for signal net assignment. The preplaced bump/TSV must be in the specified cells for 3D concurrent bump/TSV insertion and legalization.
-place_design_enable_3d {true|false}

Enable 3D placement in the Integrity 3D-IC platform. You need to set this to true before invoking concurrent macro placement, standard cell placement, and bump/TSV insertion (place_bump_tsv_detail) in a 3D design.

Default: false
-place_design_integrity_ir_fix_effort {low|medium|high}

Sets the power integrity placement IR fixing effort.

Default: low
-place_design_refine_macro {true|false}

Specifies whether to legalize the macros based on constraints after the concurrent timing-driven placement of macros and standard cells.

Default: false
-place_detail_allow_border_pin_abut {true|false}

Some libraries have cells with pin geometry that is not set back by half the routing pitch from the normal PR-boundary of that cell. When the pin geometries touch the cell PR_boundary, placing an instance of this cell can cause a DRV violation with the normal pin geometry of other cells. To avoid these DRVs, placer will add one Site padding to the cell-side during pre-processing, thus satisfying the min-spacing rules. The -place_detail_allow_border_pin_abut option disables this pre-emptive DRV avoidance behavior, and no auto-padding is done when the option is set to true.

Default: false
-place_detail_allow_single_height_row_symmetry_x <siteName>

Specifies a single-height row tech-site allowing symmetry X during detail placement.

Default: ""
-place_detail_check_route {true|false}

Considers pre-routed FIXED signal wires and avoids creating DRC violations between FIXED signal wires and instance pins. When this parameter is not specified, refinePlace ignores FIXED signal wires.

Default: false

Note: Using this parameter might result in longer run time.

If you specify refinePlace -place_detail_io_pin_blockage, you do not need to specify -place_detail_check_route for signal pins because refinePlace will treat the signal pins similarly to supply pins for blockages. However, signal wires still require this parameter.
-place_detail_color_aware_legal {true|false}

Enables the placer to honor and fix double pattern constraints between adjacent cells.

Default: false

Note: This option does not affect cell to pre-route color DRC checks.
-place_detail_context_aware_legal {none|all|optional|required|user}

Instructs placer to support cell edge to cell edge spacing constraints as defined in the LEF files.

The optional, required, user argument values can be used separately or together, but they are exclusive to all and none. 

Default: all
-place_detail_honor_inst_pad {true|false}

Honors padding from specifyInstPad in the detailed placement. Currently, only left and right padding is supported.

Default: false

When this option is set to true, instance padding is also considered in refinePlace and checkPlace.
-place_detail_pad_fixed_insts {true|false}

Specifies whether the refinePlace command honors cell padding on FIXED instances.

Default: false
-place_detail_PGFTV_insertion_cell_list listOfCells

Specifies the list of cells as PG FTV cells. 

Default: ""
-place_detail_swap_eeq_cells {true|false}

Determines whether master cells can be replaced by EEQ cells during detailed placement to improve routability. After detailed placement, the software reports the number of replacements. EEQ cells are defined in the LEF file.

Default: false
-place_detail_use_diffusion_transition_fill {true|false}

Specifies that the design has fillers with jogged diffusion obs. For designs where fillers with jogged diffusion obs are to be inserted between cells with varying diffusion widths, please specify this option.

Default: false
-place_global_adaptive_subd1 {true|false}

When set to true, placement will call Opt API to get a list of cells not usable for subD1 and disable the usage of cells in the placement engine.

The set_place_mode command can be used independently to get the list of subD1 cells.

Default: false

Examples

The following command resets all set_place_mode parameters to their default values:

tempus> set_place_mode -reset

The following is a Tempus script where Tempus ECO legal placement code honors the double pattern constraints between adjacent cells:

<Load LEF/Verilog/DEF/MMMC>

tempus> set_place_mode -place_detail_color_aware_legal false      # bool, default=false

tempus> eco_opt_design -setup
