report_design_rule

report_design_rule
[-help]
[-byDriver]
[-byNet]
[-byPin]
[-cap] 
[-excNetFile filename]
[-fanout]
[-max]
[-min] 
[-outfile filename] 
[-selNetFile filename] 
[-tran]
[> filename] 
[>> filename]

Reports the following design rule violations:

  • Nets that exceed the maximum capacitance constraints in the timing library and timing constraints file.
  • Nets that exceed the transition constraints in the timing constraints file.
  • Pins that exceed the maximum fanout constraints in the timing library and timing constraints file.

Parameters 

-help                

Prints out the command usage.

-byDriver       

Reports violations by each driver.

-byNet        

Reports violations by each net.

Default: Violations are reported by net.

-byPin              

Reports violations by each pin.

-cap          

Reports violations of capacitance constraints.

-excNetFile filename

Specifies the file that contains the hierarchical net names that are excluded from the capacitance violation report.

-fanout      

Reports violations of fanout constraints.

-max    

Reports only maximum capacitance violations.

Default: -max

-min     

Reports only minimum capacitance violations.

-outfile filename   

Specifies the output filename to which the report violations are saved.

-selNetFile filename

Specifies the file that contains the hierarchical net names selected for the report. Only these net names are considered for inclusion in the capacitance violation report.

-tran          

Reports violations of transition constraints.

Default: Reports all design rule violations.

>filename   

Redirects report into the outfile.

Default: stdout

>> filename

Redirects report into the outfile.

Default: stdout


Command Order

Use this command after running the timing analysis.

Examples

Here are some examples.
