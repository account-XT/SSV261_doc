report_aging_activity

report_aging_activity 
[-help]
[-duty_cycle]
-net <string>
[-out_file <string>]
[-toggle_rate]
[-views <string>]

Reports the duty cycles and toggle rates.

Parameters

-help

Prints out the command usage.

-duty_cycle

Specifies the dump duty cycles.

-net <string>

Specifies the net names.

-out_file <string>

Specifies the output file name.

-toggle_rate

Specifies the dump toggle rates.

-views <string>

Specifies the list of view names.

Examples

  • The following command reports the toggle rate and duty cycle information on net, net_dcu[36]. The output file “out.txt” will contain the required information:
    tempus > report_aging_activity -duty_cycly -toggle_rate -net net_dcu[36] -out_file out.txt
