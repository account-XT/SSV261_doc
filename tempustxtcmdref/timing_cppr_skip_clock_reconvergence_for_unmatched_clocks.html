timing_cppr_skip_clock_reconvergence_for_unmatched_clocks

timing_cppr_skip_clock_reconvergence_for_unmatched_clocks {true | false}  

Default: false

Data_type: Boolean

Allows the software to skip re-convergence of unmatched clocks.

When set to true, the software uses the farthest branch point from the register clock pins when the launching and capturing clocks are different - the re-converge points are ignored and not searched.

To set this global variable, use the set command.
