reset_clock_gating_check

reset_clock_gating_check
[-help] 
[-setup] 
[-hold] 
[-rise] 
[-fall] 
[-high | -low] 
[object_list]

Resets the specified setup and hold values for clock gating checks to the default values.

Parameters 

-help Prints out the command usage.

-high | -low

Resets the non-controlling value (high or low) of the clock.

-hold

Resets clock gating hold values.

-rise | -fall

Resets the specified setup (or hold) value to the rising (or falling) signals on the specified pins.

-setup

Resets clock gating setup values.

object_list

Specifies a list of clocks, instances, or pins for which clock gating checks are to be reset to default values.

If the object_list parameter is not specified, the clock gating check is reset on the current design.
