write_global_slack_report

write_global_slack_report
[-help]
[-early]
[-late]
[-rise]
[-fall]
[-include_ports]
[-max_slack val ]
[-min_slack val ]
[-view view_name ]
[> | >> file_name ]
[ pin_port_list ]

Reports early and late slack values on every instance pin in the design.

This command computes and reports the required time and slack values of the specified pins. 

Note: In DSTA mode, the write_global_slack_report command does not print information on pins that do not have any valid slack values.

Parameters 

-help Prints out the command usage.
> | >> filename

Specifies the output file name.

When specified with >, writes the report to the specified file name. If the file already exists, the software overwrites it.

When specified with >>, writes the report to the specified file name. If the file already exists, the software concatenates the report to the end of the file.

Note: To write a compressed report, add the .gz extension to the file name.
-early/-late Specifies the mode for which slack is to be reported.
-fall/-rise Specifies the transition for which slack is to be reported.

-include_ports

Reports slack information for ports. By default, the slack information is reported for pins only.

-max_slack val

Reports pins with upper-bound slack values less than the specified value.

-min_slack val  

Reports pins with lower-bound slack values less than the specified value. 

Note: This parameter is obsolete and will be removed in a future release. Cadence recommends using the -max_slack parameter.

pin_port_list

Specifies the list of pins or ports for which slack information is to be reported.

-view view_name

Reports slack information for the specified view.

  • The following command reports the early and late slacks on every instance pin in the design:
