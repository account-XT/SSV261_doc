get_qrc_tech_file

get_qrc_tech_file
[-help]
[-techfile]
[-quiet]

Returns the name of the Quantus QRC technology file used for standalone Quantus QRC extraction in a single corner design. You can set these values using the set_qrc_tech_file command.

Parameters 

-help

Outputs a brief description that includes type and default information for each get_qrc_tech_file parameter. For a detailed description of the command and all of its parameters, use the man command: man get_qrc_tech_file.

-quiet 

Returns an abbreviated output that only shows the names or current settings of the parameters set with the set_qrc_tech_file command.

-techfile

Returns the name of the Quantus QRC technology file.

Example

  • The following command specifies the name of the Quantus QRC technology file:
    tempus> get_qrc_tech_file -techfile

    #techfile 'simple.tech' (string, user setting)

    simple.tech
