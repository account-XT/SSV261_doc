add_net

add_net 
-help
<list_of_nets>
-module_based <string>

Adds a net to the design.

After this command, the software will perform a full timing update when you run the next command that reports timing, for example, report_timing.

Note: The tool supports this command for flattened designs only.

Parameters

-help

Outputs a brief description that includes type and default information for each add_net parameter.

For a detailed description of the command and all of its parameters, use the man command: man add_net

<list_of_nets>

Specifies the list of nets to add.

-module_based <string>

Adds the new net to the specified Verilog module.

If the module name contains special characters, you need to start the module name with a backslash '\' and end it with a space.

Examples

  • The following command adds nets n1, n2, and n3:
    tempus> add_net "n1 n2 n3"
  • The following command adds net with base name ant_net[1] to module H[1]:
    tempus> add_net {\ant_net[1] } -module_based {\H[1] }
