write_twf

write_twf
-help
outfile
[-exclude_instances string] 
[-format string]
[-include_instances string]
[-include_lib_cells string]
[-pin]
[-power_compatible]
[-ssta_sigma_multiplier float]
[-third_party_file_format string]
[-view string]
[-voltage_threshold string]

Generates a timing window file (TWF).  The TWF file mainly contains the earliest and the latest possible arrival times that a signal may arrive on a net or a pin.

The format of a timing window file consists of eight pairs of data as given below:

(NET <netname>

minRTW:maxRTW minRt:maxRt minRDr:maxRDr minRSlk:maxRSlk minFTW:maxFTW minFt:maxFt minFDr:maxFDr minFSlk:maxFSlk)

Where:

  • minRTW: Minimum rise arrival time
  • maxRTW: Maximum rise arrival time
  • minRt: Minimum rise transition time
  • maxRt: Maximum rise transition time
  • minRDr: Minimum rise source resistance
  • maxRDr: Maximum rise source resistance
  • minRSlk: Minimum rise slack time
  • maxRSlk: Maximum rise slack time
  • minFTW: Minimum fall timing window
  • maxFTW: Maximum fall timing window
  • minFt: Minimum fall transition time
  • maxFt: Minimum fall transition time
  • minFDr: Minimum fall source resistance
  • maxFDr: Maximum fall source resistance
  • minFSlk: Minimum fall slack time
  • maxFSlk: Maximum fall slack time

Parameters


-help Prints out the command usage.
-exclude_instances string>        Specifies a list of hierarchical instances to be excluded from the TWF file.
-format string

Specifies the name of the format to be used for TWF generation.

Note: This parameter supports third-party TWF generation.
-include_instances string         Specifies a list of hierarchical instances to be included in the TWF file.
-include_lib_cells string

Specifies the library cells that require the input timing window.

outfile

Specifies the name of the output file.

The out_file parameter must be the last argument in the list. To write a compressed file, add the .gz extension to the file name.

Note: This parameter supports third-party TWF generation.

-pin

Generates a TWF for each pin instead of each net.

Default: Generates a TWF for the crosstalk analysis tool, which contains timing windows on each net.
-power_compatible

Generates a timing window file (TWF) that can be used during power analysis.

-ssta_sigma_multiplier float

Specifies a sigma multiplier between 0 and 3. The value that you specify increases the arrival window by that amount, and the worst slack value is generated. The transition and impedance values are not impacted.
-third_party_file_format string

Specifies the name of the third-party file format to be used during TWF generation. You can specify the <ir_drop> or <jitter> format option.

Note: This parameter supports third-party TWF generation.
-view string                    

Specifies the name of the analysis view.

Note: This parameter supports third-party TWF generation.

-voltage_threshold string

Specifies voltage threshold values for generating a Timing Window File (TWF). All the slews in the TWF file will be scaled to these values. The lower threshold must be less than the higher threshold.

Value range: 0 to 100

Examples

  • The write_twf -voltage_threshold {20 80} command writes the following in the TWF file:
    (VOLTAGE_THRESHOLD 20 80) 
  • The following example shows third-party TWF report with IR drop option:

   I m_clk__I10
S A 0.508 0.509 0.175 0.195
S Z 0.077 0.064 0.054 0.054
K Z -- -- -- --
T Z 1 -- -- 2.353 2.280 3 f
T Z 1 0.374 0.268 2.353 2.280 3 r

Third-party TWF report with Jitter option is shown below:
   I m_clk__I10
T Z 1 -- -- 2.353 2.280 3 f
T Z 1 0.374 0.268 2.353 2.280 3 r

Where I - Instance, S - slew data, and K - slack data.
