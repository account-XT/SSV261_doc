distribute_design_views

distribute_design_views 
[-help]
[-client_logfile prefix]
[-create_bm]
[-create_bm_args <string>]
[-load_bm <string>]
[-load_bm_args <string>]
[-save_design {list_of_views | all}]
[-views list_of_views | -restore_dir path]
[-views list_of_views | -restore_design {views | all}]
[-views list_of_views | -restore_cellview {lib | cell}]
[-design_script inputTclCmdFile | -restore_dir path]
[-design_script inputTclCmdFile | -restore_design {views | all}]
[-design_script inputTclCmdFile | -restore_cellview {lib | cell}]
[-restore_design {views | all} -restore_dir path]
[-views list_of_views [-analysis_script list_of_commands]]
[-analysis_script list_of_commands [-views list_of_views]]
[-views list_of_views [-set_analysis_view_log  | -combine_num_views integer]]
[-out_dir outputDir [-design_script inputTclCmdFile| -restore_dir path]]

Allows the Tempus software to process a view as soon as a client is available.

When this command is used, the software does not have to wait till time out or for all the clients to be available for processing a view. This reduces the turnaround time in situations where machines are not easily available.

Parameters

-help                               

Prints out the command usage.

-analysis_script list_of_commands

Specifies the file that contains commands for reading in the necessary parasitic files and the reporting commands.

-client_logfile prefix            

Specifies the  client log filename prefix with the directory.

-combine_num_views integer      

Specifies the number of views to combine in a job.
-create_bm Allows the software to generate boundary models.
-create_bm_args <string> Specifies the arguments provided to the create_boundary_model command during boundary model generation.

-design_script inputTclCmdFile 

Specifies the name of the design and MMMC configuration loading script.

The  -design_script is mutually exclusive with restore_* options.
-load_bm Specifies the directory from where boundary model will be loaded.
-load_bm_args <string>

Specifies the arguments provided to the read_boundary_model command.

For example:
distribute_design_views -load_bm {-skip_version_check}

When specified, the software skips version checks while loading the boundary model in DMMMC flow.

-out_dir outputDir             

Specifies the directory where the run is to be executed.

-restore_cellview {lib | cell}       

Specifies the name of OA library or cell to be restored.

-restore_design {views | all}    

Specifies a list of views.

-restore_dir path             

Specifies the directory path where the design is to be restored.

-save_design {list_of_views | all}

Saves the design session information for the specified (or all) the analysis views.

-set_analysis_view_log              

Redirects the set_analysis_view command run log to set_analysis_view_<viewname>.log file.

-views {list_of_views}           

Specifies the views to distribute for both setup and hold analysis

  • The -views parameter is mutually exclusive with restore_* options.
  • The -views parameter is mandatory when -set_analysis_view_log and -combine_num_views parameters are specified.
