ctd_save_view

ctd_save_view  
[-help] 
-file fileName
[-id windowID] 
[-legend_on]
[-type {PNG | GIF}

 
Saves the current snapshot of the clock tree viewer into a file.

Parameters

-help       Outputs a brief description that includes type and default information for each ctd_save_view parameter. For a detailed description of the command and all of its parameters, use the man command: man ctd_save_view.
-file fileName Specifies the name of the file where you want to dump the display image. This parameter is required.
-id windowIDName  

Specifies the window ID whose display is to be saved.

The default value is the returned value of command get_ctd_win_id.
-legend_on Saves the whole window including the panels that are open.
-type {PNG | GIF} Specifies whether the format of the image should be GIf or PNG

Example

The following command saves the view snapshot in the snapshot1.png file.

ctd_save_view -file snapshot1 -type PNG
