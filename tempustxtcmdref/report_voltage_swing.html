report_voltage_swing

report_voltage_swing
[-help]
-high_threshold float
-low_threshold float
[-output_file string]
[-required_width {all | clock}]
[-view string]

Reports the voltage swings that are shorter than the user-specified thresholds for both clock and data signals.

Parameters

-help Outputs a brief description of the report_voltage_swing command. For a detailed description of the command, use the man command: man report_voltage_swing

-high_threshold float

Specifies the high threshold percentage of the pin supply voltage.

-low_threshold float

 Specifies the low threshold percentage of the pin supply voltage.
-output_file string Specifies the name of the output file.
-required_width {all | clock}

Reports the required high and low pulse widths corresponding to the user-specified high and low thresholds. You can specify one of the following options:

  • clock: Reports the required widths for all clock pins in the design.
  • all: Reports the required pulse widths for all input pins in the design.

Default: all
-view string

Specifies the name of the view being defined.

Note: If this option is not specified, it will dump a report for all views.

Examples

An output file in the text format containing violating pin information is presented below:

View Name: default_setup_view1
Hpin     Type_of_Voilation   Vdd    Vss    Slews(Rise/fall)  Margin (threshold)
X/buf/A (upper/lower)       0.9v   0.0V   210ps/240ps       745mv (810mv)
