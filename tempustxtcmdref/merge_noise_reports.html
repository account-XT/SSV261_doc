merge_noise_reports

merge_noise_reports 
[-help]
-base_dir <string>
[-delay {max | min}]
[-double_switching]
[-failure]
[-reverse_voltage_change_threshold <float>]
[-sort_by {noise | receiver_peak}]
[-threshold <float>]
-txtfile <string>
[-views <string>]

Generates merged noise reports for the specified views.

Parameters

-help                             

Prints out the command usage.

-base_dir <string>                

Specifies the name of the directory provided as input to the report_noise -merge_dir parameter.

-delay {max | min}                  

Specifies the uncertainty type (maximum or minimum delay).

-double_switching                  

Enables double switching reporting.

-failure  

Shows output glitch report for failure nets only.

-reverse_voltage_change_threshold <float>

Reports the minimum reverse swing threshold values.

-sort_by {noise | receiver_peak}    

Specifies the sorting of the report based on noise or receiver_peak.

-threshold <float>                

Reports the glitch (in mV) or uncertainty (in ps) filter threshold values.

-txtfile <string>              

Specifies the name of the output file.

-views <string>                  

Specifies the name of views to include in the merged output.
