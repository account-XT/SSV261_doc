timing_property_arrival_clocks_consider_latency_phase

timing_property_arrival_clocks_consider_latency_phase
{true | false}

Default: true

Data_type: Boolean

Returns the latency phase.

The get_property and report_property commands support the arrival_clocks collection property on pin objects. The arrival_clocks property considers data phases, clock source data phases, and latency phases. 

To set this global variable, use the set command.
