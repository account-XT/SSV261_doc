set_eco_mode

set_eco_mode  

[-help]
[-reset]
[-batch_mode {true | false}]
[-honor_dont_touch {true | false}]
[-honor_dont_use {true | false}]
[-honor_fixed_net_wire {true|false}] 
[-honor_fixed_status {true | false}] 
[-honor_power_intent {true|false}]
[-leq_check {true | false}]
[-prefix_name prefix]
[-refine_place {true|false}]
[-si_effort {low | medium}]
[-update_timing {true | false}]

Controls timing updates during ECO changes, checks for dont touch and dont use cells, and allows swapping non-equivalent cells.

Parameters 

-help

Outputs a brief description that includes type and default information for each set_eco_mode parameter.

For a detailed description of the command and all of its parameters, use the man command:
man set_eco_mode

-batch_mode {true | false}

Enables or disables the batch mode.

-honor_dont_touch {true | false}

Checks for dont touch on insts, cells, and nets.

Default: true

-honor_dont_use {true | false}

Checks for dont use on cells.

Default: true
-honor_fixed_net_wire {true|false}

Checks for fixed net wires.

It prevents the addition or deletion of fixed nets, so the wires' fixed status remains unchanged.

Default: true

When -honor_fixed_net_wire is set to false, add_repeater can insert a cell on the wires with the FIXED/COVER status and change their status from FIXED/COVER to ROUTED.
-honor_fixed_status {true | false}

Does not allow preplaced, fixed instances to be resized.

Default: true
-honor_power_intent {true | false}

Performs Multi Supply Voltage Design (MSV) checks during ECO. When this parameter is set to true:

  • change_cell does not allow:
    • Resizing a regular cell with an always-on cell (and vice-versa).
    • Resizing with cells belonging to different power domains.
  • add_repeater does not allow:
    • Adding a buffer to a power domain that it doesn't belong to.
    • Buffering a cross-power domain net can cause MSV violations.
    • Adding a regular buffer to a net that requires an always-on buffer.
    • Adding an always-on buffer to a net that does not require an always-on buffer.
  • delete_repeater does not allow deletion of a buffer or an inverter-pair that will cause:
    •  A redundant isolation cell.
    •  A CPF-constrained net to be deleted.

Default: true

-leq_check {true | false}

Allows the swapping of non-equivalent cells.

Default: true

-prefix_name prefix

Adds a prefix name to be used by ECO commands.
-refine_place {true|false} 

Legalizes placement whenever add_repeater or change_cell are used. When set to false, you must run -refine_place after ECO to legalize placement.

Default: true

Note: Specifying -refine_place true can affect performance when large numbers of cells are added or modified.

-reset

Resets all or specified options to the default value.

-si_effort {low | medium}

Specifies the effort level to be used for SI analysis during ECO. This parameter allows you to choose between SI analysis accuracy and run time levels.

  • low: An approximate SI analysis will be done in this mode.
  • medium: More accurate SI analysis using the two SI iterations will be done in this mode. 

Default: low

-update_timing {true | false}

Enables or disables the timing update. If this option is set to false, ECO commands do not perform the timing update.

Default: true

The batch mode command also performs timing updates (base delay and noise analysis) on the add_repeater, change_cell, and delete_repeater commands only when the batch mode is closed.

The software keeps track of instances where the add_repeater, change_cell, and delete_repeater  commands were applied in batch mode. When batch mode is closed, the base delay for these instances is updated, and the incremental noise analysis is triggered for the impacted nets.

The use model of the command is as follows:

#start a batch
set_eco_mode -batch_mode true 

#perform add_repeater, change_cell, delete_repeater operations
add_repeater -net ...
change_cell -upsize ...
delete_repeater -inst ...

#close the batch
set_eco_mode -batch_mode false

At this point, the software automatically triggers the timing updates and incremental signal integrity analysis.

Note:

  •  It is recommended to use this mode for improved ECO performance.
  • Only ECO commit operations are allowed inside the ECO batch mode. Evaluations are not supported in batch mode.

Examples

  • The following command resets all set_eco_mode parameters to their default values:
    tempus> set_eco_mode -reset
  • The following command resets the -honor_dont_use parameter to its default value;
    tempus> set_eco_mode -reset -honor_dont_use
  • The following command allows the change_cell command to swap non-equivalent cells:
    tempus> set_eco_mode –leq_check false
  • The following command disables the timing update during ECO operations:
    tempus> set_eco_mode –update_timing false
