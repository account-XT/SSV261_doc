set_outbound_report

set_outbound_report
[-help]
-delay {early | late | both}
[-filename_prefix string]
[-report_constant_nets {true | false}]
[-type {lower | upper | both}]

Controls what extrapolation information is to be saved in the log file(s). The slew extrapolation information can be stored in separate files. 

By default, the software reports slew extrapolation for both minimum and maximum analysis when outbound reporting is enabled by setting set_delay_cal_mode -reportOutBound to true.

Parameters

-help Prints out the command usage.
-delay {early | late | both}

Control whether extrapolation information is to be shown for min or max (or both) analyses.

Default: both
-filename_prefix string

Specifies the prefix to be used in the name(s) of the report file(s).

Default: design-name
-report_constant_nets {true | false} Controls whether extrapolation information is shown for constant nets.
-type {lower | upper | both} Controls whether extrapolation information is to be shown for lower or upper (or both) outbound slews.

Examples

  • The following command will dump slew extrapolation information for maximum analysis into the myreport.dc.outbound.slew.late.<view-name>.txt file:
    tempus> set_outbound_report –delay late -filename_prefix myreport
