report_timing_robustness

report_timing_robustness
[-help]
-check_type {setup | hold | setup_CGS | hold_CGH}
[-opt_list <string>]
[-path_group <string>]
-run_time_limit <integer>
-target_PTR <float>
[-view <string>]

Reports the PTR score of a design.  

The Parametric Timing Robustness (PTR) analysis calculates the probability of an entire chip meeting timing requirements, instead of relying on the probabilities of individual paths to compute the robustness of a chip. This command reports the percentage of parts (to be manufactured) that meet timing at all the endpoints.

The PTR score of a design, which is a statistical measure of the timing slack for the whole design, is based on the following steps:

  • Enumerates all the instances in a design
  • Identifies paths that are critical for PTR of a design
  • Computes the PTR based on Monte-Carlo analysis

Parameters

-help Prints out the command usage.
-check_type {setup | hold | setup_CGS | hold_CGH} Specifies the check type. 
-opt_list <string>   Specifies the PTR options list.
-path_group <string> Specifies the user-defined path groups created using the group_path command.  
-run_time_limit <integer>

Specifies the runtime limit.

Unit in minutes.
-target_PTR <float> Specifies the target PTR score.
-view <string>  Specifies the single view corresponding to the specified check type.

Examples

  • The following examples show the calculated PTR value and the report output:
    report_timing_robustness -check_type setup -path_group R2R -target_PTR 0.8 -run_time_limit 15
    collecting paths and reporting PTR ......
    Final PTR 0.89735

    report_timing_robustness -check_type setup -path_group R2R -target_PTR 0.95 -run_time_limit 15
    collecting paths and reporting PTR ......
    Final PTR 0.91295

    set P1 [report_timing_robustness -check_type setup -path_group R2R -target_PTR 0.95 -run_time_limit 15]
    collecting paths and reporting PTR ......
    Final PTR 0.91295

    report_property $P1
    -----------------------------------
    property             | value    
    -----------------------------------
    slack_mean           | 0.961705
    slack_ptr            | 0.912950
    slack_quantile       | -2.085161
    slack_skewness       | -0.668439
    slack_stddev         | 0.682927
    -----------------------------------
