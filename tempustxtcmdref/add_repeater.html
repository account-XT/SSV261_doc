add_repeater

add_repeater
[-help]
[-name <string>]
[-new_net_name <string>]
[-relativeDistToSink <float>]
[-spread_count <integer>]
[-spread_dist <float>]
[-spread_prefix <string>]
{-net <string> | -term <string>} 
[-loc {{x1 y1} {x2 y2}...} [-buforient <string>]] 
[-sort_by {slack trans area} [-max_cells <integer>]]
[-cell <string> [-evaluate_only ]] [-evaluate_only | -evaluate_all ] [{[-evaluate_all ] [-evaluate_only ]} [{[-view <string>] [-early ] [-late ] [-fall ] [-rise ] [-output_as_tcl ] [-sort_by {slack trans area}]}]] [-early | -late ]
[-first_spread_dist <float>]

Ads either a single buffer or two inverters to a net. In the Multi-mode Multi-corner (MMMC) mode, this command adds a repeater and updates timing in all views. Optionally, you can specify the location of the buffer or inverters relative to the sink pin.

Note: You do not need to provide the physical information (LEF/DEF) to perform ECO using this command.

Parameters 

-help

Outputs a brief description that includes type and default information for each add_repeater parameter.

For a detailed description of the command and all of its parameters, use the man command: man add_repeater
-buforient string

Specifies the legalized orientation for the repeater instance.

Note: You can specify this parameter with the -loc parameter only.

-cell string

Specifies the library cell to be used as a repeater. If the cell is an inverter, two inverters in series will be added.
-early

Specifies that the timing will be evaluated for early analysis. In such a case, only the active hold analysis views will be considered. If this parameter is not specified, timing will be evaluated for late analysis.

Note: This parameter must be specified with -evaluate_only or -evaluate_all only.
-evaluate_all  

Specifies to only evaluate timing for all buffer/inverter/delay cells with matching footprint (or all footprints) without any changes in the netlist.
-evaluate_only

Specifies to only evaluate timing for the given buffer/inverter/delay cells without any changes in the netlist.
-fall

Specifies that the timing will be evaluated for the fall transition. If this parameter is not specified, timing will be evaluated for both rise and fall transitions, and the worst result is reported.

Note: This parameter must be specified with -evaluate_only or -evaluate_all only.
-first_spread_dist float

Specifies the distance from the driver after which the first repeater is to be added.

Note: This parameter must be specified with -spread_dist. 
-late

Specifies that timing will be evaluated for late analysis. In such a case, only the active setup analysis views will be considered. If this parameter is not specified, timing will still be evaluated for late analysis.

Note: This parameter must be specified with -evaluate_only or -evaluate_all only.

-loc {x y | x1 y1 x2 y2}

Specifies the x and y coordinates for the location of the buffer or inverter pair. If you do not specify this parameter, the tool determines the location.

If the cell is a buffer and a location is specified, the newly created buffer is placed at that location. If the cell is an inverter and only one location is specified, both inverters will be placed at the same location.
-max_cells integer

Specifies the maximum number of improving and degrading cells (each) to be reported for evaluation.
-name inst_name

Specifies the base names of the new instances to be added.

-net net_name

Specifies the name of the net on which the buffer will be added. All sinks of the net are buffered when this parameter is specified.
-new_net_name netname

Specifies the base name(s) for the new net(s) to be added.
-output_as_tcl Displays the output as a TCL list rather than as text.

-relativeDistToSink value

Specifies the location of the buffer instance based on its (relative) distance from the sink pin. The value is a number between 0 and 1 (both inclusive). A low value (such as 0.1) places the buffer near the sink. A high value (such as 0.9) places the buffer near the driver. You can use the value 0 to do sink term buffering and the value 1 to do driver term buffering. The fraction is based on the length of the wire. Fractional values can only be specified for two-pin nets.

-rise

Specifies that the timing will be evaluated for the rise transition. If this parameter is not specified, timing will be evaluated for both rise and fall transitions, and the worst result is reported.

Note: This parameter must be specified with -evaluate_only or -evaluate_all only.
-sort_by {slack trans area}

Specifies the sorting order for evaluation.
-spread_count integer

Specifies the number of repeaters to be added for buffering.

Minimum: 1

Maximum: INT_MAX
-spread_dist float

Specifies the distance (starting from the driver) after which repeaters are to be added.

Minimum: 2.2250738585072e-308

Maximum: 1073741.823
-spread_prefix string Specifies the prefix used for new instances and nets added during spread buffering.

-term pin_or_ports

Specifies the list of pins (with one common net) that the new buffer or inverters would drive.
-view string

Specifies the active analysis views for which timing must be evaluated. If this parameter is not specified, timing will be evaluated for all active analysis views and results reported for the worst view.

Note: This parameter must be specified with -evaluate_only or -evaluate_all only.

Examples

  • The following command inserts a repeater with cell BUFX4 on the net connected to terminal DTMF_INST/RESULT_CONV_INST/RE_PHC369_r1336_0_/Y: 
    tempus> add_repeater -term DTMF_INST/RESULT_CONV_INST/RE_PHC369_r1336_0_/Y -cell BUFX4
  • The following command inserts a repeater with cell BUFX4 and attaches it to (driver) terminal DTMF_INST/RESULT_CONV_INST/RE_PHC369_r1336_0_/Y: 
    tempus> add_repeater -term DTMF_INST/RESULT_CONV_INST/RE_PHC369_r1336_0_/Y -cell BUFX4 -relativeDistToSink 1
  • The following command inserts a repeater with cell BUFX4 and attaches it to (sink) terminal DTMF_INST/RESULT_CONV_INST/RE_PHC369_r1336_0_/A: 
    tempus> add_repeater -term DTMF_INST/RESULT_CONV_INST/RE_PHC369_r1336_0_/A -cell BUFX4 -relativeDistToSink 0
  • The following command inserts a repeater with cell BUFX4 on net n123, places it at the given location, and names the new repeater instance ECO_inst: 
    tempus> add_repeater -net n123 -cell BUFX4 -loc {23.45 98.12} -name {ECO_inst}

  • The following command inserts a repeater with cell BUFX4 at a relative distance of 0.3 from the sink terminal of the two-pin net n123: 
    tempus> add_repeater -net n123 -cell BUFX4 -relativeDistToSink 0.3

  • The following command reports the evaluation results of buffering pin, EXECUTE_INST/ar0_reg_9/SE, by adding each of all the buffer/inverter/delay cells in the library:
    tempus> add_repeater -term EXECUTE_INST/ar0_reg_9/SE -evaluate_all
