set_ideal_latency

set_ideal_latency
[-help]
[-min]
[-max]
[-rise]
[-fall]
latency_value
object_list

Specifies the ideal latency to use for input or output leaf-cell pins and top-level ports that are part of an ideal network. These set a point delay on the specified object.

Note: You should specify set_ideal_latency with the set_ideal_network command to view the ideal latency result.

Parameters 

-help Prints out the command usage.

-fall

Specifies the ideal latency for the falling edge.

latency_value

Specifies the ideal latency value.

-max

Specifies the ideal latency for the maximum corner.

-min

Specifies the ideal latency for the minimum corner.

object_list

Specifies a list of objects - instance pins or ports.

-rise

Specifies the ideal latency for the rising edge.

Examples

  • The following command adds an ideal latency of 1.5ns to the input pin A of cell FE_OFC413_scan_se:
    tempus > set_ideal_latency 1.5 FE_OFC413_scan_se/A

    Please note that the above command will only be valid if the pin is part of an ideal network.
