get_aging_analysis_mode

get_aging_analysis_mode 
[-help]
[-activity_propagation_mode]
[-constraints]
[-disable_aging]
[-max_duty_cycle]
[-max_toggle_rate]
[-max_toggle_rate_limit <value>]
[-min_duty_cycle]
[-min_toggle_rate]
[-param_priority_sets]
[-recovery]
[-sequential_activity_propagation]
[-sequential_max_duty_cycle]
[-sequential_max_toggle_rate]
[-sequential_min_duty_cycle]
[-sequential_min_toggle_rate]
[-type]
[-use_fixed_duty_cycle]
[-views]

Returns the aging analysis-related global variable settings and defaults that have been made using the set_aging_analysis_mode command.

Parameters

Displays the following information about the specified set_aging_analysis_mode parameters in the Tempus log file and the Tempus console:

  • Parameter name
  • Current value
  • Type (Boolean, string, and so on)
  • Whether the user sets the current value

If you do not specify any parameters, the software displays information for all of the parameters.

Parameters

-help Prints out the command usage.

parameter_names

Displays information for the specified parameters. You can specify one or more parameters.

See set_aging_analysis_mode for descriptions of the parameters you can specify.
