timing_aocv_analysis_mode

timing_aocv_analysis_mode
{launch_capture | clock_only | separate_data_clock | combine_launch_capture} 

Default: launch_capture

Data_type: Enum

Controls handling of AOCV analysis modes. You can specify one of the following modes:

  • launch_capture: AOCV analysis will be performed for both data and clock paths, and the AOCV derating factor will be calculated based on both clock and data path stages.
  • clock_only: AOCV analysis will be performed for clock paths only, and the AOCV derating factor will be calculated based on the clock path stage depth only.
  • separate_data_clock: The software calculates the AOCV stage count for clock paths and data paths separately. Both clock and data paths have related AOCV derating factors.
  • combine_launch_capture: The software calculates AOCV stage count using combined depth for launch and capture paths. This is achieved by summation of path depth on the launch and capture paths.

To set this global variable, use the set command.
