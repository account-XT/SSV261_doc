set_qrc_tech_file

set_qrc_tech_file
[-help]
techFileName

Specifies the Quantus (QRC) technology file.

Note: Use this command for single corner extraction only. For multi-corner extraction, use the following command:

tempus> create_rc_corner -name rcCornerName -qx_tech_file fileName

Parameters

-help

Outputs a brief description that includes type and default information for each set_qrc_tech_file parameter. For a detailed description of the command and all of its parameters, use the man command: man set_qrc_tech_file.

techFileName

Specifies the name of the Quantus technology file. The technology file contains the interconnect models that standalone Quantus extraction uses.

Example

  • The following command performs standalone Quantus extraction using the qrcTechfile technology file:
    tempus> set_qrc_tech_file qrcTechfile
