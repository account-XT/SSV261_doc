get_object_name

get_object_name
[-help]
collection

Returns the name of the object(s) contained in the specified collections.

By default, the command hides escape characters in the output. To enable printing of escape characters in the output, you can set timing_enable_get_object_escaped_name_backward_compatible global variable to true.

Parameters 

-help Prints out the command usage.

collection

Specifies multiple collections that contain objects.

Examples

  • The following command returns a TCL list of names, which can match the collection inputs:
    tempus > get_object_name [get_cells and*]
  • The following command defines a variable called endpoint_list to store endpoints with the ten worst slacks:
    tempus > set endpoint_list [get_object_name [get_property \
             [report_timing -collection -max_points 10] capturing_point]]
