monitor_hosts

monitor_hosts
[-help]
[-log string]
[-overwrite]
[-period integer]

Monitors hosts and periodically prints the memory or CPU usage, and temporary disk speed of the hosts. This command automatically determines the hosts to be monitored. By default, after every 60 seconds hosts are monitored and the disk information is written to a log file. 

This command is helpful to analyze and debug the performance of a session and helps check the machine load, the available memory, and track possible reasons for a slow down or unexpected exit during a session. 

The monitor_hosts command is supported in STA, DSTA, and DMMMC flows. 

The monitor_hosts command output is described below:

Status Keys/Tags

Memory (%age of Available Memory on the corresponding host)

CPU Usage

Disk Speed (Mb/sec)

E – Excellent

Memory used less than 75%

CPU Usage less than 85%

Disk speed more than 250

G – Good

Memory used between 75% and 85%

CPU Usage between 85% to 95%

Disk speed between 125 and 250

B – Bad (*)

Memory used between 85% and 99%

CPU Usage between 95% to 105%

Disk speed between 50 and 125

T – Terrible (**)

Memory used above 99%

CPU Usage more than 105%

Disk speed less than 50

The monitor_hosts command output will show host/machine specific information and not process specific information. So if multiple processes are running on the same machine, then the command output will show the combined impact of all the processes, on the machine’s memory, machine’s CPU usage etc.

The “T” or “B” state denotes that a session may be thrashing or may not give the best results with respect to the performance. For better performance, you must re-run this command with better machines.

Parameters

-help

Prints out the command usage. For a detailed description of the command and all of its parameters, use the man command: man monitor_hosts.

-log string

Specifies the log file name.

Default: host-monitor.log

-overwrite

Overwrites the log file, if it already exists.

-period integer

Specifies the sampling period after which hosts will be monitored.

Default: 60
