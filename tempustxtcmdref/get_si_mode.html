Displays the following information about the specified set_si_mode parameters in the Tempus log file and the Tempus console:

  • Parameter name
  • Current value
  • Type (Boolean, string, and so on)
  • Whether the user sets the current value.

If you do not specify any parameters, the software displays information for all of the parameters.

Parameters

-help Prints out the command usage.

parameter_names

Displays information for the specified parameters. You can specify one or more parameters.

See set_si_mode for descriptions of the parameters you can specify.

Examples 

  • The following command gets the individual attacker threshold, which is 0.015.
    tempus> get_si_mode -individual_attacker_threshold 0.015 # float, default=0.015 
  • The following command gets the number of timing window iterations for performing SI delay analysis, which is 2.
    tempus> get_si_mode -num_si_iteration 2 # int, default=2
  • The following command gets the attacker switching probability, which is 0.3.
    tempus> get_si_mode -switch_prob 0.3 # float, default=0.3
