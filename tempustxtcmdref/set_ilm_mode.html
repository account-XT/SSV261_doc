set_ilm_mode

set_ilm_mode
[-help]
[-reset]
[-keepAsync {true | false}]
[-keepFlatten {true | false}]
[-keepHighFanoutPorts {true | false}]
[-keepLoopBack {true | false}]

Controls certain behaviors of ILM commands.

Note: The ILM is not supported for Signoff in Tempus.

Parameters 

-help

Outputs a brief description that includes type and default information for each set_ilm_mode parameter.

For a detailed description of the command and all of its parameters, use the man command: man set_ilm_mode.

-keepAsync {true | false}

Keeps paths from asynchronous input ports when ILMs are created by write_ilm. For example, paths from an input port to the reset pin of interface sequential instances, but not to the internal sequential instances.

Default: false
-keepFlatten {true | false}

Instructs the software to keep in a flattened state.

Default: true

-keepHighFanoutPorts  {true | false}

Keeps high-fanout input port paths when ILMs are created by write_ilm.

Default: true

-keepLoopBack {true | false}

Keeps loop back paths when ILMs are created by write_ilm.

When set to true, any path that touches a net used for the ILM model is also included. This is done to improve model accuracy, so that the actual capacitance at an output port can affect the delay on a net feeding an internal path that is normally not included in the ILM model. This also degrades the reduction ratio (#ILM_insts/#all_inst) for the block.

For more details, see the "Loop-Back Paths" section below.

Default: false


Loop-Back Paths

Examples

  • The following command does not keep high fanout ports when ILMs are created by write_ilm:
    ilmview> set_ilm_mode -keepHighFanoutPorts false
  • The following command resets the -highFanoutPort parameter to its original value:
    ilmview> set_ilm_mode -reset -keepHighFanoutPorts
  • The following command resets all set_ilm_mode parameters to their default values:
    ilmview> set_ilm_mode -reset
