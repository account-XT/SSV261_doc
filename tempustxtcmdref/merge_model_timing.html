merge_model_timing

merge_model_timing
-help
-library_file fileName
-modes mode_name
-mode_group group_name
[-tolerance float]
[-keep_separate_arc]
[-pin_cap_tolerance float]
[-outfile fileName]

Merges extracted timing models (ETM) for various analysis views into a single output.

The merge_model_timing command should be the last in the run script. Also, this command should be run separately in a Tempus session when a design is not loaded. 

When the DRV values are different in the libraries that are merged, then Tempus saves the worst value of the DRV with a warning message. 

If the DRV values are not equal, the greater value is stored for the following:

  • Minimum transition
  • Minimum capacitance
  • Minimum fanout

The smaller value is stored for the following, in case of unequal DRVs:

  • Maximum transition
  • Maximum capacitance
  • Maximum fanout
  • Fanout load

Parameters 

-help Prints out the command usage.

-keep_separate_arc

Enables creating separate timing arcs with respective modes.

-library_file fileName

Specifies the input library files to be merged.

-modes mode_name

Specifies the required mode names for merging libraries. The number of mode names should be equal to the number of input libraries.

-mode_group group_name

Specifies the name of the mode group.

-outfile fileName

Specifies the name of the merged library output file. By default, the output file name is merge.lib.
-pin_cap_tolerance float Specifies the pin capacitance tolerance for comparing tolerances during library merging.

-tolerance float

Specifies the tolerance value used for tolerance comparisons during library merging.

Examples

  • The following command merges library files model1.view1.lib and model1.view1.lib.ref into a single output file:
    tempus >  merge_model_timing -library_file "model1.view1.lib model1.view1.lib.ref"
    -modes "v1 v2" -mode_group v1_v2
