Displays the following information about a specified parameter in the Tempus log file and in the Tempus console:

  • Parameter name
  • Current value
  • Type (Boolean, string, and so on)
  • Whether the user set the current value

If you do not specify a parameter, the software displays information for all of the parameters.

Parameters 

-help

Outputs a brief description that includes type and default information for each get_eco_opt_mode parameter.

For a detailed description of the command and all of its parameters, use the man command:
man get_eco_opt_mode

parameter_names

Displays information for the specified parameters. You can specify one or more parameters.

See set_eco_opt_mode for descriptions.

-quiet

Displays the current settings for the specified parameters in Tcl list format only.

If you specify -quiet without any parameters, the software displays the current settings of all set_eco_opt_mode parameters in Tcl list format.

Examples

The following command displays the parameter name as "-add_inst", the default value as "true", and the current value set in the tool as "true".

tempus> get_eco_opt_mode -add_inst

The output is displayed as shown below:

-add_inst true  # bool, default=true
true
