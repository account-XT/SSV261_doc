reset_timing_derate

reset_timing_derate
[-help]
[-delay_corner delayCornerName]
[object_list]
[-increment]
[-transition] 

Resets the derate factors specified on a design or a list of instances (cells, net, or library cells). All the derating factors that are set globally or on specific instances are reset to a default value of 1.0. The derating factors for early or late paths in the design are set using the set_timing_derate command.

Parameters 

-help Prints out the command usage.

-delay_corner delayCornerName

Specifies the delay corner or a list of delay corners on which reset derating is to be applied. 
-increment

Resets the incremental derate values that are set using the set_timing_derate command. 

The set_timing_derate command saves two different values – the “base” derate and the “incremental” derate. When the -incremental parameter is used, the software populates the incremental derates.  The reset_timing_derate command will reset the incremental derate values only.

object_list

Specifies the list of cells, nets, or library cells to reset.

If the object_list contains hierarchical cells, then all cells within the hierarchical cells and across lower hierarchies have reset derate factors.

-transition

Resets the transition derate values. 

Examples

  • The following example resets all the object-specific and global derating factors:
    tempus> reset_timing_derate *
  • The following example resets only global derating factors:
    tempus> reset_timing_derate [current_design]
  • The following example resets the derating factor values for the specified delay corner: 
    tempus> reset_timing_derate -delay_corner delayCornerName
  • The following example resets the global derating values for the specified delay corner:
    tempus> reset_timing_derate -delay_corner delayCornerName [current_design]
  • The following example resets the timing derate on instance u1:
    tempus> reset_timing_derate [get_cells u1]
