report_slack_histogram

report_slack_histogram
[-help] 
[-compact]
[-early]
[-infile string] 
[-late]
[-max_slack float]
[-min_slack float]
[-outfile string]
[-plus_non_violating]
[-retime {aocv | ssta | path_slew_propagation | aocv_path_slew_propagation}]
[-retime_mode {path | exhaustive}]
[-step float]
[-target_slack float]
[-view string]

Generates a histogram of end-point slacks.

The report_slack_histogram command can be used in path-based analysis (PBA) mode.

Parameters 

-help          

Prints out the command usage.

-compact  

Specifies the compact column report format. This format removes any histogram rows that have a count
of 0.

-infile string                 

Specifies the input filename to be used for generating the histogram. When the -infile parameter is specified, the report_slack_histogram command generates reports using data from the specified file.

Default:  The software will generate this data with the default max_paths limit.
-early Specifies early mode analysis for computing the histogram.
-late Specifies late mode analysis for computing the histogram.

-max_slack float               

Specifies the upper slack limit for the generated report.

Default: 0

-min_slack float               

Specifies the lower slack limit for the generated report.

Default: Worst negative slack

-outfile string                

Specifies the name of the output file.

Default: Displays the report on the Tempus console.

-plus_non_violating       

Specifies to include the non-violating slack values.

-retime {aocv | ssta |
path_slew_propagation |
aocv_path_slew_propagation}

Re-analyzes the specified set of paths using the specified method.

-retime_mode {path | exhaustive}    

Re-analyzes the specified set of paths using the specified method.

-step float                   

Specifies the precision for the slack histogram.

Default: 0.5ns

-target_slack float

When specified, the slack histogram is centered around the defined target slack value. 

-view string                 

Writes out slack histograms for the specified view.

If you do not specify this option, the command outputs details for all the views.

Examples

  • The following command reports the lower slack limits along with the non-violating slack values:
    report_slack_histogram -compact -min_slack -10 -plus_non_violating                  

    ---------------------------------------------

    | Slack Range (ns)     |  Count  |     Sum  |

    +----------------------+---------+----------+

    | ( -9.949 ~  -9.449]  |     15  |       15 |

    | ( -9.449 ~  -8.949]  |     12  |       27 |

    | ( -8.949 ~  -8.449]  |     18  |       45 |

    | ( -8.449 ~  -7.949]  |     16  |       61 |  
    ---------------------------------------------

  • The following command reports the upper slack limits for the specified view:
    report_slack_histogram -max_slack -20 -step 0.5 -view func_fast_RCMAX 

    ---------------------------------------------

    | Slack Range (ns)     |  Count  |     Sum  |

    +----------------------+---------+----------+

    | (-21.182 ~ -21.000]  |      7  |        7 |

    | (-21.000 ~ -20.500]  |      2  |        9 |

    | (-20.500 ~ -20.000]  |      5  |       14 |

    --------------------------------------------- 

  • The following command shows a report for the specified target slack value:
    report_slack_histogram -target_slack -21

    ---------------------------------------------

    | Slack Range (ns)     |  Count  |     Sum  |

    +----------------------+---------+----------+

    | (-22.239 ~ -22.000]  |      7  |        7 |

    | (-22.000 ~ -21.500]  |      2  |        9 |

    | (-21.500 ~ -21.000]  |      5  |       14 |

    | (-21.000 ~ -20.500]  |      2  |       16 |

    | (-20.500 ~ -20.000]  |      3  |       19 |

    ---------------------------------------------
