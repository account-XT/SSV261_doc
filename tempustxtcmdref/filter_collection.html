filter_collection

filter_collection
[-help]
base_collection
{filter_expression}
[-nocase]
[-quiet]
[-regexp]

Returns a new collection of objects that were filtered from the specified collection of objects based on user-specified criteria (filter_expression).  The original collection remains unmodified.

The following rules apply:

  • The filter_expression can be created by combining several object properties using the following relational and logical operators: >, <, ==, !=, <=, >=, &&, ||, =~, !~, AND, OR. You can also use parentheses to create expressions. 
  • You can use the defined and undefined existence operators to determine whether an attribute is defined for an object.
  • All design object properties supported through the get_property command can be used for filtering the base collection.

Note: You can perform filtering operations by specifying the -filter parameter with the get_* commands.

Parameters 

-help Prints out the command usage.

base_collection

Specifies the collection of objects from which to filter objects for the new collection.

filter_expression

Specifies the criteria for filtering objects. The software adds any objects in the base collection that match filter_expression to the new collection.

See "Examples" on how to create filter expressions.

-nocase

Specifies that pattern matching is not case sensitive.

Note: You must specify -regexp to use this parameter.
-quiet Suppresses all error and warning messages that are generated when the filter_collection command is run.

-regexp

Treats the specified patterns as regular expression patterns.

Default: Treats the specified pattern as a wildcard.

Examples

  • The following command returns a single-object collection containing the pin with the hierarchical name lat_3/Q:
    filter_collection [get_pins] {hierarchical_name == lat_3/Q}
  • The following command returns a collection of pins that have a maximum slew greater than 0.1:
    filter_collection [get_pins] {slew_max_rise > 0.1}
  • The following commands create a new collection containing all those paths from the path collection with a slack value greater than -0.806 and less than 0.0:
    set paths [report_timing -collection -max_paths 10]
    set newPaths [filter_collection $paths {(slack > -0.806) && (slack < 0.0)}]
  • The following command returns a collection of object names that do not match “*clk*”:
    filter_collection $abc {full_name !~ *clk*}
    out in1 in2 in3 select TopBus[2] TopBus[1] TopBus[0] bidi
    0x53
  • The following command returns a collection of object names that are not “*clk*” only:
    filter_collection $abc {full_name != *clk*}
    out clkl clk2 in1 in2 in3 select TopBus[2] TopBus[1] TopBus[0] bidi
    0x59
  • The following command returns a collection of object names that match “*clk*”:
    filter_collection $abc {full_name =~ *clk*}
    clk1 clk2
    0x5f
  • The following command creates a collection of pins with user_constant_value:
    set constant_pins [filter_collection [get_pins] {defined(user_constant_value}]
