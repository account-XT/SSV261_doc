report_reference

report_reference
[-help] 
[-flat]
[-nosplit]
[-view]
[> file_name]
[>> file_name]

Reports reference cell usage statistics.

The command reports the unit area, library name, and total count of the reference cells. By default, the report is sorted in order of number of instances.

Parameters

-help

Prints out the command usage.

-flat

Disables printing of hierarchical instances.

-nosplit

Generates the report in no split mode.
-view Generates the report for the specified analysis view.

> file_name

Specifies the name of the write mode file name.

>> file_name

Specifies the name of the append mode file name.


Examples

  • The following report output provides reference cell details:
    tempus> report_reference

Design : top

h - hierarchical
