report_noise_propagation

report_noise_propagation 
[-help]
[-level {VL | VH | worst | all}]
[-max_paths integer]
[-max_slack float]
[-nets string]
[-nworst integer]
[-pins string]
[-source_depth integer]
[-style {default | extended}] 
[-views string]
[ [ > | >> ] ]

Prints text-based noise propagation reports that show glitch-source tracing for all the user-specified or all-violating receiver pins. The report allows you to view full paths showing the glitch propagating from the source to the violating receiver pin. This helps to easily identify and fix glitch violations.

Note: You need to set the set_si_mode -enable_glitch_report parameter to true to enable glitch reporting.

Parameters

-help

Prints out the command usage.

For a detailed description of the command and all of its parameters, use the man command: man report_noise_propagation

-level {VL | VH | worst | all}

Reports paths for the specified glitch level. You can specify one of these options: VL, VH, worst, or all.

-max_paths integer

Reports the specified number of paths.

-max_slack float

Reports paths with a glitch Slack equal to or less than the specified value.

-nets string

Reports paths with the endpoint being all the input pins connected to the specified net.

-nworst integer

Specifies the maximum number of sources per endpoint for which paths need to be reported.

-pins string

Reports the paths for the specified endpoint pins.

-source_depth integer

Specifies the maximum number of sources to be traced in any given branch in the fanin cone of violation.

-style {default | extended}

Provides an enhanced report format that shows the UDN and User-annotated fields. You can specify the following options:

  • default: Prints the ROP column and VDD (in mV) in the output report.
  • extended:  Reports the drivers with annotated glitches as propagation sources.

-views string

Reports the paths for the specified view.

> filename

Redirects output to the specified file.

>> filename

Appends output to the specified output file.
