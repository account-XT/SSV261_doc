update_model_context

update_model_context
[-help]
-dir string
[-instances string]

Allows the software to read in the context-only boundary models and perform timing analysis without the need to set up a new STA run with a different boundary model.

Parameters

-help

Prints out the command usage.

-dir string

Specifies the directory for the model context.
-instances string Specifies the instances for context update.

Examples

  • The following example shows that commands that are used to update the timing context of a boundary model:
    read_boundary_model -dir dir_derate_nominal
    …
    set_timing_derate -early 1
    set_timing_derate -late 1 
    update_timing
    update_model_context -dir dir_derate_extreme
    set_timing_derate -early 0.8
    set_timing_derate -late 1.2
    update_timing
