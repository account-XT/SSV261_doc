define_bundled_bus

define_bundled_bus 
[-help]
[-add_members string]
[-delete_members string]
[-name string]

Allows you to control user-defined bus groups.

The Tempus software automatically identifies bus nets. However, in some cases, the software may not be able to mark bus bits properly (or treat marked bits as bus). For improved bus identification, the define_bundled_bus command allows you to control the nets that you want to add (or remove) from the list of recognized bus bits.

Parameters

-help

Prints out the command usage.

-add_members string

Specifies the name of the nets to be added to the group.

-delete_members string

Specifies the name of the nets to be deleted from the group.

-name string

Specifies the name of the group.

Examples

  • The following example command will create a bus named bus1 with 3 net members x[1] and x[2]:

    define_bundled_bus -name bus1 -add_members {x[1] x[2]}
    report_bundled_bus -type user_defined
    ###############################################################

    Summary:
    Total number of user defined bus groups reported = 1
    Total number of tool inferred bus groups reported = 0

    ---------------------------------------------------------------

    Group Name (user_defined) : bus1

    Constituents:
    - x[1]
    - x[2]

  • The following example command will add one more member x[3] and delete member x[2] to the bus 'bus1':
    define_bundled_bus -name bus1 -add_members x[3] -delete_members x[2] 
    Added [1] net(s) to group 'bus1'.
    Deleted [1] net(s) from user-defined group 'bus1'.
