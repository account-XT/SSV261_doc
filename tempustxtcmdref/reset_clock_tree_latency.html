reset_clock_tree_latency

reset_clock_tree_latency
[-help]
[object_list] 

Resets all network clock latency set using the set_clock_latency command in the fanout of the specified clock or pins and ports. The reset_clock_tree_latency command resets the latency until the root pins of clocks and generated clocks.

Note: You can use the reset_clock_tree_latency command only on command line and command script. You cannot specify it in an SDC file.

Parameters

-help Prints out the command usage.

object_list

Specifies list of objects - pins, ports, or clocks for which latency will be reset.

Related Commands

  • set_propagated_clock
