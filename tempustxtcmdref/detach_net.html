detach_net

detach_net
[-help]
net_name
{list_of_pins | -all }

Disconnects a net and connects it to new pins or ports. The syntax is order-dependent.

After this command, the software will perform a full timing update when you run the next command that reports timing, for example, report_timing.

Note: The software supports this command only for flattened designs.

Parameters

-help

Outputs a brief description that includes type and default information for each detach_net parameter.

For a detailed description of the command and all of its parameters, use the man command:

man detach_net

-all

Detaches all terminals connected to the net. You cannot specify a pin/port list if you specify this parameter.

net_name

Specifies the net to connect.

list_of_pins

Specifies the pins from which the specified net is to be detached.

Examples

  • The following command detaches net26 from pins i1/A, i2/B, and i2/Z:
    tempus> detach_net net26 "i1/A i2/B i3/Z"

  • The following command is equivalent to the above example.
    tempus> detach_net [get_nets net26] [get_pins "i1/A i2/B i3/Z"]
