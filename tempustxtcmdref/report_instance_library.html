report_instance_library

report_instance_library
[-help]
[-file fileName]
[-instance instanceName ]
[-view viewName | -delay_corner delayCornerName ]
[-power_domain domainName ]
[-early | -late]

Reports library related information for an instance(s). The report prints the following information about an instance:

  • Instance name
  • Cell type
  • View name or delay corner
  • Power domain name
  • Library/Libset (early/late)
  • Library file (early/late)

  • Operating conditions

  • Binding Status : Prints out the status of the available voltage library. If the user setting is True, then the binding status is not displayed.

Parameters 

-help Prints out the command usage.

-delay_corner delayCornerName

Specifies the delay corner from which an instance library is to be selected. If no delay corner is specified, then all the instance libraries will be printed.

-early | -late

Specifies the library set (early/late) from which a library instance is to be printed. If either option is not specified, both the early and late library sets are used.

-file fileName

Specifies the name of the output file. If no file is specified, the report will be printed to the standard output file.

-instance instanceName

Specifies the instance(s) for which the report is to be printed. If no instance is provided, the report will print information about all the instances. The value of instance can be a list of regular expressions.

-power_domain domainName

Specifies the power domain from which instance(s) are to be selected. This option should be specified with the -delay_corner or -view options.

-view viewName

Specifies the view from which the instance library is to be selected.

Examples

  • The following command displays the information below about instance LIN_CONV_INST/F6A for the specified view:
    report_instance_library -instance LIN_CONV_INST/F6A -early -view scan_slow_RCMAX  

Instance              : LIN_CONV_INST/F6A
Cell                  : INV_X2
Analysis View         : scan_slow_RCMAX
Power Domain          : Default
Library/Libset(early) : F_lib_v1.0/libset_slow
Library File(early)   : /libs/F_lib_v1.0_worst.lib
Binding Status(early) : All PG Pins Voltage Match
Op Cond(early)        : P->1.000000, V->0.800000, T->25.000000 (TypTyp_0.8V_25C)
Cell Type             : gateCell

  • The following command displays the information below about instance FE_C674 for the specified delay corner:
    report_instance_library -delay_corner delay_corner_slow_RCMAX -late 

    Instance              : FE_C674
    Cell                  : BUF_X32
    Delay Corner          : delay_corner_slow_RCMAX
    PowerDomain           : Default
    Library/Libset(late)  : F_lib_v1.0/libset_fast 
    Library File(late)    : /libs/F_lib_v1.0_typic 
    Binding Status(late)  : All PG Pins Voltage Match 
    Op Cond(late)         : P->1.000000, V->0.800000, T->25.000000 (TypTyp_0.8V_25C) 
    Cell Type             : gateCell
