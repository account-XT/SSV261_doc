report_noise_lib_pin

report_noise_lib_pin 
[-help]
[> filename]

Generates a report that provides information on all user-specified noise mappings in the design.

Parameters

-help

Prints out the command usage.

> filename

Writes the report to the specified file name. If the file already exists, the software will overwrite it.

Examples

  • The following command generates the output report ‘noise_mapping.rpt’, which contains all the noise mappings present in the design:
    tempus> report_noise_lib_pin > noise_mapping.rpt

    noise_mapping.rpt

    ---------------------------------------------------
    from_pin                    to_pin
    ---------------------------------------------------
    library1/inverter/I         library2/macro/A
    library1/buffer/I           library3/memory/ADD[0]
    ---------------------------------------------------
