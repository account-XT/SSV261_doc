set_vt_skew_derate

set_vt_skew_derate
[-help]
[-delay_corner <string>]
[-fast <float>]
[-hold]
[-mean]
[-setup]
[-sigma]
[-slow <float>]
[-threshold_voltage_group <group name>]

Assigns fast and slow derate factors to specific threshold voltage groups.

Parameters

-help                                    

Prints out the command usage.

-delay_corner <string>

Specifies the list of delay corners.

-fast <float>                             

Specifies the derate factor to use when evaluating both the early and late paths for a speed-up due to Vth skew shift.

This derate value is expected to be less than 1.0.

-hold

Specifies that the derate is applied to the hold component.

-mean                                    

Specifies that the derate is applied to the mean component.

The specified derate only applies to mean delays in SOCV analysis. If the -mean or -sigma parameter is not specified, the derate applies to both the delay components.

-setup

Specifies that the derate is applied to the setup component.

-sigma                                   

Specifies that the derate is applied to the sigma component.

The specified derate applies only to the delay-variation component in SOCV analysis. 

-slow <float>                             

Specifies the derate factor to use when evaluating both the early and late paths for a slowdown due to Vth skew shift.

This derate value is expected to be greater than 1.0.

-threshold_voltage_group <group name>    

Specifies the threshold voltage group that is either predefined in Liberty or defined using the set_threshold_voltage_group command.

Examples

  • The following commands define the VT skew derate factors and customize the different path combinations to be analyzed in PBA mode:
    set_vt_skew_derate -threshold_voltage_group SVT  -fast 0.90 -slow 1.10
    set_vt_skew_derate -threshold_voltage_group LVT  -fast 0.91 -slow 1.11
    set_vt_skew_derate -threshold_voltage_group ULVT -fast 0.92 -slow 1.12
    set_vt_skew_derate -threshold_voltage_group ELVT -fast 0.93 -slow 1.13
