Viewing the Grid and Device Capacitance of a Cell

To view the grid and device capacitance of a cell:

  1. Select Power & Rail - Library Cell Viewer, and click on the PGV tab.
    The Cell Viewer form appears.
  2. Select Open Power Grid Library from the File menu to open a cell library.
  3. Right-click on the GRID_CAP or DEVICE_CAP view of a cell and choose Grid Cap Filter or Device Cap Filter from the context menu.
    The Grid Cap Filter or Device Cap Filter form appears.
  4. Select a net from Power Ground Nets. The Min and Max values can be entered to change this from the default. Any values falling outside this range will not be viewed. After the range is set, selecting the Linear button will update the filters with the new values. Selecting the Auto button will set the filters back to the default.
  5. Click Plot.

    You can customize the colors for the layers by using the IR Drop & EM Color Selection form. To access this form, click the All Colors button on the main window to open the Color Preferences form. Then, select the View-Only tab, and select IR Drop & EM, in the Multi-Color Layers section.
