Constant Current Source based IR Drop Analysis

Voltus allows you to perform constant current source based IR drop analysis, where power pads are connected with current sources instead of voltage sources. Using this flow, you can perform accurate analysis in design scenarios where voltage regulators are used to ensure constant current supply at power pads. In this mode, there could be higher voltages for some instances, and the hotspot would impact a larger portion of the design.

To run this flow, you must specify:

  • a power pad file in the xy format (set_power_pads -format xy) to define all the pad locations (voltage/current source locations).
  • a power pad file in the xyiv format using the set_power_pads -format parameter. The xyiv format indicates whether the voltage sources specified in the xy power pad location file are current source or reference voltage source. There must be at least one reference voltage source defined in the xyiv file. The format is the same as the xy file, except the additional first and last columns to indicate the current/voltage source and current/voltage value. The name specified in the xyiv file must match the xy file.
    The format of the xyiv file is:
    <Notation - I/V> <Current/Voltage Source Name> <X Y Coordinates in micron> <Layer Name> <Value (I in milliampere and V in volts)>
    The following is an example of power pad file:
    I ISR1 12.5 0 M3 100
V VSRC1 16.401 18.432 M1 0.8
    where, I is the current source and V is the reference voltage
  • the -enable_ccs_analysis parameter of the set_rail_analysis_mode command to enable constant current source analysis. The default value is false.

The following is a sample Tcl script to run this flow:

read_lib -lef $lefs
read_verilog test.v.gz
set_top_module test
read_def test.def
read_sdc test.sdc

set_dc_sources VDD -power -voltage 0.825
set_default_switching_activity -input_activity 0.2
set_power_analysis_mode -method static  -power_grid_library { pgv/../stdcells.cl } -write_static_currents true

report_power -outfile power.rpt
set_power_data -format current POWER/static_VDD.ptiavg
set_pg_nets -net VDD -voltage 0.825 -threshold 0.80
set_rail_analysis_domain -name PD -pwrnets { VDD } -gndnets VSS
set_power_pads -net VDD -format xy -file pad.vdd
set_power_pads -net VDD -format xyiv -file pad.vdd.ccs
set_rail_analysis_mode -method static -accuracy hd -power_grid_library { pgv/../techonly.cl pgv/../stdcells.cl } -enable_ccs_analysis true 
analyze_rail -type net -output CCS_IRDROP VDD
