Viewing the Dynamic Tap Current of a Cell

To view the dynamic tap current of a cell

  1. Select Power & Rail - Library Cell Viewer, and click on the PGV tab.
    The Cell Viewer form appears.
  2. Select Open Power Grid Library from the File menu to open a cell library.
  3. Right-click on the DYN_TAP_CURRENT view of a cell and choose Show Waveform from the context menu.
    The View Waveform form appears.
  4. Select a net/trigger condition and click Plot to view the dynamic current waveforms using SimVision waveform viewer interface.
