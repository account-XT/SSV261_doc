ESD Analysis with DEF

The analyze_esd_network command supports the specify_def flow where the design DEFs are not loaded at the outset which leads to performance gain.

Following is an example command list illustrating how to run analyze_esd_network with specify_def, including the PGV generation step:

set_multi_cpu_usage -localCpu 16
read_lib -lef  data/file.lef
set_advanced_pg_library_mode -common_supply_pins IO  -esd_cells { ESD1 ESD2 }

set_pg_library_mode -celltype techonly -filler_cells *FILL* -decap_cells *DECAP* -extraction_tech_file data/qrcTechFile -lef_layermap data/lefdef.mapfile -power_pins { VDD 1.0 } -ground_pins { GND } -stop@via V1 -current_distribution propagation
generate_pg_library -output ./PGV
specify_def ./data/design.def
set_rail_analysis_mode -method static -temperature 125 -accuracy hd -power_grid_library { \./PGV/techonly.cl \} -vsrc_search_distance 75 -ignore_shorts  false -enable_manufacturing_effects false -report_via_current_direction false -enable_rlrp_analysis false
analyze_esd_network -config_file ./esd_new_rule.txt -type domain -output ESD_analysis
