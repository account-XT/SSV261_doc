User-defined Mode Based Current Waveform Generation with Automatic PWL Scaling

Given one master cell PWL waveform, Voltus can automatically generate scaled PWL waveforms of the other companion cells defined in a trigger file proportional to the master cell internal power. It keeps the waveform shape and scales the waveform magnitude based on the mode and net-dependent relative ratio of the NLPM internal power energy table value to the master cell model. This feature decouples the mode-based current waveform from PGV, and allows power analysis to directly take the PWL format from the user-defined trigger file. You do not need a dynamic PGV for Voltus power and rail analysis.

The companion cells must have the same configuration as the master cell, and they can only be in different sizes.


Use the -custom_macro_pwl parameter of the set_power command to specify a custom trigger file that allows you to apply instance or cell PWL waveforms.

  • In the vector-based analysis, the user-defined PWL model overrides the .lib model. When instance input pins' state matches with the CONDITONAL_INPUT and CONDITIONAL_PIN description, the PWL waveform is applied.
  • In the vectorless mode, the -custom_macro_pwl parameter must be used with set_power –dynamic_switch_pattern in the vectorless flow.

The use model of the -custom_macro_pwl parameter is:

set_power -custom_macro_pwl { ./cell.trigger } -dynamic_switch_pattern -cell SRAM_A1 { MODE_0 MODE_0 MODE_0}


Example of a Custom Macro Power Trigger File (cell.trigger)

MASTER_CELL        SRAM_A1
COMPANION_CELLS    { SRAM_A2, SRAM_A3, SRAM_A4, SRAM_A5 }
      MODE_NAME WRITE
               CONDITIONAL_INPUT = ( !SD & !SLP & !CEB & !WEB )
               CONDITIONAL_PIN = CLK { RISE }
               USER_PWL_FILE write_rise.txt    
      END_MODE

      MODE_NAME READ
               CONDITIONAL_INPUT = ( !SD & !SLP & !CEB & WEB )        
               CONDITIONAL_PIN = CLK { RISE }
               USER_PWL_FILE read_rise.txt
      END_MODE
      ...
END

The following information is displayed in the log file:

---------------------------------------------------------------
INFO : Macro cell <Name of the cell> used user-defined current waveform.
---------------------------------------------------------------

Voltus power saves the waveform scaling factor of each companion cell in an individual text file in the output directory. The file name is scale_factor_report_<master_cell_name>.txt.

The following is an example of the text file:
# CellName NET MODE Scale-Factor
SRAM_A2 VDD WRITE 1.0
SRAM_A2 VDDM WRITE 1.0
SRAM_A2 VSS WRITE 1.0
