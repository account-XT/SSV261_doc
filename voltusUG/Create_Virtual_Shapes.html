Create Virtual Shapes

You can create what-if wires/vias to fix voltage drop and analyze the new grid for various type of existing analyses. The analysis with what-if wires/vias can be done in both early and signoff mode rail analysis. In the sign-off mode what-if analysis, only possible virtual vias between what-if wires and design original wires are automatically generated. You can also skip the generation of these automatic "whatif" vias using the -era_skip_virtual_via_by_type parameter of the set_rail_analysis_mode command. The virtual vias are dropped using the default layer cut size and cut spacing.

Virtual shapes can be created in GUI using the "What-If Analysis Setup - Virtual Shape" form.
