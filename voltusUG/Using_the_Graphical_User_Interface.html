Using the Graphical User Interface

The Voltus graphical user interface enables you to perform various operations in a design, such as specifies to read a design, configure the settings for power and rail analysis, navigate through the chip's design hierarchy, and so on.

The Voltus GUI includes the following features:

  • Main Window - identifies the components of the main window.
  • Menus - provides access to the different options or commands in Voltus. Each menu has a drop-down list with associated commands.
  • Toolbar - provides shortcuts to most of the commonly used commands in Voltus.
