Contents of Trigger File Based Memory/Macro Cell Library

The accurate memory/macro power-grid view includes:

  • Distributed RC for power net and intrinsic capacitance
  • PWL current taps for each device (transistor) in the design
  • Complete visibility inside the cell for power-grid and transistor
  • Macro trigger information that is used later by Power Analysis and Rail Analysis tools to automatically use current waveforms as per the trigger information. The Power Analysis software identifies the trigger condition saved in the EM power-grid view during vectorless or vector-based analysis and generates trigger files. The Rail Analysis software processes the trigger files generated by Power Analysis and the EM power library of the custom macro generated by the Library Characterization engine, and performs full-chip dynamic IR drop analysis with custom macros operating under different functional modes.
    The following is a sample of the log information generated during Power Analysis:
    ** INFO:  (VOLTUS_POWR-2061): Writing ASCII trigger file DYNAMIC_POWER/trigger.txt
    The trigger file contains instance names and when they will be triggered during simulation. The following is a sample auto-generated trigger file in the power analysis directory:
    INST1 2.1995e-07 1 READ
    The following is a sample of the log information generated during Rail Analysis:
    INFO (VOLTUS_RAIL-5023): Found a dynamic tap current view for instance "INST1" whose waveform is triggered at time 1e-07s.
  • Optimized collapsed views are incrementally generated by performing RC reduction and collapsing (merging) the devices in the region with relatively small current consumption, (e.g. bit cells region in the memory). This helps improve the IR drop analysis performance without sacrificing accuracy of any significant order. The optimized views can be used during IR drop analysis by selecting Fast: Accurate accuracy mode.
