Reroute the Signal Nets and Save the Design

Rerouting needs to be done in the post-routed database after refinePlace as the instances are moved to a different location, and the signal nets need to be rerouted. For rerouting, use the following command:
ecoRoute

You can do ecoRoute after every refinePlace iteration but this will increase the turnaround time. It is therefore recommended to do ecoRoute after all the iterations are done.

If you are checking timing after optimization using timeDesign, it will not be accurate unless you do ecoRoute.

At every stage, it is recommended to save the design after refinePlace as there will be changes in the design that needs to be stored. For saving the design, use the following command:
saveDesign design_name.enc
