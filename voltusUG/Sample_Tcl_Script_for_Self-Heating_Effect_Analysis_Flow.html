Sample Tcl Script for Self-Heating Effect Analysis Flow

The following is the sample Tcl script for the self-heating analysis flow:

##Setup Design

read_lib -lef { TECH/file.lef }
read_lib -typ LIB/library1.lib
read_verilog VERILOG/top.v
set_top_module test
read_def DEF/design.def
read_sdc SDC/top.sdc
create_library_set -name libs_min -timing library2.lib
create_rc_corner -name nominal -qx_tech_file qrcTechFile
create_delay_corner -name corner_min -rc_corner nominal
create_constraint_mode -name setup_func_mode -sdc_file SDC/top.sdc
create_analysis_view -constraint_mode setup_func_mode -name setup_func -delay_corner corner_min
create_analysis_view -constraint_mode setup_func_mode -name hold_func -delay_corner corner_min
set_analysis_view -setup [list setup_func] -hold [list hold_func]
set_analysis_mode -analysisType onChipVariation -checkType hold
read_spef -rc_corner nominal SPEF/top.spef
set_design_mode -process 16


### Power Analysis

set_default_switching_activity -input_activity 0.2 -seq_activity 0.1\
                               -clock_gates_output_ratio 2.0
propagate_activity 
set_power_analysis_mode -reset
set_power_analysis_mode -method static
set_power_output_dir static_db
report_power -rail_analysis_format VS -outfile static_power.rpt

## Rail Analysis

set_pg_nets -net VDD -voltage 0.80 -threshold 0.72 -tolerance 0.2 -force
set_pg_nets -net VSS -voltage 0.00 -threshold 0.08 -tolerance 0.2 -force
set_rail_analysis_domain -name ALL -pwrnets {VDD} -gndnets VSS

set_power_data -format current -scale 1 -bias_voltage 1.0 ./dynamic_db/dynamic_VDD.ptiavg
set_rail_analysis_mode -verbosity true -method dynamic -accuracy hd -vsrc_search_distance 100 -power_grid_library {./pgv/std_sign_off_voltus/techonly.cl} -process_techgen_em_rules true -temperature 110
set_power_pads -net VDD -file vdd.ploc -format xy
set_power_pads -net VSS -file vss.ploc -format xy

##Analyze Self-heat

set_advanced_rail_options -reset
analyze_self_heat -domain ALL \
-alpha_parameters {{M1 0.47 0.58} {M2 0.40 0.58} {M3 0.34 0.58} {M4 0.28 0.58} {M5 0.24 0.58} {M6 0.20 0.58} {M7 0.20 0.58} {M8 0.20 0.58} {M9 0.20 0.58} {M10 0.20 0.58} {M11 0.20 0.58}}\
-beta_parameters {0.0048 -0.0025 0.6496}\
-cell_thermal_resistance_file thermal_resistence_file\
-instance_power_file static_power.rpt \
-tiles {100 100} \
-scale_rms_limit 1.32 \
-instance_delta_temperature_file sh_itm.txt \
-tile_delta_temperature_file sh_ttm.txt \
-detail_delta_temperature_file power_detail.rpt \
-report_conn_pin_wire self_heat.rpt
read_power_rail_results -detail_delta_temperature_file power_detail.rpt
set_power_rail_display -plot ddt

The following is an example for the analyze_joule_heat command:

analyze_joule_heat -domain ALL -tile_delta_temperature_file joule_ttm.txt -tiles {10 10} -detail_delta_temperature_file joule_heat_detail.rpt -report_conn_pin_wire joule_heat.rpt

Self-heat analysis (analyze_self_heat/analyze_joule_heat) should be performed for the entire design, that is, you must use domain analysis with all PG nets (-domain ALL). The -net <pgnet> parameter should be used only for preliminary checking.
