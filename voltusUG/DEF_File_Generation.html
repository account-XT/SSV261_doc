DEF File Generation

convert_gds_to_def is a GDS2DEF utility that converts a given GDSII file to a DEF file for power/rail signoff analysis. For some cells that only have GDS format, it is not possible to display the design data within the cells in the Voltus GUI. In addition, it is not feasible to generate a desired DEF using the existing translators of Str2oa and oa2def because of missing connectivity information. Thus, it is necessary to have a GDS2DEF utility to generate a desired DEF file for rail analysis.

The use model of the convert_gds_to_def utility is given below:

convert_gds_to_def

[-help]
[-black_box_cell_file filename]
-gds_file filename
-gds_layermap filename
[-esd_cell_bbox_file filename]
[-esd_marker_layer_file filename]
[-extract_signal_net_logic_info_only]
[-ignore_gds_inst_name]
[-inst_name_file filename]
-net_location_file filename
[-inst_name_prefix prefix]
[-output_components {ALL | NONE | CONN}]
-output_def_file filename
[-output_lef_macros filename]
-power_grid_library libraryname
-top_cell cellname
[-print_complete_short_path]
[-spef_file filename]
[-tech_gds_layermap filename]
[-use_gds_label {ALL | TOP | <tech_layer_name> | <cell_name>:<tech_layer_name> | <cell_name>:ALL}]
[-verilog_file filename]
[-zero_pin_size]

The following command converts the specified GDS file new.gds to a DEF file top.def.

convert_gds_to_def -net_location_file net.loc -gds_file new.gds -power_grid_library ../pv_library.cl -gds_layermap lmap -top_cell cella -output_def_file top.def
