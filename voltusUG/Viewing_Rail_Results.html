Viewing Rail Results

To analyze the rail analysis results, do the following:

  1. Perform connectivity check between dies.

    You can use the set_rail_analysis_mode -enable_multi_die_connectivity_check true parameter to check the connectivity in $rail_result_folder/latest/ logs/simulation/voltus_rail.log and confirm if there are any floating voltage sources (type=nonvsrc).

    Following log example shows die-to-die maps correctly with no disconnected terminals.

  2. Access the multi-die mode rail result folder for each die.
    The multi-die rail result folder will have the following structure with each die instance name folder containing its reports.

  3. Open GUI for each die.
    Currently, Voltus has a single-die based GUI. You can use the hierarchical database (HDB) method to create each die's physical design database and then load its corresponding rail results folder. The following Tcl example shows creation of HDB for interposer die (IDIE) and loading rail results from the multi-die rail result folder:

    ###Create hierarchical database by Interposer LEF/DEF
    set lefs {../Interposer/data/tech.lef ../Interposer/data/back_ubump.lef ../Interposer/data/front_ubump.lef }
    set defs ../Interposer/DEF/Interposer.def.gz
    create_hier_design -lef $lefs -def $defs -skip_signal \
    -top_cell interposer -hdb_dir saveDB_IDIE
    ###Load IDIE design db and its multi-die mode rail result folder
    read_hier_design saveDB_IDIE interposer
    read_power_rail_results -rail_directory \
    StaticRailResults_test/latest -die_instance_name IDIE
    set_power_rail_display -plot ir

    The following Tcl example shows creation of HDB for logic die (LDIE) and loading rail results from the multi-die rail result folder:


    ###Create hierarchical db by Logic Die1 LEF/DEF
    set lefs {../LDIE/LEF/gsclib090_tech.lef ../LDIE/LEF/pso_ring.lef ../LDIE/LEF/pll.lef ../LDIE/LEF/decap.lef ../LDIE/LEF/pso_header.lef ../LDIE/LEF/buf_ao.lef ../LDIE/LEF/gsclib090_macro.lef ../LDIE/LEF/front_ubump.lef}
    set defs ../LDIE/GUI/super_filter.def.gz
    create_hier_design -lef $lefs -def $defs -skip_signal \
    -top_cell super_filter -hdb_dir saveDB_LDIE
    ###Load LDie1 design db and its multi-die mode rail result folder
    read_hier_design saveDB_LDIE super_filter
    read_power_rail_results -rail_directory \
    StaticRailResults_test/latest -die_instance_name LDIE1
    set_power_rail_display -plot ir
