Power and Rail Analysis Text Reports

In addition to auto-generated HTML reports, Voltus can incrementally generate text reports for all analysis types, post analysis. These reports can be generated using the report_power_rail_results command and report option. You are required to load state directory which has rail analysis results. The power reports can be generated after restoring the power database.

Example Tcl Flow

# Import design

read_design …

# Load rail analysis state directory

read_power_rail_results -rail_directory ALL_25C_avg_1/VSS

# IR drop report

report_power_rail_results -plot ir -filename VSS.irdrop.report

# Resistance analysis report

report_power_rail_results -plot rlrp -filename VSS.resistance.report

# Current density (EM) violation report

report_power_rail_results -plot rj -filename VSS.currentdensity.report

# Sensitivity analysis report

report_power_rail_results -plot rs -filename VSS.sensitivity.report

# Instance-based least resistance path report without violation report

report_power_rail_results -filename rlrp.report -limit 0 -rlrp_inst A/B/C

The parameter -limit 0 effectively turns off the violation report.

There are two ways to generate static power reports in Voltus:

  • Using report_power after restoring power database
  • Using report_power_rail_results after restoring power database

Both methods generate report in different format.In general, report_power has more detailed options to generate power distribution reports, e.g. for design hierarchy, cell type, instance, clock domain, power domain etc. In contrast, report_power_rail_results can only generate global power, activity and frequency reports to highlight worst-case values.

Example Tcl flow

# Restore power database

restore_power_database -file power.db
report_power -clock_network all -outfile clock.rpt
report_power -instances inst1
report_power -cell CKBUF
report_power -hierarchy dma_dut -outfile dma_dut.pwr
report_power -pg_net VDD -outfile VDD.pwr

OR

report_power_rail_results -plot ip -filename total_power.rpt
report_power_rail_results -plot ip_s -filename switching_power.rpt
report_power_rail_results -plot ip_i -filename internal_power.rpt
report_power_rail_results -plot ip_l -filename leakage_power.rpt
report_power_rail_results -plot freq -filename freq.rpt
report_power_rail_results -plot td -filename transition_density.rpt
report_power_rail_results -plot load -filename load_cap.rpt

In addition to text reports, you can measure the worst IR drop, total current and capacitance values in the region interactively using "Draw" and "Measure" buttons in Power & Rail Results form. This feature is also supported through Tcl command as follows,

read_power_rail_results -rail_directory ALL_25C_dynamic_1/VDD
report_power_rail_results -region {0 0 100 100}
