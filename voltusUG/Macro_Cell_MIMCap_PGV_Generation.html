Macro Cell MIMCap PGV Generation

Macro PGV generation requires GDS to extract MIMCap, considering only grid capacitance for its computation. The intrinsic capacitance should be zero. If SPICE is used for some cases then we can either set the .param capflag_mim parameter to 0 in the SPICE model file or remove SPICE to avoid counting the capacitance again.

Required Input Files

  • Technology LEF
  • Cell LEF
  • Quantus technology file
  • LEFDEF layermap - optional. If you do not specify this file, Voltus will automatically generate it.
  • GDS file of the macro
  • GDS layermap
  • XTC command file

Procedure

To create MIMCap power-grid views for a macro cell, complete the following steps:

  1. Read the LEF files for all the cells to be characterized.
    TCL command:

    read_lib -lef tech.lef mimcap.lef

  2. Specify the settings for macro cell library characterization through the command line.

    TCL command:

    set_pg_library_mode \
    -celltype macros \
    -cell_list_file macros \
    -power_pins {VDDK 1.0} \
    -ground_pins GNDK \
    -gds_files mimcap.gds \
    -gds_layermap gds.layermap \
    -lef_layermap lefdef.layermap \
    -current_distribution propagation \
    -stop@via VIA1 \
    -extraction_tech_file tech.tch

  3. Specify the XTC command file.

    TCL command:

    set_advanced_pg_library_mode -libgen_command_file libgen.inc -xtc_command_file xtc.inc

    The following is the file description and file snippet of the XTC command file:

    File Description File Snippet
    XTC command file specifies to perform the logic operation on the GDS data to derive the MIMCap shapes. 
    not ctm_13 CTM_O CTM_phy
    not cbm_13 CBM_O CBM_phy
    delete ctm_13
    delete cbm_13
    copy CTM_phy ctm_13
    copy CBM_phy cbm_13
    and VIA12 ctm_13 ctm_via12
    and VIA12 cbm_13 cbm_via12_tmp
    not cbm_via12_tmp ctm_via12 cbm_via12

    not VIA12 ctm_via12 VIA12_tmp1
    not VIA12_tmp1 cbm_via12 VIA12_tmp2
    delete VIA12
    copy VIA12_tmp2 VIA12

    connect ctm_13 ctm_via12 M13
    connect cbm_13 cbm_via12 M13
    connect M12 VIA12 M13

  4. Generate the output for power-grid library generation through the command line.
    TCL command:

    generate_pg_library -output mimcap_pgv

Output

The output directory will contain the macros_mimcap.cl, macros_mimcap.report, and macros_mimcap.summary files similar to other standard cells.
