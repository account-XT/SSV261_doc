Current Waveform Characterization for Macro EM Views

Voltus supports characterization of the dynamic current behavior of custom macros. These current waveforms will be used during rail analysis instead of the default triangular waveform. To characterize current inside a macro PGV, the flow needs one of the following inputs:

  • FSDB with Spice current waveforms
  • Datasheet parameters
  • User-defined PWL
  • Simulation vectors
  • Liberty-based vectors
  • User-specified Spice deck

For macro PGVs, the dynamic tap current port view is supported in both the early and EM views in the PWL-based flow.

A user-specified trigger file is used to add the signature of the current for different mode conditions. The trigger file contains the information on the input vectors for which it will toggle, waveform triggering input pin information, and current information. The trigger condition is used to identify the functional mode (read/write/idle) of the custom macro in the Power and Rail Analysis flow. During power analysis, if Macro PGVs with dynamic current is provided, the software will schedule the switching events for the macro blocks based on the activity ratio. The scheduling time will be based on the timing information on the trigger pin, and all the switching events will be stored into the trigger files under the power analysis output directory. Rail analysis will load the trigger files automatically when the current files (*.pti*) are loaded. The trigger file enables you to get the current signature of the memory for different current inputs during PGV generation.

To run this flow, you should also provide a Spice netlist with x,y coordinates, and Library Characterization calculates average currents through each of them and then hooks up the currents to the nearest node on the contact layer preserving the current distribution. Extraction is done till the lowest contact layer or cut layer as defined by users.


When you specify a hierarchical netlist, the cell instances should have their coordinate information in the $T format. The $T format is given below:

$T=x,y,r,a

x - X-coordinate

y - Y-coordinate

r - reflection along x axis (0 or 1), 0 - No reflection, 1 - Reflection is there along x-axis

a - rotation angle in degrees (0, 90, 180, 270)

The following diagram illustrates the current characterization flow:

Tcl command:

set_pg_library_mode \
  -power_pins {VDD 1 } \
  -ground_pins VSS \
  -celltype macros \
  -extraction_tech_file ../tech_worst.tch \
  -lef_layermap ../lef_layermap.txt \
-cell_list_file ../16x32memory/cell.list \
-spice_models {../model1.l ../model2.l ../model3.l.special} \
-spice_corners {{TT tt_hvt tt_lvt DIO TT_DIO} {TT_sr} {TT_sr}} \
-current_distribution {dynamic_simulation trigger.txt} 
set_advanced_pg_library_mode \
  -pgdb_list_file ../cell_32x64.hdr \
  -pgdb_layermap ../pgdb_layermap.txt \
-libgen_command_file ../cell_32x64_1/lib.inc 
generate_pg_library \
-output .


The following is the sample content of the trigger.txt file:

CURRENT_CHARACTERIZATION_METHOD DOTLIB
DOTLIB_LIST test.lib
MODE_COUNT 3
SIM_STOP_TIME 10ns
SIM_STEP_SIZE 20ps

For the current characterization flow, you must specify the -current_distribution { dynamic_simulation trigger_file } parameter.
