Power Density Aware Vector Profiling

The Vector Profiler flow identifies worst activity and worst average power cycles in the VCD/FSDB that are then used for detailed dynamic power and IR drop analysis. However, if you need to take into account core regions of high power density that could produce high dynamic switching current and IR drop, use tile dimension for power density calculation. In this flow, you can specify the number of physical tiles, and the tool will:

  • Compute power density in each tile at every time step
  • Track which tiles have worst power density during VCD profile
  • Sort vectors based on worst-case power density

To run this flow, you must specify the following parameters:

set_power_analysis_mode -vector_profile_mode {power_density}
report_power -power_density_tiles



The use model of this flow is:

read_activity_file -format VCD -block {} -scope {top} -start_time_shift {} -start {} -end {} ieee.vcd
set_power_analysis_mode ... -vector_profile_mode {power_density} -worst_step_size 20ns
report_power -outfile tiling -nworst 5 -time_based_report -pg_net {VDD VSS} -power_density_tiles 25
