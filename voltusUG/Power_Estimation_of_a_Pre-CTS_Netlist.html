Power Estimation of a Pre-CTS Netlist

You can run the set_virtual_clock_network_parameters command to analyze and provide fast power estimation of the clock tree power of a pre-CTS netlist. When this command is specified, Voltus constructs a virtual clock tree and estimates power of the clock network. You can estimate power selectively for specific clocks in the design.

The example Tcl command for power estimation of a pre-CTS netlist is as follows:

read_verilog design.v 
read_lib "$libraryDir/.../.../library1.lib $libraryDir/.../.../library1.lib"
set_top_module design
read_sdc $testcaseRoot/new.sdc
set_power_analysis_mode -create_binary_db true -honor_negative_energy true -ignore_control_signals false -write_static_currents true -power_grid_library " $testcaseRoot/all.cl "
set_default_switching_activity -input_activity 0.2 -period 1.87512 -duty 0.5
set_virtual_clock_network_parameters -cell {BUFX12} -library typical -max_fanout 2
report_power -rail_analysis_format VS -outfile ./instance.rpt
report_power -outfile power.rpt
report_power -clock_network all -outfile clock.rpt
exit
