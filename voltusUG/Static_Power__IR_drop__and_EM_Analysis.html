Static Power, IR drop, and EM Analysis

Voltus IC Power Integrity Solution offers static power, IR drop, and electromigration analysis. Some of the features include the following:

  • Signoff quality power-grid extraction to take into account various manufacturing effects like erosion, wire edge enlargement, temperature, dishing, slotting, cladding etc.
  • Support for RDL and full-chip GDS for power-grid extraction
  • XD and HD accuracy modes for analysis
  • Various interactive power-grid analysis plots like IR drop, current density, current across resistors, device tap currents, drop across package, instance based voltage, instance based effective resistance, etc.
  • CPF Support
    • Power domain definition
    • Power domain operating conditions
    • Off power-switch nets
  • Highlight the least effective resistance path for the instance
  • Result browser report
  • Interactive query
  • HTML reports
  • GUI and Tcl command interface
