EM Modeling using Voltus Format

The command set_rail_analysis_mode -em_models file is used to point to the file that includes the models needed for EM analysis.

The -process_techgen_em_rules and -em_models parameters of the set_rail_analysis_mode command are mutually exclusive. If none of these parameters are specified, rj analysis will not be performed.

The use model for temperature effects on resistance is given below:

  • Sources of TC1/TC2/TREF will follow the same use model as of EM rules. Voltus will read both TC1/TC2/TREF and EM rules from one of the following three sources: em model file, .cl, or extraction technology file. These sources are mutually exclusive.
    • When set_rail_analysis_mode -process_techgen_em_rules is true and -extraction_tech_file is specified, the extraction technology file settings will be used.
    • When -em_models is provided, em model file will be used.
    • In other cases, .cl file will be used.
  • If the temperature coefficients are not set in the em model file, they will be reset to default settings (0 for TC1 and TC2, 25 for Tref) and a warning message will be displayed.
  • In the em model file, Tref needs to be defined on the layer "ALL".


Normal Modeling

model [layer|all] parameter1 = value1[parameter2 = value2...parametern = valuen]

PWL Modeling

model [layer|all] parameter = "value_1 width_1 value_2 width_area_2 [value_3 width_area_3 [...value_n width_area_n]]"
model metal_layer jmax_parameter = "jmax_value_1 width_1 jmax_value_2 width_2 [jmax_value_3 width_3 [...jmax_value_n width_n]]"<via_range=number>
model via_layer jmax_parameter = "jmax_value_1 area_1 jmax_value_2 area_2 [jmax_value_3 area_3 [...jmax_value_n area_n]]"<via_range = number> <current_direction = [up | down | both]>
model layer_name jmax_length_factor = "factor_1 length _1 ... factor_n length_n"
model jmax_lifetime [jmax_dc_avg | jmax_dc_peak | jmax_dc_rms] layer_name "scale1 Lifetime1 scale2 Lifetime2 ... scalen Lifetimen"

The model command lists or changes resistor model parameters, which makes it possible for Voltus to perform electromigration verification. The model parameters provide the following information:

  • What layers are to be modeled, such as metal layers and via layers
  • Layer dimensions
  • Current density information

Parameter

layer

Specifies the name of the layer for which the software is to set parameters. This name should be the same as the layer name defined in the RCgen and XTC command file.

all

Indicates all existing layers. These layer names should be the same as the layer names defined in the RCgen and XTC command file.

parameter1 = value1 area1

parameter2 = value2 area2

.

.

parametern = valuen arean

Specifies the model parameter and its new value. If you do not include this argument, the software lists the current model settings. This is for normal modeling.

There must be spaces before and after the equals sign.

parameter = "value_1 width_area_1 value_2 width_area_2 value_2   width_area_2 ...[value_n width_area_n]"

Specifies the points of the piecewise linear interpolation. Value is one of the following parameters:

  • Ea
  • A
  • Jmax_dc_avg
  • Jmax_dc_rms
  • Jmax_dc_peak

If you specify piecewise linear current density limits for a metal layer, width_area_n must be the width of the wire, in meters. If you specify the piecewise linear current density limits for a via layer, width_area_n is the area of the via, in meters squared.

You must define at least two points in a PWL model.

jmax_parameter

jmax_parameter is one of the dc parameters (i.e. jmax_dc_avg, jmax_dc_rms, jmax_dc_peak).

via_range= number

The permitted current on a metal layer can be specified depending on the number of vias. This is done using the via_layer option. If this option is not used, all currents defined will pertain, independent of the number of vias.

"model metal_layer via_range" specifies the number of parallel vias encountered when going from the referenced layer to the top metal layer. Multiple model via_range commands are used to specify the different currents for the different ranges in number of vias. The order of these multiple commands are not important. Any via ranges not specified will apply the closest one. An example with three model commands is shown below.

current_direction = [up | down | both]

Provides the ability to specify EM model parameters based on direction. The default is both.

jmax_length_factor

Specifies the length dependent adjustment factor as a PWL function.

The length values are specified in meters.

jmax_lifetime

Specifies the current density limit for different lifetimes.

Example:


jmax_lifetime jmax_dc_avg metal1 "4.3 5 1 10 0.4 15"

jmax_dc_avg jmax_dc_rms jmax_dc_peak

Specifies dc jmax_factor for average, peak, or rms currents.

scale1 scale2 ... scalen

Specifies the scaling factor used to calculate the current density limit.

Lifetime1 Lifetime2 ... Lifetimen

Specifies the lifetime value. (in hours)

TC1 = "value_1 width_1 value_2 width_2 ...value_n width_n"

Specifies the model parameter TC1/TC2, its new value, and the width corresponding to the new value. The width values are specified in meters.

Example

  • The following is an example of using the via_range option. 
    model via_layer jmax_dc_avg = "jmax_value_1 area_1 jmax_value_n area_n" via_range=2 ;
    Where, via_range=2 refers to number of vias from 1 to 2.
    model via_layer jmax_dc_avg = "jmax_value_1 area_1 jmax_value_n area_n" via_range=4 ;
    Where, via_range=4 refers to number of vias from 3 to 4, since 1 to 2 was covered by prior command.
    model via_layer jmax_dc_avg = "jmax_value_1 area_1 jmax_value_n area_n" via_range=8 ;
    Where, via_range=8 refers to number of vias from 5 to 8, since 1 to 4 was covered by the prior two commands. For any cases that have more than 8 vias, this model will also be applied.
    The via_range rules on metal layers are only applied to resistors that belong to a segment with a via connection to the upper layer. If there is no via connection (i.e top metal layer), then the default rule (without via_range, like command shown below) will be used.
    model via_layer jmax_dc_avg = "jmax_value_1 area_1 jmax_value_n area_n"
    If wire width and number of vias rules are both specified, the number of vias rule will be applied first.
    The "info r", "which r", and "print rj" commands will list the number of via cuts to be used in EM modeling. All of these commands require a previous EM analysis with via_range models performed, since only then will it run the connectivity retracing to account for via connections.
    Temperature effects on resistance are available. The model parameters for each layer include fields for TC1, TC2, and TREF. The resistance of a resistor is calculated by using the following formula:
    Reffective = R*(1 + TC1 * delta_t + TC2 * delta_t2)
    This syntax contains the following parameters:
    • delta_t - Specifies the default temperature minus the nominal model temperature (TREF).
    • TC1 - Specifies the linear temperature coefficient. The default is 0.0 in 1/degrees.
    • TC2 - Specifies the quadratic temperature coefficient. The default is 0.0 in 1/degrees2.
    • TREF - Specifies the nominal model temperature, in degrees Celsius. The default is 25 degrees Celsius.
    • TC1 and TC2 come from the foundry. TREF refers to the temperature at which the technology file was generated. The temperature variable sets the operating temperature at which you want to run the analysis. The tool then recalculates the resistance from the extracted TREF at the analysis temperature that you want.

EM Model File Example

The following is an example of the contents of the EM model file:


###############################################################

# Example foundry specification current density based EM check
# Generated for 110C
# METAL_1 => Imax = 0.36*2.0*(w-0.02)
# METAL_2 to METAL_6 => Imax = 0.36*2.6*(w-0.02)
# METAL_7 and METAL_8 => Imax = 0.36*4.48*(w-0.02)
# where w is width. 
# Contact => 0.294mA/Cont
# VIA_1 to VIA_6 => 0.189mA/via
# VIA_7 and VIA_8 => 1.452mA/via

###############################################################

# Jmax Calculation: e.g. METAL_1
# Imax = 0.36*2.6*(w-0.02)
# For w= 0.12u, Imax = 0.36*2.0*(mA/u)*(0.1u) = 0.09mA

#

# For different widths, you can generate the PWL limits and Voltus will interpolate between these values based on width of the resistor, e.g.
