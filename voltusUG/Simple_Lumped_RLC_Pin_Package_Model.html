Simple Lumped RLC Pin Package Model


The simple lumped RLC pin package model information can be specified in the following ways:

Default Package Parameters

You can set the default package R (Resistance), L (Inductance), and C (Capacitance) in a Tcl command as below:

set_rail_analysis_mode \
[-default_package_resistor value]
[-default_package_capacitor value]
[-default_package_inductor value]

The default package parameter values are applied to each power pad defined using the set_power_pads command.

Package Parameters Embedded inside Power Pad Location File

You can also set the unique package R (Resistance), L (Inductance), and C (Capacitance) for each power pad using the set_power_pads command.

set_power_pads -net <power_net_name> -format xy -file <power_net>.pp
set_power_pads -net <ground_net_name> -format xy -file <ground_net>.pp

Example of the <power_net>.pp file:

*------------------------------------------------------------------
* <vsrc name> x(um) y(um) <layer> Package R(ohm) L(H) C(F)
* vsrc name must be unique
* vsrc name across different net name in domain should be unique
*------------------------------------------------------------------
VDDvsrc100 5.000 793.500 M7 R=25e-03 L=125e-12 C=1.80e-12
VDDvsrc101 1187.835 293.500 M7 R=15e-03 L=225e-12 C=2.80e-12
VDDvsrc102 695.000 5.000 M6 R=35e-03 L=325e-12 C=3.80e-12
VDDvsrc103 1187.835 493.500 M7 R=45e-03 L=425e-12 C=4.80e-12

Default Package Parameters in GUI

You can also set the default package R (resistance), L (Inductance), and C (Capacitance) for all power pins in the Power & Rail - Set Rail Analysis Mode form, as follows:

Package Parameters Embedded inside Power Pad Location File in GUI

In the GUI, the power pad location file can be supplied in the Advanced tab of the Power & Rail - Run Rail Analysis form. If you do not have a power pad location file, you can create it by clicking the XY File option, and then clicking the Create button.
