Command-Line Completion

You can use the Tab key within the software console to complete the text command names. After you type a partial text command name and press the Tab key, the software displays the exact command name that completes or matches the text you typed (if the string is unique to one text command) or all the commands that match the text you typed. For example, if you type set_power_ and press the Tab key, the software displays the following commands:

voltus 3> set_power_<Tab>

set_power_analysis_temperature  set_power_data       set_power_def_files set_power_include_file          set_power_lib_files  set_power_output_dir set_power_pads

If you type set_power_p<Tab>, the software completes the command name as follows:

voltus 3> set_power_pads

This function supports all Tcl commands, and the man first argument also supports it (for example, man set_power_p<Tab>).

Parameter Names Completion

The Tab completion capability is also available for parameter names starting with "-" for Voltus commands or for user commands registered with define_proc.

For example,

voltus 1> set_pg_library_mode -en

-enable_device_size_current_distribution  -enable_distributed_processing

-enable_multi_voltage_cap_generation

If you type set_pg_library_mode -enable_m<Tab>, the software completes the parameter name as follows:

voltus 1> set_pg_library_mode -enable_m

set_pg_library_mode -enable_multi_voltage_cap_generation

To view all parameters of a command, type the command name followed by - and press Tab.

For example:

voltus 1> rename_pg_library -

-cell_list_map_file  -merge_library_list_file  -output -output_library

Enum Values Completion

Tab completion can be used to view or complete enum type values for parameters.

For example, if you type set_pg_library_mode -cell_type followed by a space and press the Tab key, the software displays the following:

voltus 3> set_pg_library_mode -cell_type

macros stdcells techonly

If you type set_pg_library_mode -cell_type t<Tab>, the software completes the value as follows:

voltus 5> set_pg_library_mode -cell_type techonly

Unix File and Directory Names Completion

If you type a <Tab> in any other context, the Tcl shell will look for Unix file and directory names that match the string.

For example,

voltus 5> read_def test<Tab>

test.tcl test.def test.lef
