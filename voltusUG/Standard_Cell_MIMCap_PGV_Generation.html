Standard Cell MIMCap PGV Generation

For standard cell Metal-Insulator-Metal Capacitor (MIMCap) generation, the SPICE netlist "netlist.sp" includes a subcircuit that represents the MIMCap capacitance.

Required Input Files

  • Technology LEF
  • Cell LEF
  • Quantus technology file
  • LEFDEF layermap - optional. If you do not specify this file, Voltus will automatically generate it.
  • SPICE netlists for standard cells
  • SPICE model file containing MIMCap model. 

Procedure

To create MIMCap power-grid views for standard cells, complete the following steps:

  1. Read the LEF files for all the cells to be characterized. 
    TCL command:

    read_lib -lef tech.lef mimcap.lef

  2. Specify the settings for standard cell library characterization through the command line.
    TCL command:

    set_pg_library_mode \
        -power_pins {vdd 1.0} \
        -ground_pins {vss} \
        -celltype stdcells \
        -cell_list_file cells \
        -spice_subckts { netlist.sp } \
        -current_distribution       propagation \
        -spice_models  { \
            models/toplevel.l \
        } \
        -spice_corners              "TOP_TT" \
        -extraction_tech_file       qrcTechFile

    The following table lists the file description and file snippets for MIMCap characterization:

    File Description File Snippet
    SPICE netlist 'netlist.sp' - the netlist has a subcircuit that contains a C device with the area parameter.  .subckt mimcap vdd vss
    C1 vdd vss mimcap_sin area_mim=2e-11
    .ends

    SPICE model file 'toplevel.l' - the model file has “mimcap_sin” defined, and uses a flag “capflag_mim” to specify whether this subckt is to be used as MIMCap or not.


    Set .param capflag_mim=1 to enable MIMCap computation.

    .subckt mimcap_sin top bottom area_mim=0 wt=5u lt=5u multi=1 scale='scale_mim' capflag='capflag_mim'

    .......
    .......

    .LIB setup_mim
    .param scale_mim=1
    .param sigma_factor_mim=1
    .param capflag_mim=1
    .ENDL setup_mim

  3. Generate the output for power-grid library generation through the command line.
    TCL command:

    generate_pg_library -output stdcell_pgv

Output

The output directory will contain the stdcells.cl, stdcells.report, and stdcells.summary files similar to other standard cells. However, based on the value of capflag_mim parameter, there is a difference in the reported capacitance in stdcells.report :

  • .param capflag_mim=0 - Disables MIMCap computation so low capacitance is reported in the file: 

    =============================================================================================
    Cell                PowerNets       Capacitance     PowerGrid Views
    ---------------------------------------------------------------------------------------------|

    mimcap 
                        vdd(1.0000)     9.98341e-18          EARLY(1 taps) EM(1 taps) IR(1 taps)
                        vss(0.0000)     9.98341e-18          EARLY(1 taps) EM(1 taps) IR(1 taps)
     Cell Type = MACRO                                     Cell_Status: PASS
    ---------------------------------------------------------------------------------------------| 

  • .param capflag_mim=1 - Enables MIMCap computation so accurate capacitance is reported in the file:

    ==============================================================================================
    Cell                PowerNets       Capacitance     PowerGrid Views
    ----------------------------------------------------------------------------------------------|

    mimcap 
                        vdd(1.0000)     4.44003e-13          EARLY(1 taps) EM(1 taps) IR(1 taps)
                        vss(0.0000)     4.44003e-13          EARLY(1 taps) EM(1 taps) IR(1 taps)
     Cell Type = MACRO                                     Cell_Status: PASS
    ----------------------------------------------------------------------------------------------|
