Scale Static and Dynamic Currents

When power-grid optimization is not feasible in the regions of IR drop and electromigration violations, you can choose to scale static or dynamic currents on-the-fly to do what-if analysis. This analysis can help determine whether the designer should reduce activity, simultaneous switching and placement in the design to meet IR drop and electromigration threshold. You can scale static or dynamic currents using the "What-If Analysis Setup - Current" form. You have the option to scale current inside the design hierarchy and regions. You can interactively draw regions on the layout canvas. Additionally, there is an option to not scale currents for instances associated with clock network, however, this option is only available when scaling currents for design hierarchy. The current will be scaled for all components inside region.
