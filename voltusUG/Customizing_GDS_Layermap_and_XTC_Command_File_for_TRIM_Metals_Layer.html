Customizing GDS Layermap and XTC Command File for TRIM Metals Layer

The purpose of the CUT/TRIM layer is to cut the metal layers so as to separate the different supplies. The following diagram illustrates how the CUT layers separate the power and ground supplies:


To ensure that Voltus is able to identify the CUT layers, you need to manually modify these layers in the GDS layermap file. After modifying the layermap file, you need to customize the XTC command file for supporting these layers during power-grid library generation.

This chapter gives examples for simple (without CUT layers) and advanced (with CUT layers) GDS layermap files, and the corresponding XTC command files. It gives sample XTC command files for stop@via layer 0, 1, and 2.

Simple GDS Layer Map File

metal    M0    gds    180  250
via      VIA0  gds    159  250
metal    M1    gds    31   250
via      VIA1  gds    51   250
metal    M2    gds    32   250
via      VIA2  gds    52   250
metal    M3    gds    33   270   

Simple XTC Command File

CONNECT    M0    VIA0    M1    VIA1    M2    VIA2    M3

XTC Command File with STOP@VIA0

COPY    M0_0      M0
COPY    M0_1      M0
AND     M0_0      CM0_0      CM0_0_phy
AND     M0_1      CM0_1      CM0_1_phy
NOT     M0        CM0_0_phy  M0_0_phy
NOT     M0_0_phy  CM0_1_phy  M0_1_phy
DELETE  M0
COPY    M0_1_phy  M0
COPY    M1_0      M1
COPY    M1_1      M1
AND     M1_0      CM1_0      CM1_0_phy
AND     M1_1      CM1_1      CM1_1_phy
NOT     M1        CM1_0_phy  M1_0_phy
NOT     M1_0_phy  CM1_1_phy  M1_OUT
DELETE  M1
COPY    M1_OUT    M1
COPY    M2_0      M2
COPY    M2_1      M2
AND     M2_1      CM2        CM2_phy
NOT     M2        CM2_phy    M2_phy
DELETE  M2
COPY    M2_phy    M2
CONNECT     M0    VIA0    M1    VIA1    M2    VIA2    M3

XTC Command File with STOP@VIA1

COPY    M1_0      M1
COPY   M1_1      M1
AND    M1_0      CM1_0     CM1_0_phy
AND    M1_1      CM1_1     CM1_1_phy
NOT    M1        CM1_0_phy M1_0_phy
NOT    M1_0_phy  CM1_1_phy M1_OUT
DELETE M1
COPY   M1_OUT    M1
COPY   M2_0      M2
COPY   M2_1      M2
AND    M2_1      CM2       CM2_phy
NOT    M2        CM2_phy   M2_phy
DELETE M2
COPY   M2_phy    M2
CONNECT     M1    VIA1    M2    VIA2    M3

XTC Command File with STOP@VIA2

COPY    M2_0     M2
COPY    M2_1     M2
AND     M2_1     CM2         CM2_phy
NOT     M2       CM2_phy     M2_phy
DELETE  M2
COPY    M2_phy   M2
CONNECT     M2     VIA2     M3
