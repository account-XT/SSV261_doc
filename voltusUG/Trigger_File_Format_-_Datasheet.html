Trigger File Format - Datasheet

In Datasheet-based current characterization flow, the slews can be specified either mode-wise or globally. Therefore, following are the two formats of trigger file:

Format 1: Global Slews

CURRENT_CHARACTERIZATION_METHOD DATASHEET
CELL <cellname1>
MODE_NAME <name1>
CONDITIONAL_INPUT <conditional input statement for cellname1>
CONDITIONAL_PIN <pin_name> (rise|fall|both)
DATASHEET_DELAY <time>
DATASHEET_PARAMETER < {power_pin cap leakage_pwr} >
PEAK_CURRENT {power_pin peak_current}
END_MODE
DATASHEET_INPUT_SLEW <time>
DATASHEET_OUTPUT_SLEW <time>
END

Format 2: Mode-wise Slews

CURRENT_CHARACTERIZATION_METHOD DATASHEET
CELL <cellname1>
MODE_NAME <name1>
CONDITIONAL_INPUT <conditional input statement for cellname1>
CONDITIONAL_PIN <pin_name> (rise|fall|both)
DATASHEET_DELAY <time>
DATASHEET_PARAMETER < {power_pin cap leakage_pwr} >
PEAK_CURRENT {power_pin peak_current}
DATASHEET_INPUT_SLEW <time>
DATASHEET_OUTPUT_SLEW <time>
END_MODE

...

Example 1: Datasheet

CURRENT_CHARACTERIZATION_METHOD DATASHEET
CELL mem1
MODE_NAME READ
CONDITIONAL_INPUT = ( WZ & EZ )
CONDITIONAL_PIN CLK { RISE }
DATASHEET_DELAY 7.6913ns
DATASHEET_PARAMETER {{ VDDAR 0.1715pf 2.496e-05mW }{ VDDPR 18.8985pf 3.63e-06mW }{ VBBNW 0.1780pf 2.601e-06mW }}
END_MODE

MODE_NAME WRITE
CONDITIONAL_INPUT = ( !WZ & !WTZ & EZ )
CONDITIONAL_PIN CLK { RISE }
DATASHEET_DELAY 8.216ns
DATASHEET_PARAMETER {{ VDDAR 0.1715pf 1.355e-06mW }{ VDDPR 0.1715pf 1.81e-05mW } { VBBNW 0.1715pf 2.614e-06mW }}
END_MODE

MODE_NAME STANDBY
CONDITIONAL_INPUT = ( !EZ )
CONDITIONAL_PIN CLK { RISE }
DATASHEET_DELAY 0.6913ns
DATASHEET_PARAMETER {{ VDDAR 0.1715pf 2.902e-05mW }{ VDDPR 0.2024pf 1.81e-05mW } { VBBNW 0.1723pf 6.92e-07mW }}
END_MODE

DATASHEET_INPUT_SLEW 0.6ns
DATASHEET_OUTPUT_SLEW 0.3682ns
END
