Getting Started

For product, release, and installation information, see the README file at any of the following locations:

  • downloads.cadence.com, where you can review the README before you download the software
  • In the software installation, where it is also available when you are using or running the software

The README file lists the supported and compatible platforms for this release.

Setting Up the Run-Time Environment

If install_dir is the location of your Voltus installation, you should set up your run-time environment like this:

  • Add the install_dir/bin directory to your path. The bin directory has links to all the public executables in the install hierarchy.
  • Add install_dir/share/voltus/man to your MANPATH envar if you want the legacy Voltus man pages to be available from the Unix man command.
  • Add install_dir/share/voltus/stylus/man to your MANPATH envar if you want the Common UI Voltus man pages to be available from the Unix man command.
  • Add install_dir/share/tcltools/man to your MANPATH envar if you want the Tcl man pages to be available from the Unix man command

For example, you might add this to your startup shell script:

set install_dir = /SSV231/latest.main/lnx86
set path = ($install_dir/bin $path)
setenv MANPATH $install_dir/share/voltus/man:$install_dir/share/tcltools/man:$MANPATH

When Voltus launches, it automatically adds either the legacy or the Common UI man pages (depending on the -stylus option) and the Tcl man pages to the beginning of the current MANPATH inside Voltus. Therefore, from within Voltus, the man command will see both sets of man pages before any other man pages.

The Voltus Console

When you start Voltus in the non-GUI environment using the -no_gui parameter, the UNIX window (shell tool, xterm, and so on) where you start the Voltus session is called the Voltus console. This is where you enter all Voltus text commands and where the software displays messages. When a session is active, this console displays the following prompt:

voltus>

When you start Voltus in the GUI environment, the Voltus console is displayed within the main Voltus window.

If you use the console for other actions, for example, to use the vi editor--the session suspends until you finish the action.

If you suspend the session by typing Control-z, the voltus> prompt is no longer displayed. To return to the Voltus session, type fg, which brings the session to the foreground.

To start a Voltus session, type voltus with the appropriate parameters on the UNIX/Linux command line. If you type a command without parameters, the software starts in the GUI mode and creates a log file and a command file. The system attempts to check out the license with the most functionality, then the license with the next most functionality, and so on.

voltus

Starts one of the following products:

  • Voltus IC Power Integrity Solution L
  • Voltus IC Power Integrity Solution XL
