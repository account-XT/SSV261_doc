Trigger File Format: FSDB

The file format of the trigger file is:

CURRENT_CHARACTERIZATION_METHOD FSDB
CELL <cellname1>
MODE_NAME <name1>
CONDITIONAL_INPUT <conditional input statement for cellname1>
CONDITIONAL_PIN <pin_name> (rise|fall|both)
FDSB_START_TIME <time>
FSDB_END_TIME <time>
END_MODE
FSDB_PATH <path>
FSDB_NET_NAME <net> [<generic_name>]
END

Example

CURRENT_CHARACTERIZATION_METHOD FSDB
CELL mem1
MODE_NAME READ
CONDITIONAL_INPUT = ( !ATPGM & EZ & !SCAN & !TEZ & TM & !TPAGE & !TWTZ & !TWZ )
CONDITIONAL_PIN CLK { RISE }
FDSB_START_TIME 0ns
FSDB_END_TIME 10ns
END_MODE
FSDB_PATH "new.fsdb"
FSDB_NET_NAME "i1(vvddpr)" "VDDPR"
FSDB_NET_NAME "i1(vvddar)" "VDDAR"
FSDB_NET_NAME "i1(vvddp)" "VDDP"
FSDB_NET_NAME "i1(vvss)" "VSS"
END

You can read multiple FSDBs for different modes, and specify different start and end times for each mode. The following example shows that 2 FSDB files are read, wherein read.fsdb is read for the READ mode, and write.fsdb is read for the WRITE mode:


CURRENT_CHARACTERIZATION_METHOD FSDB
CELL BLULP00256032040
MODE_NAME READ
CONDITIONAL_INPUT = ( !ATPGM & EZ & !SCAN & !TEZ & TM & !TPAGE & !TWTZ & !TWZ )
CONDITIONAL_PIN CLK { RISE }
FDSB_START_TIME 0ns
FSDB_END_TIME    10ns
FSDB_PATH "read.fsdb"
FSDB_NET_NAME "i1(vvddpr)"  "VDDPR"
FSDB_NET_NAME "i1(vvddar)"  "VDDAR"
END MODE

MODE_NAME WRITE
CONDITIONAL_INPUT = ( !ATPGM & EZ & !SCAN & !TEZ & TM & !TPAGE & !TWTZ & !TWZ )
CONDITIONAL_PIN CLK { RISE }
FDSB_START_TIME 0ns
FSDB_END_TIME    15ns
FSDB_PATH "write.fsdb"
FSDB_NET_NAME "i1(vvddpr)"  "VDDPR"
FSDB_NET_NAME "i1(vvddar)"  "VDDAR"
END MODE
END
