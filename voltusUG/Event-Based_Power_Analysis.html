Event-Based Power Analysis

A seamless unified solution to support multiple power analysis flows simultaneously. Event-based power analysis supports the following power analysis methods:

  • dynamic mixedmode
  • dynamic vector-based
  • static
  • vector profile

In this model, the tool performs accurate state-based power estimation for all events of a scenario in a design. Event-Based Power Analysis is applicable to all event-based vectors, such as VCD, FSDB, SHM, and PHY.

Tcl Scripts for Event-Based Power Analysis

The Tcl scripts for different flows using the event-based power analysis method are as follows:

Static Power and Current

set_power_analysis_mode -method event_based \
                        -write_static_currents true \
                        -handle_glitch true \
                        -equivalent_annotation true \

Dynamic Power and Current

set_power_analysis_mode -method event_based \
                        -write_dynamic_currents true \
                        -handle_glitch true \
                        -equivalent_annotation true

Dynamic Power and Current for RTL vectors

set_power_analysis_mode -method event_based \
                        -write_dynamic_currents true \
                        -enable_state_propagation true \
                        -handle_glitch true \
                        -equivalent_annotation true

Dynamic Power and Current for Worst Power Window

set_power_analysis_mode -method event_based \
                        -write_dynamic_currents true \
                        -worst_step_size 10ns \
                        -handle_glitch true \
                        -equivalent_annotation true

Mixed Mode: Add simulation for design not annotated by vectors

set_power_analysis_mode -method event_based \
                        -write_dynamic_currents true \
                        -add_simulation true \
                        -enable_state_propagation true \
                        -handle_glitch true \
                        -equivalent_annotation true
