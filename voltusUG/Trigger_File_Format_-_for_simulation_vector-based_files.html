Trigger File Format - for simulation vector-based files

The file format of the trigger file is as follows:

CURRENT_CHARACTERIZATION_METHOD SIMULATION
SIMULATOR APS
CELL <cellname1>
MODE_NAME <name1>
CONDITIONAL_INPUT <conditional input statement for cellname1>
CONDITIONAL_PIN <pin_name> (rise|fall|both)
CONDITIONAL_STIMULUS_FILE <usim1.txt>
END_MODE
END

where,

"!" denotes low state of the signal

"&" denotes boolean AND operation

"|" denotes boolean OR operation

For each mode, you need to specify separate stimulus files (for example usim1.txt and usim2.txt). The stimulus files contain the PWL definitions that will be used by UltraSim for simulating the specific mode. 

The format of the stimulus file is a spice format that can be directly included in simulation setup.

Example 1 

CURRENT_CHARACTERIZATION_METHOD SIMULATION
SIMULATOR APS
CELL mem1
MODE_NAME READ
CONDITIONAL_INPUT = (! ATPGM & EZ &! SCAN &! TEZ & TM &! TPAGE &! TWTZ &! TWZ)
CONDITIONAL_PIN CLK {RISE}
CONDITIONAL_STIMULUS_FILE usim.txt
END_MODE
END

Example 2

CURRENT_CHARACTERIZATION_METHOD    SIMULATION
CELL ARM_32x64
MODE Read
CONDITIONAL_INPUT = ( !CEN & !WEN )
CONDITIONAL_PIN CLK { RISE }
CONDITIONAL_STIMULUS_FILE = /icd/socepvvob8/SOCE_newdesign/EPS_design/EPS_libgen_prod_data/libgen/Libgen_SpectreSKI/16x32memory/ARM_32x64/ARM_32x64.vectors start=1ns stop=20ns 
END_MODE

MODE Write
CONDITIONAL_INPUT = ( CEN & WEN )
CONDITIONAL_PIN CLK { RISE }
CONDITIONAL_STIMULUS_FILE = start=20ns stop=30ns
END_MODE

SIM_START_TIME 1ns
SIM_END_TIME   30ns
SIM_STEP_SIZE 100ps

END
