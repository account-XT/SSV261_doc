Tcl Command Examples for What-If Rail Analysis

The following are the examples of Tcl flow for what-if rail analysis:

Example 1: Scale Resistance of the Power-Grid

# Import design
read_design ….
# Power calculation
set_power_analysis_mode ….
report_power
# Rail analysis
set_power_data …
set_rail_analysis_mode ….
set_pg_nets ….
set_power_pads ….
analyze_rail ….
# View results
read_power_rail_results...
report_power_rail_results...
# What-if analysis
scale_what_if_resistance -reset
scale_what_if_resistance -net VSS -global -layer M7 -scale 0.5
scale_what_if_resistance -net VDD -region {100 100 200 200} -layer M7 -scale 0.5
scale_what_if_resistance -net VDD -region {400 400 600 600} -scale 0.5
analyze_rail …

read_power_rail_results...
report_power_rail_results...
