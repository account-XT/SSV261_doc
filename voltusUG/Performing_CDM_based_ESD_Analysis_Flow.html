Performing CDM based ESD Analysis Flow

The following steps are performed to run the CDM based ESD Analysis flow:

  1. Load the design data or the Innovus database.
  2. Perform power calculation to generate the driver/receiver pairs.
    You must specify the -create_driver_db parameter of the set_power_analysis_mode command attribute to determine all the drivers/receivers on the ground net.
  3. Set up rail analysis for extraction.
  4. Perform IR Drop analysis for every driver/receiver pair and report voltage drop above the given limit. Use the analyze_esd_voltage command to provide the current injection points (sinks), the current distribution layer (source), and the total ESD current to be distributed.
    The command generates a report containing all the violations where potential difference across driver/receiver is greater than the given threshold.


Sample Tcl Script to Run CDM Based ESD Analysis Flow

The following is a sample Tcl script to run this flow:
##Load the design
read_lib -lef { tech.lef all_cell.lef }
read_lib {all_cell_lib}
read_verilog chip_top.v.gz
set_top_module chip_top
specify_def { input_data/def/chip_top.def ...}
read_twf ../design.twf.gz
specify_spef { input_data/spef/chip_top.cmax_hot.spef ....}
##Run power calculation set_dc_sources vdd -power -voltage 1.32 set_dc_sources gnd -ground -voltage 0.0 set_default_switching_activity -input_activity 0.2 set_power_analysis_mode -method dynamic_vectorless  -write_static_currents true -disable_static false -create_driver_db true
report_power -outfile power.rpt
##Set up rail analysis set_pg_nets -net gnd -voltage 0 -threshold 0.01 set_pg_nets -net vdd -voltage 1.32 -threshold 1.2 set_rail_analysis_domain -name PD -pwrnets vdd -gndnets gnd set_power_pads -net gnd -format xy -file vss.pad.check set_rail_analysis_mode -method static -accuracy hd -power_grid_library { pgv/pgv_output/techonly.cl all_cells_pgv.cl} } -temperature 125 -ignore_fillers false -ignore_decaps false  -cluster_via1_ports false
##Perform IR drop analysis analyze_esd_voltage -net gnd -driver_receiver_file ./POWER/driverdb_railgnd  -esd_pin_location_file ./epinfile -current_distribution_layer m1 -total_current 8 -report FULL_new_gnd_esd_cdm.rpt
