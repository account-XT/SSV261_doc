Analyze AC Signal Electromigration

The charged particles of a conductor in an electric field give up kinetic energy when they collide with atomic ions. The increase in this kinetic energy of the ions manifests itself as heat and a rise in temperature. Wire self-heating or Joule Heating describes a phenomenon where high AC currents flowing through the resistive interconnects causes extreme temperature. The following diagram illustrates signal net experiencing AC current as load capacitance is charged and discharged:


In order to prevent wire self-heating or AC signal electromigration, signal interconnects should be analyzed for their AC current carrying capacity and measured against the AC current limits specified by foundry.

Earlier, the AC current density limits could only be defined in the Technology LEF file, and only root-mean-square (RMS) current limit check was supported. Now, the software supports RMS current limit, peak AC current, and average AC current limit checks. However, for peak AC current and average AC current limits, these limits must be defined in the QRC Technology file. For RMS current limits, you can define them in both the Technology LEF and QRC Technology files. To achieve more accurate results, it is recommended to use the ECSM timing library.

Sample Tcl Script for AC Signal EM Analysis

The following is the sample Tcl script for AC Signal EM Analysis:

# read design

read_lib -lef <lefs>
read_lib <timing libs>
read_verilog <verilog netlist> 
set_top_module <design name>
read_def <def netlist>

# create analysis view

create_library_set -name <library set name> -timing <timing libs>
create_rc_corner -name <rc corner name> -qx_tech_file <qrc Tech>
create_delay_corner -name <delay corner name> -rc_corner <rc corner name>
create_constraint_mode -name <constraint name> -sdc_files <timing constraints>

create_analysis_view -name <view name> -constraint_mode <constraint name> \
-delay_corner <delay corner name>

set_analysis_view -setup <view name> -hold <view name>

read_spef -rc_corner <rc corner name> <signal parasitics>


set_default_view -hold <view name>


If you use the Quantus-generated extended SPEF file format in the signal EM flow with -effort_level medium or high, you must specify the -extended and -starN parameters with the read_spef command.

# Switching factor of 100% on data network

set_signal_em_analysis_mode \
-detailed \
-toggle 1.0 \
-report AC.1.0.rpt

# Switching factor of 50% on data network

set_signal_em_analysis_mode \
-detailed \ 
-toggle 0.5 \
-report AC.0.5.rpt

# set input activity and propagate it to get realistic effective frequency

set_default_switching_activity \
-input_activity 0.2 \
-seq_activity 0.15 \
-clock_gates_output 2.0 \
-period 7.0


propagate_activity


write_tcf dma_mac.tcf


read_activity_file \
-format TCF \ 
-set_net_freq true dma_mac.tcf


set_signal_em_analysis_mode \
-method {rms avg peak}
-detailed \
-useQRCTech \
-avgRecovery 0.5 \
-ict_em_models ../../EMdata.ict \
-extraction_tech_file qrc_file 
-em_temperature 105 \
-report AC.tcf.rpt

verify_AC_limit
