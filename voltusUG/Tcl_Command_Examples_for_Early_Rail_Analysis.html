Tcl Command Examples for Early Rail Analysis

The following are the examples of Tcl command for Early Rail Analysis:

Example 1: Region-based Power Specification

An example Tcl command for the Floorplan stage design grid analysis with current regions is as follows:

read_lib -lef design/full.lef
read_verilog design/test.v.gz 
set_top_module test
read_def design/full.def
set_power_data -format area -power 1 -bias_voltage 1
set_rail_analysis_mode -method era_static -accuracy xd \
-extraction_tech_file design/tech.tch -era_current_region_file design/current_region
set_pg_nets -net VDD -voltage 1.1 -threshold 1.067
set_power_pads -net VDD -format xy -file pads/vdd.pp
analyze_rail -type net -output early_vdd VDD

Example 2: User-specified Current Regions and Instance Power File for Total Power

An example Tcl command for partially placed design grid analysis with user-defined macro power file is as follows:

set_pg_nets -net VSS -voltage 0.000 -threshold 0.020
set_power_pads -net VSS -format xy -file pads/VSS.pp
set_power_data -format area -bias_voltage 1 -power 1.5\ power/instance_power_file.txt
set_rail_analysis_mode -method era_static -accuracy xd \
-extraction_tech_file design/tech.tch -era_current_region_file design/current_region
analyze_rail -type net -output user_power_analysis VSS

Example 3: Autogenerated Current Regions and Instance Power File from Total Power

An example Tcl command for partially placed design grid analysis with tool-generated power file is as follows:
set_power_data -format area -power 1.5 -bias_voltage 1 set_rail_analysis_mode -extraction_tech_file tech.tch -accuracy xd -ignore_shorts true \
-method era_static -era_current_distribution all -era_current_distribution_layer Metal1 \
-era_current_distribution_unplaced_area diearea 
 ##When -era_current_distribution is set to all, the software will generate both the instance power file (for placed instances) and the current region file (for unplaced instances).

set_power_pads -net VDD_AO -format xy -file design/super_filter_VDD_AO.pp
set_power_pads -net VDD_SW -format xy -file design/super_filter_VDD_external.pp
set_power_pads -net VSS -format xy -file design/super_filter_VSS.pp
set_pg_nets -net VDD_AO -voltage 0.9 -threshold 0.85  -force
set_pg_nets -net VSS -voltage 0.0 -threshold 0.05  -force
set_rail_analysis_domain -name core -pwrnets { VDD_AO VDD_SW } -gndnets VSS
analyze_rail -type domain -output era_power_analysis core

Example 4: Power Engine Calculated Power

An example Tcl command for fully placed design grid analysis is as follows:
set_power_analysis_mode -method static -write_static_currents true
set_default_switching_activity -global_activity 0
set_dynamic_power_simulation -period 70ns -resolution 50ps
report_power
set_power_data -format current -scale 1 "static_power/static_VDD_AO.ptiavg\ static_power/static_VDD_SW.ptiavg static_power/static_VSS.ptiavg" set_rail_analysis_mode -power_grid_library tech.pgv -accuracy hd \
-ignore_shorts true -method era_static 

set_power_pads -net VDD_AO -format xy -file design/super_filter_VDD_AO.pp
set_power_pads -net VSS -format xy -file design/VSS.pp
set_pg_nets -net VDD_AO        -voltage 0.9 -threshold 0.85  -force
set_pg_nets -net VSS           -voltage 0.0 -threshold 0.05  -force
set_rail_analysis_domain -name core -pwrnets { VDD_AO VDD_SW } -gndnets VSS
analyze_rail -type domain -output power_engine_analysis core

Additional Tcl Command Examples for Early Rail Analysis

  • An example Tcl command for Power Gate Design with auto area based power distribution for remaining placed and unplaced instances. Here user specified current regions and macro power is also specified for accounting for some instances of the design as follows:
    read_design -physical_data design.dat CHIP
set_pg_nets -net VDD -voltage 1.1 -threshold 0.9
set_power_pads -net VDD -format xy -file design/vdd.pad
set_power_data -bias_voltage 1.2 -power 1.2 -format area\ power/macro_power_file.txt
set_rail_analysis_mode -method era_static -accuracy xd \
-extraction_tech_file design/tech.tech -era_power_gate_file design/power_gate_file\ 
-era_current_region_file design/user_current_regions -era_current_distribution all \
-era_current_distribution_layer M1
analyze_rail -type net -output mixed_power_analysis VDD
  • An example Tcl command for static analysis, where ERA is also doing follow pin routing and virtual via generation is as follows:
    read_design -physical_data design.dat CHIP
set_power_data -format area -power 0.744 -bias_voltage 1.2\ power/cell_power.txt
set_rail_analysis_mode -method era_static -accuracy xd  -extraction_tech_file tech.tch \
-era_current_distribution_layer MET1 -era_current_distribution unplaced \
-era_current_region_file power/cur_region -era_insert_virtual_followpins standard \
-era_skip_virtual_via_by_type none
set_pg_nets -net VDD -voltage 1.1 -threshold 1.067
set_power_pads -net VDD -format xy -file pads/vdd.pp
analyze_rail -type net -output ./early_vdd VDD
  • An example Tcl command for MSMV dynamic analysis is as follows:
    read_verilog design/test.v.gz 
set_top_module test
read_def design/full.def
set_pg_nets -net VSS -voltage 0 -threshold 0.18
set_pg_nets -net VDDm -voltage 0.84 -threshold 0.756
set_pg_nets -net VDD -voltage 0.84 -threshold 0.756
set_power_pads -net VDD -format xy -file design/vdd.pp
set_power_pads -net VDDm -format xy -file design/vddm.pp
set_power_pads -net VSS -format xy -file design/vss.pp
set_power_data -format current { instance_current_files/dynamic_VSS.ptiavg\ instance_current_files/dynamic_VDD.ptiavg\ instance_current_files/dynamic_VDDm.ptiavg\ instance_current_files/dynamic_VDDlu.ptiavg\ instance_current_files/dynamic_VDDau.ptiavg}

set_rail_analysis_mode -method era_dynamic -accuracy xd \
-power_grid_library { stdcells_accurate/accurate_stdcells.cl \ lpcells_accurate/accurate_stdcells.cl  memories_accurate/MEM.cl  } -off_rails VDDau

set_rail_analysis_domain -name PD -pwrnets {VDD VDDm} -gndnets VSS
analyze_rail -type domain PD
