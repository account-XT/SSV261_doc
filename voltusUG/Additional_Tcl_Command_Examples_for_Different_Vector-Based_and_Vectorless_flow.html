Additional Tcl Command Examples for Different Vector-Based and Vectorless flow

The following are the additional Tcl command examples:

Tcl Commands for Vector-Based Flow - Multiple VCD/FSDB Files

The Tcl commands for dynamic vector-based power analysis are shown below.

set_power_analysis_mode -method dynamic_vectorbased -corner max \
    -power_grid_library {fast_allcells.cl} -disable_static true 

read_activity_file -format vcd -start 10ns -end 20ns -scope top/block design.vcd
set_switching_activity -activity 0.1
set_power -cell BUFX2MTL -pwl {0 0 1 0 2 1 3 0}
set_power_output_dir dynamic_vectorbased_max
report_power

You can specify multiple VCD/FSDB files with different windows for the vector-based dynamic analysis/vector profiling flow and write out a single dynamic current file/profiling report. The Tcl commands for dynamic vectorbased power analysis using multiple VCD files are shown below:

set_power_analysis_mode \
-start_time_alignment true -disable_static false \
-power_grid_library " $testcaseRoot/library_pv.cl"\ 
-method vector_profile -x_transition_factor 1 -z_transition_factor 1 \
-vector_profile_mode {activity} -worst_step_size 2ns

By default, the software aligns all signals at t=0 (or min start time). You can disable the start time alignment by setting set_power_analysis_mode -start_time_alignment to false.


read_twf $testcaseRoot/pt.tw_ckt2 
read_activity_file -format VCD -scope top -start 3 -end 10 top.vcd 
read_activity_file -format VCD -block block1 -start 5 -end 12 block1.vcd 
read_activity_file -format VCD -block block2 -start 4 -end 15 block2.vcd 
report_power -outfile activity.rpt

#Simulation period is max(endtime - starttime), that is, 11ns.

#Start times for all VCDs will be aligned at t=0

You can specify the read_activity_file command multiple times to read multiple VCD files. When you specify the -start_time_shift parameter of this command, the software first aligns all the signals of the specified activity files at time zero, and then shifts the start time of the activity file specified with the -start_time_shift parameter. A sample Tcl command to illustrate this is given below:


set_power_analysis_mode -method dynamic_vectorbased 
read_activity_file -format VCD -scope top -start 3 -end 10 top.vcd 
read_activity_file -format VCD -block block1 -start 5 -end 12 block1.vcd -start_time_shift 2ns 
read_activity_file -format VCD -block block2 -start 4 -end 15 block2.vcd 
report_power

#Simulation period is max(endtime - starttime), that is, 11ns.

#Start times for the top + block2 VCD will be aligned at t=0 whereas for block1.vcd it will start at 2ns.

Tcl Command for Probability-Based Vectorless Flow

The Tcl commands for dynamic probability-based vectorless power analysis are shown below.


set_power_analysis_mode -method dynamic_vectorless -corner max \
                        -power_grid_library {fast_allcells.cl}
set_default_switching_activity -input_activity 0.2 -seq_activity 0.1 \
                               -hier top/block/module1
read_activity_file -format vcd -start 10ns -end 20ns -scope top/block design.vcd
set_switching_activity -activity 0.1 
set_power -cell BUFX2MTL -pwl {0 0 1 0 2 1 3 0}
set_dc_sources {VDD VDD1} -power -voltage 1.2
set_power_output_dir dynamic_vectorless_max 
report_power

You can use the set_dc_sources command to specify the operating voltages of the power/ground nets. This command is used to specify a global voltage or voltages for specific power nets in the design.

# To enable multi-threading in dynamic vectorless flow

set_multi_cpu_usage -localCpu 4
set_power_analysis_mode -method dynamic_vectorless -corner max \ 
 -power_grid_library {fast_allcells.cl} -disable_static true
 set_default_switching_activity -input_activity 0.2 -seq_activity 0.1 \
                               -hier top/block/module1 
read_activity_file -format vcd -start 10ns -end 65ns -scope top test.vcd 
set_switching_activity -activity 0.1 
set_power -cell BUFX2MTL -pwl {0 0 1 0 2 1 3 0} 
set_power_output_dir dynamic_vectorless_max 
report_power

Tcl Command for State-Propagation-Based Vectorless Flow with User-Defined Activity

The Tcl commands for dynamic state-propagation-based vectorless power analysis are shown below.


set_multi_cpu_usage -localCpu 4
set_default_switching_activity -input_activity 0.2 -seq_activity 0.1 \
                               -clock_gates_output 2.0 
set_power_analysis_mode -method dynamic_vectorless -enable_state_propagation true -power_grid_library {fast_allcells.cl}

set_dynamic_power_simulation -period 20ns -resolution 50ps
report_power -output dynamic_power

Tcl Command for State-Propagation-Based Vectorless Flow with User-Defined Power Targets

The Tcl commands for state-propagation-based vectorless power analysis with user-defined power targets are shown below.

Example 1: Enable the power target flow with fixed CGO

set_power_analysis_mode \
...
-method dynamic_vectorless \
-enable_state_propagation true \
-enable_power_target_flow true \
-enable_xp true \
-keep_clock_gate_ratio_in_iterations true
...

##Set power target at the top-level
set_power 3mW
...

##User-specified CGO
set_default_switching_activity \
-clock_gates_output 0.4

In this case, the clock gate output is fixed, while the values for input, macro, and sequential activities will be adjusted to meet the power target of 3mW.

target_0: (cg_ratio 0.2 seq_activity 0 input_activity 0 macro_activity 0)
target_0: (cg_ratio 0.2 seq_activity 1 input_activity 1 macro_activity 1)
target_0: (cg_ratio 0.2 seq_activity 0.54 input_activity 0.54 macro_activity 0.54)
Achieved total power 0.0031013 in 2 iterations

Example 2: Enable the power target flow with a single power target of 3mW

set_power_analysis_mode \
...
-method dynamic_vectorless \
-enable_state_propagation true \
-enable_power_target_flow true \
-enable_xp true \
...
##Set power target at the top-level
set_power 3mW
...

In this case, the values for input, macro, clock gate output, and sequential activities will be adjusted to meet the power target of 3mW.

target_0: (cg_ratio 0 seq_activity 0 input_activity 0 macro_activity 0)

target_0: (cg_ratio 0 seq_activity 1 input_activity 1 macro_activity 1)
target_0: (cg_ratio 0.44 seq_activity 0.44 input_activity 0.44 macro_activity 0.44)
Achieved total power 0.00310119 in 2 iterations

Example 3: Enable the power target flow with two power targets

set_power_analysis_mode \
...
-method dynamic_vectorless \
-enable_state_propagation true \
-enable_power_target_flow true \
-enable_xp true \
...

##Set 2 power targets (top and physical/logical hierarchy)
set_power 3mW
set_power 1mW -instance ring
...

In this case, the values for input, macro, clock gate output, and sequential activities will be adjusted to meet the two power targets.

target_0: (cg_ratio 0 seq_activity 0 input_activity 0 macro_activity 0)  
target_1: (cg_ratio 0 seq_activity 0 input_activity 0 macro_activity 0)


target_0: (cg_ratio 1 seq_activity 1 input_activity 1 macro_activity 1)  
target_1: (cg_ratio 1 seq_activity 1 input_activity 1 macro_activity 1)


target_0: (cg_ratio 0.44 seq_activity 0.44 input_activity 0.44 macro_activity 0.44)
target_1: (cg_ratio 0.79 seq_activity 0.79 input_activity 0.79 macro_activity 0.79)


target_0: (cg_ratio 0.38 seq_activity 0.38 input_activity 0.38 macro_activity 0.38)
target_1: (cg_ratio 0.79 seq_activity 0.79 input_activity 0.79 macro_activity 0.79)


target_0: (cg_ratio 0.35 seq_activity 0.35 input_activity 0.35 macro_activity 0.35) 
target_1: (cg_ratio 0.79 seq_activity 0.79 input_activity 0.79 macro_activity 0.79)


Achieved total power 0.00306517 in 4 iterations
