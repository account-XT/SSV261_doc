Library Generation Setup in Multi-CPU Mode

The Library Generation flow supports multi-CPU processing to improve the overall run time for large designs. You can enable this flow using the -enable_distributed_processing parameter of the set_pg_library_mode command.

The flow requires separate Tcl scripts for the macro and standard cells. For macros, you need to specify the -macros_config_file parameter of the set_pg_library_mode command to provide configuration details for each macro cell per Library Generation run. This is an additional input for macros cell type wherein you can provide macro-specific Spice and GDS. The format of the file is:

CELL <cell1>
GDS_FILE <gds_file1>
SUBCKT_FILE <subckt_file1>
TRIGGER_FILE <trigger_file_path>
POWER_GATE_PARAMS <parameters>

CELL <cell2>
GDS_FILE <gds_file1>
SUBCKT_FILE <subckt_file1>
...

CELL is the keyword to specify a new cell that is to be characterized. This is a mandatory keyword. This keyword is followed by optional keywords, like GDS_FILE and SUBCKT_FILE, that are specific to the cell.

The use model for Library Generation in the multi-CPU mode is:

set_distribute_host -local -timeout 240
set_multi_cpu_usage -localCpu 4
set_pg_library_mode -enable_distributed_processing true
-celltype macros|stdcells
-macros_config_file config.file #applicable only for macros
.....
generate_pg_library -output <directory_name>
