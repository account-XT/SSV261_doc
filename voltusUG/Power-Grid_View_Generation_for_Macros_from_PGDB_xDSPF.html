Power-Grid View Generation for Macros from PGDB/xDSPF

You can use PGDB and xDSPF as the input to library characterization for generating power-grid libraries in advanced node designs. This feature supports third-party extractors that create an extracted view of the design in the xDSPF format. In addition, library characterization supports the PGDB format netlist generated using the Quantus extractor. When you specify xDSPF or PGDB as inputs, GDS files are not required.

Tcl command for PGDB input:

set_pg_library_mode ...
set_advanced_pg_library_mode ...
    -pgdb_layermap ../pgdb_layermap.txt 
    -pgdb_list_file ../voltus_pgdb_dynamic_1/cell1.hdr

#Specify the -pgdb_layermap and -pgdb_list_file parameters to generate PGV from an external PGDB.

The syntax of the PGDB header file is as follows:

CELL cell_name
PGDB pgdb_directory

The PGDB directory contains the PGDB for all the power and ground nets of the cell. The PGDB directory has cellname_Netname.* files.

The syntax of the PGDB layermap file is as follows:


#LibGen type
 

technology file layername
 

keyword 

PGDB layername
 

metal
 

METAL_1
 

pgdb
 

metal1
 

via
 

VIA_1
 

pgdb
 

via1
 

metal
 

METAL_2
 

pgdb
 

metal2
 

via
 

VIA_2
 

pgdb
 

via2

When generating PGV from Voltus-Fi, some of the layers are not required for digital analysis, but must be preserved to maintain connectivity. Voltus supports mapping of these layers to a special layer "connectivity" in the layermap file.

Example:

diff connectivity pgdb tn_diff
diff connectivity pgdb tp_diff
metal metal1 pgdb metal1

Tcl command for xDSPF input:

set_pg_library_mode ...
set_advanced_pg_library_mode 
    -import_xdspf_list_file ../voltus_xdspf_dynamic_1/cell2.xdspf 
    -xdspf_layermap ../voltus_xdspf_dynamic_1/layermap_dspf

#Specify the -import_xdspf_list_file and -xdspf_layermap parameters to generate PGV from an xDSPF netlist.

The syntax of the xDSPF layermap file is as follows:

#-----------------------------
# layer      process 
# type       layername 
# ----------- --------------- 
metal       METAL3 
via         VIA3 
metal       METAL2 
via         VIA2

You must define layers in the stack from the top most layers to the bottom most layers. With reference to this layermap stack, the library characterizer will create the PGDB for the layers as defined in the xDSPF layermap file.
