ESD Rule File Examples

The following are examples of different rule types.

Rule for computing clamp-to-clamp resistance

Rule c2c_rule1
type clamp2clamp
power -nets VDD
ground -nets VSS
clamp_types -from "CLAMPTYPE1" -to  "CLAMPTYPE2"    
OR clamp_cells -from "CLAMPCELL1" -to "CLAMPCELL2"
reff_threshold 3
end rule

Rule for computing bump-to-clamp resistance

Rule b2c_rule2
type bump2clamp
clamp_cells "DIODE1 CLAMP1"
power -nets all -short_bumps true/false
ground -nets all -short_bumps true/false
reporting both 
reff_threshold 2.5 
report_line_threshold 500
reff_report_threshold 10
end rule

Rule for computing bump-to-clamp resistance (shorted clamps)

Rule b2c_rule
type bump2clamp 
clamp_cells "ESDCLAMP"
ground -nets NET1 -short_bumps false
reporting both
reff_threshold 3.5
pass_criteria all
effective_calculation true
parallel_clamp_threshold 2
end rule

Rule for computing bump-to-bump resistance (shorted bumps)

Rule rule_shorted_bump_device
type bump2bump
power -nets all -short_bumps true
ground -nets all -short_bumps true
lerp_threshold 10
skip_domains VSS0:VDD
esd_device_check true
end rule

Rule for computing bump-to-bump resistance (unshorted bumps)

Rule rule_unshorted_bump_device
type bump2bump
power -nets all -short_bumps false
ground -nets all -short_bumps false
lerp_threshold 10
skip_domains VDD0:VSS
esd_device_check true
end rule

Rule for computing radius-based bump-to-bump resistance check

Rule b2b_rule_region
type bump2bump
power -nets all
ground -nets all
parallel_reff_threshold 10
arc_reff_threshold 5
lerp_threshold 5
path_reff_threshold 10
bump_region_xy_size 200 200
end Rule

Rule for computing bump-to-bump resistance check for IV curve PGV models

Rule b2b_rule_non_linear_all_net
type bump2bump  
nets -from all -to all -reporting both -report_threshold 0.8 
setup -ahdl_include /DATA/models.va
current 1.5
em_results true
end rule

Rule for computing bump-to-instance resistance

Rule b2i_rule1 
type bump2instance 
power -nets VDD
ground -nets VSS
instance_list_file inst_list -include
cell_list_file cell_list -include
end Rule

The following is the content of the cell_list file:

NAND2

NAND4

The following is the content of the inst_list file:

INST/i_127
INST/i_131

Rule for computing clamp-to-instance resistance

Rule c2i_rule1 
type clamp2instance 
power -nets VDD
ground -nets VSS
clamp_cells "cell_32x64"
reff_threshold 20
pass_criteria  all
end Rule

Rule for reporting isolated bump/clamps

Rule connectivity
type connectivity
clamp_cells CLAMP_A CLAMP_B
power -nets all
ground -nets all
check_isolated_bumps true
check_isolated_clamps true
end rule

EM Rule for all nets with zaps and sinks with all bumps shorted on respective nets

Rule em_rule_all_nets
type em
source -type power -nets all -short_bumps true -report_threshold 2
sink -type ground -nets all -short_bumps true -report_threshold 1
clamp_types <types of ESD cells>
current 1.5
end rule

EM rule for zaps and sinks on specific bumps on specific nets

Rule em_rule_multi_bumps
type em
source -type power -nets VDD -short_bumps false -bumps VDDvsrc2
sink -type ground -nets VSS -short_bumps false -bumps "VSSvsrc1" 
clamp_cells ESD_CELL1
current 1.5
end rule

EM rule for zaps and sinks for cross-domain analysis with multiple nets between the source and sink bumps

Rule em_rule_non_linear
type em
setup -ahdl_include ./DATA/models.va -cross_domain true
source -type power -nets all -short_bumps true -report_threshold 1
sink -type ground -nets all -short_bumps true -report_threshold 1
clamp_cells clamp1 clamp2 clamp3 clamp4 clamp5 clamp6
current -6
end rule
