Rail Plots for Visualizing Rail Results using Rail Results Viewer

The following are the plot types to visualize rail results:

Plot Name

Description

IR Drop - ir

The voltage drop (IR dropIR drop) plot is displayed on all the power-grid segments of the analyzed net. The IR drop data is saved inside the state directory of the net. The worst case voltage can be displayed by selecting the Result Browser option. The segments with high IR drop can be debugged using the rail analysis plots in conjunction with power plots.

Grid Resistance - res

The grid resistance plot displays the resistance of each power-grid segment. This plot does not consider the power distribution when computing resistance thus highlighting power-grid weakness and resistance hot spots in the design irrespective of activity vector coverage.

This analysis plot allows designers to check power-grid robustness during early stages of the power-grid design when worst case vectors that produce high power and IR dropIR drop are unknown. The plot can be used during decap optimization (dynamic) as well because adding decaps along the path of high resistance has no effect on localized dynamic IR drop.

Instance Resistance of LRP - rlrp

The instance effective resistance plot is similar to grid resistance plot except it is plotted for the instances connected to the power-grid.

The resistance for the instance pin is calculated as total resistance along the least resistance path. If an instance has multiple power pins connected to the power-grid, instance based rlrp plot uses the pin with the worst (highest) resistance value to plot the instance based data. Like grid resistance plot, instance based resistance plot is also independent of power vectors. This allows you to identify weakly connected instances in the design during early stages of power planning. It can be used during the decap optimization as well because adding decaps along the path of high resistance has no effect on localized dynamic IR drop.

Resistor Current - rc

After observing IR drop plots, the next question is how the current flows in the design to create the IR drop plot generated. It is important to examine these plots because they also exhibit behaviors that are not obvious from examining the IR drop plots. These plots show current-flow trends that you might not have expected or current from several power pins reconverging in the middle of the chip to create high current through some wires.

Tap Current - tc

The tap current plot shows the current distribution inside the cell. The power-grid library generation program characterizes the current distribution inside the cell and replaces devices connected to the power-grid with current taps (sink). The relative current distribution inside the cell power-grid view library is based on device width and length. The instance based power calculated during power analysis is fed to rail analysis during IR drop analysis. The supplied instance power is then distributed inside the cell and can be viewed using tap current plot.

If accurate power-grid view is used during rail analysis for the memories, the tap current plot clearly highlights the low power (current) distribution in bit cells region and high power distribution in sense amplifier and decoder circuit of the memory. The tap current plot can be used to debug high IR drop caused by high power density in the region.

Current Density - rj

Once you understand how current flows through your design, you may want to know where the high current densities occur. Use the Current Density analysis type to examine them.

Current density reporting does not plot the current density of the segment but it is based on the ratio of wire current density over the current density limit that is allowed by the process - (J/Jmax). You therefore want all wires to have a ratio less than 1.0 and debug or fix the current density violations that have greater that 1.0 value. This ratio is easier to work with because its value is more consistent across designs.

Instance Voltage Drop (Net-based) - ivdn

The IR drop plot displays the net-based instance voltage drop. ivdn shows the worst instance voltage drop for each net. To see only one net, you can disable all the nets except one.

Instance Voltage Drop (Domain-based) - ivdd

ivdd will show the worst instance voltage drop for each power-ground pair. When at least one power and one ground net is selected, the plot will show the worst instance drop value.

For dynamic analysis, you can also select the type of IV method (best, worst, avg, worst avg) and/or the IV window (switching/timing window, whole window) in the Layers tab of the Power and Rail Plots - Layers/Nets form.

Power-Gate Current (I/Idsat) - pi

This plot is only applicable to the power-gated design and analysis.

The power-gate current (I/Idsat) plot displays the ratio of current through the power-gate and the saturation current (Idsat).This plot can be used to analyze and debug whether the current through power-gates exceeds the saturation current. The saturation current and on-resistance of the power-switches are characterized and stored inside the power-grid library of the power-gate cell. A ratio of greater than 1 means that the current requirement of the power-gated block can not be met with placed power-switch instance in that region. Either the power-switch needs to be upsized or more power-gate instances need to be placed.

In addition to the plot, rail analysis creates the text report (pi.report) and binary ECO file (vs2fe_pg.rpt) for Innovus Implementation System (Innovus) inside the state directory. The ECO file can be read inside Innovus using "optPowerSwitch -vsdgInFile" command to optimize power-gates.

Power-Gate Voltage - pv

The power-gate voltage plot displays the IR drop across power-switch instances. This plot can be used to analyze and debug the IR drop inside the power-gated block (e.g. if the IR drop across power gate is already high, the IR drop inside the power-gated block will be much higher. In this case, the power-gate placement will have to be refined or more power-gates will have to be added in order to resolve the IR drop problem).

Resistor Sensitivity Analysis - rs

Resistor sensitivity is calculated by the software as:

S = delta (Worst Voltage)/ delta (Resistance) in V/Ohm

Resistor sensitivity analysis is supported only in static rail analysis and can be enabled using the "set_rail_analysis_mode -enable_sensitivity_analysis true" option. By default it is false. The resistor sensitivity for power-grid can be viewed by plotting "rs" analysis type in GUI. The sensitivity analysis can be used as guidance for power-grid optimization. Sensitivity is calculated for all power-grid segments and the resistors with higher sensitivity when optimized have better chance to improve overall IR drop profile of the power-grid.

The optimization in this context means reducing overall resistance of the power-grid, e.g. wire widening. Although Voltus stand-alone product does not allow design and netlist changes, it can be used inside the Innovus platform which has wide range of power-grid editing and routing features. Optionally, you can perform what-if analysis inside the Voltus environment which allows you to scale resistance of power-grid segments on-the-fly to analyze and estimate the optimization efforts to improve IR drop profile of the power-grid.

There are two additional rs plots called rs (wire) and rs (wire group) to display resistor sensitivity on a wire or wire-group basis. Instead of displaying sensitivity of an individual resistor in a wire, these plots display highest sensitivity of a collection of resistors that form a wire or a wire group. These plots are only available when you invoke Voltus or ERA analysis in Innovus where the original power planning was done. The power planning commands define the wire or wire-groups that form the power-grid of the design, and Voltus or ERA is used to analyze sensitivity of these wires or wire-groups and optimize the power-grid using a power-planning ECO file.

Control
