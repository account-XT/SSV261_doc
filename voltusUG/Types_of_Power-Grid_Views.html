Types of Power-Grid Views

During rail analysis, different power-grid views (PGVs) are used based on the accuracy mode selected. The PGV types correspond to the accuracy mode of rail analysis. The following are the power-grid view types:

  • Tech-Only
    This view is the basic view generated in the technology library for every cell. It only contains the current distribution factor and decoupling capacitance at the power ports of the cell and does not include any information inside the cell. If any cells do not have a Power Grid Library defined, the tech view will be used to run rail analysis, but it is recommended to generate Power Grid Library for all standard cells and macro blocks to obtain accurate rail analysis.
  • Early View (Standard cells/Macros)
    This view only contains the current distribution factor and Spice simulated decoupling capacitance information at the power ports of the cell and does not include the parasitics associated with the interconnect, which prevents IR drop within the block or cell from being analyzed. Early power-grid views are default PGV view for rail analysis XD accuracy mode, which is recommended for early design phase.
  • IR View (Macros)
    IR View will perform reduction on extracted power-grid and will merge the small current value current taps together without a significant impact on the accuracy. The IR view was created for tool performance reasons. Current designs in many cases contain an embedded memory for boosting the performance. The bit cells of the memory in general contribute to the creation of a lot of current taps, however, they do not contribute much to the IR, but will affect the tool performance. This IR view suppresses those current taps which have a very small current value thus improving both memory usage and performance of the tool. There is limited visibility into the cell because the current taps for the bit-cells inside the memory could be collapsed. The IR view is the default for rail analysis HD mode, with the exception for static EM rail analysis where EM view will be applied.
  • EM View (Macros)
    The EM view contains the extracted power-grid from the GDSII data of a cell. It will create current taps on the bottom conducting layer or at the locations of the vias layer above it. GDSII and XY Spice netlist are required to generate an accurate current distribution and decoupling capacitance, but you can manually force current values and capacitance to be assigned to these taps. You can also set up a trigger file to manually define the dynamic current behavior or run Spice simulators to obtain current waveform.


For standard cell, the IR/EM view is identical to the Early view due to the simplicity of the standard cells.
