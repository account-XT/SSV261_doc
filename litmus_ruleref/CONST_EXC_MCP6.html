CONST_EXC_MCP6

NAME

CONST_EXC_MCP6 (CONSTRAINT_SIGNOFF)

MESSAGE

Multi-cycle path setup/hold multiplier is over/under defined.

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates the multiplier inconsistency of a multi-cycle path between setup and hold corners. Setting the attribute ltms_const_multicycle_path_multiplier_difference configures the difference between setup and hold multipliers of a multi-cycle path.

  • at_least_one  (default) : Setup multiplier is at least one greater than hold multiplier
  • one  : Setup multiplier is exactly one greater than hold multiplier

This rule is checked by verify_timing_intent command and the results can be reported by report_rule_check  command.

EXAMPLE

  • The following example contains multi-cycle path constraints. This rule is reported for the multi-cycle path, because the setup multiplier is not at least one greater than the hold multiplier.

    set_multicycle_path 2 -setup -from [get_ports din] -to [get_ports dout]
set_multicycle_path 2 -hold -from [get_ports din] -to [get_ports dout]
