CONST_HIER_SCA1

NAME

CONST_HIER_SCA1 (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

Inconsistent  set_case_analysis at the top-level vs. block

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule reports that there is a  set_case_analysis on a block object that does not have a tied value at the top level. Every block object with  set_case_analysis at the top level, and every block port with a tied value at the top level, should have a consistent  set_case_analysis at the block. This rule is checked by  check_target_constraints command and results can be reported by  report_rule_check command. 


This rule has specific rule occurrence attributes for the details about the violation.

Type

EXAMPLE

  • For the figure below, the block level constraints file has this following constraint. The Litmus issues a warning if the top level constraints file does not have a  set_case_analysis specified that causes pin i_blk/g4/Z to be tied to 1.

    Block level constraint (instance scope: i_blk) 

    set_case_analysis 1 [get_pins g4/Z]
  • For the above figure, the top and the block level constraints files have the following constraints, respectively, where i_blk/Blk_in gets the inverted value of Top_in. The Litmus issues a warning because i_blk/Blk_in is tied to 1 at the top level.

    Top level constraint 

    set_case_analysis 0 [get_ports Top_in]

    Block level constraint (instance scope: i_blk) 

    set_case_analysis 0 [get_ports Blk_in]
