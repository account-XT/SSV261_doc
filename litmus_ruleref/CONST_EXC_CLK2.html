CONST_EXC_CLK2

NAME

CONST_EXC_CLK2 (CONSTRAINT_ENHANCED_SIGNOFF)

MESSAGE

Clock interactions between multiple clock domains

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence ID
file_lines object_list file_lines
file_names object_list file_names
from_clock object From clock source/definition
from_file_line unsigned File Line
from_file_name string File Name
to_clock object To clock source/definition
to_file_line unsigned File Line
to_file_name string File Name
is_asynchronous bool Indicates if the clocks are asynchronous
is_physically_exclusive bool Indicates if the clocks are physically exclusive
is_logically_exclusive bool Indicates if the clocks are logically exclusive
type object_list Type
command object_list Applied command (set_false_path or set_clock_groups)

In addition, common rule occurrence attribute type provides the possible causes for the violation.

Attribute

Value

Description

type

TRUE

Clock crossing is true path

FALSE

Clock crossing is false path

PARTIALLY_FALSE

Clock crossing is partially false path

Leverage check_timing -check_only clock_crossing.

EXAMPLE

CONST_EXC_CLK2: Clock interactions between multiple clock domains.

          Severity: Warning                        Occurrence: 1

1.Fail: Clock interactions between (dp0tx2_clk_qp_dsc1) and (dp1tx3_clk_qp_dsc1) which are (asynchronous/physically_exclusive/logically_exclusive).
