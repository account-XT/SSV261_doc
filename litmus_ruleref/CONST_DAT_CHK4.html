CONST_DAT_CHK4

NAME

CONST_DAT_CHK4 (CONSTRAINT_SIGNOFF)

MESSAGE

set_max_time_borrow is not set on a latch or on a data/enable pin of a latch, or its value is bigger than half the clock period

DEFAULT SEVERITY

Warning

DESCRIPTION

The set_max_time_borrow command can be applied to clocks, cells or pins. For other object types, rule TCLCMD-917 and TCLCMD-513 will be reported. This rule is reported when the command is applied to clock objects, cells that are not level-sensitive, or pins that are not data or enable pins of level-sensitive sequential cells. It is also reported if the affected object is a level-sensitive cell or its data or enable pin, but the value specified is bigger than half the clock period of any clock propagating to the cell's enable pin. This rule is checked by verify_timing_intent command, and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id

EXAMPLE

  • If the enable pin of latch L1 is reached by clock CLK whose period is 10, this rule will be reported for all the following commands:

    set_max_time_borrow 7 [get_cells L1]
set_max_time_borrow 7 [get_pins L1/D]
set_max_time_borrow 3 [get_clocks CLK]
set_max_time_borrow 3 [get_cells MUX1]
set_max_time_borrow 3 [get_pins L1/Q]
