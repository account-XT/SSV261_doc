CONST_HIER_CLK2f

NAME

CONST_HIER_CLK2f (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

Mapped internal top-level and block clocks are defined with different clock types

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an inconsistency in clock type is found between mapped internal top level and block level clocks. The following are the possible causes for this violation:

  • Block level generated clock is mapped to top level real clock (Both of top-level clock and block level clock are defined inside a block)
  • Block level real clock is mapped to top level generated clock (Both of top-level clock and block level clock are defined inside a block)

This rule is checked by check_target_constraints command, and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

EXAMPLE

  • For the figure below, the following example contains two clocks specified in top level constraints and two clocks specified in block level constraints. This rule is reported for the clocks top_gclk and blk_gclk, because they are mapped but defined with different clock types. Clock top_gclk is a real clock by create_clock command and clock blk_gclk is a generated clock by create_generated_clock command.

    Top level constraints

    create_clock -name top_clk -period 2 [get_ports top_clk]
create_clock -name top_gclk -period 2 [get_pins i_blk/i_blk_clk_buf/Z]

    Block level constraints (instance scope: i_blk)

    create_clock -name blk_clk -period 2 [get_ports blk_clk]
create_generated_clock -name blk_gclk -source [get_ports blk_clk] -master_clock [get_clocks blk_clk] -combinational [get_pins i_blk_clk_buf/Z] -add

    Hierarchical clock mapping

    top_clk is mapped to blk_clk
top_gclk is mapped to blk_gclk
