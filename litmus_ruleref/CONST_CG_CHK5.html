CONST_CG_CHK5

NAME

CONST_CG_CHK5 (CONSTRAINT_ENHANCED_SIGNOFF)

MESSAGE

Clock gating enable pin is not reached by any constrained data

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence ID
file_lines object_list file_lines
file_names object_list file_names
blocking_commands object_list blocking_commands
clock_gating_enable_pin object Clock gating enable pin
reference_pin object_list reference_pins
type string Type

In addition, common rule occurrence attribute type provides the possible causes for the violation.

Attribute

Value

Description

type

NO_CLOCK

No clock reaching the data pin

DATA_BLOCKED

Data phase blocked by “set_disable_timing” or “set_clock_groups” command

Checking: Leverage check_timing -check_only clock_gating_no_data. Thereafter all the multiple-input gates on a clock network are analyzed.

Reporting (message & attribute): Need to include the reason why no data phase reaches clock gating enable pin. For example, the fanin of clock gating enable pin is not constrained by SID w.r.t a clock. Hence data phase is missing. SDT stops the data phase in the fanin of clock gating enable pin. Hence data phase is blocked.

EXAMPLE

CONST_CG_CHK5: Clock gating enable pin is not reached by any constrained data

Severity: Warning Occurrence: 1

1.Fail: No data signal reaching clock gating enable pin.

  Pin: common_digital/uh984_efuse_top_0/fuse_farm_0/I_sc_efuse_ctlr/I_efuse_ctlr_clkgen/g28/b1
