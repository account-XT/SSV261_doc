CONST_COMP_TIM1

NAME

CONST_COMP_TIM1 (CONSTRAINT_COMPARISON)

MESSAGE

A fragment of target level timing path cannot be matched to a corresponding fragment of reference level timing path

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that the software was not able to identify a fragment of the path in the reference level that includes, or is identical to, the fragment of the path in the target level. This rule can be reported as a consequence of inconsistent set_disable_timing between the reference level and the target level designs. That problem would be reported by rule CONST_COMP_SDT1. In this cases, making sure that there are sufficient set_disable_timing commands at both levels that are consistent and eliminating all occurrences of CONST_COMP_SDT1 will solve the issue. If there are still occurrences of this rule, then that could be because of inconsistent application of SDC constraints that cause path splitting (such as set_input_delay) between the target and the reference level. The occurrence of this rule points to an inconsistency between the timing graphs being compared, which can negatively affect the quality of results of the hierarchical checks. This rule is checked by compare_constraints command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
target_view_name string Target view name
reference_view_name string Reference view name

reference_pin object Reference pin

EXAMPLE

  • For the figure below, the following contains set_disable_timing command specified in reference level constraints. This rule is reported because the target level timing path from i_blk/g0/CK to Top_out1 cannot be matched to corresponding reference level timing path.

Reference level constraint

set_disable_timing [get_cells i_blk/g0]
