CONST_EXC_SMD5

NAME

CONST_EXC_SMD5 (CONSTRAINT_SIGNOFF)

MESSAGE

Start/end point is specified in set_max_delay/set_min_delay -through

DEFAULT SEVERITY

Ignore (default Warning)

DESCRIPTION

Indicates that a start point or an end point is specified with -through, -rise_through or -fall_through option of set_max_delay or set_min_delay command. It is recommended to use -from, -rise_from or -fall_from option for a start point and -to, -rise_to or -fall_to for an end point. The path delay specified with from or to option associated with a clock is skipped from this check. This rule is disabled by default. Using set_message command the severity can be modified to enable the rule. This rule is checked by verify_timing_intent command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id

EXAMPLE

  • The following example contains path delay constraints. This rule is reported for the set_max_delay and set_min_delay commands, because the start point din is specified with -through option.

    create_clock -name vclk -period 2 
set_input_delay -clock [get_clocks vclk] 1 [get_ports din]
set_output_delay -clock [get_clocks vclk] 1 [get_ports dout] 
set_max_delay 4 -through [get_ports din]
set_min_delay 2 -through [get_ports din]
