CONST_DAT_CHK1

NAME

CONST_DAT_CHK1 (CONSTRAINT_SIGNOFF)

MESSAGE

Data check signal is undetermined

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that data check reference point (-from option) or constrained point (-to option) specified by set_data_check command is undetermined. The following are the possible causes for this violation:

  • Data check reference point or constrained point is not reached by any clocked signal
  • Data check reference point or constrained point is reached by clocked signals which are associated with multiple clocks

This rule is checked by verify_timing_intent command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Design Name
pin object Data check pin
clocks object_list List of clocks
unconstrained_pins object_list List of unconstrained pins
corner_type object_list corner_type
file_names object_list file_names
file_lines object_list file_lines

EXAMPLE

  • The following example contains AND gates and data check constraints. This rule is reported for the reference point i_and0/A1 and the constrained point i_and0/A2, because they are not reached by any clocked signal. Besides, this rule is also reported for the reference point i_and1/A1 and the constrained point i_and1/A2, because they are reached by the clocked signals associated with the clocks vclk0 and vclk1.

    module top (input [1:0] din0, input [1:0] din1, output [1:0] dout);
    AND2_X2 i_and0 (.A1(din0[0]), .A2(din1[0]), .ZN(dout[0]));
    AND2_X2 i_and1 (.A1(din0[1]), .A2(din1[1]), .ZN(dout[1]));
endmodule

    Constraints that go with the above RTL:

    create_clock -name vclk0 -period 2
create_clock -name vclk1 -period 2
set_input_delay -clock [get_clocks vclk0] 1 [get_ports {din0[1] din1[1]}] -add
set_input_delay -clock [get_clocks vclk1] 1 [get_ports {din0[1] din1[1]}] -add
set_data_check 0.5 -from [get_pins i_and0/A1] -to [get_pins i_and0/A2]
set_data_check 0.5 -from [get_pins i_and1/A1] -to [get_pins i_and1/A2]
