CONST_CLK_DEF41

NAME

CONST_CLK_DEF41 (CONSTRAINT_SIGNOFF)

MESSAGE

Generated clock is reached by multiple master clocks

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that a generated clock is created with master clock source point (-source option) which is reached by multiple master clocks but does not specify the associated master clock. The following are the approaches for explicitly determining the associated master clock:

  • create_generated_clock command with -master_clock option
  • set_active_clocks command

By default, the associated master clock is determined with the 1st one in the list of master clocks sorted by clock name. This rule is checked by verify_timing_intent command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
master_source_pin object Master source pin
clock object Clock
master_clock object Master clock
master_clocks object_list Master clocks
file_line unsigned File line number
file_name string File name


EXAMPLE

  • The following example contains a generated clock which is reached by multiple master clocks. This rule is reported for the generated clock gclk, because the master clock source point (-source option) is reached by two master clocks clk0 and clk1 but the associated master clock is not explicitly determined.

    create_clock -name clk0 -period 2 [get_ports clk] -add
create_clock -name clk1 -period 2 [get_ports clk] -add
create_generated_clock -name gclk -source [get_ports clk] -divide_by 1 [get_ports gclk]
