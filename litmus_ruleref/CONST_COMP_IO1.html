CONST_COMP_IO1

NAME

CONST_COMP_IO1 (CONSTRAINT_COMPARISON)

MESSAGE

Target input port with delay vs. a clock is not in a timing path within the same clock group at the reference level

DEFAULT SEVERITY

Warning

DESCRIPTION

For every block input port IN with input delay versus clock CLK, Litmus finds the top level clock groups of CLK's top level equivalent clock, and checks that there is a path between timing points in those clock groups that traverse IN. This rule is checked by compare_constraints command and results can be reported by report_rule_check command. 


This rule has specific rule occurrence attributes for the details about the violation.

EXAMPLE

  • The design in the figure below (where IN1A has an input delay versus CLK1A) would cause a rule check violation if the following were not present in the combinational fan-in of IN1A. This rule would also be flagged if no DFF (Q1) or port in the same clock group can be found in the fan-out of IN1A.
    • A DFF that is clocked by the top level clock CLK1
    • A primary input IN1 that has an input delay versus CLK1

  • For the figure above, if a top level clock CLK2 is connected to the block level clock CLK1A and the the top level DFF is clocked by another top level clock CLK1 from a different clock group other than CLK2 (asynchronous, defined like the following top level constraints), then this rule check violation will happen for the following block level constraints. Here, the block input port Block_A/IN1A has set_input_delay relative to block clock CLK1A which is getting top level equivalent clock CLK2. But at top level, the timing path is not in the same clock group of the top level equivalent clock.
