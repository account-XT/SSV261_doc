CONST_HIER_CG1

NAME

CONST_HIER_CG1 (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

Inconsistent set_clock_gating_check at top-level vs. block.

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an inconsistency in set_clock_gating_check command is found between top level and block level constraints. The following are the possible causes for this violation:

  • set_clock_gating_check command specified at either top level or block level
  • set_clock_gating_check commands specified at both top level and block level but with different values

This rule is checked by check_target_constraints command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

EXAMPLE

  • For the figure below, the following constraints contain set_clock_gating_check commands specified in both top level and block level constraints. This rule is reported for the set_clock_gating_check commands, because they are specified with different values.

    Top level constraint

    set_clock_gating_check -high -setup 0.4 -hold 0.2 [get_cells i_blk/g0]

    Block level constraint (instance scope: i_blk)

    set_clock_gating_check -high -setup 0.8 -hold 0.4 [get_cells g0]
