CONST_CLK_GRP9

NAME

CONST_CLK_GRP9 (CONSTRAINT_SIGNOFF)

MESSAGE

Two clocks are physically exclusive by design, but specified as logically exclusive by set_clock_groups

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that clocks defined on the same definition point are specified as logically exclusive to each other. The clock relationship of the clocks needs to be physically exclusive instead of logically exclusive. Physically exclusive clocks cannot exist in the design at the same time. The clock relationship is specified by set_clock_groups command with -physically_exclusive option. Logically exclusive clocks can exist in the design at the same time, but do not have any functional path between them. The clock relationship is specified by set_clock_groups command with -logically_exclusive option. This rule is checked during design initialization by init_design command and the results can be reported by report_sdc command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id

EXAMPLE

  • The following example contains clocks defined on the same definition point and specified as logically exclusive to each other. This rule is reported for the clocks clk0 and clk1, because the set_clock_groups command with -logically_exclusive option specifies the clock relationship as logically exclusive.

    create_clock -name clk0 -period 2 [get_ports clk]
create_clock -name clk1 -period 4 [get_ports clk] -add
set_clock_groups -name clk_grp_log_excl -logically_exclusive -group [get_clocks clk0] -group [get_clocks clk1]
