CONST_CLK_GRP3

NAME

CONST_CLK_GRP3 (CONSTRAINT_SIGNOFF)

MESSAGE

The harmonic cycle of a pair of connected and synchronous clocks exceeds the threshold

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates the number of harmonic cycles of a set of correlated clocks exceeds the threshold. The number of cycles is calculated based on the clock with the highest frequency amongst its correlated clocks.

The threshold can be specified by the attribute ltms_const_harmonic_cycle_threshold, which has default value of 100 cycles. This rule is checked by verify_timing_intent command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
first_clock object First clock
second_clock object Second clock
lcm_cycle long LCM harmonic cycle of clocks in clock group

EXAMPLE

  • If there are three clocks in the same clock group specified by the following SDC statements:

    create_clock -name clk1 -period 5 clk1
create_clock -name clk2 -period 15 clk2
create_generated_clock -name gclk -source clk2 -master_clock clk2 -divide_by 2 FF1/Q
set_clock_groups -name grp1 -asynchronous -group {clk1 clk2 gclk}

    The periods of clk1, clk2, and gclk are 5, 15, and 30, respectively. So, the harmonic cycle will be 6 because the LCM of their periods is 30 and it is 6 cycles of clk1, which is the clock with highest frequency among correlated clocks. This number of cycles, 6, will be checked against the threshold.
