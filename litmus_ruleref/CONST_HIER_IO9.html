CONST_HIER_IO9

NAME

CONST_HIER_IO9 (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

Inter-block connection output/input delays under-constrain the path

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that a timing path crossing between two hierarchical blocks is budgeted more delay (D1+D2) than the total clock period (T).

At each point where the path crosses from one block to another one, the output (OD) and input delays (ID) at both sides represent the delay allocated ((D1=T-OD), (D2=T-ID), respectively) to the other side of the crossing. If these add up to less than the clock period (OD+ID < T), then the path is under-constrained (D1+D2=(2T-OD-ID)=T++).

The input and output delays to be correlated must be defined versus block clocks that have a common shared top level equivalent clock, whose period will be used for the check. This check requires the top-level constraints to have clocks defined and the block-top equivalences to be correctly extracted by the tool or specified in the dofile using the set_timing_context_clock_mapping command.

To report clock equivalences report_hierarchical_clock_mapping command is used. This rule is checked by check_target_constraints command and results can be reported by report_rule_check command.

EXAMPLE

  • For the figure below, there is a path from B1/OUT to B2/IN and tclk is the top-level equivalent clock of B1/bclk1 and of B2/bclk2. For the following top and both block level constraints, the sum of the output delay of B1/OUT and the input delay of B2/IN is less than the clock period of clock tclk which will report this rule.

    Top level constraint

    create_clock -name tclk -period 4 [get_ports tclk]

    Block level constraint (instance scope: B1)

    set_output_delay 1 -clock bclk1 OUT

    Block level constraint (instance scope: B2)

    set_input_delay 2 -clock bclk2 IN
