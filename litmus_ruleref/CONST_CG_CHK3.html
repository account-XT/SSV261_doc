CONST_CG_CHK3

NAME

CONST_CG_CHK3 (CONSTRAINT_SIGNOFF)

MESSAGE

Clock gating check is missing on complex gate

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that the non-controlling value of a clock for clock gating check on a complex gate, e.g. XOR, XNOR or MUX, is undetermined. The non-controlling value of the clock needs to be specified by set_clock_gating_check command with -high or -low option. By default, the non-controlling value of the clock is determined with the function of the gate. For example, clock gating check is performed on the high level for AND and NAND gates, and on the low level for OR and NOR gates. Also the rule is checked when the endpoint in the fanout of the gate contains clock pin of sequential cell, set/reset pin of sequential cell, or output/inout port. This rule is checked by verify_timing_intent command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

AttributeTypeDescription
occurrence_id unsigned Occurrence id
scope string Scope
clock_gating_clock_pin object Clock gating pin
clock_gating_output_pin object Clock gating output pin
clock_gating_enable_pin object Clock gating enable pin
sink_pin_types object_list Sink pin types

EXAMPLE

  • The following example contains an XOR gate which gates a clock signal but does not have any clock gating check constraint. This rule is reported for the XOR gate i_xor, because set_clock_gating_check command is not specified with -high or -low option to determine the non-controlling value of the clock clk for clock gating check.

    module top (input clk, input en, output gclk);
    XOR2_X2 i_xor (.A(clk), .B(en), .Z(gclk));
endmodule

    Constraint that goes with above RTL:

    create_clock -name clk -period 2 [get_ports clk]
