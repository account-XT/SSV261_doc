CONST_CLK_CTR9

NAME

CONST_CLK_CTR9 (CONSTRAINT_SIGNOFF)

MESSAGE

set_input_transition is not recommended for ideal clock source input port

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that set_input_transition is used on an ideal clock source input port. This rule is checked by verify_timing_intent command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
clock object Clock
clock_source object Clock source
max_min_option string Value of -max/ -min option
rise_fall_option string Value of -rise/ -fall option
file_line unsigned File line number
file_name string File name

EXAMPLE

  • The following command causes a rule check violation because set_input_transition is used on a clock port:

    create_clock -name clk1 -period 10 [get_ports clock]
set_input_transition 1 [get_ports clock]
