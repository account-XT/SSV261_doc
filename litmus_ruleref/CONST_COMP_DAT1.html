CONST_COMP_DAT1

NAME

CONST_COMP_DAT1 (CONSTRAINT_COMPARISON)

MESSAGE

Inconsistent set_data_check at the reference-level vs. target

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an inconsistency in set_data_check command is found between reference and target level constraints. The following are the possible causes for this violation:

  • set_data_check command specified at either reference or target level
  • set_data_check commands specified at both reference and target level but with different values

This rule is checked by compare_constraints command and the results can be reported by report_rule_check command.

EXAMPLE

  • For the figure below, the following contains set_data_check commands specified in both reference and target level constraints. This rule is reported for the set_data_check commands, because they are specified with different values.

    Top level constraint

    set_data_check 0.5 -from [get_pins i_blk/i_buf/A] -to [get_pins i_blk/i_buf/Z]

    Block level constraint (instance scope: i_blk)

    set_data_check 1.0 -from [get_pins i_buf/A] -to [get_pins i_buf/Z]
