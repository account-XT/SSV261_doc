CONST_HIER_DAT1

NAME

CONST_HIER_DAT1 (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

Inconsistent set_data_check at the top level vs. block

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an inconsistency in set_data_check command is found between top level and block level constraints. The following are the possible causes for this violation:

  • set_data_check command specified at either top level or block level
  • set_data_check commands specified at both top level and block level but with different values

This rule is checked by check_target_constraints command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

EXAMPLE

  • For the figure below, the following contains set_data_check commands specified in both top level and block level constraints. This rule is reported for the set_data_check commands, because they are specified with different values.

    Top level constraint

    set_data_check 0.5 -from [get_pins i_blk/i_buf/A] -to [get_pins i_blk/i_buf/Z]

    Block level constraint (instance scope: i_blk)

    set_data_check 1.0 -from [get_pins i_buf/A] -to [get_pins i_buf/Z]
