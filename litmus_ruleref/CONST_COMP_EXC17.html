CONST_COMP_EXC17

NAME

 CONST_COMP_EXC17 (CONSTRAINT_COMPARISON)

MESSAGE

A target path without set_false_path is part of reference paths and all such reference paths are defined as false paths

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule reports that a target path was not declared as false path at the target level and all reference paths containing this target path have been affected by reference false path specification. This rule is checked by compare_constraints command and results can be reported by report_rule_check command.
