CONST_DGN_CMB1

NAME

CONST_DGN_CMB1 (CONSTRAINT_SIGNOFF)

MESSAGE

Unconstrained combinational path

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that there is an unconstrained input/output delay value for a primary input and primary output connected combinational path. Every pair of primary inputs and primary outputs that are connected to a combinational path must have a complete set of input/output delays with respect to the same clock (or independent of any clock), or a matching set of set_max_delay and set_min_delay specified.

In addition, it checks whether a matching set of set_max_delay and set_min_delay is specified (not only for a primary input and primary output connected combinational path). You can check the rule using verify_timing_intent command and the results can be reported by report_rule_check command.

This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description
occurrence_id unsigned Occurrence id
scope string Scope
primary_input object Primary input
primary_output object Primary output
type string Type
missing_corners object_list Missing corners
file_line unsigned File line number
file_name string File name


EXAMPLE

In the following example, a combinational path exists between IN1 and OUT2, and a maximum delay is defined:

set_max_delay 3 -from IN1 -to OUT2

Litmus issues a warning because set_min_delay is missing.
