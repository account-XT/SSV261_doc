CONST_EXC_CLK1

NAME

CONST_EXC_CLK1 (CONSTRAINT_SIGNOFF)

MESSAGE

Connected master clock and generated clocks are declared as set_false_path

DEFAULT SEVERITY

Warning

DESCRIPTION

A master clock and its generated child clocks are usually considered to be correlated. This rule indicates that two connected and synchronous clocks (either a master clock and a generated child clock, or two generated child clocks from same master clock) are declared as false path by set_false_path command, making them no longer correlated. This rule is checked by verify_timing_intent command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

This rule is customizable. The specific rule instance attribute check_type configures the rule checking behavior.

AttributeDescription
check_type

Specifies the type of clocks to be checked.

Possible value: <all | master_and_generated_clocks | generated_clocks_only>

Where:

all: Checks all below types. This is the default.

master_and_generated_clocks: Checks a master clock and its generated child clocks.

generated_clocks_only: Checks generated child clocks from same master clock.

EXAMPLE

  • The following case reports this rule when the master clock clk and the generated clock gclk are connected and synchronous (there is a data path from clock clk to clock gclk) because they are declared as false path by set_false_path command.

    create_clock -name clk -period 2 [get_ports clk]
create_generated_clock -name gclk -source [get_ports clk] -divide_by 1 [get_pins i_clk_buf/Z]
set_false_path -from [get_clocks clk] -to [get_clocks gclk]
