CONST_IO_IDL5

NAME

CONST_IO_IDL5 (CONSTRAINT_SIGNOFF)

MESSAGE

Inconsistent input delay vs. clock period, or min>max

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates one of the following conditions for  set_input_delay values:

  • -min delay > -max delay
  • A delay value does not satisfy the formula specified in the attribute ltms_const_input_delay_condition

Note that the default formula is delay<ratio*period, where delay indicates -min/-max delay, ratio indicates the value of attribute ltms_const_input_delay_ratio, and period indicates the clock period. The attribute ltms_const_input_delay_ratio has a default value of 1.0. Also, if there is a set_multicycle_path  with a single -from or -through list, in which the port is included, then the clock period is multiplied by the multi-cycle path value. Note that this rule does not apply to ports that are specified in set_false_path  and that have a single path specification switch, which is either -from or a single -through. set_false_path  should have both -setup and -hold specified, or neither. Otherwise, the port is still subject to this rule check. This rule is checked by  verify_timing_intent  command and the results can be reported by  report_rule_check  command.

EXAMPLE

  • In the following command, a violation occurs because 2.75 (minimum value) > 1.75 (maximum value):

    set_input_delay 1.75 -max -clock CLK1_w {IN1}
set_input_delay 2.75 -min -clock CLK1_w {IN1}

  • In the following command, the Litmus issues a warning because the input delay does not satisfy the formula delay<ratio*period, where the attribute ltms_const_input_delay_ratio has its default value 1.0:

    create_clock -period 8.0 -name vCLK3
set_input_delay 10.0 [get_ports {IN1, IN2}] -clock vCLK3
