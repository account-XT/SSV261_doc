CONST_CLK_CTR10

NAME

CONST_CLK_CTR10 (CONSTRAINT_SIGNOFF)

MESSAGE

set_driving_cell is not recommended for clock source input port

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that set_driving_cell is defined on a clock source input port (either ideal or propagated clock). This rule is checked by verify_timing_intent command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
clock object Clock
clock_source object Clock source
file_line unsigned File line number
file_name string File name


EXAMPLE

  • The following produces a warning because there should not be a set_driving_cell on the clock port:

    set_driving_cell -lib_cell AND -from_pin B -pin Y CLK1
