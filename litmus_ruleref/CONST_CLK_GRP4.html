CONST_CLK_GRP4

NAME

CONST_CLK_GRP4 (CONSTRAINT_SIGNOFF)

MESSAGE

A synchronous clock group has more than one root clock

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an instance where a given clock group has more than one root clock source object is defined. A clock group's root clock is any real clock or any generated clock whose master clock does not belong to the same group. This rule check ensures that clock tree synthesis can align all the registers in a clock group at the block level. In case of a violation for this rule check, the report_clock_group command is used to display the clock groups. This rule is checked by verify_timing_intent command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
clocks object_list Clocks
root_clocks object_list Root clocks


EXAMPLE

  • The following generates this warning because a clock group has more than one root clock source:

    create_clock -name CLK_1 -period 5.0 -waveform {0.0 2.5} [get_ports CLK10]
create_clock -name CLK_2 -period 5.0 -waveform {0.0 2.5} [get_ports CLK11]
