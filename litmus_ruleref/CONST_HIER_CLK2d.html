CONST_HIER_CLK2d

NAME

CONST_HIER_CLK2d (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

A block's clock and a related top-level clock have different phases

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an inconsistency in clock phase is found between mapped top level and block level clocks. The following are the possible causes for this violation:

  • Mapped top level and block level clocks defined with different clock phases
  • Block level clock is in the clock tree of mapped top level clock but with different clock phase

This rule is checked by check_target_constraints command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
block_view_name string Block view name
top_view_name string Top view name

block_port object Block port

EXAMPLE

  • For the figure below, the following contains generated clocks specified in both top level and block level constraints. This rule is reported for the generated clocks Top_gclk and Blk_gclk, because they are mapped but defined with different clock phases (-invert).

    Top level constraints

    create_clock -name Top_clk -period 2 [get_ports Top_clk]
create_generated_clock -name Top_gclk -source [get_ports Top_clk] -master_clock [get_clocks Top_clk] -combinational [get_pins i_blk/g0/Z] -add

    Block level constraints (instance scope: i_blk)

    create_clock -name Blk_clk -period 2 [get_ports Blk_clk]
create_generated_clock -name Blk_gclk -source [get_ports Blk_clk] -master_clock [get_clocks Blk_clk] -combinational [get_pins g0/Z] -add -invert

    Hierarchical clock mapping

    Top_clk is mapped to Blk_clk
Top_gclk is mapped to Blk_gclk
