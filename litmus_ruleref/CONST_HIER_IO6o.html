CONST_HIER_IO6o

NAME

CONST_HIER_IO6o (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

Missing set_output_delay in block/glue SDC

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule reports that a set_output_delay in a top level constraints file has no corresponding set_output_delay at the block level constraints file. The corresponding delays are determined based on the clock equivalences and the presence or absence of the -clock_fall option. This rule is checked by check_target_constraints command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

EXAMPLE

  • For the figure below, if a port Top_out2 has output delay vs. top level clock vtop_c1 like the following (with or without -clock_fall), this rule will be reported if Top_out2 is connected to block port i_blk/Blk_out2 and the block level constraints file does not contain the following command:

    Top level constraint

    set_output_delay 1 -clock vtop_c1 [get_ports Top_out2]

    Block level constraint (instance scope: i_blk)

    set_output_delay 1 -clock vblk_c11 [get_ports Blk_out2]
  • For the figure above, this rule will also be reported if the output delay at the block pin i_blk/i_buf/Z is set by the top level constraint, but missing the block level constraint like the following:

    Top level constraint

    set_output_delay 1 -clock vtop_c1 [get_pins i_blk/i_buf/Z]

    Block level constraint (instance scope: i_blk)

    set_output_delay 1 -clock vblk_c11 [get_pins i_buf/Z]

    and the dofile contains the following:

    set_timing_context_clock_mapping -name hier_clk_map -top_clock vtop_c1 -scope_name i_blk -scope_clocks vblk_c11 -force
