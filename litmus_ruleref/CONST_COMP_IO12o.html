CONST_COMP_IO12o

NAME

CONST_COMP_IO12o (CONSTRAINT_COMPARISON)

MESSAGE

Inconsistent set_output_delay at the reference vs. target

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an inconsistency in set_output_delay command is found between reference and target level constraints. The following are the possible causes for this violation:

  • set_output_delay commands specified at both reference and target level but with different values

This rule is checked by compare_constraints command and the results can be reported by report_rule_check command.

This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Value

Inconsistent output delays

EXAMPLE

  • For the figure below, the following example contains set_output_delay commands specified in both reference and target level constraints. This rule is reported for the set_output_delay commands, because they are specified with different values (-reference_pin) provided the reference clock top_vclk and the target level clock blk_vclk are mapped using set_timing_context_clock_mapping command in the dofile.

    Top level constraints 

    create_clock -name top_vclk -period 2
set_output_delay -clock [get_clocks top_vclk] -reference_pin [get_pins i_blk/Blk_in1] 1.0 [get_pins i_blk/i_buf/Z]

    Block level constraints (instance scope: i_blk) 

    create_clock -name blk_vclk -period 2
set_output_delay -clock [get_clocks blk_vclk] -reference_pin [get_pins i_buf/A] 1.0 [get_pins i_buf/Z]

    Hierarchical clock mapping 

    top_vclk is mapped to blk_vclk
