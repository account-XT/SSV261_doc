CONST_CG_CHK7

NAME

CONST_CG_CHK7 (CONSTRAINT_ENHANCED_SIGNOFF)

MESSAGE

Clock gating frequencies causes a clipped clock

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates clock gating frequencies causes a clipped clock

This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence Id
file_lines object_list file_lines
file_names object_list file_names
pin object Pin
clock string clock
clock_pin string clock_pin
data_pin string data_pin
data_clock_name string data_clock_name

Checking: Leverage check_timing -check_only clock_clipping_freq.

Reporting (message & attribute): Need to include the frequency and waveform of clock and data signals.

Message: Clock clipping due to incompatible clock signal and data signal frequencies.

EXAMPLE

CONST_CG_CHK7: Clock gating frequency causes a clipped clock

         Severity: Warning                        Occurrence: 1

1.Fail: Clock clipping due to incompatible clock signal ('fpd3tx0_pclk0_div2_p0’ ) and data signal ('fpd3tx0_fclk0’) frequencies.

  Pin: common_digital/fpd3_tx_datapath_u0/fpd3_clocks_0/pclk_mux/g63/y 

  Clock signal pin: common_digital/fpd3_tx_datapath_u0/fpd3_clocks_0/pclk_mux/g63/b

               Data signal pin: common_digital/fpd3_tx_datapath_u0/fpd3_clocks_0/pclk_mux/g63/a
