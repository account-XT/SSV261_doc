CONST_CLK_UNC3

NAME

CONST_CLK_UNC3 (CONSTRAINT_SIGNOFF)

MESSAGE

Inconsistent clock uncertainty vs. clock period

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that a clock uncertainty value is bigger than the clock period of the relevant clock. For inter-clock uncertainty, the uncertainty value is compared with the clock period of the -to clock. This rule is checked by verify_timing_intent command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
clock object Clock
second_clock object Second clock
setup_hold_option string Setup hold option
rise_fall_from_option string Rise fall -from option
rise_fall_to_option string Rise fall -to option
uncertainty_value float Uncertainty value
period float period
file_line unsigned File line number
file_name string File name


EXAMPLE

  • The following commands will cause this rule to be reported twice:

    create_clock -period 5 -name clk11 [get_ports clk1]
create_clock -period 10 -name clk22 [get_ports clk2]
set_clock_uncertainty 8 [get_clocks clk11]
set_clock_uncertainty 9 -from [get_clocks clk22] -to [get_clocks clk11]

    Following are the reasons for those:

    • Clock uncertainty of clk11 in line #3 is greater than the clock period

    • Inter-clock uncertainty in line #4 is greater than the -to clock's clock period which is 5
