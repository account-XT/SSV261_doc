CONST_DGN_CMB5

NAME

CONST_DGN_CMB5 (CONSTRAINT_SIGNOFF)

MESSAGE

Combinational constraints present on elements belonging to internal sequential path

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that combinational constraints are imposed on elements that belong to internal sequential paths. This rule checks whether a -from or -to point of a  set_max_delay or  set_min_delay is in a path between sequential elements.

This rule is checked by  verify_timing_intent  command and the results can be reported by  report_rule_check  command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description
occurrence_id unsigned Occurrence id
scope string Scope
from_objects object_list -from objects
to_objects object_list -to objects
through_objects object_list -through objects
file_line unsigned File line number
file_name string File name
exc_type string Exc type


EXAMPLE

Litmus issues this message for the following set_max_delay  and  set_min_delay  constraints, since they are present on elements belonging to internal sequential path:

module TOP (in1, clk1, out1);
 input in1, clk1;
 output out1;
 wire w1, w2;
 DFF_X1 g1 ( .D(in1), .Q(w1), .CK(clk1) );
 BLOCK1 g2 ( .in(w1), .out(w2), .clk(clk1) );
 DFF_X1 g3 ( .D(w2), .Q(out1), .CK(clk1) );
endmodule

module BLOCK1 (input in, clk, output out);
 wire w1;
 DFF_X1 ig1 ( .D(in), .Q(w1), .CK(clk) );
 DFF_X1 ig2 ( .D(w1), .Q(out), .CK(clk) );
endmodule

Constraints that go with the above RTL:

create_clock -period 10 -waveform {0 5} -name rCLK1 [get_ports clk1]
set_min_delay 1 -from [get_pins g2/ig1/Q] -to [get_pins g2/ig2/D]
set_max_delay 2 -from [get_pins g2/ig1/Q] -to [get_pins g2/ig2/D]
