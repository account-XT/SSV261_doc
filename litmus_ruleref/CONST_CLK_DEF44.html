CONST_CLK_DEF44

NAME

CONST_CLK_DEF44 (CONSTRAINT_SIGNOFF)

MESSAGE

Clock reaches a multiplexer select pin

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that the select input of a multiplexer is reached by a clock. This rule is checked by verify_timing_intent command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
pin object Pin
clocks object_list Clocks
file_line_info object_list File line information


EXAMPLE

  • The following example contains a multiplexer and a clock. This rule is reported for the select input of the multiplexer, because it is reached by the clock clk_sel.

    module top (input [1:0] din, output dout, input sel);
    mux i_mux (.DI0(din[0]), .DI1(din[1]), .DO(dout), .S(sel));
endmodule

module mux (input DI0, input DI1, output DO, input S);
    assign DO = S? DI1: DI0;
endmodule

    Constraint that goes with the above source code:

    create_clock -name clk_sel -period 2 [get_ports sel]
