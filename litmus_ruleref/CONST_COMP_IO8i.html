CONST_COMP_IO8i

NAME

CONST_COMP_IO8i (CONSTRAINT_COMPARISON)

MESSAGE

Block/glue set_input_delay has greater value than in full-chip

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule reports that a set_input_delay in a target level constraints file has a corresponding set_input_delay at the reference constraints file, which has a smaller value. Only delays with -clock are considered. The corresponding delays are determined based on the clock equivalences with or without using the set_timing_context_clock_mapping command in the dofile and the presence or absence of the -clock_fall option. This rule is checked by compare_constraints command and results can be reported by report_rule_check command. Note that when this rule is reported for targets, it does not necessarily mean there is an error, unless the targets' ports are connected directly to reference ports. This rule is provided for completeness.

Attribute

Value

Description

EXAMPLE

  • For the figure below, this rule will be reported if port Top_in2 is connected to target port i_blk/Blk_in2 and the top and target level constraints file have the following commands:

    Top level constraint

    set_input_delay 1 -clock vtop_c1 [get_ports Top_in2]

    Block level constraint (instance scope: i_blk)

    set_input_delay 2 -clock vblk_c11 [get_ports Blk_in2]

  • For the figure above, this rule will also be reported if the input delay at some target pin i_blk/i_buf/A is set by the top and target level constraints file like the following:

    Top level constraint

    set_input_delay 1 -clock vtop_c1 [get_pins i_blk/i_buf/A]

    Block level constraint (instance scope: i_blk)

    set_input_delay 2 -clock vblk_c11 [get_pins i_buf/A]

    and the dofile contains the following:

    set_timing_context_clock_mapping -name hier_clk_map -top_clock vtop_c1 -scope_name i_blk -scope_clocks vblk_c11 -force
