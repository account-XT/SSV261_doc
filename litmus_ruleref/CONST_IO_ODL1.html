CONST_IO_ODL1

NAME

CONST_IO_ODL1 (CONSTRAINT_SIGNOFF)

MESSAGE

Output is unconstrained

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that there is an unconstrained output. Flags output ports that do not have set_output_delay. Only output ports that are connected to some constrained path start point (a clocked register or a pin with set_input_delay) are considered for this rule. However, an undriven output port will not be checked in this rule. This rule is checked by verify_timing_intent command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Scope
pin object Pin


EXAMPLE

  • If the design contains three output ports OUT1, OUT2, and OUT3, the following produces a warning because the output delay for OUT1 is missing:

    set_output_delay 0.75 -rise -clock CLK1 {OUT2}
set_output_delay 0.75 -rise -clock CLK1 {OUT3}
