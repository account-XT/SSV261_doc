TCLCMD-1068

NAME

TCLCMD-1068

SUMMARY

One or more of the target pins given with create_clock/create_generated_clock for clock are hierarchical pins. These hierarchical pins have been mapped to their respective flat pin(s). report_clocks <clk_signame_list> can be used to report the mapped flat pins for a given clock.

DESCRIPTION

This warning is issued when one or more of the target pins, specified using the create_clock or create_generated_clock constraint, for clock <clkname> are hierarchical pins.

.P

Even though constraints on hierarchical pins are supported, but in some cases (for example, floating hierarchical pins or hierarchical pin on power/ground nets), the hierarchical pins are mapped to the best possible driver or are connected to sink flat pins. You can use the report_clocks <clk_signame_list> command to report mapped flat pins for a given clock.

.P

In order to avoid this warning and subsequent mapping of such hierarchical pins to flat pins, you must redefine the clocks, specified using the above constraints, by specifying flat pins.
