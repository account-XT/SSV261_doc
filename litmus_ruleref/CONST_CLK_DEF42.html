CONST_CLK_DEF42

NAME

CONST_CLK_DEF42 (CONSTRAINT_SIGNOFF)

MESSAGE

Reference object is not reached by correct clock

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that an object referenced in a command is not reached by any clock or the clock specified in the command. The following are the possible causes for this violation:

  • set_sense command specified without -clock option but the reference object is not reached by any clock
  • set_sense command specified with -clock option but the reference object is not reached by the clock
  • set_input_delay command specified with -clock and -reference_pin options but the reference object is not reached by the clock
  • set_output_delay command specified with -clock and -reference_pin options but the reference object is not reached by the clock

This rule is checked by verify_timing_intent command and the results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
scope string Design Name
source_object object Source object
reference_object object Reference object

EXAMPLE

  • The following example contains a dummy clock and constraints. The dummy clock clk_dummy does not have any influence on the constraints. This rule is reported for the set_sense, set_input_delay, and set_output_delay commands, because the reference object is not reached by any clock or the dummy clock clk_dummy specified in the commands.

    create_clock -name clk_dummy -period 2 [get_ports clk_dummy]
set_sense -stop_propagation [get_pins i_clk_buf/Z]
set_sense -stop_propagation -clocks [get_clocks clk_dummy] [get_pins i_clk_buf/Z]
set_input_delay -clock [get_clocks clk_dummy] -reference_pin [get_pins i_clk_buf/A] 1 [get_ports din]
set_output_delay -clock [get_clocks clk_dummy] -reference_pin [get_pins i_clk_buf/A] 1 [get_ports dout]
