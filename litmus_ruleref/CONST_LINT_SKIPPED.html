CONST_LINT_SKIPPED

NAME

CONST_LINT_SKIPPED (CONSTRAINT_LINT)

MESSAGE

SDC command is skipped

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that a command in block level constraints is skipped. In Constraint Hierarchical Signoff flow, block level constraints are loaded into block scope, and all the objects referred in the block level constraints need to be accessible by the commands in the top level.

A command in block level constraints is skipped if it accepts port object and cannot accept pin object. The following are the possible causes for this violation:

  • set_load command applied to port at block level
  • set_max_fanout command applied to input port at block level
  • set_min_fanout command applied to input port at block level
  • set_wire_load_model command applied to input port at block level
  • set_drive command applied to port at block level
  • set_driving_cell command applied to port at block level
  • set_fanout_load command applied to port at block level
  • set_input_transition command applied to port at block level

This rule is checked during design initialization by init_design command and the results can be reported by report_sdc command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
file_line unsigned File number
file_name string File name
command string Constraint command

EXAMPLE

  • The following example contains set_input_transition command in block level constraints. This rule is reported for the set_input_transition command, because it is applied to the port blk_din in the block level which cannot be accessible by the set_input_transition  command in the top level. Note that set_input_transition command accepts port object only.

    Block level constraints

    set_input_transition 2 [get_ports blk_din]
