CONST_CLK_DEF1

NAME

CONST_CLK_DEF1 (CONSTRAINT_SIGNOFF)

MESSAGE

Clock is missing

DEFAULT SEVERITY

Warning

DESCRIPTION

Indicates that there is an unconstrained clock pin on a sequential element. That is, this rule checks for clocks that do not belong to any clock tree. This can happen if there is a missing create_clock or create_generated_clock command, or if there is an incorrect set_case_analysis. Note that each clock tree driver cell is reported once, together with one sequential cell driven by it, and the number of additional such sequential cells. To help the debugging process (concentrating on the more important cases first), the detailed messages that appear in the verbose report and in the GUI are sorted by the number of driven sequential cells in descending order. This rule is checked by  verify_timing_intent command and results can be reported by  report_rule_check command.

The following are possible causes of this rule violation :

  • Clock pin is not reached by any clock because of constant
  • Clock pin is not reached by any clock because of blocked clock
  • Clock pin is not reached by any clock because of missing clock
  • Generated clock is missing because not match generated clock source path count

Attribute  ltms_const_generated_clock_enable_launch_clock_based_source_path_count  can specify generated clock source path count to be launch clock based or path based.
 Attribute ltms_const_report_all_witnesses can specify whether to report all clock pins for one violation.

EXAMPLE

  • For the figure below, the Litmus identifies a warning if the following SDC has only line #1 and missing line #2:

    create_clock -name CLK -period 8 [get_pins clkgen/clkout]
create_generated_clock -name GCLK -divide_by 2 -source [get_pins clkgen/clkout] [get_pins clkoutdiv/Q]
