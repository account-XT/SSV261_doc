CONST_LINT_INFO3

NAME

CONST_LINT_INFO3 (CONSTRAINT_LINT)

MESSAGE

SDC version (sdc_version) specified in a constraint file is under minimum limit

DEFAULT SEVERITY

Ignore (default Warning)

DESCRIPTION

Indicates that SDC version specified in the constraint file is under minimum limit. Constraint files are setup by read_sdc, set_target_check_constraints, or read_mmmc command and loaded during design initialization by init_design command. This rule is checked during design initialization by init_design command and the results can be reported by report_sdc command.


This rule has specific rule occurrence attributes for the details about the violation.

Attribute

Type

Description

occurrence_id unsigned Occurrence id
file_line unsigned File number
file_name string File name
sdc_file_name string SDC file name
sdc_version string SDC Version
