CONST_COMP_CLK4

NAME

CONST_COMP_CLK4 (CONSTRAINT_COMPARISON)

MESSAGE

Missing target clock on target port/pin connected to a reference clock source

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule reports that a target's constraint file does not define a clock on a port or pin that is in the clock tree, or is a source, of a reference clock object. In the case that such a target clock is defined, this rule reports if the target clock and the reference clock are not defined as equivalent. Note that report_hierarchical_clock_mapping command can be used to understand how the clocks are mapped between the reference clocks and target level clocks to determine if this rule violation is due to incomplete clock mapping. This rule is checked by compare_constraints command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

AttributeTypeDescription
occurrence_id unsigned Occurrence id
target_view_name string Target View Name
reference_view_name string Reference View Name
scope object Block Instance
target_port object Target Port
reference_clock object Reference clock
reference_lib_gen_clk_file_line unsigned Reference_Lib_Gen_Clk_File_Line
reference_lib_gen_clk_file_name string Reference_Lib_Gen_Clk_File_Name
reference_file_line unsigned Reference file number
reference_file_name string Reference file name


In addition, common rule occurrence attribute type provides the possible causes for the violation.

AttributeValueDescription
type BLOCK_MISSING_CLOCK Missing clock at target level

EXAMPLE

  • For the figure below, this rule will report a violation if the reference port Top_clk is connected to i_blk/Blk_clk, and the reference constraints file contains the following, but the target level constraints file of target i_blk is missing the following target level command:

    Top level constraint

    create_clock -period 10 [get_ports Top_clk] -name Top_clk

    Block level constraint (instance scope: i_blk)

    create_clock -period 10 [get_ports Blk_clk] -name Blk_clk

    Hierarchical clock mapping

    Top_clk is mapped to Blk_clk
