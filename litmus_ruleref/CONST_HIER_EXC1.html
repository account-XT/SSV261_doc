CONST_HIER_EXC1

NAME

CONST_HIER_EXC1 (CONSTRAINT_HIER_SIGNOFF)

MESSAGE

A block path without set_false_path is part of a top-level false path

DEFAULT SEVERITY

Warning

DESCRIPTION

This rule reports that a block path, which was not declared as false path at the block level, has been affected by top level false path specification. This rule is checked by check_target_constraints command and results can be reported by report_rule_check command.


This rule has specific rule occurrence attributes for the details about the violation.

EXAMPLE

  • For the figure below, if the block level constraints file has a false path defined from R1 as follows and the top level constraints file has defined a false path in Block_A like the following then the Litmus issues a warning because the block level did not consider the path from IN1A to R1 as false with a false path specification from the top level.

Top level constraint

set_false_path -through Block_A/IN1A

Block level constraint (instance scope: Block_A)

set_false_path -from R1
