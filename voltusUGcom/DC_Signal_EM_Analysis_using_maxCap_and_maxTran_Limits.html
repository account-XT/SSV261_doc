DC Signal EM Analysis using maxCap and maxTran Limits

The software manages DC electromigration using maximum capacitance limit based on switching frequency. This is driven by maxCapPerFreq data in liberty. In addition, it also supports maxCapPerTran and maxCapPerFreqTran.

Optionally these constraints can be set for cell pins manually, as follows:

set_max_cap_per_freq \
-force \
-freq {0 100e6 200e6} \
-cap {2.0 2.0 1.0} \
-pins {*_16X *}

set_max_transition_per_freq \
-force \
-lib tcbn65lplvtwc \
-freq {50e6 70e6 100e6 200e6} \
-tran {5.0 4.0 3.0 1.5} \
-pins {* *}
