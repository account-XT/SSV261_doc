Unified Power Switching Flow

Voltus supports handling of the switch net designs by performing combined analysis of the always-on and switch nets. In this flow, the power-up and always-on analyses are performed in a single flow, wherein the switch nets and always-on nets are simulated together resulting in improved performance and accuracy. This flow has the following benefits:

  • Automatic tracing of all switch nets from the DEF file
  • Automatic identification of all power gates
  • Support for distributed processing in both the always-on and power-up flows
  • Ability to reuse extraction results between the two flows
  • Pin-based EIV report enhanced to display the switch net names
  • Display of switch nets in the GUI
  • Report generation for switch nets

Use Model

You can enable this flow using the -unified_power_switch_flow {true | false} parameter of the set_rail_analysis_mode command.

  • Always-on Flow: set_rail_analysis_mode -unified_power_switch_flow true
  • Power-up Flow: set_rail_analysis_mode -unified_power_switch_flow true and -powering_up_rails <powerup_rail_list>

Tcl Example for the Power-up Flow

set_rail_analysis_mode
-method dynamic -accuracy hd \
....
-powering_up_rails "VDD_sw1 VDD_sw2" \
-enable_xp true \
-unified_power_switch_flow true
