Vector Profile Report Format

The format of the vector profile report is:

# Header 
# Tile Description

Tile 1 X1 Y1 X2 Y2 
Tile 2 X1 Y1 X2 Y2 
Tile n X1 Y1 X2 Y2

# Worst-Case Vectors <sorted based on max power density tile> 
Tile No.    Power Density (mW/tile area)  # Vector Time Stamp

# Worst Tile Profile For Each Step
Tile No.    Power Density (mW/tile area um^2)    time stamp

# Worst Time Stamp Profile For Each Tile
Tile No.    Power Density (mW/tile area um^2)    time stamp

# Detailed Tile Profile For Each Step
Step(ns)    Instance    Power(mW)    Internal Power(mW)    Switching Power(mW)    Leakage Power(mW)    Activity
