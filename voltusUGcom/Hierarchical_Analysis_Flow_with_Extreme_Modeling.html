Hierarchical Analysis Flow with Extreme Modeling

The hierarchical analysis flow with XM has two steps, as shown in the following diagram:

  • xPGV generation (Block Analysis) - perform chip-level or block-level rail analysis to obtain only block-level instance current data and generate xPGV model.
  • xPGV instantiation (Top-Level Analysis) - instantiate the generated xPGVs and use them to perform top-level rail analysis.

The hierarchical analysis flow with XM requires the Voltus-XM license. It is an option to the baseline license Voltus-XL. The licensing use model for Voltus-XM is:

  • xPGV generation - One Voltus-XM license is required for generating one xPGV model.
  • xPGV usage - One Voltus-XM license is required for each xPGV model that is used in the analysis up to a maximum of 10 XM licenses. Usage of more than 10 xPGV models does not require more than 10 licenses. That is, 10 XM licenses will be able to use 12 xPGV models. License requirement is based on number of models used instead of instantiations. If a CPU block’s xPGV model is instantiated four times, it will require only one XM license.
