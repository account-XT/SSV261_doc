Rail Analysis in Body Biasing

Once the power-grid view library is generated for cells with body bias pins and power analysis is run to compute power dissipation on these pins, you can run static and dynamic IR drop analysis on body bias network. Through library generation, current taps (sinks) are added on diffusion ports.

In order to extract body bias PG network connectivity to diffusion ports of cell, and process current taps on body bias pins, specify the following command parameters during rail analysis:

  • set_rail_analysis_config -process_bulk_pins_for_body_bias true
    Default: false
    This parameter processes current taps assigned to bulk pins in power-grid view library. It is used during body bias analysis where current taps are assigned to bulk pins.
  • set_rail_analysis_config -include_extraction_tool ./mybbias.cmd
    In the mybbias.cmd file, specify the following variable:
    setvar enable_toplevel_diff_extract true
    Default: false
    Extracts ports defined on the diffusion layer in power-grid view library. This variable is used during body bias analysis to extract connectivity in the diffusion layer.

Sample Tcl Script for Rail Analysis


Following is an example Tcl script for rail analysis:
set_power_pads -net bVDD -file BVDD.vsrc -format xy
set_power_pads -net bVSS -file BVSS.vsrc -format xy
set_pg_nets -net BVDD - -threshold 0.25 -voltage 0.3
set_pg_nets -net BVSS –threshold -0.25 -voltage -0.3
set_rail_analysis_config -accuracy hd -method static \

-power_grid_libraries ./mylibrary.cl \
-process_bulk_pins_for_body_bias true \
-include_extraction_tool ./mybbias.cmd

set_power_data -reset
set_power_data -format current {static_BVDD.ptiavg static_BVSS.ptiavg}
report_rail -output_dir ./result -type net BVDD
report_rail -output_dir ./result -type net BVSS
