Creating and Loading Hierarchical Databases

Voltus provides a hierarchical database based GUI that allows you get both a flattened top view as well as a hierarchical view of a design. This feature allows you to view instance-level and design-level hierarchies. To create a hierarchical database (HDB), you need to specify a list of LEFs and hierarchical DEFs.

To create and load an HDB, you need to perform the following steps:

  1. Start Voltus using the following command:
    voltus -stylus –files input_file

  2. Specify the read_physical -lefs and init_hier_design commands to load the design (LEF files and hierarchical DEFs).

    You can read the hierarchical DEFs using the read_def or init_hier_design command.

  3. Specify the write_hier_db command to save a snapshot of the design data, including the binary timing data, timing constraints file, netlist, and the timing analysis state.
  4. Specify the read_hier_db command to restore all logical design information from a previous hierarchical design session saved in the software.
  5. Start the GUI using the gui_show command.

    • select an instance and pull up level by level, or to directly pull up to the top level

After loading the HDB database, you can load the rail directory and analyze the different rail plots.

Tcl Commands for Creating and Loading Hierarchical Database:

The following are the Tcl commands for creating an HDB:
read_physical -lefs tech.lef allcells.lef
init_hier_design -defs $designDir/Data/def/design1.def $designDir/Data/def/Cpu.def $designDir/Data/def/design2.def $designDir/Data/def/design3.def .. -skip_signal_nets
write_hier_db saveDB

The following are the Tcl commands for restoring a saved HDB and loading the state directory:
read_hier_db saveDB Chip
read_power_rail_results -rail_directory ./rail/pd_25C_dynamic_1 -instance_voltage_window {timing whole} -instance_voltage_method {avg worst}
