EM Modeling using QRC Technology File


In addition to the set_rail_analysis_config -em_models file command parameter, you can use the QRC Techfile for EM model specification. The set_rail_analysis_config -process_techgen_em_rules true parameter specifies to process the EM models in the ICT section of the qrcTechFile.


The -process_techgen_em_rules and -em_models parameters of the set_rail_analysis_config command are mutually exclusive. If none of these parameters are specified, rj analysis will not be performed. When -process_techgen_em_rules is specified with -extraction_tech_file, the extraction technology file will be processed. If -process_techgen_em_rules is specified without -extraction_tech_file, the .cl model will be processed.


You need to use Techgen to update the qrcTechFile with the EM model information. Techgen can be found under the bin directory of the Quantus QRC installation hierarchy. Use the following Techgen command to include the EM rules from the specified .ircx file or ICT file into the qrcTechFile for all the process nodes: Techgen -update_em techfile iRCX_file_with_EM_models/ict_file_with_EM models The EM models are available in the specified IRCX or ICT-EM (ICT with only the em_model section) file. Instead of updating the qrcTechFile, you can also use the following command to directly specify the ICT-EM file in Voltus to calculate the EM limits for power net EM analysis: set_rail_analysis_config –process_techgen_em_rules true –ict_em_models ICT-EM file


If you are defining an em_model to be used for limit based analysis, specify the em_jmax_ac_avg parameter that specifies the maximum AC average current density which can either be defined as a single value, a PWL table, or an equation (EQU). The following examples illustrate the limits supported:

  • Single value - use a single number limit for current density.
    em_jmax_dc_avg 12.15
  • PWL table - use piecewise linear (PWL) interpolation in the em_model to accurately determine current density using interpolation of specified points on a graph. It allows you to specify Jmax value for each width/area of metal/via in the design to support width dependency on limits.
    • Conductor: em_jmax_dc_avg = "jmax_value_1 width_1 … jmax_value_n width_n"
    • Via: em_jmax_dc_avg = "jmax_value_1 area_1 … jmax_value_n area_n"

    em_jmax_dc_avg PWL 0.1672 0.002025 0.3344 0.005265
  • Equation - use an equation to calculate current density. The EQU keyword denotes the definition of an equation for current density. It supports width dependencies.
    em_jmax_dc_avg EQU 1 * 0.996 * ( w - 0.003 )
