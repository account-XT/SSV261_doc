Steady State Rail Analysis

Steady state rail analysis can be done on power-gated design to analyze whether placed power-gates are sufficient to accommodate the power need of the power-gated block. The GUI and Tcl instructions to run steady state rail analysis on power-gated design is same as described in static power, IR drop and EM analysis and dynamic power and IR drop analysis. The static or dynamic power can be fed in the form of current files of all associated nets to do this analysis.

If CPF is used, you can specify the analysis view using set_rail_analysis_config -analysis_view view. This will automatically derive all power domains defined in CPF and voltage of all power nets in the domain.

set_rail_analysis_config -analysis_view view
# following commands are executed automatically by the program
# set_pg_nets
# set_rail_analysis_domain

If a switched net is off in an analysis view, this information is also automatically derived from CPF. However, if CPF is not loaded, you must specify off power nets manually using set_rail_analysis_config -exclude_nets net_name. In addition, you must specify all power nets, its voltages and domain using the set_pg_nets and set_rail_analysis_domain commands.

It is important to note that when analyzing power-gated domain, you do not have to specify a switched net in the domain definition (set_rail_analysis_domain). This definition should only contain always-on net names. The switched net is automatically traced by the program and the state of this switched net is either driven by set_rail_analysis_config -exclude_nets or directly from CPF.

In non-CPF steady state analysis of power-gated domain,

set_rail_analysis_config -exclude_nets VDDlu
set_pg_nets -net VDDau -voltage 0.84 -threshold 0.756 -tolerance 0.3
set_pg_nets -net VDDlu -voltage 0.84 -threshold 0.756 -tolerance 0.3
set_pg_nets -net VDDm -voltage 0.84 -threshold 0.756 -tolerance 0.3
set_pg_nets -net VDD -voltage 1.08 -threshold 0.972 -tolerance 0.3
set_pg_nets -net VSS -voltage 0.0 -threshold 0.084 -tolerance 0.3 
set_rail_analysis_domain -domain_name PDmac1 -power_nets VDDm -ground_nets VSS
set_rail_analysis_domain -domain_name PDmac2 -power_nets VDDm -ground_nets VSS
set_rail_analysis_domain -domain_name PDcore -power_nets VDD -ground_nets VSS
set_rail_analysis_domain -domain_name ALL -power_nets {VDDm VDD} -ground_nets VSS

Once the analysis is complete, load the results using report_power_rail_results command and view the graphical plots "power-gate current I/Idsat - pi" and "power-gate voltage -pv".

In addition, review the pi.report text file generated by the analysis.
