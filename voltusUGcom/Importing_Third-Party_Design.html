Importing Third-Party Design

Voltus IC Power Integrity Solution allows you to load Verilog, timing libraries, SDC, DEF(s), LEF(s) and SPEF(s). The design data can be loaded from the GUI using the Setup tab as shown in the following steps:

  1. Select the Setup tab.
  2. Fill out the fields or click Load to load a design setup file that has the appropriate Tcl commands.
  3. Click Apply.

Tcl Command for Importing Third-Party Design

The design data can be loaded using the following Tcl commands:

read_physical -lefs tech.lef allcells.lef
read_libs -min_libs stdcells_min.lib memories_min.lib
read_libs -max_libs stdcells_max.lib memories_max.lib
read_netlist "$Design_Dir/verilog/design.v" -top top_module_name
init_design
read_sdc design.sdc
read_def design.def.gz
read_spef design.spef.gz
read_power_intent -cpf design.cpf

To improve the design import performance, the read_def command supports the -skip_signal_nets parameter which skips signal nets when loading the DEF files.
read_def -skip_signal_nets design.def
