Hotspot Debugger

Hotspot Debugger enables you to identify and fix the hotspots in a design. Hotspot Debugger can automatically identify the region with worst IR drops and EM violations, and provide necessary information to determine and fix the root cause. Using this feature, you can identify whether the hotspot is caused by one or more of the following:

  • Data error
  • Weak power-grids or missing vias
  • High average power density, simultaneous switching
  • Low decap density
  • Lack of power-gates
  • Lack of power bumps
  • Package effects

Hotspot Debugger will identify the top violating instances in each region and report the following information:

  • Hotspot Region Coordinate
  • Timing Library Analysis
  • Power-Grid View Analysis
  • Power-Grid Integrity Analysis
  • IR-Drop Composition
  • Root Cause Analysis

Use the report_irdrop_regions command to identify hotspots. You must specify this command after running the report_rail command.

The Hotspot Debugger feature requires a VTS-XL license.
