Checking the Power-Grid Library and Report

You can perform a comprehensive check of power-grid libraries and generate a report. These checks include:

  • Verify that all the PGV views exist: Early/IR/EM
  • Report the dynamic PWL and static current
  • Perform a compatibility check on the version, layermap and resistivity parameters
  • Check any missing information, such as temperature, qrcTechFile location, and so on.

Viewing a Power-Grid Library Report in the GUI

The power-grid library report includes the cell name, associated power pins and their voltage, capacitance, generated views and PASS/FAIL cell status. The power gate cells are identified and characterized Ron, Idsat and Ileakage values are printed. The cells without any power-grid views or power nets/pins are tagged with the FAILED status.

The following steps are needed to view a power-grid library cell in the GUI:

  1. Select Power & Rail - Textual Reports - PowerGrid Library.
    The following form appears:
  2. Click the browse button next to the Power Library field, and select a library from the PowerGrid Library browser window.
  3. Select the View Power Library option
  4. Select All Cells to view all cells, or select Cell and specify the cells to view in the library report.
  5. Click Apply or OK.
    The power-grid view library report appears in the Console tab.
