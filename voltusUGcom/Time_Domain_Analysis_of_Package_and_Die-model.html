Time Domain Analysis of Package and Die-model

The following figure shows how the package is mapped to the die to perform full-chip dynamic transient analysis using Voltus.

However, this transient analysis is expensive and limited to only a few clock cycles. In order to simulate the package + die for longer duration to analyze the impact of package inductance (Ldi/dt) beyond initial clock cycles, you can run transient analysis on package + die-model, as shown in the following figure:



The package + die-model transient simulation setup is captured in .sp file in the output directory specified by write_die_model command. This setup can be simulated in SPICE. Although original dynamic IR drop simulation is performed over limited number of cycles, it may not fully capture on-chip current and voltage oscillation due to package. You can choose to repeat the original dynamic current profile of the chip (captured as .isrc file in output directory) using the -repeat <time in ns> option in write_die_model command. This enables you to perform transient simulation of package and die-model for longer periods of time:

* Voltage sources *

*******************************
VVSS VSS_in 0 DC 0
VVDDm VDDm_in 0 DC 0.84
VVDD VDD_in 0 DC 1.08
*******************************
* User specified package file *
*******************************
.INCLUDE "./c2_399_msmv.ckt"
**********************************************
* Sub-circuit file created for the representing die
**********************************************
.SUBCKT ALL N001 N002 N003
** Die Model Resistors
R_VSS00 N001 N004 0.00794167
R_VSS01 N004 N007 0.00794167
R_VSS02 N007 N010 0.00794167
R_VDDm00 N002 N005 0.573108
R_VDDm01 N005 N008 0.573108
R_VDDm02 N008 N011 0.573108
R_VDD00 N003 N006 0.0413616
R_VDD01 N006 N009 0.0413616
R_VDD02 N009 N012 0.0413616
** Die model Capacitors
C_VSS00 N004 0 3.71397e-09
C_VSS_VDDm_01 N007 N008 2.27204e-24
C_VSS_VDD_03 N007 N009 2.4652e-18
C_VDDm00 N005 0 3.63009e-10
C_VDD00 N006 0 6.03553e-10
** Die Model Stimulus
.INCLUDE "ALL.sp.isrc"
.ENDS ALL
*******************************
* Instance of package model *
*******************************
Xpkg1 VSS_in PK_O2 VDD_in PK_O4 VDDm_in PK_O6 c2_399
*******************************
* Instance of die model *
*******************************
Xdie1 PK_O2 PK_O6 PK_O4 ALL
* Transient analysis
*.TRAN 10p 14n
*.PROBE TRAN I(*) V(*)
*.PRINT TRAN I(xdie1.R_VSS00) I(xdie1.R_VDDm00) I(xdie1.R_VDD00)
.END
