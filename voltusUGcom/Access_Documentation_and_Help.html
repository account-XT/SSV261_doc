Access Documentation and Help

You can access the Voltus documentation and help system by using the following methods:

  • Launch Cadence Doc Assistant from the command prompt
  • Access documentation and help from the GUI
  • Use the man and help commands on the text command line
  • Other sources of information

Launching Cadence Doc Assistant from the Command Prompt

To launch Cadence Doc Assistant (CDA) from the command prompt:

  1. Change to the following directory:
    installation_dir/tools/bin
  2. Enter the following command:
    ./cda

After launching Cadence® Doc Assistant, click the hamburger menu on the top right of the Doc Assistant window, and click Help to display the help page for CDA.

Access Documentation and Help from the GUI

The software provides the following two methods to access documentation and help from the GUI:

  • Select Help on the Main Menu
    Click Help on the main menu and then select Documentation Library to open the CDA window. The CDA window provides access to all the documentation shipped with the release.
    Alternatively, select Help, and then click on any of the following options to open a document directly:
    • Text Command Reference - Opens the Table of Contents page of the text command reference.
    • User Guide - Opens the Table of Contents page of the user guide.
    • What’s New - Opens the Table of Contents page of the what’s new document
  • Select Help on a Voltus Form
    Click the Help button in the bottom right corner of a form. Clicking the Help button opens the Voltus Menu Reference entry for the form in the Cadence Help window.

Use the man and help Commands on the Text Command Line

You can use the man and help commands on the text command line to access the documentation and help as follows:

Using the help Command to View the Command Syntax

  • Type the following command in the software console to see syntax information for a command.

help command_name

For example, to see syntax information for the read_lib command, type the following command:

help set_power_include_file

The software displays the following text:

Command: set_power_include_file:
Usage: set_power_include_file [-help] [<file>] [-reset]
-help      # Prints out the command usage
<file>     # Specifies the powermeter include file which contains powermeter options (string, optional)
-reset     # Specifies to reset and ignore all the previous powermeter include files. (bool, optional)
  • Type the following command in the software console to see the entire list of Voltus commands and their syntax.

help

Use the man Command to View the Command Description

To see the complete set of information for a Voltus command, type the following command in the software console:

man command_name

For example, to see the complete set of information for the set_power_include_file command, type the following command:

man set_power_include_file

The software displays the following text:

Name

set_power_include_file - Specifies a power analysis include file

Syntax

set_power_include_file file [-reset]

Description

Specifies a power analysis include file. You can use the
set_power_include_file command to specify certain commands of the
dynamic engine which do not have a Voltus equivalent. For more informa-
tion on these commands, refer to the Power Analysis Options chapter.
The set_power_include_file command is required only if the
power_static_netlist attribute is set to def.

Note: The set_power_include_file command is used to pass the legacy
power analysis commands and report_power command options only in the
dynamic mode (vectorbased and vectorless). If the power_method
attribute is set to static, the set_power_include_file command is ignored.

Parameters

file                Name of the include file. This file will include all commands
                    that can not be translated to Voltus commands. In addition, you
                    can also include the report_power command options to generate
                    different power reports.

-reset              Resets all options back to default values.

Examples

* The following command specifies a power include file of
power.inc:
set_power_include_file power.inc

    Opens Cadence Online Support in your browser.
  • Web Collaboration
    Opens SpaceCruiser in your browser.
