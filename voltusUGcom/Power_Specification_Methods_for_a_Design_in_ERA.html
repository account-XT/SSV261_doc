Power Specification Methods for a Design in ERA

The three common methods to specify power for a design are:

  • Region Based Power Specification - This method is used for a fully unplaced design. You can specify the power based on the region and layer interactively in the GUI or command file. The specified power is distributed evenly on the specified layer in the given region, as shown below:
    The region-based power specification can be used in conjunction with the other methods.
  • Total Power and Text Power File - This method is used for a partially placed design. You can specify the total power consumption for the design, and optionally you can specify the estimated (or known) power consumption for the cell or macros: In addition, you can always specify the distribution of the total power using the region-based power specification. This method can be implemented using the following two options:
      • Option 1: Specify the user-defined current region and user-defined cell power file.
      • Option 2: Use the tool-generated current region and tool-generated power file for placed instances. 
    The following example illustrates the total power consumption for a design:


    Here, power consumption for the known placed instances can be specified for better accuracy. In the unplaced cell region, the current region is specified by interactively drawing regions in the GUI and specifying current on the desired layer.
  • Power Engine Calculated Power and Instance-based Power - If a design is fully placed, you can calculate the power by running the report_power command, or using GUI (Power & Rail -> Run Power Analysis menu). The power is computed using the synthesized Verilog netlist so it will be computed for all the instances in the design.
