Power Map File for Thermal Analysis

Voltus supports generation of a tile-based power map file to perform accurate thermal analysis. This power map file is later used by PowerDC, the thermal analysis tool for packages and boards.


To generate the power mapping file, you need to specify the following parameters of the report_power command:


  • -thermal_power_map_file file_name - generates the power map file with the specified name in the output directory.
  • -thermal_power_map_tiles {Xint Yint} - defines the tile number in the X and Y direction. By default 10*10 will be used.
  • -thermal_leakage_temperature {temp1 temp2 temp3 …} - defines the temperature to calculate leakage for the power map file in a simple format.
  • -thermal_power_map_format {simple | stack} - generates a tile-based power map file in the simple or stack format to perform accurate thermal analysis. The simple format generates a 2D power map file and the stack format generates a 3D power map file. You must use the stack format to support multiple dies in a package for thermal analysis. The default format is simple.
  • -thermal_conductivity_inputs file_name - specifies a file containing the thermal conductivity value for layers. You can use this parameter to include the thermal conductivity value of the following layers in the power map file:
    • Silicon
    • Metal
    • Dielectric
    • Micro Bump (optional for 3DIC design)
    • Fill material in micro bump layer (optional for 3DIC design)


The format of the thermal conductivity input file is:

Unit <unit_definition> (optional, by default unit is mW/(um * C))
Metal  <thermal_conductivity_value>
Silicon <thermal_conductivity_value>
Dielectric <thermal_conductivity_value>
Bump  <thermal_conductivity_value> (optional)
Fill_Material  <thermal_conductivity_value> (optional)

Tcl Scripts for Generating Power Map File

The Tcl scripts for generating simple power map file and stack power map file are as follows:


Tcl Script for Generating a Simple Power Map File


The following is the Tcl script for generation a simple power map file:

set_db power_method static
set_power_analysis_temperature 25
report_power -rail_analysis_format VS -o1ut_file powermeter.txt -thermal_power_map_file powermap.txt -thermal_power_map_tiles { 4 6 } -thermal_power_map_format simple



Tcl Script for Generating a Stack Power Map File


The following is the Tcl script for generation a stack power map file:

set_db power_method vector_profile power_vector_profile_mode {power_density} ...
read_activity_file -format SHM /shm/ADDER.trn -scope adder_tb_e/u1 -start 0ns -end 60ns
set_power_analysis_temperature 25
report_power -out_file powermeter.txt -thermal_power_map_tiles { 2 2} -thermal_leakage_temperature { 25 35 50} -thermal_power_map_format stack -power_density_tiles_row_col { 2 2} -time_based_report
