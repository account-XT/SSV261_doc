Generating Power-Grid Library for a Flip Chip Design

When running power and rail analysis for a flip chip design, you can create voltage sources for the flip chip to be used in the Rail Analysis flow. The bumps are modeled with several points in a resistor network, and hence avoid false EM violations.

The LEF file of the flip chip bump can be used as a reference. Bumps are usually octagonal, although sometimes they are represented as squares. The following is an example of the bump LEF file:


    VERSION 5.6 ;
    BUSBITCHARS "[]" ;
    DIVIDERCHAR "/" ;
    UNITS
     DATABASE MICRONS 1000 ;
     END UNITS
    MACRO BUMP
     CLASS COVER BUMP ;
     FOREIGN BUMP -49.45 -49.45 ;
     ORIGIN 49.45 49.45 ;
     SIZE 98.9 BY 98.9 ;
     PIN PAD
        DIRECTION INOUT ;
        USE SIGNAL ;
        PORT
          LAYER AP ;
            #RECT -49.45 -49.45 49.45 49.45 ;
            POLYGON -20.49 -49.45 20.49 -49.45 49.45 -20.49 49.45
            20.49 20.49 49.45 -20.49 49.45 -49.45    20.49 -49.45 -20.49 ;
        END
      END PAD
    END BUMP
   END LIBRARY

In the LEF file, a polygon shape is used to create an octagonal bump, but the corresponding coordinates that would have been used for a square are commented out.

The following are the steps for PGV characterization of a flip-chip design:

  1. Create a file called bump.padfile. This file contains one line, the MACRO name of the bump from the LEF, as shown below:
    BUMP
  2. Create a file called bump.srcfile, as shown below:
    CELL BUMP NET PAD PORT { AP -49.45 -49.45 49.45 49.45 } The CELL and NET names in the voltage source file must match that of the bump LEF file. The NET name is the PIN name from the LEF. Similarly, the port layer name in the voltage source file (AP) is the same layer from the LEF. The commented-out square coordinates in the LEF example can be used to specify the coordinates of the PORT shape which should be a square that encloses the octagonal bump.
  3. Create the bump power-grid view. You can create a technology-based bump PGV or a standard cell based PGV. When generating a standard cell based PGV, you can:
    • Specify separate pad names for power and ground pins
    • Specify a common pad name for power and ground pins
    • Specify x, y locations of the voltage sources to be connected to the pad cells
  4. Run Rail analysis.
    When running rail analysis, use the bump.padfile in the set_power_pads command. The same padfile can be used for any rail, as shown below: set_power_pads \ -net VDD \ -format padcell \ -file bump.padfile set_power_pads \ -net VSS \ -format padcell \ -file bump.padfile

All bumps will be recognized as voltage sources, with multiple points inside the bump shape.
