Library Setup for Innovus

Multiple libraries characterized with different operating voltages (triLibs) can be read into Tempus. Delay calculator computes an instance delay by interpolating delays between two libraries that are close to IR drop voltage of that particular instance.

For example, if you load libraries characterized for 1.0 volts, 0.9 volts, and 0.8 volts, the delay calculator uses1.0v and 0.9v libraries for all instances with IR drop < 1.0v and > 0.9v.

The triLibs can be loaded into Tempus in the following three ways:

  • Reading Libraries using the read_lib Commands
    read_libs [list [list $libDir/max/scmetro_cmos10lp_hvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_hvt_ss_0p9v_125c.lib] \
    $libDir/max/scmetro_cmos10lp_hvt_ss_1p08v_125c.lib] \
    [list $libDir/max/scmetro_cmos10lp_lvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_lvt_ss_0p9v_125c.lib \
    $libDir/max/scmetro_cmos10lp_lvt_ss_1p08v_125c.lib] \
    [list $libDir/max/scmetro_cmos10lp_rvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_rvt_ss_0p9v_125c.lib \
    $libDir/max/scmetro_cmos10lp_rvt_ss_1p08v_125c.lib]\
    $libDir/max/pllclk_slow.lib \
    $libDir/max/iometroil_cmos10lp_hvt_ff_1p1v_2p7v_2p5v_m40c.lib \
    $libDir/max/ram_256x16A_ss_1p08v_125c_syn.lib \
    $libDir/max/rom_512x16A_ss_1p08v_125c_syn.lib]
    Libraries with same cells characterized for different voltages should be grouped into separate list. From the above example, libraries scmetro_cmos10lp_hvt_ss_*, scmetro_cmos10lp_lvt_ss_* and scmetro_cmos10lp_rvt_ss_* which has three libraries characterized for 1.0v, 0.9v and 0.8v are grouped into a list. The list can be mixed with other libraries like pllclk_slow.lib, which is not characterized with multiple operating voltages.
  • MMMC Setup
    triLibs can be specified while creating library sets for particular corner.
    create_library_set -name max_corner \
    [list [list $libDir/max/scmetro_cmos10lp_hvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_hvt_ss_0p9v_125c.lib] \
    $libDir/max/scmetro_cmos10lp_hvt_ss_1p08v_125c.lib] \
    [list $libDir/max/scmetro_cmos10lp_lvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_lvt_ss_0p9v_125c.lib \
    $libDir/max/scmetro_cmos10lp_lvt_ss_1p08v_125c.lib] \
    [list $libDir/max/scmetro_cmos10lp_rvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_rvt_ss_0p9v_125c.lib \
    $libDir/max/scmetro_cmos10lp_rvt_ss_1p08v_125c.lib]\
    $libDir/max/pllclk_slow.lib \
    $libDir/max/iometroil_cmos10lp_hvt_ff_1p1v_2p7v_2p5v_m40c.lib \
    $libDir/max/ram_256x16A_ss_1p08v_125c_syn.lib \
    $libDir/max/rom_512x16A_ss_1p08_125c_syn.lib]
  • read_design Configuration File
    Libraries can be loaded into Tempus via configuration file which exists in the saved database. The following syntax should be used in the configuration file to load triLibs via read_db
    set rda_Input (ui_timelib)
    [list [list $libDir/max scmetro_cmos10lp_hvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_hvt_ss_0p9v_125c.lib] \

$libDir/max/scmetro_cmos10lp_hvt_ss_1p08v_125c.lib] \
    [list $libDir/max/scmetro_cmos10lp_lvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_lvt_ss_0p9v_125c.lib \

$libDir/max/scmetro_cmos10lp_lvt_ss_1p08v_125c.lib] \
    [list $libDir/max/scmetro_cmos10lp_rvt_ss_0p8v_125c.lib \
    $libDir/max/scmetro_cmos10lp_rvt_ss_0p9v_125c.lib \

$libDir/max/scmetro_cmos10lp_rvt_ss_1p08v_125c.lib] \

$libDir/max/pllclk_slow.lib \

$libDir/max/iometroil_cmos10lp_hvt_ff_1p1v_m40c.lib \

$libDir/max/ram_256x16A_ss_1p08v_125c_syn.lib \

$libDir/max/rom_512x16A_ss_1p08v_125c_syn.lib]

    It is recommended that for better accuracy, the difference between two adjacent libraries should not be more than 20%. Also better delay accuracy can be achieved by reducing this difference at lower operating voltages.

    The voltage range of characterized libraries should cover min and max IR drop voltages. If IR drop voltage of an instance falls out side this range, extrapolation is not supported currently, instead Tempus adjusts the voltage to the closest value. For example, if libraries characterized for 0.8, 0.9 and 1.0 are read-in and a particular instance IR drop voltage is 1.1volt, Tempus computes the delays for this instance based on 1.0 volt.

Sample Tcl Script for IR Drop Impact on Timing

Non-MMMC Mode

The following is the sample Tcl script for Non-MMMC Mode:


#Load the design
read_db simple.conf


#Set analysis mode to on chip variations
set_db timing_analysis_type onChipVariation


# Read parasitics information
read_spef simple.spef


# input max and min IR drop files
update_delay_corner -late_irdrop_files simple_max.iv
update_delay_corner -early_irdrop_files simple_min.iv


#Analyze setup and hold timing of critical paths
report_timing -late -path_type full_clock
report_timing -early -path_type full_clock


#Analyze clock skew
report_clock_timing -type skew -nworst 10 -verbose


#Analyze clock jitter
report_clock_timing -type jitter -nworst 10


#check data path delays from spice with orioinal STA report
write_spice_deck -report_timing_cmd {-from i_5/CK -late -path_type full_clock} \
 -out_dir path_spice_deck_max -power_nets {VDD VNW} -ground_nets {VSS VPW} \
 -spice_model_files "spmodels.sp" -spice_subckt_files cmos10lphvt_m.cdl \
 -run_path_simulation


#check clock path delays from spice with original STA report
write_spice_deck -report_timing_cmd {-from i_5/CK -early -path_type full_clock} \
 -out_dir path_spice_deck_min -power_nets {VDD VNW} -ground_nets {VSS VPW} \
 -spice_model_files "spmodels.sp" -spice_subckt_files $ file cmos10lphvt_m.cdl \
 -run_path_simulation

Setting Up a Delay Corner in MMMC Mode with TriLibs and IR Drop Files Per Corner


create_library_set -name max_corner \
 [list [list $libDir/max/scmetro_cmos10lp_hvt_ss_0p8v_125c.lib \
 $libDir/max/scmetro_cmos10lp_hvt_ss_0p9v_125c.lib] \
 $libDir/max/scmetro_cmos10lp_hvt_ss_1p08v_125c.lib] \
 [list $libDir/max/scmetro_cmos10lp_lvt_ss_0p8v_125c.lib \
 $libDir/max/scmetro_cmos10lp_lvt_ss_0p9v_125c.lib \
 $libDir/max/scmetro_cmos10lp_lvt_ss_1p08v_125c.lib] \
 $libDir/max/pllclk_slow.lib ]

create_rc_corner -name rc-cworst -cap_table myTech.4_bc.CapTbl -temperature 50

create_delay_corner -name dcWCCOM \
-rc_corner rc-cworst \
-late_irdrop_files high_active.iv\
-early_irdrop_files low_active.iv
