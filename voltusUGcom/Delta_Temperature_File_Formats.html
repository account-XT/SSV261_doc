Delta Temperature File Formats

Detail Delta Temperature File (ddt) - Self-Heat Analysis

The following is the detail delta temperature file format for self-heat analysis:


# Report Format :

# LayerName  I_rms(mA)  Alpha Beta T_FEOL T_RMS T_BEOL  ll_x ll_y  ur_x  ur_y  

# Net: IN01

# Net: IN02

M2  0.0002  0.8000  0.8429  0.2363  0.0000  0.1594 (4939.380 1177.008) (4939.397 1177.040)
M2  0.0002  0.5500  0.8429  0.2092  0.0000  0.0970 (4939.315 1177.008) (4939.380 1177.040)


Detail Delta Temperature File (ddt) - Joule Heat Analysis

The following is the detail delta temperature file format for Joule heat analysis:


# Report Format :

# LayerName I_rms(mA) dT_RMS  ll_x     ll_y       ur_x     ur_y      

# Net: IN01

 M2       0.0380    0.0511  (144.684  118.310) (144.720 118.330)
 M3       0.0380    0.1023  (144.708  118.320) (144.732 120.040)
 ...

where ,

  • DIE_AREA specifies the coordinates of the die area. nx and ny is the tile number in the temperature map file.
  • NUMBER_OF_LAYERS is the number of layers in each die instance.
  • LAYER specifies the LEF layer name.
  • XCOR and YCOR are coordinates of each layer.
  • T(0,0) …. is the temperature value assigned to a tile at a specific coordinate.
