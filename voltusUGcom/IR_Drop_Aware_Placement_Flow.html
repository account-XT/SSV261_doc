IR Drop Aware Placement Flow

The following diagram illustrates the IR Drop Aware Placement analysis flow:



The flow has three fundamental steps:

  1. Restore the post CTS or post-routed database using the following command:
    read_db
  2. Set up power and rail analysis modes and environment using the following commands:
    set_power_output_dir dir_name
set_db power_* ...
set_default_switching_activity ...
set_dynamic_power_simulation ...
set_rail_analysis_config ...
set_pg_nets ...
set_rail_analysis_domain ...
set_power_pads ...
  3. Perform IR aware placement analysis using the following commands:
    set_db power_* ...
place_detail ...
route_eco

In this flow, the place_detail command performs power and rail analysis, identifies hotspots, and refines the placement of instances. After checking for IR Drop violations, if there are still some critical violations, a second iteration of IR aware placement is done which is followed by IR Drop analysis.
