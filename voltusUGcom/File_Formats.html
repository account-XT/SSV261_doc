File Formats

The following are the types of file formats:

Library Generation

The library generation file formats are as follows:

  • Current Region File
  • Cell Pin Net Map File
  • Cell Accura Data File
  • Cell Decap File
  • Cell Well Cap File
  • Circuit Include File
  • GDS Layermap File
  • LEF-DEF Layermap File
  • Pad Voltage Source File
  • Port File
  • Trigger File

Power Generation

The power generation file formats are as follows:

  • Instance ASCII Power File
  • Instance Temperature File
  • TCF File
  • TWF File

Rail Analysis

The rail analysis file formats are as follows:

  • Dynamic Trigger File During Rail Analysis
  • Dynamic Trigger File During Rail Analysis
  • EM Models File
  • EM Only ICT File
  • Package Model and Mapping File
  • Power-Up Sequence File
