Performing Signal FIT Analysis

To perform signal FIT analysis:

  1. Run signal EM analysis.
    Tcl command:

    set_db  
        check_ac_limit_method {avg} \
            check_ac_limit_avg_recovery 0 \
            check_ac_limit_detailed \
            check_ac_limit_use_qrc_tech \
            check_ac_limit_use_db_freq \
            check_ac_limit_out_file seb_reduce.rpt \
            check_ac_limit_enable_seb \
            check_ac_limit_seb_table seb_table.txt \ 
            check_ac_limit_env_temperature 85 \ 
            check_ac_limit_seb_lifetime 43800 \
            check_ac_limit_check_thermal_aware_em \ 
            check_ac_limit_read_detail_delta_temperature_file power_detail.rpt \
            check_ac_limit_ict_em_models $ictem
    check_ac_limits

    The Voltus console will display the number of violations, as shown in the following snippet:

    Num Violations: 72

    **************End VerifyACLimit****************
       (CPU Time =0:03:56 MEM=23.020M)
