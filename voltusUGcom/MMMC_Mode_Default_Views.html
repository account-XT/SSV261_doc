MMMC Mode Default Views

If set to the MMMC mode, it is recommended to specify the view by one of the below commands,

set_db power_view viewname

or

report_power -view viewname

If you do not, then the default power view is the first setup or hold view depending on the set_db timing_analysis_check_type attribute.

Power analysis runs on only one view at a time, and therefore, the argument to the -view parameter must specify only one view. If you give multiple view names to the -view parameter of report_power or you do not activate the view using the set_db timing_analysis_check_type attribute, a warning message will be displayed.

For multiple views, you need to have multiple runs, one for each view. Also, you need to make the view active in order to do power analysis.

If specified as shown below,

set_analysis_view -setup {view1 view2} -hold {view3 view4}
read_spef -rc_corner best design.spef
set_db timing_analysis_check_type setup
report_power

then the power view in this case is the first setup view which is view1.The default for timing_analysis_check_type is setup.

If specified as shown in the next example,

set_analysis_view -setup {view1 view2} -hold {view3 view4}
read_spef -rc_corner best design.spef
set_db timing_analysis_check_type hold
report_power

then the power view in this case is the first hold view which is view3.

When CPF or MMMC views are loaded, SPEFs must be read after the set_analysis_view command as shown in the above examples.
