IR Drop Aware Critical Path Analysis Using Spice

Tempus supports IR drop aware spice analysis of timing paths. It writes out sensitized spice netlist for given timing path and invokes Spectre simulator to do spice simulations. Upon completion of spice simulations, Tempus reads back the spice report and generates delay comparison table between spice delays and Tempus internal delay calculator.

When IR drop files are read into Tempus, Tempus automatically creates a constant voltage source for each instance in the spice netlist with voltage specified in the IR drop file for that particular instance.

Spice Simulations with Constant IR Drop Voltage Per Instance

Spice deck created using write_spice_deck command after reading IR drop files automatically creates constant voltage source per each instance.

The following is the syntax of write_spice_deck command:

write_spice_deck [-report_timing_cmd {report_timing_options} \ 
 -power_nets {power nets} -ground_nets {ground nets} \
 -spice_model_files <spice model files> \
 -spice_subckt_files <spice sub circuit file> \

 -
out_dir
 <output directory for spice run>\
 -run_path_simulation

Example:

write_spice_deck [-report_timing_cmd {-from i_5/CK -path_type full_clock}\ 
 -power_nets {VDD VNW} -ground_nets {VSS VPW} \
 -spice_model_files "spmodels.sp" \
 -spice_subckt_files "cmos10lphvt_m.cdl" \
 -out_dir path_spice_deck_max \
 -run_path_simulation

To be able to run Spectre simulator, it should be in your search path or use -spectre_exe_path option to specify full path to Spectre.
