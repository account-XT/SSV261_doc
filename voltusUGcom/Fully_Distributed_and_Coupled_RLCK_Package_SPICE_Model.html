Fully Distributed and Coupled RLCK Package SPICE Model

The package SPICE models used in Voltus can be from different package modeling tools. However, the models generated using Sigrity XtractIM is better integrated with Voltus.

Set SPICE Package Subckt in Tcl

You can specify the SPICE package model in the Tcl command as below:


set_package -spice_model_file <file> [-mapping_file <file>] [-offset {x y}] [-rotate_angle <rotation_angle_in_degress>] [-flip {true | false}]

where [-mapping_file <file>], [-offset {x y}], [-rotate <rotation_angle_in_degress>], and [-flip {true | false}] are optional parameters. They are not required if the package model is extracted by Sigrity XtractIM and if it contains the die placement information. If the die placement information is not available in the XtractIM package model, or the package model is from third-party tools, then you can use either the MCP Editor utility to create a mapping file, or some of these parameters to instruct rail analysis how to connect the package model properly.

Controlled and Dependent Sources

In addition to the RLCK elements, Voltus supports the following "Controlled" or "Dependent" sources in the package model:

  • Voltage controlled voltage source (VCVS)
  • Current controlled current source (CCCS)
  • Voltage controlled current source (VCCS)
  • Current controlled voltage source (CCVS)

The format of these sources are given below:

Exxx n+ n- <VCVS> in+ in- gain
Fxxx n+ n- <CCCS> vn1 gain
Gxxx n+ n- <VCCS> in+ in- transconductance
Hxxx n+ n- <CCVS> vn1 transresistance

where,

n+ and n- are the positive and negative terminals of the dependent source, respectively.

in+ and in- are the positive and negative terminals of the controlling voltage source, respectively.

vn1 is the zero value voltage source used to measure the controlling current.

Example

.SUBCKT INV_5_5
+ VDDIN_1 VDD
R1 VDDIN_1 2 3
R2 2 0 5
R3 2 3 3
R4 3 0 5
R5 3 4 3
Evx 4 VDD VCVS 2 0 0.1
Evx1 4 VDD 2 0 0.2
Gvx 4 VDD VCCS 2 0 0.3
Gvx1 4 VDD 2 0 0.4
.ENDS
