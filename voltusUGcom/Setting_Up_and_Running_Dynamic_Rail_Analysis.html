Setting Up and Running Dynamic Rail Analysis

The following procedure describes how to set up the dynamic rail analysis mode and then run rail analysis.

Required Input Files

  • Power-grid libraries (.cl)
  • Vectorless or vector-based files created during dynamic power calculation

Procedure

To perform dynamic rail analysis, complete the following steps:

  1. Specify the location of the current files generated during dynamic power analysis.
    Tcl command: 

    set_power_data -reset
    set_dynamic_rail_simulation -reset
    set_dynamic_rail_simulation -resolution 50ps
    set_power_data \
        -format                     current \
        { \
            dynVecLessPowerResults/dynamic_VDD_AO.ptiavg \
            dynVecLessPowerResults/dynamic_VDD_column.ptiavg \
            dynVecLessPowerResults/dynamic_VDD_ring.ptiavg \
            dynVecLessPowerResults/dynamic_VDD_external.ptiavg \
            dynVecLessPowerResults/dynamic_VSS.ptiavg \
        }

  2. Define the rail analysis mode through the command line or through the GUI.
    GUI: Select Power Rail - Set Rail Analysis Mode.
    Tcl command: 

    set_rail_analysis_config \
        -method                     dynamic \
        -analysis_view              AV_wc_on \
        -write_movies            true \
        -write_voltage_waveforms     true \
        -accuracy                   hd \
        -temperature                125 \
        -gif_resolution             0 \
        -power_grid_libraries { \
        ../data/pgv_dir/tech_pgv/techonly.cl \
            ../data/pgv_dir/stdcell_pgv/stdcells.cl \
            ../data/pgv_dir/macro_pgv/macros_pll.cl \
        }

    Note:

    • XD uses LEF based views, and HD uses GDS based accurate views.
    • The technology library is a mandatory requirement for rail analysis. However, to obtain accurate IR drop simulation, power-grid library should be characterized for standard cells and macro blocks. When specifying the list of PGVs to rail analysis using the set_rail_analyis_config command or the Set Rail Analysis Mode form, you must specify the technology library as the first PGV library in the list.
    • You need to specify the EM analysis models if analyzing Electromigration. If you do not specify an Electromigration model file, the software will select Electromigration models from the Quantus technology file. You can use the command set_rail_analyis_config -em_models file to override these settings.

  3. Optional. If you do not load the CPF file, use the set_pg_nets command to define the power nets in the design, and assign attributes to these nets. Then, use set_rail_analysis_domain to define the power domains.
    Tcl command: 

    set_pg_nets -net VDD_AO     -voltage 0.9 -threshold 0.85 
    set_pg_nets -net VDD_ring   -voltage 0.9 -threshold 0.85 
    set_pg_nets -net VSS        -voltage 0.0 -threshold 0.05 
    set_rail_analysis_domain -domain_name PD_ring -power_nets VDD_AO  -ground_nets VSS -threshold 0.10
    set_rail_analysis_domain -domain_name PD_AO -power_nets VDD_AO  -ground_nets VSS -threshold 0.10
    set_distribute_host -custom -custom_script_list { {{bsub -m "sjf-dsgpe-07" -q hier -n 8  -K} 1} {{bsub -m "sjf-dsgpe-08" -q hier -n 8 -K} 1}}

  4. Define the location of the voltage sources for each power/ground net.
    Tcl command: 

    set_power_pads -net VDD_AO -format xy -file ../design/super_filter_VDD_AO.pp
set_power_pads -net VSS -format xy -file ../design/super_filter_VSS.pp

  5. Run rail analysis through the command line or through the GUI.
    GUI: Select Power Rail - Run Rail Analysis.
    Tcl command: 

    report_rail \
    -output_dir ./dynVecLessRailResults \
    -type                       domain

Output

The rail output directory will contain the following information:

Directory Name

Description

<domainName>_<temperature>_dynamic_<X>

For each run, an output directory is generated with the default name <domainName>_<temperature>_dynamic_<X>. <domainName> will be replaced with ALL if all domains are to be analyzed (analyze_rail -output dir -type domain ALL), or with <netName> if a power net is to be analyzed. The output directory contains state directories for each net, such as VDD and VSS.

Each state directory contains the following:

  • results – a file that gives a summary of the rail analysis results for various plots, such as tc (tap current), rc (resistor current), and so on.
  • Reports – a folder that contains a list of useful report files that contain all power-grid integrity data.
  • Auto-generated GIF files for the rail analysis plots

Tcl Command:

The following is the Tcl command for dynamic rail analysis:
set_rail_analysis_config -method dynamic \
-write_movies true -write_voltage_waveforms false \
-accuracy hd -power_grid_libraries \
{accurate_stdcells.cl memories.cl}
set_rail_analysis_domain -domain_name PDcore -power_nets VDD -ground_nets VSS
set_pg_nets -net VDD -voltage 1.08 -threshold 0.972 -tolerance 0.3
set_pg_nets -net VSS -voltage 0.0 -threshold 0.108 -tolerance 0.3
set_power_data -format current {dynamic_VDD.ptiavg dynamic_VSS.ptiavg}
set_power_pads -net VDD -format xy -file VDD.ppl
set_power_pads -net VSS -format xy -file VSS.ppl
report_rail -type domain -output_dir ./ PDcore
