Multi-Voltage Capacitance Characterization

Voltus generates PGVs that contain voltage-dependent capacitance table for the specified cell. This feature allows you to use accurate cell capacitance at different supply voltages in power-up analysis, and in different voltage domains in dynamic analysis.

To enable this feature, specify the following parameters during PGV generation:

  • set_pg_library_mode -enable_multi_voltage_cap_generation {true | false} - computes the capacitance values over a range of input voltages, including the nominal voltage. It generates 10 values from 0.1 to 1.3 times the vdd voltage.

    You can use the set_advanced_pg_library_mode -stdcell_characterization_voltage_value {val1 val2 val3 ...} parameter to specify capacitance characterization voltages when generating standard cell PGVs containing voltage-dependent capacitance table for the specified cell. This parameter allows you to compute the capacitance based on the user-defined voltage values. This parameter must be specified with the -enable_multi_voltage_cap_generation true parameter. If this parameter is not specified with -enable_multi_voltage_cap_generation, capacitance is calculated based on the software-derived voltage range. When the -stdcell_characterization_voltage_value parameter is specified, the library generation engine prints the capacitance values and corresponding voltages in the report file, and the rail analysis engine prints the capacitance used for each instance.

    The following example illustrates the use model of user-defined cap characterization:

    set_pg_library_mode  -ground_pins VSS -power_pins  {VDD 0.9 TVDD 0.9 } \
    -cell_type stdcells -enable_multi_voltage_cap_generation true
    set_advanced_pg_library_mode -stdcell_characterization_voltage_value {1.0 1.2 1.5 2.0 3.3}

    Command Example:

    set_pg_library_mode -cell_type stdcells -cells_file cellfile -extraction_tech_file ./../qrcTechFile -layer_map ./../lefdef.layermap -temperature 125 -power_pins { vcc 1.26 vccpg 1.26 vccr 1.26 } -ground_pins { vss } -power_switch_parameters {{powercell_pg1 vcc vccpg} {powercell_pg1 vcc vccr} {powercell_pg2 vcc vccpg} {powercell_pg2 vcc vccr}} -spice_corners { tt } -spice_models spice_model/libspice -spice_subckts { powercell_pg.net powercell_pg2.net } -enable_multi_voltage_cap_generation true

    The PGV report includes the following information:

    INFO: PGV contains voltage dependent cap table for this cell

  • check_pg_library -report_detail_multiple_voltage_cap filename - generates a capacitance table that contains the detailed capacitance values of the given power-grid library.

    Command Example:
    check_pg_library -report_detail_multiple_voltage_cap ../powergate_stdcells.cl
