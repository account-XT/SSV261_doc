Generating the Open Access Based Library

Voltus allows you to specify an OpenAccess (OA) database for Library Generation, instead of converting the design to the GDSII database format. When you specify an OA database with the layout data, the software generates a GDS file for the specified OA library. This GDS file is used to generate the cell library. The layermap file for GDS will be automatically created from the specified OA file. The automatic layermap file will contain arbitrary GDS layer numbers corresponding to layer names in OA. For OA setup, you must specify the first OA library as the technology library.

Note that the LEF files will be required to run this flow if the macro OA database does not have an abstract view (view containing LEF ports information).

To run this flow:

  1. Specify the read_libs -oa_ref_libs {technology_library_name cell_library_name} command.
  2. Save a cds.lib file in the home directory. This file contains the OA database for technology and cell library.

You do not need to specify a GDS layermap.

Tcl command:

The following is a sample script, called create_bump_pwrgrid.ss0p81v.tcl

read_libs -oa_ref_libs { tech_lib1  cell1 }
set_pg_library_mode \
-ground_pins VSS \
-cells_file /../cell.list \
-power_pins {VDD 0.9 VDD_LP 0.9} \
-cell_type macros \
-spice_corners {tt tt_sr} \
-spice_subckts /../cell1.net \
-lef_layer_map /../lef_layermap.txt \
-stop_via CONT \
-current_distribution {dynamic_simulation /../input_trigger.txt} \
-spice_models {/../spice90.l /../spice_90g.l.special} \
-extraction_tech_file /../c_worst.tch
set_advanced_pg_library_mode \
-techgen_dir /../tech \
write_pg_library \
-out_dir .
