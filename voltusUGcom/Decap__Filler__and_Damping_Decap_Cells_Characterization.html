Decap, Filler, and Damping Decap Cells Characterization

Decoupling capacitance on power-grid helps in reducing dynamic IR drop. When creating the power-grid library, you must specify the list of decap and filler cells for decap optimization:

  • Decap cells are cells that have explicit decoupling capacitance for use in optimization. These cells are nearly equivalent to feedthrough cells, except that there is typically an active device between the power and ground nets to provide extra decoupling capacitance. The coupling capacitance is stored in the power-grid library, and is used in top-level IR drop analysis.
  • Filler cells are cells that have no GDS data. The geometrical data contained in the LEF files for these cells is considered complete for the purposes of determining the promoted views. The data contained in the filler cells is extracted at the top level.

You can specify the list of decap and filler cells using the following command:

  • set_pg_library_mode -decap_cells <cell_name> -filler_cells <cell_name>

For Early/IR/EM view generation, the cap value for all decap cells is automatically calculated using the Spice netlist. You can also specify a value using the external LibGen include file (set_advanced_pg_library_mode -pg_library_generation_command_file). For Tech views, you can specify the default capacitance value for all cells (set_pg_library_mode -default_area_capacitance).

During standard cell cap characterization, the tool does not take into account the series resistance that connects to device coupling capacitance between the power and ground nets. The reason being that this resistance is too small to affect IR drop analysis. It only calculates coupling capacitance for each tap present in a decap cell. However, there are also some special damping decap cells that are used in the design to control resonance frequency. These decap cells have a high series resistance that needs to be modeled. You can specify the following command to model this resistance, that is, to write an additional series resistance value with the coupling capacitance value for each VDD/VSS pin:

  • set_advanced_pg_library_mode -damping_decap_cells { cell1 cell2 ..} -damping_decap_frequency value

The cells in the damping decap list will be characterized at the damping decap frequency. Damping decap cells are characterized at a very low frequency. Default is 200K Hz.
