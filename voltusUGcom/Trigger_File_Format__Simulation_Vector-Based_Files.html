Trigger File Format: Simulation Vector-Based Files

The file format of the trigger file is:

CURRENT_CHARACTERIZATION_METHOD SIMULATION
SIMULATOR APS
CELL <cellname1>
MODE_NAME <name1>
CONDITIONAL_INPUT <conditional input statement for cellname1>
CONDITIONAL_PIN <pin_name> (rise|fall|both)
CONDITIONAL_STIMULUS_FILE <usim1.txt>
END_MODE
END

where,

"!" denotes low state of the signal

"&" denotes boolean AND operation

"|" denotes boolean OR operation

For each mode, you need to specify separate stimulus files (for example usim1.txt and usim2.txt). The stimulus files contain the PWL definitions that will be used by UltraSim for simulating the specific mode.

Example

CURRENT_CHARACTERIZATION_METHOD SIMULATION
SIMULATOR APS
CELL mem1
MODE_NAME READ
CONDITIONAL_INPUT = (! ATPGM & EZ &! SCAN &! TEZ & TM &! TPAGE &! TWTZ &! TWZ)
CONDITIONAL_PIN CLK {RISE}
CONDITIONAL_STIMULUS_FILE usim.txt
END_MODE
END
