Dynamic Rail Analysis Plots, Movies and Waveforms

Dynamic rail analysis plots interface is available through Power Rail - Power Rail Results form. The interface is same as static rail analysis plots but in addition dynamic rail analysis offers various capacitance plots like grid capacitance, available capacitance, filler cell density, etc.

The following table lists the dynamic analysis plot types and the corresponding controls to enable them:

Type

Control

Power gate current I/Idsat (pi), power gate voltage (pv)

Enabled automatically when power-gate(s) are connected to the analyzed net.

Voltage across package model (vu)

Enabled automatically when package data is provided (spice model, in power pin location file, or through default_package_* commands)

Instance effective resistance (rlrp)

Enabled if set_rail_analyis_config -enable_rlrp_analysis true

Resistor current (rc)

Enabled if set_rail_analyis_config -enable_rc_analysis true

Voltage drop across vias (vv)

Enabled if set_rail_analyis_config -enable_voltage_across_vias true

In addition to dynamic plots, dynamic IR drop and Tap Current movies are generated that can be viewed using Power Rail - Dynamic Results - Waveforms form. The movies are also available using the Tcl command: view_dynamic_movie -type ir -movies_directory VDD/movies_directory. The dynamic IR drop waveforms are created for all instances in state directory as net.ptiavg file. The current waveforms through voltage sources are saved inside voltus_rail_pad.tran.ptiavg file to analyze impact of on-chip capacitance. The dynamic IR drop waveforms can be plotted using Power Rail - Dynamic Results - Waveforms form.
