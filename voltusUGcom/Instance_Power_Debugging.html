Instance Power Debugging

The calculated instance power can be debugged using the report_inst_power command. This command generates a text based report for the specified instance. The command enables you to determine how the different components of static power are calculated. You can use the report to debug after performing power analysis (report_power).

This command is available through both the static and dynamic power engines. This command is supported in the dynamic power engine by including this command in the power include file through the command set_power_include_file.

For dynamic power engine, the report_inst_power command does not generate text reports incrementally. If the dynamic run has been performed and you need the debug information for a static power number, you should re-run power analysis.

For example, the first row signifies to calculate power for 1st arc when pin A is rising and Y is rising and B is high. Activity from either the activity file or calculated by power engine is 0.0390625/1e-09. Energy number from the .lib is 3.84665e-15. Power for the arc is calculated as activity * energy 0.0390625/1e-09*3.84665e-15 = 0.00015026mw. Similarly, internal power is calculated for each arc.

The total internal power is calculated as shown below:

step 1) calculate power: A -> Y

step 2) calculate power: B -> Y

then, output power at Y is:


Power(Y) = [ Power(A -> Y) * TD(A) + Power(B -> Y) * TD(B) ] / [TD(A)+TD(B)] (#1)
Details: (in mW) Note: TD(A) =2.5*e+07; TD(B) = 3.125*e+07;
1) Power (A -> Y)
a) when = B
Power (A -> Y) = [ power (A->Y ^) + power (A -> Y v) ] /2 = [avg (rise + fall)]
               ~ [ 15.030*e-05 + 21.9*e-05 ] / 2 = 18.46*e-05
b) when = !B
Power (A -> Y) = [ power (A->Y ^) + power (A -> Y v) ] /2 = [avg (rise + fall)]
               ~ [ 16.28*e-05 + 4.01*e-05 ] / 2 = 10.145*e-05
c) final: Power (A -> Y) = Pow (A->Y) * Duty(B) + Pow (A->Y) * Duty(!B)
                         = [18.46*(0.513) + 10.145*(.487)] * e-05
                         = 14.41 * e-05
2) Power (B->Y)
a) when : A
Pow(B->Y) = 20.6 * e-05 = [avg (rise + fall)]

b) when : !A
Power(B->Y) = 20.457 * e-05 =[ avg (rise + fall)]

c) final Pow(B->Y) = Pow(B->Y) * duty(A) + Power(B->Y)*duty(!A)
                  =[ 20.6 * .4375 + 20.457 * .5625] * e-05
                   = 20.5125 * e -05

See (#1)

Power (Y) = [ (14.41 * 2.5 * e+07) + ( 20.5125 * 3.125 * e+07) ] * e-05 / [[(2.5 + 3.125)]*e+07]
= ( 9.0125 + 11.5 ) * e-05 / ( 5.625)
= 17.8 * e-05 mW
