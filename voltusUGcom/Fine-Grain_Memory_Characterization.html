Fine-Grain Memory Characterization

For fine-grain power gate support, each cell has an internal switched rail. To use fine-grain power gates, the following needs to be done:

  • Specify the set_pg_library_mode -power_switch_fine_grain_simulation true and -power_switch_parameters {{cell supply switched [Ron Idsat Ileak]}+}
  • Add a label for the switched rail manually using the set_advanced_pg_library_mode -add_port_labels file_name parameter. This file contains details about the label of a switched rail. Use this parameter if the switched rail is not labeled.

Tcl Command Example for Generating a Power-Gate Cell Library for Fine Grain Cells

The following is the Tcl script to generate a power-gate cell library for fine grain cells:

set_pg_library_mode 
-cell_type macros
-spice_subckts { typical_max_m40.spice } 
-spice_corners { ss_lib } 
-spice_models models/v1d1_usage.l 
-stream_files {mem1.gds.gz mem2.gds.gz} \
-stream_layer_map gds.layermap \
-generate_port_using_stream defmbb
-extraction_tech_file RCgen.tch 
-lef_layer_map lefdef.map 
-power_pins { VDD 1.08 VDDO 1.08 VDDG 1.08 } 
-ground_pins { VSS GND VSSG }  
-current_distribution {dynamic_simulation dynsim_trigger.txt}
-stop_via C01L
-cells_file built_cells_list 
-power_switch_parameters { { cell1 VDDG VDD } { cell2 VDDG VDD } } 
-power_switch_fine_grain_simulation true
set_advanced_pg_library_mode -add_port_labels label
write_pg_library -out_dir temp

You can also use the -power_switch_parameters parameter to specify multiple switched nets. The following example specifies that the cell block1 with vdd as always-on net and vdds1 and vdds2 as switched nets:

-power_switch_parameters {{block1 vdd vdds1} {block1 vdd vdds2}}
