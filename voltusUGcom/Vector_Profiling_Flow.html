Vector Profiling Flow

To perform Vector profiling, you must provide basic data such as the Verilog netlist, SDC file, Liberty files (.libs), SPEF file, DEF file, and the vector files (VCD, TCF, FSDB, SAIF, PHY, or SHM). Use the read_activity_file -format command to specify the file format.

By default, the report_power -out_file command parameter generates a summarized vector profile report. You can use the -time_based_report parameter to generate a detailed vector profile report with profiling results for all steps. 

The Power Analysis engine generates a text based profiling report and profiling database, which can be viewed using the SimVision interface, based on the options defined with the report_power command and power category attributes.
