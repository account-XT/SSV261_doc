Hierarchical Power Integrity Analysis with Extreme Modeling

Voltus can perform hierarchical power integrity (PI) analysis of large designs using the Extreme Modeling (XM) technology. Voltus-XM allows you to create xPGV models for the IP blocks which accurately capture the demand current and electrical parasitics of the block. These xPGV models are smaller compared to the fully extracted block and when used in the chip-level analysis, it can help significantly reduce run time and memory. The generated IP models can be reused in different designs or for multiple instantiations within a design. The modeling methodology used in Voltus-XM ensures minimal result difference relative to a fully flat analysis.

Voltus-XM (also known as xPGV generation) is an advanced PGV modeling flow that has been introduced for generating power-grid view (xPGV) models for large digital blocks. The hierarchical analysis flow with XM is intended primarily for reducing the compute resource requirements for the analysis of large designs. It can be used when there are multiple DEF files composing a design, and the blocks represented by the component DEF files can be analyzed independently.

The xPGV view is not intended for use on small macro blocks representing power switches which feed other blocks. The modeling internal to the xPGV views is based on current sources, and this can lead to inaccurate results if current flows out of the xPGV block. Avoid using this flow if there are LEF pins defined for switched nets on the block which are intended to behave as outputs. If a block contains power switches, but the switched nets are completely contained within the block, then the xPGV flow can be used. The switched net data will not appear in the view, but the current consumed by the switched nets is included in the via currents of the always-on nets that supply power to the switched nets.
