Trigger File Format: User-Defined PWLs

The file format of the trigger file is:

CURRENT_CHARACTERIZATION_METHOD PWL
CELL <cellname1>
MODE_NAME <name1>
CONDITIONAL_INPUT <conditional input statement for cellname1>
CONDITIONAL_PIN <pin_name> (rise|fall|both)
USER_PWL_FILE pwl1.txt
END_MODE
END

The format of the PWL file is:

UNIT CURRENT <current unit> (default is A, Supported values are A, mA, uA & nA)
UNIT TIME <time unit> (default is s, Supported values are s, ms, us, ns, ps)
NET <net_name1>
REGION {t1 v1 t2 v2 t3 v3.. }
NET <net_name2>
REGION {t4 v4 t5 v25 t6 v6.. }

Here, the time and current units are as defined using UNIT CURRENT and UNIT TIME syntax. NET specifies that the REGION command following it applies to the specified net name. This stays in effect until another NET or CELL specification is encountered. REGION specifies the power up piecewise linear (PWL) stimulus in (time, voltage) pair format.

Example

CURRENT_CHARACTERIZATION_METHOD PWL
CELL mem1
MODE_NAME READ
CONDITIONAL_INPUT = ( !ATPGM & EZ & !SCAN & !TEZ & TM & !TPAGE & !TWTZ & !TWZ )
CONDITIONAL_PIN CLK { RISE }
USER_PWL_FILE pwl1.txt
END_MODE
END
